# WebDriver Window Positioning

WebDriver window positioning moves a browser window to screen coordinates and can retrieve its current position. A point supplies the x and y location, which can be combined with [[WebDriver Window Sizing]] to reproduce a specific desktop or multi-monitor arrangement.

Position checks are most useful when visibility or coordinate-based behavior depends on window placement. They should not be confused with pointer offsets inside the page, which belong to [[Selenium Pointer Offset Movement]].
