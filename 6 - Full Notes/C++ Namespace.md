# C++ Namespace

A C++ namespace groups related names and prevents collisions between functions, classes, and variables that would otherwise occupy the same scope. The scope-resolution operator identifies a member of a particular namespace.

Named namespaces organize reusable libraries. An anonymous namespace instead restricts names to the current source file, which is useful for helper functions or constants that should not become part of a library's external interface.
