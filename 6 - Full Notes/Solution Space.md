# Solution Space

The solution space contains the steps, models, software structures, and technical choices proposed to move from the current state to the desired state in the [[Problem Space]]. A [[Domain Model]] belongs to the solution space even when it closely reflects domain language. Separating the two spaces prevents an early implementation idea from being treated as an immutable requirement and allows several possible solutions to be evaluated against the same business problem.
