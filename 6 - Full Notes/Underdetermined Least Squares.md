# Underdetermined Least Squares

Underdetermined least squares addresses a consistent system with fewer equations than unknowns by selecting a solution using an additional criterion.

The usual choice is the [[Minimum-Norm Solution]], the solution closest to the origin and orthogonal to the null space. Under full row rank it can be written $A^T(AA^T)^{-1}b$.
