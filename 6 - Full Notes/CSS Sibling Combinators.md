# CSS Sibling Combinators

Sibling combinators select an element according to an earlier sibling with the same parent. The adjacent-sibling combinator `+` requires the selected element to immediately follow the first match.

The general-sibling combinator `~` can match any later sibling, even when other siblings intervene. Both depend on document order and operate forward from the first selector; they do not select a preceding sibling.
