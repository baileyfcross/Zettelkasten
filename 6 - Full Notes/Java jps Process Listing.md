# Java jps Process Listing

The JDK `jps` utility lists locally visible Java Virtual Machine processes with their process identifiers and identifying launch information. It provides a Java-focused way to find the PID needed by other diagnostic tools.

Options can show main arguments, VM arguments, or fuller class and archive names. The listing is a discovery step rather than a full monitor; once the target process is identified, `jcmd`, JConsole, or Mission Control can request or observe detailed runtime state.
