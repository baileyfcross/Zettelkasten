# Java Preview Feature

A Java preview feature is fully specified and implemented but exposed temporarily so practical experience and feedback can refine its design. Its types, signatures, or behavior may still change, and exceptional feedback can redirect or discontinue it before finalization.

Preview use must be explicitly enabled during compilation and execution with `--enable-preview`; a matching source version is normally supplied during compilation. This opt-in boundary keeps experimental language or API behavior visible to users while preventing accidental dependence in ordinary builds.
