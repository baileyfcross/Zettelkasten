# Hybrid Mobile Application

A hybrid mobile application places a responsive web application inside a native container. HTML, CSS, and JavaScript can provide one shared interface implementation, while the container supplies installation and selected access to device capabilities.

This approach reduces duplicated UI work but introduces a web rendering layer between the application and native controls. Performance, interaction fidelity, and access to platform features therefore depend on the container and its native bridges.
