# Conceptual Clustering

Conceptual clustering groups observations while also building an interpretable description of each group. A concept summarizes which attribute values are predictable within the class and which values distinguish it from other classes.

COBWEB represents those concepts as nodes in an incrementally updated hierarchy. The group definition is therefore tied to an inference model, not only a geometric boundary.
