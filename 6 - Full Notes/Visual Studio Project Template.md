# Visual Studio Project Template

A Visual Studio project template creates a project with files, references, and configuration suited to a particular application type. Templates exist for console programs, class libraries, web applications, desktop interfaces, services, and tests.

Starting from the closest template removes repetitive setup while leaving the generated structure editable. The selected template should follow the intended runtime and application model rather than merely being familiar.
