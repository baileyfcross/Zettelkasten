# Validation Dataset

A validation dataset is held apart from parameter fitting and used to compare model choices, thresholds, or hyperparameters. It provides development feedback without consuming the final [[Test Dataset]].

Repeated decisions based on validation results can still overfit that partition, so final performance requires a separate untouched test.
