# AWS Outposts

AWS Outposts installs AWS-managed infrastructure at a customer site so supported AWS services can run alongside local systems. It addresses workloads that require low-latency access to on-premises equipment, local processing, or a consistent AWS operating model outside a region.

The customer supplies the site, power, physical conditions, and connectivity, while AWS manages the rack hardware and service integration. Outposts extends a region; it does not eliminate dependency on regional control planes and network links.
