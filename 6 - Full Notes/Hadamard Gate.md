# Hadamard Gate

The Hadamard gate maps computational-basis states to the diagonal basis:

$$
H|0\rangle=|+\rangle=\frac{|0\rangle+|1\rangle}{\sqrt2},\qquad
H|1\rangle=|-\rangle=\frac{|0\rangle-|1\rangle}{\sqrt2}.
$$

Applying $H$ twice returns the original state because $H^2=I$. This shows that creating equal measurement probabilities is not the same as irreversibly randomizing a qubit: a second coherent basis change can convert relative phase back into a definite computational-basis outcome.
