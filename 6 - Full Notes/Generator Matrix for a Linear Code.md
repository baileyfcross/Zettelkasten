# Generator Matrix for a Linear Code

A generator matrix $G$ maps a message vector $a$ to its [[Codeword]] $v=Ga$. Its columns are linearly independent and span the code's codeword space.

For an $[n,k]$ binary code, a standard generator matrix can be arranged as an identity block together with a redundancy block. A compatible [[Parity-Check Matrix]] $P$ satisfies $PG=0$.
