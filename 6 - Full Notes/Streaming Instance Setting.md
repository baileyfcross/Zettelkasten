# Streaming Instance Setting

A streaming instance setting presents new observations over time while the set of measured variables is comparatively stable. Feature extractors update their state from each instance rather than repeatedly processing the complete history.

Online dimension reduction and latent-variable methods operate in this regime. Their challenge is to approximate batch representations with limited memory while remaining responsive to changes in the data distribution.
