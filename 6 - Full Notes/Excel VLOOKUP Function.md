# Excel VLOOKUP Function

Excel VLOOKUP searches the leftmost column of a table and returns a value from a specified column in the matching row. Exact-match mode requires the lookup value to match, while approximate-match mode selects according to an ordered boundary table.

VLOOKUP's return column is identified by position, so inserting or rearranging columns can change the result if the formula is not adjusted. Approximate lookup also depends on correct sorting and clearly defined thresholds. When the key is not in the leftmost column or a more flexible structure is needed, [[Excel INDEX and MATCH Lookup]] separates matching from retrieval.
