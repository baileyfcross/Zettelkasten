# Occlusion Handling

Occlusion handling determines which real or virtual surface should be visible at each image location. A real object in front of a virtual object must hide it, while a virtual object nearer to the viewpoint must cover the corresponding real pixels.

Correct depth ordering requires geometry or image-derived evidence about the physical scene. Missing or inaccurate boundaries create conspicuous cutouts because occlusion is a strong depth cue.
