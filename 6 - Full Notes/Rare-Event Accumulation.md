# Rare-Event Accumulation

Rare-event accumulation means that an event with a small probability for one coordinate can become common when many coordinates are examined. For $p$ independent standard Gaussian errors, controlling the largest absolute error requires a threshold of order $\sqrt{\log p}$ rather than a fixed one-coordinate threshold.

This is the probabilistic source of the [[Multiple Testing Problem]]. A five-percent rule applied separately to thousands of null features can produce hundreds of false positives, so high-dimensional inference must control a property of the entire selection procedure rather than reuse a single-test cutoff.
