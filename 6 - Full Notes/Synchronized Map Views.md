# Synchronized Map Views

Synchronized map views display related datasets in separate maps while sharing pan, zoom, and possibly cursor position. They let viewers compare spatial patterns without combining every layer into one obscured overlay. Each view should use compatible extents and clearly labeled legends, especially when scales differ. Linked navigation preserves geographic correspondence, but visual comparison still depends on consistent projections and panel sizes.
