# CSS Float Shapes

CSS Shapes changes the boundary around which inline content wraps beside a float. Instead of always using the float's rectangular margin box, the wrap can follow a basic shape, box edge, or an image's transparency.

The shaped boundary affects surrounding content but does not clip or reshape the floated element itself. A shape margin can expand the wrap distance outside the calculated contour.
