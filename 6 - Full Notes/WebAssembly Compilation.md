# WebAssembly Compilation

WebAssembly compilation converts source written in a supported language into WASM that the browser can load and execute. The book uses WebAssembly Studio to build a small C example and inspect the generated output.

Compilation can catch source-language errors before deployment and provides an efficient browser execution target. It does not guarantee that the total application is faster because startup downloads and interactions with other libraries remain part of performance.
