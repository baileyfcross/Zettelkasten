# Strong Duality Theorem

Strong duality states that when a primal linear program and its dual attain optimal solutions, their optimal objective values are equal. The common value closes the gap permitted by [[Weak Duality Theorem|weak duality]].

This equality allows one problem's optimal tableau to reveal information about the other. It also supports the economic reading of dual variables as resource values rather than treating the dual as only a computational transformation.
