# Robot Definition Boundary

There is no stable boundary separating a robot from an ordinary machine. Some definitions require a physical system that senses its environment, processes what it senses, and acts toward a goal. Others require mobility or autonomy, while broader accounts include fixed manipulators, teleoperated surgical systems, thermostats, or even software with real-world effects.

The disagreement is not merely verbal. A strict definition can exclude devices commonly sold as robots, while a broad one can include almost every automated system. The useful response is to state which capabilities matter in a given discussion and relate them to the [[Robot Sense-Think-Act Cycle]] rather than assuming the label already settles questions of agency or responsibility.
