# Recommender System

A recommender system predicts or ranks items that may be useful to a user from observed preferences, item information, or interactions. Its output reduces a large choice space to a personalized set of candidates.

Different systems rely on [[Collaborative Filtering]], [[Content-Based Recommendation]], or a hybrid. The appropriate design depends on available feedback, scale, changing context, and how recommendation quality will be evaluated.

Users, items, and their interactions form the system's core data model. One computation predicts a user's likely utility for a candidate, while another selects and orders candidates using context or product constraints. The resulting ranked list is valuable only when it produces choices the user finds relevant and actionable.
