# AWS Firewall Manager

AWS Firewall Manager centrally defines and applies protection policies across accounts and resources in an AWS Organization. It can coordinate services such as AWS WAF, Shield Advanced, Network Firewall, and VPC security groups, then report noncompliant resources. Central policy reduces inconsistent local configuration, but delegated administration, scope, remediation behavior, and exceptions must be designed so enforcement does not unexpectedly disrupt workloads.
