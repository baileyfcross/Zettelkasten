# Expectation-Maximization Algorithm

The expectation-maximization algorithm estimates parameters when some variables are unobserved or data is incomplete. It alternates between estimating a distribution over latent values and improving parameters using that estimate.

Each iteration does not decrease the data likelihood, but convergence can lead to a local rather than global optimum. Initialization and model structure therefore influence the learned result.
