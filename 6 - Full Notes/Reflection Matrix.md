# Reflection Matrix

For a hyperplane through the origin with unit normal $u$, the matrix $H=I-2uu^T$ reflects a vector across that hyperplane. It subtracts twice the vector's projection onto the normal direction.

The matrix is symmetric, orthogonal, involutory, and has determinant $-1$. The same construction is called a [[Householder Transformation]] when used to eliminate matrix entries or build a QR factorization.
