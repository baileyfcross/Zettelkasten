# Server-Side Debugging

Server-side debugging observes application behavior running in the ASP.NET Core process. It can follow startup, middleware, the [[HTTP Request Pipeline]], controllers, entities, and database queries as one request is handled.

Breakpoints and diagnostic output make runtime values visible without changing the public response. Production systems should rely on protected logs rather than exposing detailed errors to clients.
