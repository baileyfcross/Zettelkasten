# Java if-else Statement

A Java `if` statement executes a branch when its boolean condition is true. An optional `else` supplies the alternative, and an `else if` chain evaluates later conditions only after earlier ones fail.

Braces make the intended block explicit even when it currently contains one statement. Conditions can combine short-circuit operators so an earlier test protects a later operation. When many branches compare one selector against known alternatives, a `switch` can express the decision more directly.
