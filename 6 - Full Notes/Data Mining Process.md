# Data Mining Process

A compact data mining process defines the problem, prepares and explores the data, selects or constructs a model, explores and validates that model, and deploys and updates it.

These activities are interdependent. Deployment creates new data and feedback, while model exploration can reveal preparation defects. Treating the process as a cycle makes revision part of normal operation.
