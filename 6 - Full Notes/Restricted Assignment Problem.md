# Restricted Assignment Problem

A restricted assignment problem prohibits a specific origin-destination pairing. The forbidden cell is given an infinite or sufficiently large cost before the [[Hungarian Method]] is applied.

This device prevents the cell from being chosen when a permitted complete assignment exists. Multiple restrictions can make the model infeasible, so the final assignment must be checked to ensure every required row and column is still matchable.
