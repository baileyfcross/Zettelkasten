# Network Topology

A network topology describes the arrangement of nodes and communication links. Physical topology records the actual infrastructure, while logical topology describes the path and direction by which nodes exchange data.

Topology affects routing, cost, resilience, and failure concentration. Software should account for those effects without assuming that the logical path visible to an application exactly matches the underlying cables or radio links.
