# Cloud Cost Model

A cloud cost model estimates what a provider must spend to create, operate, maintain, and eventually refresh a cloud service. It can include equipment, capital, labor, software licenses, electricity, cooling, floor space, depreciation, inflation, and exchange-rate effects.

Risk and a desired margin are added to those costs before they become a [[Cloud Price Model]]. One-time costs can be converted into recurring amounts so the provider can express the service as a regular charge.
