# Spectral Feature Selection Frameworks

Spectral Feature Selection Frameworks is the chapter-level topic for selecting original variables by preserving graph-encoded relationships among samples. Full Notes should link to one of the focused child topics rather than directly to this chapter tag.

## Overview Chapter

Feature selection reduces dimensionality while keeping the original variables available for interpretation. The spectral approach begins by replacing a narrowly defined prediction target with a more general object: a matrix describing which samples should be regarded as similar. This makes the same framework useful with class labels, unlabeled geometry, a mixture of labeled and unlabeled observations, or additional knowledge sources. The central question is no longer merely whether one variable correlates with an outcome. It is whether the values of a variable, or a selected group of variables, preserve the relationships that define the learning problem.

[[Spectral Feature Scoring and Graph Structure]] develops the univariate version of that idea. A sample-similarity matrix becomes a weighted graph, and its normalized Laplacian supplies eigenvectors ordered by graph smoothness. Leading nontrivial eigenvectors behave like soft indicators of the graph's large-scale divisions: nearby samples receive similar values, while later eigenvectors increasingly describe finer or noisier variation. A feature is useful when its values align with the relevant smooth directions. The SPEC framework turns this principle into a filter method by combining a similarity matrix, a spectral transformation, and a ranking function. Different similarity constructions produce supervised, unsupervised, or semi-supervised selectors without changing the basic mechanism. Removing the trivial density direction, truncating noisy tail eigenvectors, and transforming eigenvalues are not cosmetic choices; they determine what structure the score rewards and how stable the ranking remains under perturbation.

Univariate scores cannot tell whether several individually strong features repeat the same information. [[Multivariate Spectral Feature Selection]] addresses that limitation by evaluating a set jointly. One formulation treats weighted spectral directions as multiple regression targets and applies an L2,1 penalty to the coefficient matrix. Because the penalty operates on entire rows, one predictor is either used across the target representation or suppressed altogether. Another formulation compares a target similarity matrix with the kernel reconstructed from selected features, repeatedly updating a residual similarity matrix. Both formulations aim to preserve sample relationships while avoiding redundant variables. Active-set and regularization-path methods make the row-sparse problem practical when the desired output is a fixed number of features rather than a preselected penalty value.

[[Spectral Feature Selection Connections and Evaluation]] shows why apparently different selectors can share this interpretation. Laplacian Score rewards locality preservation; Fisher Score rewards within-class compactness and between-class separation; ReliefF contrasts nearby hits with nearby misses; the trace-ratio criterion compares within- and between-class graph structure; and a linear-kernel HSIC selector measures dependence with a target kernel. Under suitable normalizations, each can be written as a feature vector aligned with a particular similarity operator. The multivariate formulation also connects selection to least-squares versions of linear discriminant analysis, support vector classification, and principal component analysis. These connections do not make the algorithms interchangeable: their similarity matrices, normalization rules, and redundancy behavior remain different. Evaluation should therefore distinguish predictive accuracy, selected-feature redundancy, continuous similarity residual, and neighborhood preservation.

When both the sample count and feature count are large, the pairwise and regression calculations can exceed one machine's capacity. [[Parallel Spectral Feature Selection]] decomposes useful quantities into sums over samples. Workers compute local matrix products, feature-residual correlations, or similarity contributions, and collective operations combine them into global results. This design can approach linear speedup when local arithmetic dominates communication, but the cost model must keep CPU work and network transfer separate. Similarity construction, univariate scoring, active-set optimization, and matrix-comparison updates have different communication patterns, so they should not be described by one generic claim that an algorithm is parallel.

Small-sample, high-dimensional problems present the opposite difficulty: computation may be feasible, but the observations do not contain enough evidence to estimate relevance reliably. [[Multi-Source Feature Selection]] supplements the target data with knowledge about samples or features. Feature similarity, feature function, feature interaction, sample categories, and auxiliary measurements have heterogeneous representations, so they must be converted into internal forms a selector can use. One framework converts every source into a sample-similarity matrix and fuses those matrices before spectral selection. A more general framework produces a ranking from each knowledge source and learns how to aggregate the rankings. Relevance can also propagate through a feature-relation graph or be voted through known feature functions.

These five views form a single progression. A graph defines the target structure; a spectral score measures alignment; multivariate optimization controls redundancy; distributed decomposition makes the calculation scalable; and knowledge integration stabilizes relevance when the target sample is too small. The approach remains conditional on modeling choices. A misleading similarity matrix faithfully preserves the wrong relationships, an ill-chosen spectrum can emphasize noise, a sparse penalty can omit complementary variables, network overhead can erase parallel gains, and an external knowledge source can import bias. Spectral feature selection is therefore best understood as a family of explicit structure-preservation models, not as one universally correct ranking formula.
