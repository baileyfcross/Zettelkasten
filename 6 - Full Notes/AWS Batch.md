# AWS Batch

AWS Batch schedules containerized batch jobs onto dynamically provisioned compute environments. Job definitions describe the container and resources, job queues establish priority, and dependencies can order related work. The service is well suited to large sets of independent or parallel tasks and can use EC2, Spot, or Fargate capacity. Efficient batching still requires appropriate job granularity, retry behavior, data locality, and idempotent processing.
