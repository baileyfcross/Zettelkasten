# JavaScript Array Map

`Array.map` invokes a transformation function once for every source item and returns an array containing each result. The output has the same number of positions but may contain strings, objects, React elements, functions, or any other JavaScript value.

Because map creates a new array, it can update one matching object by returning a copied replacement while returning all other objects unchanged. React also uses map to turn data collections into element collections, with a stable key helping the renderer identify each resulting child.
