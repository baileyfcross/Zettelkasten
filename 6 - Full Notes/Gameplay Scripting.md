# Gameplay Scripting

Gameplay scripting implements frequently changed rules, events, quests, interfaces, or object behavior in a higher-level language connected to the game engine. Scripts usually trade some execution performance for faster iteration and easier authoring.

The engine exposes selected functions and data rather than unrestricted internals. This boundary keeps performance-critical systems in native code while allowing game-specific behavior to change without rebuilding the entire engine.
