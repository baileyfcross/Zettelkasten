# Git Clone

`git clone` creates a local repository from an existing repository location. The result includes a working tree, commit history, branches and tags available from the source, and remote configuration for later synchronization.

Cloning differs from downloading only the current files because it preserves the repository's version-control data. Local commits can then be created offline and later exchanged with the configured remote.
