# XAML User Interfaces

XAML is a declarative markup language used to construct .NET user-interface object trees. Elements correspond to controls and containers, attributes set properties, and nesting expresses visual or logical composition.

Code-behind can respond to events, while binding and commands reduce direct manipulation of controls. Separating declarative presentation from application behavior makes layout, styling, and reusable resources easier to reason about.
