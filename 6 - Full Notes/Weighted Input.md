# Weighted Input

Weighted input is the sum obtained by multiplying each artificial-neuron input by its corresponding [[Neural Network Weight]] and adding the products. A [[Neural Network Bias]] is then added before the value enters the [[Activation Function]].

This calculation lets different connections influence the neuron by different amounts. Training changes the weights and bias, thereby changing how the same external input propagates through the network.
