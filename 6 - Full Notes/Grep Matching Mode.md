# Grep Matching Mode

Grep matching mode determines whether a search pattern is interpreted as a basic regular expression, an extended regular expression, or a fixed string. Fixed-string mode is the safest and often fastest choice when metacharacters should be treated literally.

Other options can require whole-word or whole-line matches, ignore case, invert selection, or print counts and line numbers. The chosen mode should reflect whether the input is a pattern language or ordinary text supplied by a user.
