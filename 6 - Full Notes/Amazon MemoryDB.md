# Amazon MemoryDB

Amazon MemoryDB is a durable, Redis-compatible in-memory database for applications that need very low latency while retaining a primary database record. It combines an in-memory access layer with a durable multi-availability-zone transaction log. This distinguishes it from using a cache whose contents can be reconstructed from another database. Dataset size, command compatibility, persistence needs, and cost determine whether MemoryDB or ElastiCache is the better fit.
