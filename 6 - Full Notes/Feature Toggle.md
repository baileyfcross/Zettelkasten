# Feature Toggle

A feature toggle separates deployment from exposure by allowing code already present in a live build to be enabled or disabled through configuration. Teams can integrate incomplete or experimental work without making it available to every player.

Toggles support staged testing and rapid rollback, but each one adds state and maintenance cost. Temporary toggles should be removed after their decision has been made.
