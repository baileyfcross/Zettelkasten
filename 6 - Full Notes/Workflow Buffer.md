# Workflow Buffer

A workflow buffer is a bounded queue of completed work held between stages to absorb variation. It can keep a downstream constraint supplied when upstream completion is uneven.

Buffers trade resilience for waiting time: larger buffers increase lead and cycle time and can conceal flow problems. Their size should protect the constraint without becoming unexamined inventory.
