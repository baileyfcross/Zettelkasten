# Blazor

Blazor is Microsoft's framework for building interactive web interfaces with Razor markup and C#. In the 2019 source, it connects familiar ASP.NET-style component syntax to either server-side execution or an experimental client-side WebAssembly model.

A `.razor` component combines HTML, event bindings, and a C# code block. The framework tracks state changes and updates the displayed document, letting developers create a single-page interaction without writing the component behavior in JavaScript.
