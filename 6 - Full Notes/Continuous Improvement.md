# Continuous Improvement

Continuous improvement repeatedly inspects how value is created, chooses a small change, and measures whether the system improves. Problems exposed by transparency become inputs to learning instead of reasons to conceal the real process.

A [[Sprint Retrospective]] creates a recurring cadence for this work, while Lean methods extend attention to the whole value stream. Improvement is part of delivery, not a separate initiative postponed until work is quiet.
