# Amazon Bedrock Knowledge Base Java Retrieval

An Amazon Bedrock Knowledge Base can retrieve managed knowledge sources for a Java generative-AI application. The source presents retrieval as a grounding stage that can be invoked through AWS services before or together with generation.

Managed retrieval still requires corpus governance. Data-source synchronization, identity, metadata filters, result limits, citations, and answer evaluation determine whether the application supplies current and authorized evidence rather than merely plausible context.
