# Cloud Gear

A cloud gear is a specialist form of [[Cloud Cell]] used mainly in infrastructure or platform services. It packages a focused supporting application such as antivirus protection, disk encryption, public file sharing, or backup.

Treating the capability as a reusable unit allows it to be attached to more than one cloud service instead of being rebuilt for every environment. Its interface and management requirements must be standardized for that reuse to be dependable.
