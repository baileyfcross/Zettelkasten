# Digital Input Device

A digital input device reports discrete states, commonly interpreted as on or off. Keyboard keys and gamepad buttons are examples, but useful game behavior usually requires more meaning than the current binary value.

Comparing present and previous states yields transitions such as just pressed and just released. Those transitions distinguish a single command from an action intended to continue while the control is held.
