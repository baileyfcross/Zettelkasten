# Manual Perspective-Plane Scene Extraction

Perspective lines in a photograph can guide a connected set of floor, wall, ceiling, and recess planes. The book builds a hallway this way with Photoshop's Vanishing Point grids, extending each new plane from an existing edge so its orientation remains related to the rest. Exporting the planes yields a basic textured 3D environment that can be lit or used with an added CG character. A mismatched starting grid propagates through later planes, so visible lines such as floor tiles should be aligned carefully.
