# Cube Root

A cube root of (a) is a number whose [[Cube]] equals (a):

$$b=\sqrt[3]{a}\quad\text{when}\quad b^3=a.$$

For example, (sqrt[3]{27}=3) and (sqrt[3]{-27}=-3). Because cubing preserves sign and is one-to-one on real numbers, every real number has exactly one real cube root. The index (3) is written on the radical symbol, unlike the usually omitted index (2) of a [[Square Root]].
