# HTTP POST

HTTP POST submits a representation for the server to process, commonly creating a new resource beneath a collection endpoint. The API binds and validates the request body before calling the write operation.

A successful creation response can include the created representation and its resource location. Invalid input should be reported before persistence, while authentication may identify who is making the change.
