# Deep Game Data Analysis

Deep game data analysis enumerates the distinct values of an attribute, counts how often each occurs, and charts the resulting distribution. This exposes structure hidden by high-level statistics, such as gaps in a scale, several frequency peaks, tight clusters, or counterbalancing high and low outliers.

The method can reveal implicit classes like weak, average, and strong objects or show that one attribute value has a special systemic role. Analysis becomes increasingly specific to the game as it goes deeper, so its goal is not to apply every possible calculation but to form and investigate useful explanations of the observed pattern.
