# Cloud Maturity Model

A cloud maturity model assesses how deliberately an organization purchases, uses, controls, and improves cloud services. The book defines five stages: performed, defined, managed, adapted, and optimized.

Maturity can be assessed separately for people, processes, monitoring and reporting, oversight, and financial management. The overall level reflects where most characteristics coincide, while differences among dimensions identify the next practical improvements.
