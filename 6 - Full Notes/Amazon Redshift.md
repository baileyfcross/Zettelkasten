# Amazon Redshift

Amazon Redshift is a managed analytical data warehouse built for large SQL queries and massively parallel processing. It serves reporting and aggregation workloads that differ from the small transactional updates of an operational relational database.

Redshift can run as provisioned or serverless capacity, and Redshift Spectrum can query selected data in S3 without loading it into warehouse tables first. Data layout, ingestion, access, and workload isolation still shape performance and cost.
