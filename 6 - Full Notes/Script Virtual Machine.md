# Script Virtual Machine

A script virtual machine executes an intermediate instruction representation produced from source scripts. It maintains execution state, operands, variables, calls, and control flow independently from the processor's native instruction set.

The engine can pause, resume, or invoke scripted behavior through this controlled runtime. Interpretation adds overhead, but the virtual machine provides portability and a clear boundary between scripts and lower-level engine code.
