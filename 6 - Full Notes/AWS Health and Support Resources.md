# AWS Health and Support Resources

AWS health and support resources include service-status information, account-specific health events, documentation, the Knowledge Center, FAQs, and security guidance. They help customers distinguish a provider event from a local configuration failure and find supported remediation information.

Public status is broad, while account-aware health information identifies events relevant to the customer's resources. These sources should feed an incident process rather than be checked only after users report an outage.
