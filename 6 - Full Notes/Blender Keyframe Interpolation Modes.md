# Blender Keyframe Interpolation Modes

Blender keyframe interpolation modes determine how an animated value moves between known keys. Constant holds the previous value until the next key, Linear changes at a uniform rate, and Bezier uses editable handles to create smooth acceleration and deceleration. Easing families and dynamic effects such as Back, Bounce, and Elastic provide more specialized transitions.

The mode is part of motion design, not merely curve appearance. Constant supports blocking and abrupt state changes, Linear suits uniform movement, and Bezier supports controlled natural timing. More dramatic easing can communicate anticipation, impact, or rebound, but inappropriate overshoot may make motion appear weightless or physically implausible.
