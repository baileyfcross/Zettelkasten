# API Data Privacy and Retention

API data privacy governs which personal data an interface collects, the lawful purpose for processing it, who may access it, and how consumers can exercise applicable rights. The book connects these obligations to consent, encryption, access control, breach response, and cross-border transfer.

A retention policy adds a time boundary: personal data should not remain indefinitely merely because storage is available. The API and its backing services need deletion, correction, audit, and export behavior that matches the published privacy policy and relevant compliance obligations.
