# Explosion Diagram

An explosion diagram separates the components of an assembled object along controlled directions so internal structure and part relationships become visible. In AR, the diagram can remain registered with the physical assembly while virtual components move into a more legible arrangement.

The transformation must preserve correspondence between each displaced part and its original location. It is especially useful when direct transparency would create excessive visual interference.
