# Zero-Interaction Interface

A zero-interaction interface performs a useful task without requiring the user to issue a command at the moment of action. Sensors, stored preferences, external data, and rules allow the system to infer when a response is appropriate and carry it out automatically.

A connected irrigation controller can adjust watering from soil conditions and forecasts after its initial setup. The disappearance of visible controls does not eliminate interface design; it moves design into configuration, feedback, exceptions, and override. Users still need to understand what the system did, correct mistaken assumptions, and regain control when the automation behaves unexpectedly.
