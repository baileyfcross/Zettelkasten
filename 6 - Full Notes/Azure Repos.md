# Azure Repos

Azure Repos provides version-controlled repositories within an Azure DevOps project. It stores the source history that build and release pipelines consume and supports collaborative controls around branches and proposed changes.

Connecting commits and pull requests to work items adds traceability from a planned need to the code that implements it. The repository remains an evidence source, not a replacement for requirements or review.
