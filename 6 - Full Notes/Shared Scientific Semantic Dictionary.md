# Shared Scientific Semantic Dictionary

A shared scientific semantic dictionary assigns communal definitions to domain concepts used in data and computation. A value can point to a dictionary entry that states what the quantity means, how it is represented, and which units or constraints apply.

The dictionary prevents two programs from interpreting the same label differently and reduces dependence on outdated human documentation. Its terms need stable [[Unique Semantic Identifier|identifiers]] so meaning survives file movement and software changes. Community adoption is essential: a private dictionary can be precise but will not provide interoperability across laboratories.
