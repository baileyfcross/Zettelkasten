# R Color Specification

R color specification assigns named colors, indexed palette entries, or explicit color values to graphical elements. A vector of colors can distinguish several series or categories when its order matches the order used to draw and label them.

Color should reinforce a substantive grouping or numeric scale and remain interpretable when printed or viewed with color-vision differences. Redundant line types or symbols keep the message available when hue alone is insufficient.
