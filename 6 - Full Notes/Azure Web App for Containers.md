# Azure Web App for Containers

Azure Web App for Containers runs a web or API container on the App Service platform. It fits lift-and-shift applications and conventional web hosting that need managed scaling, deployment slots, TLS, and platform integration without Kubernetes operations. The App Service plan defines the underlying shared or dedicated capacity, so image portability does not remove decisions about instance size, scale, networking, persistent files, startup, and health checks.
