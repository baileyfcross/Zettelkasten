# Cluster Co-Association Matrix

A cluster co-association matrix records how often each pair of observations appears in the same cluster across an ensemble. It converts label-invariant partition evidence into a similarity matrix.

A standard clusterer can partition the matrix to obtain consensus groups. The representation captures pairwise agreement but loses higher-order structure, and a homogeneous ensemble may make shared bias look like strong evidence.
