# JavaFX Scientific Visualization

JavaFX can place interactive visualization inside a scientific design loop rather than waiting until a calculation finishes. The Deep Space Trajectory Explorer cited in the book combines multibody trajectory calculations with manipulable visualizations so mission designers can compare orbits against constraints while refining a design.

This pattern pairs Java's scalable computation with a scene graph, charts, and 3D extensions that can expose intermediate state. Immediate visual feedback can shorten the development cycle and make constraint tradeoffs easier to understand. Libraries such as [[FXyz JavaFX 3D Extensions]] add domain-oriented geometry, while [[JavaFX ND4J and JShell Workflow]] shows how small visualization functions can be called during exploratory numeric work.
