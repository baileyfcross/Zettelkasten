# Vector

A vector is an ordered row or column of values. It is a special case of a [[Matrix]] and can represent a state, a set of coordinates, or a collection of related measurements.

In PageRank, the [[PageRank Vector]] contains one relative-importance value for every web page. Repeated [[Vector-Matrix Multiplication]] updates those values until they converge to an [[Eigenvector]] of the Google matrix.

A row vector is a $1\times n$ matrix and a column vector is an $n\times1$ matrix. Beyond coordinates, a vector is any element of a [[Vector Space]], where [[Vector Addition]] and [[Scalar Multiplication of a Vector]] obey the vector-space axioms.

The source collects all observed outcomes into one column vector and all unknown linear-model parameters into another. Vector notation replaces a separate scalar equation for every experimental unit with a single matrix equation that is easier to manipulate and implement in R.
