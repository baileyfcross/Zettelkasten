# Target Object Guidance

Target object guidance directs a user toward a physical or augmented object that is not currently visible. The interface communicates direction and sometimes distance while preserving awareness of the surrounding environment.

Once the object enters view, registered highlighting or annotation can replace the off-screen cue. The transition should make clear that both cues refer to the same target and avoid directing attention through an unsafe or impossible route.
