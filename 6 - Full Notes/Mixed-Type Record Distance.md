# Mixed-Type Record Distance

Mixed distance combines component dissimilarities for records containing both continuous and discrete attributes. Attribute-information objects dispatch the type-appropriate calculation, allowing one loop to handle a heterogeneous schema.

Numeric and categorical contributions must be placed on compatible scales or one type can dominate. The implementation's uniform interface does not remove the modeling need to choose weights and normalization.
