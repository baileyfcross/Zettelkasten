# Multi-Agent Task Decomposition

Multi-agent task decomposition divides a complex objective into bounded subtasks assigned to agents with distinct expertise or tools. The decomposition specifies dependencies and identifies which results must be combined before the overall workflow can finish.

Splitting work is valuable only when the boundaries reduce complexity or enable independent evidence gathering. Excessive decomposition adds coordination cost, duplicates context, and makes errors harder to attribute, so a single agent remains preferable for tightly coupled work.
