# Directed Graph

A directed graph is a [[Graph]] whose edges have directions. An edge from vertex $A$ to vertex $B$ does not imply that another edge leads back from $B$ to $A$.

The web is directed because one page may link to another without receiving a return link. Directed graphs can contain cycles, while a [[Directed Acyclic Graph]] prohibits them and is useful for dependency and prerequisite relationships.
