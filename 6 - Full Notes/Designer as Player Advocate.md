# Designer as Player Advocate

The game designer acts as an advocate for the player by evaluating decisions from the perspective of someone encountering the finished game without the team's history and explanations. A convenient implementation is not automatically an acceptable experience.

This responsibility requires resisting familiarity bias. Developers compare the current build with earlier broken versions and know why every feature exists; a new player sees only the present interface and consequences. Playtesting supplies the outside evidence needed to correct that gap.
