# AI Network Health Analysis

AI network health analysis summarizes structured device metrics into conditions, likely concerns, and recommended investigation. A prompt can ask for an overall assessment while preserving the per-device measurements that support each conclusion.

The result should distinguish threshold evidence from interpretation. High CPU and rising latency may justify attention, but the model cannot establish causation from one snapshot. Conventional alerts and rules can identify known conditions, while the model adds explanation and prioritization that an engineer verifies against current telemetry.
