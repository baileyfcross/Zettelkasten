# Web Deploy Package

A Web Deploy package is a portable deployment artifact produced for later installation through Web Deploy rather than sent immediately to a live destination. It separates package creation from the moment and credentials of deployment.

This is useful when another operator or environment owns the release step. The package must still correspond to the target's runtime and configuration expectations.
