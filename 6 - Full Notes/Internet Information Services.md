# Internet Information Services

Internet Information Services is the Windows web server used to host published ASP.NET Core applications. A site binding connects host, port, and certificate settings to the deployed application folder.

After the ASP.NET Core hosting bundle is installed, IIS can run the application with an in-process model and an appropriately configured application pool. HTTPS requires a certificate and secure site binding.
