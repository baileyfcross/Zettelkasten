# Amazon Managed Workflows for Apache Airflow

Amazon Managed Workflows for Apache Airflow runs Apache Airflow so teams can define scheduled data workflows as directed acyclic graphs without administering the orchestration servers themselves. Tasks encode dependencies, retries, and schedules across ingestion and transformation services. MWAA coordinates work rather than performing every transformation; reliable pipelines still require idempotent tasks, protected credentials, observable failures, and clear ownership of the systems each task invokes.
