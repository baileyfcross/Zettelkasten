# Redundant Feature Elimination

Redundant feature elimination removes variables that add no new target information once other selected variables are known. A feature may correlate with the class yet still be redundant because another feature already represents the same predictive signal.

Eliminating redundancy narrows the hypothesis space and reduces the time required to train a classifier. It must be distinguished from removing irrelevant features, which lack a useful direct association with the target in the first place.
