# Linear Programming Sensitivity Analysis

Linear programming sensitivity analysis studies how changes in objective coefficients, constraint coefficients, resource limits, variables, or constraints affect an optimal solution.

For right-hand-side changes that preserve the current basis, a shadow price gives the change in optimal objective value per additional unit of a resource. Larger changes may require reoptimization.

Changes to resource values, new constraints, or deleted variables can disturb feasibility, while changed objective coefficients, new activities, changed activity columns, or deleted constraints can disturb optimality.
