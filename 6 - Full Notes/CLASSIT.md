# CLASSIT

CLASSIT extends COBWEB-style conceptual clustering so numerical as well as nominal attributes can be represented. Numeric values are summarized through distribution parameters rather than treated as unrelated categories.

The extension retains incremental probabilistic hierarchy construction while addressing the original method's restriction to nominal attributes.
