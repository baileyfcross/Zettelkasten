# Web Crawler

A web crawler systematically follows [[Hyperlink|hyperlinks]] to discover and read web pages. Search engines use crawling to collect the documents and connections that can later be indexed and searched.

Crawling and ranking are separate tasks. The crawler supplies page content and link structure, a [[Search Engine Index]] supports matching a query, and [[PageRank]] can help order the matched pages by relative importance.
