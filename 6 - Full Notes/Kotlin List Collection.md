# Kotlin List Collection

A Kotlin list stores an ordered sequence and permits access by position. Repeated values are allowed because identity in the sequence includes where an element occurs, not merely whether the value is present.

`listOf` presents a read-only list interface, while `mutableListOf` supplies insertion, removal, and replacement operations. Choosing between them states whether the caller should only observe the ordering or is also responsible for changing it.
