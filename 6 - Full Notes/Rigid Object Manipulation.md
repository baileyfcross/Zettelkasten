# Rigid Object Manipulation

Rigid object manipulation uses the measured pose of a physical object as input to an augmented application. The user translates or rotates a tracked prop, and the system maps that motion to a virtual object, tool, viewpoint, or parameter.

Physical shape and constraints can supply useful affordances and passive haptic feedback. The mapping must account for tracking range, occlusion, clutching, and whether the prop's real geometry is semantically related to its virtual role.
