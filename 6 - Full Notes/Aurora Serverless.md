# Aurora Serverless

Aurora Serverless adjusts database compute capacity according to workload demand while retaining Aurora's managed relational storage. It suits variable or intermittent applications that do not need a fixed provisioned instance size at all times.

Serverless capacity changes the compute-management and billing model, not relational semantics. Connection behavior, supported features, scaling range, and workload latency still need evaluation before replacing a consistently provisioned cluster.
