# Rational Implicitization

Rational implicitization converts coordinate ratios fᵢ/gᵢ into polynomial equations for the closure of the parametrized image. The construction must exclude parameter values where a denominator vanishes.

Auxiliary variables and equations enforce the nonvanishing condition before a [[Gröbner Basis]] eliminates parameters. The resulting relations describe the image without retaining the original parameter coordinates.
