# Softmax Function

The softmax function converts a vector of real-valued outputs into a probability distribution. Every resulting value lies between zero and one, and all values sum to one.

In a multiclass [[Classifier]], each output corresponds to one label and can be interpreted as the network's confidence for that class. [[Categorical Cross-Entropy]] compares this predicted distribution with the target distribution during training.
