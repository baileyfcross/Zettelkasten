# Amazon EventBridge Rule

An Amazon EventBridge rule matches events on an event bus and routes matching events to one or more targets. Its event pattern can select fields from events emitted by AWS services, custom applications, or integrated software providers; a rule can also run on a schedule.

EventBridge enables event-driven integration without requiring producers to know their consumers. Targets may include Lambda, SQS, SNS, or an [[AWS Step Functions State Machine]], allowing a matched state change to trigger asynchronous work or a coordinated workflow.
