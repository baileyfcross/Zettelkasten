# UML Sequence Diagram

A UML sequence diagram shows an interaction as messages ordered across participants. Lifelines are arranged horizontally, and progress down the diagram represents the order in which calls, returns, and other events occur.

The view explains how one scenario flows through a system rather than describing every possible behavior. It can expose responsibility chains, missing responses, and unnecessary hops that a static class diagram does not show.
