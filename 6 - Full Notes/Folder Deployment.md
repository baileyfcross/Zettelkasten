# Folder Deployment

Folder deployment writes an application's publish output to a selected local or network directory. It produces the final artifact layout without assuming how another process will copy, package, or install that output on the server.

The target is useful for inspection and for release systems that take responsibility after the build. A successful folder publish confirms artifact production, not that the eventual host can run the application.
