# Target Hardware Polygon Budget

A polygon budget allocates geometric complexity according to the devices expected to run the game. Mobile hardware, older computers, and high-end desktops cannot display the same scene cost at the same frame rate.

The budget applies to the whole visible scene, not each object in isolation. Prominent interactive assets may receive more geometry while distant or repeated objects rely on simpler meshes, [[Baked Surface Detail for Low-Poly Assets|baked detail]], and level-of-detail variants.
