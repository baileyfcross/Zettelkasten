# Secure Sockets Layer

Secure Sockets Layer encrypted data exchanged between a browser and server and authenticated the connection. Netscape introduced it to protect information such as credit-card numbers sent over the Web.

Secure transport made commercial transactions more credible on an open network. Its descendants underpin HTTPS, even though the original protocol versions have been replaced.
