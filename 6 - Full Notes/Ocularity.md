# Ocularity

Ocularity describes how display imagery is delivered to the eyes. A monocular display serves one eye, a bi-ocular display presents the same image to both eyes, and a binocular display supplies a separately rendered view to each eye.

Only the binocular arrangement can reproduce stereoscopic disparity as a depth cue. The choice also affects hardware complexity, field coverage, comfort, and how consistently virtual content can be aligned with the physical view.
