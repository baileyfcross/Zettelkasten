# Uncertain Decision Tree Classification

Uncertain decision tree classification evaluates how probability mass, rather than a single value, crosses a candidate split. An uncertain observation may contribute fractionally to more than one child node.

Split quality and class distributions are computed from these weighted contributions. Prediction similarly aggregates possible paths, retaining uncertainty through the tree instead of assigning the observation prematurely to one branch.
