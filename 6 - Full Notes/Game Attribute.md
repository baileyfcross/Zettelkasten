# Game Attribute

A game attribute is a named value that contributes to a part's current state and influences the rules that use it. Mechanics specify behavior; attributes supply the data that varies that behavior without rewriting the rule. Attributes may be visible to players, hidden, or derived from other values.

Attribute ranges should be understandable, broad enough to distinguish meaningful states, and reusable across related parts. Every added attribute increases implementation and balance complexity, so it should enable useful behavior or a [[Meaningful Decision]].

An attribute needs a game-specific definition and an explicit relationship to one or more mechanics. A real-world idea such as strength has many possible meanings, but a game may define it narrowly as the maximum weight a character can lift or the value used by a combat formula. Candidate attributes can be simplified into a [[Game Attribute Group]] when the distinctions do not serve the designed activity.
