# Roblox Studio Project Lifecycle

A Roblox project moves through creation, local or cloud saving, playtesting, publishing, and continued revision. Roblox Studio can start from a template or an empty place, while its editing panels expose the objects and properties that make up the experience.

Playtesting runs a temporary simulation, so changes made only while the simulation is active are not durable edits. A reliable workflow returns to edit mode, saves intentional changes, tests again, and publishes only after the experience behaves as intended. This lifecycle connects the editing environment to [[Roblox Place Structure]] and the reusable assets managed through [[Roblox Package Versioning]].
