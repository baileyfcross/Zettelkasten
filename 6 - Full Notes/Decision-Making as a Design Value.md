# Decision-Making as a Design Value

A decision-making design value specifies where players should choose, which consequences should matter, and how much information should be available at the moment of choice. It identifies the intended relationship between deliberation and action.

This value can call for transparent optimization, bluffing under hidden information, rapid commitment, or reflective ambiguity. The interface and feedback should preserve that intended decision condition rather than accidentally resolving or obscuring it.

The value should also identify when the player is meant to have [[Player Agency]]. Adding choices indiscriminately can create [[Choice Overload in Games|choice overload]], while removing a routine [[Obvious Game Decision]] can preserve attention for decisions that actually matter.
