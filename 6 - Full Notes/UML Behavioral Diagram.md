# UML Behavioral Diagram

A UML behavioral diagram describes what a system does: actions, interactions, state changes, timing, or externally visible functions. It complements a structural diagram by showing behavior performed by or across the system's parts.

[[UML Use Case Diagram|Use case diagrams]] organize goals and actors, while [[UML Sequence Diagram|sequence diagrams]] order messages among participants. Each view answers a different behavioral question and deliberately omits unrelated implementation detail.
