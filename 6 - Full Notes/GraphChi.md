# GraphChi

GraphChi is a single-machine graph-processing system that handles graphs larger than memory by organizing edges into disk shards. Parallel sliding windows turn many random graph accesses into more efficient sequential storage operations.

It demonstrates that out-of-core layout and scheduling can make large graph computation practical without a distributed cluster.
