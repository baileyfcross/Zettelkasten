# Analytics Base Table

An analytics base table is the assembled dataset supplied to a machine-learning algorithm. Each row is one analytics record, and the columns implement the attributes selected for the task. Its construction usually requires extracting, cleaning, standardizing, transforming, and integrating data from several sources.

The table is not merely a copy of an operational database. It embodies decisions about the unit of analysis, usable time period, target definition, feature construction, and duplicate handling. These choices can affect a model more than the eventual algorithm choice.
