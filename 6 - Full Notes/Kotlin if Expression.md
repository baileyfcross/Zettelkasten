# Kotlin if Expression

Kotlin's `if` selects a branch from a Boolean condition and can be used as an expression. When its result is assigned or returned, the selected branch's final expression supplies the value.

An `else` branch is therefore necessary when the surrounding context needs a value for every path. Chained `else if` conditions can classify several cases, but each condition is considered in order and the first matching branch determines the result.
