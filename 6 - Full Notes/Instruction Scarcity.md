# Instruction Scarcity

Instruction scarcity limits how many commands, goals, or explanations compete for a player's attention at one time. When every possible action is announced, important information becomes harder to identify and the player must manage the interface instead of the game situation.

Scarcity increases the value of each message. A designer can reveal controls contextually, keep one mission salient, and defer secondary information until it becomes actionable. This reduces cognitive load without requiring the underlying game to be simple.
