# WebAssembly Language Portability

WebAssembly language portability allows code from supported compiled languages to target a common browser runtime format. A developer can use existing C or, through Blazor, C# knowledge for browser-side work instead of expressing all computation directly in JavaScript.

Portability depends on an appropriate compiler and the APIs available in the host. The benefit is greatest when a team can share language skills or application logic across server, client, mobile, and browser targets.
