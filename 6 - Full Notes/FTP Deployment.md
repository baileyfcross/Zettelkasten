# FTP Deployment

FTP deployment transfers a web application's published files to a server through an FTP target. Visual Studio can retain the server location and related publication choices in a profile so the file transfer is repeatable.

File transfer alone does not configure the host or protect environment secrets. Credentials and transport security must be managed deliberately, and the remote directory must correspond to the site's actual serving location.
