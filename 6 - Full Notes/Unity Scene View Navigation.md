# Unity Scene View Navigation

Unity Scene view navigation moves the editor's authoring camera without necessarily moving a camera object in the game. Pan, orbit, zoom, fly-through controls, focus commands, and the axis gizmo let an author inspect and edit a scene from useful viewpoints.

The distinction between the Scene camera and a [[Unity Camera Component]] prevents a common mistake: changing the editor viewpoint does not change what the player sees. Axis snapping and object focus make precise placement easier, while perspective and orthographic Scene modes support different editing tasks.
