# Security Architecture Analysis

Security architecture analysis evaluates how a system's components, trust boundaries, data flows, privileges, and dependencies shape its exposure to attack. It asks whether the design preserves security goals before implementation details obscure the larger structure.

This analysis supports [[Defense in Depth]] by identifying where controls should be placed and how one component's failure could propagate. It complements [[Security Code Review]], which inspects the implementation at a finer scale.
