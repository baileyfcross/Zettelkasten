# Levenshtein Edit Distance

Levenshtein edit distance is the minimum number of allowed single-character insertions, deletions, and substitutions needed to transform one string into another. It gives a direct measure of surface-form similarity between two character sequences.

The distance can rank dictionary replacements for misspellings and support approximate matching of messages or document fragments. It does not capture semantic equivalence: two differently worded statements can have high edit distance even when they mean the same thing.
