# AWS Systems Manager Host Management

AWS Systems Manager host management provides inventory, configuration visibility, controlled remote actions, patching, and automation across managed compute nodes. Explorer and Inventory views help operators understand system state, while documents and associations make recurring actions reproducible. Nodes must be enrolled with the required agent and permissions, and central operation should use scoped access rather than turning fleet convenience into universal administrator reach.
