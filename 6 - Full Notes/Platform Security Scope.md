# Platform Security Scope

Platform security scope defines the minimum controls the platform enforces, the controls it supports for product teams, and the responsibilities that remain elsewhere in the organization. This boundary prevents both dangerous omissions and an attempt to make one platform own the entire cybersecurity posture.

The scope should begin with user journeys, regulatory obligations, data classifications, and credible threats. Excess controls can create a barrier to adoption and drive users around the platform, while under-scoping exposes shared infrastructure and every tenant. Security becomes usable when requirements are delivered in small, understandable capabilities with explicit ownership and exception handling.
