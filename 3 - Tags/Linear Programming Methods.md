# Linear Programming Methods

Parent topic: [[Applied Linear Algebra and Optimization]]

Linear programming turns constrained choices into geometric, algebraic, network, allocation, and competitive decision models. Full Notes should use one of the focused child topics below rather than linking directly to this chapter tag.

## Overview Chapter

A linear program begins with a translation from a real decision to a mathematical one. [[Linear Programming Models and Geometry]] identifies the quantities that can be chosen, combines their unit profits or costs in a linear objective, and expresses limits or requirements as linear equations and inequalities. The assumptions are substantial: coefficients are treated as known, each activity contributes proportionally, effects add without interactions, and activity levels are divisible unless an integer restriction is imposed. Nonnegativity commonly prevents physically meaningless negative production or shipment.

Those restrictions intersect to form a convex feasible region. Convexity matters because a segment between two feasible points remains feasible, so the region has no separated pockets. If a finite optimum exists, at least one extreme point attains it. In two variables, a graph makes this structure visible: constraint half-planes define the common region, corner evaluation finds a best point, and a family of parallel isoprofit or isocost lines shows the direction of improvement. The same picture distinguishes alternative optima along an edge, an objective that improves without bound, and inconsistent constraints with no common feasible point.

[[Simplex Algorithms and Basis Structure]] converts that geometry into a repeatable algebraic search. Standard form uses equations, nonnegative variables, and a nonnegative right-hand side. Canonical form goes further by arranging the columns of current basic variables as an identity matrix. Slack variables can provide that identity for less-than constraints; surplus variables record excess above a minimum but usually need an artificial variable to create a starting basis. Big M penalizes artificial variables inside the original objective, while two-phase simplex first solves a separate feasibility problem and restores the original objective only after all artificial activity has been eliminated.

A simplex tableau records the current basis, coefficients, right-hand sides, and objective row. An improving nonbasic variable enters, the minimum ratio test selects the basic variable that reaches zero first, and a pivot turns the entering column into a unit column. Each iteration moves to an adjacent basic feasible solution while retaining the constraints. Degeneracy arises when a basic variable equals zero: the basis may change without movement to a new geometric point or an immediate objective improvement. Even so, the basis language gives a finite set of candidate corners and links computation directly to the model's geometry.

[[Linear Programming Duality and Sensitivity]] shows that an optimum is also a system of bounds and valuations. Every primal linear program has a dual in which constraints and variables exchange roles and the coefficient matrix is transposed. Weak duality says every feasible dual minimization value bounds every feasible primal maximization value from above. Strong duality closes that gap at optimum. In a resource model, dual variables become shadow prices: they assign an imputed marginal worth to limited capacity, and reduced costs compare an activity's revenue with the resources it consumes.

Sensitivity analysis asks how long that conclusion survives when estimated inputs change. Multiplying a revised right-hand-side vector by the current basis inverse tests whether the same basis remains feasible; revised objective coefficients test whether it remains optimal. Allowable ranges and 100 percent rules provide sufficient conditions for retaining the basis under individual or simultaneous changes. A new constraint may preserve the current solution or require dual-simplex repair, while a new activity can be priced with existing dual variables before a primal-simplex reoptimization. These techniques reuse the final tableau instead of solving every variation from the beginning.

Network structure creates more specialized algorithms. [[Transportation and Transshipment Optimization]] assigns shipment quantities from origins to destinations while satisfying supply and demand at minimum total cost. A balanced table has equal total supply and demand and ordinarily needs $m+n-1$ basic cells. Northwest-corner, row-minimum, column-minimum, least-cost, and Vogel procedures construct starting plans with increasing use of cost information. Stepping-stone loops and MODI potentials then compute improvement indices, move flow while preserving all balances, and certify optimality. Dummy nodes balance unequal totals, large penalties exclude forbidden routes, symbolic zero allocations repair degeneracy, and transshipment nodes permit flow through intermediate locations rather than only direct shipping.

[[Assignment Optimization]] is the one-to-one specialization of transportation. Every origin has unit supply, every destination has unit demand, and binary variables select pairings. Because a general transportation basis would be highly degenerate, the Hungarian method exploits the square cost matrix directly. Row and column reductions create zeros without changing which complete assignment is optimal. Independent zeros propose pairings; a minimum line cover diagnoses whether there are enough; and subtracting the smallest uncovered entry while adding it at line intersections creates new opportunities. Dummy rows or columns balance unequal sets, high costs forbid pairings, and opportunity-loss conversion turns a profit-maximization assignment into the required minimization form.

Finally, [[Matrix Game Theory]] applies optimization to two rational opponents. A payoff matrix lists the maximizing row player's result for every pair of strategies, while the minimizing column player sees the opposite payoff in a two-person zero-sum game. Maximin and minimax choices establish lower and upper bounds. Equality identifies a saddle point, a stable pair of pure strategies, and the value of the game. Without a saddle point, each player randomizes through a mixed strategy so that the opponent cannot profit from predictability.

Small games can be solved by equating expected payoffs, and games with two strategies on one side can be reduced graphically by selecting the relevant envelope of payoff lines. Dominance removes rows or columns that can never improve a rational player's result. A larger rectangular game can be scaled into a primal-dual pair of linear programs whose variables encode strategy probabilities and whose shared optimum determines the value. This final connection completes the chapter: modeling defines the choices, geometry explains feasible corners, simplex searches bases, duality certifies and prices the result, network algorithms exploit special matrices, and game theory turns the same machinery toward competitive decisions.
