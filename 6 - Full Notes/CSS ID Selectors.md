# CSS ID Selectors

An ID selector matches an element through the value of its `id` attribute and is written with a leading number sign. Document conventions expect an ID value to identify one element, so the selector is suited to a uniquely identified location.

ID selectors contribute strongly to [[CSS Specificity]]. That strength can make later overrides harder than with [[CSS Class Selectors]], so uniqueness and cascade effects both matter when choosing between them.
