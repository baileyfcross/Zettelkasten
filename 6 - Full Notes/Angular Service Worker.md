# Angular Service Worker

The Angular service worker is the framework-supported service-worker implementation supplied through the `@angular/service-worker` package. It integrates generated application bundles with configurable caching and update behavior.

An Angular application imports the service-worker module for production use and supplies a [[Service Worker Configuration]]. The framework can add the required package and files automatically or they can be configured manually.
