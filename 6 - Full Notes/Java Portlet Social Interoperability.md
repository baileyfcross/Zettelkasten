# Java Portlet Social Interoperability

The Java Portlet specification defines deployable web components that a portal server can assemble with other components. JSR 168 established the early model, and Portlet 3.0 arrived through JSR 362. In principle, the same portlet could run in different compliant portal products rather than being rewritten for each vendor.

Web Services for Remote Portlets extended the interoperability goal across portal boundaries. Social features were considered for later portlet work but did not become part of the specification described by the source. The model remains more enterprise-server-oriented than [[Enterprise Social Mashups]], yet it provides the foundation for the social-login, sharing, maps, and gadgets described in [[Enterprise Social Portal Integration]].
