# Blender Weight Paint Brush Tools

Weight Paint uses Draw, Blur, Average, Smear, Gradient, and Sample tools to edit influence values. Gradient establishes a progressive field, while Sample can read either an existing weight or the vertex group associated with part of the mesh.

Weight, radius, strength, and falloff control how strongly and how widely each stroke changes the field. Unlike color painting, the brush is editing numeric membership rather than visible pigment.
