# Domain Requirement

A domain requirement is imposed by the field in which software operates rather than by a particular interface preference. Tax rules, accounting principles, communication protocols, and other authoritative domain constraints shape what the system must compute or permit.

Domain requirements often become central classes, services, or libraries beneath the user interface. They should be traced to their governing source so a change in regulation or protocol can be distinguished from an ordinary feature request.
