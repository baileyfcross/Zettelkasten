# Game Modding

Game modding is the alteration or extension of a game by players using exposed code, data, or creation tools. Mods can add characters, quests, scenarios, objects, rules, or entirely new experiences to an existing system and world.

Modding is a form of [[Shared Authorship]] that can keep a game evolving beyond its original content. Supporting it may require substantial tool design, documentation, and examples that help players understand how to create coherent additions.
