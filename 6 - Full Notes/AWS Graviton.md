# AWS Graviton

AWS Graviton is a family of AWS-designed Arm-based processors used in EC2 and several managed services. Graviton instances target strong price performance and energy efficiency for compatible workloads. Moving from x86 requires checking operating-system images, native libraries, container architectures, and vendor software; portable source code and multi-architecture images make adoption easier, while architecture-specific binaries can make the processor choice an application migration.
