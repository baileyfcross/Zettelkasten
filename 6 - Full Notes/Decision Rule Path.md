# Decision Rule Path

A decision rule path is the conjunction of attribute-value tests encountered from a decision tree's root to one leaf. The leaf label supplies the consequence of the corresponding if-then rule.

Extracting one rule per path turns a tree into an explicit rule set. Pruning can remove conditions that mainly reflect noise.
