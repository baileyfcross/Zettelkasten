# Data Classification

Parent topic: [[Machine Learning and Neural Networks]]

Data classification learns a mapping from measured features to known category labels and then applies that mapping to unseen observations. The subject is broader than any single algorithm: successful classification depends on representation, training data, inductive assumptions, computational scale, evaluation, and the structure of the domain. ## Overview Chapter

[[Classification Feature Selection]] begins before a classifier is fitted. High-dimensional collections often contain noisy, irrelevant, or redundant variables that increase cost and encourage overfitting. Filters score variables without repeatedly fitting a chosen classifier, wrappers judge candidate subsets through predictive performance, and embedded methods select variables during model fitting. Structured and streaming settings add group, tree, graph, or arrival-order constraints. The governing idea is to retain a small, interpretable subset that preserves discrimination between classes.

[[Probabilistic Classification Models]] express a prediction through probabilities, likelihoods, or graphical dependencies. Naive Bayes deliberately simplifies the joint distribution with conditional-independence assumptions, while logistic regression models conditional class probability directly. Bayesian networks, hidden Markov models, Markov random fields, and conditional random fields represent different dependency structures. These models clarify what evidence contributes to a class score and whether the task calls for generating observations, estimating a boundary, or performing inference over connected variables.

[[Classification and Decision Trees]] organizes prediction as recursive partitioning. Each internal node tests a feature, each branch represents an outcome, and each leaf supplies a class decision. Split criteria seek purer child nodes, while stopping and pruning control unnecessary complexity. Trees are readable because a root-to-leaf path is an explicit decision rule, but their apparent simplicity conceals important choices about continuous values, missing observations, scalability, and protection against fitting accidental patterns in the training sample.

[[Rule and Instance-Based Classification]] contrasts two ways to make the decision explicit. Rule learners induce ordered or unordered if-then conditions whose antecedents describe a region and whose consequents name a class. Instance-based methods postpone generalization until prediction time, using nearby stored examples and a distance function to infer a label. Rules favor global descriptions; lazy methods favor local adaptation. Both depend on conflict resolution, relevance weighting, and careful definitions of similarity or coverage.

[[Support Vector Classification]] frames classification as geometric separation. A linear support vector machine chooses a boundary with a large margin from the closest training observations, and slack variables trade margin width against violations when the classes overlap. Kernels replace ordinary inner products so that nonlinear boundaries can be learned implicitly in a transformed feature space. Dual optimization concentrates the solution on support vectors, while one-versus-rest and one-versus-one decompositions extend the binary formulation to multiple classes.

[[Neural Network Classification and Clustering]] builds nonlinear decision functions from connected computational units. Threshold, linear, sigmoid, and radial-basis units differ in their response, while feedforward topology determines how intermediate representations are composed. Perceptron and delta-style updates establish the basic learning logic; multilayer networks use backpropagation to distribute output error across hidden layers. Competitive and self-organizing systems add an unsupervised view, showing how learned representations can support both class separation and structure discovery.

[[Streaming and Scalable Classification]] changes the engineering assumptions. A stream may be too large to retain and may evolve through concept drift, so a useful classifier must update incrementally while forgetting stale evidence. Rare or novel classes are especially difficult because recent windows contain few examples. For large stored collections, scalable SVM solvers, parallel decision-tree construction, sparse computation, and distributed model combination reduce training cost without changing the predictive objective.

[[Text and Multimedia Classification]] adapts general methods to representations with distinctive structure. Text is sparse and high-dimensional, making word selection and frequency modeling central. Images, audio, and video require feature extraction before learning, and multimedia decisions can fuse signals at the feature or decision level. Ontological and geographic relations contribute context that isolated low-level features miss. The classifier therefore depends as much on an appropriate representation and fusion strategy as on the final prediction rule.

[[Sequence and Network Classification]] retains dependencies that ordinary feature vectors discard. Time-series methods compare trajectories despite shifts or unequal timing, while discrete-sequence methods use patterns, alignments, kernels, or generative models. Network classification exploits edges between cases: labels can propagate, neighbors can become relational features, and repeated local inference can produce a collective assignment. These methods must avoid treating correlated observations as independent while still finding a computationally manageable representation.

[[Uncertain and Rare-Class Classification]] addresses two departures from clean, balanced training data. Uncertain attributes are distributions or ranges rather than exact points, requiring split, rule, density, or neighborhood calculations to integrate measurement uncertainty. Rare-class tasks assign asymmetric importance to the minority class through costs, weights, resampling, or one-class models. Positive-unlabeled and novelty-detection settings further weaken label availability, so evaluation must distinguish genuine detection from superficially high accuracy caused by the dominant class.

[[Distance Metric Learning]] treats similarity itself as a supervised parameter. A generalized Mahalanobis metric is equivalent to Euclidean distance after a learned projection, so its matrix determines which directions count as close. Class labels or must-link and cannot-link constraints encourage same-class cases to approach one another and different-class cases to separate. Global, local, linear, nonlinear, batch, semi-supervised, and online variants tailor this geometry to the downstream neighborhood decision.

[[Ensemble and Semi-Supervised Classification]] obtains additional evidence in two different ways. Ensembles combine diverse models so that uncorrelated errors can cancel, using Bayesian weighting, bootstrap aggregation, random forests, boosting, or stacked predictions. Semi-supervised methods combine labeled and unlabeled cases under assumptions about shared distributions, multiple views, smooth graph neighborhoods, or cluster structure. Both approaches improve generalization only when their extra components contribute information rather than repeating the same bias.

[[Transfer and Active Learning]] manages scarce labels strategically. Transfer learning reuses instances, representations, parameters, or relations from a source domain, but mismatched domains can cause negative transfer. Active learning instead chooses which unlabeled case should be sent to an oracle. Uncertainty, committee disagreement, expected model change, and expected error reduction measure different kinds of prospective value. The common goal is to spend existing knowledge or labeling effort where it changes the classifier most.

[[Classification Evaluation and Visualization]] closes the loop between model construction and warranted conclusions. Holdout, cross-validation, Monte Carlo, and bootstrap schemes separate fitting from testing with different bias, variance, and computational costs. Accuracy, precision, recall, F-measure, and receiver-operating characteristics reveal different error tradeoffs, especially under imbalance. Statistical comparisons test whether performance differences recur across datasets, while visual classification systems help people inspect boundaries, uncertainty, features, and ensemble behavior.

Taken together, these topics describe classification as an evidence pipeline rather than a leaderboard of algorithms. Representations and selected features define what can be learned; model families encode different assumptions; scale and data structure determine feasible computation; auxiliary labels, transferred knowledge, and ensembles alter the information available; and evaluation determines whether an apparent improvement is trustworthy. A sound classifier aligns all of these choices with the costs, dependencies, and uncertainty of the application.
