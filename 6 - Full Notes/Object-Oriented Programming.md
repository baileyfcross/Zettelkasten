# Object-Oriented Programming

Object-oriented programming organizes software around objects that combine state and behavior. A class describes a reusable kind of object, while instantiated objects collaborate through explicit relationships to perform the application's work.

The approach is a design paradigm rather than a language or tool. In C#, [[Encapsulation]], inheritance through [[Base Class|base]] and [[Derived Class|derived classes]], [[Abstraction]], and polymorphism provide complementary ways to protect state, reuse definitions, expose essential contracts, and vary behavior.

For scientific computing, a class can represent one mathematical responsibility such as matrix operations, random-number generation, or objective evaluation. Keeping the data and valid operations together protects representation details and makes the resulting objects reusable across algorithms.
