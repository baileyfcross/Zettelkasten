# Comparative Render Slots

Render slots preserve several recent render results inside Blender's image editor. Assigning successive tests to different slots makes it possible to switch rapidly between lighting, material, framing, or quality variants without first saving each one as a separate image.

The slots support visual comparison but are not a durable archive. Once a preferred result is identified, it should be saved explicitly with enough context to explain which scene settings produced it.
