# Podman AI Lab

Podman AI Lab is a Podman Desktop extension for selecting models and launching local containerized inference services. It presents recipes and model choices through the graphical workflow, then exposes the running server's endpoint so another application can send inference requests.

The book demonstrates an OpenAI-compatible local server connected to a separate AnythingLLM application container. The model service and user interface remain independently managed workloads joined through networking and configuration, illustrating that local AI experimentation is still a container architecture problem involving images, endpoints, resources, persistence, and trust.
