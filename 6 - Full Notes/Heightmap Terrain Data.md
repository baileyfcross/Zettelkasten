# Heightmap Terrain Data

A terrain heightmap encodes elevation as grayscale image values for a selected geographic region. In the workflow described by the book, an external map service exported several PNG variants inside an archive, from which a merged heightmap could be selected for Blender.

The image is data as well as a picture: pixel position corresponds to ground location and brightness corresponds to relative elevation. Geographic coverage, resolution, and the service's current availability constrain how faithfully it can represent a real site.
