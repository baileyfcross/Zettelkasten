# R Multiple-Panel Layout

An R multiple-panel layout divides a graphics device into regions so several related plots can be viewed together. A regular row-by-column arrangement suits comparable panels, while a layout matrix can allocate unequal regions for a main graph and supporting views.

Shared limits and consistent encodings make cross-panel comparison valid. Text and margins often need adjustment because a label sized for a full device can overwhelm a smaller panel.
