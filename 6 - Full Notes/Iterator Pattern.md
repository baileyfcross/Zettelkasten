# Iterator Pattern

The Iterator pattern provides sequential access to the elements of a collection without exposing the collection's internal representation. A traversal object maintains position and offers operations such as checking for another element and retrieving the next one.

Because traversal is separated from storage, arrays, lists, trees, and other collections can present a common way to visit their contents. Multiple iterator instances can also support independent traversals without embedding each traversal's state in the collection itself.
