# Game Leaderboard

A game leaderboard orders player or group entries by a named score supplied to a gamer service. The game can submit an updated value and request a range such as the global leaders, nearby ranks, or entries belonging to friends.

The board needs a stable scoring definition and an update rule such as highest value, lowest time, or cumulative total. Display is asynchronous because the service must retrieve remote entries. Scores that affect trust or rewards should originate from validated play or a server-controlled [[Player Statistics Service]].
