# Cloud-Hosted Dedicated Game Server

A cloud-hosted dedicated game server runs authoritative multiplayer simulation on provider-managed compute rather than on a participating player's machine. It can offer stable bandwidth, availability, fair administration, cheat resistance, and unobtrusive proof that the game is authorized to connect.

On-demand infrastructure removes much of the upfront hardware barrier but adds operating cost, provider dependence, changing APIs, fleet-management code, and the loss of player-owned servers. A studio must manage [[Game Server Provisioning]], health, capacity, and shutdown so elasticity does not become uncontrolled expense or unreliable session placement.
