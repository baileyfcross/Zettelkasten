# Unity Canvas

A Unity Canvas is the root container that drives a user interface. Text, images, buttons, sliders, and other UI elements must remain descendants of a Canvas so Unity can lay out and render them as an interface.

A canvas may render directly over the screen, through a camera, or as an object in world space. Because changing one child can cause a canvas rebuild, frequently updated elements may need thoughtful grouping. Responsive placement is handled through [[Unity RectTransform Anchoring]].
