# Single-Page Application

A single-page application loads one main HTML document and uses client-side code to change the visible interface and request data as the user works. It aims for desktop-like responsiveness without requiring a complete page reload for each interaction.

The pattern separates data, business behavior, and presentation, transfers much of the UI to the browser, and uses [[Angular Routing]] to preserve navigation state. It still depends on a [[Web Server]] and usually communicates with a [[Web API]].
