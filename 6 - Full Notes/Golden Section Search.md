# Golden Section Search

Golden section search locates the minimum of a unimodal function inside a bracketed interval without using derivatives. It compares two interior points and discards the outer subinterval that cannot contain the minimum.

The interior spacing is chosen from the golden ratio so one old point becomes an interior point of the next interval. Each iteration therefore needs only one new function evaluation while the uncertainty interval shrinks by a constant factor.
