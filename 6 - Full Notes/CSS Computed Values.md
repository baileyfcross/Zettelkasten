# CSS Computed Values

A computed value is the result obtained after the cascade, inheritance, and value computation have processed a property's specified value. Relative expressions may be resolved into another form, while some values remain relative until layout supplies the required geometry.

The computed value is not always the final number painted on screen. Used and actual values can depend on containing blocks, available space, font metrics, rounding, and device constraints during later formatting.
