# Topic Model Perplexity

Topic model perplexity measures how well a fitted generative model predicts held-out text; lower values indicate less surprise under the model. Cross-validation can average the measure across several train-test partitions for each candidate topic count.

Perplexity is a guide to predictive fit, not a direct measure of human coherence. Small numerical differences can coexist with large interpretive differences, so [[Topic Count Selection]] should combine held-out results with qualitative validation.
