# Microsoft Entra ID Protection

Microsoft Entra ID Protection detects, investigates, and helps remediate identity risk. It combines Microsoft threat intelligence, service and device telemetry, researcher findings, and tenant feedback to identify suspicious users, sign-ins, applications, and credentials.

Detections such as leaked credentials, password spray, unfamiliar behavior, suspicious token use, or adversary-in-the-middle infrastructure receive a risk level and appear in risky-user, risky-sign-in, workload-identity, and detection reports. Administrators can investigate and export the evidence, while [[Risk-Based Conditional Access]] can challenge, block, or require a secure password reset automatically. The value is not only detection but shortening the time between a credible signal and an enforceable response.
