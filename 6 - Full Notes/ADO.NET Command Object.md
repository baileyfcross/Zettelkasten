# ADO.NET Command Object

An ADO.NET command object represents an instruction to execute through a database connection. Its command text and command type can identify SQL text, a stored procedure, or another provider-supported form, while parameters carry external values.

Different execution methods express different expected results: [[ADO.NET ExecuteReader]] returns rows, [[ADO.NET ExecuteNonQuery]] reports affected rows, and [[ADO.NET ExecuteScalar]] returns one value.
