# CSS Background Blending

The `background-blend-mode` property controls how an element's background image layers blend with one another and with the background color. Comma-separated modes correspond to background layers and are repeated when fewer modes than images are supplied.

This blending is confined to the element's backgrounds, unlike [[CSS Element Blending]], which combines the complete rendered element with the backdrop outside it.
