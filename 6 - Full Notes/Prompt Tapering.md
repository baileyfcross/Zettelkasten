# Prompt Tapering

Prompt tapering records the same prompt fragment with multiple endings or continuations so concatenated speech preserves natural transitions. The selected version depends on what audio will follow.

This technique reduces audible seams in [[Concatenative Prompt Recording]]. It trades recording and storage effort for more natural prosody in a limited set of generated messages.
