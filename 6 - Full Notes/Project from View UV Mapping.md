# Project from View UV Mapping

Project from View flattens selected faces according to their current appearance in the 3D Viewport. It is useful when an image should align from one deliberate viewing direction, such as projecting a photographic facade onto simplified geometry.

Perspective or orthographic view, camera bounds, resolution aspect, clipping, and scale-to-bounds change the mapping. Faces turned away from the view receive poor coverage, so the method is best for view-oriented regions rather than an entire complex object.
