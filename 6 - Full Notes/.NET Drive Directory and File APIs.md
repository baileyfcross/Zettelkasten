# .NET Drive Directory and File APIs

.NET provides static APIs for examining drives, managing directories, and reading or writing files. `DriveInfo` describes mounted storage, `Directory` manages folders, and `File` offers convenient whole-file operations such as reading lines or bytes.

These high-level APIs suit bounded operations whose data can be handled at once. Larger data or incremental processing calls for the stream model, which exposes the same underlying resources without requiring the entire file to be loaded into memory.

The APIs cover existence checks and create, copy, move, and delete operations, but their object models carry different intent. Static `File` methods suit isolated operations, while `FileInfo` represents a particular path across multiple operations; both still require deliberate exception and path handling.
