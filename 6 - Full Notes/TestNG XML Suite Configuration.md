# TestNG XML Suite Configuration

TestNG XML suite configuration defines named suites and tests, selects classes or groups, supplies parameters, and controls execution outside the Java source. It allows smoke and regression collections to be assembled from the same test classes.

The suite element can also configure [[Parallel Test Execution]] with a parallel scope and thread count. Configuration should preserve test isolation when several methods or classes run concurrently.
