# R Power and Sample Size

R power and sample-size calculations connect effect size, sample size, significance level, and the probability of rejecting a false null hypothesis for a specified design. Given all but one of these quantities, a design-specific function can solve for the remaining value.

The calculation is only as credible as its assumed effect and variability. It should use the test, sidedness, allocation, and outcome scale planned for the study, and sensitivity analysis should show how the answer changes under plausible inputs.
