# Multiplayer Distributed Gaming

Multiplayer distributed gaming places players at separate machines connected through a network. Each participant can receive an individual view and private information, unlike local multiplayer on one shared display.

Distribution expands possible scale and distance while adding synchronization and trust problems. The software must decide which machine or server is authoritative and how inconsistent views are reconciled.
