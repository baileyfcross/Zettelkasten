# Calendar Raster Display

A calendar raster display places successive time periods in rows and encodes values with cell color. It turns a long [[Time Series]] into a compact two-dimensional pattern in which recurring seasons, unusual periods, and gaps can be compared across years. Unlike a line plot, it emphasizes blocks and repetition rather than precise trajectories. The color scale must be stable across the entire raster for comparisons to remain meaningful.
