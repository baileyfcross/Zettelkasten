# AWS Migration Hub

AWS Migration Hub provides a central place to discover, plan, and track application migrations across multiple AWS and partner migration tools. It associates servers and resources with applications so progress can be observed at the workload level rather than as disconnected tool activity. Central tracking helps program teams coordinate waves and status, while the underlying discovery, replication, database, and modernization services still perform their specialized tasks.
