# Clinical Prediction External Validation

Clinical prediction external validation evaluates a completed model on data from a different population, institution, period, or collection process. It tests whether apparent performance survives changes that were absent from model development.

Internal resampling can estimate optimism within one dataset, but it cannot reproduce every difference in practice. Coding, prevalence, equipment, and patient mix can all shift. External validation should examine discrimination and calibration, document the new setting, and avoid silently refitting the model before reporting how the original specification performed.
