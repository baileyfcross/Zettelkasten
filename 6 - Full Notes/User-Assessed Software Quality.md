# User-Assessed Software Quality

Software quality is partly an assessment made by users, not only a collection of measurable properties in code. A technically efficient and correct product may still be judged poor if it disrupts work, violates expectations, or creates avoidable risks.

This view complements standards for reliability, maintainability, and performance. It asks whether those properties combine into a valuable and satisfying experience in a particular context.
