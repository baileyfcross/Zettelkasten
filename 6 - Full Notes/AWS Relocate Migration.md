# AWS Relocate Migration

Relocating moves an entire environment to AWS without changing the individual applications within it. The book uses VMware workloads as the characteristic case: the virtualization estate can move while preserving its familiar operating model and application configuration. Relocation reduces per-application change during the move, although it does not itself modernize the applications or remove dependencies inherited from the source environment.
