# Package Dependency

A package dependency exists when one software package requires functions or data supplied by another. Installing an R package may therefore install or require several supporting packages before the requested functionality can run.

Dependencies make modular software reuse possible, but they also expand the version combinations that must be managed. A reproducible analysis should record the packages and versions it relies on, especially when moving from an exploratory workstation to a production environment.
