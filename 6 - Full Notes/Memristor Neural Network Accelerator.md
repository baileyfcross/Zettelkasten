# Memristor Neural Network Accelerator

A memristor neural network accelerator stores synaptic weights as conductances in crossbar arrays and uses analog current summation for parallel dot products. The same structure combines storage with computation and can reduce the bandwidth bottleneck between separate memory and arithmetic units.

Device nonideality matters: resistance variation, stuck-at faults, interconnect effects, conversion circuits, and limited write behavior affect both accuracy and yield. Simulation and fault-aware training are therefore part of the accelerator design.
