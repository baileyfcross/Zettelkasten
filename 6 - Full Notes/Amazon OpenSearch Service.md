# Amazon OpenSearch Service

Amazon OpenSearch Service operates managed OpenSearch clusters for search, log analytics, application monitoring, and near-real-time exploration. Data is indexed so users and applications can perform text searches, filters, aggregations, and dashboard visualization.

It is optimized for indexed search and operational analytics rather than relational transactions. Streaming delivery through [[Amazon Data Firehose]] can feed records into an index, while access controls, encryption, capacity, and index lifecycle still require deliberate configuration.
