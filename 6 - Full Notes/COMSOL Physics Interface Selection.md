# COMSOL Physics Interface Selection

Physics interfaces provide governing equations and condition types for solids, fluids, flow, radiation, and coupled phenomena. Selection should follow the dominant mechanisms and the dimensional component in which they will operate.

A specialized multiphysics interface can create appropriate couplings automatically, while separate interfaces allow more deliberate sequencing or customization. In either route, the analyst must confirm that every intended domain and boundary participates in the [[Dominant Physics Selection for Thermal Problems|selected physics]].
