# Model Metadata

Model metadata records the formula, significant or retained covariates, fit measures, and rationale for the next step in every modeling iteration. A spreadsheet can preserve this history while the statistical code generates the models themselves.

The record makes selection reproducible and helps explain why a variable left or reentered the model. It is particularly valuable when collinearity changes coefficients across iterations or when empirical judgment supplements a numerical threshold.
