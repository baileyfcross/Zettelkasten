# Unity Prefab

A Unity prefab is a reusable project asset that stores a configured GameObject hierarchy as a template. Any number of scene or runtime instances can be created from it, while the prefab retains a common source definition.

Prefabs separate reusable construction from placement. A developer can assemble components once, instantiate the result repeatedly, and edit shared defaults without rebuilding every occurrence. Instances may also carry overrides, so maintenance depends on knowing which values belong to the prefab and which intentionally differ in a particular scene.
