# Native Web Application

A native web application combines multiple small single-page modules within a multipage web structure. It uses browser and server navigation where appropriate instead of forcing every capability into one long-lived client application.

This hybrid arrangement can preserve SPA-like interactive sections while allowing selected page transitions, redirects, or services to operate independently. It therefore differs from a single, fully client-routed [[Single-Page Application]].
