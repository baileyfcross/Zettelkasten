# Working Memory

Working memory temporarily stores information and supports short-term manipulation or transformation of it. Its capacity is limited, it decays quickly, and retaining information depends strongly on [[Attention]] and rehearsal.

Working-memory capacity differs among people. An interface that makes a user remember too many transient items can increase [[Cognitive Load]] and errors. Keeping needed information visible and preferring recognition over recall can reduce this burden.

Working memory interacts with [[Long-Term Memory]], which supplies more durable knowledge, categories, procedures, and learned skills.

The practical game-design constraint is only a few unfamiliar chunks at once, not a license to count every interface item as equally demanding. A concept already organized in a [[Player Knowledge Schema]] occupies less effective capacity than several new rules learned simultaneously.
