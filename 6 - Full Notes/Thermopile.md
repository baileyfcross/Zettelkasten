# Thermopile

A thermopile connects multiple thermocouple or thermoelectric pairs in series so their Seebeck voltages add. It raises output voltage without requiring a single pair to span a larger temperature difference. The source presents this arrangement as one way to make a [[Thermoelectric Generator]] more useful for a load. Each pair still has its own material and heat-leak constraints.
