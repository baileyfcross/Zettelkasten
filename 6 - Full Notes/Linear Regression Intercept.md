# Linear Regression Intercept

The linear regression intercept is the model's predicted outcome when every numeric predictor equals zero and every indicator is in its reference state. It anchors the fitted equation from which other coefficients add or subtract.

The intercept may lack a practical interpretation when zero is outside the observed range or the combined reference profile is unrealistic. Centering predictors can give it a more meaningful reference without changing the fitted relationships.
