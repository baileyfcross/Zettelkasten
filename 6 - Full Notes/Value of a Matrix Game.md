# Value of a Matrix Game

The value of a matrix game is the expected gain to the maximizing player, and equally the expected loss to the minimizing player, when both use optimal strategies. A value of zero defines a fair game under the book's convention.

With a saddle point, the value is the coincident maximin and minimax entry. Without one, the value lies between those bounds and is obtained from optimal [[Mixed Strategy in Matrix Games|mixed strategies]].
