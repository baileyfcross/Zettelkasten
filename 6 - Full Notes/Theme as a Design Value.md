# Theme as a Design Value

A theme design value identifies what the game is about and how that subject should reach the player. Story, systems, visual representation, metaphor, and consequence can each communicate the theme rather than leaving it solely to exposition.

Stating the delivery mechanism makes the value testable. If the theme is supposed to emerge from play, a playtest should reveal it through decisions and outcomes instead of depending on an explanation from the designer.
