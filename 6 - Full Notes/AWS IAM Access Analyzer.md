# AWS IAM Access Analyzer

AWS IAM Access Analyzer examines resource policies to identify access granted outside a chosen zone of trust, such as an account or organization. It can also validate policies and use observed access to help refine permissions. A finding signals that a policy permits an external principal, not necessarily that the access is malicious; owners must compare it with the intended sharing relationship and remediate unintended exposure.
