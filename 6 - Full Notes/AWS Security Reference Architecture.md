# AWS Security Reference Architecture

The AWS Security Reference Architecture is an opinionated multi-account design for organizing security capabilities, logs, delegated administration, and preventive and detective controls. The book presents it as a phased path: define the desired security state, establish account and identity foundations, protect data and networks, centralize visibility, and improve through findings. It is a starting pattern that must be adapted to an organization’s risks and responsibilities.
