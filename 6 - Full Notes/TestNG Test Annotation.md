# TestNG Test Annotation

The TestNG `@Test` annotation marks a Java method as a test and can configure its execution. Attributes can assign priority, disable the method, declare dependencies or groups, connect a data provider, and specify an expected exception.

The annotation supplies framework metadata rather than the test's browser behavior. The method still needs a focused scenario and [[Test Assertion|assertions]] that define success.
