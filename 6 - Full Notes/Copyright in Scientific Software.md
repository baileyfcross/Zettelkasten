# Copyright in Scientific Software

Scientific source code is an original expression and is therefore protected by copyright by default. Merely posting code does not necessarily grant others permission to copy, modify, or redistribute it, even when the scientific purpose is verification.

An explicit software license is needed to authorize those uses. Releasing source rather than only a compiled binary is essential for understanding the computational method. A [[Permissive Software License for Research]] maximizes reuse with limited conditions, while a [[Copyleft Software License]] can require distributed derivatives to preserve specified freedoms.
