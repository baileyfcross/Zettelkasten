# World Geographic Reference System

The World Geographic Reference System, or GEOREF, encodes latitude and longitude through nested lettered and numbered grids. Fifteen-degree quadrangles are subdivided into one-degree regions and then into minutes or decimal fractions of minutes. The notation provides a compact common reference that can be used on any chart carrying latitude and longitude.
