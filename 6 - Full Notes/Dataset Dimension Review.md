# Dataset Dimension Review

A dataset dimension review checks the number of rows and columns immediately after import. Comparing the observed dimensions with an expected count can expose a wrong delimiter, dropped records, duplicated headers, or an unintended file.

Dimension review is a quick first step before examining classes, names, distributions, and missingness.
