# Reactive Stream

A reactive stream is a time-ordered sequence of notifications. It may emit values, report an error, and signal completion, so a consumer must consider more than the next ordinary value. User events, inventory updates, and calculated totals can each be treated as streams. Operators can derive new streams without requiring producers to know every downstream consumer.
