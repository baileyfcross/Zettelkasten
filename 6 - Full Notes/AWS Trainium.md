# AWS Trainium

AWS Trainium is custom silicon designed for training deep-learning and foundation models on AWS. Trainium-powered EC2 instance families combine the accelerators with the Neuron software stack so distributed training can use hardware optimized for high model throughput and price performance. Real benefit depends on framework compatibility, model parallelism, accelerator utilization, data supply, and the engineering effort required to tune the training workload.
