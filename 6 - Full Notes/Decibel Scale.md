# Decibel Scale

The decibel scale expresses an intensity ratio logarithmically:

$$L=10\log_{10}(I/I_0)\ \mathrm{dB}.$$

For sound, $I_0$ is commonly the threshold reference intensity. A tenfold intensity increase adds 10 dB, while doubling intensity adds about 3 dB. Decibels compare levels rather than serving as an absolute SI unit.
