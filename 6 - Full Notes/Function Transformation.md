# Function Transformation

Function transformations derive new graphs from a known graph. Adding a constant outside the function shifts vertically, replacing $x$ by $x-h$ shifts horizontally, multiplying the output scales vertically, and replacing $x$ by a multiple scales horizontally. Negative factors create reflections across an axis. Their order matters when several transformations are combined.
