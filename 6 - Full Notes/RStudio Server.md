# RStudio Server

RStudio Server provides the RStudio development environment through a web browser while R executes on a remote machine. It lets multiple analysts use centrally managed computation and packages without moving every dataset to a desktop.

Its browser interface preserves the familiar editor, console, environment, files, plots, packages, and help panes of [[RStudio]].
