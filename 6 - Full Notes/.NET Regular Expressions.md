# .NET Regular Expressions

A regular expression describes a pattern to find, validate, split, or replace text. Character classes, anchors, quantifiers, groups, and alternatives combine into rules that can express structures more flexible than a literal substring.

.NET exposes patterns through the `Regex` type. Verbatim C# strings are useful because backslashes can reach the regular-expression engine without being consumed first as language escape sequences. A pattern should normally be anchored when the entire input must conform, not merely contain one matching fragment.
