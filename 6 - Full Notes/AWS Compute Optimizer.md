# AWS Compute Optimizer

AWS Compute Optimizer analyzes utilization metrics and recommends better-sized configurations for supported compute and storage resources. It can identify overprovisioned resources that waste money and underprovisioned resources that risk poor performance. Recommendations are evidence for review rather than automatic truth: historical demand, seasonal peaks, licensing, memory visibility, resilience headroom, and planned changes should be considered before resizing.
