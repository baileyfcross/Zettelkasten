# Big Data Project Portfolio

A big data project portfolio treats a large initiative as a set of related subprojects rather than one indivisible investment. Components may create data, infrastructure, models, interfaces, or operational changes with different costs and benefits.

Portfolio analysis can choose an order, defer a component, or omit it when dependencies and financial returns make another feasible combination more valuable.
