# Squared Vector Length

Squared vector length is the sum of the squared components of a vector, equivalent to the vector's [[Dot Product]] with itself. It preserves relative distance comparisons without performing the square root required by the full [[Vector Norm]].

Games can compare squared distances when they only need to know which point is closer or whether a threshold is exceeded. The threshold must also be squared for the comparison to remain valid.
