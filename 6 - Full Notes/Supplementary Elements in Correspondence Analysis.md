# Supplementary Elements in Correspondence Analysis

A supplementary element is projected into an existing correspondence-analysis factor space without defining its principal axes. This permits a study to use coarse categories as the active table while retaining finer attributes for interpretation.

The book calls this information focusing: aggregate observations or attributes establish a lower-resolution geometry, and the full detail can then be mapped into it. The approach can reduce computational and interpretive load, but the chosen active resolution remains a substantive modeling decision.
