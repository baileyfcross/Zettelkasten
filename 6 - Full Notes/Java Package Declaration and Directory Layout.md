# Java Package Declaration and Directory Layout

A Java `package` statement assigns every type in a source file to one dot-separated package name. Only comments may precede it, a source file can contain only one package statement, and a file without one contributes its types to the unnamed package.

Java implementations map package components to nested directories so compiled classes can be located under the corresponding hierarchy. Lowercase names are conventional, and a reversed Internet domain prefix helps make an organization's package sequence unique.
