# Git Commit

A Git commit records the staged snapshot together with metadata such as its message, author information, and parent commit. Its hash identifies the resulting history object.

Only staged content enters the commit; unrelated working-tree changes remain outside it. A clear message explains the purpose of the snapshot so [[Git Log|history inspection]] reveals decisions rather than only file differences.
