# Selenium Web Element Locator

A Selenium web element locator is a rule that identifies an element in the [[Document Object Model Tree]]. Once located, the element can be clicked, typed into, inspected, or used as the starting point for another operation.

Useful locators are precise enough to select the intended element and stable enough to survive harmless layout changes. Selenium supplies strategies based on IDs, names, link text, tag or class names, XPath, and CSS selectors.
