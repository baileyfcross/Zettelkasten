# Clustering Filter Feature Selection

A filter method ranks or selects features before the final clustering algorithm is run. It uses properties of the data such as variance, redundancy, local geometry, or spectral consistency rather than feedback from a particular clusterer.

Filters are usually computationally efficient and reusable across algorithms. Their independence is also a limitation because a feature score can preserve generic structure without improving the specific grouping objective used downstream.
