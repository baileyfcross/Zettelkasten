# Mesh Extrusion in Blender

Extrusion extends selected mesh components while creating the geometry that connects the old and new positions. It is Blender's central modeling operation because it grows a surface instead of merely moving existing components.

A face extrusion can create a projecting volume, while edges or vertices can extend an open form. After extrusion begins, the new selection can be transformed, constrained, or canceled using the same interaction patterns as other Blender operations.
