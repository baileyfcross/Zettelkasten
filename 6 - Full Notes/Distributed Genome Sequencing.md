# Distributed Genome Sequencing

Distributed genome sequencing divides large sequence datasets or matching tasks across networked compute nodes. Frameworks can provide aggregate memory and throughput beyond one machine, especially when individual partitions can be processed independently.

Communication, partition balance, and intermediate data determine scalability. A distributed system remains built from general processors, so it trades flexible capacity and fault handling against the efficiency of a dedicated [[FPGA Genome Sequencing]] path.
