# Complex Event Processing

Complex event processing detects higher-level situations from patterns across multiple low-level events. Rules can combine order, time windows, absence, correlation, and attributes to recognize a condition that no single sensor record expresses.

Useful detection requires explicit event-time semantics because delayed or out-of-order observations can otherwise change whether the pattern appears to have occurred.
