# UML Self Message

A UML self message is a message a lifeline sends to itself to represent an internal operation. The arrow leaves the current activation and loops back to another activation on the same lifeline.

Self messages make internal delegation or calculation visible without inventing a separate participant. When the self-call repeats the same operation recursively, it can be modeled more specifically as a [[UML Recursive Message]].
