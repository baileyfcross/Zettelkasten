# Pattern-Space Clustering

Pattern-space clustering groups data objects using their mapped relationships to selected patterns. Objects can be similar because they share structural motifs even when their original encodings differ greatly.

Pattern features can also define subspaces associated with distinct clusters. Redundant ubiquitous patterns should be controlled so that meaningful structural variation dominates the distance measure.
