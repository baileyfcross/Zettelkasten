# Blender To Sphere Tool

To Sphere moves selected vertices toward equal distance from a shared center. A factor controls the blend between the original form and the spherical target, allowing partial rounding as well as a complete transformation.

The operation redistributes existing vertices but does not add resolution. The source topology must already contain enough components and a suitable arrangement for the resulting curvature to shade cleanly.
