# User Control of Personal Data

User control of personal data is the practical ability to understand, access, correct, object to, or otherwise influence how one's information is processed. Control requires usable mechanisms as well as formal statements of rights.

Big-data inference complicates control because derived attributes may affect a person even when they never supplied those attributes directly. Systems must therefore account for both observed and inferred data.
