# Cross-Language Information Retrieval

Cross-language information retrieval accepts a query in one language and finds relevant documents written in others. Translation can be applied to the query, the documents, or both, allowing a user to search patent, intelligence, scientific, or news collections without knowing every represented language.

Short queries create a special ambiguity problem because one or two words provide little context for choosing a translation. A system can ask the user to clarify, expand the query with specialized terminology, or use relevance feedback from selected results. The retrieval goal also changes the quality threshold: an imperfect translation can be useful if it reliably surfaces the right documents for inspection.
