# Matrix Determinant

The determinant is a scalar associated with a square [[Matrix]]. It can be expanded along any row or column using signed minors, and a zero determinant identifies a singular matrix.

For a linear system, a nonzero determinant supports a unique solution. In an [[Eigenvalue Problem]], the characteristic equation sets the determinant of the shifted matrix to zero so nontrivial eigenvectors can exist.
