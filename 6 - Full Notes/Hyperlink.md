# Hyperlink

A hyperlink is a reference from text to another location in the same document or to a different document. On the web, a hyperlink creates a directed connection from its source page to its destination page.

These connections turn pages into a [[Web Graph]]. Incoming links become [[Backlink|backlinks]], and PageRank treats each outgoing link as receiving part of the source page's relative importance.
