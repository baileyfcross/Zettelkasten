# Unity Animator Controller

A Unity Animator Controller is an asset that organizes animation states, transitions, parameters, and blends. The [[Unity Animator Component]] evaluates this controller to decide which [[Unity Animation Clip|clip]] or blended motion should affect its object.

Because the controller is an asset, one state graph can be reused by multiple compatible objects. Parameters provide the interface from scripts to animation logic: gameplay sets a boolean, trigger, integer, or float, and the controller's transition conditions interpret it.
