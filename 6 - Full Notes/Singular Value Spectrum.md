# Singular Value Spectrum

A singular value spectrum is the ordered collection of singular values from a [[Singular Value Decomposition]]. Squared singular values quantify how much sum-of-squares variation lies along the corresponding transformed directions.

A steep spectrum indicates that a small number of directions capture much of the dataset's structure. A gradual spectrum warns that aggressive reduction will discard substantial variation and distort distances or reconstruction.
