# Modular Arithmetic

Modular arithmetic replaces an integer by its nonnegative remainder modulo n and performs operations on residue classes. Addition modulo n forms a cyclic group on the classes 0 through n-1.

Multiplication forms a group only on those residue classes that are invertible modulo n.
