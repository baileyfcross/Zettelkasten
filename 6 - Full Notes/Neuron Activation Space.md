# Neuron Activation Space

Kelleher distinguishes an activation space from the raw [[Model Input Space|input space]] and the [[Model Weight Space|parameter space]]. In his geometric example, weighted inputs are represented in the activation space where a threshold decision is applied. The resulting [[Decision Boundary]] can also be projected back to the original input coordinates.

The distinction is useful because an input case, the weights used to transform it, and the transformed value on which a unit acts are different objects. For a neuron, a weighted sum is followed by an [[Activation Function]] that maps it to the neuron's output activation. The activation-space view helps explain how a boundary produced after weighting corresponds to classifications of original inputs.
