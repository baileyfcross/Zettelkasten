# Uncertainty Density Function

An uncertainty density function assigns probabilities to the possible values of an imprecisely observed attribute or object. It preserves more information than a simple interval because likely and unlikely realizations are distinguished.

Classification algorithms can integrate a test, rule, or distance over this density. The result reflects expected behavior across possible values rather than pretending that a single point estimate was observed without error.
