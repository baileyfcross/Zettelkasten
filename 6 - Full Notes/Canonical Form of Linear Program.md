# Canonical Form of Linear Program

Canonical form arranges a linear program so the current basic-variable columns form an identity matrix and the objective is written as an equation. This makes each [[Basic Variable]] directly readable from the right-hand side when [[Nonbasic Variable|nonbasic variables]] are set to zero.

A standard-form model may need slack, surplus, or artificial variables before it has a usable canonical basis. Each [[Simplex Pivot Operation]] then restores canonical form around a new set of basic variables.
