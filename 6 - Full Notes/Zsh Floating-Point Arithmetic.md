# Zsh Floating-Point Arithmetic

Zsh floating-point arithmetic evaluates decimal expressions within the shell when at least one operand is expressed as a floating-point value. This can avoid an external calculator for simple calculations that Bash would handle only as integers.

Binary floating-point representation can still produce trailing approximation digits, and display formatting is separate from calculation. Results that require financial or exact decimal semantics need a more suitable numeric tool.
