# Blender Text Objects

A Blender text object places editable text at the 3D cursor. In Edit mode it accepts typing, word and character selection, deletion, line breaks, clipboard paste, and the contents of an external text file.

Text is curve-based, so its appearance and depth can be controlled like other curve geometry. It can be deformed along a curve or converted to curves and meshes when direct component editing becomes necessary.

As a scene object, text retains editable character content alongside transform and curve-style properties. Conversion should therefore be delayed until an operation or interchange format specifically needs polygonal geometry.
