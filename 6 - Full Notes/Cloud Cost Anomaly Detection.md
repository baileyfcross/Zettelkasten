# Cloud Cost Anomaly Detection

Cloud cost anomaly detection identifies spending or usage that deviates materially from an expected pattern. It can surface a runaway resource, a configuration mistake, unexpected traffic, or a changed purchasing condition before the next monthly review turns the anomaly into a large surprise.

A useful alert accounts for normal seasonality and routes enough ownership context for someone to investigate. Detection does not prove waste: a product launch may create legitimate growth. It supplies an early financial signal that can be correlated with deployments, operational telemetry, and the allocation data used in the [[FinOps Lifecycle]].
