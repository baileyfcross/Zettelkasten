# COBWEB Concept Hierarchy

A COBWEB concept hierarchy is a tree in which each node represents a probabilistic concept and terminal nodes can describe individual instances. Nodes store concept occurrence and attribute-value probabilities.

Adding an instance can update the stored statistics or restructure a local subtree through incorporation, new-disjunct, merge, or split operations. Skewed input can produce an unbalanced and expensive tree.
