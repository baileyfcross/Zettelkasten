# Interactive Time-Series Plot

An interactive time-series plot lets a viewer inspect and transform a temporal display during use. Common operations include [[Temporal Hover Readout|hover readout]], [[Temporal Zooming|zooming]], series highlighting, and range selection. Interaction can expose detail without placing every label on the static figure, but the initial view still needs a clear scale and overview. Essential meaning should not depend on an undiscoverable control.
