# AWS Pricing Calculator

AWS Pricing Calculator builds an estimate from expected service configurations and usage assumptions. It allows an architect to model resource quantities, service tiers, purchase options, storage, and data movement before deploying a workload.

The result is only as reliable as its assumptions. Demand, growth, architecture, discounts, and service prices can change, so the estimate should document its inputs and later be compared with actual usage in [[AWS Cost Explorer]].
