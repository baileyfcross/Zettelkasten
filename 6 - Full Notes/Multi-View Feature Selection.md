# Multi-View Feature Selection

Multi-view feature selection chooses variables when each object is described by several distinct feature sets or modalities. It must use complementary information across views while controlling redundancy within and between them.

A selector may seek agreement, preserve view-specific structure, or weight views by predictive value. Treating all dimensions as one undifferentiated matrix can obscure these relationships.
