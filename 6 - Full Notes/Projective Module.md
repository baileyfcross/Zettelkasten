# Projective Module

A projective module P has the lifting property: for every surjection N → M and map P → M, there is a map P → N whose composite is the original map. Maps from P can be lifted across quotients.

Every [[Free Module]] is projective, and a module is projective exactly when it is a [[Direct Summand of a Free Module]]. Short exact sequences ending in a projective module split.
