# JPEG Quantization Table Signature

A JPEG quantization table signature uses the values that control how strongly spatial-frequency coefficients are rounded during compression. A color JPEG can contain three 8-by-8 tables—one for luminance and two for chrominance—providing 192 values whose pattern may be distinctive to a device or application.

Comparing those values with known outputs can identify an incompatible encoder or prior resave. Attribution remains probabilistic because different products can share tables and some cameras select tables dynamically according to scene or quality settings.
