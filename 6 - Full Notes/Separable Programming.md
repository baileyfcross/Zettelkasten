# Separable Programming

Separable programming approximates a nonlinear problem whose objective and constraints can be written as sums of single-variable functions.

Each nonlinear function is replaced by a piecewise-linear approximation over selected breakpoints. The resulting model can be handled as a [[Linear Programming]] problem, with approximation quality depending on the breakpoint spacing.
