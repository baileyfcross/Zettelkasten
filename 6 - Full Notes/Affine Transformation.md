# Affine Transformation

An affine transformation has the form $T(x)=Mx+b$, combining a linear map with a translation. It preserves points, straight lines, parallelism, and ratios of distances along the same line, but it need not preserve lengths or angles.

Every linear transformation is affine, while a nonzero translation makes an affine transformation non-linear because the origin is not fixed. [[Homogeneous Coordinates]] allow both parts to be represented by one matrix.
