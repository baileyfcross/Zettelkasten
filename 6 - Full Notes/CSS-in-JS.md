# CSS-in-JS

CSS-in-JS defines component styles through JavaScript or TypeScript rather than only through separate stylesheet class names. A library such as Emotion can create styled components or generate class rules from expressions.

Keeping style close to the component can make dynamic values and reuse convenient. It also couples styling to the chosen toolchain, so shared colors and layout primitives should still be factored into reusable definitions.
