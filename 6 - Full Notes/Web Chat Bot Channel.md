# Web Chat Bot Channel

The Web Chat channel provides a browser-based interface for interacting with a registered bot. It is available as a convenient way to verify the deployed bot without first building a custom client.

Web Chat and Direct Line are two interfaces to the same bot service. The channel changes how users connect, not the intent recognition and response logic running behind the messaging endpoint.
