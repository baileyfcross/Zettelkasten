# Built-In .NET Exception Types

Built-in .NET exception types classify familiar runtime failures so callers can distinguish them programmatically. Examples include `DivideByZeroException`, `IndexOutOfRangeException`, `InvalidCastException`, and `NullReferenceException`.

A specific type communicates more than a general `Exception` because it narrows the failed assumption and supports a targeted catch policy. The type does not replace a clear message or the surrounding operation's context.
