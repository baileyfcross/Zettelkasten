# Principal Component

A principal component is a linear combination of centered variables defining a direction of variation in a dataset. The first component has the greatest possible variance among unit-length directions, and each later component is orthogonal to the earlier ones while maximizing remaining variance.

Sample coordinates along these directions are called component scores. A component is a mathematical combination of features and requires loadings, scores, and experimental metadata for substantive interpretation.
