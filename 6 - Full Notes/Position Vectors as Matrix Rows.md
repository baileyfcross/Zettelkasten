# Position Vectors as Matrix Rows

A geometric model can collect its point coordinates as rows of a matrix. Each row is a position vector relative to a specified coordinate system, and applying the same transformation to every row updates the whole model at once.

In a row-vector convention the point matrix appears on the left of the transformation matrix, so the written multiplication order matches the order in which transforms are applied. A column-vector convention places points on the right and reverses that apparent order. Mixing the two conventions changes signs and composition order, so one convention must be used consistently.
