# Reactive Stream Filtering

Filtering a reactive stream forwards only notifications whose values satisfy a predicate. The book applies a threshold to a merged number stream, leaving the original producers unchanged while the downstream observer sees a smaller sequence. This turns a selection rule into a composable stage of event processing rather than a condition embedded in every producer.
