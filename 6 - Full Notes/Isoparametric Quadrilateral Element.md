# Isoparametric Quadrilateral Element

An isoparametric quadrilateral element uses the same shape functions to map element geometry and interpolate field variables. Natural coordinates describe a regular parent element that is transformed into the physical quadrilateral.

Higher-order versions add side nodes and can represent curved boundaries. The mapping lets a common formulation handle a range of element shapes while numerical integration evaluates transformed coefficients.
