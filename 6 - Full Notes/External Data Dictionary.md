# External Data Dictionary

An external data dictionary documents variable names, meanings, types, valid values, category definitions, and special missing codes outside the analysis program. A spreadsheet or similarly accessible format lets programmers, domain experts, and reviewers examine the same metadata.

External documentation is more portable than relying on SAS labels, formats, or comments embedded in code. It supports interdisciplinary review and allows the dataset to be understood before it is loaded into a particular statistical environment.
