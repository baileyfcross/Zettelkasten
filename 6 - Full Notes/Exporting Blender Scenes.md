# Exporting Blender Scenes

Exporting restructures Blender's 3D data into a format that another application or game pipeline can understand. It is distinct from rendering, which converts the scene into camera-based images.

Many exporters are implemented as add-ons and may be disabled by default. Enabling the required exporter in Preferences makes its format available from the File Export menu.
