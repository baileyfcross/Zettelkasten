# Azure Architecture Service Retirement

Azure service retirement is an architectural lifecycle event that can invalidate an otherwise sound reference design. A retiring service requires identification of the supported successor, feature differences, migration path, deadlines, and dependent workloads. Architecture maps and standards should therefore record service currency and ownership rather than freezing product choices indefinitely; replacement services may cover the primary use case without matching every old capability.
