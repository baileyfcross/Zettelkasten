# Elastic Load Balancing

Elastic Load Balancing distributes incoming traffic across registered targets and sends requests only to targets that pass configured health checks. A load balancer can span multiple [[AWS Availability Zone|Availability Zones]], hiding individual instance addresses behind a stable service endpoint.

AWS offers different load-balancer types for different traffic. [[Application Load Balancer]] handles application-layer HTTP routing, [[Network Load Balancer]] emphasizes high-performance transport-layer traffic, and [[Gateway Load Balancer]] inserts virtual network appliances into traffic paths.
