# Refresh Rate

Refresh rate is the frequency with which an [[Output Device]] updates what it presents, usually measured in hertz.

For a [[Visual Display]], refresh rate is how quickly the device refreshes the image from the frame buffer. It is distinct from frame rate, which is how quickly the graphics system generates frames. Low visual refresh rates can cause flicker, while higher rates can help reduce [[Latency]].

For a [[Haptic Display]], temporal resolution is often described as refresh rate. Force feedback requires rapid updates; insufficient temporal resolution can create unintended vibration and make virtual objects feel softer than intended.
