# Go Range Iteration

Go range iteration traverses supported values such as arrays, slices, maps, strings, channels, and iterator sequences. Depending on the source, it can produce an index or key together with the current value.

The [[Go Blank Identifier]] discards a position that is not needed. Map order is unspecified, string ranging decodes UTF-8 into byte positions and runes, and ranging over a channel receives values until the channel is closed.
