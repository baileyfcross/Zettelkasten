# R Surface Plot

An R surface plot represents values defined over two coordinates through contours, color, perspective height, or a combination of those encodings. A two-dimensional contour or image view supports precise location, while a three-dimensional perspective view emphasizes peaks, valleys, and overall shape.

The input grid and axis order must match the value matrix. Perspective, lighting, and color can create apparent structure, so a labeled two-dimensional view often provides a necessary companion to the 3D surface.
