# CSS Background Positioning and Sizing

Background positioning places an image relative to a chosen origin box using keywords, lengths, or percentages. A percentage aligns the corresponding point of the image with the corresponding point of the positioning area, rather than simply offsetting by that percentage.

`background-size` can preserve intrinsic size, assign explicit dimensions, or use `cover` and `contain` to scale while preserving aspect ratio. Repetition then tiles the positioned image across the painting area when requested.
