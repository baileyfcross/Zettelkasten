# Time-Sharing

Time-sharing lets many terminal users interact with one large computer by rapidly dividing processor attention among them. Because machine operations are much faster than human reactions, each person can receive responses that feel immediate.

The model made scarce computing resources accessible and encouraged conversational software. Scaling it required sophisticated scheduling, memory protection, and operating systems.
