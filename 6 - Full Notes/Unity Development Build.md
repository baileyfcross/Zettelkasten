# Unity Development Build

A Unity Development Build includes diagnostic support intended for testing, such as connection to debugging and performance-profiling tools. It helps investigate behavior that differs between the editor and the built player.

Diagnostic capability can add overhead and is not the normal configuration for a public release. A useful release workflow tests development builds while problems are still being measured, then verifies a non-development build under realistic target conditions.
