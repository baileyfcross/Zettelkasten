# Microsoft Bot Framework

Microsoft Bot Framework is the service and programming framework used to receive conversational activities, run bot logic, and send replies through supported channels. It hides much of the state-machine and transport plumbing while leaving response behavior to the application.

The 2019 project begins with an echo-bot template, processes message activities through an adapter, adds LUIS-based intent recognition, and deploys the bot to Azure App Service. A separate channel registration then connects clients to the published messaging endpoint.
