# CSS Keywords Strings and URLs

CSS properties can accept predefined keywords, quoted strings, and URL values. A keyword has meaning only in the grammar of the property that accepts it, so the same spelling can represent unrelated behavior in different properties.

Strings preserve textual data and may use single or double quotes with escaping. URL values identify external resources such as images or fonts and are resolved relative to the stylesheet in which the URL appears.
