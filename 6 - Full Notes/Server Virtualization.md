# Server Virtualization

Server virtualization allows one physical host to run several independent [[Virtual Machine]]s. Each virtual machine can have its own operating system and applications even though the instances share the host's processors, memory, storage, and networking hardware.

Consolidation can reduce procurement, floor-space, cooling, electricity, and maintenance requirements. In cloud computing, virtualization also makes pooled instances easier to activate and release, but billing, self-service, service catalogs, and orchestration are additional systems layered around it.
