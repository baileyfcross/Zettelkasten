# Pattern Selection Phase

The pattern selection phase chooses a manageable, informative subset from mined candidates. Criteria can measure redundancy, coverage, discrimination, stability, or downstream performance.

Selection prevents the representation from inheriting the full combinatorial output of mining. Post-processing evaluates an existing candidate set, while in-process methods prune during enumeration.
