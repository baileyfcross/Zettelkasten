# Camera Project Painting

Camera project painting transfers a transparent image onto a model from the active camera and writes the projected pixels into the model's UV texture. An artist can render the view, paint details over that reference in an external editor, hide the reference layer, and return the transparent detail image to Blender.

Several camera angles can cover more of the object, while restricting projection to selected faces prevents unwanted spill. Orthographic views reduce perspective distortion when the intended detail permits them.
