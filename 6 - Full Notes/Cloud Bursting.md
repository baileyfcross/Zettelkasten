# Cloud Bursting

Cloud bursting moves excess work from one cloud to capacity supplied by another when the first cloud cannot meet demand. It extends elasticity across a cloud or provider boundary rather than only adding resources inside one pool.

The secondary service must be compatible enough to accept the work, data, and control state. Contracts, security, performance, and [[Cloud Service Interoperability]] therefore determine whether bursting can occur automatically without breaking the original service commitment.
