# BIRCH Clustering

BIRCH is a hybrid method for large numerical databases that first compresses observations into a height-balanced cluster-feature tree and then applies a global partitioning method to the leaf summaries.

The method can build its in-memory representation in one scan and restart with a larger diameter threshold when the tree is too large. It remains sensitive to input order and favors roughly spherical groups of similar size.
