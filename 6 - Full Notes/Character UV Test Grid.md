# Character UV Test Grid

A character UV test grid is a numbered or lettered checker image temporarily projected through the character's UV map. Stretched cells reveal shape distortion, unequal cell size reveals inconsistent texture allocation, and readable labels make mirrored or misplaced regions easier to identify.

The grid should be inspected on the model while seams, pinning, and island scale are still editable. Areas that matter to the final image can receive more UV space, while hidden scalp or interior regions can be reduced as long as their lower resolution does not become visible.
