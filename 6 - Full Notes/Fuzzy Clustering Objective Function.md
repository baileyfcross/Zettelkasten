# Fuzzy Clustering Objective Function

A fuzzy clustering objective function measures the membership-weighted discrepancy between observations and cluster prototypes. Minimizing it seeks centers close to observations that have strong membership in their clusters.

The function connects the geometry of the data with the membership matrix. Different weighting exponents, distance measures, and prototype shapes produce different fuzzy algorithms.
