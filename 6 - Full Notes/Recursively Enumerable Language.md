# Recursively Enumerable Language

A recursively enumerable language can be listed by a machine that runs indefinitely, eventually outputting every member and no nonmember. The order need not be fixed, and repetitions are allowed.

This class is equivalent to the [[Turing-Acceptable Language|Turing-acceptable languages]], the ranges of Turing-computable enumerating functions, and the languages generated by general grammars. Dovetailing several simulations prevents one nonhalting computation from blocking all later candidates.
