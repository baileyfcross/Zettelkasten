# Electrostatic Poisson Finite Element Problem

An electrostatic Poisson finite element problem solves scalar potential in a region containing prescribed volume charge. Linear triangular elements approximate both the potential and source distribution at their nodes.

The assembled equation contains a field-gradient matrix and a source-weighting matrix. Prescribed potentials partition free and fixed nodes, after which iterative or band-matrix solution yields the unknown potential values.
