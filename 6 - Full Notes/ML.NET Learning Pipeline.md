# ML.NET Learning Pipeline

An ML.NET learning pipeline chains estimators that prepare columns and train an algorithm. Fitting the pipeline against training data produces a transformer capable of applying the learned sequence to compatible input data.

Keeping preparation and learning in one pipeline ensures the same transformations are applied during training and prediction. The fitted pipeline can be saved as a model artifact together with the input schema required to load it later.
