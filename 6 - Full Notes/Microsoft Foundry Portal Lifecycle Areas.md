# Microsoft Foundry Portal Lifecycle Areas

The Microsoft Foundry portal divides AI work among Discover, Build, and Operate. Discover exposes model catalogs, tool integrations, and solution templates. Build contains models, agents, workflows, fine-tuning, knowledge, data, evaluations, and guardrails. Operate centralizes deployed assets, metrics, compliance, quotas, and project administration.

These areas express a lifecycle rather than three disconnected menus. A team discovers a suitable capability, configures and tests an application, then observes and governs its production behavior. Assets move across those activities while retaining project context, so model selection, evaluation evidence, deployment details, and operational signals can be considered together.
