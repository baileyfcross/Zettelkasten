# AWS Client VPN

AWS Client VPN is a managed OpenVPN-based service that gives individual users encrypted remote access to AWS and connected networks. Administrators associate the endpoint with target subnets, define authorization rules, and choose authentication. Split-tunnel configuration sends only selected routes through the VPN, whereas full tunnel sends all client traffic. Client VPN serves roaming users; [[AWS Site-to-Site VPN]] connects networks through gateways.
