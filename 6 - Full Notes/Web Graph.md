# Web Graph

The web graph represents each web page as a [[Vertex]] and each [[Hyperlink]] as a directed [[Edge]]. A page can link to another without receiving a link back, so the structure is a [[Directed Graph]].

This model turns the enormous scale of the web into usable information. [[PageRank]] derives relative page importance from patterns of outgoing links, backlinks, dangling nodes, and connected groups within the graph.
