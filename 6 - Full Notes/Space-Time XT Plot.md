# Space-Time XT Plot

A space-time XT plot places spatial locations or zones on the horizontal axis, time on the vertical axis, and observed value in color. Each column traces one location through time, enabling comparison of persistent levels and shared temporal events across a network. The display preserves the location identities but not their two-dimensional geographic arrangement, so a [[Space-Time Map Series]] supplies complementary spatial context.
