# Matrix Pencil

A matrix pencil is a parameterized matrix of the form $A-tB$. Its generalized eigenvalues are the parameter values for which the pencil loses rank.

A [[Companion Matrix|companion]] pencil converts a polynomial equation into this rank condition, and a [[Generalized Companion Matrix]] does the same for a polynomial matrix. The linearized form makes polynomial roots accessible through matrix eigenvalue methods.
