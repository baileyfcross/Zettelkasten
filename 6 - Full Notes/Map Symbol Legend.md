# Map Symbol Legend

A map symbol legend decodes the relationship between symbol size, color, or form and the mapped attributes. For a [[Proportional Symbol Map]], representative nested or separated symbols should show actual values and preserve the same scaling rule as the map. A graduated legend should also state class boundaries. The legend must be visually close enough for comparison without obscuring locations or being mistaken for data.
