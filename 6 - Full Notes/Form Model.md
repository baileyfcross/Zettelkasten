# Form Model

A form model represents the current values, validation state, and control hierarchy of a form independently from the persistent data model. It records whether controls are valid, changed, or awaiting asynchronous validation.

In an [[Angular Reactive Form]], the model is assembled from [[Angular Form Control|form controls]] and [[Angular Form Group|form groups]]. The component can inspect or react to that structure without searching the rendered HTML.
