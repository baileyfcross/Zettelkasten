# CSS Box Model

The CSS box model represents a rendered element as nested content, padding, border, and margin regions. Content occupies the innermost area, [[CSS Padding]] separates it from the border, and [[CSS Margins]] create transparent separation outside the border.

Declared width and height normally describe the content box in the model used by the source, so padding and borders add to the outer dimensions. Neighboring boxes are positioned according to these dimensions and the formatting context.
