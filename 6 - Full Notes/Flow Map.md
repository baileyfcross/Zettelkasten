# Flow Map

A flow map depicts connections or movement between places. Lines can represent migration, trade, traffic, or other transfers, while direction and width may encode where a flow goes and how much moves along it.

Unlike a map that assigns one value to each region, a flow map makes the relationship between an origin and destination the principal object. Its design must keep dense connections legible because overlapping paths can conceal rather than reveal movement. Geographic context should be sufficient for orientation without competing with the flows.
