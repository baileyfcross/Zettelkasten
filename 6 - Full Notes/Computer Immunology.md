# Computer Immunology

Computer immunology applies ideas from biological immune systems to cyber defense. Instead of relying only on a fixed list of known threats, a system can distinguish expected activity from harmful change, remember prior encounters, and coordinate a response.

The analogy motivates the [[Self-Nonself Security Model]], [[Security Memory of Prior Infections]], and [[Autonomic Security System]]. It is a design framework: computing systems must translate biological functions into measurable technical signals and controlled actions.
