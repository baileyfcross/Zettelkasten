# Azure Security Architect

An Azure security architect adds identity, data protection, network defense, compliance, detection, and response views to cloud solutions. The role translates regulatory or organizational requirements into controls suited to shared-responsibility and automated cloud environments. Because cloud-native defense relies heavily on identity and policy, the security architect must collaborate early with platform, application, and infrastructure teams instead of applying a perimeter review after design is complete.
