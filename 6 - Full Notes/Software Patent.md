# Software Patent

A software patent seeks protection for a qualifying computer-implemented invention rather than for the literal source text protected by copyright. The claimed subject must be more than an abstract idea merely described as running on a computer and must satisfy the jurisdiction's patentability rules.

The distinction matters because independently written code can express the same algorithm without copying another program's text, yet a valid patent claim may still restrict practicing the claimed method. Patent scope and eligibility are legal questions that require more than comparing repositories.
