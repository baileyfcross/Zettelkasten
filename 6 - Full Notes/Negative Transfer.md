# Negative Transfer

Negative transfer occurs when imported source knowledge makes target performance worse than learning from target evidence alone. It can arise from mismatched feature distributions, label meanings, class boundaries, or source quality.

Detecting negative transfer requires a target-grounded baseline and validation that separates genuine help from added sample size. Selective weighting, source rejection, or weaker coupling can limit damage from an unsuitable domain.
