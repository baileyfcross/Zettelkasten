# Wireshark

Wireshark is a packet capture and protocol analysis tool that displays network frames and decodes their layered fields. Filters can isolate a host, address, port, or protocol so an engineer can inspect one exchange among larger volumes of traffic.

The tool makes packet structure and timing visible, helping distinguish application errors from connection, routing, or protocol behavior. A capture should be collected only where authorized and stored as potentially sensitive data.
