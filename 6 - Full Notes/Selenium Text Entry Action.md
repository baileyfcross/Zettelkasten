# Selenium Text Entry Action

Selenium text entry uses `sendKeys()` to deliver characters or key constants to an element or action sequence. It can fill a search field, password control, single-line input, or multiline text area and can be combined with [[Selenium Keyboard Key State|modifier-key state]].

After entering data, the test can read the element's value and compare it with the intended input. That verification distinguishes successful typing from merely issuing the command.
