# Multilevel Network

A multilevel network organizes a graph as a family of subgraphs whose node and edge unions form the complete system. Each level can represent a distinct scale or grouping while remaining part of one overall network.

The formulation emphasizes nested or grouped structure rather than requiring identical node sets across layers. Analysis can compare within-level patterns with relationships that span levels.
