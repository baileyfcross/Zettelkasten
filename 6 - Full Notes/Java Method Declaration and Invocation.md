# Java Method Declaration and Invocation

A Java method declaration combines an access level, optional modifiers, a return type, a name, parameters, and a body. An instance method operates through an object and can use its fields, whereas a static method belongs to the class and has no implicit current instance.

Invocation evaluates arguments, copies their values into parameters, executes the body, and optionally returns a value compatible with the declared return type. A `void` method returns no value. Method signatures let the compiler select among overloads and reject calls whose arguments do not match an accessible declaration.
