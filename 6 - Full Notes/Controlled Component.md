# Controlled Component

A controlled component is a form element whose displayed value is synchronized with React state. The component supplies the current value and handles change events by updating that state.

This makes the React model the source of truth for the field, allowing validation and submission to read consistent values. A form with many controlled fields can produce repetitive handlers, motivating a [[Generic Form Component]].
