# CSS Element Selectors

An element selector matches document elements by their element name. A rule such as `h1 {color: purple;}` applies its declarations to every matching heading in the document.

Element selectors express a semantic relationship between a document type and its presentation, but they are broad. [[CSS Class Selectors]] and [[CSS Attribute Selectors]] can select a smaller set without changing the element's basic meaning.
