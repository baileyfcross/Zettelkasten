# STIRR Clustering

STIRR, Sieving Through Iterated Relational Reinforcement, represents categorical attribute values as weighted graph or hypergraph nodes. Tuples connect the values that occur together.

An iterative nonlinear system propagates weights through those relations until a fixed point is reached. Values with related co-occurrence patterns develop compatible weights and can be isolated as groups.
