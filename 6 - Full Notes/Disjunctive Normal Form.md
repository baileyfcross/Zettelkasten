# Disjunctive Normal Form

A proposition is in disjunctive normal form when it is an OR of AND clauses whose terms are variables or negated variables. Each true row of a [[Truth Table]] supplies one conjunction: use the variable when the row assigns true and its negation when the row assigns false.

Taking the disjunction of these row clauses produces a formula with exactly the table's output behavior. This construction shows that AND, OR, and NOT gates can implement any Boolean input-output table used by a [[Electronic Circuits|combinatorial logic circuit]].
