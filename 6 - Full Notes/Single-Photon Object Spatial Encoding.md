# Single-Photon Object Spatial Encoding

A monochromatic single photon can encode an object's transverse structure through its spatial wavefunction. After free-space propagation, the object modulates the incident amplitude, and a later linear optical system maps that modulated field to the interferometer's image plane. The resulting input state is described by the total transfer function of the source, object, propagation, and imaging optics.

This physical encoding differs from first recording a pixel array and then loading its numbers into a quantum device. In the proposed [[Hong-Ou-Mandel Quantum Optical Neuron]], the object itself prepares the input branch. For the numerical benchmark, the authors replace the object and lenses with a second spatial light modulator displaying the digital image; this simulates the spatial state while omitting the claimed acquisition advantage of direct object illumination.
