# Client-Side Blazor

Client-side Blazor is the 2019 preview model in which the browser downloads a .NET runtime and application assemblies and executes C# locally through WebAssembly. Interface events can update the page without a server call after the application is loaded.

Local execution enables a C# client but adds an initial download that affects startup. The source explicitly treats this hosting model as not yet part of the official .NET Core 3 release, so its statements describe that historical preview.
