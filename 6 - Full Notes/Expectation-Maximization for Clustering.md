# Expectation-Maximization for Clustering

Expectation-maximization for clustering alternates between estimating probabilistic component memberships from current parameters and updating the component parameters from those weighted assignments.

Each iteration does not decrease the likelihood, but the algorithm normally reaches a local rather than guaranteed global maximum. Hierarchical model-based clustering can provide an initialization.
