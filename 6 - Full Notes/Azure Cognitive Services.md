# Azure Cognitive Services

Azure Cognitive Services is the book's name for managed machine-learning capabilities exposed through Azure APIs. An application supplies data to a pretrained service and receives structured predictions without building and training the underlying model itself.

The emotion detector provisions the Face API, obtains an endpoint and access key, and sends an image from a Xamarin.Forms client. Managed inference reduces local modeling work while making the application dependent on the provider's model, interface, and availability.
