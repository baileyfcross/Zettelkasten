# Spatial Query

A spatial query selects or summarizes stored data according to geographic relationships. Examples include finding the nearest service, identifying parcels inside a flood zone, locating properties near water, or pairing roads with regions they cross.

The query differs from a predictive spatial model: it asks about data already held by the database rather than estimating an unobserved future. Efficient execution depends on representing geometry explicitly and using indexes or algorithms that can discard impossible candidates before performing exact distance or intersection calculations.
