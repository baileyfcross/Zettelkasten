# Unknown Variable

An unknown variable is a [[Variable]] whose value is constrained by an equation or inequality and must be determined. In (3x-5=28), (x) is unknown because only particular values make the assertion true.

Solving transforms the relationship into an equivalent form that isolates the unknown. A symbol does not become an unknown merely by appearing in an expression; it may instead stand for an arbitrary parameter or a known quantity. Identifying the role of each symbol prevents a solution process from treating every letter as something to solve simultaneously.
