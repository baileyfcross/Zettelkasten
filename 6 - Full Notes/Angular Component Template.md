# Angular Component Template

An Angular component template is the HTML-based view associated with an [[Angular Component]]. It combines markup with bindings, interpolation, and directives so that component state can determine what the browser displays.

The template should remain focused on presentation. Data fetching, state transitions, and reusable business-facing operations belong in the component class or an injected [[Angular Service]].
