# Uncertain Rule-Based Classification

Uncertain rule-based classification replaces binary rule satisfaction with the probability that an imprecise observation satisfies the antecedent. Coverage and confidence therefore accumulate fractional support.

At prediction time, a rule's influence can be weighted by its satisfaction probability. This distinguishes a case concentrated inside the rule region from one whose possible values only barely overlap it.
