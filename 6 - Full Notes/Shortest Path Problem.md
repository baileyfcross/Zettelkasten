# Shortest Path Problem

The shortest path problem asks for the route between graph vertices with the smallest [[Graph Path Length]]. In an unweighted graph this can mean the fewest edges; in a [[Weighted Graph]] it means the smallest sum of edge weights.

Enumerating every possible route is correct but can become infeasible. [[Dijkstra's Algorithm]] finds shortest paths from one starting vertex efficiently when edge weights are nonnegative.
