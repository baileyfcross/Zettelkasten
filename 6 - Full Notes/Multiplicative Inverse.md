# Multiplicative Inverse

A multiplicative inverse of an element a is an element u for which au equals the [[Ring Identity]]. When it exists, a is a [[Ring Unit]] and the inverse is written a⁻¹.

Every nonzero element of a [[Field]] has an inverse. A general [[Commutative Ring]] can contain nonzero elements without inverses, which is why localization changes a ring by formally adjoining selected inverses.
