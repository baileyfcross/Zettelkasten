# Azure Solution Architecture Map

The Azure Solution Architecture Map organizes design around workload types and cross-cutting concerns. Workloads are classified as systems of engagement, record, insight, intelligence, or integration, while monitoring, CI/CD, identity, security, networking, governance, and containerization cut across those roles. The map helps an architect ask which capability a service supplies and which non-functional views are still missing before assembling a target architecture.
