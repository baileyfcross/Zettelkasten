# AWK Script File

An awk script file stores pattern-action rules in a reusable program loaded by the awk interpreter. With an appropriate shebang and executable permission, it can also act as a standalone command whose remaining arguments identify input files.

Moving a complex program out of shell quoting improves readability and reduces conflicts between shell metacharacters and awk syntax. The script should still document which awk implementation or extensions it requires.
