# Neural Network Accelerator

A neural network accelerator is a hardware or heterogeneous system specialized for the tensor, vector, and activation operations used by neural models. It seeks higher throughput or energy efficiency by matching data movement, arithmetic precision, and parallel execution to the network.

Acceleration is not one architecture. [[Neural Network ASIC]], [[Neural Network GPU Acceleration]], [[Neural Network FPGA Acceleration]], and [[Neural Network Storage Acceleration]] trade programmability, development time, bandwidth, power, and specialization differently.
