# Agent Intent Resolution Evaluation

Agent intent resolution evaluation checks whether an agent correctly identifies what the user wants before choosing a tool, knowledge source, or workflow branch. It is especially important when similar requests require different actions, permissions, or data systems. A polished final answer cannot compensate for consistently routing the request to the wrong capability.

Evaluation examples should include clear intents, ambiguous wording, overlapping categories, and unsupported requests. Results can expose whether the problem lies in instructions, labels, tool descriptions, or missing clarification behavior. Measuring intent resolution separately makes routing failures visible before they are confused with retrieval or generation errors.
