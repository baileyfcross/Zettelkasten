# Small-Multiple Choropleth

A small-multiple choropleth repeats the same regional map for different times, variables, or groups. Fixed geography supports rapid comparison of changing color patterns, while separate panels prevent layers from obscuring one another. Shared class boundaries and palettes are essential when color must have the same meaning in every panel. The layout becomes ineffective when panels are too small to preserve recognizable regions.
