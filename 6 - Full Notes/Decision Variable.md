# Decision Variable

A decision variable represents a quantity whose value the optimization process is allowed to choose. Examples include production amounts, resource allocations, or activity levels.

Its coefficients in the [[Linear Objective Function]] measure value or cost, while its coefficients in each [[Linear Constraint]] measure resource use or other effects.
