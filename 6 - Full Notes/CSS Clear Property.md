# CSS Clear Property

The `clear` property prevents a box from appearing beside earlier floats on selected sides. The browser moves the box downward until its relevant border edge is below the bottom margin edge of those floats.

Clearing acts on the element itself rather than canceling [[CSS Floats]]. It creates enough clearance for the box to avoid the specified float side while later content can still respond to remaining floats.
