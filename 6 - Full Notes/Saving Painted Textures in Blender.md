# Saving Painted Textures in Blender

A texture painted in Blender must be saved as an external image if it is to persist independently of the current in-memory image buffer. The Image Editor's Save As command chooses its location and format.

The UV layout can also be exported as an image, providing a guide for work in another painting application. A lossless format such as PNG preserves the painted result while keeping file size manageable.
