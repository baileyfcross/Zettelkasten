# Marker Set Validation

Marker set validation checks whether the returns produced by a [[Linguistic Marker Set]] actually represent the intended concept. Researchers inspect usage, associations, variation, and false positives instead of assuming that a keyword match is meaningful.

Validation is especially important when definitions and proximity windows change results sharply. Explicit assumptions help reviewers judge conclusions even when the full corpus or analytical implementation is difficult to reproduce.
