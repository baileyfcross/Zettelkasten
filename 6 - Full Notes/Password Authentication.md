# Password Authentication

Password authentication verifies a claimed identity through a secret the user knows. Its security depends on both the quality of the secret and the way the system stores, transmits, verifies, and recovers it.

Passwords are vulnerable to guessing, reuse, theft, and deceptive collection. A [[Cryptographic Salt]] and hash can improve stored-password protection, while [[Multi-Factor Authentication]] reduces dependence on the password as the only evidence of identity.
