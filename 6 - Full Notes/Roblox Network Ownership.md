# Roblox Network Ownership

Network ownership determines which machine simulates the physics of an unanchored Roblox assembly. Giving a nearby client ownership can make motion responsive and reduce server work, while server ownership provides tighter authority over objects whose movement affects security or shared rules.

Ownership is therefore both a performance and trust decision. A client-controlled physics result can be manipulated, so consequential motion must be bounded or checked by the server. The tradeoff sits between [[Roblox Client-Server Replication]], physical responsiveness, and [[Roblox Server-Side Validation]].
