# Prospective Provenance

Prospective provenance records what a computation is intended to do. It describes the workflow structure, modules, connections, declared inputs, and configuration that exist before execution.

This planned representation lets a researcher inspect dependencies, reuse a workflow, or compare alternative designs without first running them. It differs from [[Retrospective Provenance]], which records what actually happened, and from [[Workflow Evolution Provenance]], which records how the planned workflow changed across versions. Together they connect design, execution, and history.
