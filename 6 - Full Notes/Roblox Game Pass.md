# Roblox Game Pass

A Roblox Game Pass is a purchasable entitlement associated with an experience, commonly used for a lasting privilege or access benefit. Server code checks ownership and grants the promised capability rather than trusting the client to report a purchase.

The product should communicate its effect clearly and handle players who already own it. Because platform behavior and policy can evolve, current implementation details should be confirmed against Roblox documentation. A pass differs from [[Roblox Developer Product]], which is designed for purchases that can be made repeatedly.
