# R Bioconductor Package Installation

R Bioconductor package installation uses the Bioconductor repository tooling so package releases remain aligned with a compatible R and Bioconductor version. This coordinated repository differs from installing an arbitrary package name from the default general-purpose repository.

Dependencies and version compatibility should be allowed to resolve through the Bioconductor installer. The resulting environment should still be documented with [[R Session Information]] because package availability changes across release cycles.
