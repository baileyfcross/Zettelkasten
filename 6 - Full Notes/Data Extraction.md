# Data Extraction

Data extraction retrieves relevant records from source systems so they can enter an analytical pipeline. Sources may differ in structure, access method, update rate, and meaning, so extraction must preserve enough provenance to interpret later results.

Selecting what to extract already shapes the evidence. Missing systems, inaccessible fields, and inconsistent collection practices can produce a partial view before modeling begins.
