# Git Staging Area

The Git staging area is the proposed content of the next commit. [[Git Add]] copies selected working-tree changes into this index, allowing other local edits to remain outside the snapshot.

Staging is a review boundary between editing and committing. A developer can inspect and adjust the selected changes so the resulting [[Git Commit]] represents one understandable unit of work.
