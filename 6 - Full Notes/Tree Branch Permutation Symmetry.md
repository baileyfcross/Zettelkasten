# Tree Branch Permutation Symmetry

Swapping the two child branches below a dendrogram node changes the page order of leaves but not the membership of clusters inside either subtree. Such adjacency-preserving permutations are tree symmetries; the book describes their combined actions through a wreath-product group.

This distinguishes a hierarchy's intrinsic nested structure from an arbitrary left-right drawing convention. A summary constant within a cluster is invariant under these branch exchanges, providing a mathematical basis for multiscale aggregation on a tree.
