# Azure DevOps Area Path

An Azure DevOps area path classifies work items by a product, subsystem, or organizational ownership boundary. Teams and queries can use the hierarchy to focus views on the work for which they are responsible.

Area paths should reflect stable reporting and ownership needs. Encoding a rapidly changing implementation detail into the hierarchy makes historical comparison and cross-team work harder to interpret.
