# Data Security States

Data protection must cover three operational states: [[Data at Rest]] in storage, [[Data in Transit]] between locations, and [[Data in Process]] while a system uses it. A control that protects only one state leaves transition points or active processing exposed.

Treating the states separately helps designers choose appropriate access, encryption, integrity, and monitoring controls for the way information exists at each moment.
