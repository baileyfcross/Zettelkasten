# Unity 2D Physics

Unity 2D physics uses dedicated Rigidbody2D and Collider2D components backed by Box2D. These components provide forces, gravity, contact, triggers, and constraints for flat games while preserving the engine's component-oriented workflow.

Two-dimensional and three-dimensional physics components do not collide with each other. A 2D project should therefore keep interacting bodies within the 2D family. Sprites may still occupy three-dimensional scene coordinates for ordering, but their simulated interaction remains planar.
