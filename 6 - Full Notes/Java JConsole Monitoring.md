# Java JConsole Monitoring

JConsole is a graphical JDK monitoring client that connects to a local or suitably exposed remote JVM. It presents memory, thread, class-loading, CPU, and MBean information and can perform supported management operations.

Remote access requires an intentional management or debugging connection and must be secured rather than casually exposed. JConsole is useful for a live overview; longer recordings and deeper profiling are better handled by Java Flight Recorder and Mission Control when the problem unfolds over time.
