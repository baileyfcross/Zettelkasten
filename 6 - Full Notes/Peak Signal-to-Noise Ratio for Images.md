# Peak Signal-to-Noise Ratio for Images

Peak signal-to-noise ratio compares an original and a modified image using mean squared pixel error relative to the largest possible sample value. A higher PSNR indicates less numerical error under that model.

PSNR is easy to calculate and useful for controlled comparisons, but it treats errors with the same magnitude similarly even when their visual importance differs. It can therefore rank an obviously objectionable artifact and an unobtrusive texture change poorly relative to human judgment. See [[Structural Similarity Index]] and [[Butteraugli Perceptual Image Comparison]].
