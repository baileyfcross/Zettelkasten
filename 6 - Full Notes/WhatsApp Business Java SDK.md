# WhatsApp Business Java SDK

A WhatsApp Business Java SDK gives an enterprise application typed access to business messaging operations such as constructing messages and interacting with the provider's API. The integration is business-to-customer communication rather than unrestricted peer-to-peer automation, so provider registration, templates, permissions, and account policy shape what the client may send.

Messaging code should separate conversation intent from provider payloads, protect access credentials, and account for asynchronous status and webhook events. This makes delivery state and consent part of the application's model instead of assuming that a successful request equals a completed conversation. [[Social Messaging Services]] explains the service category; [[Social Platform Java Client Selection]] supplies the maintenance and coupling criteria for choosing a client.
