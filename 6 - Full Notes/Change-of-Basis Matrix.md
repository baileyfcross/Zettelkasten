# Change-of-Basis Matrix

A change-of-basis matrix converts coordinates from one [[Ordered Basis]] to another. If its columns are the new basis vectors expressed in the old basis, multiplying by it maps new coordinates to old coordinates.

For a linear operator, changing from basis $\mathcal B$ to $\mathcal B'$ transforms its matrix by $A'=P^{-1}AP$. This [[Similarity Transformation]] changes the coordinate description without changing the operator itself.
