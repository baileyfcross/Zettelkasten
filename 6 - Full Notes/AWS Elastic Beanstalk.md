# AWS Elastic Beanstalk

AWS Elastic Beanstalk deploys application code into an environment whose AWS resources it provisions and coordinates. Depending on the platform, it can create compute instances, load balancing, scaling, and monitoring while leaving the developer responsible for the application and its data.

The service offers a higher-level deployment experience without hiding the underlying resources completely. Teams can inspect and tune those resources, but changes should respect Beanstalk's environment lifecycle so platform-managed configuration remains consistent.
