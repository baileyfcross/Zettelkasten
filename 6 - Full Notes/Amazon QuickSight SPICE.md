# Amazon QuickSight SPICE

SPICE is Amazon QuickSight’s in-memory calculation engine for interactive analysis. Importing a dataset into SPICE decouples dashboard reads from repeated queries against the source and provides consistently fast calculations for concurrent viewers. The imported copy must be refreshed to reflect source changes, so freshness requirements, refresh schedules, dataset size, and direct-query alternatives should be chosen together.
