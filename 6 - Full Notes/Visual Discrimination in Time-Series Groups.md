# Visual Discrimination in Time-Series Groups

Visual discrimination in time-series groups is the ability to distinguish multiple trajectories reliably through color, line, label, or panel arrangement. A qualitative palette must contain separable colors, but an arbitrary palette does not express similarity. The source orders colors using hierarchical clustering of temporal behavior so visually related trajectories receive related hues. [[Direct Time-Series Labeling]] can reduce dependence on color when the number of groups exceeds comfortable legend use.
