# LLM-Assisted Intrusion Detection

LLM-assisted intrusion detection interprets network or host events in context to identify behavior that may represent unauthorized access or attack progression. Language-based interfaces can also explain correlated alerts and help analysts create or refine detection logic.

The system should augment the intrusion-detection engine rather than replace packet, flow, endpoint, and rule evidence. False positives, latency, privacy, and resistance to adversarial input must be evaluated before model output drives response.
