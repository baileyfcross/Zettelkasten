# Image Recognition

Image recognition is the computational task of identifying patterns or classes represented in digital images. A grayscale image can be supplied to a neural network as a [[Matrix]] of pixel-intensity values, with each value serving as an input feature.

During [[Supervised Learning]], labeled images form a training dataset and a separate test dataset measures generalization. A multiclass output layer can assign probabilities to possible object categories through a [[Softmax Function]].
