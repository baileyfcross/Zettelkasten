# Prompt Jailbreaking

Prompt jailbreaking uses specially constructed input to bypass a model application's behavioral restrictions and elicit output or actions the system intended to forbid. It targets the reliability of instruction following rather than necessarily exploiting a conventional memory-safety flaw.

Because textual restrictions are probabilistic, application security must also enforce authorization, tool constraints, output validation, and data boundaries in deterministic code. A model refusing most test prompts is not proof that a privileged action is protected.
