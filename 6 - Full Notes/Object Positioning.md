# Object Positioning

Object positioning changes the three-dimensional location of an object. It is one of the canonical tasks of [[3D Manipulation]].

The task can vary by the distance and direction to the initial and target positions, the total translation distance, and the precision required. A direct spatial mapping may make coarse movement intuitive, but large control-display gain can amplify hand jitter and make precise placement difficult.

Constraints can remove unnecessary [[Degrees of Freedom]], while suitable [[Feedback]] helps the user judge when the object has reached the intended location.
