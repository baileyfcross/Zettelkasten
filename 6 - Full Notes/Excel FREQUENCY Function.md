# Excel FREQUENCY Function

The Excel FREQUENCY function counts numeric observations into intervals defined by a set of bin limits. It returns an array containing one count for each bin plus an additional count for values greater than the highest limit. Blank cells and text do not contribute numeric observations.

Bin limits should be ordered and chosen to answer a meaningful distribution question. In the legacy workflow described by the source, the output range is selected before entering the function as an array formula. The results summarize how many values fall into groups; they do not preserve the identity of the individual records in each group.
