# Time-Series Scatterplot Matrix

A time-series scatterplot matrix displays every pairwise relationship among variables in a multivariate [[Time Series]]. Repeated panels let viewers compare correlation, curvature, clusters, and unusual observations across variable pairs. Time is not inherently visible in the positions, so [[Temporal Color Encoding]] can distinguish periods or groups. The matrix scales poorly with the number of variables because each added variable creates a new row and column of panels.
