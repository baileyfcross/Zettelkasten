# Dialog Module

A dialog module is a reusable subflow for a recurring conversational function such as confirmation, help, authentication, or collecting an address. It packages related states and transitions behind a defined entry and exit.

Modules reduce duplication in a [[Finite-State Dialog Manager]] and make common recovery behavior consistent. They also expose clearer boundaries for testing and maintenance.
