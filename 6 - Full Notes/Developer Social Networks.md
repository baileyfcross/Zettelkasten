# Developer Social Networks

A developer social network connects identity and collaboration to source repositories, projects, issues, contributions, and release activity. GitHub, GitLab, Bitbucket, Launchpad, and SourceForge are examples in the source. Their social graph is partly derived from following people and projects, but also from observable technical work.

Integration therefore needs more than a public profile. Applications may inspect organizations, repositories, collaborators, pull requests, issues, or project metadata through authenticated APIs. [[Java GitHub API Clients]] shows two Java object models for one such platform. Because access can affect code and organizational assets, token scopes and application authorization are as important as the social features.
