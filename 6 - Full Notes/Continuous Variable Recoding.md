# Continuous Variable Recoding

Continuous variable recoding changes the representation of a measured quantity for analysis. It may replace special nonnumeric codes, cap values at a study boundary, create meaningful ranges, or convert the variable into ordered groups.

Recoding must preserve a documented connection to the source measure. Summary statistics, plots, and cross-tabulations with the original variable help verify that legitimate values remained intact and that special codes did not enter calculations as if they were measurements.
