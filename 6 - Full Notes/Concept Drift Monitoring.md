# Concept Drift Monitoring

Concept drift is a change over time in the process or behavior a model is meant to predict. Because a model learned from past observations does not automatically change with the world, its performance can deteriorate after deployment.

Monitoring compares later records and outcomes with the conditions under which the model was trained. A meaningful change can prompt fresh data preparation, evaluation, and retraining. The book treats this as a reason the data science life cycle is iterative rather than ending when the first model goes live.
