# AWS ParallelCluster

AWS ParallelCluster is an AWS-supported cluster-management tool for creating elastic high-performance computing environments. It configures a scheduler, head node, compute fleet, networking, and storage from a reproducible definition, then scales worker nodes around queued jobs. Tightly coupled workloads may combine it with Elastic Fabric Adapter and high-performance storage, while loosely coupled work can emphasize inexpensive scale-out capacity.
