# CSS Animation Fill and Play States

An animation fill mode controls whether keyframe values apply before the active interval begins, after it ends, in both directions, or only while it runs. This can hold the starting or ending keyframe instead of immediately reverting to the underlying style.

The play-state property pauses or resumes an animation without discarding its current progress. These controls act alongside delay, iteration, and direction to define the animation's complete timeline behavior.
