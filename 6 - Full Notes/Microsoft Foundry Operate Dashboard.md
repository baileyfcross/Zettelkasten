# Microsoft Foundry Operate Dashboard

The Microsoft Foundry Operate dashboard gives a cross-project view of running agents, estimated cost, access rate, token consumption, alerts, execution trends, and success rate. Its Assets, Compliance, Quota, and Admin areas connect that summary to the deployed models, agents, tools, policies, capacity limits, users, and connections producing it.

The dashboard is a starting point for investigation rather than proof of application quality. A high run-success rate can coexist with poorly grounded answers, while token or latency changes may reveal a prompt or traffic shift. Operational health therefore needs to be read alongside evaluation and trace evidence.
