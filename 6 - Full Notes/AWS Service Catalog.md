# AWS Service Catalog

AWS Service Catalog lets an organization publish approved cloud products that users can provision through controlled self-service. A product can package infrastructure definitions and constraints so consumers receive a repeatable capability without needing permission to assemble every underlying resource freely. This separates platform governance from delivery speed: administrators curate acceptable options, while application teams launch products through a consistent interface.
