# Project Behavior Anomaly Detection

Project behavior anomaly detection identifies unusual patterns in work, communication, or schedule data that may indicate coordination problems or emerging risk. Examples include sudden handoff growth, repeated reopening, missed updates, or activity inconsistent with the project baseline.

Behavioral signals are sensitive and context-dependent. They should be used to ask better process questions, not to infer an individual's motive or competence, and access should be limited to legitimate project-risk purposes.
