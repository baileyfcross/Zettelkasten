# Validation-Guided Tuning

Validation-guided tuning chooses model complexity or settings by comparing performance on data excluded from fitting. The process separates parameter estimation from decisions about the learning procedure.

The selected configuration should then be assessed once on a final test partition that did not influence tuning.
