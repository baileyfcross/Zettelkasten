# Legacy Excel Array Formula

A legacy Excel array formula performs calculations on several values at once and may return one result or populate a selected output range. In the Excel versions emphasized by the source, it is confirmed with Ctrl+Shift+Enter, after which Excel displays braces around the formula; the braces are not typed manually.

Editing part of a multi-cell array result is restricted because the cells belong to one calculation. Array formulas can avoid helper columns and express complex criteria, but their evaluation shape must be understood. Newer Excel versions provide dynamic arrays, so a workbook should document whether it depends on legacy entry behavior for compatibility.
