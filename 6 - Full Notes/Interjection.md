# Interjection

An interjection is a user contribution that interrupts or temporarily departs from the current dialog flow. It can request help, repeat information, correct a value, cancel, or start a new goal.

Handling interjections makes a conversation less rigid than a single-path form. After the interruption, the [[Dialog Manager]] must decide whether to resume, revise, or abandon the prior task.
