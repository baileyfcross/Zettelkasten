# AWS Cloud Adoption Framework

The AWS Cloud Adoption Framework organizes cloud transformation into six perspectives: business, people, governance, platform, security, and operations. Each perspective groups capabilities and stakeholders that must change for cloud adoption to produce sustained organizational value.

CAF is broader than a technical migration checklist. It helps identify capability gaps, coordinate transformation initiatives, and connect technology work to business outcomes, while the [[AWS Well-Architected Framework]] evaluates the qualities of individual workloads and their architecture.

The framework also gives the [[AWS Migration Readiness Assessment]] a shared vocabulary for identifying gaps. The book describes cloud transformation through envision, align, launch, and scale phases: establish the intended outcomes, coordinate stakeholders and capability gaps, deliver initial initiatives, and then expand the operating model.
