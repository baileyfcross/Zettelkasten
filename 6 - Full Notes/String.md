# String

A string is a finite sequence of symbols from an [[Alphabet]]. Its length counts symbols, concatenation appends one sequence to another, and reversal lists the same symbols in the opposite order.

String equality requires both equal length and the same symbol in every position. Concatenation is associative but generally not commutative, and the [[Empty String]] serves as its identity.
