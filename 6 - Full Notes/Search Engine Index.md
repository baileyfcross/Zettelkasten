# Search Engine Index

A search engine index is the stored representation of web-page content gathered by a [[Web Crawler]]. It allows a search engine to find documents matching a query without rereading the live web for every request.

Matching is only one part of search. A common query may retrieve enormous numbers of pages, so [[Search Result Ranking]] must order the candidates to place likely relevant and authoritative results first.
