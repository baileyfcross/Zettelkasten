# Ring Homomorphism

A ring homomorphism is a map between rings that preserves addition, multiplication, and the [[Ring Identity]]. Its kernel is an [[Ideal]] of the source ring, and its image is a subring of the target.

The kernel records which elements become zero. The [[First Isomorphism Theorem for Rings]] identifies the image with the source modulo that kernel, connecting homomorphisms directly to [[Quotient Ring]]s.
