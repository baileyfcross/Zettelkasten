# X3D Scene Export from Blender

X3D is an ISO-standard descendant of VRML for storing, retrieving, and playing real-time 3D scenes. Blender can export geometry with options for modifiers, triangulation, normals, compression, transforms, and selection filtering.

Hierarchy export preserves parent-child relationships, while name decoration can mark node types in exported identifiers. These choices affect whether the receiving system sees a structured scene or only an unorganized collection of shapes.
