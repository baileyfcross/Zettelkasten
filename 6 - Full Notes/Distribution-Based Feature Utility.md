# Distribution-Based Feature Utility

Distribution-based feature utility estimates the value of a transformation from how it changes feature or class distributions, without fully training a downstream model. Divergence and separability measures can provide inexpensive search guidance.

The proxy accelerates exploration but may not align perfectly with eventual predictive performance. It is most useful when its assumptions match the task and expensive candidates receive later model-based confirmation.
