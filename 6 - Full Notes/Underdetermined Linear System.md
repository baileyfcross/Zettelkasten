# Underdetermined Linear System

An underdetermined linear system has fewer equations than unknowns. When consistent, it typically has infinitely many solutions because some variables remain free.

A [[Minimum-Norm Solution]] selects the solution closest to the origin. It can be expressed using a [[Pseudoinverse]] when the needed rank conditions hold.
