# Personal Iteration

Personal iteration is the local loop in which a developer changes code or content, runs it, observes the result, and revises it. Hardware speed, build tools, in-game editing, and asset hot loading determine how frequently this loop can occur.

Reducing seconds or minutes from a loop repeated throughout the day compounds into more experiments and earlier discovery of defects or design problems.
