# Discretionary Access Control

Discretionary access control lets an authorized user or object owner decide who may access a resource. File permissions that the owner can grant, change, or remove are a common example.

The flexibility supports collaboration but also allows user mistakes to weaken protection. [[Mandatory Access Control]] instead places the governing policy beyond ordinary user discretion.
