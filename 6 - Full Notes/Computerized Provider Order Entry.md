# Computerized Provider Order Entry

Computerized provider order entry records medication, laboratory, imaging, and other care orders directly in an electronic system. Structured entry can reduce transcription problems and make orders immediately available to downstream departments.

Order entry is also a natural intervention point for a [[Clinical Decision Support System]]. The system can check dose, allergy, duplication, or interaction rules while the clinician is acting. That benefit depends on workflow fit: poorly targeted warnings can create [[Clinical Decision Support Alert Fatigue]], while incomplete patient data can make an apparently precise alert unreliable.
