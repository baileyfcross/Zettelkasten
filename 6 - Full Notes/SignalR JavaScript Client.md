# SignalR JavaScript Client

The SignalR JavaScript client is the browser library that builds and starts a connection to an ASP.NET Core hub. The book installs the package with npm and copies the required client files into the application's public web root.

Client code attaches [[SignalR Client Handler|handlers]] before starting the connection and invokes [[SignalR Hub Method|hub methods]] for outbound actions. Its route and message names must match the server configuration exactly.
