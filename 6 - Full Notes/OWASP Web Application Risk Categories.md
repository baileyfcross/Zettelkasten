# OWASP Web Application Risk Categories

OWASP web application risk categories organize recurring classes of weakness in web software. They give developers and assessors a shared vocabulary for problems such as improper input handling, broken identity controls, unsafe configuration, and exposure of sensitive data.

The categories guide attention but do not replace analysis of a particular application. Their practical value is to connect the [[Secure Software Development Lifecycle]] with recognizable patterns of [[Cyber Vulnerability]].
