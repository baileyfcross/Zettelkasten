# Exploratory Data Analysis

Exploratory data analysis uses summaries and visual displays to investigate distributions, relationships, anomalies, and plausible structures before formal modeling. Scatterplots and multidimensional views often reveal information that a table of statistics conceals.

Exploration should occur throughout knowledge discovery. It helps select attributes and methods, diagnose model behavior, and communicate why a discovered pattern deserves further testing.
