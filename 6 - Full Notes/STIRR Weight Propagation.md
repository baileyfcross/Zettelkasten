# STIRR Weight Propagation

STIRR weight propagation updates an attribute-value node from the weights of the other values appearing with it in database tuples. A combiner function aggregates each tuple's influence, after which the configuration is normalized.

Repeated reinforcement is transitive: values strongly related to an initial or emerging pattern pass influence through their shared records.
