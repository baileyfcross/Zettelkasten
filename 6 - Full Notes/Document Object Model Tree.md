# Document Object Model Tree

The Document Object Model represents an HTML page as a tree whose nodes include elements, text, and attributes. The document is the root, nested elements form parent-child relationships, and elements under the same parent are siblings.

Selenium locators search this structure rather than the page's visual appearance alone. Understanding the tree makes [[Selenium Web Element Locator|element locators]], XPath paths, and CSS relationships easier to design and maintain.
