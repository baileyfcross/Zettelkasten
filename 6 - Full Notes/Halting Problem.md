# Halting Problem

The halting problem asks whether a given [[Turing Machine]] will eventually halt on a specified input. No Turing machine or general computer program can answer this question correctly for every machine-input pair.

The proof encodes machines, assumes a decider, and constructs a machine whose behavior contradicts that decider when applied to its own indexed input. The associated halting language is [[Recursively Enumerable Language|recursively enumerable]] but not [[Recursive Language|recursive]], while its complement is not recursively enumerable.
