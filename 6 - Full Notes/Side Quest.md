# Side Quest

A side quest is an optional authored sequence that the player can pursue outside the main path of a game. It may reveal more about a character, location, conflict, or part of the world while adding a separate goal and set of challenges.

Its value depends on how optional it truly is. When a side quest contains narrative information needed to understand the main plot, players may experience it as required even if the system allows them to pass it by.
