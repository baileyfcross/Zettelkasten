# End-to-End Test

An end-to-end test drives a user-visible workflow through the running client and server. It interacts with the browser, observes rendered behavior, and exercises the network and application boundaries involved in completing the scenario.

This scope provides strong workflow evidence but introduces more moving parts and slower feedback. It is best focused on valuable journeys while smaller tests cover detailed branches.
