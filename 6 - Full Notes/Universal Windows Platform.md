# Universal Windows Platform

The Universal Windows Platform is an application model for Windows devices that uses a defined API surface, package identity, and capability declarations. Its applications can adapt interfaces across different screen sizes and device families while sharing a common Windows codebase.

Capabilities make access to sensitive device functions explicit, and packaging governs installation and distribution. UWP's constraints distinguish it from classic desktop frameworks even when both use C# and XAML.
