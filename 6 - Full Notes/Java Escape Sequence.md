# Java Escape Sequence

An escape sequence represents a character that would be difficult or ambiguous to write directly inside a Java character or string literal. A backslash introduces forms for newline, tab, backspace, carriage return, form feed, quotes, backslash, and selected whitespace or line-continuation behavior.

Escaping belongs to source syntax: the resulting runtime string contains the represented character rather than the two source characters used to spell it. A [[Java Text Block]] reduces much of the quoting and line-break noise for multiline text while retaining escape processing where it is needed.
