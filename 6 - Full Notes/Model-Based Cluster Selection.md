# Model-Based Cluster Selection

Model-based cluster selection chooses the component count and parameterization that provide the best supported probabilistic description of the data. It compares whole fitted models rather than selecting k independently of cluster shape.

Likelihood improvement must be weighed against model complexity. A more flexible mixture can fit the sample better while generalizing worse.
