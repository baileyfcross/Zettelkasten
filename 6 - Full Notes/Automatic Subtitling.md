# Automatic Subtitling

Automatic subtitling converts speech into timed text and can add machine translation to produce captions in other languages. It combines audio segmentation, speech recognition, translation, line breaking, and display timing, so errors in an early stage pass into every later stage.

The technique supports noisy public environments, live media, accessibility for hearing-impaired viewers, and multilingual distribution. Real-time constraints and limited screen space make literal transcript quality insufficient: the output must remain synchronized, readable, and concise. Reliable deployment therefore requires evaluating the complete pipeline rather than the translation component in isolation.
