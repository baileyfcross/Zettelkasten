# Crisp Partition

A crisp partition divides a data set into nonempty, mutually disjoint clusters whose union contains every observation. Each observation has membership one in exactly one cluster and zero in the others.

This representation is simple and decisive, but it can handle ambiguous or overlapping groups poorly. Fuzzy clustering generalizes it by permitting intermediate membership values.
