# .NET Internationalization

.NET internationalization adapts text, numbers, dates, currencies, comparisons, and other behavior to a language and region. The current culture supplies formatting conventions, while the UI culture helps select localized resources.

Culture-sensitive behavior should be explicit at boundaries. User-facing output normally follows the user's culture, while persistent identifiers and machine-readable formats often require an invariant convention. Resource files separate translatable content from the program logic that chooses it.
