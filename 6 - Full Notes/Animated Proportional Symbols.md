# Animated Proportional Symbols

Animated proportional symbols keep point locations fixed while changing symbol radius, color, or both through time. The source animates station circles whose size encodes measured value and whose color distinguishes weekdays from weekends. Stable identities help viewers follow each location, while missing values can be mapped to zero size. A [[Animation Progress Bar|time reference]] is needed because repeated motion alone does not reveal the current date.
