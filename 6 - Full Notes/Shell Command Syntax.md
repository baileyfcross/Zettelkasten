# Shell Command Syntax

A shell command commonly consists of a command name followed by options that modify behavior and arguments that identify the objects to process. The apparent sequence is simple, but the shell first applies quoting, expansion, and redirection before the selected program receives its final argument vector.

Options may use short or long forms, accept their own values, or be combined according to the command's rules. Because utilities do not all parse options identically, documentation such as manual pages remains the authoritative description of a command's interface.
