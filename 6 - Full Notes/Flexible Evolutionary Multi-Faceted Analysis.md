# Flexible Evolutionary Multi-Faceted Analysis

Flexible evolutionary multi-faceted analysis is a tensor-based framework for modeling behavior that changes across time and several aspects. Projection matrices reduce each mode while graph-based regularizers preserve relationships specific to that facet.

Tensor perturbation updates eigenvalues and eigenvectors from incoming changes instead of repeating a complete decomposition. The approximation is efficient when each increment is sparse and higher-order changes remain small.
