# Excel Flash Fill

Excel Flash Fill infers a text transformation from examples supplied by the user and fills the remaining rows with predicted results. It can split, combine, or reformat consistent strings without requiring the user to write a formula.

The filled output is a set of values rather than a transparent, continuously recalculating rule. Its predictions should be reviewed, especially when names, punctuation, missing fields, or other exceptions vary across records. Flash Fill is efficient for one-time cleanup; repeatable transformations that must update with source data are usually better represented by explicit formulas or query steps.
