# Hypergraph Partitioning

A hypergraph edge can connect more than two vertices, preserving multiway relationships that an ordinary graph would decompose into pairwise links. Hypergraph partitioning divides vertices while minimizing cut hyperedges under balance constraints.

This representation is useful for transactions, circuits, and relational data in which one event joins many objects. The cut definition must specify whether splitting a hyperedge once or across several blocks carries different cost.
