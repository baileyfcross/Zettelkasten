# R S4 Class System

The R S4 class system defines formal classes with named slots and declared slot types. A class definition specifies its representation, and the new constructor creates an instance whose supplied values must satisfy those structural declarations.

Formal definitions make object expectations inspectable and support inheritance between related statistical types. Slot access should respect the class interface because direct manipulation can bypass the validity rules that constructors and methods are intended to enforce.
