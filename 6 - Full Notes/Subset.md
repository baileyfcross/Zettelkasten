# Subset

A subset is a set whose every element belongs to another set. The notation A ⊆ B allows equality, while a proper subset excludes equality.

Subsets become algebraic substructures only when they also preserve the operations of the larger structure.

The empty set is a subset of every set because an implication beginning with membership in the empty set can have no counterexample. The family of all subsets of A forms its [[Power Set]].
