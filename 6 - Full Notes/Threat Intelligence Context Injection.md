# Threat Intelligence Context Injection

Threat intelligence context injection enriches normalized network events with known indicators, classifications, or adversary context. A suspicious source address in a firewall log becomes more useful when the analysis can compare it with a curated intelligence file and the organization's network map.

The intelligence needs provenance, timestamps, and expiration because indicators become stale and can be wrong. Matching should remain a visible deterministic step where possible, while the model explains the relationship and recommends investigation. Unmatched events must not be declared safe merely because the supplied intelligence lacks them.
