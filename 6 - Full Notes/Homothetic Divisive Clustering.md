# Homothetic Divisive Clustering

Homothetic divisive clustering splits a data set using one binary variable at a time so that a chosen within- or between-group criterion improves. The process continues with other variables until a stopping rule is met.

Because each split depends on a single variable, the resulting hierarchy is readily described but may miss structure that depends on combinations of attributes.
