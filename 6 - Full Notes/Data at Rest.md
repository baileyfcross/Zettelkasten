# Data at Rest

Data at rest is inactive or intermittently used data stored in a digital medium, including disks, cloud storage, backups, and archives. Its storage location may persist long after the application that created it has stopped running.

Protection can include encryption, access control, retention limits, integrity verification, and secure destruction. Backup and archival copies must be included because protecting only the primary store leaves other copies exposed.
