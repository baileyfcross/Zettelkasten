# Information Authenticity

Information authenticity is confidence that information genuinely originated or was created where it claims. It concerns the veracity of the source, not only whether the contents remained unchanged afterward.

Establishing identity, validating credentials or certificates, and protecting messages against substitution support authenticity. It complements [[Data Integrity]] because an unmodified message can still be inauthentic if it came from an impostor.
