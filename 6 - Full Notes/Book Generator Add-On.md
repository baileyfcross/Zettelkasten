# Book Generator Add-On

The Book Generator add-on procedurally populated shelves or scenes with book meshes. A width parameter could expand a single generated book into a row whose individual volumes varied in dimensions, producing background variety without modeling each prop.

Generated books included UV mapping, making image-based covers easier to apply. The tool is most suitable for repeated set dressing; prominent foreground books may still need deliberate geometry, texture, and arrangement beyond the generated defaults.
