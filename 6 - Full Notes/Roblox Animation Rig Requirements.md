# Roblox Animation Rig Requirements

A Roblox animation rig is a hierarchy of parts connected by Motor6D joints so the Animation Editor can identify and pose articulated relationships. A designated root or primary part establishes the stable reference from which the rest of the rig is organized.

Loose parts or ordinary physical constraints do not provide the same skeletal structure. Before animating, the model should be named and connected consistently, with joint relationships that match the motion expected in the game. A valid rig can then store [[Roblox Pose Keyframes]] and be driven alongside [[Roblox Humanoid Character]] behavior when appropriate.
