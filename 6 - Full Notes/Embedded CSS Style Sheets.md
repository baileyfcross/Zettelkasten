# Embedded CSS Style Sheets

An embedded stylesheet places CSS rules inside a document's `style` element. The rules apply to that document without requiring a separate CSS file, and a `media` attribute can restrict them to selected output media.

Embedding keeps the rules near the markup but limits their reuse. It is broader than [[Inline CSS Styles]], because selectors in the embedded sheet can match any appropriate element in the document.
