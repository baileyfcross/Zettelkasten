# Codebase Context Retrieval

Codebase context retrieval locates definitions, call sites, dependencies, configuration, tests, and documentation relevant to a development task. It gives a code model focused repository evidence without placing the entire project in one context window.

Symbol navigation and semantic search serve different needs and can be combined. Retrieved fragments should retain paths and relationships so the model can distinguish authoritative definitions from examples or stale documentation.
