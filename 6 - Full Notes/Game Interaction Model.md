# Game Interaction Model

A game interaction model defines how the player projects intention into the game world. It identifies the entities the player controls, the scope of that control, and the operations the interface must make available.

The interaction model is one component of a [[Gameplay Mode]], alongside gameplay and camera model. Avatar-based, party-based, multipresent, contestant, and desktop models create different requirements for selection, navigation, and feedback.
