# Stepping-Stone Method

The stepping-stone method tests each nonbasic transportation cell by constructing a [[Closed Loop in a Transportation Tableau]]. Unit costs are alternately added and subtracted around the loop to obtain an improvement index.

For a minimization problem, nonnegative indices certify optimality. If an index is negative, the most negative loop enters; the smallest allocation at a minus corner determines how much shipment can be shifted while preserving every row and column total.
