# Simple Parametric Curve

A simple parametric curve has no multiple points: distinct parameter values do not map to the same point, apart from the permitted endpoint coincidence when discussing a simple closed curve.

This condition separates a trace without self-intersections from a parameterization that loops back across itself. A simple curve that is also closed is a [[Jordan Curve]].
