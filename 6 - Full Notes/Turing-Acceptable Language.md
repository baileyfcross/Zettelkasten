# Turing-Acceptable Language

A language is Turing-acceptable when some [[Turing Machine]] halts exactly on the strings in the language. For a string outside the language, the machine may run forever rather than halt with an explicit rejection.

Every [[Turing-Decidable Language|decidable language]] is acceptable, but the converse fails. Turing-acceptable languages are exactly the [[Recursively Enumerable Language|recursively enumerable languages]] and exactly the languages generated by general grammars.
