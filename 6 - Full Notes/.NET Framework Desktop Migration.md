# .NET Framework Desktop Migration

A .NET Framework desktop migration moves an existing Windows application onto the newer .NET Core runtime while preserving as much application behavior as practical. In the book's 2019 example, a working Windows Forms codebase is retargeted to .NET Core 3 before its compilation and resource differences are repaired.

The migration begins with the project boundary rather than a rewrite of every form. Dependencies, platform APIs, project references, and output resources must then be checked individually because runtime compatibility does not guarantee that every framework-era assumption remains available.
