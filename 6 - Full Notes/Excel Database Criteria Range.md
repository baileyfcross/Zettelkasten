# Excel Database Criteria Range

An Excel database criteria range is a small worksheet area that tells database functions which table records qualify. Its header cells reproduce field names from the database, and the cells below contain values or expressions that define conditions.

Criteria placed on the same row act together, while separate rows can express alternatives. Exact header matching and deliberate layout are essential because a misplaced criterion can change the logical rule. Keeping the criteria range visible and labeled makes DCOUNT, DSUM, DAVERAGE, and related functions easier to audit than conditions hidden inside a dense formula.
