# Visual Studio Code Metrics

Visual Studio code metrics calculates measures such as maintainability index, cyclomatic complexity, depth of inheritance, class coupling, and lines of code across a .NET solution. Results can be inspected at progressively narrower structural levels.

The report helps an architect locate code that deserves investigation and compare change over time. The metrics are most useful alongside tests and review because they describe structure, not whether the system meets its requirements.
