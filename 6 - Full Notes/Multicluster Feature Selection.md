# Multicluster Feature Selection

Multicluster feature selection uses several spectral directions to represent multiple latent groups rather than scoring features against a single division. A sparse regression or related selection step identifies features that jointly explain those directions.

Using multiple directions helps preserve distinctions among several clusters and can capture complementary features. The estimated number of structural directions and the similarity graph remain modeling choices that affect the selected subset.
