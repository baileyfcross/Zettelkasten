# Alternative Optimal Solutions

Alternative optimal solutions occur when more than one feasible point attains the same best objective value. Graphically, the objective line is parallel to a binding edge, so every feasible point on that segment is optimal.

In a final simplex tableau, the same condition can appear when an eligible nonbasic variable has a zero objective-row improvement value. Pivoting it into the basis yields another optimal basic feasible solution without changing the objective.
