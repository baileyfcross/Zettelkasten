# Consensus Decision-Making in Design

Consensus decision-making seeks a proposal every affected collaborator can support or accept, even if it is not each person's first choice. It differs from unanimity of preference and from majority rule that leaves a persistent minority unheard.

The method works best when the team has shared design values and a defined way to end discussion. Evidence from a prototype can transform an abstract dispute into a question the group can observe together.
