# Apache Tez

Apache Tez is a Hadoop execution framework that represents a job as a directed acyclic graph of processing stages rather than a fixed sequence of separate MapReduce jobs. It can avoid unnecessary materialization and coordinate a more efficient dataflow.

Query systems can compile higher-level plans into Tez graphs while YARN supplies the cluster resources.
