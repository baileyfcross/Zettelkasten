# Text Classification Mutual Information

Text classification mutual information compares the observed co-occurrence of a word and class with the co-occurrence expected if they were independent. A large positive value signals that the term is unusually associated with that category.

Scores can be calculated class by class and then combined for multiclass selection. Rare terms can receive unstable high values, so frequency support and validation should accompany the information criterion.
