# Excel Present Value Function

The Excel PV function calculates the present value of a stream of future payments, optionally including a future balance. It converts future cash flows into an equivalent value today using a periodic interest rate and a number of periods.

Rate and period units must agree: a monthly payment model needs a monthly rate and a count of months. Excel's financial functions use cash-flow signs to distinguish money paid from money received, so an unexpected negative result may reflect perspective rather than a mathematical failure. Timing assumptions about payments at the beginning or end of periods also affect the result.
