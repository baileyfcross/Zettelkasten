# Test Explorer

Visual Studio Test Explorer discovers tests from supported adapters, groups and filters them, runs selected scopes, and presents pass, fail, skip, duration, and diagnostic output. It is the operational view that connects source-level test methods to repeated local execution.

Discovery and execution depend on the project's test SDK and framework adapter. A green display is evidence about the executed configuration and test set, not proof that untested schedules or environments are correct.
