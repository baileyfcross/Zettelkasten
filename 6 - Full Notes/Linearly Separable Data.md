# Linearly Separable Data

Linearly separable data can be divided into classes by a linear [[Decision Boundary]]. In two dimensions the boundary is a straight line, in three dimensions it is a plane, and in higher dimensions it generalizes to a hyperplane.

A single artificial neuron using a step activation can learn this kind of separation. Concentric or otherwise nonlinear class regions require an [[Artificial Neural Network]] that combines several neurons and hidden layers.
