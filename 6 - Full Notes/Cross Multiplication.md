# Cross Multiplication

Cross multiplication solves a proportion by multiplying both sides by both nonzero denominators. From

$$\frac{a}{b}=\frac{c}{d},\qquad b,d\neq0,$$

it follows that

$$ad=bc.$$

The step is a shorthand for [[Clearing Denominators]], not a separate rule that applies to arbitrary sums of fractions. When a denominator contains a variable, values that make it zero must be excluded before the products are formed. Any resulting candidate should be verified in the original proportion.
