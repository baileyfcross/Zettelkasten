# Tag Co-Occurrence Network

A tag co-occurrence network represents tags as nodes and connects two tags when they appear on the same item. An edge weight counts how often the pair occurs, producing a weighted undirected graph when co-occurrence has no direction.

The representation exposes relationships that individual tag frequencies cannot show. It also inherits the platform’s tagging rules and user practices, so a strong edge indicates repeated joint use rather than a universal semantic relation.
