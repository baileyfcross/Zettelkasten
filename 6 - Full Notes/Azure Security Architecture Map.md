# Azure Security Architecture Map

The Azure Security Architecture Map organizes protection across data, identity, network, application delivery, posture management, workload defense, DevSecOps, and security operations. It makes security a set of connected architectural capabilities rather than a final perimeter layer. An architect uses the map to establish trust boundaries, preventive and detective controls, operational ownership, and response paths, then chooses services according to workload risk and deployment model.
