# Multi-Person Multi-Version Programs

Large software is difficult because many people create and maintain many versions of interacting programs. Each change must remain compatible with other components, preserve shared assumptions, and reach users through a controlled lifecycle.

Version control helps track artifacts, but the deeper problem is coordination. Teams need stable interfaces, ownership, integration practices, and communication structures that make concurrent change intelligible.
