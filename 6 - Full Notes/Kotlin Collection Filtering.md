# Kotlin Collection Filtering

Kotlin's `filter` operation evaluates a predicate for each source element and returns a collection containing the elements for which that predicate is true. The original values are retained rather than transformed.

Related operations can filter by index, type, or the negative of a condition. The predicate is therefore a selection policy separated from traversal, allowing the same collection mechanism to express many different subsets without a hand-written accumulation loop.
