# CSS Print Break Control

Print break properties influence whether a page break is inserted before, after, or inside an element. Values can request, avoid, or select a side-specific break so major sections begin on an appropriate left or right page.

Break avoidance is a preference rather than an unlimited guarantee because content must eventually be fragmented when it exceeds a page. Widows and orphans set minimum line counts retained around a page break inside a paragraph.
