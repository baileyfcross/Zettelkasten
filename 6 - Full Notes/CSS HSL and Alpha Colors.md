# CSS HSL and Alpha Colors

The CSS `hsl()` form describes color through hue, saturation, and lightness. Hue is an angle around a color circle, saturation measures color intensity, and lightness ranges from black through the chosen hue toward white.

The `hsla()` form described by the source adds transparency. HSL can make families of related shades easier to express than direct RGB components, while the rendered color still enters the same compositing process as [[CSS RGB and Alpha Colors]].
