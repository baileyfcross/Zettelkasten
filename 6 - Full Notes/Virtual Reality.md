# Virtual Reality

Virtual reality is an approach that uses displays, [[3D Tracking]], and other technologies to immerse a user in a [[Virtual Environment]]. It replaces the person's view of the physical environment with a synthetic spatial world and can create [[Presence]], the feeling of being there.

Immersion does not guarantee a usable experience. The [[3D User Interface]] must coordinate input, output, interaction techniques, and human capabilities. Inconsistent sensory information, poor ergonomics, or excessive [[Latency]] can reduce performance and contribute to [[Cybersickness]].
