# Audio Snapshot

An audio snapshot is an authored set of temporary mix and effect changes applied across one or more [[Audio Bus|buses]]. Activating it can lower music, emphasize dialogue, add reverb, or otherwise reshape the mix for a situation.

Snapshots can fade in and out rather than switching abruptly. Because they modify routing state rather than replacing every sound, existing event instances continue playing through the transition.
