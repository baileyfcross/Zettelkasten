# Custom Accelerator

A custom accelerator implements a targeted computation with hardware resources and a data path specialized for its operations. Removing general-purpose instruction overhead can improve throughput, latency, or energy efficiency.

The benefit is limited by host communication, memory bandwidth, unsupported cases, and the cost of changing the design when the algorithm or data representation evolves.
