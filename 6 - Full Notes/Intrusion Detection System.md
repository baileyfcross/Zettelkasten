# Intrusion Detection System

An intrusion detection system analyzes activity to identify possible attacks, misuse, or behavior inconsistent with authorized use. It can examine firewall, server, identity, and service logs for repeated login failures, unusual traffic, or attempts to retrieve inappropriate data.

Detection turns raw operational records into security alerts that people or automated systems can investigate. It reports suspicious behavior; an [[Intrusion Prevention System]] additionally acts to block or contain it.
