# React Component Lifecycle

The React component lifecycle is the ordered sequence in which a component is initialized, rendered, updated, and removed. Lifecycle boundaries provide controlled places for work that cannot be expressed as the pure calculation of an element tree, such as requests, timers, DOM-dependent libraries, or cleanup.

The first-edition source describes the React 15 class lifecycle, including several `componentWill...` methods that later React versions changed or deprecated. Its lasting design distinction is between [[React Mounting Lifecycle|mounting]], [[React Updating Lifecycle|updating]], and [[React Unmounting Lifecycle|unmounting]], with external work paired to the phase that owns it.
