# Data Warehousing

Data warehousing is the organizational and technical process of creating, maintaining, and using a [[Data Warehouse]]. It integrates disparate databases, organizes large stores by subject, and supports efficient retrieval and interpretation.

Separating decision-support data from operational processing can improve accessibility and analytic consistency. Continued quality controls are needed because integrated data can preserve inconsistencies as easily as it preserves facts.
