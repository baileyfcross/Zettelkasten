# Game Model

A game model is the game's simplified, dynamic representation of a world. It includes the combined parts, states, rules, and systems that respond to player actions and create the space for gameplay.

The model does not need to reproduce reality in full; it must expose the structure relevant to the experience. Consistent [[Feedback]] allows the player's [[Player Mental Model|mental model]] to track it closely enough for prediction and meaningful action.
