# Design Values

Design values are explicit qualities the finished play experience should embody. They describe what the team is trying to make players do, perceive, consider, and feel rather than enumerating features that happen to be present.

Because values remain stable while implementations change, they guide choices throughout iteration. A proposed feature is useful when it advances those qualities and expendable when it does not.
