# R For Loop

An R for loop assigns successive values from an iteration vector to an index name and evaluates the statements inside its braces for each value. It is appropriate when a calculation depends on earlier iterations, produces side effects, or is easier to understand as an explicit recurrence.

The iteration sequence and target positions should be stated visibly. A loop that begins too early or ends too late can read an uninitialized value or write outside the intended part of the result without expressing the scientific recurrence correctly.
