# Virtual Private Network

A virtual private network creates an [[Encrypted Communication Channel]] across a network that is not itself trusted. It can protect [[Data in Transit]] and give a remote device logical access to resources as though it were connected through a controlled network boundary.

A VPN protects the tunnel, not every endpoint or application using it. Identity checks, device security, access limits, and monitoring remain necessary parts of [[Defense in Depth]].
