# Point Space-Time Grid

A point space-time grid pairs a fixed set of point locations with a set of observation times. When every combination is represented, it is a [[Full Space-Time Grid]] and can be stored as an [[STFDF Object]]. With $n$ stations and $m$ times, the values must follow the object's expected $n m$ ordering. The regular structure supports directly comparable map slices and station series.
