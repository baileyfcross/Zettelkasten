# Attribute Weight

An attribute weight is a multiplier that represents how strongly an attribute contributes to an object's practical value in a particular game. Raw totals are misleading when top speed matters more than acceleration or a decorative horn value has little effect on racing performance.

Weights should begin with simple provisional values and be revised from playtest results. The weighted total helps compare deliberately different objects on a common basis, but it does not dictate that every object must be equal; known outliers can serve jokes, punishments, or expert challenges. The purpose is to model actual influence, then test whether that model matches play.
