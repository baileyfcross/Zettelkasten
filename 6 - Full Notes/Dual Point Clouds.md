# Dual Point Clouds

Correspondence analysis treats rows and columns as linked point clouds rather than analyzing one side and discarding the other. An observation is located in relation to the attributes it contains, and an attribute is located in relation to the observations in which it occurs.

The book describes transition formulas between these dual factor spaces. In a scene-word analysis, the map can therefore show scene-to-scene, word-to-word, and scene-to-word relationships. This duality is what makes the factor map a semantic context for the entire cross-tabulation.
