# SOAP Web Service

A SOAP web service exchanges structured messages according to the Simple Object Access Protocol. SOAP defines an application-level messaging contract above the transport and is commonly carried through HTTP rather than replacing HTTP's network role.

The contract can standardize operations and message structure across consumers, but its additional envelope and service conventions are useful only when both sides need that formal interoperability.
