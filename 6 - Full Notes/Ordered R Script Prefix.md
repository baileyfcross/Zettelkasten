# Ordered R Script Prefix

An ordered R script prefix uses leading numbers to communicate a project's intended execution sequence. Names such as `01-import.R` and `02-clean.R` make dependencies visible in a directory listing.

The ordering is documentation, not a substitute for explicit inputs and outputs between stages.
