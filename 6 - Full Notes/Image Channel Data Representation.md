# Image Channel Data Representation

A pixel is commonly represented as several numeric channels rather than one indivisible color. The number of channels, their meanings, and the bit depth assigned to each determine how many values the image can express.

An RGB image stores red, green, and blue components, while other spaces may store luminance separately from color differences. An additional alpha channel can describe coverage or opacity. Compression formats exploit relationships within and between these channels instead of treating every stored number as independent. See [[RGB and Luma-Chroma Color Spaces]].
