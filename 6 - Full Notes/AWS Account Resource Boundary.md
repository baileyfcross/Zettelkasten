# AWS Account Resource Boundary

An AWS account is a container and isolation boundary for resources, identities, billing, and quotas. Resources created in one account are not visible or usable from another unless a policy and trust relationship explicitly permit access.

Using accounts as boundaries limits blast radius and clarifies ownership. Separate production, development, security, and sandbox accounts can receive different controls while still being governed together through [[AWS Multi-Account Strategy]].
