# Visual Classification

Visual classification joins interactive visualization with model construction or prediction so that a person can inspect data, boundaries, features, and uncertain cases. The display acts as a reasoning interface rather than a decorative report.

Useful systems must represent high-dimensional evidence without overwhelming the viewer and must connect visible actions to reproducible classifier changes. Human feedback can then supplement labels or model constraints.
