# Azure Function

An Azure Function is a small stateless unit of code invoked by a configured trigger and hosted with managed scaling. The developer supplies the operation while Azure supplies and scales the execution infrastructure, which is why the model is described as serverless.

The book's C# function compares dates for a logic app and returns a compact result. A function is useful when a high-level workflow reaches a calculation that is clearer or more reliable in ordinary code.
