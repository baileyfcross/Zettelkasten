# CSS Numbers Percentages and Fractions

CSS distinguishes integers from general numbers and combines numeric values with units when a property expects a dimension. Percentages are relative values whose reference depends on the property, such as a containing block dimension or an inherited font size.

Grid layout also defines the `fr` unit as a fraction of remaining space in a grid container. Its meaning belongs to [[CSS Fractional Grid Units]] rather than to percentages or ordinary arithmetic fractions.
