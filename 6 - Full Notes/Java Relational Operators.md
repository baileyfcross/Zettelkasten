# Java Relational Operators

The relational operators `<`, `>`, `<=`, and `>=` compare numeric primitive values and produce a boolean result. Numeric promotion first brings operands to a compatible evaluation type.

These operators do not provide a general ordering for objects. Reference types use a comparison method such as `compareTo` or a `Comparator`, and equality uses `equals` when logical value comparison is intended. Keeping those operations separate prevents an object's identity from being mistaken for its domain order.
