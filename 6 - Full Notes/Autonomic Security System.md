# Autonomic Security System

An autonomic security system can monitor its own condition, identify harmful behavior, choose a response, and restore operation with limited human intervention. The model aims for self-protection and self-healing when attack speed exceeds manual response.

Autonomy requires bounded actions, trusted observations, and recovery safeguards so that a false alarm does not cause greater damage than the threat. [[Computer Immunology]] provides one conceptual basis for this adaptive behavior.
