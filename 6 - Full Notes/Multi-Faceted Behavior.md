# Multi-Faceted Behavior

Multi-faceted behavior describes actions through several interacting dimensions, such as user, object, action type, context, and time. A tensor retains those dimensions instead of flattening them into unrelated pairs.

Factorization extracts latent patterns shared across facets, while regularization can preserve known relationships within each dimension. The representation supports both behavioral pattern discovery and future-action prediction.
