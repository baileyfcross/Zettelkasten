# UML System Boundary

A UML system boundary is the rectangle that defines which use cases belong to the modeled system or module. Actors remain outside because they interact with the system without being part of its internal functional scope.

Choosing the boundary is a modeling decision. A large application may use a separate boundary for an independently understandable module, allowing the diagram to focus on the responsibilities included in that view.
