# System State

System state is the aggregate of the current values of a system's attributes. It describes the system at a particular moment, such as the amount of a resource in a [[Stock]] or the health of a game character.

State changes over time through [[System Behavior|behaviors]] and interactions. Because later actions depend on current state, feedback loops make the history of changes consequential to future behavior.
