# Eclipse Deeplearning4j JVM Training Stack

Eclipse Deeplearning4j supplies JVM-oriented components for defining, training, and executing neural networks, with supporting tensor and data-processing libraries. The source situates it among Java machine-learning options when teams want model work inside the JVM ecosystem.

It represents a different level of abstraction from calling a hosted generative model. Choosing it means owning architecture, training data, numerical configuration, artifacts, and serving behavior rather than delegating those concerns to a foundation-model API.
