# Choosing a Chroma Key Color

A keying background need not be blue or green. Its color should contrast clearly with the subject's colors so the keyer can separate them, and it should be saturated and lit as evenly as the shoot permits. A costume or object that repeats the screen color is likely to disappear with it. Uneven illumination expands the background's color range and forces a wider key tolerance, increasing the chance that foreground detail is lost. The screen choice therefore shapes the difficulty of the later [[Color-Space Keyer Tolerance]] adjustment.
