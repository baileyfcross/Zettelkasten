# Metadata-Grounded Release Notes

Metadata-grounded release notes are generated only from controlled fields such as merged pull-request titles, labels, authors, and bodies. The workflow first creates a structured report, then groups changes into a fixed format without inventing features, fixes, infrastructure work, or breaking changes.

The generated document is validated for required sections and nonempty content, then used to create a draft rather than a published release. This separates documentation assistance from release authority: AI improves consistency and audience readability, while a human reviews the draft before the [[Release Pipeline]] communicates it as an official release.
