# Web-Guided Color Harmony

A color-scheme tool can generate related swatches from a selected harmony rule or extract a palette from an inspirational image. This externalizes part of color planning before the values are transferred into Blender for painting and material work.

The generated palette is a structured proposal rather than a finished visual decision. Lighting, material response, neighboring colors, and scene purpose still determine whether those swatches work once applied to three-dimensional assets.
