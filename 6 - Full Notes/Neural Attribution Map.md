# Neural Attribution Map

An attribution map displays which inputs or internal activations a neural network relies on for a particular output. Kelleher describes saliency or heat-map views that estimate how strongly the output relates to neurons in earlier layers.

This helps inspect a decision pathway in a large network whose representations are distributed across many units. The map is a model-analysis aid, not an exact human-readable chain of reasoning or proof that the model used only the highlighted information. Alongside [[Neural Feature Visualization]], it addresses part of the [[Neural Network Explainability Gap]] by making internal contributions easier to examine.
