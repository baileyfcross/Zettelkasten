# AJAX

AJAX is the browser application pattern of exchanging data with a server asynchronously and updating part of the interface without reloading the entire page. It became a foundation for responsive web clients and the [[Single-Page Application]] pattern.

The transport can be exposed through [[XMLHttpRequest]], the [[Fetch API]], or a framework wrapper such as [[Angular HttpClient]]. The response is commonly JSON rather than a complete HTML document.
