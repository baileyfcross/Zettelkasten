# Blender Startup File Customization

A user startup file makes the current Blender scene and interface the default state for later sessions. It can preserve preferred objects, editor layouts, units, and other project conventions, reducing repeated setup work.

For a team, distributing the same startup file creates a common starting environment. That consistency is useful only when changes are intentional, because saving startup data can also preserve temporary scene content or layout choices that were not meant to become defaults.
