# Rare Class Stream Detection

Rare class stream detection identifies a known minority class within a continuous flow where recent windows contain few positive examples. Ordinary accuracy can remain high even when the stream classifier misses every rare event.

Costs, selective sampling, class-sensitive thresholds, and protected memory can increase attention to the minority. The learner must distinguish a persistent rare class from a genuinely new class whose first cases were absent from training.
