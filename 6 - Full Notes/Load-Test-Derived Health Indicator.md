# Load-Test-Derived Health Indicator

A load-test-derived health indicator is selected by observing how a system behaves under realistic demand, degradation, and failure. The test reveals which queue, dependency, resource, or leading metric changes before user-visible throughput, latency, or error objectives are lost.

A useful exercise runs realistic scenarios in a production-like or scaled environment, captures telemetry across layers, and identifies the indicators that explain limits and ripple effects. The result is more specific than a universal dashboard because it reflects the architecture's measured behavior.
