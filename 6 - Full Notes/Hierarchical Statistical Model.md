# Hierarchical Statistical Model

A hierarchical statistical model represents variation at more than one level. In high-throughput biology, one level describes observations within each feature and another describes how feature-specific parameters vary across thousands of related features.

The hierarchy permits [[Information Borrowing Across Features]] without requiring all features to have identical parameters. It is especially useful when each individual feature has too few replicates for a stable standalone estimate.
