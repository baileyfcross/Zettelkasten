# XAML Markup Extension

A XAML markup extension supplies a value when a XAML document is constructed rather than requiring the value to be written literally. Its `ProvideValue` method can interpret a compact expression, retrieve a resource, or produce a value using the service context supplied by the XAML loader.

Markup extensions make repeated value-resolution logic declarative. They should remain narrowly focused so a short XAML expression does not hide substantial application behavior.
