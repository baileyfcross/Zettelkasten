# Amazon Managed Grafana

Amazon Managed Grafana supplies managed Grafana workspaces for visualizing and exploring metrics, logs, and traces from AWS and compatible external data sources. It removes server maintenance and integrates workspace authentication and data-source permissions with AWS. Dashboards remain an interpretation layer: reliable operations still depend on trustworthy telemetry, meaningful service-level indicators, controlled access, and alerts connected to response procedures.
