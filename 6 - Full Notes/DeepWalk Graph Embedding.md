# DeepWalk Graph Embedding

DeepWalk learns node vectors by generating random walks and treating the visited node sequences like sentences. A word-embedding objective places nodes with similar walk contexts near one another.

The method captures higher-order proximity without explicitly computing all paths. Walk length, number of walks, window size, and graph connectivity shape the context distribution it learns.
