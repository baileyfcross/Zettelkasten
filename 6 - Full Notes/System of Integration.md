# System of Integration

A system of integration connects applications and services through APIs, workflows, messages, events, and transfer mechanisms. API gateways handle synchronous exposure and policy, while brokers and integration platforms support asynchronous or orchestrated exchange. The integration layer must define message contracts, routing, retries, identity, ordering, and failure visibility; otherwise it becomes a hidden coupling point rather than a controlled boundary.
