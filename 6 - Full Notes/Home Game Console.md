# Home Game Console

A home game console is a specialized game machine typically used with a television in a shared living-room space. Standardized hardware and controllers give designers a predictable performance and input target.

Console play often supports comfortable long sessions and local social play, but certification, proprietary development access, screen distance, and shared display conditions constrain interface and production choices.
