# UML Use Case Diagram

A UML use case diagram presents the functional goals a system offers and the external actors that participate in them. It can describe a whole system at a high level or focus on the goals of one module.

The diagram is about functional scope, not implementation sequence. [[UML Actor|Actors]] remain outside the [[UML System Boundary]], use cases appear inside it, and communication links show which actor participates in which goal.
