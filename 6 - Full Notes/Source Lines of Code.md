# Source Lines of Code

Source lines of code is a size metric that counts executable or structural lines according to a tool's rules. It can provide context for comparing components and observing growth, but it does not measure delivered value or correctness.

Large methods and classes may merit decomposition when size accompanies complexity or coupling. Optimizing for a smaller count alone can make code denser and harder to understand, so the metric must be interpreted with other evidence.
