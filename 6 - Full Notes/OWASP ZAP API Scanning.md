# OWASP ZAP API Scanning

OWASP ZAP can scan a running API for vulnerability patterns such as cross-site scripting and injection weaknesses. The book describes configuring the API URL as a target and running an automated scan as part of proactive security assessment.

A scanner supplies evidence, not a proof of safety. Findings need review and remediation, authenticated operations require suitable test credentials, and periodic scans should complement code review, dependency checks, penetration testing, and examination of the hosting environment.
