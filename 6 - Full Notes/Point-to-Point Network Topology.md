# Point-to-Point Network Topology

A point-to-point network topology consists of one logical connection between two nodes. It is the smallest complete network and gives each endpoint a direct path to the other.

The arrangement has low implementation and routing complexity, but it does not by itself provide an alternate route. Losing its one link removes communication between the two nodes.
