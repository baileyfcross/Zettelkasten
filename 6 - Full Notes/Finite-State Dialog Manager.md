# Finite-State Dialog Manager

A finite-state dialog manager represents an interaction as states connected by transitions. Each state defines expected input and assistant behavior, while recognized events determine the next state.

The model makes a narrow service flow predictable and testable. Its limitations appear when users change goals, provide information out of order, or require context not encoded in the state graph.
