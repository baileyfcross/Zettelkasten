# Injective Module

An injective module Q has the extension property: whenever N embeds in M, every homomorphism N → Q extends to a homomorphism M → Q.

Injectivity is dual to projectivity. Short exact sequences beginning with an injective module split, and [[Injective Resolution]]s provide one route to defining the [[Ext Functor]].
