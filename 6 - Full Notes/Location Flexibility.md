# Location Flexibility

Location flexibility is the value gained when people can reach a computing environment and its information from different places. Network-delivered services can support remote work and global reach without keeping the application or data on one local workstation.

The benefit depends on [[Broad Network Access]], suitable client devices, identity controls, and network availability. It can improve productivity, but it also expands the locations and endpoints that must be secured.
