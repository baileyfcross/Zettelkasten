# Cost-Sensitive Rare-Class Learning

Cost-sensitive rare-class learning assigns a larger penalty to missing minority examples than to common majority errors. Training then minimizes expected cost rather than the unweighted number of mistakes.

Costs may alter example weights, split criteria, rule confidence, margins, or decision thresholds. They should reflect application consequences when possible, because arbitrary costs can improve recall while creating an unacceptable number of false alarms.
