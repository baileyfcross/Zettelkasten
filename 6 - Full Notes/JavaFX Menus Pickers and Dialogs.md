# JavaFX Menus Pickers and Dialogs

JavaFX supplies menu and popup controls for commands that should not occupy permanent layout space. `MenuBar`, `Menu`, and `MenuItem` form conventional application menus; `MenuButton` and `SplitMenuButton` combine a compact button surface with a command list; and `ContextMenu` presents commands for a specific interaction context.

Choice-oriented controls include `ChoiceBox`, editable or noneditable `ComboBox`, `ColorPicker`, and `DatePicker`. Dialog APIs range from predefined alerts, choice dialogs, and text-input dialogs to custom `Dialog` and `DialogPane` content. Each control exposes observable value or result state, allowing it to coordinate with [[JavaFX Event Handling]] and [[JavaFX Property Binding]] rather than requiring unrelated global variables.
