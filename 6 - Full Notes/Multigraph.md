# Multigraph

A multigraph is a [[Graph]] that permits multiple instances of an edge between the same pair of vertices. The repeated edges are distinct relationships even though their endpoints are identical.

The Königsberg bridge representation is a multigraph because several separate bridges connect the same landmasses. Preserving those parallel edges is essential when the question asks whether every physical bridge can be crossed exactly once.
