# Algorithm and Source Code Copyright Distinction

Copyright distinguishes an algorithmic idea or method from the particular source code that expresses it. The implementation may be copyrighted even though the underlying mathematical procedure is not protected by copyright in the same way.

This distinction explains why a paper can describe a method that another researcher independently reimplements while reuse of the author's actual code still requires permission. For reproducible research, an open license on [[Copyright in Scientific Software|scientific software]] reduces the need for clean-room reimplementation and allows the published computation to be inspected directly.
