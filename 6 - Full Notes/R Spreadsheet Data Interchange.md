# R Spreadsheet Data Interchange

R spreadsheet data interchange reads a worksheet or spreadsheet range into a rectangular R object and can write an R table back to a workbook-compatible form. Worksheet selection, header placement, blank cells, mixed column types, and date encoding must be made explicit because a visually tidy sheet is not necessarily a well-typed [[R Data Frame]].

For simple exchange, a [[Delimited Text Data|delimited text]] export is often easier to inspect and version. Direct workbook access is valuable when multiple sheets, cell types, or an established Excel delivery format must be preserved.
