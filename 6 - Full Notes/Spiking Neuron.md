# Spiking Neuron

A spiking neuron maintains an internal activation potential that changes as input pulses arrive and decays when they do not. It emits an output event only when the potential crosses a threshold. Timing therefore matters: enough inputs must occur within a suitable window to trigger a spike.

Kelleher contrasts this event-driven unit with a standard artificial neuron that computes an activation from the inputs at each processing step. In [[Neuromorphic Computing]], sparse firing can reduce repeated activity and energy use. It is a hardware-oriented computational model inspired by biological signaling, not a claim that all neural-network tasks are better expressed with spikes.
