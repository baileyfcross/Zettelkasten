# AWS Database Migration Service

AWS Database Migration Service copies data from a supported source database to a target and can continue replicating changes to reduce cutover downtime. Homogeneous migrations retain the engine family, while heterogeneous migrations may require AWS Schema Conversion Tool to translate schema and code.

DMS moves data but does not by itself prove application compatibility. Schema behavior, stored logic, permissions, network connectivity, validation, performance, and a rollback plan remain parts of migration readiness.
