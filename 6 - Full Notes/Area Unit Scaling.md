# Area Unit Scaling

An area carries two powers of length, so changing its length unit changes both dimensions. The book converts square feet to square kilometers through square meters, using $\mathrm{m^2/ft^2}$ followed by $\mathrm{km^2/m^2}$. A single unsquared feet-to-meters multiplier would leave the wrong magnitude even if the output label looked plausible. Squaring the length ratio or using an established area ratio yields the same dimensional cancellation. See [[Volume Unit Scaling]] and [[Conversion-Factor Chains]].
