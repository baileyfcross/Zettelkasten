# Problem Space

The problem space describes the gap between a current state and a desired state, including the intermediate states, constraints, and rules that shape possible movement between them. Customers, users, and [[Domain Knowledge]] normally live in this space. A team must understand it before committing to a [[Solution Space]], because a technically polished answer can still solve the wrong problem. Keeping problem statements separate from proposed features makes assumptions easier to challenge.
