# Raster Map Animation

A raster map animation plots each layer of a time-indexed raster with the same graphical settings and concatenates the resulting image files into a movie. It can reveal movement of a continuous field, such as forecast cloud cover, when adjacent layers change smoothly. Administrative boundaries supply fixed spatial context. Inconsistent scales or extents would turn frame-to-frame changes in rendering into apparent changes in the data.
