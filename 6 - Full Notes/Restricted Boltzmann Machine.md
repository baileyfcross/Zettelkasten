# Restricted Boltzmann Machine

A restricted Boltzmann machine is an undirected probabilistic model with visible and hidden units and no connections within either layer. The restricted structure makes conditional sampling and learning more tractable than in a fully connected Boltzmann machine.

Hidden-unit activations form learned features of the visible input. Training adjusts weights so that the model assigns greater probability to observed patterns, commonly using approximations to otherwise expensive likelihood gradients.
