# Integral Domain

An integral domain is a nonzero [[Commutative Ring]] in which a product can equal zero only when at least one factor is zero. Equivalently, it has no [[Zero Divisor]]s.

Every [[Field]] is an integral domain, but an integral domain need not make every nonzero element invertible. A proper ideal is a [[Prime Ideal]] exactly when the corresponding [[Quotient Ring]] is an integral domain.
