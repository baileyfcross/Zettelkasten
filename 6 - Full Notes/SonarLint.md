# SonarLint

SonarLint is an editor extension that reports code-quality and reliability issues while a developer works. It shifts selected analysis from a later centralized review into the immediate coding feedback loop.

Local diagnostics help prevent repeated problems before a commit, but the team's shared build analysis remains the authoritative policy. Developers need consistent rule configuration so local and pipeline results do not contradict one another.
