# Excel TRANSPOSE Function

The Excel TRANSPOSE function switches the orientation of a range so source rows become output columns and source columns become output rows. In the legacy array workflow covered by the source, the user first selects an output area with reversed dimensions and confirms the formula with Ctrl+Shift+Enter.

Unlike copying and pasting transposed values, the function preserves a calculated connection to the source. Changes to source cells therefore update the transposed result. The output shape must match the source dimensions, and legacy multi-cell array restrictions apply when editing or clearing the returned range.
