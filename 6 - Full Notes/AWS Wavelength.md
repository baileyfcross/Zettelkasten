# AWS Wavelength

AWS Wavelength places supported AWS compute and storage capabilities inside telecommunications-provider 5G networks. It is intended for applications such as live media, connected devices, and interactive systems that need very low latency between a mobile client and application processing.

A Wavelength Zone extends a region through the carrier network rather than replacing regional services. The application must separate latency-sensitive components from state or services that remain in the parent region.
