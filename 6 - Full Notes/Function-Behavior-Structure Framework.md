# Function-Behavior-Structure Framework

The Function-Behavior-Structure framework describes a design through its purpose, the behaviors that achieve that purpose, and the physical or representational parts and relationships that enable those behaviors.

It can be applied top-down from desired function to structure or bottom-up as Structure-Behavior-Function. In [[Systemic Game Design]], it connects the intended player experience to [[Game System|systems]] and the [[Game Part|parts]] that implement them.
