# Cloud Web Hosting

Cloud web hosting runs a website on infrastructure or a platform that can change capacity with demand. Web traffic often varies by hour, day, campaign, or product launch, so a fixed environment may alternate between idle excess and inadequate peak capacity.

[[Rapid Elasticity]] and consumption-oriented pricing fit this pattern because resources can scale out during a burst and scale in afterward. Application design, network capacity, measurements, and load tests are still needed to make that elasticity effective.
