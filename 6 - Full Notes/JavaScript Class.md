# JavaScript Class

An ES6 JavaScript class provides constructor, method, inheritance, and `super` syntax around JavaScript's existing prototype-based object model. Calling `new` creates an instance, and `extends` lets a subclass inherit and selectively augment superclass behavior.

The syntax resembles classical object orientation, but it does not replace prototypal inheritance. React's historical class-component model extends `React.Component`, which supplies component behavior while the subclass defines its rendering and state-related methods.
