# R Function Call

An R function call applies a named operation to supplied arguments and returns a value, possibly with side effects such as drawing a plot. Named arguments can make intent clearer when a function accepts many options.

Calls can be nested, assigned to objects, or connected with an [[R Pipe Operator]], making them the basic compositional unit of R analysis.
