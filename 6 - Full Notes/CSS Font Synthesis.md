# CSS Font Synthesis

Font synthesis occurs when the user agent creates a bold or italic appearance because the requested family does not contain a matching face. Synthetic forms can preserve a stylistic distinction but may not have the quality of a font designed for that weight or style.

The `font-synthesis` property controls whether weight or style synthesis is allowed. It therefore changes the fallback behavior of [[CSS Font Matching]] rather than selecting a family by itself.
