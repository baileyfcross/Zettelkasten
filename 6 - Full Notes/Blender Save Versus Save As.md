# Blender Save Versus Save As

Save writes the current Blender project back to its existing `.blend` file, while Save As writes the current state under a chosen path or name and leaves the earlier file intact. Both preserve the project's scene data, models, materials, animation, and other stored Blender state.

Save As is therefore a simple branching mechanism before a risky revision or destructive experiment. It does not replace regular backups, but it prevents a revised pose, imported asset, or scene arrangement from silently becoming the only remaining copy of the earlier work.
