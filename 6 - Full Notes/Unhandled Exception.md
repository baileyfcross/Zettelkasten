# Unhandled Exception

An unhandled exception is a runtime exception that reaches the top of an execution path without a matching handler. In a simple application, the runtime normally terminates the process and reports the exception and call stack.

The possibility of termination makes exception boundaries part of application design. Code should handle failures where it can preserve a valid state or add meaningful context, while allowing unrecoverable conditions to remain visible.
