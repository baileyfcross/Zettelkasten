# Data Type and Permissible Operations

An attribute's measurement type constrains sensible arithmetic and comparison. Nominal values distinguish categories without order; ordinal values have an order but not necessarily equal distances; numeric interval values admit meaningful differences, while ratio values also have a meaningful zero and ratios.

Encoding categories as numbers does not make their numeric distances real. A model or transformation that averages arbitrary category codes can introduce relationships absent from the domain. Choosing a data representation therefore includes checking what operations the values actually justify.
