# OSI Model

The Open Systems Interconnection model divides network communication into seven conceptual layers: application, presentation, session, transport, network, data link, and physical. Each layer offers a defined service to the layer above and delegates lower-level work to the layer below.

The model separates responsibilities even when a practical protocol does not mirror every boundary exactly. It provides a vocabulary for locating where formatting, session control, delivery, routing, framing, or signal transmission belongs.
