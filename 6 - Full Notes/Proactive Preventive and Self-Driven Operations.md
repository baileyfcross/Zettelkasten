# Proactive Preventive and Self-Driven Operations

Proactive operation responds to an early signal before a failure, such as adding memory when consumption approaches exhaustion. Preventive operation addresses the underlying cause, such as correcting the leak that makes memory grow. A self-driven system automates detection, response, investigation, and a proposed corrective change.

These stages differ in depth, not merely speed. Scaling can avoid an outage without preventing recurrence, while an automated root-cause analysis and reviewed pull request can change the system that produced the risk.
