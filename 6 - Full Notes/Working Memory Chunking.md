# Working Memory Chunking

Working memory chunking groups several elements into one meaningful unit, allowing limited [[Working Memory]] to handle more structured information. Familiar genre conventions, symbols, and action patterns can each become a chunk stored through experience.

Designers can support chunking by organizing related information, using established meanings consistently, teaching actions in context, and repeating them until they become stable knowledge. An arbitrary list remains many items; a well-formed schema can be manipulated as one.
