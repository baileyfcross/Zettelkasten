# Fuzzy Membership Function

A fuzzy membership function maps an input value or observation to a degree of membership in a fuzzy set or cluster. Its shape operationalizes what labels such as low, close, or similar mean.

Membership design is central because different functions produce different fuzzy partitions. Common forms include triangular, trapezoidal, Gaussian, and sigmoidal curves.
