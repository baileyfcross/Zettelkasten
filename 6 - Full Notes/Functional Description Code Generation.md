# Functional Description Code Generation

Functional description code generation turns a statement of desired behavior into an implementation, such as natural-language-to-SQL or event-rule generation. It attempts to bridge business expression and formal program syntax.

The bridge is difficult because requirements are often more abstract than functions, and information is lost while moving from need to behavior to code. Precise constraints, schema context, examples, and executable acceptance tests reduce the gap.
