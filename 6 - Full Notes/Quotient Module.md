# Quotient Module

For a [[Submodule]] N of M, the quotient module M/N consists of additive cosets m + N, with scalar multiplication defined by r(m+N) = rm+N.

The natural map M → M/N is a surjective [[Module Homomorphism]] with kernel N. A [[Short Exact Sequence]] 0 → N → M → M/N → 0 records this relationship.
