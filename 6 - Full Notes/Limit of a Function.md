# Limit of a Function

The statement $\lim_{x\to a}f(x)=L$ describes the value approached by $f(x)$ as $x$ approaches $a$. It depends on nearby inputs rather than necessarily on $f(a)$, so a limit can exist when the function is missing or differently defined at the point. Agreement of the two [[One-Sided Limit]]s is required.
