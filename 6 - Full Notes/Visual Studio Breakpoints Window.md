# Visual Studio Breakpoints Window

The Visual Studio Breakpoints window manages the breakpoints defined across a solution. It lists their locations, enabled state, labels, conditions, filters, and actions so debugging stops can be reviewed as a set rather than hunted down file by file.

Conditional breakpoints pause only when an expression matches, and breakpoint actions can record information without always stopping. Import, export, search, enable, and delete operations make a repeatable debugging setup possible.
