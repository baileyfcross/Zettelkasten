# Immortalized Cell Line

An immortalized cell line can proliferate indefinitely under suitable laboratory conditions because it acquired or was given changes that bypass normal limits on division. It supplies a consistent and expandable experimental material.

The same changes that make the line convenient can distinguish it from native donor tissue, so results must be interpreted within the model's limitations.
