# Three-Node Bar Element

A three-node bar element adds a midside node between two end nodes and uses quadratic displacement interpolation. Each node still carries one axial translational degree of freedom.

The higher-order field can represent distributed loading and linearly varying cross section more accurately than one linear element. A coarser mesh of quadratic elements may therefore match the accuracy of many two-node elements.
