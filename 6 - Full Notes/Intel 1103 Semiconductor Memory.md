# Intel 1103 Semiconductor Memory

Intel’s 1103 was a semiconductor memory chip introduced in 1970 that stored roughly one thousand bits. Its density, electrical compatibility, and mass production made it competitive with hand-assembled magnetic core memory.

The chip’s success established memory as a high-volume integrated-circuit market. Regular repeated cells avoided the narrow demand faced by highly specialized logic designs.
