# Git Merge

`git merge` integrates the history of another branch into the currently checked-out branch. Git either advances the current reference when no divergence exists or creates a merge result that joins the parent histories.

When both lines changed incompatible portions of the same content, the developer must resolve conflicts before completing the merge. The operation should be run from the branch intended to receive the other branch's work.
