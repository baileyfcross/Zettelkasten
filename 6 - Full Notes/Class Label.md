# Class Label

A class label is a value representing the category to which an observation belongs. In supervised classification, the [[Training Dataset]] pairs every input example with the label the model is expected to predict.

Labels may be encoded as numbers even when they stand for human-readable classes. An image-recognition system can associate ten output positions with ten clothing categories, and a [[Softmax Function]] assigns a probability to each labeled possibility.
