# Light Clock

A light clock is an ideal clock in which one tick is defined by a light pulse traveling between mirrors. An observer at rest with the clock sees the pulse cross only the mirror separation, while an observer who sees the clock move also sees the pulse travel diagonally through space.

Both observers must measure the same light speed. Euclidean geometry applied to the longer diagonal path therefore requires more coordinate time between ticks for the moving clock. The resulting relation is $\Delta t=\gamma\Delta\tau$, the formula for [[Time Dilation]].

The model is valuable because it ties clock rate to a reproducible physical process rather than to a mechanical peculiarity of a particular clock. Any process that functions as a clock must show the same relativistic rate change if the laws of physics are invariant between inertial frames.
