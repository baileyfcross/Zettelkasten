# CSS Grid Lines Tracks Cells and Areas

Grid lines divide a grid into row and column tracks. The intersection of one row track and one column track is a cell, while a grid area is a rectangular collection of one or more cells.

Lines can be numbered or named, and areas can receive names through the grid template. Placement addresses the bounding lines or an area name rather than inserting content into a separate table-like structure.
