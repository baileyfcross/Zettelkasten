# Stride PBR and Shader Pipeline

Stride combines physically based materials, light probes, post-processing, multithreading, and modern graphics APIs in its rendering stack. Customizable shaders and lower-level APIs allow the pipeline to move beyond built-in material behavior.

An imported Blender asset must map its textures and material parameters into that real-time representation. Similar PBR terminology does not guarantee identical appearance, so lighting, color space, normals, and roughness should be checked in the target renderer.
