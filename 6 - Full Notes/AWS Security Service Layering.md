# AWS Security Service Layering

AWS security service layering assigns complementary controls to different stages of prevention, detection, investigation, and response. IAM restricts actions, KMS protects key use, WAF filters web requests, Inspector finds vulnerabilities, GuardDuty detects suspicious behavior, and Detective helps investigate relationships.

No service covers every failure mode. Layering reduces reliance on one control and creates multiple opportunities to stop or notice an attack, but only when findings have owners, logs are protected, alerts are actionable, and response procedures connect the layers.
