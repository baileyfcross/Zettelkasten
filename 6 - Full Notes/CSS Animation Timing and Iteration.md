# CSS Animation Timing and Iteration

CSS animation timing combines a duration, delay, timing function, iteration count, and direction. An animation can run once, repeat a number of times or indefinitely, and alternate direction between successive iterations.

Timing functions may apply to the entire animation or be changed at individual keyframes for the following interval. Negative delays begin as though part of the animation had already elapsed.
