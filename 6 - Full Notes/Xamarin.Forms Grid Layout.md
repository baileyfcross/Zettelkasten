# Xamarin.Forms Grid Layout

A Xamarin.Forms `Grid` places controls into rows and columns whose sizes can be fixed, proportional, or based on content. A child can occupy one cell or span several, making the layout suitable for forms and interfaces whose elements must align across two dimensions.

The row and column definitions describe relationships rather than absolute screen coordinates, allowing the same visual structure to adapt to different mobile dimensions.
