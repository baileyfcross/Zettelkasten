# NoSQL Database

A NoSQL database uses a data model other than the traditional relational table-and-join model. The category includes document, key-value, graph, and other stores whose structures and scaling choices fit different access patterns.

Cosmos DB supplies a [[Document Database]] in the project, while its API compatibility lets the application use MongoDB conventions. Choosing NoSQL is therefore not merely choosing the cloud; it is choosing storage and query semantics that should match the application's data relationships.
