# Browser Driver

A browser driver is the browser-specific intermediary that accepts Selenium commands and executes them in a browser. ChromeDriver, GeckoDriver, EdgeDriver, and SafariDriver connect the general WebDriver API to their respective browser implementations.

A compatible driver must be available before a [[WebDriver Browser Session]] can begin. The driver interprets [[Selenium Command Transport|transported commands]], controls the browser, and returns results to the client binding.
