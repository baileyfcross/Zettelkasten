# FPGA Genome Sequencing

FPGA genome sequencing implements selected matching or alignment kernels as configurable digital circuits. Parallel comparators, pipelines, local storage, and custom-width data paths can improve throughput with low active power.

The host processor still loads data, controls the design, and handles flexible workflow logic. [[Processor System and Programmable Logic Partitioning]] and [[Accelerator IP Core Integration]] turn the kernel into a usable system.
