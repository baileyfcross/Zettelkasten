# COMSOL Result Tables and Export

COMSOL tables store evaluated values for inspection, plotting, or comparison across times and parameter cases. Export nodes write numerical data, images, animations, meshes, or other result products for use outside the model.

An export should retain units, parameter identifiers, and enough context to reconstruct its source. Treating a table as an explicit result artifact makes [[Thermal Model Verification and Sensitivity|sensitivity comparisons]] reproducible and reduces reliance on values read approximately from plots.
