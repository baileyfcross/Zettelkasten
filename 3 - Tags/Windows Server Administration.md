# Windows Server Administration

Parent topic: [[Systems Foundations]]

Windows Server administration joins operating-system deployment, directory identity, network infrastructure, shared storage, security, virtualization, and remote application delivery into one operating discipline. The eight topics below follow the path from establishing manageable hosts to providing dependable services and diagnosing them under change.

## Overview Chapter

[[Windows Server Deployment and Administration]] establishes the platform on which every other service depends. An administrator first selects an edition and installation option that fit the workload, licensing model, and desired management surface. Desktop Experience provides a local graphical shell, while Server Core reduces installed components and encourages remote administration. Roles and features give an otherwise general-purpose server its function. Server Manager, Windows Admin Center, PowerShell remoting, and Azure Arc then provide progressively broader ways to manage one host, groups of hosts, and hybrid resources. Repeatable Sysprep images and supported in-place upgrades help standardize the fleet. Performance baselines, data collector sets, counters, alerts, and event logs turn that fleet into an observable system, while Azure Arc-assisted hotpatching applies eligible updates with less immediate reboot disruption and still demands testing and post-patch validation.

Identity and policy are the organizing layer in [[Active Directory and Group Policy Administration]]. Active Directory Domain Services stores identities and configuration in a replicated directory hosted by domain controllers. Forests, trees, domains, trusts, sites, and operations-master roles define the directory's security, naming, replication, and administrative boundaries. Windows Server 2025's 32 KB database pages expand large-object capacity and reduce fragmentation, but their forest-level adoption calls for backups, compatibility checks, and controlled validation. Schema change management protects the shared directory model through impact analysis, lab testing, restricted authority, and version history. Object-level auditing, diagnostic tools, the Recycle Bin, and granular recovery then provide a narrower repair path than restoring the entire directory. Group Policy connects identity to configuration through scoped, predictably processed objects and a shared Central Store.

[[Windows DNS and DHCP Services]] supplies the naming and addressing that make directory and application services reachable. Host and alias records translate service names, while mail and authentication records publish routing and validation data. Forward, reverse, secondary, stub, split-brain, and Active Directory-integrated zones serve different delegation, replication, and internal-versus-external naming needs. DNS over HTTPS protects resolver traffic in appropriate client scenarios. DHCP scopes, options, exclusions, and reservations allocate IPv4 configuration deliberately; two-server failover preserves leases and address service when one partner is unavailable. IP Address Management gives administrators a central view of DNS and DHCP infrastructure.

Those services operate across the paths described in [[Windows Server Networking and Remote Access]]. Private IPv4 subnets and IPv6 prefixes define local reachability, while route tables and gateways determine where off-subnet traffic goes. Windows diagnostic tools test each layer from local configuration through name resolution and transport. NIC teaming protects or aggregates physical links, and software-defined networking moves network policy into a virtualized control plane. Routing and Remote Access supplies routing and VPN services. Always On VPN and DirectAccess automate remote connectivity in different ways, while Web Application Proxy publishes selected web applications without extending an entire internal network to the client.

Data availability is the concern of [[Windows File Services and High Availability]]. SMB shares expose files, but effective access is the intersection of share permissions, NTFS permissions, inheritance, and group membership. DFS namespaces give users a stable logical path, and DFS Replication maintains copies where its replication model fits. SMB over QUIC carries certificate-authenticated SMB across untrusted networks without a conventional VPN. Data deduplication replaces repeated blocks with references to one stored copy, while storage tiering moves hot and cold data between faster and cheaper media. Availability mechanisms address different failure modes: Network Load Balancing distributes stateless traffic, failover clustering moves stateful workloads among validated nodes, Storage Replica duplicates volumes, and Storage Spaces Direct pools local disks across cluster members.

[[Windows Server Security and PKI]] treats security as layered trust rather than a single perimeter. A public key infrastructure defines certificate authorities, templates, enrollment, signing requests, certificate chains, and private-key handling. Active Directory Certificate Services integrates those processes with domain identities and policy. Windows Defender Firewall adds host-level filtering even inside a protected network, and Defender Antivirus combines real-time endpoint scanning with behavioral and cloud-assisted detection. Audit policy decides which successful and failed activities become durable evidence. Security baselines make approved settings explicit, while drift monitoring exposes unauthorized or accidental departures. BitLocker protects volumes with TPM-backed key release, LAPS rotates local administrator credentials, Defender for Identity observes directory-related threats, and Just Enough Administration constrains privileged PowerShell activity to approved commands and endpoints.

Compute isolation is covered by [[Windows Server Virtualization and Containers]]. Windows containers package an application with layered operating-system components and can use lightweight process isolation or stronger Hyper-V isolation. Base images determine the container's footprint and compatibility, while HostProcess containers provide controlled access to the host for cluster-management workloads. Hyper-V supplies the broader virtual-machine boundary. Its role, virtual switches, Generation 2 machine model, checkpoints, and shielded-VM architecture define how virtual servers receive hardware, networking, recovery points, and protection from an untrusted fabric administrator. Dynamic Memory varies guest RAM within explicit bounds, nested virtualization exposes hypervisor support to a guest for lab-style inner machines, and VHD versus VHDX selects between legacy compatibility and greater virtual-disk scale and resilience.

Finally, [[Windows Remote Desktop Services]] turns centralized Windows applications and desktops into multi-user services. Session Hosts run user sessions; Connection Broker distributes and reconnects them; Licensing, Web Access, and Gateway provide authorization, discovery, and protected external entry. Collections group hosts and publish resources. Drain mode and application install mode make maintenance and software changes safer, FSLogix profile containers preserve a consistent user environment, and RemoteApp presents individual applications without exposing a complete remote desktop. Together, these components show the recurring Windows Server pattern: separate responsibilities, make state explicit, and build redundant paths around services that users depend on.
