# Susceptible-Infected-Recovered Model

The susceptible-infected-recovered model divides nodes into those not yet reached, those actively transmitting, and those informed but no longer transmitting. Infection and recovery probabilities govern movement between the three states.

For social information, an infected user is ready to pass the message and a recovered user has stopped forwarding it. The recovery state prevents a node from becoming active again in the basic model.
