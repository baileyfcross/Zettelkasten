# Graph Path

A graph path is a sequence of [[Edge|edges]] that connects a sequence of [[Vertex|vertices]]. It describes a possible route through the relationships represented by a [[Graph]].

Different questions place different requirements on the route. An [[Eulerian Path]] visits every edge exactly once, while a [[Shortest Path Problem]] asks for the route with the smallest [[Graph Path Length]].
