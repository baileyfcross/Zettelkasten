# Azure Application Setting

An Azure application setting is a named configuration value supplied by App Service to the hosted process. It lets deployment provide environment-specific URLs, feature values, and other configuration without rebuilding source code.

The setting name must match what the application configuration reads. Slot-specific settings can remain attached to staging or production when application versions are swapped between them.
