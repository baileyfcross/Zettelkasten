# Web API

A Web API is a programmatic set of server-side endpoints exposed through HTTP or HTTPS. Each endpoint accepts a defined request and returns a response represented in a format such as JSON.

In ASP.NET Core, [[MVC Controller|controller]] actions commonly implement these endpoints. An Angular [[Single-Page Application]] calls them to obtain or modify data without requiring the server to render the client interface.
