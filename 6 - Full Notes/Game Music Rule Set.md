# Game Music Rule Set

A game music rule set defines the choices a generative or adaptive system may make. Rules can govern scales, chord progressions, rhythmic patterns, melodic motion, counterpoint, instrumentation, density, and the relationship between a [[Game Music Control Input]] and a musical outcome.

Rules turn a composer's style into executable boundaries rather than a single rendered performance. They must be restrictive enough to keep combinations coherent and permissive enough to produce useful variation. Because players can expose unusual paths through the system, the rule set also becomes a test surface: edge cases must be heard, not merely reasoned about on paper.
