# Excel Text Extraction Functions

Excel LEFT, RIGHT, and MID functions extract characters from a text value. LEFT counts from the beginning, RIGHT counts from the end, and MID starts at a specified position and returns a specified number of characters. LEN reports the total character count and can help calculate those positions.

These functions are most reliable when source text follows a consistent structure. If separators or field lengths vary, a fixed position can cut the wrong substring. Combining extraction with [[Excel Text Search Functions]] lets a formula locate a delimiter first, while cleanup functions can remove invisible characters that otherwise distort length and position calculations.
