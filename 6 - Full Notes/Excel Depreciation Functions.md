# Excel Depreciation Functions

Excel financial functions model several depreciation methods. SLN allocates an asset's depreciable amount evenly across its useful life. SYD accelerates depreciation using sum-of-years digits, and DDB applies a declining-balance method that usually recognizes more depreciation in earlier periods.

Each method requires assumptions such as initial cost, salvage value, useful life, and the period being calculated. Those assumptions should use consistent units and match the accounting method intended by the model. Different methods redistribute expense through time rather than changing the asset's original cost, so comparisons should examine the complete schedule instead of one isolated period.
