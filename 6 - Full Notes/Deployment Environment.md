# Deployment Environment

A deployment environment is a named operating context with its own configuration, infrastructure, diagnostics, and security expectations. Development, staging, and production environments let the same application select settings appropriate to different parts of delivery.

ASP.NET Core can load environment-specific configuration files and behavior. The environment name should be set by the host rather than embedded into the application source.
