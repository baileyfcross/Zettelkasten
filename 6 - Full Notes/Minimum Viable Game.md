# Minimum Viable Game

A minimum viable game is the smallest combination of features, content, and constraints needed for a successful launch. It defines the essential player value and commercial threshold against which lower-value scope can be traded.

The MVG is not a low-quality prototype. It must satisfy its intended release conditions, but it excludes additions that do not determine viability and can be delivered later.
