# Hybrid Recommender System

A hybrid recommender system combines collaborative and content-based information so one approach can compensate for weaknesses in the other. Item features can support new or sparsely rated items, while collective behavior can reveal preferences not obvious from content alone.

The combination may occur through blended scores, staged models, or shared representations. Evaluation must show that added complexity improves useful recommendations rather than only fitting historical interactions.
