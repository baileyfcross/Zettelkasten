# Cloud Federation

Cloud federation is a composition of services supplied by disparate clouds, commonly across provider boundaries. The resulting service can mix an organization's own cloud cells with third-party cells or can be assembled entirely from external providers.

Federation can add capacity, augment a service rapidly, balance work, or provide failure safety. It relies on [[Cloud Service Interoperability]] because the components must exchange data and control despite being owned and operated separately.
