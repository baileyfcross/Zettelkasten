# Network Agent Use-Case Fit Scorecard

A network agent use-case fit scorecard tests whether agentic reasoning is justified before implementation begins. Strong signals include a task that combines several context sources, changes its next step according to evidence, can begin read-only, produces outputs that can be validated, exposes its evidence to engineers, and has a named owner.

A fixed single-command workflow, an unavoidable first-step write action, free-form judgment with no checks, a black-box answer, or absent ownership is a signal to use conventional automation, narrow the scope, or redesign the idea. The scorecard protects against adding a model where deterministic tooling is already the safer solution.
