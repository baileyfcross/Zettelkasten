# SQL Injection

SQL injection occurs when untrusted input is interpreted as part of a database command rather than as a value. A flexible sorting or filtering endpoint can create this vulnerability if it inserts unchecked client expressions into a query.

The application should constrain selectable property names to known model fields and use parameterized values. Hiding the input in an Angular interface is insufficient because a client can construct its own [[HTTP Request]].
