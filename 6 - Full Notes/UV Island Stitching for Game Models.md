# UV Island Stitching for Game Models

UV stitching joins compatible perimeter edges from separate islands and previews how the islands will connect before the operation is accepted. Repeated stitches can consolidate an overly fragmented automatic unwrap into fewer, larger islands.

Reducing seams can limit duplicated boundary vertices in some real-time pipelines, but a single giant island is not automatically better. Stretch, packing efficiency, texture orientation, and concealment of visible seams must remain balanced.
