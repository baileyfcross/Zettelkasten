# Excel LOOKUP Function

Excel LOOKUP searches a one-row or one-column vector for a value and returns a corresponding item from a result vector, or works with an array form. Its behavior is oriented toward approximate matching rather than a strict exact-match search.

The lookup values must be ordered correctly for reliable results, and a missing exact value may return the nearest qualifying lower boundary. This makes LOOKUP useful for bands and thresholds but risky when identifiers require exact equality. The lookup and result vectors should have corresponding positions and be documented as an approximate mapping.
