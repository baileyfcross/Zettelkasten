# Multivariable Function

A multivariable function maps a subset of $\mathbb{R}^n$ into $\mathbb{R}^m$. When $m=1$ it is a [[Scalar Field]], and when it has several output components it is a [[Vector Field]].

Its graph lies in $\mathbb{R}^{n+m}$, so only low-dimensional cases can be drawn directly. Scalar-valued functions can instead be studied through [[Level Curve|level curves]] and level surfaces that hold the output constant.
