# Shortest Path Mesh Selection

Shortest-path selection finds a connected route through mesh components between two chosen endpoints. It is useful when the desired selection follows topology but is not a complete edge loop.

The result depends on the mesh's connectivity, so poor or irregular topology can send the path somewhere unexpected. The command is most effective when endpoints and the intervening edge structure express the route the artist actually intends.
