# Space-Time Raster Density Plot

A space-time raster density plot estimates a smooth distribution of cell values for each selected temporal group. It can make multiple modes and gradual distribution changes easier to compare than a binned histogram. Bandwidth controls smoothness and can create or erase apparent structure. Since the plot aggregates across cells, it should be read alongside maps that preserve the geography of the [[Space-Time Raster]].
