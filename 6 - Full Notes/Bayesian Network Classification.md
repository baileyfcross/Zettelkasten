# Bayesian Network Classification

Bayesian network classification represents variables with a directed acyclic graph whose edges specify conditional dependencies. The graph factorizes the joint probability into local conditional distributions.

A class node can influence features directly or participate in a richer dependency structure than naive Bayes permits. Classification uses probabilistic inference to compare posterior class probabilities after observed evidence is entered into the network.
