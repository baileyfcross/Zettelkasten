# Object-Oriented Design

Object-oriented design turns the conceptual model from [[Object-Oriented Analysis]] into an implementable system of classes, interfaces, attributes, methods, and collaborations. It decides how responsibilities are assigned and whether relationships use inheritance, composition, aggregation, or delegation.

The design model explains how the system will satisfy its requirements, not only which domain concepts exist. Class diagrams and interface descriptions make those decisions reviewable before code fixes them into a particular implementation.
