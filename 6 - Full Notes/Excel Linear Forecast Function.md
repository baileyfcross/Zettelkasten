# Excel Linear Forecast Function

Excel FORECAST.LINEAR estimates a dependent value for a chosen independent value by fitting a straight-line relationship to known x and y observations. It extends the linear pattern implied by the historical pairs and is useful when a roughly constant rate of change is a reasonable approximation.

The calculation does not prove that the relationship will continue or that x causes y. Extrapolation beyond observed values is especially sensitive to structural changes and outliers. A forecast should therefore be paired with a plot, domain judgment, and an examination of association such as [[Excel CORREL Function]] rather than treated as certainty.
