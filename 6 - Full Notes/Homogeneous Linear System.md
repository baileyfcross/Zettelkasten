# Homogeneous Linear System

A homogeneous linear system has the form $Ax=0$. It always has the [[Trivial Solution]] $x=0$.

If the coefficient matrix lacks full column rank, the system also has infinitely many nontrivial solutions. The null space formed by all solutions is a [[Vector Subspace]].
