# Helidon Metrics

Helidon Metrics is Helidon MP's compatible implementation of the MicroProfile Metrics specification. A MicroProfile application receives standard metric endpoints automatically and can add application measurements through annotations, the programmatic Metrics API, or built-in REST-request instrumentation.

Helidon maintains annotated metrics when their containing beans are managed through Jakarta CDI. This connects the declarative resource model to a registry and HTTP exposition layer without requiring each endpoint to manually format its measurements.
