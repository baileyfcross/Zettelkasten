# Large Margin Nearest Neighbor

Large margin nearest neighbor learning pulls designated same-class target neighbors together while penalizing different-class impostors that enter their neighborhoods. The learned Mahalanobis matrix is optimized for subsequent nearest-neighbor classification.

This combines a compactness objective with margin constraints around local neighborhoods. It is more targeted than maximizing global class separation because it concentrates on the pairs that can actually change a local prediction.
