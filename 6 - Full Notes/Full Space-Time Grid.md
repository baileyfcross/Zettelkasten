# Full Space-Time Grid

A full space-time grid contains an observation slot for every combination of a defined set of spatial features and observation times. If there are $n$ locations and $m$ times, its data table has $n m$ rows even when some values are missing. The `spacetime` package represents this layout with STF or [[STFDF Object|STFDF]], enabling systematic spatial slices, temporal series, and space-time plots.
