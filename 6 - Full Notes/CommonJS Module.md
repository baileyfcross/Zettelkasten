# CommonJS Module

A CommonJS module publishes JavaScript values through `module.exports` and consumes another module with `require`. It is the module pattern described by the source as supported across Node.js versions of its period.

CommonJS and [[ES6 Module|ES6 modules]] solve the same reuse problem with different boundaries and syntax. Build tools can translate or bundle both forms, but code must still distinguish the environment's native module convention from the syntax accepted only after a build step.
