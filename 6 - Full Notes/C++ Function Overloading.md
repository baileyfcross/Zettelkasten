# C++ Function Overloading

C++ function overloading gives several functions the same name while distinguishing them by their parameter types or arity. The compiler selects the matching implementation from the arguments at the call site.

Overloading lets a mathematical operation retain one conceptual name across representations. Matrix multiplication, scalar multiplication, and matrix-vector multiplication can therefore share an operator name while performing type-appropriate work; this is distinct from runtime polymorphism through virtual functions.
