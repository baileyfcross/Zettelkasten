# Java Long-Term Support Release

A Java long-term support release is a feature release selected for an extended support period, making it a more stable planning point for production systems than adopting every six-month release. The book describes Java 17, 21, and 25 as successive LTS milestones and notes that the LTS interval was shortened from three years to two.

Organizations often prefer LTS-to-LTS movement because security updates and maintenance horizons are easier to plan. That preference does not remove migration work: libraries, removed APIs, build tools, and customer constraints still have to be checked through a [[Java Migration Compatibility Audit]].
