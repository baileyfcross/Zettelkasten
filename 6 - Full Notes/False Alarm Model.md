# False Alarm Model

A false alarm model represents the possibility that a sensor reports a detection even though the target or event is absent. A Boolean hidden variable can select between the ordinary sensor distribution and a false-alarm distribution.

Inference then considers both explanations instead of forcing every positive reading to be caused by the searched state. The prior probability and observation pattern determine how much support is assigned to the false-alarm branch.
