# Classification Likelihood

Classification likelihood evaluates a model while treating component assignments as part of the clustering solution. It rewards parameter values and memberships that jointly explain the observations.

This differs from mixture likelihood, which integrates over uncertain component membership. The choice affects how strongly the procedure favors crisp assignments.
