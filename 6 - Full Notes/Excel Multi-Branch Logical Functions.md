# Excel Multi-Branch Logical Functions

Excel IFS and SWITCH functions organize decisions with more than two outcomes. IFS evaluates condition-result pairs in order and returns the result associated with the first true condition. SWITCH compares one expression with a list of possible values and returns the result attached to the first match.

IFS suits ordered tests such as grading thresholds, while SWITCH suits exact categories such as codes or weekday numbers. Both can replace deeply nested [[Excel IF Function]] formulas, but their availability depends on the Excel version. A final catch-all result prevents unmatched inputs from producing an unexplained error and makes the model's fallback behavior explicit.
