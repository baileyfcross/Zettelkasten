# Armory3D Blender-Integrated Game Development

Armory3D integrates game development into Blender so scenes and assets can move toward a real-time build without repeated manual export between separate applications. Its stack uses Kha for multimedia and Haxe for cross-platform development.

The unified workflow reduces transfer friction but does not eliminate the boundary between authoring and runtime behavior. Artists still need to verify supported nodes, real-time budgets, interaction logic, animation, and platform output.
