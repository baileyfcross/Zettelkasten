# Program

A program is a set of instructions written in a [[Programming Language]] that describes a computational process. A program can implement one or more [[Algorithm]]s by translating their steps and control structures into executable notation.

Programs and algorithms are not identical. An algorithm must terminate, while a program may intentionally continue running as long as its computer remains operational. A continuously running service is therefore a computational process even when the whole program is not itself one terminating algorithm.
