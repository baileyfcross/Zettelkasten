# CSS Flex Item Ordering

The `order` property assigns flex items to ordinal groups that are laid out before or after the default group. Items with the same order value retain their source order within that group.

This changes visual arrangement but not document, focus, or speech order. The source warns that screen readers should follow the source, so order should not be used to repair meaningful sequencing that belongs in the markup.
