# Multilayer Network Aggregation

Multilayer network aggregation combines several layers into a simpler graph, often by merging corresponding nodes and treating any layer edge as a connection. The result reduces computational and visual complexity.

Aggregation can change degrees, paths, communities, and dynamic processes because it erases edge types and layer constraints. It should therefore be justified by the question rather than used as a neutral preprocessing step.
