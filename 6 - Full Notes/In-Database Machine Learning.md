# In-Database Machine Learning

In-database machine learning runs analytical functions and model training near the records stored in a database, often through SQL-accessible capabilities. The book's guiding principle is to move algorithms to the data rather than repeatedly exporting data to a separate analysis server.

Avoiding export can shorten preparation and scoring workflows, reduce format conversion, preserve database access controls, and ease deployment of results into applications. It does not remove the need for feature design, evaluation, or a business process that acts on the predictions.
