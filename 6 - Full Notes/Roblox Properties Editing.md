# Roblox Properties Editing

The Properties window exposes editable attributes of the currently selected Roblox instance. Different classes reveal different settings: a part has size, position, material, color, reflectance, transparency, and collision behavior, while a light, sound, or particle emitter exposes properties specific to that effect.

Property editing turns a generic instance into a configured game object without requiring every value to be assigned in code. Scripts can later read or change the same properties, so editor-authored values provide the starting state and code supplies runtime behavior. This division is especially useful for [[Roblox Part Assembly]] and [[Roblox World Lighting]].
