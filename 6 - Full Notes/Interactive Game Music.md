# Interactive Game Music

Interactive game music is a score whose musical behavior changes in response to information from the running game. Unlike a fixed linear track, its duration, form, density, instrumentation, harmony, or other properties can vary because a player acts or the game state changes.

The book distinguishes direct interaction from adaptation: a player may explicitly manipulate music, while an adaptive score reacts indirectly to conditions such as danger or location. In both cases, a [[Game Music Control Input]] connects game information to a defined musical result, making the score part of the game system rather than an independent recording.
