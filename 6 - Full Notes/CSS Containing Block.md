# CSS Containing Block

A containing block is the reference rectangle used to calculate the position and dimensions of a descendant box. Percentage widths, offsets, and some heights resolve against dimensions supplied by this block.

The element that establishes the containing block depends on the formatting and positioning scheme. In particular, [[CSS Absolute Positioning]] searches for an appropriate positioned ancestor instead of necessarily using the nearest ordinary parent.
