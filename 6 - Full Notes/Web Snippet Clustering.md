# Web Snippet Clustering

Web snippet clustering organizes short search-result descriptions into coherent topical groups. The method must work with sparse text, duplicated language, noisy markup, and ambiguous queries while producing labels quickly enough for interactive use.

Phrase extraction, background knowledge, and overlap-tolerant clustering help distinguish different senses of a query. Good labels are part of the result because users need to understand each cluster before choosing which results to inspect.
