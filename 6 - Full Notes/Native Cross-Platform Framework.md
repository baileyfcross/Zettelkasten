# Native Cross-Platform Framework

A native cross-platform framework lets several mobile targets share a programming language and application framework while still producing applications that use native platform APIs and controls. The shared layer reduces repeated business and interface code without requiring every platform difference to disappear.

Each target still has an application head or harness for startup, packaging, permissions, and native integrations. Xamarin and Xamarin.Forms apply this model with shared .NET code and platform-specific projects.
