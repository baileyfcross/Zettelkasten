# AWS CloudTrail Event

An AWS CloudTrail event records an action taken through the AWS API, console, command-line tools, or an AWS service. The record can identify the principal, requested operation, time, source, target resource, and response details.

Events answer governance questions such as who changed a security group or deleted a resource. The event history provides a limited recent view, while an [[AWS CloudTrail Trail]] delivers an ongoing record to durable storage for longer retention and analysis.
