# Personal Context

Personal context is information about the user that can help an assistant interpret or rank possible actions. It may include preferences, location, contacts, calendar state, past choices, or device settings.

A [[Personal Virtual Assistant]] can use this context in [[Candidate Hypothesis Ranking]] and response generation. Because it can reveal sensitive behavior, access and retention must match the user's privacy expectations.
