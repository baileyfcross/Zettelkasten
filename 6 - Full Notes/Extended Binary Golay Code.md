# Extended Binary Golay Code

The extended binary Golay code is a binary linear code of length 24, dimension 12, and minimum distance eight. A standard construction combines a 12-dimensional identity block with a specially structured binary matrix.

The code is self-dual, so its generator and parity-check descriptions exchange roles. Its large minimum distance supplies substantial error separation while retaining half of the coordinates for independent message information.
