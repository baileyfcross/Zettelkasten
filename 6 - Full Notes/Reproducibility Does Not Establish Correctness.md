# Reproducibility Does Not Establish Correctness

A computation can be perfectly reproducible and still be scientifically wrong. Reexecuting the same code on the same data may faithfully repeat a programming error, a biased design, an unsuitable model, or a mistaken interpretation.

Reproducibility instead makes the reasoning inspectable. By exposing the [[Research Compendium|narrative, code, and data]], it lets others locate errors more quickly, test alternatives, and extend the work. It is evidence about the recoverability of a result, not a substitute for validation, criticism, or [[Replication and Computational Reproducibility|independent replication]].
