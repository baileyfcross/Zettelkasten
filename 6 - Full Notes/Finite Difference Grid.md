# Finite Difference Grid

A finite difference grid divides a continuous region into a network of mesh points. On a rectangular grid, a point $(x,y)=(ih,jk)$ can be indexed as $(i,j)$, where $h$ and $k$ are the coordinate spacings.

The unknown field is represented only at these nodes, and derivatives are replaced by relations among neighboring node values. Boundary values populate the edge nodes while a numerical scheme determines the interior or future-time nodes.
