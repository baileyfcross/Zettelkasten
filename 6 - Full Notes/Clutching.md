# Clutching

Clutching occurs when a manipulation cannot be completed in one motion, forcing the user to release, reposition, and reengage the control before continuing.

A wrench used in a confined space is a physical example. In a [[3D User Interface]], limited device range or an unsuitable control mapping can produce the same repeated interruption during [[Object Positioning]] or [[Object Rotation]].

Clutching is wasted motion that can reduce performance and comfort. A precision grip, motion amplification, or a mapping with a more suitable range can reduce the number of regrasping cycles, though amplification can also reduce fine control.
