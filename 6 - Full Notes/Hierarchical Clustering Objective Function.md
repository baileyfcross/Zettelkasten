# Hierarchical Clustering Objective Function

A hierarchical clustering objective function quantifies the desirability or information loss of a candidate merge or split. Linkage distances and Ward's error criterion are examples.

The algorithm normally makes a greedy local choice at each stage. The hierarchy should therefore be interpreted as the consequence of that objective, not as an objective-free description of the data.
