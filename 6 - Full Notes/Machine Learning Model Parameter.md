# Machine Learning Model Parameter

A machine-learning model parameter is an adjustable value inside a fixed model structure. Fitting chooses parameter values that improve a performance criterion on observed examples; in a linear model, the weights determine the contribution and direction of each input attribute.

Parameters differ from a [[Hyperparameter]], which chooses such things as the model family, complexity, or training configuration outside the ordinary fitting step. Changing parameters selects a member of one model family, whereas changing the structure can alter what relationships the learner is capable of representing.
