# AWS Config Rule

An AWS Config rule evaluates recorded resource configurations against an expected condition. AWS-managed or custom rules can identify resources that do not satisfy requirements such as encryption, approved settings, or required relationships.

Config preserves configuration history and evaluates state, whereas [[AWS CloudTrail Event|CloudTrail events]] record API activity. A noncompliant result is evidence for investigation or remediation, not proof that every aspect of the resource violates a complete security policy.
