# Web Mercator Projection

Web Mercator is the projected coordinate system widely used by tiled online maps. It supports a consistent square tile pyramid and familiar pan-and-zoom behavior, but it increasingly enlarges area toward the poles and is not suitable for accurate global area comparison. Thematic layers commonly require [[Spatial Data Reprojection]] before being placed over Web Mercator tiles. That alignment does not remove the projection's distortions.
