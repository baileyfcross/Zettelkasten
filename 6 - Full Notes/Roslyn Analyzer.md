# Roslyn Analyzer

A Roslyn analyzer inspects C# syntax and semantic information during editing or compilation and emits diagnostics for patterns defined by its rules. Because it participates in the compiler platform, the same concern can appear in the editor and automated build.

Analyzers shorten the delay between introducing a problem and receiving feedback. Rule sets and diagnostic severity should match the project's standards so warnings remain credible rather than becoming ignored noise.
