# R Confidence Interval Plot

An R confidence interval plot places estimates at categorical or numeric positions and draws vertical or horizontal intervals around them. The point and interval communicate effect magnitude and uncertainty together, making the display more informative than bars whose heights show only central values.

The legend or caption should identify the interval level and the quantity estimated. Overlap between two intervals is not a general-purpose significance test, so formal comparisons should use the model's intended contrasts.
