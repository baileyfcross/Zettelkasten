# Set Difference

The set difference A ∖ B contains the elements that belong to A but not to B. In predicate form, A ∖ B = {x | x ∈ A ∧ x ∉ B}.

Unlike [[Union of Sets]] and [[Intersection of Sets]], set difference is not commutative: removing B's elements from A generally produces a different set from removing A's elements from B.
