# CSS Specificity

CSS specificity measures how precisely a selector identifies its subjects. The source represents it as ordered components for inline declarations, IDs, classes and attributes or pseudo-classes, and element names or pseudo-elements.

The components are compared from strongest to weakest rather than treated as one ordinary decimal number. Specificity is consulted only after importance and origin in [[CSS Cascade Weight Ordering]], and ties proceed to [[CSS Source Order Tie-Breaking]].
