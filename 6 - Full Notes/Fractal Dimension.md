# Fractal Dimension

A fractal dimension measures how the detail or occupied set of a geometric object scales as the observation scale changes. It can take a noninteger value, unlike ordinary topological dimension.

One practical estimate counts the number of boxes of side length $\epsilon$ required to cover the set and examines how that count grows as $\epsilon$ decreases. Strange attractors can have fractal dimension because their repeated stretching and folding creates structure across many scales.
