# Data in Process

Data in process is information actively being used by a program or computing device. Processing may require plaintext values in memory, so protections that secure [[Data at Rest]] or [[Data in Transit]] do not automatically cover this state.

Process isolation, memory protection, least privilege, trusted execution, and careful application design reduce exposure while data is active. Considering all [[Data Security States]] prevents storage or transport encryption from creating a false sense of complete protection.
