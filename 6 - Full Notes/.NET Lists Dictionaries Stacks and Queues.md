# .NET Lists Dictionaries Stacks and Queues

A .NET list stores an ordered, resizable sequence; a dictionary associates unique keys with values; a stack removes the most recently added item first; and a queue removes the earliest added item first.

Choosing a collection communicates the operations the program needs. Lists favor indexed sequence work, dictionaries favor lookup by key, stacks model nested or reversible progress, and queues model arrival order. Generic element types keep each structure type-safe.
