# Module Length

The length ℓ(M) of a module is the number of simple factors in a [[Composition Series]], when such a series exists. The value is independent of the chosen composition series.

Length is additive across a [[Short Exact Sequence]]. A module has finite length exactly when it is both Noetherian and [[Artinian Module|Artinian]].
