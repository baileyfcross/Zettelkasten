# Universal Quantifier

The universal quantifier ∀ turns an open statement P(x) into the proposition ∀x P(x), which is true exactly when P(a) is true for every entity a in the domain of discourse.

Negating a universal claim produces an existential counterexample: ¬∀x P(x) is [[Logically Equivalent]] to ∃x ¬P(x). The order of mixed quantifiers matters because “one entity works for all” differs from “each entity has some witness.”
