# Mono Runtime

Mono is the managed runtime foundation used by Xamarin to execute .NET code on mobile platforms. It supplies the runtime and adaptation needed for a shared managed program to call the services of iOS or Android.

The execution strategy is platform-dependent rather than uniform. Xamarin.iOS compiles managed code ahead of time, while Xamarin.Android can package a Mono runtime and compile intermediate-language code as the application executes.
