# Dialogue Tree

A dialogue tree documents a scripted conversation as player choices and corresponding non-player-character responses. Each exchange can lead to another set of options, end the conversation, or trigger a game or story consequence.

The tree makes authored possibilities tractable without requiring unrestricted natural-language understanding. Designers must control branching growth and write options that accurately signal the avatar's intended meaning.
