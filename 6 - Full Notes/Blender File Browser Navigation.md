# Blender File Browser Navigation

The Blender File Browser is an editor for navigating drives, folders, and file paths when opening or saving projects or selecting external assets such as images. Its current directory, filename field, navigation controls, and view modes determine both the target location and how candidates are displayed.

Because the browser often opens at the most recently used location, the visible filename alone is not enough to verify a save. The complete path should be checked before confirming the operation. Thumbnail view can help identify image assets, while browsing inside a `.blend` file exposes appendable datablock categories.
