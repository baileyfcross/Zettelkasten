# Neural Network Storage Acceleration

Neural network storage acceleration performs part of the computation within or close to emerging memory. ReRAM, STT-RAM, phase-change memory, or logic layers beneath stacked memory can reduce transfers across the processor-memory boundary.

Crossbar structures are especially suited to parallel dot products, but analog conversion, device variation, endurance, and training support complicate the design. The architecture must model both arithmetic error and memory behavior rather than treating storage as an ideal compute array.
