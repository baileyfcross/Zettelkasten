# Trainable Single-Photon Probe State

The probe state is the trainable branch of a [[Hong-Ou-Mandel Quantum Optical Neuron]]. Its single-photon spatial spectrum depends on parameters that play the role of a neuron's weights. Training changes those parameters so that the probe overlaps strongly with inputs assigned to one class and weakly with inputs assigned to the other.

Keeping data and parameters in separate interferometer branches is operationally important. An input object can be presented through free-space propagation while the learned probe remains fixed, rather than preparing a new joint data-parameter state for every example. A spatial light modulator supplies one concrete realization of the probe, but the mathematical construction permits a generic single-photon state followed by linear optics. Once training is complete, the same probe can classify successive objects through their coincidence statistics.
