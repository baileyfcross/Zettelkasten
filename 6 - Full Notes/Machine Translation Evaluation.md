# Machine Translation Evaluation

Machine translation evaluation measures whether one system or version produces more useful translations than another. The task is inherently difficult because valid translations are not unique and quality depends on purpose: getting the gist, publishing a fluent text, preserving terminology, and assisting a professional translator require different evidence.

Human evaluation can test comprehension or judge [[Adequacy and Fluency Evaluation]], but it is costly and agreement varies among reviewers. Automatic metrics such as [[BLEU Score]] and [[METEOR Score]] compare system output with reference translations quickly and reproducibly. These proxies are useful for tracking aggregate change, but they should not be treated as complete measurements of meaning, style, or real-world utility.
