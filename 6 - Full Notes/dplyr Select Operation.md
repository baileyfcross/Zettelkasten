# dplyr Select Operation

The dplyr `select` operation returns specified columns from an [[R Data Frame]]. It lets an analysis retain only the variables needed for a calculation or present a deliberate ordering of fields.

Selection should preserve the distinction between rows and columns: `filter` chooses observations, while `select` chooses variables. Naming columns explicitly makes the transformation easier to review than relying on unexplained numeric positions.
