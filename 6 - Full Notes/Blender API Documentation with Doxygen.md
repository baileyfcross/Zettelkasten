# Blender API Documentation with Doxygen

Blender includes a Doxygen configuration that can generate navigable HTML or PDF documentation and call graphs from the source tree. The resulting references help trace where API functions are defined and called across a large module graph.

Generated documentation is only as descriptive as the underlying comments, and many [[Blender BLI API]] functions are sparsely documented, inline, or implemented as macros. Doxygen therefore complements direct code reading, tests, and [[Blender Debug Build Configuration]] traces rather than replacing them.
