# Linear Potential Element

A linear potential element interpolates scalar potential between element nodes with first-order shape functions. In one dimension, two endpoint values define a straight-line variation whose derivative is constant inside the element.

The interpolation functions sum to one and reproduce their own nodal value. Substitution into a variational, weighted-residual, or direct formulation produces the element coefficient matrix.
