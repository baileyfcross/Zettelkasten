# Xamarin.Forms Style

A Xamarin.Forms style collects property setters that can be applied to compatible controls. An implicit style targets every matching control in its scope, while a keyed explicit style is applied only where it is referenced.

Styles can live in application, page, or view resource dictionaries. Centralizing repeated setters reduces XAML duplication and makes the scope of a visual convention explicit.
