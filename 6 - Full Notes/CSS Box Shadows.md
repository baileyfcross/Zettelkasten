# CSS Box Shadows

The `box-shadow` property paints one or more shadows around an element's border box. Each shadow can specify horizontal and vertical offsets, blur radius, spread distance, color, and whether it is inset.

Comma-separated shadows are layered with the first shadow on top. Shadows are visual effects and do not alter layout dimensions, though they can extend beyond the box and overlap neighboring content.
