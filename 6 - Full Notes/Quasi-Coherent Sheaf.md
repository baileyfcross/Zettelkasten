# Quasi-Coherent Sheaf

A quasi-coherent sheaf on an affine scheme is locally obtained from a module by localization. For an A-module M, the associated sheaf assigns M_f to the basic open set D(f).

The source describes an equivalence between A-modules and quasi-coherent sheaves on Spec(A). Module operations can therefore be interpreted as local geometric data over an [[Affine Scheme]].
