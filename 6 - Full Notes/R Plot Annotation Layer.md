# R Plot Annotation Layer

An R plot annotation layer adds points, lines, text, titles, subtitles, or reference marks to an existing base-graphics coordinate system. The initial plot defines the axes; later calls reuse those coordinates instead of creating a new display.

Each layer should clarify a comparison, model, or exceptional observation. Because later layers can obscure earlier data, draw order, symbol size, and contrast are part of the analytical design.
