# Completed Task Log

A completed task log retains finished work and the iteration in which it was completed instead of simply deleting it from the active list. The history helps a team reconstruct what changed, verify dependencies, and understand how effort has been spent.

Completion does not make a decision permanent. If evaluation reopens the underlying design, the log distinguishes a deliberately superseded result from work that was never done.
