# Codeword

A codeword is a permitted fixed-length vector in a code. In a [[Linear Code]], every linear combination of codewords is another codeword, and the zero vector is always included.

A received vector is valid when it satisfies the code's parity checks. If corruption moves the vector outside the code, its nonzero syndrome can provide evidence about which coordinate changed.
