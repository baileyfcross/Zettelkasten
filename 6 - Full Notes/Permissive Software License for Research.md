# Permissive Software License for Research

A permissive software license allows source code to be used, copied, modified, and redistributed with relatively few conditions, commonly preservation of copyright and license notices and a liability disclaimer. Modified BSD and MIT-style licenses are examples discussed for scientific code.

The model fits research that prioritizes broad verification and reuse, including incorporation into differently licensed projects. Permissive does not mean ownerless: downstream users must follow the stated conditions, and [[Legal Attribution and Scientific Citation|legal attribution]] does not eliminate the scholarly duty to cite the software as a scientific contribution.
