# Localization at an Element

Localization at an element f uses the multiplicatively closed set {1,f,f²,…}. The resulting ring R_f permits denominators that are powers of f.

Geometrically, this ring supplies functions on the basic open subset where f does not vanish. Algebraically, [[Localization as a Quotient Ring]] presents R_f by adjoining an inverse for f.
