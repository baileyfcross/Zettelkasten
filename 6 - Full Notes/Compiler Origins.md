# Compiler Origins

Early compilers grew from libraries of precoded routines that programmers assembled with custom instructions. The more general breakthrough was a program that accepted familiar symbolic input and generated new machine code as output.

Treating a program as transformable data depended on stored-program memory. Compilers shifted attention from machine housekeeping toward the problem a user wanted to solve.
