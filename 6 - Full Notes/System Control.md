# System Control

System control is the task of issuing commands that request a function, change the interaction mode, or change system state. The user specifies what should happen and leaves the details of execution to the system.

System control connects other tasks such as [[Object Selection]], [[3D Manipulation]], and [[3D Travel]]. It can use physical controllers, graphical menus, voice, gestures, tools, or [[Multimodal Interaction]].

Good system control preserves the flow of action, limits focus and device switching, exposes available commands, organizes functions clearly, and provides unmistakable [[Feedback]] about the current mode. A 2D or hybrid control can be preferable even inside a [[3D User Interface]].
