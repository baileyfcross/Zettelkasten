# Partition of a Set

A partition is a collection of nonempty, pairwise disjoint subsets whose union is the whole set. Every equivalence relation determines a partition into equivalence classes, and every partition determines an equivalence relation.

This correspondence explains why quotient constructions organize elements into nonoverlapping classes.
