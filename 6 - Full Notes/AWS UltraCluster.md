# AWS UltraCluster

AWS UltraCluster joins thousands of accelerators, such as Trainium chips or NVIDIA GPUs, through high-performance networking and storage to create a supercomputer-scale training environment. It targets foundation models whose computation and parameters exceed a single instance or small cluster. Effective use depends on distributed-training strategy, communication efficiency, checkpointing, data throughput, and keeping expensive accelerators productively occupied.
