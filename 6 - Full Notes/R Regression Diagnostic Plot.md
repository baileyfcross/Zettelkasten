# R Regression Diagnostic Plot

R regression diagnostic plots examine residuals against fitted values, spread across the fitted range, normal quantiles, leverage, and influence. Each view tests a different part of the fitted model: remaining structure, heteroscedasticity, tail behavior, or observations capable of changing the result disproportionately.

The default plotting method for a fitted linear model can produce several standard diagnostics, but the displays require interpretation. A conspicuous point is a reason to inspect data provenance and model sensitivity, not an automatic instruction to delete the observation.
