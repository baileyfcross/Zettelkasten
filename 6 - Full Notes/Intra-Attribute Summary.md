# Intra-Attribute Summary

An intra-attribute summary records pairs of values from the same attribute that share strong connections through another attribute. It can be derived by joining the corresponding inter-attribute summary with itself.

These within-domain relationships help CACTUS identify values that can participate together in an attribute projection of a cluster.
