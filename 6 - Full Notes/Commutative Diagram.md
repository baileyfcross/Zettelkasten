# Commutative Diagram

A commutative diagram is a network of objects and homomorphisms in which every directed path with the same start and endpoint gives the same composite map.

Commutativity expresses compatibility among constructions. The [[Four Lemma]], [[Five Lemma]], and [[Snake Lemma]] use diagrams with exact rows to transfer injectivity, surjectivity, and kernel-cokernel information between related sequences.
