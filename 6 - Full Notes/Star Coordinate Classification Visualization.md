# Star Coordinate Classification Visualization

Star coordinate classification visualization assigns each feature a radial axis and projects an observation as the weighted sum of its feature positions along those axes. Manipulating axis direction or length changes the visible projection.

The display supports exploration of class separation in a two-dimensional view. Because projection geometry depends on axis configuration, apparent clusters or boundaries should be treated as hypotheses to verify rather than fixed properties of the data.
