# Thermal Model Uncertainty from Input Properties

Thermal predictions inherit uncertainty from conductivity, heat capacity, density, emissivity, convection coefficients, source rates, and boundary temperatures. A precise numerical solution does not remove uncertainty in those physical inputs.

Ranges based on measurement accuracy or plausible operating variation can be explored with sweeps. Comparing their effect on the target output identifies which properties merit better characterization and prevents insignificant numerical detail from obscuring dominant [[Thermophysical Material Characterization|material uncertainty]].
