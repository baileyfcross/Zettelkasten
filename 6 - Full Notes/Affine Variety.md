# Affine Variety

An affine variety in Kⁿ is the set of common zeros of a collection of polynomials over an algebraically closed [[Field]] K. The same set can be described by the [[Ideal]] generated by those polynomials.

Passing from equations to their ideal makes the description independent of a chosen generating list. [[Vanishing Ideal]]s move in the opposite direction by collecting every polynomial that vanishes on a set of points.
