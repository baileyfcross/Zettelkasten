# Subproject Dependency

A subproject dependency requires one component or result to exist before another component can begin or deliver value. Dependencies restrict the rollout sequences available to a project portfolio.

Modeling them explicitly prevents a financially attractive but impossible order and reveals enabling work whose value is realized mainly through the downstream options it creates.
