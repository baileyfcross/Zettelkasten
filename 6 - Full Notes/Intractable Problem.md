# Intractable Problem

An intractable problem is one for which the best known exact algorithms require an impractical amount of time on nontrivial inputs. The problem may be clearly defined and solvable in principle while still resisting useful computation at scale.

Intractability shifts attention from merely finding any [[Algorithm]] to finding a different kind of result. An [[Approximation Algorithm]] may return a solution close enough to the optimum, or analysis may establish useful bounds on how far that result can be from the best possible one.
