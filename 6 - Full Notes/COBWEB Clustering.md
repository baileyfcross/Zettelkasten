# COBWEB Clustering

COBWEB is an incremental conceptual-clustering algorithm that organizes nominal instances into a probabilistic hierarchy. Each concept node stores its occurrence probability and conditional probabilities for observed attribute values.

When a new instance arrives, the algorithm navigates the tree and selects a local operation using category utility. The structure is designed to improve inference about missing or unknown attributes.
