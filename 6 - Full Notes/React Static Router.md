# React Static Router

A React static router renders a component tree for one supplied location without depending on browser history. It is the server-side routing adapter in the source's universal application, receiving the request URL and a routing context before the tree is converted to HTML.

The static router makes route selection deterministic for a single response. A browser router later assumes responsibility for interactive navigation, but both routers wrap the same application routes so a bookmarked URL identifies the same initial content in either environment.
