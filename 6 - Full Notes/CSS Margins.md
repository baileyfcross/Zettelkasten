# CSS Margins

Margins form the transparent outer region of the [[CSS Box Model]] and separate an element's border from neighboring boxes. Each side accepts lengths, percentages, or `auto`, and margins may be negative.

Automatic horizontal margins can absorb remaining width and center a sized block. Vertical margins in normal block flow may participate in [[CSS Vertical Margin Collapsing]], so declared values do not always add directly.
