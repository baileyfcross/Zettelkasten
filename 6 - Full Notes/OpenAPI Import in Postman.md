# OpenAPI Import in Postman

OpenAPI import in Postman converts a machine-readable API description into a collection of requests organized by the described paths and operations. Schemas, parameters, and examples provide starting material for request bodies and tests.

Import accelerates exploration but does not prove that the description matches the deployed application. Regenerating or reconciling the collection after contract changes prevents the tooling from becoming a stale parallel specification.
