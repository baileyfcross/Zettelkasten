# AWS Migration Readiness Assessment

An AWS Migration Readiness Assessment evaluates whether an organization has the capabilities needed to execute cloud adoption. It uses the perspectives of the [[AWS Cloud Adoption Framework]] to expose gaps across business, people, governance, platform, security, and operations. The output informs the mobilization backlog; it is not merely a technical inventory, because unaddressed skills, ownership, funding, or control gaps can stop a technically feasible migration.
