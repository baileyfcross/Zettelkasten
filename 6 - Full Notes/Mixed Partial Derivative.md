# Mixed Partial Derivative

A mixed partial derivative differentiates a multivariable function successively with respect to different variables. For example, $f_{xy}$ first differentiates with respect to $x$ and then differentiates that result with respect to $y$ under the stated notation convention.

For functions smooth enough for the derivatives to behave regularly, the order can be exchanged, so $f_{xy}=f_{yx}$. This equality supports exact-differential tests and reduces the number of distinct second derivatives required in local quadratic approximations.
