# Personal Data API

A personal data API is an interface through which software can request a person's records from a service and combine them with other tools. It can make repeated access and user-led innovation more practical than manually downloading a file.

The interface embodies decisions about what the provider considers worth exposing. It may return only calculated summaries rather than raw observations, restrict historical depth, omit context, or change fields without preserving compatibility. An API is therefore also an opinion about which questions outside users are allowed to ask.

Authentication and permission are necessary because programmatic access can widen disclosure as well as choice. A useful interface combines documented meanings, stable formats, revocable authorization, and enough detail for the intended purpose.
