# Angular Routing

Angular routing maps browser-side URL patterns to client components. It lets a [[Single-Page Application]] preserve meaningful navigation and location while changing views without requesting a complete replacement page from the server.

In a combined application, server middleware first handles static files and mapped API endpoints; an SPA fallback can then pass remaining paths to Angular so its routing rules select the client view.
