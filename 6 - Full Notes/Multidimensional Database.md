# Multidimensional Database

A multidimensional database organizes measures across dimensions so users can examine data from several perspectives. Its structure supports rapid aggregation and navigation through categories, time periods, locations, or other analytic axes.

Data cubes and online analytical processing expose these dimensions through operations such as pivoting, filtering, drilling, and slicing. The representation is especially useful during exploratory analysis.
