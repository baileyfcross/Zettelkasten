# Amazon S3 Lifecycle Rule

An Amazon S3 lifecycle rule changes or removes objects according to age and scope. Transition actions move current or noncurrent versions to another storage class, while expiration actions delete objects or markers when retention ends.

Rules turn retention and cost policy into repeatable automation. Their timing must respect minimum storage durations, legal holds, and recovery requirements; an inexpensive archive transition is harmful if users still need immediate access.
