# Probabilistic Control

Probabilistic control infers actions that make a desired state or observation plausible under an uncertain system model. It treats action as a searched variable while goals and available evidence condition the question.

The answer can retain a distribution over actions instead of pretending one command is certainly correct. This makes ambiguity, sensor uncertainty, and uncertain dynamics explicit in the controller's choice.
