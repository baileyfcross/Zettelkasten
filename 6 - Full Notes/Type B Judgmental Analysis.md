# Type B Judgmental Analysis

Type B judgmental analysis permits judges to evaluate different subjects or different numbers of subjects while retaining the same criterion and predictor variables. It is useful when a fully crossed rating design is impractical.

The added flexibility complicates comparison because the estimated policies may reflect different case distributions as well as different judgment strategies.
