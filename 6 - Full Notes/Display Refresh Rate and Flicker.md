# Display Refresh Rate and Flicker

Refresh rate is the number of times per second a display renews the screen image. In a scanned display it depends on the scanning frequency and the number of lines or pixels that must be visited for each frame. A rate of 75 hertz, for example, means that the displayed image is redrawn seventy-five times per second.

Phosphor brightness decays between refreshes. If the interval is long enough for that fading to become visible, the viewer perceives flicker. The processing time required to access every pixel therefore places a practical lower bound on frame duration and an upper bound on refresh frequency for a given raster size.
