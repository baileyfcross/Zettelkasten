# Modal Dialog Box

A modal dialog box is a UI screen layered above another screen to request a decision or present information that must be handled before underlying interaction continues. It receives input while lower screens remain visible but inactive.

Implementing the dialog on a [[Game Menu Stack]] allows dismissal to reveal the prior screen automatically. Buttons or callbacks communicate the selected result without coupling the dialog to every caller.
