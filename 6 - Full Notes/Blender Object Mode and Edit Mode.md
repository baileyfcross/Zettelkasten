# Blender Object Mode and Edit Mode

Object mode treats a model as a whole for selection, transformation, hierarchy, and scene organization. Edit mode exposes the internal components of selected objects so their shape can be changed.

The Tab key commonly switches between the modes, and the Modeling workspace can enter Edit mode automatically for selected objects. Multiple objects of the same type can be edited together, while objects of different types retain separate editing rules.

In the source's beginner workflow, Object Mode positions and configures the whole primitive, while Edit Mode exposes vertices, edges, and faces for reshaping, deletion, extrusion, and subdivision. Confusing the modes changes the scope of a transform from an object's scene transform to its internal mesh coordinates.
