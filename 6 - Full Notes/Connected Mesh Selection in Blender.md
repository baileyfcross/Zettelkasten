# Connected Mesh Selection in Blender

Linked selection treats vertices connected by edges as one mesh island. Placing the pointer near a component and pressing L selects its connected island; Shift+L removes an island from the selection.

This is useful when a single mesh object contains several disconnected pieces. It gives access to a coherent part without box-selecting each component or separating every island into its own object.
