# Game Data Fulcrum

A game data fulcrum is a representative object used as the common comparison point for a large family of game objects. Each new character, weapon, or vehicle is balanced against the fulcrum rather than exhaustively against every other member of the set.

This turns an exploding pairwise test problem into a roughly linear creation process. The fulcrum should first be tuned in isolation and across relevant environments until it behaves as the desired center. It may be an internal benchmark that never appears in the shipped game, as long as it remains stable enough to support comparisons.
