# Posterior Probability

Posterior probability is the distribution obtained after conditioning a model on observed evidence. It combines the prior description with the evidence likelihood and normalization required by the complete set of alternatives.

The posterior is conditional on both the observations and the modeling assumptions. It can answer the current question directly or become summarized knowledge used as a prior in a later recursive update.
