# Text Classification Information Gain

Text classification information gain measures how much knowing whether a word is present reduces uncertainty about the class label. It compares class entropy before and after partitioning documents by that feature.

A term earns a high score when its presence or absence sharply changes the class distribution. Computing the score across a large vocabulary supports filter selection before the more expensive classifier is trained.
