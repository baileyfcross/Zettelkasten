# Survival Analysis

Survival analysis studies whether and when an event occurs while accounting for observations whose event time is not fully observed. Each record combines an event indicator with a time-to-event or censoring time.

The method can describe survival curves, compare groups, or estimate adjusted hazard or time relationships. It is only as credible as the event timing and observation window; uncertain diagnosis dates can make a simpler binary-outcome analysis more defensible.
