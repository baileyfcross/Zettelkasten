# Blender Selected-Object Export

Selection-only export limits an interchange file to the objects deliberately selected in the current scene. It lets an artist publish one asset or a controlled group without copying unrelated cameras, tests, lights, and work-in-progress geometry.

The option depends on correct selection and, in some formats, active-collection filters. A clean export set should be verified in a fresh file or target engine because hidden or unselected dependencies may still be required for materials, rigs, or hierarchy.
