# Square Matrix

A square matrix has the same number of rows and columns, so its size is $n\times n$. Square shape permits operations and properties that rectangular matrices do not have, including a [[Determinant]], [[Matrix Trace]], eigenvalues, and possibly a [[Matrix Inverse]].

Important square-matrix families include [[Diagonal Matrix]], [[Upper Triangular Matrix]], [[Symmetric Matrix]], and [[Orthogonal Matrix]].
