# ISO Sensitivity

ISO sensitivity describes the camera's amplification of the sensor signal. Raising ISO allows an image to be exposed with less light, a smaller aperture, or a faster shutter, but it generally makes sensor noise more visible.

An analyst can compare a recorded ISO value with the apparent noise and the other exposure settings. Compression, denoising, resizing, and local image content also affect visible noise, so a mismatch should be interpreted with those transformations in mind.
