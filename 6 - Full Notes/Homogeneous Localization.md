# Homogeneous Localization

Homogeneous localization forms fractions using homogeneous denominators from a multiplicative set. The fraction m/s receives degree deg(m) − deg(s), so the localized module retains a grading.

This differs from ordinary localization only in the attention paid to degrees. It supports local analysis without discarding the homogeneous structure needed in projective geometry.
