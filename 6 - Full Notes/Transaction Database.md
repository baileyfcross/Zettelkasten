# Transaction Database

A transaction database is a finite collection of records, each containing a set of items that occurred together. A shopping basket is the standard example, but a transaction can represent any co-occurring categorical events.

Association-rule methods scan the database to count itemsets and discover combinations that meet support and confidence requirements.
