# Clusterwise Redshift Regression

The book uses astronomical redshift measurements to illustrate precision-based search. Photometric redshift is easier to obtain but less precise than spectrometric redshift, so the project groups measurement pairs by shared decimal prefixes before considering local matching or regression.

The cluster is defined by similarity in the measured redshift values, not by sky location. A prefix tree can retrieve candidate pairs rapidly from a large survey, but any regression still needs its own accuracy assessment: shared digits identify a useful search neighborhood, not a guaranteed physical relationship.
