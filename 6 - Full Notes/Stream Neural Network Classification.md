# Stream Neural Network Classification

Stream neural network classification applies incremental gradient updates to a network as labeled observations become available. Each update changes a nonlinear boundary without requiring a complete retraining pass.

The learning rate and memory mechanism determine how quickly the network responds to changing distributions. Rehearsal, decay, or ensembles can reduce catastrophic replacement of older but still relevant patterns.
