# Prototype Documentation

Prototype documentation records the question an artifact was built to answer, what was included or omitted, how it was tested, what happened, and why the next decision followed. It preserves learning that would otherwise disappear when the artifact is discarded.

The record should be proportional to the test. A brief decision note can be sufficient when it captures the prototype's why, what, and how clearly enough to inform later iterations.
