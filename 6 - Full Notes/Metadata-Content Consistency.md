# Metadata-Content Consistency

Metadata-content consistency tests whether recorded file fields plausibly describe the visible photograph. The stated exposure should agree with motion and focus, a GPS position should fit the depicted place, and the camera or software history should be compatible with the claimed origin.

A contradiction can expose an impossible or incomplete provenance story. Consistency is weaker evidence because metadata can be forged and many combinations of settings can yield similar appearances. The test is best used to generate targeted questions and to corroborate independent forensic cues.
