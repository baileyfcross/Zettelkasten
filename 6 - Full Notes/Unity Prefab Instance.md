# Unity Prefab Instance

A Unity prefab instance is a scene or runtime object created from a [[Unity Prefab]] asset. It begins with the prefab's hierarchy, components, and default property values while retaining a connection to that reusable source.

The connection distinguishes an instance from an unrelated duplicate. Shared prefab changes can propagate to many instances, while selected properties may differ locally. Instances make repeated content maintainable because the project stores common construction once and places it wherever the game requires.
