# Spatiotemporal Time-Series Plot

A spatiotemporal time-series plot draws a separate temporal trajectory for each spatial location or zone in a shared panel or aligned set of panels. It emphasizes timing, common peaks, and persistent differences but removes map position. Thin transparent lines can reveal the network's overall behavior. A [[Space-Time XT Plot]] may make long-duration level differences easier to scan, while maps identify where those locations are.
