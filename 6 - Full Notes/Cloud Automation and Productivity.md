# Cloud Automation and Productivity

Cloud automation and productivity describes the value created when readily available computing services let organizations automate work without first building a full infrastructure estate. Applications, information, and workflows can be provisioned as recurring operating services.

Automation can remove manual delay and let people concentrate on the organization's main work. It can also displace existing tasks and create dependency on remote services, so productivity gains should be evaluated alongside workforce, continuity, and control effects.
