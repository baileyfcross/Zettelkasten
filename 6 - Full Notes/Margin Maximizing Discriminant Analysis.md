# Margin Maximizing Discriminant Analysis

Margin maximizing discriminant analysis learns several orthogonal projection directions that separate labeled classes with large margins. It extends the support-vector objective from one separating direction to a multidimensional embedding.

Slack variables permit overlap, while an orthogonality constraint prevents the learned directions from collapsing onto the same axis. Euclidean distance after projection becomes the task-specific metric used for comparison.
