# Player Knowledge Schema

A player knowledge schema is an organized structure in [[Long-Term Memory]] that compresses many related rules and actions into one usable concept. An experienced player can treat "platformer" as a chunk that already implies movement, jumping, gravity, hazards, and a likely goal.

Novices lack these compressed structures and must process the underlying elements separately. Tutorial and interface design should therefore not assume that genre conventions are innate; prior experience determines how much new information occupies [[Working Memory]].
