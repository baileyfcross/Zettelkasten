# Reactive Assistant

A reactive assistant acts in response to an explicit user request or event. The user initiates the exchange, so the immediate purpose of the interaction is comparatively clear.

Reactive behavior limits interruption and privacy risks, but it cannot surface useful information before the user thinks to ask. A [[Proactive Assistant]] takes the stronger step of initiating an interaction.
