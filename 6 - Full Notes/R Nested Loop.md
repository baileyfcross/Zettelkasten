# R Nested Loop

An R nested loop places one iteration inside another so a calculation runs across every required pair of outer and inner index values. It naturally fills a matrix, compares combinations, or advances several coupled dimensions.

Each loop needs a distinct index and verified bounds. Because the inner body runs once for every index pair, computational cost grows as the product of the sequence lengths and can become substantial even when each individual calculation is simple.
