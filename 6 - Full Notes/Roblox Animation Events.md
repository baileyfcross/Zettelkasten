# Roblox Animation Events

Animation events place named markers at specific times in a Roblox animation. A script can listen for a marker and trigger synchronized behavior such as a footstep sound, particle burst, hit window, or interaction cue.

The event connects authored timing to runtime logic without forcing the script to guess from elapsed time alone. Important gameplay outcomes should still be validated by authoritative code, because visual playback can vary or be manipulated. Markers complement [[Roblox Pose Keyframes]] by attaching meaning to moments inside the motion.
