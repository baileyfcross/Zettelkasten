# Excel CORREL Function

Excel CORREL returns the correlation coefficient between two aligned numeric datasets. Values near positive one indicate a strong positive linear association, values near negative one indicate a strong negative linear association, and values near zero indicate little linear association.

The two ranges must describe paired observations and contain compatible numbers of data points. Correlation is sensitive to outliers and can miss nonlinear relationships. Most importantly, a strong coefficient does not establish that one variable causes the other; it summarizes how the paired values move together in the available data.
