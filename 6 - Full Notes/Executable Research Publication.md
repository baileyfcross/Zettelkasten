# Executable Research Publication

An executable research publication connects a scientific narrative to computations that readers can rerun. Figures, tables, and numerical claims are generated from accessible code and data rather than copied into a static document as detached results.

Execution can occur inside the authoring document, through an [[Executable Companion Page]], or in a linked computational environment. The essential feature is not a particular interface but a verifiable connection between claims and operations. That connection turns the publication into an entry point for inspection, parameter changes, and [[Replication and Computational Reproducibility|computational reproduction]].
