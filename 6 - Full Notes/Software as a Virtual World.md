# Software as a Virtual World

Software creates a virtual world in which users perceive objects, take actions, follow rules, and pursue purposes. Games make this structure explicit, but spreadsheets, marketplaces, social networks, and service apps also define distinctive worlds.

Designing the world means shaping possible actions, norms, feedback, and identities—not just implementing functions. A useful system lets its inhabitants accomplish meaningful work within a coherent experience.
