# Game Interface Accessibility

Game interface accessibility designs controls and presentation so people with differing visual, auditory, motor, or other abilities can perceive information and perform required actions. It includes more than adding an easy mode.

Color should not be the sole carrier of state, spoken dialogue can be subtitled, critical audio can have visual equivalents, and control demands can be adjustable. Accessibility works best when included in the interface architecture rather than patched onto finished content.
