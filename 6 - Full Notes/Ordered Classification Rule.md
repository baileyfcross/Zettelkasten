# Ordered Classification Rule

An ordered classification rule belongs to a priority list of if-then conditions. Prediction tests rules in sequence and uses the consequent of the first antecedent satisfied by the observation.

Ordering resolves conflicts without combining every matching rule, but it makes a rule's meaning depend on all earlier entries. A default rule at the end supplies a class for cases that satisfy no learned condition.
