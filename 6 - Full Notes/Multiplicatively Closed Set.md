# Multiplicatively Closed Set

A multiplicatively closed set S contains the [[Ring Identity]] and is closed under multiplication. It specifies which elements may appear as denominators in [[Ring Localization]].

If an ideal is disjoint from S, a maximality argument produces a [[Prime Ideal]] containing that ideal and still disjoint from S. Primes that meet S disappear after localization because one of their elements becomes invertible.
