# Vapnik-Chervonenkis Dimension

Vapnik–Chervonenkis dimension measures the expressive capacity of a binary classifier class by the largest number of points it can label in every possible way. A finite VC dimension controls how many distinct label patterns the class can realize on a sample.

This capacity enters generalization bounds for [[Empirical Risk Minimization]]. Greater flexibility can improve approximation to the Bayes rule, but it also increases the gap between empirical and true risk unless the sample grows. VC dimension therefore formalizes the classification version of a bias–complexity tradeoff without counting parameters alone.
