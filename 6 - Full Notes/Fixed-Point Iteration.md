# Fixed-Point Iteration

Fixed-point iteration begins with $x_0$ and repeatedly computes $x_{k+1}=g(x_k)$. If the sequence converges, its limit satisfies $g(p)=p$ and is a [[Fixed Point]].

A sufficient local condition is that $g$ maps an interval into itself and has derivative magnitude below one there. A poor rearrangement can make the same equation diverge.
