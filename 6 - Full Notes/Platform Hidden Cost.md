# Platform Hidden Cost

A platform hidden cost is expenditure created by architectural dependencies or operating behavior that is not obvious from the headline price of a primary resource. Load balancers, API gateways, data transfer, retained snapshots, backup copies, idle capacity, and unconstrained managed services can dominate the bill around an otherwise inexpensive workload.

Migration and integration work add another layer because adapting existing systems to provider assumptions consumes engineering time and ongoing maintenance. Cost analysis should therefore follow complete user journeys and data flows rather than compare only compute prices. Ownership metadata and utilization evidence make these indirect drivers visible enough to change.
