# Attributed Graph

An attributed graph associates properties with its vertices, edges, or both. The topology expresses relationships while attributes carry types, labels, weights, identifiers, or application data used by queries and updates.

Accelerators must fetch and interpret these values as well as traverse adjacency, so property layout and memory access can be as important as the edge representation.
