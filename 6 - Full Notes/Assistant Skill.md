# Assistant Skill

An assistant skill is a packaged capability that extends what a broader assistant can understand and do. It usually defines a domain, supported intents, required entities, dialog behavior, and access to a relevant service.

A broad [[Personal Virtual Assistant]] must select the right skill through [[Intent Triggering]]. Once activated, the skill can use a narrower [[Intent Schema]] and task-specific [[Dialog Policy]].
