# Cluster Separation

Cluster separation measures how distinct a cluster or observation is from competing clusters. For a point, it can be defined as the smallest average distance to the members of another cluster.

Strong separation complements cohesion. A grouping can contain internally compact clusters yet remain poor if those clusters are not distinguishable from each other.
