# Frequency Table

A frequency table counts observations at each level of a categorical variable. It may also report proportions, cumulative counts, cumulative proportions, and an explicit category for missing values.

The denominator must be clear. Percentages based only on valid responses answer a different question from percentages that include missing records, and both can be useful when assessing data quality and describing the analytic population.
