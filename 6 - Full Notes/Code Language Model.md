# Code Language Model

A code language model is trained on programming-language and related technical text so it can represent and predict code tokens, structure, and semantics. Large code models use extensive multilingual corpora and transformer pretraining to support generation, completion, search, explanation, and repair.

Source code contains repeated statistical patterns but also strict syntax, dependencies, and executable behavior. A model's probability distribution can propose likely code, while tools and tests determine whether that proposal is valid in a particular repository.
