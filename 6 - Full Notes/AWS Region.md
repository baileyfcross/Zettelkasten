# AWS Region

An AWS Region is a geographically defined area that contains several isolated [[AWS Availability Zone|availability zones]]. A customer selects a region for regional services and data according to latency, service availability, price, and legal or data-residency requirements.

Resources are not automatically copied between regions. Multi-region recovery or global delivery therefore requires explicit replication, routing, and operational design. A region is a meaningful failure and governance boundary, not merely a location label.
