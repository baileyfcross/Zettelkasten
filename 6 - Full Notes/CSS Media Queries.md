# CSS Media Queries

A CSS media query conditionally applies a stylesheet or block of rules according to an output medium and its features. Queries can appear on linked or imported stylesheets and in `@media` blocks inside a stylesheet.

When a query is false, its rules do not participate in presentation, but the resource may still be retrieved. Media queries let one document adapt rather than requiring separate markup for every display or print condition.
