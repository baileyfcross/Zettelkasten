# Personal Computer Game Platform

The personal computer is a flexible game platform used at a desk by one person, with keyboard, mouse, display, storage, networking, and hardware configurations that vary widely. It supports detailed interfaces, modification, and many genres.

Variation is both strength and cost. Designers gain precision controls and extensibility but must account for performance ranges, installation environments, display differences, and a less standardized input setup.
