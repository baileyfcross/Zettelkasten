# Categorical Feature

A categorical feature takes values from a discrete set of labels whose identities matter but whose order usually does not. Color values such as black, blue, green, and red are categories rather than positions on a numerical scale.

Encoding categories as arbitrary numbers can introduce a false ordering and misleading distances. [[One-Hot Encoding]] instead represents category membership with separate binary indicators when an algorithm requires numerical input.
