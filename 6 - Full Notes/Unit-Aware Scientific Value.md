# Unit-Aware Scientific Value

A unit-aware scientific value carries a quantity's unit as machine-interpretable semantics rather than relying on a reader to infer it from a manual or column heading. The unit can be validated, converted, and checked alongside the numerical value.

Explicit units prevent a result from being numerically repeatable but scientifically uninterpretable. They also permit assertions that an output has both the expected value and dimensional meaning. In an [[Executable Mathematical Semantics|executable formula]], unit references should resolve through shared dictionaries so different programs apply the same definition.
