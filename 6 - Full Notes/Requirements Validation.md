# Requirements Validation

Requirements validation determines whether the delivered or proposed system satisfies the agreed needs and constraints. It uses review, demonstrations, acceptance criteria, and tests to compare observable behavior with the specification.

Validation asks whether the team built the right system, while implementation verification asks whether a component was built according to its design. Customer participation is essential where value or usability cannot be inferred from technical correctness alone.
