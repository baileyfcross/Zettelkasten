# Client-Side Debugging

Client-side debugging observes JavaScript or TypeScript behavior running in the browser. It can inspect component variables, form controls, subscriptions, network requests, and changes to the rendered document.

A [[JavaScript Source Map]] allows a debugger to connect generated JavaScript back to the original TypeScript. Browser developer tools provide an additional view of console messages, source files, requests, and element state.
