# Generative AI Data Management Stage

The generative-AI data management stage ingests raw records from databases, APIs, streams, lakes, and public datasets, then cleans, normalizes, structures, and versions them for experimentation or retrieval. Distributed tools can run the transformations as parallel Kubernetes workloads.

Data quality and lineage become model inputs. The stage should record source, permissions, transformations, version, and retention so a training or evaluation result can be traced back to the exact material that produced it.
