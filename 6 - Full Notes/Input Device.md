# Input Device

An input device is a physical device that allows communication from a user to a computer. It is the hardware used to capture an action; the [[Interaction Technique]] supplies the software mapping that turns the captured data into an effect in the system.

Input can be discrete, such as a button value, continuous, such as a stream of positions, or a combination of both. Important characteristics include [[Degrees of Freedom]], data frequency, whether measurements are absolute or relative, and whether the sensor must be held or worn. A device should be selected together with the task and interaction technique because one device may map naturally to one task and poorly to another.
