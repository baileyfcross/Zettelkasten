# Game Structure

Game structure is the set of relationships among gameplay modes and the rules that move the game from one mode to another. It explains when different challenges, actions, views, and controls become available.

Shell menus sit outside active gameplay but still participate in the player's route through the software. A [[Flowboard]] makes the modes and transitions visible so omissions and confusing loops can be found before implementation.
