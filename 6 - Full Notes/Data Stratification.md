# Data Stratification

Data stratification divides observations into groups defined by the value or range of another variable and examines the outcome distribution within each group. It can reveal how a relationship changes across a predictor instead of reducing all observations to one aggregate summary.

In the source's height example, grouping sons by rounded father height makes conditional averages and distributions visible. Poorly chosen or sparse strata can introduce noise, so the grouping scale needs substantive and statistical justification.
