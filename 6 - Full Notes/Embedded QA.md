# Embedded QA

Embedded QA places a tester within a cross-discipline team so testing knowledge participates in planning, acceptance criteria, implementation feedback, regression work, and tool improvement. This shortens the delay between creating and understanding a defect.

A centralized test pool can still supplement the team as scale and platform complexity grow. Embedding changes when quality expertise enters decisions, not who alone owns quality.
