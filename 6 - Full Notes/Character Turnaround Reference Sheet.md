# Character Turnaround Reference Sheet

A character turnaround reference sheet aligns neutral front, side, and back drawings so major features occupy corresponding heights and widths across views. Separate head and body sheets can expose more useful detail, and a side body view may omit an arm that would otherwise cover the torso.

Turnarounds guide proportion rather than define a physically exact volume. Hand-drawn views inevitably disagree, so the modeler uses horizontal guides and orthographic placement to reduce guesswork while allowing the three-dimensional form to resolve contradictions.
