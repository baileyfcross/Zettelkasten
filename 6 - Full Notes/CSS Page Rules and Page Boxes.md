# CSS Page Rules and Page Boxes

The CSS `@page` rule describes page boxes in paged media. It can set page margins and size and can target left, right, first, or named pages through page pseudo-classes.

The page box contains the page area into which document content is flowed, surrounded by page margins. These rules concern the output sheet rather than selecting an element in the document tree.
