# Spreadsheet Color Coding Convention

A spreadsheet color coding convention assigns stable visual roles to cells, such as distinct styles for headers, tunable inputs, formulas, sublabels, and static reference text. There is no universal game-industry palette; the important requirements are that the scheme be documented, introduced early, and applied consistently.

Color lets a reader see at a glance which cells may be edited and which would break calculations if overwritten. Because color usually does not survive export to a game engine, it should supplement rather than replace labels, validation, and a sound table structure.
