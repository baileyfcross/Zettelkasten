# Amazon Athena Workgroup

An Amazon Athena workgroup separates query execution for teams, applications, or purposes. It can enforce settings such as the result location, encryption, and limits on scanned data while exposing usage metrics by group. Workgroups create an administrative and cost boundary around a shared serverless query service; they do not isolate poorly designed files, so partitioning and columnar formats remain important.
