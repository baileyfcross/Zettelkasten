# Kotlin Internal DSL

An internal Kotlin domain-specific language uses ordinary Kotlin syntax and type checking to express a vocabulary for one constrained part of an application. Unlike an external DSL, it does not require a separate standalone language or parser.

Lambdas with receivers, extension functions, and trailing-lambda syntax let configuration read in a domain-oriented order while remaining Kotlin code. The book recommends this form for suitable configuration and library interfaces, not as a replacement for ordinary classes throughout an application.
