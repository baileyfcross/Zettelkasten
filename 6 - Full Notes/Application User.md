# Application User

An application user is the identity entity specialized for one application's account model. It extends the framework's base identity user with any additional persistent properties the application requires.

The user becomes part of the Entity Framework Core context and is created, found, or updated through [[User Manager]]. It should contain identity data rather than unrelated client presentation state.
