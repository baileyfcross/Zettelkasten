# Generalization in Machine Learning

Generalization is a learned model's ability to make useful predictions for cases that were not used to fit it. Memorizing a finite [[Training Dataset]] is insufficient when the intended population contains many other possible inputs.

Learning becomes possible when the problem has regularity: nearby or otherwise similar inputs tend to have related outputs. The chosen representation defines what “similar” means, while an [[Inductive Bias in Machine Learning|inductive bias]] decides which of the many models compatible with the sample should be preferred. Generalization is therefore assessed on unused data rather than inferred from training fit alone.
