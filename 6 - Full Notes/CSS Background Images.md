# CSS Background Images

The `background-image` property paints an image behind an element's content and border. The source can be a URL or a generated image such as [[CSS Linear Gradients|a gradient]], and the image sits above the background color.

Backgrounds do not affect box dimensions. Position, size, repetition, attachment, origin, and clipping determine how the image is mapped across the element's background painting area.
