# Java Primitive and Reference Types

Java primitive variables directly hold values from eight built-in types, while reference variables hold values that identify objects or arrays. Assigning a primitive copies its represented value; assigning a reference copies the reference, so two variables can designate the same mutable object.

Class, interface, enum, array, record, and annotation types participate in the reference type system. A reference can use a compatible supertype while pointing to a subtype object, enabling polymorphism, but member access at compile time is constrained by the reference's declared type.
