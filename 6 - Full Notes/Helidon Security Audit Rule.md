# Helidon Security Audit Rule

A Helidon security path rule can enable auditing for requests evaluated under that rule. The configuration attaches audit behavior to selected protected routes, including routes intentionally designed to deny access.

This makes the decision to record security evaluation explicit at the policy boundary. Auditing can coexist with required or optional authentication and with role restrictions, so it observes the configured decision path rather than replacing authorization.
