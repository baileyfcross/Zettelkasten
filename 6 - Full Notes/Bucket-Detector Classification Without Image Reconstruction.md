# Bucket-Detector Classification Without Image Reconstruction

Bucket detectors register photons without resolving where they arrived. Placing one at each output of a Hong-Ou-Mandel interferometer makes the relevant observation the rate of events in which one photon appears at each output. Because that rate depends on the global overlap between the input and probe states, the apparatus can make a classification decision without producing a pixel-by-pixel image.

This is task-specific sensing: the optical system discards the spatial record needed to reconstruct or inspect the object and preserves only a statistic trained for a binary decision. The method therefore saves imaging resources only when the class prediction is the desired output. It is not a general replacement for a camera when later analysis needs the image itself, and it assumes a prepared [[Trainable Single-Photon Probe State]] appropriate to the classification task.
