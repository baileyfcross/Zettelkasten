# Parity-Check Code

A parity-check code appends a check symbol chosen so that the sum of a codeword's coordinates satisfies a fixed field equation. In a binary even-parity code, the total number of ones is even.

This simple redundancy detects any single bit flip, because the altered word violates the parity equation. It cannot distinguish every multiple error or a permutation that preserves parity, motivating richer [[Error-Correcting Code|error-correcting codes]].
