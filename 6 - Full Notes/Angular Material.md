# Angular Material

Angular Material is a collection of Angular user-interface modules and components. Applications import only the modules they need, such as table, paginator, sort, or select controls, and combine them with application-specific data and behavior.

The library supplies presentation and interaction primitives rather than the data source itself. An [[Angular Material Table]] still depends on a component or service to fetch, page, sort, and filter API results.
