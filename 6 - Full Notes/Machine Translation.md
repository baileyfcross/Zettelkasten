# Machine Translation

Machine translation automatically converts a text in a source language into a text in a target language. The task is not a substitution cipher: languages divide meaning differently, reorder grammatical roles, use idioms, and leave different information implicit. A useful system must therefore balance fidelity to the source with fluency and convention in the target language.

The field has repeatedly changed how it represents that problem. [[Rule-Based Machine Translation]] encodes dictionaries and transfer rules, [[Statistical Machine Translation]] learns local correspondences from translated corpora, and [[Neural Machine Translation]] learns continuous sentence representations. Each approach reduces some manual work while introducing new dependence on data, computation, and evaluation.
