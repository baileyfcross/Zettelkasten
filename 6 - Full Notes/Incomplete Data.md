# Incomplete Data

Incomplete data omits values for variables that participate in a probabilistic model. Treating the missing values as latent variables allows their possibilities to be inferred rather than silently discarded or filled with unjustified constants.

Parameter learning then depends on both observed evidence and uncertainty about what was not observed. Expectation-maximization is one method for alternating between those two parts of the problem.
