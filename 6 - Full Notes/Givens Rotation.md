# Givens Rotation

A Givens rotation is an [[Orthogonal Matrix|orthogonal]] transformation that mixes two coordinates while leaving the others unchanged. Its sine and cosine are chosen to zero one selected matrix entry.

Sequences of these rotations can reduce matrices while preserving eigenvalues and norms. They are useful when only a few entries need to be eliminated.
