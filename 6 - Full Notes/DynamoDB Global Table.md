# DynamoDB Global Table

A DynamoDB global table replicates a table across multiple AWS regions with multi-active write capability. Applications can access a geographically closer replica and continue operating when a regional endpoint is unavailable.

Asynchronous cross-region replication means concurrent updates and conflict handling must fit the application. Global placement improves availability and latency while increasing cost, data-residency scope, and operational complexity.
