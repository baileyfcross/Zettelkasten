# Category Utility

Category utility evaluates a partition by comparing how accurately attribute values can be predicted with knowledge of the categories against prediction without that knowledge. It favors values that are both predictable within a class and predictive of class membership.

COBWEB chooses the local tree operation with the highest utility. Dividing by the number of classes discourages improvement caused only by excessive fragmentation.
