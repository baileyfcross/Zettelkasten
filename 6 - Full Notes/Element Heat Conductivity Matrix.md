# Element Heat Conductivity Matrix

An element heat conductivity matrix relates nodal temperatures to conductive heat-flow rates. For a uniform one-dimensional element, it scales with conductivity and area and inversely with element length.

Its signed two-node pattern mirrors the axial-bar stiffness matrix because both govern a gradient-driven flux. Assembly combines elements of different materials into a global conduction system.
