# Apache Hive

Apache Hive is a distributed data-warehouse system for large structured datasets stored through the Hadoop ecosystem. It uses [[HiveQL]] and a metastore containing schemas and statistics to compile queries into parallel jobs.

The catalog enables operations such as column and partition pruning, join planning, and indexed access. Hive favors structured, high-latency analytical queries rather than procedural transformation of unstructured records.
