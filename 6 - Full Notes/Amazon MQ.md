# Amazon MQ

Amazon MQ is a managed message-broker service for software that uses established broker protocols and APIs. It operates compatible Apache ActiveMQ or RabbitMQ brokers, reducing the need to provision, patch, and monitor the underlying broker hosts.

It is especially useful when migrating applications already written for traditional messaging systems. New cloud-native designs may instead use [[Amazon SNS Topic|SNS]] and [[Amazon SQS Queue|SQS]], whose service-specific interfaces remove more broker administration and scale differently.
