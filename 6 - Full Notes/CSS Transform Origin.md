# CSS Transform Origin

The `transform-origin` property chooses the point around which an element is rotated, scaled, or otherwise transformed. Horizontal and vertical components can use keywords, lengths, or percentages, and a third length can place the origin along the z-axis.

Moving the origin changes the apparent path of the same transform without changing its angle or scale. A rotation around a corner therefore produces a different result from rotation around the default center.
