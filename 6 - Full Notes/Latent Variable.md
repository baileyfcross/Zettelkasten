# Latent Variable

A latent variable is included in a probabilistic description but is not directly observed in the available dataset or current question. It represents hidden structure that can explain dependencies, classes, states, or model choices among observed variables.

Inference assigns a distribution to the latent alternatives or marginalizes them. Learning with latent variables is an incomplete-data problem because parameter estimation must account for values that were not recorded.
