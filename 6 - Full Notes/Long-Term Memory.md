# Long-Term Memory

Long-term memory stores information about the world, concepts, events, and procedures beyond the temporary capacity of [[Working Memory]]. Declarative memory holds facts and events, while nondeclarative memory includes priming, skills, habits, conditioning, and habituation.

Recall reactivates memory traces and is influenced by cues and context. It can also be biased, misattributed, blocked, or altered by suggestion. Interfaces can support recall by providing meaningful cues and consistent mappings, while repeated interaction can turn explicit procedures into skills through [[Skill Acquisition]].

Spatial information accumulated during [[Navigation]] is represented by a [[Cognitive Map]].
