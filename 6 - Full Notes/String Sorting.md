# String Sorting

String sorting treats a key as a sequence of symbols such as characters or digits. The symbols must have an order, allowing complete strings to be ordered lexicographically or processed one position at a time.

[[Radix Sort]] is called a string-sorting method because it distributes items by individual key positions. A numerical key such as 123 is handled as the ordered symbols 1, 2, and 3 rather than as one indivisible number.
