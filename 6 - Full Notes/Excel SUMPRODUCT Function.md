# Excel SUMPRODUCT Function

Excel SUMPRODUCT multiplies corresponding elements in one or more arrays and then sums the products. A classic use is a weighted total, such as quantities multiplied by unit prices. Because comparisons can produce arrays of true and false results, SUMPRODUCT can also perform compact conditional counts and sums.

All participating arrays must have compatible dimensions so corresponding positions describe the same records. Its flexibility can make a dense expression difficult to audit, so criteria and multiplication stages should remain conceptually distinct. For straightforward one- or multi-criterion totals, [[Excel Conditional Aggregation Functions]] often communicate intent more directly.
