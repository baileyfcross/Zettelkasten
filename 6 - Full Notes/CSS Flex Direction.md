# CSS Flex Direction

The `flex-direction` property chooses the main axis and its forward direction. Row and row-reverse follow the inline axis, while column and column-reverse follow the block axis.

Because inline and block directions depend on [[CSS Writing Modes and Direction]], row does not universally mean left to right. Reverse values change visual placement but do not rewrite the document's source or reading order.
