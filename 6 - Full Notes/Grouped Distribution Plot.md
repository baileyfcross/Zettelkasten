# Grouped Distribution Plot

A grouped distribution plot compares a continuous measurement across categories, often with side-by-side box plots. The outcome appears on the measurement axis and the grouping variable determines the separate visual summaries.

The graph supports decisions about group differences, spread, and possible violations of equal-variance assumptions. Category labels should use substantive names rather than raw codes so the comparison can be interpreted without consulting the data dictionary.
