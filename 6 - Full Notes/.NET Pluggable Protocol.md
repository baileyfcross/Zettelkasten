# .NET Pluggable Protocol

A .NET pluggable protocol registers a URI scheme with custom request and response implementations. Callers can then create a request from that scheme through the same framework entry point used for built-in protocols, instead of scattering protocol-specific construction code across the application.

The implementation still needs a schema, interaction rules, serialization, and a request pipeline. Registration creates a conventional abstraction around those decisions; it does not define the protocol's semantics or reliability.
