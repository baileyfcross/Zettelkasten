# User-Defined Function

A user-defined function adds a custom operation to a data-processing language when its built-in transformations are insufficient. Pig, Hive, and Spark SQL use UDFs to apply specialized record or tuple computations inside a scalable execution plan.

UDFs increase expressiveness and let high-level queries participate in complex algorithms. Their placement still affects serialization, optimization, communication, and reuse across distributed workers.
