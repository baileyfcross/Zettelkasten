# SLES for SAP Applications Stack

SLES for SAP Applications combines the SLES operating-system foundation with high-availability and management capabilities intended for SAP workloads. Its value is not one tuning flag but an integrated support and operations stack for deploying, protecting, updating, monitoring, and maintaining business-critical SAP systems.

The platform includes longer maintenance options and capabilities such as workload memory protection, live patching, Trento, and Saptune. Each addresses a different layer: availability topology, kernel maintenance, configuration assessment, or workload tuning. Using the product does not remove the need to validate the specific SAP architecture and service dependencies.
