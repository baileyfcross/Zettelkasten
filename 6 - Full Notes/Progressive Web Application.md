# Progressive Web Application

A progressive web application is a web application enhanced with browser capabilities associated with installed applications, including offline-oriented loading, background service workers, manifest metadata, and home-screen installation.

Its technical baseline includes a [[Secure Origin]], a registered [[Service Worker]] with fetch handling, minimal offline startup behavior, and a valid [[Web App Manifest]]. It remains linkable and delivered through ordinary web technologies.
