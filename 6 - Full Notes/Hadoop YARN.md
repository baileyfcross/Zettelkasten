# Hadoop YARN

Hadoop YARN separates cluster-wide resource management from the application-specific logic that schedules and monitors an individual job. A central resource manager allocates containers, while an application master coordinates one application's execution.

This separation lets the cluster support processing models beyond classic MapReduce and allows different frameworks to share the same managed resources.
