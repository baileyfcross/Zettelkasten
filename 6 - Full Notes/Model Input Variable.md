# Model Input Variable

A model input variable is an observed or derived feature intentionally supplied to a learning algorithm. Its inclusion should follow relevance, quality, availability at prediction time, and leakage checks.

Documenting the input role prevents targets, identifiers, and post-outcome fields from entering the model accidentally.
