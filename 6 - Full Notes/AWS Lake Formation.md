# AWS Lake Formation

AWS Lake Formation helps build and govern a data lake by coordinating catalog metadata and fine-grained access to registered data. Permissions can be expressed at database, table, column, row, or cell scope and reused by compatible analytical services. Central governance reduces independent bucket-policy and engine-policy management, but effective control still depends on reliable catalog structure, clear data ownership, and correctly integrated consumers.
