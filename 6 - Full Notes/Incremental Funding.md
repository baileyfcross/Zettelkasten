# Incremental Funding

Incremental funding releases capital for a project in stages tied to subprojects, evidence, or delivered capabilities. An organization can learn from early work before committing the full portfolio cost.

The sequence changes when expenses occur and when benefits begin, so it can change net present value even when the same components are eventually completed.
