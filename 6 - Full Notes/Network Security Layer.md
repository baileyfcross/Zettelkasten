# Network Security Layer

The network security layer controls and observes communication among systems. [[Firewall]] rules restrict traffic at boundaries, while an [[Intrusion Detection System]], [[Intrusion Prevention System]], and [[Security Event Monitoring]] help identify or stop suspicious behavior.

This layer is strongest when controls are distributed rather than concentrated at one perimeter. Internal segmentation and monitoring can constrain movement after an attacker or malicious program reaches the network.
