# Variational Finite Element Formulation

A variational finite element formulation converts a governing field equation into a scalar functional and seeks nodal values that make the functional stationary or minimal. Electrostatic energy provides a representative functional for Poisson and Laplace problems.

Substituting element shape functions and differentiating with respect to nodal unknowns yields element equations. The approach requires an available extremum principle consistent with the physics and boundary conditions.
