# WebAssembly Browser Execution

WebAssembly browser execution runs compiled code inside the browser's application context. Major browsers listed by the 2019 source could execute it, while older browsers such as Internet Explorer could require a JavaScript alternative.

The browser supplies a widely deployed host, which avoids installing a traditional desktop executable on every user's machine. Code still has to be downloaded and operate within browser constraints rather than gaining unrestricted access to the computer.
