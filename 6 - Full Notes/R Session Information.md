# R Session Information

R session information records the R version, platform, locale, attached packages, and package versions active during an analysis. It provides a compact environment fingerprint for diagnosing why the same code behaves differently on another machine or at a later date.

The record is most useful when saved with the analysis output and source code. It describes the loaded environment but does not by itself recreate it, so package installation sources and data provenance still need separate preservation.
