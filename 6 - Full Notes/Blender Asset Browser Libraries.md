# Blender Asset Browser Libraries

Blender's Asset Browser exposes marked objects, collections, materials, scenes, animations, images, sounds, and other reusable data through libraries. An item becomes an asset when it is marked, saved into an appropriate library, and made available through a configured library path.

Dragging assets into the viewport turns reuse into a direct scene-building operation. A current-file library supports project-local reuse, while a user library supports content that should be available across Blender files.
