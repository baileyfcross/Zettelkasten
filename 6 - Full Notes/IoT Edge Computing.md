# IoT Edge Computing

IoT edge computing performs storage, analytics, or machine intelligence on or close to the device that generates the data. It avoids sending every observation to a remote cloud before a decision can be made, which reduces latency, bandwidth use, and energy costs.

Local processing is especially important for robots, autonomous vehicles, voice controls, and safety systems that cannot wait for a network round trip. It can also improve privacy by keeping raw audio, video, or personal data on premises and transmitting only results. The tradeoff is that resource-constrained edge devices must manage limited power, storage, processing capacity, and updates.
