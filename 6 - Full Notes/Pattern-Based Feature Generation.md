# Pattern-Based Feature Generation

Pattern-based feature generation discovers structured patterns in data and converts them into dimensions for analysis or learning. The workflow separates pattern mining, pattern selection, and pattern-to-value mapping.

This separation makes the representation explicit: mining defines the candidate vocabulary, selection controls quality and size, and mapping determines how each data object is encoded.
