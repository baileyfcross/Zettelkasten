# Regression Residual Plot

A regression residual plot graphs [[Residual|residuals]] against fitted values, predictors, or theoretical quantiles. A well-specified linear model should not leave an obvious trend or systematic change in residual spread.

Curvature can indicate violation of the [[Linearity Assumption]], while a funnel shape suggests nonconstant variance. Quantile–quantile residual plots assess distributional shape, and unusual isolated points may warrant investigation for data errors or influence.
