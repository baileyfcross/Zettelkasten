# Minimum Support Threshold

A minimum support threshold is the smallest transaction fraction an itemset must reach to be treated as frequent. It controls how aggressively association-rule mining prunes rare combinations.

A high threshold can miss important uncommon patterns, while a low one can produce an overwhelming candidate set. The choice should reflect the application and database size.
