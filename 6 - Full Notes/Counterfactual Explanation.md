# Counterfactual Explanation

A counterfactual explanation describes a small change to a case that would have produced a different model decision. Instead of exposing every internal calculation, it tells an affected person which relevant condition separated the observed result from an alternative.

For a denied loan, an explanation might state that a higher income would have crossed the acceptance boundary. The explanation should use actionable and legitimate variables, remain faithful to the model, and avoid disclosing protected commercial details or implying that an ethically unacceptable decision becomes fair merely because it can be described.
