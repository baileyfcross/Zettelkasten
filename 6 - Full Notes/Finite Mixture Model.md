# Finite Mixture Model

A finite mixture model represents an observed distribution as a weighted combination of a fixed number of component distributions. The weights are positive and sum to one.

For clustering, each component is a group-specific data model. Fitting estimates its parameters and the latent memberships that best explain the observations.
