# Admittance-Type Haptic Device

An admittance-type haptic device measures the force applied by a user and responds by controlling position or movement. The device converts the sensed effort through a model of the environment into commanded motion.

This is the complementary control arrangement to an [[Impedance-Type Haptic Device]], which measures position and returns force. Admittance control can suit mechanisms that are difficult for the user to move directly, but it requires accurate force sensing and a stable motion controller so delay or noise does not turn intended resistance into unexpected motion.
