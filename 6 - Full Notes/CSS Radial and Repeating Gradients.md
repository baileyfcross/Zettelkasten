# CSS Radial and Repeating Gradients

A radial gradient changes color outward from a center through circular or elliptical rings. Its size can be given explicitly or selected with keywords that reach a chosen side or corner of the gradient box.

Repeating linear and radial gradients repeat the color-stop pattern after the final stop, producing stripes, rings, or other tiled effects without a separate image file. The interval between the first and last effective stops defines the repeated period.
