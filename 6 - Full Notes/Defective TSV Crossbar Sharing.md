# Defective TSV Crossbar Sharing

Defective TSV crossbar sharing connects several damaged vias to a smaller set of electromigration mitigation modules. TSVs are grouped, and a switching network selects which member receives a balancing operation.

Larger sharing groups save circuit area but may delay protection when several vias need service. The design therefore trades crossbar and module overhead against the maximum interval allowed between balancing actions.
