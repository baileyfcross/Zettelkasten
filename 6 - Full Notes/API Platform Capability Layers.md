# API Platform Capability Layers

An API platform can be divided into development, runtime, and engagement capabilities. The development layer supplies design tools, reusable request, security, transformation, routing, and code-generation building blocks. The runtime executes APIs with availability, throughput, latency, load balancing, connection pooling, caching, monitoring, logging, and analytics concerns.

The engagement layer manages the provider's relationship with consumers through discovery, documentation, credentials, interactive trials, onboarding, versions, rate plans, service levels, and community support. Together the layers connect develop, deploy, and publish work without requiring one product to own every capability.
