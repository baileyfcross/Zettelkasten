# Selenium Pointer Click Actions

Selenium pointer click actions reproduce common mouse-button interactions on a located element. A normal click presses and releases the primary button, a double click performs two primary clicks, and a context click uses the secondary button to invoke context-menu behavior.

The pointer is directed toward the element before the action. Tests should validate the resulting application state rather than treating successful command execution as proof that the intended behavior occurred.
