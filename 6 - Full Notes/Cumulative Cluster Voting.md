# Cumulative Cluster Voting

Cumulative cluster voting builds consensus by accumulating support for compatible cluster assignments across component solutions. Because cluster labels are interchangeable, the procedure first aligns or compares groups through membership overlap.

Repeated evidence can stabilize assignments that recur across runs. Alignment errors and dominance by many nearly identical inputs can distort the vote, so ensemble diversity and component weighting must be considered.
