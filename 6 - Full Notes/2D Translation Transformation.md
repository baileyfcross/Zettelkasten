# 2D Translation Transformation

A two-dimensional translation displaces every object point by the same vector. For a point (x, y) and displacement (tx, ty), the transformed point is (x + tx, y + ty). Distances, angles, orientation, and shape are preserved because only position changes.

In ordinary Cartesian form translation is vector addition rather than multiplication by a 2 by 2 matrix. [[2D Point Representation in Homogeneous Coordinates]] adds a constant coordinate so the translation can be represented by matrix multiplication and composed with scaling, rotation, reflection, and shear in one ordered product.
