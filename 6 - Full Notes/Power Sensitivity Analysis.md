# Power Sensitivity Analysis

A power sensitivity analysis repeats a power or sample-size calculation across a range of plausible effect sizes. It shows how strongly the design requirement depends on an uncertain assumption instead of presenting one number with false precision.

The sequence should remain within values that the statistical function can evaluate and that the science can defend. Automation can calculate every scenario, but the resulting curve or table still needs an explanation of which effects would be practically meaningful.
