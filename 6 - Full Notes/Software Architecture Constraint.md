# Software Architecture Constraint

A software architecture constraint limits the set of designs that can satisfy a system. Required platforms, regulations, deadlines, budgets, integration protocols, deployment environments, and measurable quality targets can all constrain the architecture.

Constraints should be recorded explicitly because they explain why a locally attractive option was rejected. Treating an assumption as a permanent constraint can unnecessarily narrow the solution, so each one needs a source and a reason.
