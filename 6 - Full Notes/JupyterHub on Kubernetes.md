# JupyterHub on Kubernetes

JupyterHub on Kubernetes gives each authenticated experimenter an isolated notebook pod with controlled images, storage, CPU, memory, and accelerator access. The platform can standardize dependencies while allowing interactive data exploration and model development.

A notebook is an experimentation surface, not a production pipeline. Its code, environment, data references, parameters, and outputs must move into version control and durable artifact storage before a result can be repeated or reviewed.
