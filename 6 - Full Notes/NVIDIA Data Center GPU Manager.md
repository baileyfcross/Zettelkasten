# NVIDIA Data Center GPU Manager

NVIDIA Data Center GPU Manager, or DCGM, is an enterprise toolkit for managing and monitoring NVIDIA GPUs across individual nodes, clusters, containers, and MIG-enabled systems. It provides discovery, real-time telemetry, diagnostics, health information, and interfaces for automation.

DCGM is an operational data source rather than only a dashboard. Its [[DCGM Host Engine]] can serve command-line, API, policy, and exporter clients, allowing the same device evidence to support troubleshooting, fleet planning, health gates, and long-term Prometheus monitoring.
