# Network Level Layout

A network level layout connects spaces through several branching paths. It gives players substantial freedom to choose routes and can make learning the environment part of the challenge.

The freedom reduces control over event order, so stories and dependencies must tolerate multiple sequences or use selected gates. Choke points should be deliberate because they concentrate movement and conflict.
