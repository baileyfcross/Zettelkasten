# Blender Render Output Settings

Output Properties determine how a rendered image or animation is stored. They include the destination path, image dimensions, frame range, and file format.

Blender retains a render internally at high quality and applies the chosen file encoding when saving. Selecting the output format before rendering provides access to format-specific controls and makes automated animation output predictable.
