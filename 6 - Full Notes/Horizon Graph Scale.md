# Horizon Graph Scale

A horizon graph scale determines the magnitude boundaries mapped to successive color bands. A common scale supports comparison among panels because the same intensity means the same deviation everywhere. Panel-specific scales expose each series' internal variation but prevent direct magnitude comparison. The choice must match the question and be stated clearly, because the compact encoding of a [[Horizon Graph]] makes an unnoticed scale change especially misleading.
