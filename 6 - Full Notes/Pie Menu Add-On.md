# Pie Menu Add-On

Pie menus arrange context-sensitive commands radially around the pointer. Directional movement selects an option, making frequent choices such as changing object modes accessible through a gesture instead of a linear menu search.

The advantage depends on stable spatial positions: repeated use builds motor memory for a direction. A crowded or frequently rearranged pie weakens that benefit, so the menu is best reserved for a small set of high-frequency alternatives.
