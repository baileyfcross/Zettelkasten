# MATLAB Numeric Format

A MATLAB numeric format controls how numbers are displayed, such as short decimal or scientific notation. Changing the format does not change the stored numerical value.

This distinction matters when assessing error: a displayed value may show fewer digits than are retained internally, while actual calculations remain subject to floating-point precision.
