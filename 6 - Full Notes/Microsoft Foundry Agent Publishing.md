# Microsoft Foundry Agent Publishing

Microsoft Foundry agent publishing turns a configured agent version into a deployable interface with an endpoint and identity. The published asset includes the chosen model, instructions, tools, workflows, knowledge sources, memory settings, safety configuration, and other versioned behavior.

Publishing is not the same as broad user availability. Distribution through Teams or Microsoft 365 Copilot can require an additional administrative approval and user-group assignment. The published agent may also use a different runtime identity from the developer who tested it, so every external tool and data connection must be authorized again for that identity before release.
