# VPC Endpoint

A VPC endpoint lets resources reach a supported service privately without sending traffic through an internet gateway or NAT device. Interface endpoints create elastic network interfaces and use [[AWS PrivateLink]], while gateway endpoints add route-table targets for Amazon S3 and DynamoDB. Endpoint policies, security groups, route tables, and private DNS determine which resources can use the path and which service actions are allowed.
