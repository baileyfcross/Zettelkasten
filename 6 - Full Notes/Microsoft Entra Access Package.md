# Microsoft Entra Access Package

A Microsoft Entra access package is a governed bundle of resources—such as group membership, application roles, and SharePoint access—that a user can request as one unit. The package belongs to a catalog, which limits which resources and administrators participate in that access program.

One or more policies define who may request the package, whether approval and justification are required, how long access lasts, and whether a review recertifies it. A package can therefore express the access needed for a project, department, or partner relationship rather than forcing requestors to discover each resource separately. The bundle should remain focused: unrelated resources with different owners or review cadences belong in different packages under [[Microsoft Entra Entitlement Management]].
