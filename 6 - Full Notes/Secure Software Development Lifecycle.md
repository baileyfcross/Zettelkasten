# Secure Software Development Lifecycle

A secure software development lifecycle integrates security into requirements, architecture, implementation, testing, deployment, and maintenance. It treats protection as a continuing design concern rather than a final test performed after the application is complete.

Practices such as [[Security Architecture Analysis]], [[Security Code Review]], and [[Penetration Testing]] reveal different classes of weakness. Addressing problems early generally reduces both exposure and the cost of correction.
