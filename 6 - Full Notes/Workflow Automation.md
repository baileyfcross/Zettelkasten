# Workflow Automation

Workflow automation uses software and services to carry out repeatable process steps, transfer information, trigger later work, and check conditions with less manual coordination. A workflow can still contain human decisions where judgment or approval is required.

Automation improves consistency and scalability when the process and interfaces are well defined. Automating a redundant or poorly designed step can instead make the same waste occur faster, which is why process analysis should precede implementation.
