# Azure AI Architecture Map

The Azure AI Architecture Map organizes artificial-intelligence workloads around model consumption, orchestration, grounding data, search, safety, observability, and application integration. It treats generative AI as a system rather than a single model endpoint: prompts, embeddings, retrieval, tools, agents, gateways, and governance all become architectural concerns. The map is a decision aid, so its value lies in exposing capabilities and tradeoffs before selecting Azure services.
