# Unit Conversion Factor

A conversion factor is a ratio between compatible unit scales. Written with both units, it can be multiplied by a measured value so the starting unit cancels and the desired unit remains. For example, the book uses $0.3048\ \mathrm{m/ft}$ to convert a feet-per-second value into meters per second: the feet cancel, and the seconds are unchanged. The orientation of the ratio matters even when its number is familiar. See [[Reciprocal Conversion Factors]] and [[Physical Quantity as Value and Unit]].
