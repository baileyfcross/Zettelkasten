# JavaScript Destructuring Assignment

JavaScript destructuring assignment extracts selected object fields or array positions into local bindings. An object pattern declares which named fields a function intends to use, while an array pattern can take the first item, skip positions with commas, or separate a leading value from the remainder.

Destructuring a function parameter makes the required inputs visible at the function boundary. It also combines with [[JavaScript Spread Operator|rest and spread syntax]] to split one item from the remaining collection without manually indexing every value.
