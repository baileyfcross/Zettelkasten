# Operating System Shell

An operating system shell accepts user commands, interprets its own language constructs, and starts programs that request services from the kernel. On Linux and Unix-like systems, Bash, zsh, and other shells can serve both as interactive command environments and as interpreters for saved scripts.

The shell is not the terminal and is not the kernel. The terminal presents input and output, while the shell performs parsing, expansion, redirection, and process launch. Choosing an interpreter therefore determines which syntax and built-in capabilities a script may safely use.
