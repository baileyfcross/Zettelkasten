# Similarity Graph for Spectral Clustering

A similarity graph represents observations as vertices and retains weighted edges between nearby or sufficiently similar pairs. It converts geometric data into a relational object on which spectral clustering operates.

Common constructions include full, epsilon-neighborhood, and k-nearest-neighbor graphs. Edge scale, connectivity, and weight function strongly affect the Laplacian spectrum, so graph construction is part of the clustering model rather than mere preprocessing.
