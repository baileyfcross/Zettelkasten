# Density-Based Uncertain Classification

Density-based uncertain classification estimates class support around a test object while accounting for probability distributions over locations. Nearby probability mass contributes more evidence than distant mass.

This generalizes a point-based local density estimate to uncertain observations. The kernel scale and uncertainty model jointly determine which training cases influence the decision, so excessive smoothing can erase real class boundaries.
