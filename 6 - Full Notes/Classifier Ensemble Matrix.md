# Classifier Ensemble Matrix

A classifier ensemble matrix visualizes the predictions or errors of multiple classifiers across many observations. Rows and columns align models, cases, labels, or confidence so that agreement and disagreement become visible patterns.

Sorting and linked views can reveal redundant classifiers, difficult cases, and complementary error regions. The matrix is most informative when the visual encoding distinguishes correct consensus from unanimous shared failure.
