# Convention over Configuration

Convention over configuration lets a framework infer ordinary behavior from established names and structures, requiring explicit settings only when a model differs from those defaults. This reduces repetitive setup while preserving an escape path for exceptional cases.

[[Entity Framework Core]] uses conventions to recognize entity keys and relationships. [[Data Annotation|annotations]] or model-building code can then override or extend those inferred mappings.
