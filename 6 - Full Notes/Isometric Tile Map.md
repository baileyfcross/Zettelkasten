# Isometric Tile Map

An isometric tile map arranges diamond-shaped tiles so a two-dimensional image suggests a three-dimensional angled view. Grid coordinates must be transformed into slanted screen coordinates rather than mapped directly to horizontal and vertical pixels.

The underlying level can still use a regular tile grid, but rendering order and coordinate conversion must preserve the apparent depth relationship among tiles and objects.
