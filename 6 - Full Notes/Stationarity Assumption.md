# Stationarity Assumption

Training on historical records implicitly assumes that the learned relationships will remain useful when the model meets future cases. This is the stationarity assumption. It can fail when customers, incentives, policies, measurement systems, or other features of the domain change.

An evaluation on held-out historic data is therefore a necessary but incomplete check. A deployed model needs monitoring for changing inputs and outcomes so the organization can revisit its data, target, and model when the underlying process no longer resembles the past.
