# CSS Text Alignment

The `text-align` property controls the inline-axis alignment of content within a block container. Values can align lines to a physical side, center them, justify them, or use start and end directions that follow the writing mode.

Alignment applies to inline content inside the block rather than moving the block box itself. `text-align-last` can separately control the final line of a block or a line immediately before a forced break.
