# Game Difficulty

Game difficulty is the demand a game places on a player's current skill and understanding. It can arise from timing, prediction, coordination, strategy, endurance, or the need to learn relationships within the system.

Increasing difficulty is one possible shape for a game, not a universal measure of quality. A challenging experience can build confidence through mastery, while other games use [[Game Resistance|resistance]] to support reflection, exploration, or listening rather than conquest.
