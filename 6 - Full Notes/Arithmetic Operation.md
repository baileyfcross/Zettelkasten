# Arithmetic Operation

An arithmetic operation combines or transforms numbers according to a defined rule. The elementary operations are addition, subtraction, multiplication, division, exponentiation, and root extraction.

Some operations can be defined through earlier ones. Subtraction finds the value that must be added to recover a minuend, division finds the value that must be multiplied by a divisor, exponentiation abbreviates repeated multiplication, and a root reverses a power. Which results are allowed depends on the number system: natural numbers are closed under addition and multiplication but not under every subtraction or division.
