# JavaScript Template Literal

A JavaScript template literal uses backticks to combine text with evaluated expressions written as `${...}`. Any expression that returns a value can be inserted, replacing chains of string concatenation with one readable string template.

Template literals preserve spaces and line breaks, so they can represent formatted messages or markup across several source lines. They pair naturally with [[JavaScript Destructuring Assignment]] when a function first extracts the values that a template will display.
