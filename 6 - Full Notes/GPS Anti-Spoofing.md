# GPS Anti-Spoofing

GPS anti-spoofing protects an authorized military ranging service by encrypting the precise code so that an adversary cannot easily imitate it. A receiver without the required keys cannot reproduce and authenticate the protected sequence in the same way. Anti-spoofing addresses acceptance of false signals, whereas [[Selective Availability]] reduced the accuracy of the open service; the two mechanisms therefore pursued different security goals.
