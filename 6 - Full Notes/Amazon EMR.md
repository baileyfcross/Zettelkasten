# Amazon EMR

Amazon EMR provides managed environments for big-data frameworks such as Apache Hadoop and Apache Spark. It provisions and configures compute resources so distributed jobs can process large datasets, commonly with source and result data stored in Amazon S3.

EMR suits customizable, framework-based processing that may involve complex transformations or long-running clusters. [[Amazon Athena]] offers a simpler serverless option for interactive SQL, while EMR exposes more control over the processing engine and cluster configuration.
