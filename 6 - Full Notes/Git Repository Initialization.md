# Git Repository Initialization

`git init` creates Git repository metadata for an existing directory. The new `.git` directory holds the object database, references, configuration, and other information required to record history locally.

Initialization does not automatically create a commit from every file. The developer still reviews the working tree, stages intended paths, and creates the first snapshot.
