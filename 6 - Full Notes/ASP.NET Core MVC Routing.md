# ASP.NET Core MVC Routing

MVC routing maps an incoming request's path and HTTP method to a controller action. Conventional routes interpret segments through a shared pattern, while attribute routes place route templates directly on controllers and actions.

Route design forms part of an application's public interface. Specific patterns, constraints, and ordering should avoid ambiguous matches and should produce stable, meaningful URLs independent of internal implementation details.
