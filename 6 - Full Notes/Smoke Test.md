# Smoke Test

A smoke test is a fast, broad check that a build loads and begins running without an immediate critical failure. For a multiplatform game, the check is performed on every supported platform and relevant build configuration.

It supplies a cheap gate before slower tests or playthroughs. Passing proves basic viability, not full correctness or playability.
