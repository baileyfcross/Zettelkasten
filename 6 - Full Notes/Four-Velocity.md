# Four-Velocity

Four-velocity is the derivative of [[Four-Position]] with respect to [[Proper Time]]. For ordinary three-velocity $\mathbf{v}$, it can be written

$$U=\gamma(c,\mathbf{v})$$

when the time component is listed first.

Its components change between inertial frames, but its Minkowski norm is constant: $U\cdot U=c^2$ with the time-positive convention. This constancy expresses that four-velocity changes direction in spacetime under acceleration without acquiring an arbitrary Minkowski magnitude.

The source describes this geometrically as all massive observers having the same magnitude of motion through spacetime, with different ordinary velocities corresponding to different directions. Differentiating $U$ with respect to proper time yields [[Four-Acceleration]].
