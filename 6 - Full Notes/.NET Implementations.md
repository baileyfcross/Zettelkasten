# .NET Implementations

At the time covered by the source, Microsoft's .NET ecosystem included .NET Framework for established Windows applications, .NET Core for new cross-platform applications, and Xamarin for mobile platforms. Mono provided another open implementation and contributed technology to these efforts.

These implementations offered overlapping APIs but different platform capabilities. [[.NET Standard]] defined a shared API contract so libraries could target a level implemented by several runtimes instead of binding to only one product.
