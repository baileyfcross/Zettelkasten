# Feature Transformation Function

A feature transformation function maps one or more existing variables to a derived variable. Unary functions operate on one input, binary functions combine two inputs, and compositions create deeper transformations.

The available functions form the grammar of automated feature construction. Type compatibility and semantic constraints prevent meaningless candidates, while composition depth controls expressiveness and search growth.
