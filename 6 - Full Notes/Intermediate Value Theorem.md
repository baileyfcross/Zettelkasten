# Intermediate Value Theorem

If a real-valued function is continuous on $[a,b]$, then it takes every value between $f(a)$ and $f(b)$. Thus, for any intermediate value $v$, some $c$ in $(a,b)$ satisfies $f(c)=v$. A sign change across the endpoints therefore guarantees at least one zero inside the interval.
