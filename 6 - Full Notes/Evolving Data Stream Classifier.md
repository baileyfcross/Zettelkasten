# Evolving Data Stream Classifier

An evolving data stream classifier adapts when the relationship between features and labels changes over time. Recent examples must influence the model more strongly when older patterns no longer describe the current process.

Adaptation can use sliding windows, fading weights, change detectors, or replacement of model components. A learner that adapts too slowly preserves stale concepts, while one that adapts too quickly mistakes random variation for genuine drift.
