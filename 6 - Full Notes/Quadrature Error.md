# Quadrature Error

Quadrature error is the difference between a definite integral and the value returned by a [[Quadrature Formula]]. For interpolation-based rules, the leading error contains a higher derivative of the integrand and a power of the mesh width.

The composite [[Trapezoidal Rule]] has an $O(h^2)$ error, while the composite [[Simpson One-Third Rule]] has an $O(h^4)$ error under suitable smoothness. Error estimates justify mesh refinement and make extrapolation possible.
