# LLM Supply Chain Security

LLM supply chain security protects the data, model weights, adapters, code, dependencies, registries, endpoints, prompts, and deployment artifacts used to build and operate a language-model system. Tampering at any stage can alter model behavior or introduce executable compromise.

Controls include provenance, integrity verification, dependency review, restricted publishing, reproducible configuration, vulnerability scanning, and monitored promotion. Third-party models and datasets require the same trust analysis as software packages plus attention to embedded learned behavior.
