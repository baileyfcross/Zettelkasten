# Microsoft Foundry AI Cost Planning

Microsoft Foundry AI cost planning estimates the combined expense of the Azure services behind an application. Model tokens, search, storage, compute, networking, monitoring, and optional services can each use different prices, quotas, regions, and billing units even when the Foundry portal itself is available to explore.

Planning begins before deployment with expected request volume, prompt and response size, model choice, retrieval traffic, and regional configuration. The Azure Pricing Calculator can combine services and produce scenario estimates, while production dashboards reveal actual token use and agent cost. A technically valid design remains incomplete if its usage pattern cannot be sustained economically.
