# Security Container

A security container is a boundary around users, systems, software, storage, backups, and other elements that share the same security requirements. Components inside the boundary are permitted to trust one another according to the container's policy.

Network segmentation and virtual networks can isolate one container from another, while firewalls control crossings. Identification, [[Authentication]], and [[Authorization]] then determine who may enter and what an accepted user may do.
