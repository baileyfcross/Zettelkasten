# Vertical Angles

Vertical angles are the opposite angles formed when two lines intersect. Each angle forms a linear pair with the same adjacent angle, so both are supplements of that shared angle and are therefore equal. This basic equality supports angle chasing in constructions involving intersecting lines and polygons.
