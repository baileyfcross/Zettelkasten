# Roblox TweenService

TweenService changes supported object properties smoothly over a chosen duration according to an easing style and direction. A tween can animate a part's CFrame, a GUI element's transparency, or another interpolable property without writing a manual frame-by-frame loop.

The script defines TweenInfo, supplies a goal-property table, creates the tween for a target instance, and plays it. Completion signals can sequence later actions. Tweens are best for bounded transitions with known endpoints; continuously responsive movement such as a camera following live input is better handled with [[Roblox Render Step Camera Update]].
