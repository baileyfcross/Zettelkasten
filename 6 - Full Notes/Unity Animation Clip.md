# Unity Animation Clip

A Unity Animation Clip is an asset that records how selected properties change over time. Clips can come from imported character animation, sequential 2D sprites, or keyframes authored directly in Unity.

The clip contains motion data but does not by itself decide when gameplay should use that motion. An [[Unity Animator Controller]] places clips into states and transitions, while Timeline can sequence clips for directed events. Keeping clips focused makes them easier to loop, blend, and reuse.
