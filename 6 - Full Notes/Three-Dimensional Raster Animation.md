# Three-Dimensional Raster Animation

A three-dimensional raster animation renders each time layer as a surface and plays the surfaces sequentially in an interactive 3D scene. Common horizontal and vertical scales are required so changes reflect data rather than automatic rescaling. Rotation and zoom can expose shape, but perspective and occlusion complicate comparison. A two-dimensional [[Raster Map Animation]] remains a useful companion for reading geographic position and color consistently.
