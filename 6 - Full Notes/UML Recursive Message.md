# UML Recursive Message

A UML recursive message is a self message in which an operation invokes itself. The diagram shows a new nested activation on the same lifeline, making the recursive level distinct from the currently active call.

The notation highlights control nesting rather than the full data structure of the recursion. A useful diagram also indicates the condition or progression that eventually reaches the base case.
