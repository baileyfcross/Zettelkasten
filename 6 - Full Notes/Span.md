# Span

The span of a set of vectors is the collection of all their [[Linear Combination|linear combinations]]. It is the smallest [[Vector Subspace]] containing those vectors.

A set spans a vector space when every vector in the space can be expressed from it. A spanning set that is also linearly independent is a [[Basis]].
