# AWS Directory Service

AWS Directory Service supplies managed directory options for workloads that depend on Microsoft Active Directory or compatible directory access. It can support domain-aware applications, Windows workloads, and integration with an existing on-premises directory.

Directory integration is different from assigning IAM permissions to AWS APIs. The design must keep workforce directory authentication, application authorization, and AWS role assumption as explicit boundaries even when they share a sign-on experience.
