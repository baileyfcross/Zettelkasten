# CSS Progressive Enhancement

CSS progressive enhancement begins with a usable baseline and adds presentation when the user agent supports a newer capability. A float or inline-block layout can remain in place, for example, while a [[CSS Feature Queries|feature query]] replaces it with grid rules in supporting browsers.

The unsupported block is skipped rather than breaking the baseline. This makes advanced layout and effects optional layers instead of prerequisites for accessing the document.
