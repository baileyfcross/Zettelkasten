# API Change Log

An API change log records externally visible additions, modifications, fixes, and removals by version and date. It gives consumers a concise history from which they can identify whether a release changes the contract they depend on.

The book's governance example separates added behavior from changed error handling. Useful entries describe consumer impact and point to migration details rather than merely listing internal commits that do not alter public behavior.
