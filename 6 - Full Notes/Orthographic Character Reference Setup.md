# Orthographic Character Reference Setup

Orthographic character reference setup places aligned front and side drawings on image empties facing their corresponding viewport axes. Reduced opacity, back-depth display, and axis-limited visibility allow geometry to be compared with the drawings without the images blocking selection or appearing from the wrong side.

Reference objects should be centered, scaled against a shared feature, named, and placed in a collection that can be hidden or made unselectable. Because two-dimensional views can contradict one another, the setup supplies proportional guides rather than a demand that the model match every line exactly.
