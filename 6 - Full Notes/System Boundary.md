# System Boundary

A system boundary distinguishes the parts included in a system from its environment. In a complex system, the boundary is often recognized through a dense cluster of local interactions rather than imposed as an arbitrary line.

A practical test is whether something can materially change the behavior of the whole: if it can, it may belong inside the boundary under study. Because systems are nested in a [[System Hierarchy]], a useful boundary changes with the level and question being examined.
