# Phase Space Trajectory

A phase space represents the instantaneous state of a dynamical system using its variables as coordinates. As time evolves, the system traces a trajectory whose geometry records the evolution without requiring time to be drawn as a separate axis.

Fixed points appear where all rates of change vanish, while closed curves can represent periodic motion. The arrangement of nearby trajectories reveals stability and makes nonlinear behavior, including attraction, repulsion, and more complicated long-term motion, visible.
