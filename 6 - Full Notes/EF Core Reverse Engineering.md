# EF Core Reverse Engineering

EF Core reverse engineering reads an existing database schema and generates an initial code model and context. It provides a database-first starting point when tables already exist or are managed outside the application.

The book describes the EF Core 3 workflow as one-way: after scaffolding, the code model becomes the continuing source from which later schema changes are produced. It is not a permanent round-trip synchronization between a visual or database model and source classes.
