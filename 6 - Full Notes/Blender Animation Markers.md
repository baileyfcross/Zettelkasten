# Blender Animation Markers

Blender animation markers label whole-number frames that contain significant events, such as a pose change, camera switch, lighting cue, or beginning of an action. Unlike keyframes, a marker does not store an animated property value; it supplies a named temporal reference shared by animation editors.

Markers can be added, renamed, moved, duplicated, deleted, and used as snapping or mirroring targets. A selected camera can also be bound to a marker so the active shot changes at that frame. Clear names turn the timeline into a readable plan and help coordinate keys, edits, and camera decisions around the same event structure.
