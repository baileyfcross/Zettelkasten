# MicroProfile Reactive Messaging

MicroProfile Reactive Messaging specifies asynchronous interaction among services and resources for event-driven microservices. It connects message-producing and message-consuming components while relying on the semantics supplied by Reactive Streams Operators.

The specification separates the application-facing messaging model from the lower-level stream rules. Application developers use supported messaging facilities, while third-party stream libraries handle the strict thread-safety and stream-control behavior that is difficult to implement correctly from scratch.
