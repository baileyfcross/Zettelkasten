# Testing Pyramid

A testing pyramid layers many fast, narrow automated checks beneath fewer slow, broad playthroughs. Build configuration checks, unit and asset validation, smoke tests, level loads, automated playthroughs, and human QA provide progressively wider evidence.

Lower tiers run more frequently and block bad builds early. Higher tiers remain necessary because integrated game behavior and player experience cannot be inferred from component tests alone.
