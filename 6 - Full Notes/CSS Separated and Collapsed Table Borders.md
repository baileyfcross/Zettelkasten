# CSS Separated and Collapsed Table Borders

The separated table-border model gives each cell its own border and can insert space between adjacent cells with `border-spacing`. Empty-cell behavior can determine whether an empty cell's border and background are shown.

The collapsed model merges adjoining borders into shared lines. Conflict rules choose a winning style, width, and source when cell, row, column, group, and table borders meet.
