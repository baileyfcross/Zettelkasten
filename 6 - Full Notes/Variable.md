# Variable

A variable is a symbol, usually a letter, used to represent a number without fixing one numerical value in the expression. It permits [[Mathematical Generality]] because a relationship written with (a) and (b) can apply to every allowed pair rather than requiring a list of examples.

A variable can play different roles. It may denote an arbitrary value in an [[Algebraic Identity]], an input assigned during [[Substitution]], or an [[Unknown Variable]] whose value must be found from an equation. Its written sign does not reveal the sign of its value; (-x) is positive whenever (x) is negative.
