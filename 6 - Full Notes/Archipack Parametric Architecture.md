# Archipack Parametric Architecture

Archipack creates parametric architectural elements including walls, floors, roofs, doors, windows, stairs, fences, and trusses. Dimensions and other parameters remain editable through its controls, allowing the modeled building parts to be revised interactively.

This is valuable during architectural iteration because a generated element remains a system of measurements rather than becoming only a fixed mesh. The add-on therefore trades some manual freedom for speed and repeatable control.
