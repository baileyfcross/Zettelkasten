# Cloud Service Integration

Cloud service integration coordinates several delivered services so that they form a consistent portfolio for a business. It connects providers with one another and connects their services to the organizational units that consume them.

Integration includes more than exchanging application data. Contracts, service levels, identity, monitoring, reports, and bills may also need common forms so the combined service can be operated and evaluated as a whole.
