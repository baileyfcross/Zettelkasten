# Hamming Distance

The Hamming distance between two equal-length words is the number of coordinates at which they differ. For a linear code, the minimum nonzero distance between codewords determines how much corruption can be distinguished.

A minimum distance of three permits correction of one coordinate error: a corrupted word can be associated with the unique codeword within distance one, provided the code has that separation.
