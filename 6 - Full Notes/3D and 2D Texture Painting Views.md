# 3D and 2D Texture Painting Views

Blender can paint an image through the textured 3D mesh in the Viewport or directly on the flattened canvas in the Image Editor. Both views modify the same pixels through the active UV mapping.

The 3D view provides surface context and hides much of the island fragmentation, while the 2D view exposes seams, padding, and exact image placement. Moving between them helps separate appearance on the object from organization in texture space.
