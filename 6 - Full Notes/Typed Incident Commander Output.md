# Typed Incident Commander Output

Typed incident commander output maps final synthesis into a defined result object rather than free-form prose. Required fields can include the incident identifier, executive summary, likely cause, immediate action, rollback recommendation, validation plan, and stakeholder message.

Application code checks every required field before printing, storing, or publishing the incident packet. A typed response improves parsing but does not prove factual accuracy; it establishes structural completeness so later evaluation can focus on grounding, safety, and operational usefulness.
