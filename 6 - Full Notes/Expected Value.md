# Expected Value

Expected value evaluates an uncertain choice by multiplying each possible outcome's value by its probability and summing the results. It provides a common numerical basis for comparing branches whose payoffs and likelihoods differ.

The calculation is a model, not a complete description of human preference. [[Risk Attitude]], diminishing marginal utility, and [[Loss Aversion]] can make people choose differently from a strict expected-value maximizer even when the probabilities are known.
