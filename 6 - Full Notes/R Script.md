# R Script

An R script is a plain-text sequence of R expressions saved so the calculation can be rerun, corrected, and shared. Unlike a transient console history, the script can place object creation, functions, graphs, and checks in a deliberate order that documents how the result was produced.

A useful script starts from declared inputs and can run from top to bottom in a clean session. Descriptive filenames and comments make it easier to locate the scientific purpose without treating the code as a substitute for the explanation of the model.
