# Roto-Gradient Depth Maps for Stereo

To convert a single photographed view into stereo, separate foreground and background regions and assign them a grayscale depth description. The book creates a performer map with layered roto shapes filled by gradients: darker values represent farther features and lighter values closer ones. In motion, the shapes must follow each scene element rather than describe only one still frame. Avoid pure black and white so later grade adjustments have room to change the depth. The map then drives [[2D Displacement for Stereo Conversion]] or [[Rubber-Sheet Stereo Conversion]].
