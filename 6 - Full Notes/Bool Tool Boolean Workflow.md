# Bool Tool Boolean Workflow

Bool Tool packages Boolean modifier operations into a faster object-level workflow. Auto Boolean applies the result immediately, while Brush Boolean preserves the cutting object and modifier so its position and effect remain editable until the result is applied.

Wireframe display for the cutter makes an architectural opening easier to position and inspect. The distinction between immediate and brush operations is a choice between a quick destructive result and a controllable nondestructive relationship.
