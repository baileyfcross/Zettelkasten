# Excel Formula

An Excel formula is an expression entered in a cell to calculate a result. It begins with an equals sign and may combine constants, arithmetic operators, cell references, ranges, and functions. Excel follows the usual precedence rules, so parentheses are useful whenever the intended order should be unmistakable.

A formula is valuable because its result recalculates when referenced inputs change. This turns a worksheet from a static table into a model whose outputs depend on defined inputs. A clear formula keeps those dependencies visible and uses references instead of repeatedly typing values that belong elsewhere in the workbook.
