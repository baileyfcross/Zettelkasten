# Intel Xeon Phi

Intel Xeon Phi is a many-core coprocessor architecture designed for highly parallel numerical workloads. Many x86-compatible cores and wide vector units let suitable programs accelerate computation while using familiar programming models.

Neural-network training must provide enough parallel work and locality to offset data movement, thread management, and synchronization on the device.
