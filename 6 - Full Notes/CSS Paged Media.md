# CSS Paged Media

Paged media divides a document into discrete page boxes instead of one continuous viewport. Content flows from one page to the next, and CSS can influence page dimensions, margins, named pages, breaks, and how fragments appear at page boundaries.

The model applies to printing and other page-oriented output. Fixed-position content can repeat on each page, while ordinary flow is fragmented across the available page areas.
