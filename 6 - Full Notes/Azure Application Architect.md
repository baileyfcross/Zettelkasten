# Azure Application Architect

An Azure application architect shapes maintainable application code and its integration with Azure services and SDKs. The role applies design principles, patterns, and business boundaries while accounting for horizontal scaling, distributed messaging, managed identity, and service behavior. Cloud-native application architecture therefore extends beyond code structure: the application must be multi-instance aware and must treat managed platform capabilities as explicit contracts.
