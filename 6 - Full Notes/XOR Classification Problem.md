# XOR Classification Problem

The XOR classification problem assigns one class when two binary inputs differ and another when they match. Its positive and negative cases cannot be separated by one straight decision boundary.

XOR demonstrates the limit of a single perceptron. Hidden layers combine several linear boundaries to represent the required nonlinear separation.
