# Amazon RDS Proxy

Amazon RDS Proxy is a managed database proxy that pools and reuses connections to supported RDS and Aurora databases. It protects the database from connection storms created by rapidly scaling or short-lived application workers and can improve failover behavior by preserving the application-facing endpoint. The proxy does not optimize inefficient SQL; transaction pinning, authentication, pool sizing, and database capacity still matter.
