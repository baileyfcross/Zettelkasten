# .NET String Operations

A .NET string is an immutable sequence of characters. Its members report length, retrieve characters, split on delimiters, find content, extract substrings, join sequences, and format values into text.

Because strings are immutable, an operation returns a new string rather than altering the original instance. A chain of repeated concatenations can therefore allocate many temporary values; [[StringBuilder]] provides a mutable buffer when text is assembled incrementally.
