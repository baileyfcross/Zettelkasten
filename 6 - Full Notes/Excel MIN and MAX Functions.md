# Excel MIN and MAX Functions

Excel MIN returns the smallest numeric value in a set, while MAX returns the largest. They summarize the endpoints of a dataset and can operate on individual arguments, ranges, or combinations of both. Text and empty cells in referenced ranges do not contribute numeric values.

An extremum is a value, not automatically the identity of the record containing it. To retrieve a related label, a worksheet can find the extremum and use [[Excel INDEX and MATCH Lookup]] to locate the corresponding row. When only records meeting criteria should qualify, [[Excel Conditional Extrema Functions]] provides a more direct calculation.
