# C# Abstract Class

An abstract class is a non-instantiable base class that can contain both implemented members and abstract members without implementations. A derived concrete class must override the inherited abstract members before it can be instantiated.

An abstract class is useful when related types need a shared implementation and a required extension point. Unlike an interface, it can hold class state and ordinary method bodies, but a class can inherit from only one base class.
