# Module Homomorphism

A module homomorphism is a map f: M → N that preserves addition and scalar multiplication. It sends a linear combination r₁m₁ + r₂m₂ to r₁f(m₁) + r₂f(m₂).

Kernels and images of module homomorphisms are [[Submodule]]s. Families of these maps form [[Exact Sequence]]s, and all maps from M to N together form the [[Hom Module]].
