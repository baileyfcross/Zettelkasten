# Host Security Layer

The host security layer protects individual computers and devices through hardened configuration, timely updates, malware defenses, logging, and [[Operating System Security]]. It limits what can run, which resources a process can reach, and how an event on one host can affect others.

Host controls remain necessary even behind a protected network boundary. Portable devices, compromised credentials, and permitted traffic can all bypass perimeter assumptions.
