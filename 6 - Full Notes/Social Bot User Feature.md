# Social Bot User Feature

A social bot user feature derives from profile and account attributes such as age, description, counts, or interface settings. These variables summarize how an account presents itself and its accumulated platform activity.

User features are inexpensive and interpretable, but sophisticated bots can imitate normal profiles. They are strongest when combined with behavioral and relational evidence.
