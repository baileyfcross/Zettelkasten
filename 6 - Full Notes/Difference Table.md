# Difference Table

A difference table arranges tabulated function values beside their first, second, and higher finite differences. Forward tables align leading differences with the first entry, while backward and central tables use different index placements.

The table exposes regularity in the data. Constant $n$th differences indicate a polynomial of degree $n$ on an equally spaced grid, and inconsistent entries can be used to locate a [[Missing Term in a Difference Table]] or assess error propagation.
