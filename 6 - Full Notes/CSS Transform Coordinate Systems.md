# CSS Transform Coordinate Systems

CSS transforms operate in a coordinate system attached to an element. The horizontal x-axis and vertical y-axis define the two-dimensional plane, while a z-axis extends toward and away from the viewer for three-dimensional transforms.

Transform functions are combined into a matrix and applied in written order, so changing their sequence can change the result. [[CSS Transform Origin]] determines the point around which the combined transformation acts.
