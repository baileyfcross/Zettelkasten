# Top-N Drug-Target Validation

Top-N drug-target validation ranks unknown pairs by predicted interaction probability and checks how many of the highest-ranked pairs appear in independent interaction databases. It tests whether the model produces a useful shortlist rather than only a favorable aggregate discrimination score.

The outcome depends on database coverage: absence from the reference still does not prove noninteraction. Top-N confirmation should therefore guide experiments, not replace biological validation.
