# CSS Positioning Schemes

The CSS `position` property selects how a box is placed and how its offset properties are interpreted. Static positioning follows normal flow, while relative, absolute, fixed, and sticky positioning introduce different relationships to the original position, containing block, or viewport.

Positioning can make boxes overlap and can establish containing blocks for descendants. [[CSS Stacking Order]] then determines the painting order of positioned elements that occupy the same area.
