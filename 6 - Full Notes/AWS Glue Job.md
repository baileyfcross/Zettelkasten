# AWS Glue Job

An AWS Glue job executes managed extract, transform, and load code against cataloged or directly connected data sources. A job can read raw data, clean or join records, change formats, and write prepared datasets to a target such as Amazon S3. Worker type and count determine available compute, while bookmarks can track previously processed input. The job definition should make transformations, retry behavior, and output partitioning reproducible.
