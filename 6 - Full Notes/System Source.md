# System Source

A system source generates a [[Resource]] or increases the amount available to another part. The source may represent a concrete origin, such as a mine, or an abstract event, such as receiving experience for an action.

A model can treat the resource as appearing from outside its [[System Boundary]] when representing the larger origin would add detail without useful behavior. Excess source flow without adequate [[System Sink|sinks]] can create [[Economic Inflation]].
