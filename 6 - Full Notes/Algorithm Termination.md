# Algorithm Termination

Algorithm termination is the requirement that a procedure finish after a finite number of steps. A repeated operation therefore needs a condition that eventually ends its [[Iteration Control Structure|iteration]] rather than allowing it to continue forever.

Termination distinguishes an [[Algorithm]] from a general computational process. A program may intentionally run indefinitely, but a claimed algorithm must reach an [[Algorithm Output]] for every valid input covered by its definition.
