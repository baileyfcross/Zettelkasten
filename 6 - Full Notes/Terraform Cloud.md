# Terraform Cloud

Terraform Cloud is a hosted platform for executing and governing Terraform workflows. It combines source-control integration, remote runs and state, protected variables and dynamic credentials, workspace organization, team access, a private module registry, and extension points around plan and apply.

Its higher-level value is operational: module testing and publishing standardize reusable code, while drift detection, continuous validation, audit records, cost estimation, and policy as code support day-two management. It can replace much of the Terraform-specific plumbing built in a general CI system, though application compilation and unrelated delivery work may remain elsewhere. The service centralizes the [[Terraform Production Operating Model]] rather than changing the declarative core.
