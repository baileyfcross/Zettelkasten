# Bash Integer Arithmetic

Bash integer arithmetic evaluates expressions inside arithmetic expansion or arithmetic commands without treating operators as ordinary text. Variables can participate by name, and integer attributes can cause assignments to be evaluated arithmetically.

The result is limited to integer arithmetic and the shell's numeric range. When a calculation needs fractions or controlled precision, [[BC Floating-Point Arithmetic]] provides a separate numeric language better suited to that requirement.
