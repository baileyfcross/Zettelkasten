# Network Health Metrics Packet

A network health metrics packet is a structured snapshot of device identity, role, location, CPU, memory, bandwidth, latency, error rate, uptime, interfaces, and active connections. It gives an analysis tool common fields across routers, switches, and firewalls.

Values need units, collection times, and source identifiers so thresholds are meaningful. Missing data must be represented explicitly rather than silently converted to zero. The packet is evidence for [[AI Network Health Analysis]], while the monitoring system—not the language model—remains the authority for the measurements.
