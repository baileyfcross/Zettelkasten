# Time Complexity

Time complexity describes how the number of elementary operations performed by an [[Algorithm]] grows with [[Input Size]]. Counting operations avoids tying the analysis to the clock speed of one computer.

Actual runtime still depends on hardware and implementation, but growth rate predicts how the same implementation will behave at larger scales. [[Big O Notation]] expresses an asymptotic upper bound and groups algorithms into useful families for comparison.
