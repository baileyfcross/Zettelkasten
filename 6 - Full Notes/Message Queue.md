# Message Queue

A message queue is a buffer in memory, a database dataset, or a file-backed store where sending applications place messages until receiving applications retrieve them. It allows work to cross application and machine boundaries without requiring both parties to be active at the same instant.

Queues support decoupling, ordering, persistence, filtering, priority, and controlled access. Their delivery behavior must be stated explicitly because reliable, guaranteed, and transacted messages make different promises.
