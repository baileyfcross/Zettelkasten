# Excel Standard Deviation Function

An Excel standard deviation function measures how widely numeric observations are dispersed around their mean. A smaller result indicates values clustered more tightly; a larger result indicates greater spread. Excel provides different functions depending on whether the data represents a sample or the complete population.

The sample-versus-population choice changes the denominator and should reflect how the data was obtained, not which result looks preferable. Standard deviation uses the same units as the observations, making it more interpretable than squared deviations. It summarizes spread but does not by itself reveal skew, outliers, or multiple clusters.
