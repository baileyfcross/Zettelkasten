# CSS RGB and Alpha Colors

CSS can describe a color by its red, green, and blue components using hexadecimal notation or the `rgb()` functional form. Components may be expressed with integer ranges or percentages, and equivalent component combinations represent the same color.

The `rgba()` form in the source adds an alpha component from transparent to opaque. Alpha changes how the chosen color is composited with what lies behind it without changing the element's descendants as whole-element opacity would.
