# Empty String

The empty string ε is the unique [[String]] containing zero symbols. It has length zero, is its own reversal, and leaves any string unchanged when concatenated on either side.

The empty string is an object, not the absence of a language: {ε} is a one-element language, whereas ∅ contains no strings. ε belongs to every Σ* and to every [[Kleene Star|Kleene closure]].
