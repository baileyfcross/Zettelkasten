# Texture Paint Blend Mode Families

Texture-paint blend modes combine a brush color with existing image pixels through different channel operations. Darken and burn families reduce values, lighten and dodge families raise them, and contrast modes such as overlay treat dark and light regions differently.

Hue, saturation, color, and value modes preserve some perceptual components while replacing others. Difference, exclusion, subtract, and alpha operations serve more specialized edits, so the chosen mode should match the intended pixel relationship rather than its name alone.
