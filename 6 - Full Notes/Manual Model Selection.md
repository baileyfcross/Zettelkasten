# Manual Model Selection

Manual model selection requires the analyst to specify and inspect each model iteration rather than delegate every choice to an automated routine. It makes category coding, reference groups, coefficient changes, and empirical reasons for retaining variables visible.

The method is slower but can treat a multi-indicator categorical construct coherently and reveal when variables compete through collinearity. Manual selection still needs explicit rules and [[Model Metadata]] so judgment does not become undocumented discretion.
