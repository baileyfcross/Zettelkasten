# Blender Image Object

A Blender image object places a two-dimensional image in the 3D scene as a reference rather than as ordinary mesh geometry. It is commonly used to hold concept art, orthographic views, or another visual guide beside the model so form and proportion can be compared during construction.

Because the object exists in Object Mode, it can be positioned and oriented like other scene elements while remaining distinct from an image texture applied to a renderable surface. This distinction separates a modeling aid from final surface appearance. Reference images are most effective when their scale, view direction, and alignment are established deliberately.
