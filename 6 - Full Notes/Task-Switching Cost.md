# Task-Switching Cost

Task-switching cost is the loss of speed, accuracy, and learning quality that occurs when attention repeatedly moves between tasks. Apparent multitasking is usually rapid switching rather than simultaneous conscious processing.

A game imposes this cost when players must alternate between action, distant instructions, secondary displays, or unrelated demands. Reducing unnecessary switches supports flow and learning because the player can maintain a stable focus instead of repeatedly reconstructing context.
