# Map Layer Overlay

A map layer overlay composes spatial datasets in the same coordinate space and graphical frame. A raster may form the background, polygons or lines provide boundaries, points carry thematic symbols, and labels identify selected features. Correct [[Spatial Data Reprojection]] is required before alignment. Layer order, transparency, and stroke weight determine whether context supports or hides the analytical marks.
