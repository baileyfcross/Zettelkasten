# Java Primitive Type Pattern

In Java 23, primitive patterns were a preview capability that extended pattern matching and `instanceof`-style tests toward primitive values and conversions. A primitive pattern can accept a value only when the conversion and represented value satisfy the pattern's compatibility rules, then bind the converted value.

Because the feature was preview in the book's Java 23 setting, source and launch commands must enable preview features and the syntax can change in later releases. It should therefore be recorded as version-specific rather than assumed to be a permanent baseline language rule.
