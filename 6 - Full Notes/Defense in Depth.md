# Defense in Depth

Defense in depth protects a system with multiple security layers so that the failure of one control does not expose the entire environment. The source applies this idea across the [[Human Security Layer]], [[Network Security Layer]], [[Host Security Layer]], [[Application Security Layer]], and [[Data Security States]], with cloud and mobile systems crossing several layers.

The layers should reinforce one another. Prevention reduces opportunities for attack, detection reveals activity that crosses a boundary, and response limits the consequences when an attack succeeds.
