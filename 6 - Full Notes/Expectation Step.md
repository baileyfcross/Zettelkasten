# Expectation Step

The expectation step of expectation-maximization computes the posterior distribution of latent variables using the current parameter estimates. It uses observed data to assign probabilistic responsibility to the missing alternatives.

These expected latent assignments replace unavailable complete-data counts or values in the next optimization. Uncertainty is retained through weights rather than a forced single completion.
