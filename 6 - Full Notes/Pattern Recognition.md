# Pattern Recognition

Pattern recognition infers a hidden category or structure from observed features. A probabilistic description models how each candidate pattern could generate the available evidence and uses prior knowledge to resolve ambiguous matches.

Classification is one common question posed to such a model. Marginalizing nuisance variables permits recognition to tolerate variations that are not part of the desired category.
