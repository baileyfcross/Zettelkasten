# JavaScript Array Filter

`Array.filter` evaluates a predicate for every source item and returns a new array containing only the items for which the predicate is true. The predicate expresses the selection rule while the array method owns traversal and output construction.

Filter can remove an item without mutating the original array by keeping every item whose identifier differs from the one being removed. This makes it a natural partner to [[JavaScript Immutability]] and a useful building block for Redux reducers.
