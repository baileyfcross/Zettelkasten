# Template Lifecycle Management

Template lifecycle management treats reusable platform templates like maintained source code. They need a repository, documentation, versioning, testing, change history, release strategy, ownership, and a deprecation path as dependencies and standards evolve.

GitOps or dependency automation can detect when rendered projects lag behind a newer base and propose updates. Usage tracking helps distinguish a valuable shared template from one that should be improved or retired rather than kept indefinitely because it once existed.
