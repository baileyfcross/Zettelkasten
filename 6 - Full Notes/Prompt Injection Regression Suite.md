# Prompt Injection Regression Suite

A prompt injection regression suite is a versioned collection of known malicious payloads and expected safe outcomes. It runs when system prompts, model versions, templates, retrieval behavior, or guardrail code change and blocks release when a previously contained attack succeeds.

Every confirmed injection incident should add its payload or a safe representative variant before closure. Known cases do not replace ongoing adversarial exploration, but they convert discoveries into permanent executable evidence and prevent a later optimization from silently reopening the same path.
