# Multidimensional Scaling

Multidimensional scaling constructs low-dimensional coordinates whose pairwise distances approximate an input [[Distance Matrix]]. A two-dimensional scaling plot makes relative similarity among high-dimensional samples visible without plotting every original feature.

For Euclidean distances, the source relates the leading scaling coordinates to the leading singular-vector representation. The plot is most faithful when the first few dimensions dominate the distance structure.
