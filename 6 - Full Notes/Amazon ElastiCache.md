# Amazon ElastiCache

Amazon ElastiCache provides managed in-memory caching with supported engines such as Redis-compatible options and Memcached. Applications place frequently accessed or computationally expensive data in memory to reduce database load and response time.

A cache introduces freshness, eviction, and failure decisions. The persistent database remains authoritative unless the architecture explicitly uses the cache for another role. Cache keys, expiration, invalidation, and fallback behavior are application responsibilities.
