# CSS Font Face Rule

The CSS `@font-face` rule defines a font resource that can participate in ordinary font selection. Its descriptors name the family, identify one or more sources, and describe the face's style, weight, stretch, and character coverage.

Once defined, the family can be requested with `font-family` like a locally available font. The rule describes a resource; it does not itself apply that font to any element.
