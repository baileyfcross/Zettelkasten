# Semantic Scientific Document

A semantic scientific document contains data, definitions, mathematical forms, computation instructions, assertions, and results in a structured representation. The document is not only a report about a calculation; it can supply the entities that an execution system interprets and updates.

Processing can transclude external resources, manipulate the structure, decorate elements with executable domain objects, and then perform the computation. [[Syntactic and Semantic Validation]] is threaded through the stages. Because the output retains definitions and inputs, it can become an immediately rerunnable record and interoperate with other programs that understand the same semantics.
