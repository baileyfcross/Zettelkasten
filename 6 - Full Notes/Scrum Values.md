# Scrum Values

The Scrum values are focus, courage, openness, commitment, and respect. Focus directs attention to the current goal; courage permits difficult work and conversations; openness exposes progress and problems; commitment supports shared goals; respect recognizes each contributor's capability.

The framework's events cannot create empiricism by themselves. These values make honest inspection, collaborative decisions, and meaningful adaptation possible.
