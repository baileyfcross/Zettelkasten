# Selenium Select List

A Selenium select list wraps an HTML `select` element whose user chooses one option. The `Select` helper can choose by visible text, option value, or index and can return the selected option or the complete option list.

Single-select controls do not support independent deselection of every option; a test can select a deliberate default when it needs to simulate clearing the choice. The selected value should be asserted after interaction.
