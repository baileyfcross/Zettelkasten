# Programming Language

A programming language is an artificial language used to describe computational instructions. Its vocabulary, syntax, and grammar provide notation for operations and for the [[Control Structure|control structures]] that determine the order in which those operations execute.

Writing an [[Algorithm]] in a programming language makes its steps executable by a computer. Different languages may express the same algorithm differently, so the algorithmic method remains distinct from its particular implementation.
