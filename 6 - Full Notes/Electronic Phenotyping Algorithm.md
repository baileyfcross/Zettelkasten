# Electronic Phenotyping Algorithm

An electronic phenotyping algorithm identifies patients with a clinically meaningful condition or trait from EHR evidence. It may combine diagnosis codes, procedures, medications, laboratory values, reports, and temporal constraints instead of relying on one field.

The combination is necessary because individual record elements are incomplete proxies. A code can reflect billing, a medication can have several indications, and a negative mention in a note is not a confirmed disease. A phenotype should therefore define inclusion and exclusion logic, resolve contradictory evidence, and be validated against expert-reviewed cases before it is used for research.
