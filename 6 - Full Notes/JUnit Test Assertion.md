# JUnit Test Assertion

A JUnit assertion compares observed behavior with the test's expectation and fails the test when they differ. Assertions cover equality, identity, nullability, boolean conditions, arrays, exceptions, time limits, and grouped checks.

The assertion should state the externally meaningful outcome rather than reproduce the implementation. A failure message or descriptive test name explains the contract being checked. Unlike the Java `assert` keyword, JUnit assertions run as part of the test framework and do not depend on the JVM's assertion-enable flag.
