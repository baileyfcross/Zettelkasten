# Saddle Point

A saddle point is a [[Stationary Point]] that is neither a local maximum nor a local minimum. The function increases in some nearby directions and decreases in others.

For a twice-differentiable function, an indefinite [[Hessian Matrix]] identifies this mixed curvature. A zero gradient alone therefore does not establish an optimum.
