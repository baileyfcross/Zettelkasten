# Graph Accelerator

A graph accelerator specializes the traversal, edge processing, and vertex-update operations common in graph analytics. It can coordinate several processing elements with a memory system designed for fine-grained, irregular access.

Performance depends on keeping the units supplied with useful edges despite skewed degrees, weak locality, synchronization, and changing active frontiers.
