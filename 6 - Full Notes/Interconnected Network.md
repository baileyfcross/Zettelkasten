# Interconnected Network

An interconnected network is a family of layer graphs whose nodes interact across layers. Cross-layer edges represent those interactions but do not necessarily mean that one endpoint functionally depends on the other.

This distinction separates ordinary coupling from an [[Interdependent Network]]. Node or layer labels can identify which subsystem each endpoint belongs to.
