# Open Set in Euclidean Space

A set $S\subseteq\mathbb{R}^n$ is open when every point $a\in S$ is surrounded by some [[Open Ball]] contained entirely in $S$.

Equivalently, every point of an open set is an [[Interior Point of a Set|interior point]]. Open boxes, open ellipsoids, arbitrary unions of open sets, and finite intersections of open sets supply standard examples.
