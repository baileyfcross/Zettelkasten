# Microservice Instance Scaling

Microservice instance scaling creates additional runtime instances of the same service type and distributes requests or messages among them. It increases operational capacity without changing the functional boundary represented by the service.

The instances need compatible configuration and a safe relationship to state. Load balancing, message partitions, or an orchestrator determines which instance receives each unit of work.
