# CSS Text Indentation

The `text-indent` property offsets the first formatted line of a block container. The value can be positive or negative and may use a length or a percentage based on the containing block's width.

Indentation changes line layout without inserting characters into the document. A negative value can create a hanging indent, but the shifted text may require matching padding or margins to keep it from leaving the visible box.
