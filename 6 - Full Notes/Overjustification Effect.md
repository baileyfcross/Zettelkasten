# Overjustification Effect

The overjustification effect occurs when an expected external reward reduces a person's prior intrinsic interest in an activity. The activity is reinterpreted as something done for payment rather than something valuable in itself.

An unexpected reward need not have the same effect because it does not become the reason for beginning the behavior. Game rewards should therefore reinforce the intended experience without teaching players that the activity is worthwhile only when a separate prize is promised.
