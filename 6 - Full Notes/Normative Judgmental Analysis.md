# Normative Judgmental Analysis

Normative judgmental analysis directs judges to rank each profile using the supplied predictor variables. The common attribute set provides the basis for estimating and comparing decision equations.

Restricting attention to the predictors makes differences among policies easier to interpret. It also means that omitted factors cannot be recovered from the fitted equation.
