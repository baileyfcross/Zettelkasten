# Provenance Query and Comparison

Provenance query and comparison use recorded workflow structure, execution facts, and history to explain relationships among runs. A researcher can ask which inputs changed, which dependency version differed, where an error occurred, or which parameter choices produced a selected output.

These operations turn provenance from passive documentation into an analytic resource. Comparing [[Prospective Provenance]] with [[Retrospective Provenance]] reveals deviations from the plan, while [[Workflow Evolution Provenance]] explains differences among versions. The result supports debugging, reflective reasoning, and reuse of successful computational patterns.
