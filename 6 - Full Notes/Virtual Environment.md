# Virtual Environment

A virtual environment is a synthetic spatial world, usually three-dimensional, seen from a first-person point of view. The user's view is controlled in real time.

A virtual environment is the world being experienced, while [[Virtual Reality]] is an approach that uses displays, tracking, and other technologies to immerse a person in that world. The terms are often used interchangeably in practice.

Interaction within a virtual environment can involve [[3D Manipulation]], [[Navigation]], and [[System Control]], supported by a [[3D User Interface]].
