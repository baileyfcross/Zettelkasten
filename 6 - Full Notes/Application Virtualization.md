# Application Virtualization

Application virtualization hosts an application centrally and delivers access to many users without requiring the full application to be installed and managed on every client. Users interact through a browser, mobile client, or a remote presentation of the hosted application.

Central hosting can share application costs and let comparatively modest devices use demanding software. If application data is also stored remotely, a user becomes less dependent on one physical device or location.
