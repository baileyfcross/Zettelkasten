# System Integrity Verification

System integrity verification provides evidence that a computer has not been altered or compromised since a trusted state. The source combines user identity verification, secure boot, and hashing of files, folders, or an entire drive to examine different layers of the host.

The order matters: data checks are less meaningful when the operating system performing them cannot be trusted. A verified host provides the foundation on which [[Data Integrity Verification]] can rely.
