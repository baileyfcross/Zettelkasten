# Navigation Mesh

A navigation mesh partitions walkable space into connected convex polygons. An agent can move directly within one polygon and search adjacency between polygons to plan a route through the environment.

Compared with isolated [[Path Node|path nodes]], the mesh describes traversable regions rather than only preferred points. It supports more flexible movement while still reducing detailed world geometry to a manageable [[Pathfinding Graph]].
