# User Timeout

A user timeout occurs when the assistant receives no expected response within a defined interval. Silence can mean the user did not hear, needs more time, became distracted, or abandoned the interaction.

A [[Dialog Policy]] can reprompt, simplify the question, offer help, or end gracefully. Repeatedly replaying the identical prompt ignores the different reasons that silence can have.
