# Unity Editor Workspace

The Unity Editor workspace separates authoring concerns into coordinated panes. The Scene or Prefab pane edits spatial content, the Game pane previews the active camera, the Hierarchy lists scene objects, the Project pane exposes assets and packages, the Inspector edits the selected object's data, and the Console reports diagnostics.

The panes are views over related project state rather than independent documents. Selecting a [[Unity GameObject]] in the Hierarchy reveals its components in the Inspector, while selecting an asset shows its import or configuration data. A useful layout keeps editing, runtime preview, object structure, assets, and errors visible enough to support rapid iteration.
