# Selection Control Structure

A selection control structure evaluates a condition and chooses which alternative sequence of steps to execute. It lets an [[Algorithm]] respond differently to different states or input values.

In Euclid's algorithm, testing whether the remainder is zero selects between stopping with the greatest common divisor and continuing the calculation. Selection can be nested inside an [[Iteration Control Structure]] so the decision is reconsidered after each repetition.
