# Extension Theorem

The extension theorem gives conditions under which a partial solution of an [[Elimination Ideal]] can be extended by a value for the eliminated variable to solve the original polynomial system.

Leading coefficients of the original equations identify exceptional partial solutions where extension can fail. The theorem complements the closure result: elimination describes projected equations, while extension determines when those projected points lift to actual solutions.
