# Security Sandboxing

Security sandboxing runs code inside a restricted container whose access to files, memory, devices, and other resources is deliberately limited. Potentially harmful behavior can be observed or contained without granting the code ordinary host permissions.

Quarantined files are one application of this separation model. A sandbox reduces impact but still depends on the correctness of the boundary that mediates every attempted escape or resource request.
