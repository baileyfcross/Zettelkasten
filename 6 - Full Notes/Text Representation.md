# Text Representation

Text representation retains selected information from a document as features suitable for search, classification, clustering, recommendation, or prediction. Every representation emphasizes a perspective: character strings preserve surface form, bags of words preserve term occurrence, and structural or latent models preserve other relationships.

The representation should map text objects relevant to the same task into similar descriptions while separating objects that should differ. Richer representations can capture more meaning but often require more computation, data, and language-specific processing.
