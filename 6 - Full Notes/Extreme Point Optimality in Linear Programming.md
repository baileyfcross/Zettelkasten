# Extreme Point Optimality in Linear Programming

The feasible set of a linear program is convex because any weighted point on the segment between two feasible points remains feasible. When this set is a convex polyhedron and an optimum exists, at least one extreme point attains the optimal objective value.

In standard form, an extreme point is equivalent to a [[Basic Feasible Solution]]. This is the geometric foundation of the [[Graphical Linear Programming Method]] and the algebraic reason that simplex methods move between bases.
