# STIRR Fixed Point

A STIRR fixed point is a normalized weight configuration that no longer changes under the relational reinforcement function. At that point further propagation produces the same weights.

The positive and negative basins of the fixed configuration can separate groups of attribute values. Convergence depends on the combiner and starting conditions.
