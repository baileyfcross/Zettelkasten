# Computational Complexity

Computational complexity describes the resources an [[Algorithm]] requires as the size of its input grows. The principal resources are [[Time Complexity|time]], represented by the number of elementary operations, and [[Space Complexity|space]], represented by required storage.

The purpose is to compare algorithms independently of a particular computer. Hardware changes the duration of one operation, but it does not change whether the number of operations grows linearly, quadratically, exponentially, or according to another complexity family.
