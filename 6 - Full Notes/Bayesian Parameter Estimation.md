# Bayesian Parameter Estimation

Bayesian parameter estimation treats an unknown model parameter as a variable with its own prior distribution. Observed data updates that prior into a posterior over possible parameter values.

Keeping a distribution expresses remaining uncertainty and lets later predictions average across plausible parameters. New data can be incorporated by using the current posterior as the next prior.
