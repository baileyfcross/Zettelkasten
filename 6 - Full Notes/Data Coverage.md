# Data Coverage

Data coverage tests representative valid and invalid inputs as well as data generated internally by a program. Typical values show that ordinary use works, while malformed, missing, extreme, and incompatible values test whether defensive behavior holds.

The aim is not to enumerate every possible value but to select equivalence classes and risk-bearing cases. Values at and just beyond valid limits are especially useful because comparisons and indexing often fail at boundaries.
