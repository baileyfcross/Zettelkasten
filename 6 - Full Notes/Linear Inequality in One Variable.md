# Linear Inequality in One Variable

A linear inequality in one variable compares linear expressions whose unknown appears only to the first power. A typical form is

$$ax+b<c$$

or the corresponding (>), (\leq), or (\geq) relation.

Solving isolates the variable by applying compatible operations to both sides. Addition and subtraction preserve the relation, as does multiplication or division by a positive value. A negative multiplier requires [[Reversing an Inequality]]. The answer is a set of values rather than usually one number.
