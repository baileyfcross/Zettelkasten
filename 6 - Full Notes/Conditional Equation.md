# Conditional Equation

A conditional equation is an equality that is true only for particular values of its variables. The equation (4+x=6-x) is true when (x=1) but false for most real values.

Those particular values form the [[Solution of an Equation]]. A conditional equation contrasts with an [[Algebraic Identity]], which remains true for every allowed assignment, and with an inconsistent assertion that has no solution. Solving uses equality-preserving transformations to isolate the unknown and then checks the result in the original condition.
