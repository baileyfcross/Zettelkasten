# Logic App Action

A Logic App action performs one configured unit of work after the trigger or a preceding step. Actions can read rows, call a function, post a message, or delete processed data through managed service connectors.

An action receives values from earlier outputs and exposes its own result as dynamic content for later steps. Explicit naming makes that dataflow understandable when many actions accumulate in the visual workflow.
