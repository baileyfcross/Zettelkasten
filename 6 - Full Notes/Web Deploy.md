# Web Deploy

Web Deploy is a publishing target for transferring and synchronizing a web application's deployment content with a compatible server. Visual Studio can store the destination and build choices in a publish profile for repeatable releases.

The target automates movement of application artifacts, not the correctness of the destination environment. Server configuration, database access, application settings, and credentials still have to match the published build.
