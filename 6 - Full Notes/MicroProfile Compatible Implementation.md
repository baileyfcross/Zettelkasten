# MicroProfile Compatible Implementation

A MicroProfile compatible implementation is a runtime whose implementation of the specifications has passed the applicable Technology Compatibility Kit. The tests check correctness and consistency so applications can rely on specified behavior rather than a vendor's unsupported claim of similarity.

After passing the TCK, an organization can submit a Compatibility Certification Request to the MicroProfile Working Group for approval. This certification process connects vendor competition to a shared portability contract and is the basis for describing a Helidon MP release as compatible with a particular MicroProfile version.
