# Supra-Adjacency Matrix

A supra-adjacency matrix represents an entire multilayer network as a block matrix. Diagonal blocks contain each layer's [[Adjacency Matrix]], while off-diagonal blocks encode [[Interlayer Edge|interlayer edges]].

This form permits matrix, spectral, walk, and path methods to be extended from single graphs. The resulting super-network may still behave differently from an aggregation that merges all copies of a node.
