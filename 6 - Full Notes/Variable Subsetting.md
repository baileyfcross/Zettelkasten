# Variable Subsetting

Variable subsetting retains only the columns needed for an analysis. The selected set usually includes source variables required to construct the exposure, outcome, potential confounders, missingness flags, and validation checks.

Removing unrelated columns reduces memory use and makes the analytic structure easier to inspect. Selection should be guided by a prespecified research design and documented metadata, since returning later to search the source for variables associated with a desired result can become analytical fishing.
