# Dynamic Software Testing

Dynamic software testing evaluates functionality, performance, or security by executing the software and observing its behavior. Test cases provide inputs and expected results, the runtime environment produces evidence, and failures are analyzed before fixes undergo regression testing.

The method reveals behavior that source inspection alone cannot establish but depends on environments, interactions, coverage, and resources. LLMs can help generate or prioritize cases and interpret results without replacing execution as the deciding evidence.
