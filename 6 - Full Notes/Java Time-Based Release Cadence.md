# Java Time-Based Release Cadence

Java's time-based release cadence publishes a new feature release every six months instead of waiting for a predetermined feature set to be complete. Features ready at the release boundary ship, while unfinished work can continue through later releases.

The cadence makes release dates more predictable than the earlier feature-driven approach, but it also requires tool vendors and application teams to absorb platform changes more frequently. [[Java Preview Feature]] and [[Java Incubator Feature]] provide controlled paths for exposing work that still needs feedback without making it a permanent standard API immediately.
