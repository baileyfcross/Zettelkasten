# CSS Font Shorthand

The CSS `font` shorthand sets several font properties in one declaration. A valid ordinary form includes a font size and family, may place line height after the size, and may precede them with style, variant, weight, or stretch values.

Properties omitted from a shorthand are reset to their initial values rather than preserved from earlier rules. System-font keywords form a separate shorthand form that requests typography associated with parts of the user interface.
