# MetaCost Relabeling

MetaCost relabeling converts cost-sensitive classification into an ordinary learning problem by estimating class probabilities and replacing each training label with the class having the lowest expected misclassification cost.

An ensemble supplies more stable probability estimates than a single fitted model. After relabeling, a standard base classifier is trained, allowing cost information to influence algorithms that do not natively support unequal errors.
