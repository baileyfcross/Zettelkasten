# Identifier versus Predictive Attribute

An identifier labels an instance so its records can be joined, checked, or traced. Although it may occupy a column in an analytic table, the identifier is generally not a substantive predictor of the target. Treating arbitrary ID values as meaningful features can invite accidental patterns.

The distinction belongs to data understanding: a column's machine-readable type does not reveal its analytical role. A number can be an ID, a count, an ordered rating, or a measured quantity, and those roles permit different transformations and interpretations.
