# CSS List Marker Types

The `list-style-type` property chooses the marker used by a list item. Values include bullets, numbers, alphabetic forms, and many language-specific systems, while `none` suppresses the marker.

The marker belongs to the list-item formatting model rather than to the document's text content. [[CSS Counters and Counter Styles]] supplies the numbering behavior behind many marker types and supports custom patterns.
