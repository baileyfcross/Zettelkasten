# Multiple Scenes in a Blend File

A single `.blend` file can contain several scenes. Each scene can provide a distinct arrangement of objects, cameras, lighting, and world settings while remaining inside one project container.

Multiple scenes are useful for related shots, variants, or stages that should travel together. They are not merely viewport layouts: switching scenes changes the scene data being worked on, whereas switching workspaces changes how shared data is presented.
