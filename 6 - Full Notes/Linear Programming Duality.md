# Linear Programming Duality

Linear programming duality associates a second optimization problem with a primal program. Constraints in one correspond to variables in the other, and a maximization problem is paired with a minimization problem.

Weak duality bounds any primal feasible value by any dual feasible value. When optimal solutions exist, the primal and dual objective values are equal.
