# Streaming Kernel Learning

Streaming kernel learning constructs or updates nonlinear feature mappings as data arrive. Budgeted bases, approximations, or incremental kernel matrices keep computation from growing without bound.

The kernel supplies expressive similarity features, but an unrestricted set of support points is incompatible with long streams. Budget maintenance therefore balances fidelity to the nonlinear structure against fixed memory and update time.
