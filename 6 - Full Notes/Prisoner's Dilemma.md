# Prisoner's Dilemma

The Prisoner's Dilemma is a two-player game in which each player individually benefits from defecting regardless of the other's action, yet mutual defection leaves both worse off than mutual cooperation. The dominant individual incentives therefore produce a collectively inferior equilibrium.

Its [[Payoff Matrix]] separates equilibrium from Pareto improvement: neither player can improve alone from mutual defection, but both would benefit if they could credibly coordinate on cooperation. Repetition changes the strategic context because current behavior can affect later responses.
