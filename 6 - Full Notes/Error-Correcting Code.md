# Error-Correcting Code

An error-correcting code adds structured redundancy so that a received word can be checked and certain corruptions can be repaired. In a linear code, generator and parity-check matrices express those operations as transformations over a finite field.

Correction depends on codeword separation. Distinct nonzero parity-check columns locate a single error, while the code's minimum [[Hamming Distance]] describes the broader number of errors that can be detected or corrected.
