# Conversation Context

Conversation context is the information carried across turns that affects how a new utterance should be interpreted. It includes prior intents, mentioned entities, questions asked, values supplied, and unresolved goals.

The [[Dialog Manager]] uses this state for [[Conversational Reference Resolution]], interpreting [[Elliptical Utterance|elliptical utterances]], and avoiding repeated questions. Context turns isolated sentences into a coherent interaction.
