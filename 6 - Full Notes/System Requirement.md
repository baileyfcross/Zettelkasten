# System Requirement

A system requirement is a documented capability or constraint that the complete system must satisfy. It can describe externally visible behavior, operational limits, interfaces, data obligations, or qualities that span several components.

System requirements sit above a particular class or service implementation. Decomposition may assign responsibility to multiple parts, but [[Requirement Traceability]] should preserve the connection back to the original need.
