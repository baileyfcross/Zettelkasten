# Dataset Representativeness

Dataset representativeness is the degree to which data cover the people, situations, and variation relevant to a model's intended use. Size alone does not guarantee representation. A large collection can systematically omit groups, environments, or rare but consequential cases.

Poor representation makes learned performance uneven and can create [[Algorithmic Bias]]. The appropriate comparison population depends on the deployment context, so a dataset suitable for one task may fail in another. Evaluating representativeness requires examining how examples were produced and selected, not only summary statistics after collection.
