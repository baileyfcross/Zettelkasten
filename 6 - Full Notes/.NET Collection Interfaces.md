# .NET Collection Interfaces

.NET collection interfaces describe capabilities shared across many concrete containers. `ICollection` exposes a count, while `IEnumerable` supplies an enumerator that supports sequential traversal and therefore `foreach`.

Generic forms preserve the stored element type and avoid casts required by older nongeneric collections. Depending on the contract rather than a specific implementation lets a caller accept lists, sets, queues, or another sequence when it only needs common enumeration behavior.
