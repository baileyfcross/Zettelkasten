# Bivariate Raster Map

A bivariate raster map encodes two aligned raster variables in each cell. The source uses hue for a categorical class and transparency or lightness for a quantitative value, accompanied by a two-dimensional legend. The technique can reveal how magnitude varies within categories, but combined encodings multiply the number of apparent states. Restrained class counts and perceptually ordered value levels are necessary for reliable interpretation.
