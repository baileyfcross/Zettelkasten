# Collective Network Classification

Collective network classification predicts labels for connected nodes jointly rather than classifying each record in isolation. A node's attributes and the labels or features of its neighbors can inform one another.

The approach exploits relational dependence but creates circular inference because unknown neighboring labels are also being predicted. Iterative, propagation, regularization, or graphical-model procedures resolve this coupling approximately or exactly when structure permits.
