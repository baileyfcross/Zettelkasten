# Input Size

Input size is the quantity used to express the scale of a problem instance, conventionally written as $n$. Its meaning depends on the problem: it may be the number of records to sort, vertices in a graph, or digits in a number.

[[Computational Complexity]] relates resource use to this measure rather than treating every input as equivalent. Selecting the relevant dimension is part of modeling the problem because an irrelevant physical property of the data may have no effect on the operations an [[Algorithm]] performs.
