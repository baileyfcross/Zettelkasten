# Post-Training Resolution-Independent Optical Inference

After the probe has been trained, the proposed optical neuron performs one classification with resource counts that do not grow with an $N$-pixel representation. Interference carries out the overlap physically, leaving only constant-size scalar post-processing, while coincidence estimation uses a number of photon trials set by the requested statistical precision rather than by $N$.

This is a conditional inference claim. It assumes the object can prepare the input spatial state directly, the trained probe already exists, the desired output is only a binary decision, and precision is held fixed as resolution changes. Classical simulation of the apparatus, preparation of learned parameters, and the number of training epochs are separate costs. Under those conditions, the paper contrasts $O(1)$ quantum optical inference with at least linear reconstruct-then-classify processing and calls the reduction from resolution-dependent to constant scaling a superexponential speedup.
