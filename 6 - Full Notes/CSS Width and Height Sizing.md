# CSS Width and Height Sizing

CSS `width` and `height` assign preferred content dimensions, while minimum and maximum properties constrain the resulting size. Lengths provide explicit measures and percentages usually refer to the corresponding dimension of a [[CSS Containing Block]].

Automatic sizing depends on the element type, formatting context, intrinsic replaced-element dimensions, and available space. A percentage height may behave as automatic when the containing block's height is not explicitly determined.
