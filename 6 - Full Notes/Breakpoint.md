# Breakpoint

A breakpoint marks a source location where a [[Debugger]] should pause program execution. While paused, a developer can inspect variables, evaluate expressions, review the call stack, and step through subsequent operations.

A breakpoint inside a controller can expose server request state, while one in an Angular component can expose form or subscription state. Conditions can narrow the pause to a relevant case.

A Visual Studio breakpoint can also carry a label, a Boolean condition, and an action. The Breakpoints window makes those stops manageable across a solution, while step-into, step-over, and step-out commands continue execution at different call depths.
