# Software Development

A set of computer science activities that are dedicated to the process of creating, designing, and supporting [[Software]].

For interactive software, [[User Interface]] design is part of the development process rather than a cosmetic step at the end. [[Usability Engineering]] iterates through analysis, design, implementation, and [[User Interface Evaluation]] so evidence from a [[Prototype]] can refine the system before it is treated as complete.
