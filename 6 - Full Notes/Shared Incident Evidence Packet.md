# Shared Incident Evidence Packet

A shared incident evidence packet gives specialists a common, labeled set of approved operational data. It can include incident metadata, a deployment log, application errors, service-health measures, and the relevant runbook, with each text section bounded before model use.

The packet reduces disagreement caused by hidden inputs while preserving role-specific interpretation. It should use synthetic or sanitized data in demonstrations and governed sources in production. Labels and truncation make provenance and limits visible, but specialists must still avoid inventing evidence that is absent from the packet.
