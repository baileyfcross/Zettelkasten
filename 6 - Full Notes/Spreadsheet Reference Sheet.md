# Spreadsheet Reference Sheet

A spreadsheet reference sheet is the workbook's centralized bank of reusable inputs. It can hold attribute weights, minimum and maximum values, unit conversions, difficulty multipliers, object-count limits, and other variables used by several formulas or sheets.

Moving a repeated literal value to the reference sheet gives it one labeled source of truth. Designers can then tune the source while dependent calculations update automatically. A variable used only on one sheet may also belong on the reference sheet when leaving it in place would clutter or obscure the object data.
