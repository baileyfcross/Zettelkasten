# Git Push

`git push` sends local objects and updates selected references in a remote repository. A typical invocation identifies a remote and a local branch whose commits should become reachable from a remote branch.

Push transfers committed history, not merely every current working-tree edit. The remote may reject an update when policy, permissions, file limits, or conflicting history prevents the requested reference change.
