# Java Arithmetic Operators

Java supplies unary sign, increment and decrement, plus binary addition, subtraction, multiplication, division, and remainder. Numeric promotion determines the type in which an operation is evaluated, and overflow of an integer primitive wraps according to its fixed-width representation rather than automatically widening or throwing.

The `+` operator also concatenates strings when either operand is a String, converting the other value to text. Prefix increment changes a variable before yielding its value, while postfix increment yields the previous value before applying the same side effect.
