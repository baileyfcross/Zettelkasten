# AWS Budget

An AWS Budget compares actual or forecast cost and usage with a defined threshold. It can notify stakeholders and, in supported cases, initiate an action when spending, utilization, or reservation coverage crosses a configured point.

A budget is a feedback control, not a hard limit on every charge. Forecast lag, notification routing, threshold design, and response ownership determine whether the warning arrives early enough to change an outcome.
