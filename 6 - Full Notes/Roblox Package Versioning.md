# Roblox Package Versioning

A Roblox Package turns a model or other supported object hierarchy into reusable content that can be inserted in multiple locations. Linked copies can receive later updates from the package source, which is useful for shared props, systems, and assemblies.

Versioning makes reuse intentional: publish a tested change, decide which copies should adopt it, and preserve the ability to recover an earlier state when a revision fails. Removing an instance from one place is not the same as deleting the source asset. Packages complement [[Roblox Team Create]] by giving collaborators a controlled unit of shared content.
