# Kotlin Notebook

Kotlin Notebook provides executable code cells and Markdown cells inside IntelliJ IDEA. A developer can run one cell, see its output next to the code, retain values for later cells, and rerun the notebook as an interactive analysis sequence.

Notebook directives can load libraries such as Kotlin DataFrame and Kandy. This makes the document a combination of explanation, program state, results, and visualization, which is useful for exploration but also means that cell order and prior execution state affect what a later cell observes.
