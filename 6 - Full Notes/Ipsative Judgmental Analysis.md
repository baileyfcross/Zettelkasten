# Ipsative Judgmental Analysis

Ipsative judgmental analysis allows judges to use personal knowledge of the capabilities or context of each profile case when assigning a rank. It quantifies those subjective opinions through a common analytic structure.

Because knowledge beyond the presented predictors may influence a score, judges should be qualified and related to the cases. The result can be more objective in analysis without pretending the original judgments were context-free.
