# CSS Universal Selector Specificity

The CSS universal selector `*` matches every element but contributes no specificity. It can therefore broaden which elements a selector reaches without making that selector harder to override.

Its zero contribution differs from the contribution of an element selector. This matters when comparing otherwise similar selectors under [[CSS Specificity]], because a broad match is not automatically a strong match.
