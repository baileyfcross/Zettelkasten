# All-Missing Variable

An all-missing variable contains no observed values in the analytic dataset. It cannot contribute empirical information to a model and may cause software errors or misleading metadata.

Removing it from model inputs is usually appropriate, while retaining its name in an exclusion record documents that the source field existed but supplied no usable values.
