# Microsoft Defender for Cloud

Microsoft Defender for Cloud combines foundational posture assessment, enhanced Defender CSPM capabilities, and workload-specific protection plans. It can inventory resources, calculate secure-score recommendations, identify attack paths, and generate security alerts across Azure and connected environments. Architecture decisions include which subscriptions and workloads are covered, which paid plans are enabled, how policies are inherited, who owns remediation, and how findings reach the broader security-operations process.
