# Flat Web Architecture

The Web’s flat architecture lets one URL reach a resource anywhere without exposing its physical distance or host type. This uniform access supports open publication and seamless navigation.

Flatness removes a built-in hierarchy or index, making discovery difficult at scale. Directories, portals, and search engines arose to supply the organization the core architecture omitted.
