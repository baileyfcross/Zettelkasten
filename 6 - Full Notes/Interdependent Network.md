# Interdependent Network

An interdependent network contains nodes in one layer whose operation depends on nodes in another. A communication router may depend on a power station, while the power system may depend on communication control.

Dependency edges allow failure to propagate back and forth between layers. This coupling can make the combined system more fragile than either network analyzed separately.
