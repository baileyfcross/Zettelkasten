# Cyclic Module

A cyclic module is generated by one element m. The map R → Rm sending r to rm is surjective, with kernel Ann(m), so Rm is isomorphic to R/Ann(m).

This description connects elements to ideals. A prime p is an [[Associated Prime]] of M exactly when M contains a cyclic submodule isomorphic to R/p.
