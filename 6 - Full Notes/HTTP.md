# HTTP

Hypertext Transfer Protocol defines how Web clients request resources and how servers respond. It operates above Internet transport protocols and hides differences among the machines that store the files.

HTTP made exchange consistent across independent systems. Later extensions supported security, caching, persistent sessions, and increasingly complex applications.
