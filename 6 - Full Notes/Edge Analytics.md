# Edge Analytics

Edge analytics performs filtering, summarization, inference, or event detection near the sensors that generate data. It reduces network traffic and can produce a response even when connectivity to a central data center is slow or unavailable.

The edge has limited power, memory, and compute capacity, so models and state must be chosen for constrained execution and coordinated with downstream analysis.
