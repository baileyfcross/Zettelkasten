# Free Variable

A free variable is included in the Bayesian description but is neither searched nor fixed as evidence in the current question. Its possible values are marginalized when computing the requested distribution.

Ignoring a variable in the result does not assign it an arbitrary value. The inference accumulates its contributions according to the joint model, which can be a major source of computational cost.
