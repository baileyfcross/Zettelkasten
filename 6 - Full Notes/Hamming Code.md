# Hamming Code

A Hamming code is a family of linear error-correcting codes whose parity-check matrix uses distinct nonzero binary columns. The classic code has length seven, dimension four, and minimum [[Hamming Distance]] three.

For a single bit error, the syndrome equals the parity-check column at the corrupted coordinate. This identifies the bit to flip, so the code can correct one error rather than merely detect it.
