# Azure Cloud-Native Developer

An Azure cloud-native developer works across application code and the platform capabilities that make it deployable and operable. Identity, configuration, CI/CD, infrastructure definitions, diagnostics, managed messaging, and service limits are part of the development boundary rather than work deferred entirely to operations. This everything-as-code mindset does not eliminate specialist teams; it makes their contracts and shared responsibilities visible in the application lifecycle.
