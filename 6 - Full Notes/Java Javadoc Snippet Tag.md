# Java Javadoc Snippet Tag

The Javadoc `@snippet` tag embeds a source-code fragment in generated API documentation. It preserves code layout and supports snippet-oriented features such as highlighting without the escaping problems of raw HTML `pre` or the lost line breaks of a simple `code` element.

Snippets make executable-looking examples part of an API contract while keeping them visibly distinct from prose. They complement [[Java Markdown Documentation Comment|Markdown documentation comments]], whose fenced code is concise but does not supply the same highlighting facility described by the book.
