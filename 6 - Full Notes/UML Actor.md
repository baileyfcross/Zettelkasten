# UML Actor

A UML actor is an external role that interacts with the modeled system. It can represent a person, another system, a device, or a separate module rather than one named individual.

In a use case diagram, the actor initiates or participates in goals through communication links. In a sequence diagram, an actor can send the first message into the interaction while remaining outside the system being modeled.
