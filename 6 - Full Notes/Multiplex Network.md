# Multiplex Network

A multiplex network contains several edge layers defined over exactly the same set of nodes. Each layer may be directed or undirected and weighted or unweighted, but every entity has a corresponding presence in every layer.

The layers can represent different forms of interaction among the same people or components. Identity connections tie a node's copies together without erasing the distinction between relationship types.
