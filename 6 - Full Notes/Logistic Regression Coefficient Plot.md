# Logistic Regression Coefficient Plot

A logistic regression coefficient plot displays estimates and uncertainty from a fitted binary-outcome model. On the log-odds scale, zero is the no-association reference; on the odds-ratio scale, the corresponding reference is one.

The log-odds scale can produce a visually balanced display when odds ratios span asymmetric ranges. Color grouping and substantive labels help compare related indicators, but the numeric odds-ratio table remains the main reporting artifact.
