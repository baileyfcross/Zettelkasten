# Processor-Memory Bottleneck

The von Neumann design separates processing from memory, creating heavy traffic across the channel between them. As processors become faster, moving instructions and data can limit performance more than computation itself.

Caches retain frequently used data near the CPU, while specialized and cellular architectures reduce or redistribute traffic. Each remedy changes how designers should organize data and computation.
