# Amazon Managed Streaming for Apache Kafka

Amazon Managed Streaming for Apache Kafka runs Apache Kafka clusters while AWS handles control-plane work such as broker provisioning, replacement, patching, and availability. Producers write ordered records to partitioned topics, and consumer groups read them independently. MSK is suited to teams that need Kafka APIs and ecosystem compatibility without operating the broker fleet themselves; application-level topic design, retention, partitioning, and consumer behavior remain customer decisions.
