# Tyche Storage Protocol

Tyche is the book's Ethernet-based protocol for converged networked storage. It organizes communication channels and storage messages around a lean I/O path intended to use commodity Ethernet efficiently.

Its implementation combines preallocated memory, custom queues, NUMA-aware work placement, adaptive batching, copy reduction, and multiple network interfaces to address small-request latency and multicore scaling.
