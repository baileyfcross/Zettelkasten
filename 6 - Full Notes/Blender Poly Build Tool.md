# Blender Poly Build Tool

Poly Build supports direct topology construction by adding, moving, and deleting vertices and faces with context-sensitive cursor actions. It reduces tool switching when building a surface one polygon at a time.

The workflow is especially useful for retopology because the artist can extend clean faces over a reference surface. Snapping and planned edge flow remain necessary; the tool accelerates construction but does not decide the topology.
