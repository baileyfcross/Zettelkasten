# Network Socket

A network socket is the software endpoint used to communicate through a network port. Its specification includes the address family, socket type, and protocol needed to create a compatible connection or datagram endpoint.

Client code connects a socket to a remote endpoint, while server code binds and listens for incoming connections. The socket exposes low-level control but leaves application message framing and error handling to the program.
