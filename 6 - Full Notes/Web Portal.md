# Web Portal

A Web portal collects search, news, mail, discussion, entertainment, and other services on one page. It aims to become a user’s starting point and retain attention within a curated environment.

Advertising supported many portals during the dot-com boom. Their incentive to keep visitors could conflict with the search function that sent users elsewhere.
