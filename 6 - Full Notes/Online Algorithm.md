# Online Algorithm

An online algorithm processes input incrementally rather than requiring the complete problem instance before it begins. At every point it maintains a solution based on the information received so far.

This property is useful when data arrive as a stream or future input is unknown. [[Insertion Sort]] can maintain an ordered collection as new items arrive, while a greedy edge-coloring procedure can schedule matches even when contestants join after scheduling has begun.
