# Virtual Property and Crime

Virtual property consists of currency, objects, spaces, avatars, or capabilities whose value and use exist inside a digital environment. Theft or destruction of these items can have consequences beyond the display when they were bought with money, earned through labor, or used to participate in a community.

Immersive systems enlarge the attack surface. An intruder may steal assets, alter the environment, impersonate another participant, or insert unexpected sensory events that cause psychological or physical harm. What looks like ordinary account compromise in a flat interface can become an embodied event when it occurs around the user in a convincing virtual space.

Governance must specify ownership, transfer, restoration, evidence, and appeal rather than assuming that a virtual object is valueless because it lacks a physical form. Those rules also interact with [[Data Jurisdiction]] when platforms and participants occupy different legal locations.
