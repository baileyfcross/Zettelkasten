# .NET Namespace

A .NET namespace organizes type names and prevents unrelated libraries from colliding on the same short identifier. A `using` directive lets source code refer to types in that namespace without repeating the fully qualified name.

Namespaces and assemblies are different structures. A namespace can span several assemblies, and one assembly can contain types from several namespaces. Referencing supplies the compiled code; importing supplies name resolution convenience.
