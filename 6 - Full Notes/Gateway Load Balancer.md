# Gateway Load Balancer

A Gateway Load Balancer provides a scalable insertion point for third-party virtual network appliances such as firewalls, intrusion-detection systems, and traffic inspection devices. It distributes traffic among appliance instances while preserving a transparent path between traffic sources and destinations.

This pattern separates appliance scaling from application scaling. Organizations can centralize inspection services and make them highly available without manually directing every workload to a particular appliance instance.
