# Selenium ID Locator

A Selenium ID locator selects an element by its HTML `id` attribute using `By.id`. Because an ID is intended to be unique within a document, it usually provides a direct and efficient locator when the application assigns a stable value.

An ID-based locator can remain valid when surrounding structure or visible language changes. Dynamically generated IDs, however, should not be treated as stable merely because they are unique during one page load.
