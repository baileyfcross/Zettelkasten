# Kleene Star

The Kleene star of a language S is S* = S⁰ ∪ S¹ ∪ S² ∪ …, the set of strings formed by concatenating zero or more strings from S. Because S⁰ = {ε}, every Kleene closure contains the [[Empty String]].

When Σ is treated as a set of one-symbol strings, Σ* is exactly the set of all finite [[String|strings]] over the [[Alphabet]] Σ. The same operator supplies repetition in a [[Regular Expression]].
