# Graph Feature Generation

Graph feature generation converts nodes, edges, neighborhoods, or whole networks into numerical representations. Features may be designed from known structural measures or learned as embeddings from graph relationships.

The representation scale must match the prediction target. Local features describe a node's immediate context, global features encode broader position, and learned vectors can combine multiple structural regularities.
