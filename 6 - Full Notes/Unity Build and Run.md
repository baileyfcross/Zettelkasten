# Unity Build and Run

Unity Build and Run performs a platform build and then launches or deploys the result for immediate testing. The output format and launch behavior depend on the active platform selected in [[Unity Build Settings]].

The command shortens the edit-build-test loop but does not replace configuration review. Included scenes, [[Unity Player Settings]], installed platform support, and destination requirements still determine whether the built game is correct. A final artifact should also be tested independently of the editor session.
