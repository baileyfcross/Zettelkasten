# Static Server Power

Static server power is the energy a server consumes simply by remaining powered and available, independent of its current workload. Cooling fans, power conversion, memory refresh, and idle components contribute to this baseline.

Because the baseline can be substantial, consolidating work and turning unused machines off may save more energy than small reductions in active utilization.
