# Serious Game

A serious game is designed to address a real-world purpose through play, such as education, training, public communication, or problem solving. Entertainment can support the purpose even when it is not the final objective.

The real-world goal does not excuse weak game design. Players still need intelligible rules, meaningful challenges, useful feedback, and reasons to remain engaged.
