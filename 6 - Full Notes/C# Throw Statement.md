# C# Throw Statement

The C# `throw` statement signals an exception deliberately. Code can create and throw an appropriate exception when a violated precondition or failed operation cannot be represented as an ordinary result.

Throwing transfers control to a compatible handler higher in the call chain. The chosen exception type and message should describe the failure precisely enough for that handler, a log, or a developer to understand the violated contract.
