# Pair Programming

Pair programming has two developers work together at one workstation on the same change. One concentrates on the immediate implementation while the other reviews, anticipates consequences, and keeps the wider design in view; the roles rotate frequently.

The practice provides continuous review, spreads knowledge, and supports test-driven work. Its output includes shared understanding as well as code.
