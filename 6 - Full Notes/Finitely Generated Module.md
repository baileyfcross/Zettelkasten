# Finitely Generated Module

A module is finitely generated when a finite list of elements spans it through ring-linear combinations. Equivalently, it is the image of a finite-rank [[Free Module]].

Finite generation makes local and chain arguments manageable. Over a [[Noetherian Ring]], every submodule of a finitely generated module is finitely generated, and [[Nakayama's Lemma]] controls minimal generators over local rings.
