# Amazon Neptune

Amazon Neptune is a managed graph database for data whose relationships are central to the queries. It supports property-graph and RDF models and can traverse connected entities for uses such as knowledge graphs, recommendations, fraud relationships, and network analysis. A graph database is advantageous when relationship traversal would require expensive relational joins, but graph schema and query language should follow the application's actual access paths.
