# Screen Flow Schematic

A screen-flow schematic represents the screens or interaction states a player can enter and the actions that move between them. It reveals unreachable states, missing exits, repeated navigation, and transitions that need explicit feedback.

Because it focuses on relationships rather than visual finish, it can guide an [[Game Interface Prototype|interface prototype]] before detailed assets exist. Each node should have a purpose in the player's larger path.
