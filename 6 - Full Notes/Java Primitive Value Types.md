# Java Primitive Value Types

Java defines eight primitive types: `boolean`; the UTF-16 code-unit type `char`; the signed integer types `byte`, `short`, `int`, and `long`; and the IEEE 754 floating-point types `float` and `double`. Their names are language keywords, and fields receive a type-specific default value.

Each numeric primitive has a fixed representation and range. Integer literals are normally `int` and floating literals `double`, so suffixes or explicit conversions may be required for `long` and `float`. Primitive values are not objects and do not directly expose methods.
