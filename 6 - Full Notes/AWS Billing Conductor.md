# AWS Billing Conductor

AWS Billing Conductor creates customized billing views for groups of linked accounts. Organizations can define pricing rules and generate pro forma cost data for internal chargeback or customer billing without changing the actual AWS invoice and payment relationship.

The service separates external provider charges from an organization's internal allocation model. Clear reconciliation is important because the pro forma view can intentionally differ from the amounts AWS bills to the payer account.
