# Logistic Regression Classification

Logistic regression classification models the conditional probability of a class directly as a logistic transformation of a linear score. In the binary case, the log odds are linear in the input features.

A threshold converts the estimated probability into a discrete label, while the probability itself supports ranking and cost-sensitive decisions. Unlike a generative classifier, logistic regression does not require a model for how features are distributed within each class.
