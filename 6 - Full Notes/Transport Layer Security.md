# Transport Layer Security

Transport Layer Security protects a connection by authenticating the server, negotiating cryptographic parameters, and encrypting messages with session keys. It succeeded SSL while retaining the same goal of confidentiality and integrity over an untrusted network.

TLS combines asymmetric techniques for identity and key agreement with efficient symmetric encryption for the session. Its guarantees depend on certificate validation and secure configuration as well as on the cryptographic algorithms themselves.
