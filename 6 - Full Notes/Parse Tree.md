# Parse Tree

A parse tree displays how a [[Context-Free Grammar]] generates a string. The start symbol is the root, production applications form branches, and terminal symbols read from left to right along the leaves form the generated string.

The tree records grammatical structure without recording the order in which independent productions were applied. Each parse tree corresponds to one left derivation, so a string with two distinct parse trees demonstrates an [[Ambiguous Grammar]].
