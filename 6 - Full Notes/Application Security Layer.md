# Application Security Layer

The application security layer protects the programs through which users and systems process data. It includes secure design, input handling, identity and permission checks, testing, and maintenance throughout the [[Secure Software Development Lifecycle]].

Application weaknesses may expose data even when networks and hosts are well defended. [[Security Code Review]], [[Security Architecture Analysis]], and [[Penetration Testing]] examine different aspects of this layer before and after deployment.
