# Linguistic Marker Set

A linguistic marker set is an explicitly developed group of words or forms used to represent a concept in a text corpus. It replaces a single intuitive keyword with a set grounded in how the corpus actually expresses the idea.

Marker construction is iterative. Researchers explore language use, add or remove forms, and examine associations so the set captures meaningful variation without admitting excessive false positives.
