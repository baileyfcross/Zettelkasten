# Texture Paint Symmetry

Texture Paint symmetry mirrors brush actions across enabled object axes. It keeps repeated sides visually consistent and reduces duplicate work on assets designed around bilateral or radial structure.

The mesh origin and local axes define the reflection planes, so unapplied transforms or an offset origin can produce unexpected copies. Symmetry is most effective when the UV layout and model topology support the same structural repetition.
