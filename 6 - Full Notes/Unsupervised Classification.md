# Unsupervised Classification

Unsupervised classification discovers groups when class labels and often the number of classes are unknown. The data representation, proximity measure, and clustering algorithm determine the proposed organization.

This contrasts with [[Supervised Classification]], where labeled examples define the classes to be predicted. An unsupervised result still requires validation and domain interpretation because the algorithm's structure is not automatically a meaningful taxonomy.
