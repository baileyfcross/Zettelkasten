# Activity Log

An activity log records a time-ordered view of events or state changes that matter during application use. In a reactive Angular form, subscriptions can append changes from the [[Form Model]] as they occur.

The log makes behavior visible without stopping the application at every step. It is especially useful for changes produced asynchronously, where the final state alone does not reveal the order that led to it.
