# Page Factory FindBy Annotation

The Page Factory `@FindBy` annotation declares how a page-object field should locate a web element. An ID, name, CSS selector, XPath, or another supported strategy is attached to the field instead of repeated inside interaction methods.

The annotation describes location only; behavior remains in [[Page Object Interaction Method|page methods]]. Descriptive field names are still necessary because compact syntax does not make an ambiguous element understandable.
