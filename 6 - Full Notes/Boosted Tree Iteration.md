# Boosted Tree Iteration

A boosted tree iteration adds another tree to an existing ensemble to correct its current residual or gradient error. The number of rounds controls model capacity together with learning rate and tree complexity.

Too few rounds underfit, while too many can overfit unless regularization and validation guide stopping.
