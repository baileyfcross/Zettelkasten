# Absolute Error

Absolute error is the magnitude of the difference between an exact value $x$ and an approximation $x^*$: $|x-x^*|$.

It measures error in the same units as the quantity. Its importance depends on scale, so [[Relative Error]] is often more informative when comparing approximations of very different magnitudes.

An absolute error bound remains meaningful near zero, where division by the exact value makes relative error unavailable or misleading. Numerical stopping rules often combine an absolute tolerance for small values with a relative tolerance for larger values.
