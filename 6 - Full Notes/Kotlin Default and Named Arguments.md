# Kotlin Default and Named Arguments

A Kotlin parameter can declare a default value that is used when the caller omits that argument. Defaults let one function represent common and exceptional call shapes without creating a separate overload for every combination.

Named arguments bind supplied values to parameter names at the call site. They make the meaning of similar values visible and allow selected defaulted parameters to be skipped. Once names are used, the call records part of the function's parameter vocabulary as well as its value order.
