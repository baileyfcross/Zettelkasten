# IBM Personal Computer

IBM introduced its Personal Computer in 1981 using an Intel processor and components supplied largely by outside vendors. The company’s reputation helped the machine enter businesses rapidly.

Its relatively open component structure and externally supplied operating system made it easier for competitors to build compatible machines. The resulting ecosystem shifted industry power away from IBM.
