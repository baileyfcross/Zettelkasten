# Alpha-Investing Feature Selection

Alpha-investing feature selection treats sequential feature tests as investments from a changing statistical wealth. Accepting a useful feature can replenish the budget, while testing candidates spends it.

The procedure is suited to streaming dimensions because it makes an immediate inclusion decision while controlling the accumulation of false discoveries. Its behavior depends on the order of arriving features and on how aggressively the available testing wealth is allocated.
