# Dynamic Technology

Dynamic technology is the behavior of a game's technical components while play is occurring. It includes the realized output of randomizers, artificial intelligence, simulation, rendering, networking, and every other executing part of a digital game's code.

An implementation can be correctly inscribed yet produce unexpected runtime behavior because timing, state, probability, performance, and player input interact. Treating the runtime result as its own analytical element encourages observation and instrumentation rather than assuming that source code alone reveals the experience.
