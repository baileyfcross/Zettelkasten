# CSS Flex Wrapping

The `flex-wrap` property decides whether flex items remain on one line or are divided across several lines when they do not fit. Wrapping can proceed in the normal cross-axis direction or in reverse.

Each flex line distributes its own free space, so items on different lines do not necessarily align to the same main-axis sizes. The `flex-flow` shorthand combines wrapping with [[CSS Flex Direction]].
