# Xamarin.Forms ContentPage

A Xamarin.Forms `ContentPage` represents one screen whose `Content` contains a visual hierarchy of layouts and controls. It can be declared in XAML with a code-behind class or constructed entirely in C#.

The page participates in navigation and provides lifecycle events for appearance and disappearance. Keeping page logic focused on presentation while services and view models handle application concerns makes the screen easier to reuse and test.
