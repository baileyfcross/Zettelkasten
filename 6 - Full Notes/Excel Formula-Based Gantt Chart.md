# Excel Formula-Based Gantt Chart

An Excel formula-based Gantt chart uses date headings across columns and conditional formatting to shade the dates that fall within each task's start and end boundaries. An AND rule tests whether the column date is on or after the task start and on or before the task finish.

Mixed references keep the timeline heading's row fixed while allowing its column to change, and keep each task's date columns fixed while allowing its row to change. The resulting chart remains tied to worksheet values, so changing a schedule immediately changes the bars. It visualizes timing but does not by itself calculate dependencies or resource conflicts.
