# Egocentric Network Visualization

An egocentric network visualization displays a selected node, its neighborhood, or a small set of related communities rather than drawing an entire large graph. Restricting the view makes local edge weights and associations legible.

Removing the focal node can reveal relationships among its neighbors that its many incident edges would otherwise obscure. The view supports micro-analysis, while [[Community Graph Coarsening]] provides the complementary macro-level picture.
