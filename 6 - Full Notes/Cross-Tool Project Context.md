# Cross-Tool Project Context

Cross-tool project context links communication, documentation, task management, reporting, and code-delivery systems so a question can be answered from the relevant records rather than one application's partial view. Entity and time references connect the same project across systems.

Integration must respect each system's authorization and source-of-truth role. A model should cite the underlying message, document, or work item and avoid turning a synthesized answer into an untracked replacement for official state.
