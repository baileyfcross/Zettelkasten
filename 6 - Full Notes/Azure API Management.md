# Azure API Management

Azure API Management publishes APIs through a managed gateway and administrative plane. It supports versions, revisions, products, subscriptions, developer access, and policies for token validation, throttling, headers, transformations, routing, and caching. The gateway is a policy-enforcement point, not the owner of backend business logic. Its regional topology, private connectivity, capacity, policy order, and management-plane availability affect the API platform’s resilience.
