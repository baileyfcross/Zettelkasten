# CSS Transform Perspective and Backface Visibility

CSS perspective controls how distance along the z-axis changes apparent size. It can be introduced for an individual transform or established on a parent so several transformed children share one viewing context and perspective origin.

The `backface-visibility` property decides whether the reverse side of a transformed element is painted when it faces the viewer. Hiding the back face is useful when paired elements represent two sides of one object.
