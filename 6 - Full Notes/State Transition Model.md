# State Transition Model

A state transition model describes the probability of a system's current hidden state given its preceding state. It captures the dynamics that carry information forward through an iterative probabilistic model.

The model supports prediction before a new measurement is considered. Actions or controls can also condition the transition when the system's evolution depends on an intervention.
