# Parametric Curve

A parametric curve is a map $r:[a,b]\to\mathbb{R}^n$ whose image is the curve's trace. In the plane it is commonly written $r(t)=(x(t),y(t))$, while a [[Space Curve]] has a third component $z(t)$.

The parameter specifies both position and traversal. Different formulas or parameter intervals can trace the same geometric set while changing its starting point, direction, speed, or number of repetitions.
