# Unity Texture Import

Unity texture import turns a flat image file into an asset that can be sampled by materials, sprites, user interfaces, or other rendering systems. Import settings determine how Unity interprets and prepares the image for its intended use.

For a 3D surface, a texture typically becomes a property of a [[Unity Material]] rather than being attached directly to a model. That material's [[Unity Shader]] decides what the image means—for example, visible color or another surface input—so texture choice and shader expectations must agree.
