# SLES Subscription Preparation

SLES deployment begins by matching the planned machine to an available SUSE subscription and obtaining installation media or an approved cloud image. The subscription supplies registration credentials and determines which supported products, modules, repositories, updates, and services the installed system may use.

Registration can occur during [[Agama Installer Workflow]] or after installation through [[SLES System Registration]]. Treating entitlement information as an installation prerequisite avoids completing a server that cannot reach its intended software channels, while an intentionally unregistered installation requires a separate repository and update plan.
