# Model-View-ViewModel Pattern

Model-View-ViewModel (MVVM) separates domain data, its visual representation, and the view-facing state and operations that mediate between them. The view model can format a discount for display and expose actions without putting that work directly in a view. The book applies the arrangement to an Angular front end backed by an ASP.NET Core API, showing that the boundary is a user-interface design idea rather than a feature exclusive to one framework.
