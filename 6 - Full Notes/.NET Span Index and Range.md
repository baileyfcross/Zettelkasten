# .NET Span Index and Range

`Span<T>` provides a bounded view over contiguous memory without requiring a new array for each slice. It supports efficient processing of part of an array, stack memory, or another compatible buffer while retaining element type and bounds.

The `Index` type can describe a position from the start or end, and `Range` describes a start-to-end interval. C# index and range syntax makes these values concise, while the underlying operation can avoid copying when the target exposes span-aware access.
