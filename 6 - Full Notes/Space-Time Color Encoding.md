# Space-Time Color Encoding

Space-time color encoding applies a stable palette or set of class boundaries to observations across both locations and times. Stability allows a color to retain the same quantitative meaning in every panel or animation frame. Color can also encode a temporal category, such as weekday versus weekend, while symbol size carries the measured value. The two roles must remain separable in the legend and display.
