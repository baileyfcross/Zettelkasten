# Azure Technical Architect

An Azure technical architect supplies deep, hands-on knowledge of a platform or technology stack. The role expands high-level reference components into implementable detail, coaches engineers, and connects solution intent with operational reality. For example, a technical architect can turn an AKS box on a solution diagram into node-pool, networking, scaling, policy, and deployment decisions that engineers can build and test.
