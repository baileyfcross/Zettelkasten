# Amazon Bedrock Intelligent Prompt Routing

Amazon Bedrock Intelligent Prompt Routing directs a request to an appropriate foundation model according to the request’s complexity and the available models’ capabilities. Straightforward prompts can use a faster, less expensive model, while harder work is routed to a stronger model. Routing seeks a better quality, latency, and cost balance than sending every prompt to the largest model, but the selected route still requires task-specific evaluation.
