# Excel SUM Function

The Excel SUM function adds numeric values supplied as cells, ranges, constants, or multiple arguments. It is clearer and more scalable than a long chain of addition operators, especially when the values occupy a contiguous range.

The chosen range defines the result, so totals should be checked for accidentally omitted rows, included subtotals, and future data added outside a fixed boundary. SUM does not filter by meaning on its own. When only certain records should contribute, [[Excel Conditional Aggregation Functions]] or [[Excel SUBTOTAL Function]] may better represent the intended rule.
