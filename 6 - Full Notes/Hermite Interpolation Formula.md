# Hermite Interpolation Formula

Hermite interpolation constructs a polynomial that matches both function values and prescribed derivative values at the interpolation nodes. With $n+1$ nodes supplying values and first derivatives, the interpolant can have degree at most $2n+1$.

The extra derivative conditions distinguish it from [[Lagrange Interpolation]], which matches values only. The resulting polynomial joins the data with local slope information but requires more computation and reliable derivative data.
