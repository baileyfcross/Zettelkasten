# Unity Build Settings

Unity Build Settings define the target platform, included scenes, platform-specific build options, and the command that produces a runnable game. They connect the authored project to a concrete deployment artifact.

The window also exposes [[Unity Player Settings]], platform switching, and the distinction between Build and Build and Run. Before building, the scene list and order should be verified because they govern startup content and the indexes used by [[Unity SceneManager]].
