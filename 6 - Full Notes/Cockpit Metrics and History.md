# Cockpit Metrics and History

Cockpit's overview and metrics views present current CPU, memory, disk, and network activity and can connect those observations to retained historical data when the required performance collection support is installed. The display is an interface over host measurements rather than a substitute for the underlying data source.

Instant metrics help confirm a live symptom, while history reveals whether it is persistent, periodic, or correlated with another resource. Missing history should be diagnosed as a collection or retention issue instead of interpreted as proof that the earlier load did not occur.
