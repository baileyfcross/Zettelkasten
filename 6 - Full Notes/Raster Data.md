# Raster Data

Raster data divide a geographic extent into a rectangular grid and store a value for each cell. A layer may represent a quantitative field such as elevation or categorical classes such as land cover. Cell size determines spatial resolution, while extent and [[Coordinate Reference System]] locate the grid. Multiple aligned layers can form a [[RasterStack]] for different variables or times.
