# CSS Absolute Length Units

CSS absolute length units include physical-style units such as inches, centimeters, millimeters, points, and picas, along with pixels. CSS fixes conversion ratios among these units, with 96 CSS pixels corresponding to one CSS inch.

The CSS inch is a reference measurement and need not equal a physical inch on every screen. Absolute units are useful when a stable internal relationship matters, while [[CSS Relative Length Units]] adapt measurements to fonts or viewports.
