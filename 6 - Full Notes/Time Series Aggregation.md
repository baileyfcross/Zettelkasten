# Time Series Aggregation

Time-series aggregation groups observations into a coarser temporal grid and summarizes each group with a function such as a mean, sum, minimum, or maximum. Daily values may become monthly values indexed by [[yearmon Time Index]], for example. Aggregation changes temporal resolution and can reveal broad patterns, but it also removes within-period variation, so the summary function and grouping interval must fit the analytical question.
