# Voice User Interface

A voice user interface lets people control a system through speech and hear or see its responses. Its design includes prompts, vocabulary, turn-taking, error recovery, and expectations about what the assistant can do.

Careful VUI design can compensate for imperfect [[Automatic Speech Recognition]] by narrowing likely answers with a [[Directed Prompt]], confirming risky choices, and giving users a clear path after a mismatch.
