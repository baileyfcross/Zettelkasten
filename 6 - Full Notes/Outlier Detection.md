# Outlier Detection

Outlier detection identifies observations whose relationship to the rest of a data set is unusually weak or structurally different. Methods can use distributions, pairwise distance, neighborhood density, clustering, or fuzzy membership.

Detection is a screening step rather than automatic deletion. Suspected cases should be investigated because correcting an error and erasing a rare event have very different consequences.
