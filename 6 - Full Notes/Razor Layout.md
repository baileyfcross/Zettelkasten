# Razor Layout

A Razor layout defines the shared outer structure of multiple pages or views, such as navigation, metadata, scripts, and a common visual shell. Each content page supplies its body and may define named sections consumed by the layout.

Layouts reduce duplicated markup and create a single place for application-wide presentation changes. Shared view imports and startup files can further establish common namespaces, tag helpers, and default layout choices.
