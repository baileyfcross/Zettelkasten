# Butteraugli Perceptual Image Comparison

Butteraugli is a perceptual image-difference metric designed to estimate where compression changes become noticeable. It compares images through a model tuned to visual perception rather than treating every channel error equally.

A perceptual score can help an encoder search for smaller output that remains visually acceptable, especially at high quality. The metric does not eliminate judgment: content, display conditions, and the location of error still affect whether a result is appropriate.
