# TestNG Testing Framework

TestNG is a Java testing framework designed for unit, integration, and functional testing. In Selenium projects it supplies test discovery, lifecycle annotations, assertions, data providers, grouping, dependencies, XML suite configuration, reporting, and parallel execution.

Selenium controls the browser, while TestNG organizes and evaluates the tests. Keeping those responsibilities distinct makes browser scenarios easier to configure, repeat, and report.
