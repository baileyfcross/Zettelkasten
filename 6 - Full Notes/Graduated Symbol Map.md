# Graduated Symbol Map

A graduated symbol map assigns observations to classes and gives every member of a class the same symbol size. It trades the continuous magnitude encoding of a [[Proportional Symbol Map]] for a small set of visually discriminable categories. [[Fisher-Jenks Classification]] can define classes from the distribution, and [[Symbol Range Grading]] can select sizes that remain distinguishable. A legend must show both boundaries and corresponding symbols.
