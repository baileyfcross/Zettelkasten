# Positive Input Edge

A positive input edge occurs when a digital control was released in the previous frame and is pressed in the current frame. It represents the moment of activation rather than the continuing held state.

Menus, jumps, and toggle commands often respond to this edge so one physical press causes one action. The result is computed from consecutive [[Input Polling|polled]] states or produced by an equivalent event system.
