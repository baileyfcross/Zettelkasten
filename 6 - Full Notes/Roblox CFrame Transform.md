# Roblox CFrame Transform

A CFrame represents both a three-dimensional position and an orientation. Roblox scripts use it to place or rotate parts, define coordinate frames, transform points and directions, and compose spatial changes in a specific order.

CFrame multiplication is order-sensitive because each transform changes the coordinate frame in which the next operation is interpreted. Relative transforms are often clearer than repeatedly editing position and rotation components separately. CFrames also provide the target values used by [[Roblox TweenService]], [[Roblox Model Primary Part Movement]], and scripted cameras.
