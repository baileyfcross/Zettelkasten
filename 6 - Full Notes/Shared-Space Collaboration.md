# Shared-Space Collaboration

Shared-space collaboration lets multiple users perceive and manipulate the same real and virtual objects in a common physical workspace. Each participant receives a view rendered from an individual pose while the underlying augmented scene remains shared.

The physical setting supplies a natural reference for speech, gaze, and gesture. Consistent registration and synchronized object state let actions appear to occur in one space rather than in disconnected private displays.
