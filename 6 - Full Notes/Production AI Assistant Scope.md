# Production AI Assistant Scope

A production AI assistant needs an explicit scope that defines its supported users, tasks, knowledge sources, tools, actions, and escalation boundaries. Scope prevents a successful prototype from becoming an undefined general-purpose interface whose authority expands merely because the model can produce plausible text about adjacent topics.

The scope should appear in system instructions, tool permissions, evaluation datasets, user-facing expectations, and operational runbooks. Unsupported requests need a refusal or handoff path. When new capabilities are proposed, teams can evaluate them as deliberate scope changes with their own data, security, quality, and ownership requirements.
