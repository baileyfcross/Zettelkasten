# Routing Algorithms

A routing algorithm selects the sequence of links and switches that carries a message from source to destination. Deterministic routing follows a fixed rule, while adaptive routing can react to failures or congestion.

Route choice affects hop count, contention, ordering, and fault tolerance. A shortest path is not always the fastest path when many messages compete for the same links, so distributed performance depends on traffic as well as topology.
