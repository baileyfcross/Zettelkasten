# Angular

Angular is a client-side framework for building reactive, cross-platform web applications for desktop and mobile browsers. It combines a component-based and modular application structure with templates, routing, dependency injection, forms, HTTP communication, and testing support.

Angular source is commonly written in [[TypeScript]] and compiled into JavaScript understood by browsers. In a full-stack application it supplies the client while [[ASP.NET Core]] exposes server-side endpoints and persistence operations.
