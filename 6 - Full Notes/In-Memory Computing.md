# In-Memory Computing

In-memory computing keeps active data and intermediate state in main memory so processors avoid repeated disk access. It is especially useful for interactive, iterative, and streaming workloads whose latency is dominated by storage transfers.

Memory residence does not remove the need for durability, distribution, or recovery. Systems must decide what to replicate, checkpoint, or reconstruct after a failure.
