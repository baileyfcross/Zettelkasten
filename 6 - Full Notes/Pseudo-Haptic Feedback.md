# Pseudo-Haptic Feedback

Pseudo-haptic feedback uses synchronized visual manipulation to create a haptic impression without generating the corresponding physical force. If an on-screen object moves less than expected for the user's hand motion, the discrepancy can be interpreted as friction, mass, or stiffness.

The technique exploits multisensory inference: visual consequences alter the interpretation of movement and effort. It can extend an interface whose actuator cannot reproduce a property, but it depends on believable temporal and spatial coupling. Excessive mismatch breaks the illusion and reveals that the visual object is merely lagging or scaled.
