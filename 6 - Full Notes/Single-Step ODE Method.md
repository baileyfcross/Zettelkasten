# Single-Step ODE Method

A single-step ODE method computes the next approximation using information associated with the current point, without requiring a stored history of several earlier solution values.

[[Euler Method]] and Runge-Kutta formulas are self-starting examples. Their one-step structure makes changes of step size comparatively straightforward, although the function may be evaluated several times inside one step.
