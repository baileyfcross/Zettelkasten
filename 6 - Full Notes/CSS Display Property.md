# CSS Display Property

The `display` property controls the kind of box an element generates and the formatting role it adopts. Values can create block, inline, list-item, inline-block, table-related, flex, or grid behavior, and `none` suppresses box generation entirely.

The source also covers multi-keyword concepts such as outer flow and inner formatting roles. Changing display affects layout, not the document element's semantic identity.
