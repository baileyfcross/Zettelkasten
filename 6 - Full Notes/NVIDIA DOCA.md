# NVIDIA DOCA

NVIDIA DOCA is the software framework for developing and operating accelerated services on BlueField and related NVIDIA networking platforms. It supplies SDK libraries, APIs, drivers, tools, and supporting software for network, storage, security, telemetry, and infrastructure acceleration.

DOCA makes the DPU data plane programmable in a role analogous to CUDA's programmability of the GPU, but for different workloads and APIs. Because DPU code can affect the entire node's traffic and security boundary, development and rollout require strict validation and governance.
