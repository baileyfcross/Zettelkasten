# Sed Substitution Command

The sed substitution command replaces text matched by a regular expression with replacement text. Flags determine whether replacement affects the first match, every match, a selected occurrence, or only records satisfying another condition.

The delimiter can be changed when slash-heavy paths would otherwise require excessive escaping. Replacement text has its own metacharacters, so captured groups and literal ampersands must be handled according to sed's replacement rules rather than the search-pattern rules.
