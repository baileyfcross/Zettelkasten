# AWS CloudOps Compliance and Audit Pillar

The configuration, compliance, and audit pillar keeps an inventory of cloud resources, records changes, and evaluates current state against required controls. Services such as [[AWS CloudTrail Trail|AWS CloudTrail]], [[AWS Config Rule|AWS Config]], and [[AWS Systems Manager]] provide complementary evidence about actions, configurations, and managed nodes. Automation can continuously detect drift, but remediation rules still need explicit ownership and an understood exception process.
