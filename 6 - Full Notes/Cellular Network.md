# Cellular Network

A cellular network divides a geographic region into small radio coverage areas whose frequencies can be reused at sufficient distance. Low-power phones communicate with nearby base stations rather than one powerful transmitter.

The network tracks subscribers and coordinates movement among cells. This architecture expanded mobile capacity beyond the small number of channels available to earlier car-phone systems.
