# Potential Flow Finite Element Procedure

The potential-flow finite element procedure selects a scalar potential and element type, defines gradient-to-velocity relationships, derives element equations, and assembles a global system with boundary conditions.

The solved nodal potentials are differentiated to obtain element velocities and volumetric rates. This sequence mirrors structural FEM while replacing displacement and force with flow-specific field quantities.
