# Interactive Space-Time Cube

An interactive space-time cube represents two spatial dimensions and time as three orthogonal axes without first aggregating a dimension. The cube can be rotated, moved, and zoomed, while keyboard controls select visible slices along each axis. Different orientations resemble alternative [[Hovmoller Diagram|Hovmoller views]]. The cube preserves the full array conceptually but suffers from occlusion and perspective, so two-dimensional reductions remain important.
