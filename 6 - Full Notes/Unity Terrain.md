# Unity Terrain

Unity Terrain is a specialized component and authoring system for large outdoor landscapes. It represents a height-based surface that can be sculpted, textured, populated with vegetation, and explored with a character controller.

Because terrain is heightmap based, it excels at hills, valleys, and broad ground but cannot directly represent arbitrary overhangs. Imported mesh landscapes can supply freer geometry, while Terrain preserves access to Unity's integrated sculpting, surface-painting, tree, and detail tools.
