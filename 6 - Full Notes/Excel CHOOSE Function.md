# Excel CHOOSE Function

The Excel CHOOSE function returns one item from a supplied list according to a numeric index. An index of one selects the first item, two selects the second, and so forth. The alternatives may be constants, cell references, ranges, or expressions.

CHOOSE is useful for small controlled mappings and for selecting among calculation branches when an index already exists. The index must fall within the supplied list, and a long list can become difficult to maintain. Larger mappings are usually clearer in a worksheet table retrieved through a lookup because the choices remain visible and editable without changing the formula.
