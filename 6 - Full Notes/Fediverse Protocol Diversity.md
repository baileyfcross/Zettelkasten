# Fediverse Protocol Diversity

The Fediverse is a collection of independently operated social services that communicate through federation protocols rather than one central provider. The source lists Mastodon, Diaspora, Friendica, GNU social, Hubzilla, Lemmy, PeerTube, and Pleroma as examples, while emphasizing that they do not all use the same protocol.

ActivityPub is prominent, but the ecosystem also includes Diaspora's pod-to-pod protocol, DFRN for distributed profiles and secure friend relationships, OStatus, Micropub, Matrix, and other approaches. Federation therefore does not automatically imply universal interoperability. Applications must know which object model and delivery protocol a server supports. [[ActivityPub Federation Model]] and [[Matrix Federated Messaging]] illustrate two different scopes within the wider decentralized landscape.
