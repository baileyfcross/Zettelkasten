# Blender Freestyle Style Modifiers

Freestyle modifiers vary stroke color, alpha, thickness, or geometry according to properties such as position along a stroke, crease angle, surface curvature, camera distance, object distance, material, noise, or tangent direction.

The modifiers make a detected contour expressive without changing the underlying mesh. A calligraphic thickness rule, distance fade, or noise displacement can transform the same line set into different technical or artistic styles.
