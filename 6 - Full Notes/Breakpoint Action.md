# Breakpoint Action

A breakpoint action performs diagnostic work when execution reaches a breakpoint, such as writing a message to the output window. It can capture values without requiring the program to remain paused.

Actions can be combined with conditions so output is produced only for relevant states. This turns a breakpoint into a targeted trace point while retaining the option to stop execution when needed.
