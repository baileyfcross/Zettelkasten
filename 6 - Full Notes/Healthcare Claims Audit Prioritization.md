# Healthcare Claims Audit Prioritization

Healthcare claims audit prioritization ranks claims, episodes, or providers so limited investigative effort is directed toward the most informative or costly cases. The objective differs from ordinary classification because only a fraction of flagged items can be reviewed.

A useful ranking combines estimated risk, potential financial impact, and the expected value of an audit. It should also provide the evidence behind the score and record audit outcomes for learning. Concentrating only on familiar patterns can create a feedback loop that misses new fraud types, so exploration remains necessary.
