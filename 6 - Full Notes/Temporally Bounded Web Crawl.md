# Temporally Bounded Web Crawl

A temporally bounded web crawl collects pages or articles whose timestamps fall inside an explicit time window. Date extraction and normalization let the crawler stop following material outside the period instead of treating the web as an undifferentiated archive.

Missing, ambiguous, or revised timestamps complicate the boundary, and link discovery can still be biased by the starting pages. The collector should retain the observed timestamp and rule used so later analysis can distinguish publication time from retrieval time.
