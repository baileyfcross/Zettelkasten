# Production Software Multiplication of Effort

Turning a program into production software requires more than finishing its core function. It must become part of a system of interacting components and gain the reliability structures needed for use by people outside its original development context.

Fred Brooks estimated that each transformation could triple effort, making a production system roughly nine times as costly as a standalone program. The rule highlights the large amount of work hidden behind deployment, integration, documentation, testing, and support.
