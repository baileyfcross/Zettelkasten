# Blender Mesh Tool Operator Settings

Many Blender mesh operations expose an adjustment panel immediately after execution. It retains parameters such as distance, direction, steps, axis, falloff, clamping, or fill so the artist can refine the result numerically after the first gesture.

Starting another operation normally ends that opportunity, making the settings part of the current action rather than a permanent modifier. Reviewing them before continuing improves precision and reveals capabilities that are not obvious from the toolbar icon alone.
