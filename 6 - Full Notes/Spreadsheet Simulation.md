# Spreadsheet Simulation

A spreadsheet simulation represents game state, formulas, and uncertain events in recalculating cells so that a designer can observe system behavior without implementing the complete game. Random-number functions generate trials, while tables record the results for analysis.

The model should expose assumptions, separate inputs from formulas, and preserve the sequence of complicated rules in a flowchart when necessary. It is useful for balance questions because parameters can be changed quickly and their effects compared across many trials.
