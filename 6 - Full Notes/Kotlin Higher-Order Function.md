# Kotlin Higher-Order Function

A higher-order Kotlin function accepts another function as an argument, returns a function, or does both. A function type states the parameter types and result type of the behavior that can cross this boundary.

This separates an algorithm's stable structure from an operation supplied by its caller. Collection functions use the pattern for predicates and transformations, allowing the same traversal mechanism to filter, map, or otherwise process values according to a passed lambda or function reference.
