# Durable Memory Selection

Durable agent memory should contain concise, reusable, validated information such as repository conventions, deployment procedures, workflow progress, event outcomes, or references to approved observability summaries. It should not become a copy of every log or model response.

Secrets, credentials, personal data, private reasoning, and unverified outputs are unsafe memory. A hallucination that is stored as long-term knowledge can contaminate later decisions. Selection therefore asks not only whether information might be useful, but whether its source, accuracy, sensitivity, scope, and future influence are acceptable.
