# Real-Time Global Illumination

Real-time global illumination approximates light that travels through multiple surface interactions quickly enough for an interactive display. In AR, it can support diffuse color transfer, indirect shadows, and specular effects connecting real and virtual objects.

The method must update as the viewpoint, objects, or lights change, while respecting a strict frame budget. Practical techniques trade physical completeness for an approximation whose most visible common-lighting effects remain coherent.
