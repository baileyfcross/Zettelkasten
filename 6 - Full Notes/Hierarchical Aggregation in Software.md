# Hierarchical Aggregation in Software

Hierarchical aggregation builds larger software objects from smaller components joined by defined interfaces. At each level, an aggregate can be treated as a unit without requiring constant attention to its internal details.

The hierarchy controls complexity through decomposition, modularity, abstraction, and information hiding. It succeeds only when interfaces preserve the assumptions that neighboring levels need.
