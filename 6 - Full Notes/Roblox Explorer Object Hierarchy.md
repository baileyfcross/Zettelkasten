# Roblox Explorer Object Hierarchy

The Explorer represents a Roblox place as a hierarchy of services, containers, models, parts, scripts, interfaces, and other instances. Parent-child placement is meaningful: it controls organization, inheritance of context, and how scripts locate related objects.

Expanding the hierarchy makes otherwise invisible structure inspectable. A script can traverse from itself to a parent or child instead of relying on a global name, and a model can keep its parts and behavior together. The hierarchy is therefore both an editor navigation tool and the structural basis of [[Roblox Object Hierarchy Scripting]].
