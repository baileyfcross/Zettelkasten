# The Decision Problem

The decision problem asks whether an algorithm can determine, for every proposition in a formal logical system, whether that proposition is true. Work by mathematical logicians in the 1930s showed that no such general algorithm exists.

The result established a permanent limit on automatic reasoning. Related arguments show why no program can correctly decide for every possible program whether it will halt or loop forever.
