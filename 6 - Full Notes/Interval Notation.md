# Interval Notation

Interval notation describes a connected portion of the [[Real Number Line]]. Square brackets include a finite endpoint, parentheses exclude it, and infinity always receives a parenthesis because it is not a real endpoint. Intersections retain only values shared by every interval, while unions collect values belonging to at least one interval.
