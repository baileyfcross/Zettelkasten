# UML Use Case

A UML use case names a capability through which an actor pursues a goal with the system. It is drawn as an oval inside the system boundary and labeled with the behavior, such as ordering food or producing a sales report.

The use case states what useful outcome is available without specifying the classes, database calls, or message sequence that implement it. Those details belong in complementary models.
