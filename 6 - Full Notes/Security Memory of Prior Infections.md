# Security Memory of Prior Infections

Security memory of prior infections is the capacity to retain useful knowledge from earlier attacks and apply it to later encounters. The system records indicators, affected behavior, response outcomes, and recovery evidence rather than returning to an uninformed state.

This immune-inspired property can accelerate recognition and response, but stored experience must be updated when attackers change techniques. It complements both [[Signature-Based Threat Detection]] and a changing [[Behavioral Security Baseline]].
