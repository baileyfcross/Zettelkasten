# Recommendation Serendipity

Recommendation serendipity is an unexpectedly relevant suggestion that helps a user discover an appealing option outside the most predictable continuation of prior behavior. It requires relevance and surprise together: an unfamiliar item that has no value to the user is merely random.

Similarity provides a credible path from known preferences, while diversity and novelty prevent the candidate set from collapsing into repetition. The [[Exploration-Exploitation Tradeoff]] therefore shapes serendipity: the system must spend some opportunities learning beyond safe recommendations without sacrificing so much relevance that users stop trusting it.
