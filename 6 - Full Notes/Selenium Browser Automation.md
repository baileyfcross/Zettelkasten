# Selenium Browser Automation

Selenium browser automation drives a web browser through code so a test can reproduce user navigation and interaction. A script uses a [[Selenium Client Language Binding]] to issue commands, while a [[Browser Driver]] translates them into operations in a specific browser.

The same test intent can be exercised across supported browsers and operating systems. Reliable automation still requires explicit setup, observable expectations, and termination of the [[WebDriver Browser Session]] after the scenario.
