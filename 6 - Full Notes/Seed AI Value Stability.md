# Seed AI Value Stability

A seed AI is the initial system in a sequence of self-improving successors. Because the seed is less capable than the systems it may create, developers might be able to teach and test its values before it gains overwhelming power.

The safety requirement is not merely that the first system behave well. Core constraints and values must survive every redesign, copy, or successor it produces. If self-modification can alter the [[Reinforcement Learning Reward Function]] arbitrarily, a benevolent starting point offers no guarantee about the later system. Value stability is therefore part of correctness across architectural change.
