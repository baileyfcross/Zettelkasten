# Gaussian Membership Function

A Gaussian membership function assigns maximum membership at a center and decreases smoothly according to a bell-shaped curve controlled by its spread. It provides a differentiable representation without sharp corners.

The center states the prototype value and the width determines how quickly membership fades. Overlapping Gaussian functions can encode ordered fuzzy categories.
