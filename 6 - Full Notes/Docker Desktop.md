# Docker Desktop

Docker Desktop packages a graphical container-development environment for macOS and Windows. It combines Docker Engine, the command-line client, Compose, credential support, and optional local Kubernetes facilities while managing the virtualized Linux environment needed to run Linux containers on those hosts.

The interface exposes common image, container, port, environment, and volume operations without changing the underlying container model. A developer can launch, pause, restart, stop, inspect, and open a container while still keeping Dockerfiles, Compose files, and commands as the reproducible description of the workload.
