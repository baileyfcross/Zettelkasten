# Salient Image Feature

A salient image feature is a local point or region whose intensity structure is distinctive enough to be found reliably after modest image transformation. Corners and textured junctions are more useful than flat areas because their neighborhoods can be localized in multiple directions.

Clone detectors use a sparse set of such features to avoid comparing every pixel block. Each feature receives a descriptor that supports fast matching, after which the spatial relationship between matched features supplies evidence for or against duplication.
