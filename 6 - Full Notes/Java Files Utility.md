# Java Files Utility

`java.nio.file.Files` supplies static operations over Path values for checking attributes, creating files and directories, opening streams and readers, reading or writing complete content, listing, walking, copying, moving, and deleting.

Most failures are expressed as informative I/O exceptions rather than an unexplained false result. Options make replacement, link handling, and opening behavior explicit. Methods that return streams hold underlying resources and should be used within [[Java Try-with-Resources]].
