# Root of an Equation

A root of an equation $f(x)=0$ is a value of $x$ at which the function vanishes. Root-finding converts many nonlinear equations into the task of locating such a zero.

[[Bisection Method]] brackets a root using a sign change, while [[Newton Root-Finding Method]] uses local derivative information. A root is not automatically an optimum unless it is a zero of an appropriate derivative and passes further tests.
