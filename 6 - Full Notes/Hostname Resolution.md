# Hostname Resolution

Hostname resolution converts a host or domain name into one or more IP addresses that a network operation can use. In .NET, DNS utilities can perform this lookup and expose the canonical host information and returned address collection.

The result should not be treated as a permanent one-to-one identity. A name can change addresses, provide several addresses, or fail to resolve, so connection code must handle those outcomes explicitly.
