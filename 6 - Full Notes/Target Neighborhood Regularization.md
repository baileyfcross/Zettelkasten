# Target Neighborhood Regularization

Target neighborhood regularization encourages proteins with high target similarity to occupy nearby positions in a drug-target latent space. The book constructs a nearest-neighbor graph from target sequence similarity and adds its penalty to the factorization objective.

It parallels [[Drug Neighborhood Regularization]] but uses independent similarity data and a separate regularization strength. The two sides need not carry equal information, particularly when one domain has many entities with only one verified interaction.
