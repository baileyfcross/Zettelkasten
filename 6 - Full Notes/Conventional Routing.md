# Conventional Routing

Conventional routing applies a shared route template whose segments select controller, action, identifiers, or optional values. It centralizes a common URL scheme and is frequently suited to server-rendered MVC applications with consistent controller conventions.

The convention becomes part of every matched public URL. APIs often prefer attribute routing when each resource contract benefits from a route declared beside its action, but the two approaches can coexist deliberately.
