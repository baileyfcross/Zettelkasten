# System Hierarchy

A system hierarchy is an organization in which a system contains lower-level systems as parts and is itself a part of a higher-level system. Each level has behaviors that can be described without reproducing every detail below it.

Designers move among these integrative levels to connect atomic parts, loops, and the complete experience. Clear levels support [[Systemic Depth]], while long nonlocal dependencies across levels can make a design brittle.
