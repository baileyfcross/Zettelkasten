# R Source Command

The R source command reads a script file and evaluates its expressions as one operation. It lets a user load function definitions or execute a complete analysis from the console without copying the script text into the prompt.

The path is resolved from the working directory unless an absolute path is supplied, and path separators must be valid for the platform. Sourcing makes reuse convenient, but the called script should still make its required inputs and side effects clear.
