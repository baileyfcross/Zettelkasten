# Cluster Density Variation

Cluster density variation occurs when some groups occupy compact, crowded regions while others are sparse or diffuse. One global distance threshold or centroid objective can split a sparse cluster or absorb an outlier near a dense cluster.

Local-density methods and sensitivity analysis help address the problem. The reported result should explain how unequal densities affected parameter and algorithm choice.
