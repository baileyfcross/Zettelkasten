# Design Values as Exit Criteria

Design values become exit criteria when the team uses them to judge whether iteration has produced the intended experience consistently enough to proceed. This converts broad creative aspirations into questions that evidence from playtests can answer.

A feature-complete game can still fail this test if its play contradicts the agreed qualities. Conversely, a simpler implementation may be ready when it fulfills the values without requiring additional design complexity.
