# Crash Release Diffusion Feature

A crash release diffusion feature measures how release-related changes spread across files, directories, or subsystems. Counts, proportions, and entropy-like summaries encode the breadth of modification.

Wide diffusion may increase coordination and integration risk even when total changed lines are modest. The feature complements code size and complexity rather than duplicating them.
