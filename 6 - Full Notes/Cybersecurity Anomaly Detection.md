# Cybersecurity Anomaly Detection

Cybersecurity anomaly detection identifies activity that differs materially from a [[Behavioral Security Baseline]]. It can expose unknown attacks, compromised accounts, unusual data movement, or system faults that lack a known malicious signature.

An anomaly is evidence for investigation, not proof of attack. Effective detection balances sensitivity with context so that normal variation does not overwhelm responders and subtle harmful behavior is not absorbed into the baseline.
