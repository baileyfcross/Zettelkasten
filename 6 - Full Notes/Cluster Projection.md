# Cluster Projection

A cluster projection is the subset of values from one attribute that participates in a categorical cluster. CACTUS first finds projections relative to other attributes, intersects them, and then synthesizes projections across the full attribute set.

Projection lets the method build a multidimensional categorical cluster from supported lower-dimensional relationships.
