# CKAN Resource Metadata

CKAN resource metadata describes a published resource's URL, format, name, identifier, timestamps, and related properties. Reviewing it helps an analyst choose the correct file and detect changes in a data source.

Metadata should be preserved with the analysis because a stable catalog entry may point to updated content over time.
