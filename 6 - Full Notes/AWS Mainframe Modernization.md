# AWS Mainframe Modernization

AWS Mainframe Modernization supplies tools and managed environments for assessing, migrating, modernizing, and operating mainframe applications on AWS. It recognizes that mainframe change is more than copying compute: code, data, batch schedules, dependencies, testing, and the target operating model must be addressed together. The service supports both automated refactoring and replatforming paths so the chosen transformation depth can match business constraints.
