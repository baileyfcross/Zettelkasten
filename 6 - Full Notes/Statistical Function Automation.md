# Statistical Function Automation

Statistical function automation packages a repeated analysis into a parameterized function or iteration. In R, a custom function names its inputs, performs the operations inside its body, and returns an object that can be reused across variables or datasets.

Loops and apply-family functions offer other ways to repeat work, such as creating the same contingency table for several covariates. Automation should follow a correct manual workflow: repeating an unclear or unvalidated operation only scales its mistakes.
