# Evidence-Driven Network Agent Troubleshooting

Evidence-driven network agent troubleshooting begins with a reported symptom, gathers current facts through approved read-only tools, checks whether those facts support a conclusion, and either requests more evidence or reports the result. The model selects useful observations and explains relationships; application code controls tool execution and preserves the returned state.

The agent should behave like a careful investigator rather than a root-cause oracle. A device being reachable does not prove that its interfaces or routing peers are healthy, and an unreachable host does not prove which network layer failed. The final response remains traceable to a [[Network Troubleshooting Evidence Record]].
