# Addition Property of Equality

The addition property of equality states that adding equal quantities to equal quantities preserves equality. If (a=b), then for any real (c),

$$a+c=b+c.$$

Subtracting the same quantity from both sides is the same rule applied with an [[Opposite Number]]. It supports moving a term across an equation without changing the solution, provided the shorthand is understood as an operation on both sides. The property is central to producing [[Equivalent Equations]].
