# Sequential Color Palette

A sequential color palette encodes ordered quantitative values through a progression from light to dark or low to high chroma. It suits a [[Choropleth Map]] whose variable has a meaningful single direction. Perceptual order should agree with numeric order, and neighboring steps must remain distinguishable. The palette should also preserve legibility against boundaries and backgrounds rather than using hue changes that introduce false categories.
