# Bayesian Program

A Bayesian program consists of a probabilistic description and a question. The description defines a joint distribution from specified structure and identified parameters, while the question states which conditional distribution should be computed.

Formally separating these parts prevents a particular inference direction from being built into the model. The same joint description can answer different questions by changing the roles assigned to its variables.
