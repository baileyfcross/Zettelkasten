# Blender Scene Layer Organization

Blender 2.7x scenes provided twenty numbered layers for separating objects into reusable visibility sets. An object could be moved to a layer, and several layers could be shown together, letting an artist expose only the parts relevant to the current task.

These historical layers lacked descriptive names in the default interface, so a stable team convention or a layer-management add-on was important. Modern collections serve a related organizational role but should not be confused with this older fixed-layer system.
