# Cloud of Things

A cloud of things is a cloud service whose scope is the management or use of connected nonliving objects. Sensors report state or location, and cloud-hosted logic can monitor, coordinate, or control devices for people and organizations.

Examples include lighting, appliances, buildings, vehicles, and health-monitoring equipment. Device identity, network reach, automation, data ownership, location, and service availability become part of the system rather than properties of the physical object alone.
