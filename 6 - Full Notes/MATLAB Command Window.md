# MATLAB Command Window

The MATLAB Command Window is the interactive interface where expressions and commands are entered and evaluated immediately. It can be used like a calculator or to invoke matrix, plotting, and numerical routines.

Commands create variables in the [[MATLAB Workspace]]. Longer or reusable procedures are better placed in a [[MATLAB Function File]] rather than repeatedly entered interactively.
