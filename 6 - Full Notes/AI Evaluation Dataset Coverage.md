# AI Evaluation Dataset Coverage

An AI evaluation dataset should represent the variety and difficulty of requests the application must handle, including ordinary cases, ambiguous inputs, edge cases, safety-sensitive prompts, and requests that require refusal or escalation. A narrow dataset can make a system appear reliable while leaving important behaviors untested.

Coverage should be assessed across user intents, data sources, languages or formats, and expected tool paths. Production failures and user feedback can then supply new test cases. The dataset becomes a maintained operational asset whose breadth determines how much confidence an evaluation run can legitimately provide.
