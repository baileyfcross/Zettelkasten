# C++ Function Template

A C++ function template describes a family of functions whose parameter or return types are supplied when the function is instantiated. One algorithmic definition can consequently operate on several compatible numeric or object types.

Templates support compile-time reuse without converting every value to a common type. The operations used inside the template still impose requirements: a sorting function, for example, needs its instantiated element type to support the comparisons and assignments performed by the algorithm.
