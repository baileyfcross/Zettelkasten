# Collada Scene Interchange

COLLADA uses an XML-based schema and the `.dae` extension to exchange digital assets among graphics applications. It can carry scene and geometry information while referenced texture images remain as separate files beside the document.

An imported COLLADA asset may preserve objects without reproducing the source application's material-node setup exactly. The artist should verify image paths and rebuild incompatible shading connections before treating visual similarity in the source package as guaranteed.
