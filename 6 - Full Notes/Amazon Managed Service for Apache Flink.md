# Amazon Managed Service for Apache Flink

Amazon Managed Service for Apache Flink runs Apache Flink applications that analyze and transform streaming data. It manages the service infrastructure while applications perform stateful computations such as windowed aggregation, filtering, enrichment, and anomaly detection.

The service can consume records from sources such as [[Amazon Kinesis Data Streams]] and produce processed results for downstream storage or action. Its purpose is continuous computation over data in motion rather than ad hoc querying of data already stored in S3.
