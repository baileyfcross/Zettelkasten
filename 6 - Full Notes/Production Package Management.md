# Production Package Management

Production package management is the controlled maintenance of the language runtime and package versions used by a recurring analysis. R and its packages can update on independent schedules, so indiscriminate upgrades may change behavior or break dependencies.

A production workflow should deliberately test updates, document the working environment, and preserve a restorable set of versions. The cost of open, rapidly evolving software is not a license fee but the operational attention needed to keep the environment both current and reproducible.
