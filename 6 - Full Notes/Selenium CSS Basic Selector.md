# Selenium CSS Basic Selector

A Selenium CSS basic selector locates an element by type, class, or ID through `By.cssSelector`. A tag name targets a type, a leading period targets a class, and a leading hash targets an ID.

These selectors are concise building blocks. They can be extended with [[Selenium CSS Combinator Locator|combinators]], attributes, and pseudo-classes when a single tag, class, or ID does not uniquely describe the element.
