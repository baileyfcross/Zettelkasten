# Purpose Limitation

Purpose limitation requires personal data to be collected for specified and legitimate purposes and restrains incompatible later use. It connects a dataset to the reason that justified obtaining it instead of treating possession as unlimited permission.

Because big-data value often comes from reuse and combination, purpose limitation forces a new processing goal to be evaluated rather than silently inherited from the original collection.

Predictive analytics makes the tension sharper because useful relationships may be discovered only after collection. An unspecified possibility of future insight does not itself define a legitimate purpose, so later analysis still requires justification.
