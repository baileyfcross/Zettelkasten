# LUIS Utterance

A LUIS utterance is an example phrase associated with an intent during model training or testing. Several differently worded examples teach the model that varied surface text can express the same conversational purpose.

The book recommends multiple phrases for every intent and uses testing errors as new labeled feedback. Adding examples has no effect until the model is trained again and the updated model is published for the bot to call.
