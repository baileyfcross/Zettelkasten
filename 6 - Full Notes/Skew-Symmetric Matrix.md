# Skew-Symmetric Matrix

A real square matrix is skew-symmetric when $A^T=-A$. Every diagonal entry must therefore be zero.

The condition is checked by comparing corresponding entries across the main diagonal: $a_{ij}=-a_{ji}$. This distinguishes skew symmetry from the mirrored equality of a [[Symmetric Matrix]].
