# API Continuous Delivery

API continuous delivery automates building, testing, packaging, and preparing an API release whenever an accepted change enters the delivery workflow. A release proceeds only after the pipeline's quality and security checks succeed.

The book applies this flow to conventional and serverless APIs and distinguishes repeatable delivery from an unreviewed production change. Versioned artifacts, environment-specific configuration, deployment checks, rollback planning, and consumer-facing change communication remain necessary even when the mechanical steps are automated.
