# Blender 3D Navigation Add-On

The 3D Navigation add-on exposed clickable controls for standard front, back, side, top, and bottom views alongside common 3D Cursor operations. It offered an interface-based alternative for artists who did not want to memorize every navigation shortcut.

The panel does not change the underlying camera or cursor concepts; it centralizes established commands. This makes it useful for discoverability and occasional operations, while experienced shortcut users may prefer the faster keyboard path.
