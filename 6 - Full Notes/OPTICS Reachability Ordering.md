# OPTICS Reachability Ordering

OPTICS orders observations so that points belonging to the same density-connected structure tend to appear near one another. Each point receives a reachability value describing the density level needed to connect it to an already processed neighborhood.

A reachability plot exposes valleys corresponding to clusters over a range of density thresholds instead of committing to one global cut. Interpretation or a subsequent extraction rule is still needed to turn the ordering into a final partition.
