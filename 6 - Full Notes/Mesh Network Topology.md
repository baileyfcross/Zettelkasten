# Mesh Network Topology

A mesh network topology gives nodes an irregular set of point-to-point links, with some nodes connected to several neighbors. A fully connected mesh is the special case in which every node has a direct connection to every other node.

Multiple paths can make a mesh resilient to individual link failures. That resilience requires routing decisions and more connection infrastructure than simpler topologies.
