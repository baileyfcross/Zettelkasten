# AWS CloudFormation Template

An AWS CloudFormation template is a declarative text document that describes AWS resources, their properties, parameters, outputs, and relationships. CloudFormation interprets the template and creates or updates the corresponding infrastructure as an [[AWS CloudFormation Stack]].

Because the intended state is stored as code, the template can be reviewed, versioned, reused, and applied consistently. Parameters should expose genuine deployment differences without turning the template into an opaque collection of special cases.
