# Extreme Gradient Boosting

Extreme gradient boosting builds an additive sequence of trees, with each new tree reducing errors left by the current ensemble. Regularization, learning rate, tree depth, and iteration count control the balance between fit and generalization.

The book applies XGBoost to a sparse encoded matrix and evaluates the resulting probabilities on held-out data.
