# JavaScript Source Map

A JavaScript source map records how generated JavaScript corresponds to the original source from which it was compiled or bundled. It lets a debugger display and pause in [[TypeScript]] even though the browser executes JavaScript.

Without the mapping, client faults point only into transformed output that can differ substantially from the authored component or service. Source maps are therefore a development aid and should be handled according to deployment needs.
