# Xamarin.Forms Custom Renderer

A Xamarin.Forms custom renderer controls how a shared element is created and updated as a native platform control. The renderer is registered in a platform project and translates the shared element's properties and lifecycle into the target UI toolkit.

Custom renderers offer deeper control than effects because they can replace the normal rendering implementation. That power also creates more platform code and maintenance, so a platform specific, behavior, or effect is preferable when it can express the requirement.
