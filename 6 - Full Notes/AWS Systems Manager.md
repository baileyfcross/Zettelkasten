# AWS Systems Manager

AWS Systems Manager provides operational capabilities for managing compute resources and application configuration at scale. Its tools support activities such as inventory, patching, command execution, automation runbooks, parameter storage, and browser-based sessions to managed nodes.

The service can reduce direct administrative access and replace one-off manual maintenance with controlled, logged procedures. Managed nodes still require appropriate connectivity, permissions, and agent or platform support for the selected capability.
