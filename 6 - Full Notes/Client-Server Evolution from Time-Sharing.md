# Client-Server Evolution from Time-Sharing

Client-server computing distributes work between user-controlled machines and powerful shared servers. Servers manage large datasets and common services, while clients handle interaction, graphics, and some computation.

The arrangement evolved from time-sharing but replaced passive terminals with capable networked computers. It preserves shared resources without surrendering responsive local control.
