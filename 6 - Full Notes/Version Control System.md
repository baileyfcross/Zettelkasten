# Version Control System

A version control system records changes to a collection of files so collaborators can identify revisions, compare work, and recover earlier states. Each recorded revision gives a project a shared history instead of relying on manually copied backup folders.

Version control also coordinates concurrent development by making each contribution and merge explicit. Git is distributed, so a local repository contains history and supports most revision operations without a network connection.
