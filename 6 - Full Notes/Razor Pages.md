# Razor Pages

Razor Pages is an ASP.NET Core approach for server-rendered, page-focused behavior. A Razor Page packages view-oriented handling more closely than the separate controller-and-view structure used by MVC, making it suitable when a page and its request logic belong together.

A single-page Angular client may not need server-rendered views, but Razor Pages can still coexist with [[MVC Controller|controllers]] that return JSON or with identity interfaces mapped through [[Endpoint Routing]].
