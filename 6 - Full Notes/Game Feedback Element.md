# Game Feedback Element

A game feedback element is a visible or audible interface component that tells the player the effect of an action or supplies state needed for the next decision. Animation, sound, indicators, text, and controller response can all serve this role.

Good feedback is timely and attributable: the player can connect the signal to the action or event that caused it. Redundant sensory channels can improve clarity and accessibility.
