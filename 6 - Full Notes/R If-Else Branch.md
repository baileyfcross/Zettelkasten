# R If-Else Branch

An R if-else branch selects one of two blocks according to a single logical condition. The `else` must remain syntactically connected to the closing brace of the preceding `if`, and both branches should produce compatible state or return values when later code treats them alike.

Additional conditions can be nested or chained, but their order matters because the first satisfied branch is taken. Mutually exclusive scientific cases should be written so their boundaries do not overlap or leave an unintended gap.
