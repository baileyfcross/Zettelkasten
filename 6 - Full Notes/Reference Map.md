# Reference Map

A reference map helps locate named geographic features such as roads, settlements, boundaries, and landmarks. Its purpose is orientation rather than emphasizing one statistical variable. Web tiles can supply this context beneath a thematic layer, provided the thematic data are transformed to the tile system. Excess detail competes with symbols, so reference content should be selected according to scale and the locations readers need to recognize.
