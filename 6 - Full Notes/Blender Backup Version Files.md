# Blender Backup Version Files

Blender 2.7x could preserve earlier saves beside the active project as numbered `.blend1`, `.blend2`, and later backup versions. Renaming the desired backup to the normal `.blend` extension turns that preserved state into an ordinary project file.

The number of saved versions is configurable. More versions widen the recovery window but consume more storage, while incremental Save As numbering creates deliberate milestones rather than relying only on automatic backups.
