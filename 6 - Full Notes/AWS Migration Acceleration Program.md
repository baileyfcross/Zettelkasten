# AWS Migration Acceleration Program

The AWS Migration Acceleration Program combines technical guidance, specialist support, training, tools, and financial incentives for larger migration and modernization programs. It aligns assistance with the [[AWS Three-Phase Migration Process|assess, mobilize, and migrate-and-modernize phases]]. MAP is a program framework rather than a workload-movement service: its role is to reduce organizational and financial friction around a coordinated transformation.
