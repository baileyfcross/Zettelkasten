# CSS Table Sizing and Alignment

CSS table width can be calculated from cell content and constraints or from a fixed layout that relies more directly on table and column declarations. Cell widths must coordinate across rows because every cell in a column shares the column's grid width.

Cell height is influenced by row height and content. Horizontal text alignment and vertical alignment place the cell's content within the space assigned by the table layout.
