# AWS Cost Allocation Tag

An AWS cost allocation tag is a resource tag activated for billing analysis. Consistent keys and values can attribute spend to an application, team, environment, cost center, or other ownership model in cost reports and [[AWS Cost Explorer]].

Tags improve accountability only when resources support them and teams apply them consistently. Tag policies, required metadata, automation, and treatment of shared or untaggable charges are needed to prevent incomplete allocation.
