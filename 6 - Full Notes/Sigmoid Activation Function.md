# Sigmoid Activation Function

The sigmoid activation function is a smooth S-shaped function whose output ranges from zero to one. Large negative inputs approach zero, large positive inputs approach one, and an input of zero produces one-half.

It supplies a differentiable approximation to a binary step while keeping activation bounded. Compared with the [[Tanh Activation Function]], sigmoid is not centered around zero because it does not produce negative outputs.
