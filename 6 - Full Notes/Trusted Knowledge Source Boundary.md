# Trusted Knowledge Source Boundary

A trusted knowledge source boundary identifies which repositories, indexes, databases, or enterprise systems an agent may use as evidence. The boundary keeps the assistant from blending governed organizational information with unverified material simply because both are retrievable or familiar to the model.

Trust should include provenance, freshness, access rights, and intended use, not only the technical ability to connect. System instructions can require the agent to remain inside approved sources, while retrieval verification and identity controls enforce the boundary. When evidence is missing, the correct behavior is uncertainty or escalation rather than unsupported completion.
