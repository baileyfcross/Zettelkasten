# Classification Model Application

Classification model application uses an evaluated model to assign labels to unseen records. A decision tree follows attribute branches, while a probabilistic classifier compares class probabilities.

Application also creates evidence about drift and failure. Predictions should be monitored because the data distribution and class meanings can change after deployment.
