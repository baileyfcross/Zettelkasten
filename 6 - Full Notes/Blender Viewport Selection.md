# Blender Viewport Selection

In Blender's modern default configuration, left-click selects an object. Shift-left-click adds another object to the selection and removes an already selected object from that set.

The last object selected is the active object, a distinction that matters for operations using local, gimbal, or normal orientation and for relationships such as joining or parenting. Selection therefore identifies both a set and, within it, the object that supplies active context.
