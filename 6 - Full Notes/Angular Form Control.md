# Angular Form Control

An Angular form control represents one field within a reactive [[Form Model]]. It holds the field's current value and validation status and can publish changes over time.

Validators are attached to the control so the model can distinguish valid and invalid input before submission. Related controls are collected within an [[Angular Form Group]].
