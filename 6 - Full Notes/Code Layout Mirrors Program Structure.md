# Code Layout Mirrors Program Structure

Code layout should make the program's logical nesting and grouping visible to a human reader. Consistent indentation, block boundaries, whitespace between related groups, and deliberate line wrapping let the page communicate control structure before every expression is parsed.

Formatting is therefore part of communication rather than decoration. Inconsistent braces or indentation can suggest a boundary that execution does not have, while a consistent style reduces exceptions the reader must remember and makes later changes easier to review.
