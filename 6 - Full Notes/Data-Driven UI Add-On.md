# Data-Driven UI Add-On

A data-driven UI add-on combines script behavior with declarative data files so users or content authors can extend a game's interface without changing the engine. The files describe layout and metadata, while scripts respond to events and update elements.

Powerful extension points require a security boundary. Privileged operations can remain in protected engine code, with add-ons permitted to observe or hook approved behavior rather than replace core functions.
