# Event Indicator

An event indicator records whether the outcome occurred within the survival analysis window, commonly as 1 for an event and 0 for censoring. It is interpreted together with the [[Time-to-Event Variable]].

An outcome that occurs after the chosen cutoff is treated as unobserved within that window, even if it is known to happen later. The coding must therefore be regenerated when the study horizon changes.
