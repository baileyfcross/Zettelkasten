# Dynamic Server Power

Dynamic server power is the workload-dependent portion of energy consumption above the static baseline. CPU activity, memory access, disk I/O, and network use each contribute according to how a task exercises the machine.

Estimating these components supports attribution to virtual machines and lets a scheduler compare the energy consequence of different placements.
