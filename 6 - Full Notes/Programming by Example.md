# Programming by Example

Programming by example infers a transformation or program from representative input-output pairs rather than a complete textual algorithm. A system searches for logic consistent with the demonstrations and then applies that logic to new inputs.

Examples communicate expected behavior concretely but may underdetermine edge cases and constraints. A useful workflow adds diverse positive and boundary examples, exposes the inferred rule, and validates it beyond the sample pairs.
