# Final Test Evaluation

Final test evaluation measures the completed modeling procedure on an untouched test set. It is performed after feature choices, tuning, thresholds, and preprocessing rules have been fixed.

Using the result to redesign the model turns the test set into development data and requires a new independent evaluation.
