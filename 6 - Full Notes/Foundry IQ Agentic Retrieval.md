# Foundry IQ Agentic Retrieval

Foundry IQ agentic retrieval plans and synthesizes across connected knowledge sources for an agent. The platform manages document parsing, indexing, embeddings, and retrieval logic behind the knowledge-base interface, reducing the amount of retrieval infrastructure a portal user must configure manually.

Automation does not remove the need for retrieval governance. Source quality, permitted access, freshness, citation behavior, empty-result handling, and evaluation still determine whether an answer is trustworthy. The agent's instructions should require the retrieval tool for knowledge-bound questions and define a safe escalation or no-answer response when the tool provides insufficient evidence.
