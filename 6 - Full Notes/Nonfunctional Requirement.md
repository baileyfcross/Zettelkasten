# Nonfunctional Requirement

A nonfunctional requirement constrains the manner in which a system provides its behavior. Response time, load capacity, scalability, security, interoperability, robustness, and usability are examples because they qualify the operation of features rather than naming a feature alone.

The requirement becomes architecturally useful when it is measurable. “Fast” leaves no testable boundary, while a response-time target under a stated load can guide design and later support [[Requirements Validation]].
