# Probabilistic Classification Accuracy

Probabilistic classification accuracy evaluates predicted class probabilities without immediately discarding them through a fixed decision threshold. Proper scoring rules reward probability assigned to the observed class and penalize confident errors more strongly.

Threshold-based measures can still be derived for operational decisions, but probability-sensitive evaluation asks whether confidence is informative as well as whether the top-ranked label is correct.
