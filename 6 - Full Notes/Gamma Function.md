# Gamma Function

The gamma function extends the factorial to noninteger arguments through the improper integral $\Gamma(z)=\int_0^\infty t^{z-1}e^{-t}dt$ for arguments where the integral converges. Integration by parts gives the recurrence $\Gamma(z+1)=z\Gamma(z)$.

For positive integers, the recurrence makes $\Gamma(n+1)=n!$. The function therefore connects factorial patterns, Gaussian-type integrals, and normalization constants that appear throughout mathematical physics.
