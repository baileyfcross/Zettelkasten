# Backpropagation Network

A backpropagation network is a multilayer neural network trained by propagating output error backward through its connections. The chain rule assigns each weight a contribution to the loss.

Weights are changed in the direction that reduces error, scaled by a learning rate. Repeated passes continue until the error or parameter change meets a stopping criterion.
