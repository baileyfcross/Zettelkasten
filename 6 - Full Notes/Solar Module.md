# Solar Module

A solar module connects several [[Solar Cell]]s in a series-parallel wiring arrangement and encloses them under a rigid transparent cover. The number of cells in series helps set voltage, while parallel paths increase current. Contacts, cover, frame, and exposed gaps distinguish module performance from that of an individual cell. Modules are the repeatable building blocks of a [[Solar Array]].
