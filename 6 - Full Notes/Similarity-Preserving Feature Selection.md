# Similarity-Preserving Feature Selection

Similarity-preserving feature selection chooses original variables so that relationships among samples in the reduced representation resemble a target [[Sample Similarity Matrix]]. The target may encode classes, clusters, neighborhoods, or external knowledge.

An individually scored formulation asks whether each feature aligns with the target operator. A multivariate formulation instead evaluates the kernel or representation produced by a set of features, which makes redundancy visible: two features can each be relevant while adding little new structure together.
