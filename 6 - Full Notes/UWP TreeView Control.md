# UWP TreeView Control

A UWP TreeView presents hierarchical items as expandable branches and can be hosted in an older desktop application through [[XAML Islands]]. The book replaces a visually dated Windows Forms tree with the UWP control while retaining the surrounding e-book manager.

Each tree item is represented by a model, and the root collection becomes the control's item source. An item template then describes how the model's properties appear, allowing data binding to construct the hierarchy instead of manually adding every visual node.
