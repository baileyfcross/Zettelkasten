# React Router Location Prop

The React Router location prop describes the browser location matched for a rendered route, including its pathname. A route component can use that value to explain which resource was not found or to derive presentation from the current navigational state.

Location is router-owned input rather than ordinary component state. Receiving it as a prop keeps a route component declarative: the component renders output for the supplied location while the router remains responsible for tracking browser history and changes.
