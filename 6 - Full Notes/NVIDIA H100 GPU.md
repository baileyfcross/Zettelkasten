# NVIDIA H100 GPU

The NVIDIA H100 is a Hopper-generation data center GPU aimed at demanding large-model training and inference. The book describes an 80 GB HBM3 configuration, fourth-generation Tensor Cores with FP8 support, and newer NVLink capabilities for distributed AI systems.

It fits workloads whose model scale, memory bandwidth, Tensor Core throughput, and communication needs justify a high-performance platform. The product name still does not identify every form factor or server topology, so deployment decisions require the exact configuration and validated software stack.
