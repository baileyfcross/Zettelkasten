# Azure Synapse Analytics

Azure Synapse Analytics brings data warehousing, Spark processing, pipelines, data-lake access, and analytical tooling into one workspace for data scientists and business-intelligence teams. It can unify several stages of an analytical solution without making their concerns identical. Dedicated or serverless query modes, integration runtimes, private networking, workload management, storage layout, and team skills still determine how the workspace should be partitioned and operated.
