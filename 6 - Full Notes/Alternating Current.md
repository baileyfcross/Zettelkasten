# Alternating Current

Alternating current reverses direction periodically. A sinusoidal supply can be written $I=I_0\sin\omega t$ and $V=V_0\sin\omega t$ for a purely resistive load. Capacitors and inductors shift current phase relative to voltage, so AC analysis requires both magnitude and phase rather than resistance alone.
