# Rails Resourceful API Routing

Rails resourceful routing generates the conventional collection and item routes for a named resource and maps HTTP methods to standard controller actions. One `resources` declaration can establish create, read, update, and delete paths with predictable names.

The book uses this convention to keep API routing concise and align controllers with REST operations. Namespaces can place routes beneath a version while the public contract remains distinct from the Active Record model and controller implementation behind it.
