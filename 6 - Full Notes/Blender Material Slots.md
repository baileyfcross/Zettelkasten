# Blender Material Slots

Material slots let one object use several materials. In Edit mode, selected mesh faces, text characters, or curve control points can be assigned to the material stored in a chosen slot.

This creates discrete surface regions without splitting the object. Because the boundary follows component assignments, slots are well suited to abrupt material changes but do not themselves create smooth blends across the surface.
