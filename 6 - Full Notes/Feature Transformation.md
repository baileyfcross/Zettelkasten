# Feature Transformation

Feature transformation constructs new variables from existing variables through a mathematical or statistical mapping. A logarithm, ratio, square, standardization, projection, or composition of several functions can expose relationships that are difficult for a learner to use in the original representation.

A transformation preserves a connection to the input features, unlike some forms of domain-specific feature generation. Its value is judged by the downstream analytic task, not by novelty alone.
