# Linear Time Complexity

Linear time complexity, written $O(n)$, means that the work performed grows in direct proportion to [[Input Size]]. Doubling the number of items therefore multiplies the leading amount of work by approximately two.

[[Linear Search]] has linear worst-case time because it may need to inspect every item. Linear behavior is often the best possible when an [[Algorithm]] must read all $n$ input elements at least once.
