# User Interface as a Computing Driver

The user interface has repeatedly shaped which computing systems succeed. Wartime controls, interactive terminals, graphical workstations, personal computers, search pages, and touch devices all had to fit human perception and action.

Technical capability becomes socially useful only when people can direct and understand it. Interface design is therefore a historical driver alongside faster processors and denser memory.
