# Basic Variable

In a simplex tableau, basic variables correspond to columns that form an identity matrix. Their current values are read from the right-hand side when all nonbasic variables are set to zero.

Changing the basis exchanges one basic and one [[Nonbasic Variable|nonbasic variable]], moving to an adjacent basic feasible solution.
