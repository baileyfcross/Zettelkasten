# Deep Learning

Deep learning uses multilayer neural networks to learn increasingly abstract representations from data. The method can model complex relationships without requiring every useful feature to be specified manually.

Its usefulness in automated business analytics depends on adequate data, computation, evaluation, and a clear connection to the target decision. Model depth does not remove the need to test results outside the data used for fitting.
