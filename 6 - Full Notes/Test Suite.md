# Test Suite

A test suite is a named collection of related tests that share a subject or behavior. Setup can be run before each test so every specification begins from a fresh and predictable fixture.

Jasmine uses descriptive suite blocks to group Angular expectations. Running the whole suite reveals whether a change preserved behavior across all included cases rather than only the test currently being edited.


A [[TestNG XML Suite Configuration|`testng.xml` configuration]] can assemble Selenium test classes and groups into named smoke or regression suites. The same configuration controls parameters and can enable [[Parallel Test Execution|parallel execution]] without changing each test method.
