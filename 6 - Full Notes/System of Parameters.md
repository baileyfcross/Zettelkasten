# System of Parameters

For a finitely generated module M over a Noetherian local ring, a system of parameters is a set a₁,…,aₙ in the maximal ideal such that M/(a₁,…,aₙ)M has finite [[Module Length]].

A minimal system has length equal to the [[Dimension of a Module]]. In a [[Regular Local Ring]], a system of parameters that generates the maximal ideal is a regular system of parameters.
