# Software Cheat Detection

Software cheat detection looks for known programs, modified memory, or suspicious code running alongside a game client. It can identify cheats that protocol validation cannot see, such as a map hack that reads legitimately replicated state and changes only what the local player sees.

Detection software operates on an untrusted player machine and can itself create privacy, compatibility, and evasion problems. Confirmed detections are often enforced in delayed ban waves so cheat authors receive less immediate feedback about which signature exposed them. It is one layer within [[Game Network Cheat Prevention]], not a substitute for limited client authority.
