# Social Bot Network Feature

A social bot network feature describes structural or interaction relationships involving an account. Retweet, mention, and hashtag co-occurrence networks provide different views of how it participates in information flow.

Network measures can expose coordination, centrality, and neighborhood patterns. Each network definition encodes a different behavior, so combining them requires attention to scale and meaning.
