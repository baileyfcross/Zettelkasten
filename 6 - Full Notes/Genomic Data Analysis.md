# Genomic Data Analysis

Genomic data analysis turns instrument output into biological claims through quality control, alignment or assembly, variant calling, annotation, comparison, and statistical interpretation. Each stage introduces assumptions and produces intermediate evidence.

Reproducibility requires reference genomes, software versions, parameters, and sample provenance to accompany the final reported variants or associations.
