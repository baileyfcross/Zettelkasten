# Space-Time Point Small Multiples

Space-time point small multiples repeat a point map for selected times, encoding each location's value with a common symbol or color scale. They preserve station geography and make local changes visible from panel to panel. Only a limited number of times can be shown legibly on one page, so the source combines these maps with [[Point Space-Time XT Plot|XT]] and time-series views for longer sequences.
