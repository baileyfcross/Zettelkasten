# X-Ray Visualization

X-ray visualization reveals structures that are physically hidden behind visible surfaces. An AR system can render an occluded object or interior model while providing depth cues that communicate where it lies relative to the foreground.

Simply drawing the hidden object on top can destroy the meaning of occlusion. Ghosting, cutaways, explosion diagrams, and spatial distortion preserve some evidence of the surrounding structure while making the target visible.
