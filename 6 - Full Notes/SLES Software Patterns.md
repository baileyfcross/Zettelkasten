# SLES Software Patterns

A SLES software pattern is a named collection of packages and recommendations assembled for a role or capability. Selecting a pattern expresses intent at a higher level than listing every package individually, allowing the package manager to install the coherent supporting set.

Patterns are not immutable images. Their contents can evolve with the distribution, and optional or recommended packages may affect the final transaction. An administrator should inspect the proposed packages and use an appropriate role-specific pattern rather than treating every pattern as a minimal dependency bundle.
