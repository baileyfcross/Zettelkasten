# Static Small-Multiple Complement

A static small-multiple complement places selected animation frames together on one page. Animation emphasizes movement, while the static array supports simultaneous comparison of positions and relationships at known times. The source recommends using both for a space-time raster because neither fully replaces the other. Shared scales and clear time labels let the static panels serve as a durable reference for the transient sequence.
