# Bayesian Cluster Ensemble

A Bayesian cluster ensemble models observed partitions as noisy evidence about latent consensus memberships. Posterior inference can estimate the consensus together with uncertainty and reliability parameters for component clusterings.

The probabilistic framework can weight inputs differently and represent ambiguous assignments. Results depend on priors and the assumed noise process, which may not match systematic differences among algorithms or data views.
