# Self-Nonself Security Model

The self-nonself security model distinguishes activity that belongs to a system's expected operation from activity that appears foreign or harmful. The idea parallels an immune system's need to tolerate normal components while responding to possible intruders.

In cyber defense, the distinction is learned from system identity and behavior rather than assumed from a single signature. It supports a [[Behavioral Security Baseline]] but must account for legitimate change to avoid treating every novelty as an attack.
