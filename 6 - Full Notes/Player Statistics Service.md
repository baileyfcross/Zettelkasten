# Player Statistics Service

A player statistics service stores named measurements associated with a platform identity, such as games played, wins, or cumulative actions. The client or trusted server first retrieves the current values, modifies permitted fields, and submits the updated statistics through the gamer service API.

Definitions should live in one authoritative list so enumeration values, names, types, and update code do not drift apart. Statistics can supply conditions for an [[Achievement]] or values for a [[Game Leaderboard]], but authoritative competitive results should not depend solely on claims from an untrusted client.
