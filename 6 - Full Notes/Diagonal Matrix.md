# Diagonal Matrix

A diagonal matrix is a [[Square Matrix]] whose off-diagonal entries are all zero. Its main diagonal can contain arbitrary values.

Diagonal matrices are inexpensive to multiply, invert when every diagonal entry is nonzero, and raise to powers. [[Matrix Diagonalization]] seeks a representation in which a matrix becomes diagonal because computations then reduce to independent scalar operations.
