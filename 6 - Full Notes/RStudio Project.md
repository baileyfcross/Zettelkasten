# RStudio Project

An RStudio project associates an analysis with a particular folder and opens R with that folder as its [[R Working Directory]]. Code, data, and supporting files can then use paths relative to a shared project root.

The source recommends projects as a simple organizational boundary for beginners. They reduce dependence on machine-specific absolute paths and help collaborators reproduce the same file relationships.
