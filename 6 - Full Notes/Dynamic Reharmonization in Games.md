# Dynamic Reharmonization in Games

Dynamic reharmonization changes the chordal context of game music while it is running. A system can map gameplay events to alternative chords, scales, or voicings so the same melodic material acquires a different emotional meaning without switching to a separate complete cue.

The technique needs musical rules that constrain which notes remain valid as harmony changes. MIDI instruments can render those choices directly, while prerecorded designs may divide material into short cells or isolated parts that the engine recombines. This makes reharmonization more flexible than ordinary cue switching but also more dependent on detailed implementation and testing.
