# Virtual Machine Power Metering

Virtual machine power metering estimates the share of a physical server's consumption attributable to each virtual machine. It combines host-level measurements with monitored CPU, memory, storage, and network activity.

The estimate can support energy-aware billing and scheduling, although shared components make exact attribution difficult. A model must state how it divides static power and interference among tenants.
