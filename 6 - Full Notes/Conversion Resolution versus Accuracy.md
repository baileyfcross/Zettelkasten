# Conversion Resolution versus Accuracy

Resolution is the number of digits presented in a measurement or calculation; accuracy concerns how well those digits represent the intended quantity. The book warns that a conversion result with many displayed places can appear more trustworthy than the starting observation warrants. It gives 1000 as an ambiguous example: the app initially reads four significant digits, but an estimate to the nearest thousand should be reported with only one. The user must supply that context because the digits alone cannot settle it. See [[Significant Digits in Unit Conversion]].
