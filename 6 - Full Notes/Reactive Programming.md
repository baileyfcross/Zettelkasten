# Reactive Programming

Reactive programming models changing values as asynchronous streams and expresses what should happen when new values arrive. Rather than repeatedly asking whether a quantity changed, a consumer subscribes to notifications and transforms the resulting sequence. The book's inventory examples use observable product updates and stream operations to separate producers from the code that responds to them.
