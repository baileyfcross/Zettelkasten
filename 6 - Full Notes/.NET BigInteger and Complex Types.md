# .NET BigInteger and Complex Types

`BigInteger` represents whole numbers whose size can grow beyond the fixed ranges of built-in integer types, limited primarily by available memory. It trades fixed-width efficiency for arithmetic on very large values.

The .NET `Complex` type stores real and imaginary components and implements arithmetic for values of the form `a + bi`. These specialized numeric types extend the language's primitive vocabulary for domains that need unbounded integers or complex-number operations.
