# 2D Shear Transformation

A two-dimensional shear displaces one coordinate in proportion to the other. An x-direction shear changes x by a multiple of y while retaining y; a y-direction shear changes y by a multiple of x while retaining x.

Shear preserves parallelism but distorts angles and can turn rectangles into parallelograms. When an object must be sheared relative to a line that is not a principal axis, translations and rotations first align that reference with an axis, the elementary shear is applied, and the alignment steps are inverted.
