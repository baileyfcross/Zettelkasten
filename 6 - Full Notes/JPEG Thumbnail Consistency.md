# JPEG Thumbnail Consistency

JPEG thumbnail consistency compares an embedded preview with the thumbnail that the claimed camera would be expected to generate from the full-resolution image. The comparison considers visible content as well as dimensions, sharpening, resampling, and compression characteristics.

A leftover preview can expose an edit directly, while an unusually regenerated preview can reveal that other software resaved the file. A consistent pair cannot establish authenticity because an editor can update both representations or remove the thumbnail entirely.
