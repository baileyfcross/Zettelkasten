# Java Math Utility Class

`java.lang.Math` is a utility class whose static constants and methods augment Java's arithmetic operators. Callers use the class name directly for operations including absolute value, minimum and maximum selection, square root, rounding, angle conversion, trigonometry, and pseudorandom number generation.

`StrictMath` supplies a related set of operations with stricter cross-platform definitions. Both forms keep mathematical operations at class scope because no independent Math object state is required.
