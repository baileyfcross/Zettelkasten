# Cosmos DB API Compatibility

Cosmos DB API compatibility lets a database account expose a programming interface modeled after another established data API. The book selects the MongoDB API so its ASP.NET Core application can use the MongoDB driver and treat the Cosmos instance like a MongoDB database.

API selection changes how the application communicates but not the underlying managed service. In the 2019 workflow the choice is made when the account is created and is not presented as a freely interchangeable setting afterward.
