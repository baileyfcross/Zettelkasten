# Arithmetic Progression

An arithmetic progression is a [[Sequence]] in which each term after the first is obtained by adding a constant [[Common Difference]]. The progression

$$2,7,12,17,\ldots$$

has common difference (5). Its values grow linearly with position, so the [[General Term of an Arithmetic Progression]] has the form (a_1+d(n-1)). Recognizing this form allows membership questions to become linear equations and long sums to be simplified through term pairing.
