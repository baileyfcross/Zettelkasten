# Build Iteration

Build iteration is the loop from committing a change through building, automated testing, and sharing a verified result. Frequent small commits reduce the amount of unintegrated work and make failures easier to isolate.

A reliable [[Continuous Integration]] system shortens this loop by building each supported configuration and reporting defects quickly enough for the responsible developer to respond.
