# Java String Construction

A Java string is a sequence of characters represented by `java.lang.String`. A string literal is the simplest construction syntax, while String constructors can build a value from sources such as a character array.

Constructing a String from another String creates a second object without changing the character sequence and is usually unnecessary. A literal can instead supply the pooled immutable value directly, while a character-array constructor is useful when characters have already been assembled separately.
