# Pipeline Trigger

A pipeline trigger is the event that starts an automated pipeline. A source-code change can trigger continuous integration so the shared repository is compiled and tested without waiting for someone to launch the build manually.

Trigger scope determines which branches or changes receive that feedback. It should align with the repository flow that the team considers eligible for integration or release.
