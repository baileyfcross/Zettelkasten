# Cloud Service Interoperability

Cloud service interoperability is the capability to use the same or similar services across different cloud providers and to make cooperating services work together. Its scope includes data, processes, security, governance, monitoring, billing, reporting, and service management as well as technical protocols.

Interoperability enables provider substitution, federation, cloud bursting, and continuity. It requires common interfaces and compatible commitments rather than assuming that two services with similar marketing names can exchange work seamlessly.
