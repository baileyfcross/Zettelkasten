# Electrotactile Display

An electrotactile display passes brief controlled current pulses through electrodes on the skin to activate cutaneous nerve fibers. It has no moving parts and can be compact and power-efficient, which makes it attractive for wearable sensory-substitution systems.

Its limitations include variable electrode contact, dependence on skin hydration, diffuse sensations, and a narrow dynamic range between detection and pain. Current and pulse duration must therefore be controlled carefully. This direct nerve stimulation differs from [[Electrovibration]], which changes friction between a moving finger and an insulated conductive surface.
