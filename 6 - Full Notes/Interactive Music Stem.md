# Interactive Music Stem

An interactive music stem is an exported group of instruments or musical functions designed to play in synchronization with other stems. The game can change their relative levels or enable and disable them to create [[Vertical Remixing]] from one underlying cue.

Every stem must share the same start time, length, tempo map, and loop boundary so combinations remain phase-aligned. The composer must also make each layer meaningful alone and balanced in every permitted mixture. Delivering stems increases file count, memory use, export work, and testing compared with a single linear mix.
