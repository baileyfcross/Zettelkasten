# Linear Regression Model Presentation

A linear regression model presentation organizes coefficient estimates and their uncertainty by substantive category and level. It commonly shows an unadjusted model, a partially adjusted model, and the fully adjusted final model so readers can see how adjustment changes the exposure estimate.

Reference groups and absent terms must be labeled explicitly. Exporting a tidy model table reduces transcription errors, while a [[Coefficient Plot]] can support interpretation of direction, magnitude, and precision.
