# Quick Access Private Network

Quick Access is the broad publishing mode in Microsoft Entra Private Access. An administrator associates a connector group with private application segments defined by fully qualified domain names, IP addresses or ranges, protocols, and ports, then assigns the resulting enterprise application to users and groups.

It provides a fast route away from full-network VPN access and supplies traffic for application discovery, but wide ranges can reproduce the same excessive reachability under a new transport. Observed destinations should be reviewed and converted into narrower per-app Global Secure Access applications with distinct assignments and Conditional Access policies. Quick Access is therefore a migration and discovery mechanism whose secure end state is explicit segmentation.
