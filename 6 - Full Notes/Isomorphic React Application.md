# Isomorphic React Application

An isomorphic React application can render the same component tree in more than one environment, especially on a server for the initial response and in a browser for later interaction. The application may use environment-specific adapters even when much of its component and state code is shared.

Initial server HTML makes content available before the client bundle runs, while browser rendering preserves single-page interaction after loading. [[Universal JavaScript]] describes code that executes unchanged in both places; isomorphism describes the broader application capability even when some I/O code differs by platform.
