# Generic Dataset Variable

A generic dataset variable is a stable object name used for the current analytic table, such as `ds`. It lets a reusable workflow refer to its working data consistently even when the source filename or subject changes.

The convention improves script portability, but provenance must still identify which original resource was loaded into the object.
