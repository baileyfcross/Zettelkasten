# R Multiple Linear Model

An R multiple linear model uses the [[R Formula Interface]] to relate a quantitative response to several predictors. Each coefficient is interpreted conditionally on the other modeled terms, while the model summary reports estimates, standard errors, tests, and measures of residual variation.

Adding predictors does not guarantee a better explanation. Collinearity, inappropriate functional form, influential observations, and residual structure must be assessed before adjusted coefficients or predictions are trusted.
