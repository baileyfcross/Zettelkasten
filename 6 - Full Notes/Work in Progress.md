# Work in Progress

Work in progress is all work that has begun but has not reached the workflow's completion state. High WIP creates queues, increases context switching, delays feedback, and hides the location of constraints.

Finishing a smaller number of items before starting others usually shortens [[Cycle Time]] and produces usable value sooner, even if fewer individuals appear continuously busy.
