# Machine Learning Lifecycle

A machine-learning workflow moves from collecting data through preparation, algorithm selection, training, evaluation, and deployment. These stages form a feedback loop because poor evaluation can reveal problems with features, data quality, or the original problem definition.

Deployment is not the end of the lifecycle. The application must continue to measure model behavior and revisit training when input populations or desired outcomes change.
