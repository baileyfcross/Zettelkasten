# Data Link Layer

The data link layer organizes transmission between nodes that share a physical network segment. It frames bits into transferable units, associates them with link-level addresses, and commonly supplies local error detection.

Its scope is one link rather than an end-to-end internet route. The network layer can move a packet across several such links while each data-link implementation handles its immediate medium.
