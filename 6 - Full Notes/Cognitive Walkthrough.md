# Cognitive Walkthrough

A cognitive walkthrough evaluates an interface by stepping through the tasks a user would perform and examining whether the design supports each step.

It is especially useful for understanding the experience of first-time or infrequent users who are learning through exploration. Evaluators ask whether the user will know what to do, notice the available action, connect it to the intended goal, and understand the system's response.

Because it can be performed on an early [[Prototype]] without a full user study, it is a rapid analytic form of [[User Interface Evaluation]].
