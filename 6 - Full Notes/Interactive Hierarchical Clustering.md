# Interactive Hierarchical Clustering

Interactive hierarchical clustering allows users to inspect and revise merges, splits, or branch priorities while a cluster tree is constructed or explored. Domain knowledge can prevent an implausible early merge from constraining every higher level.

User edits may be encoded as constraints and propagated to later decisions. The system should show the structural consequences of an intervention because changing one branch can alter feasible groupings elsewhere in the hierarchy.
