# NAVSTAR GPS Architecture

The NAVSTAR GPS architecture combined the Navy's medium-Earth-orbit satellites and spaceborne clocks with the Air Force's pseudorandom-code ranging. The resulting design provided three-dimensional position, velocity, precise time, global coverage, passive reception, and resistance to interference. Although often expanded as if it were an acronym, NAVSTAR was the program name applied to the unified satellite-navigation system rather than a technical description of one component.
