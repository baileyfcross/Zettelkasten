# Tracking Update Rate

Tracking update rate is the number of sensor measurements produced in a unit of time. A higher rate provides more frequent pose information and can describe fast motion more closely, provided the readings are useful and reach the application promptly.

Update rate is distinct from latency. A tracker may report many measurements per second while each measurement arrives too late for correct visual registration, so both temporal properties must be evaluated.
