# Amazon API Gateway

Amazon API Gateway is a managed front door for HTTP, REST, and WebSocket APIs. It routes requests to backends such as Lambda functions or other services and can apply authentication, authorization, throttling, validation, transformations, caching, stages, and monitoring. The gateway centralizes edge concerns, but API contracts, backend idempotency, latency, failure handling, and service ownership still determine the behavior clients experience.
