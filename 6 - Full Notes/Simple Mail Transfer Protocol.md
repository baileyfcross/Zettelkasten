# Simple Mail Transfer Protocol

The Simple Mail Transfer Protocol is an application-layer protocol for submitting and relaying email messages between systems. A client connects to a mail server, issues commands that identify sender and recipients, and transfers the message content.

SMTP's original text-oriented format does not by itself describe every modern body type or attachment. MIME extends the message representation while SMTP continues to carry it.
