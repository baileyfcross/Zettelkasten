# AWS Data Lake

An AWS data lake stores structured, semi-structured, and unstructured data at large scale, commonly in Amazon S3, while preserving data for several future consumers and processing styles. Storage alone does not make a useful lake. Ingestion, zones, catalog metadata, ownership, access controls, quality, lifecycle, query optimization, and cost attribution turn the shared object store into an analytical system rather than an opaque collection of files.
