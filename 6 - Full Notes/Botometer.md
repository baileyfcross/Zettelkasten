# Botometer

Botometer is a social-bot detection system that computes a large collection of account, network, content, sentiment, and temporal features and returns automation-related scores. Its public interface makes a research classifier available for account assessment.

The system illustrates how feature breadth supports holistic detection. A score is model-dependent evidence rather than proof, and performance can change as platform behavior and bot strategies evolve.
