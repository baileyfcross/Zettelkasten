# Amazon ECS

Amazon Elastic Container Service orchestrates containerized tasks and services from declared task definitions. It schedules images, maintains desired service counts, and integrates with AWS networking, load balancing, identity, and logging.

Tasks can run on customer-managed EC2 capacity or a serverless container capacity mode. ECS manages orchestration, while customers still build secure images, define CPU and memory, protect secrets, and design application state outside replaceable containers.
