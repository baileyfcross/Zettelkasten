# D'Alembert Solution

The D'Alembert solution is the general solution of the one-dimensional [[Wave Equation]] on an unrestricted line: $y(x,t)=f(x-ct)+g(x+ct)$. The two arbitrary functions represent profiles traveling in opposite directions at speed $c$.

Initial displacement and velocity determine the two traveling contributions. Boundaries modify the construction by requiring reflected profiles that enforce the endpoint condition, so the unrestricted formula also provides a foundation for solving semi-infinite string problems.
