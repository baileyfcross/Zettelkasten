# Microsoft Entra Private Access

Microsoft Entra Private Access provides identity-based access to private TCP and UDP resources without exposing a broad network through a traditional VPN. Private network connectors establish outbound connections to Global Secure Access, and application segments describe reachable hosts, address ranges, protocols, and ports.

Quick Access can publish a wide private range for initial VPN replacement, while per-app Global Secure Access applications provide finer assignment and Conditional Access boundaries. Application discovery helps turn observed traffic into those narrower segments, and intelligent local access can keep suitable on-network traffic local. The Zero Trust goal is to authorize a user to a specific private application, not to make every resource on an internal subnet reachable after one connection.
