# Richardson Maturity Model

The Richardson maturity model classifies HTTP services from level zero through level three. It progresses from treating HTTP as a generic tunnel, to identifying resources with distinct URIs, to using HTTP methods and response semantics, and finally to exposing hypermedia controls.

The levels are a diagnostic model rather than proof that every REST constraint is satisfied. They help a team see whether its interface is resource-oriented and discoverable or merely places remote procedure calls behind HTTP.
