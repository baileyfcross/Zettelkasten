# Unity Package

A Unity package is a reusable module that adds assets or capabilities to a project. Installed packages appear in the Packages area of the [[Unity Project View]], even though their managed files are not simply ordinary folders inside the project's Assets directory.

Packages can supply engine features, tools, or third-party content. They should be treated as dependencies with versions and scope, not as invisible additions. Reviewing what a package imports and keeping only what the project needs reduces clutter and makes later upgrades easier to understand.
