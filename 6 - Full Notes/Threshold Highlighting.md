# Threshold Highlighting

Threshold highlighting marks the time intervals in which a series satisfies a condition, such as temperature falling below a reference or radiation exceeding a limit. A shaded background block lets viewers compare the duration and timing of qualifying intervals while the original [[Time Plot]] remains visible. The threshold defines an analytical statement, so its value and direction should be explained rather than left as an unexplained color change.
