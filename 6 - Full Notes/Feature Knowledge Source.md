# Feature Knowledge Source

A feature knowledge source describes properties or relationships of variables independently of the target observations. It may encode feature similarity, feature function, or feature interaction, such as sequence similarity, controlled annotations, pathways, or interaction networks.

These categories suggest different uses. Similarity can define a feature-relation graph or a covariance model; function can filter or vote for variables; interaction can guide relevance propagation. The representation must be converted before it can contribute to [[Multi-Source Spectral Feature Selection]].
