# Coherence Variable

A coherence variable is a Boolean variable that, when true, imposes that two variables have the same probability distribution under corresponding premises. It extends the idea of equality from known values to uncertain probabilistic values.

Coherence variables can connect soft evidence, activate or deactivate parts of a model, fuse descriptions, and express cycles. Because the connection is itself represented inside the joint model, it can participate in inference in either direction.
