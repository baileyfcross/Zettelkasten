# Spatiotemporal Visualization in R

Spatiotemporal Visualization in R is the chapter-tier topic for organizing and displaying observations whose meaning depends jointly on geographic position and time.

## Overview Chapter

Space-time visualization begins with the combinations that actually exist in the data. [[R Spatiotemporal Data Structures]] distinguishes a full grid, where every spatial feature is crossed with every observation time, from a sparse lattice that stores only non-missing crossings. Irregular observations have no shared grid, while trajectories pair successive positions with times to represent movement. The `spacetime` classes attach data frames to these layouts, and time-indexed raster stacks attach temporal coordinates to aligned raster layers. These choices are operational rather than cosmetic: they determine valid subsetting, aggregation, reshaping, and which kinds of display can assume common locations or common times.

Multilayer fields are explored through [[Spatiotemporal Raster Displays]]. A level plot places selected raster snapshots in map panels, preserving the two spatial dimensions at each time. Hundreds of daily layers cannot remain legible on one page, so temporal aggregation can produce monthly means while openly sacrificing within-month variability. Histograms, densities, box plots, violin plots, and scatterplot matrices then summarize how cell distributions and relationships change across temporal groups. These distribution views expose multimodality, spread, and nonlinear relationships that maps may not reveal, but they pool across location. Small-multiple maps remain necessary for discovering where each part of a distribution occurs.

The full space-time array can also be projected into more compact forms through [[Space-Time Reduction Displays]]. Zonal aggregation collapses one spatial direction, after which a Hovmoller diagram uses color to place time against the remaining coordinate. The same reduced matrix can be treated as a multivariate time series, with one trajectory or horizon strip per geographic band. XT plots place location on one axis and time on the other, making persistent differences and shared events easy to scan while discarding two-dimensional geography. Map series restore geography but show fewer times. An interactive cube retains all three axes conceptually and can be rotated to reveal different slices, although occlusion and perspective mean that it complements rather than supersedes the reduced views.

Fixed monitoring locations introduce the specific workflow collected in [[Spatiotemporal Point Displays]]. Long-format measurements identify one station-time value per row. A full station grid requires reshaping those records into a space-wide time series and ordering values correctly for a full space-time data frame. Map small multiples then preserve station location for selected dates. XT views compact the full year into station columns, and superposed time-series views reveal network-wide peaks and persistent level differences. Symbol size and color must retain stable meanings across times. Used together, the views distinguish a local anomaly from a broad event and a consistently different station from a brief fluctuation.

[[Animated Geovisualization]] maps time or viewpoint to a sequence of frames. A raster movie renders each layer with fixed extent, scale, and context before concatenating the images at a chosen rate. Similar consecutive states support perceptual continuity, while abrupt changes make frames difficult to integrate. Static small multiples remain essential because animation emphasizes movement but depends on memory for exact positions. Three-dimensional raster sequences add surface form and interactive viewing, but also add perspective and occlusion. Point animations vary circle size and color at stable locations, using a progress bar or a synchronized time-series marker to show the current date. Fly-by animation instead moves the camera around a spatial scene, demonstrating that an animation may depict a changing view even when the underlying attribute is static.

These topics show why no single picture can retain two spatial dimensions, time, attributes, and precise comparison equally well. Data structures make the available combinations explicit. Raster snapshots and point maps preserve geography for selected times. Distribution plots summarize values, reduction displays expose long sequences, and animations convey movement. A strong analysis combines views whose losses are complementary, keeps scales and indexes synchronized, and states every aggregation that turns a full space-time object into a smaller representation. Motion should not hide its temporal reference, and compact matrices should not be mistaken for maps. The goal is a coordinated explanation of where a pattern occurs, when it changes, and which transformation made that pattern visible.
