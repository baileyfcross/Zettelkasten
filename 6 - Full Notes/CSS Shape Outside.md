# CSS Shape Outside

The `shape-outside` property defines the wrapping contour used around a floated element. It can name a reference box, use a basic shape such as a circle, ellipse, inset rectangle, or polygon, or derive a contour from image transparency.

Image-based contours can use a threshold to decide which alpha values count as part of the shape. The property applies to floats and controls wrapping, whereas [[CSS Clipping Paths]] control what is visibly painted.
