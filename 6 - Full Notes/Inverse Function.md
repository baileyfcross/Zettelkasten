# Inverse Function

An inverse function reverses a one-to-one function: $f^{-1}(f(x))=x$ on the original domain. Its graph is the reflection of the original graph across $y=x$, and its domain and range are exchanged. A function must assign distinct outputs to distinct inputs, or its domain must be restricted before an inverse can be defined.
