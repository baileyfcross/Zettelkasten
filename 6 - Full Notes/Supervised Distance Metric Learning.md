# Supervised Distance Metric Learning

Supervised distance metric learning uses class labels or must-link and cannot-link pairs to shape a distance function. Same-label or must-linked observations should be close, while conflicting labels or cannot-links should be separated.

Methods differ in whether the transformation is linear or nonlinear, global or local, and inductive or transductive. These choices determine whether the learned metric can be applied to new cases and whether it preserves neighborhood distinctions throughout the space.
