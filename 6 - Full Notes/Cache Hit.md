# Cache Hit

A cache hit occurs when a requested value is present in the cache and can be returned without contacting the slower backing system. The avoided network or computation cost is the immediate performance benefit of caching.

A hit is useful only if the cached value is still valid for the request. Cache lookup keys, expiration, and invalidation rules determine whether the fast result is also the correct result.
