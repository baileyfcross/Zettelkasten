# Java JAR File

A JAR is a ZIP-format Java archive with a `.jar` extension. It preserves the hierarchical directories that organize packaged class files and includes a `META-INF` directory containing a manifest that describes archive contents.

The JDK `jar` tool can create an archive and list its table of contents. Placing the archive on the classpath lets the runtime locate its packaged classes, providing a less error-prone distribution unit than separately reproducing every package directory and class file.
