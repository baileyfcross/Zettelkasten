# Automated Biomedical Indexing

Automated biomedical indexing assigns terms or concepts to documents using language processing and statistical methods. It can scale to large collections and provide labels before manual curation is available.

The system may map phrases to a [[Controlled Medical Terminology]] or predict labels from features learned on previously indexed documents. Performance varies by concept frequency and document type, and an error can affect every search that depends on the label. Evaluation should therefore examine precision, recall, and the effect of indexing errors on actual retrieval tasks.
