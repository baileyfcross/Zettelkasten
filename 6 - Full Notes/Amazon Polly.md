# Amazon Polly

Amazon Polly converts written text into synthesized speech. An application submits text and selects a language, voice, and output format; Polly returns audio that can support narration, accessibility, interactive systems, or generated announcements.

Speech Synthesis Markup Language can influence pronunciation, pauses, emphasis, and speaking style. Polly performs text-to-speech, the inverse direction of [[Amazon Transcribe]], which converts spoken audio into text.
