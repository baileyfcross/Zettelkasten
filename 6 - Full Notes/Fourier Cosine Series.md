# Fourier Cosine Series

A Fourier cosine series expands a function using only cosine modes. It naturally represents an even periodic function because cosine is unchanged under reflection of its argument.

A function originally specified only on a half interval can be extended evenly and then expanded in cosine terms. This construction is useful for boundary-value problems whose endpoint conditions select modes with vanishing normal derivative.
