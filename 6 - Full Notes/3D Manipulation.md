# 3D Manipulation

3D manipulation uses an [[Interaction Technique]] to map user input into changes to objects in a three-dimensional environment. For design and evaluation, it is commonly narrowed to manipulation of spatial rigid objects whose shape is preserved.

Canonical tasks include [[Object Selection]], [[Object Positioning]], [[Object Rotation]], and [[Object Scaling]]. Each task has parameters such as target distance, size, surrounding density, required precision, and amount of movement. Application-specific tasks may add constraints that these canonical tasks do not capture.

Technique quality depends on the task, [[Input Device]], display, user, and environment. There is no single best manipulation technique for every application.
