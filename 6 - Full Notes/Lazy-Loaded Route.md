# Lazy-Loaded Route

A lazy-loaded route defers downloading and evaluating a route's component bundle until navigation requires it. This reduces the initial JavaScript needed to start the application.

React can load the component through a dynamic import and display fallback content while the code arrives. The boundary is most useful for pages that are substantial or not needed by every user.
