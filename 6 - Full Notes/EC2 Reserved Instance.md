# EC2 Reserved Instance

An EC2 Reserved Instance is a billing discount associated with a one- or three-year commitment to specified instance attributes. Standard reservations offer greater discount with less flexibility, while convertible reservations allow broader exchange under their terms.

The purchase is not a running server by itself. It reduces eligible usage cost and can include a capacity reservation depending on scope. Accurate baseline demand is necessary because the commitment continues even if the workload changes.
