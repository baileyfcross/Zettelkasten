# Consensus Clustering

Consensus clustering produces a representative partition from multiple candidate clusterings, resampled datasets, or data views. It is often used to assess stability as well as to improve robustness.

A consensus is persuasive when it persists across credible perturbations and heterogeneous methods, not simply when many replicas of one method agree. The final number of clusters and the consensus objective remain modeling decisions that should be reported.
