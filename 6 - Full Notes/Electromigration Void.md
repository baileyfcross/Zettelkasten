# Electromigration Void

An electromigration void forms where electron-driven mass transport removes metal atoms from part of an interconnect. As the void grows, it narrows the conductive path and can eventually create an open circuit.

This failure product is distinct from a manufacturing [[TSV Void Defect]], although a preexisting TSV void can intensify the same electromigration mechanism by concentrating current in the remaining metal.
