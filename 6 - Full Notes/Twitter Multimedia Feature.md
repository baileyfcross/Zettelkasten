# Twitter Multimedia Feature

A Twitter multimedia feature is derived from images or videos attached to a post. Visual descriptors, recognized objects, color and texture summaries, or learned representations complement the tweet's text.

Media can carry the central message when text is brief or ambiguous. Reliable use requires resolving attachments, handling absent media, and aligning visual evidence with the surrounding post.
