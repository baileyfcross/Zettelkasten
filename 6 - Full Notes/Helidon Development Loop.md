# Helidon Development Loop

The Helidon development loop is the continuous-development mode offered by the [[Helidon Command-Line Interface]]. It watches project source files, recompiles after a change, and restarts the application so a developer can exercise the revised service without manually repeating each build and launch step.

The loop can be selected while initializing a project or invoked through the CLI's `dev` capability. It changes the feedback cycle during development, not the project's runtime model or final packaging.
