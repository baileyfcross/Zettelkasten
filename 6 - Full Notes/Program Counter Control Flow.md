# Program Counter Control Flow

The program counter is a processor register containing the address of the next instruction. Sequential execution advances it to the following address, while branch instructions replace it when a condition calls for a different path.

This mechanism implements selection in machine code and underlies the familiar if-then-else structure. A program’s control flow is therefore a changing sequence of instruction addresses, not merely the visual order of source code.
