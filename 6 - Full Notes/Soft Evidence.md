# Soft Evidence

Soft evidence supplies a probability distribution over a variable's possible values rather than asserting one observed value with certainty. It represents an uncertain measurement, an upstream inference, or another source whose output remains probabilistic.

A coherence variable can connect a mirror variable carrying that distribution to the corresponding variable in the target model. This preserves both the original prior and the uncertainty of the new evidence without pretending the distribution is a single value.
