# Grouping Variable

A grouping variable combines source values into a smaller set of analytically meaningful categories. Its design may distinguish exposure levels, collapse sparse or unknown categories, or align the data with a comparison planned for tables and models.

The mapping should be written as a table before it is coded and checked afterward with a contingency table against the source variable. Grouping improves interpretability but can discard information, so category boundaries need a substantive rationale.
