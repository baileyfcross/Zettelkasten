# Web App Manifest

A Web App Manifest is a JSON file describing install-related metadata for a web application. It identifies values such as the application name, short name, start URL, display behavior, and icon set.

A page links to the manifest so the browser can recognize the site as an application and create an installed entry or home-screen icon. The manifest complements rather than replaces the [[Service Worker]].
