# Character Design Brief

A character design brief describes enough personality, context, role, and appearance to guide visual decisions before drawing begins. Profession, habits, aspirations, setting, and attitude suggest plausible clothing, posture, proportions, expressions, and movement.

The brief need not contain a complete fictional biography. Its purpose is to make design choices coherent and testable, so details reinforce the same character instead of accumulating only because each looks interesting in isolation.
