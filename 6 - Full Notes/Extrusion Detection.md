# Extrusion Detection

Extrusion detection monitors information and communication leaving a protected environment. It reverses the usual emphasis on stopping entry by looking for data theft, unexpected command traffic, or other evidence that an internal system is already compromised.

Outbound destinations, volumes, timing, and content patterns can reveal [[Cyber Command and Control]] or collection by [[Spyware]]. The approach supports [[Outcome-Based Cyber Defense]] by concentrating on the attempted loss of information.
