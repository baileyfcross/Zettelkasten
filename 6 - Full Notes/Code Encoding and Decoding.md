# Code Encoding and Decoding

Encoding converts a message vector into a longer [[Codeword]] by adding structured redundancy. For a linear code, multiplying by a generator matrix performs the conversion.

Decoding reverses the representation after checking for errors. A parity-check syndrome first tests membership in the code and, when the code's columns are suitably distinct, can identify a single corrupted coordinate before the original message is recovered.
