# Data-Oriented Middleware

Data-oriented middleware lets applications share persistent datasets through a database or comparable data service. The shared store becomes an integration point at which independently implemented applications can query and update agreed records.

Connectivity protocols and query languages can make the store accessible across platforms. A [[Common Data Model]], transaction rules, ownership, and concurrency behavior are still needed so shared access does not create inconsistent meanings or updates.
