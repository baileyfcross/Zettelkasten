# Stride Modular Asset Toolchain

Stride provides integrated editors for creating, managing, and modifying game assets within a modular engine. Nested prefab and archetype systems support reuse across scenes and asset types.

Modern C# scripting and hot reload shorten the iteration loop between an imported asset and its game behavior. The pipeline still begins with a portable Blender export whose geometry, materials, scale, and hierarchy match the engine's expectations.
