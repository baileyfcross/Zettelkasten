# CSS Print Stylesheets

A print stylesheet applies presentation tailored to printed pages through the print media type. It can remove navigation or other screen-only controls, expose useful link destinations, adjust colors and dimensions, and choose page-break behavior.

Print CSS works with [[CSS Paged Media]] rather than treating paper as a tall screen. The document's structure remains shared, while media conditions provide a presentation suited to pagination and a noninteractive output surface.
