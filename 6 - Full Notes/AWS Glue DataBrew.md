# AWS Glue DataBrew

AWS Glue DataBrew is a visual data-preparation environment for profiling, cleaning, normalizing, and transforming datasets without writing the full transformation as code. Users assemble reusable recipes and run them as jobs against source data. It is useful for analyst-led preparation and exploration, but recipes still need controlled inputs, review, versioning, and output ownership if they become part of a production data pipeline.
