# Game UI Screen Resolution

Game UI screen resolution is the pixel dimension within which interface elements are rendered. A layout authored for one resolution can become too small, stretched, or misplaced when displayed at another size or aspect ratio.

Resolution-aware UI uses anchors, reference dimensions, and [[Game UI Coordinate Conversion]] to preserve hierarchy and usable target sizes. Text and detailed artwork may require separate assets or scaling policies rather than uniform enlargement.
