# Azure Cosmos DB

Azure Cosmos DB is the managed document-oriented database used by the book's task and bug tracker. The 2019 service combines NoSQL storage with configurable throughput, geographic replication, and compatibility APIs that allow an application to interact through a familiar data model.

Managed hosting transfers infrastructure, failover, and geographic scaling work to the provider, but it also introduces usage-based cost and configuration choices. Location, replication, write regions, API selection, collection capacity, and connection information all affect how the application behaves.
