# Excel Multi-Criteria Array Formula

An Excel multi-criteria array formula evaluates conditions across aligned ranges and combines their true and false results with arithmetic. Multiplication commonly represents AND because only rows whose conditions all evaluate as true contribute a one. The resulting array can be counted, summed, or used to locate a matching position.

This technique supports lookups and aggregations beyond the structure of a single built-in function. Every array must describe corresponding records, and data-type mismatches or errors propagate through the calculation. In legacy Excel, these formulas may require Ctrl+Shift+Enter as described in [[Legacy Excel Array Formula]], which should be recorded for users maintaining the workbook.
