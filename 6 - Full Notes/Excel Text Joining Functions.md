# Excel Text Joining Functions

Excel CONCATENATE and CONCAT combine text fragments, while TEXTJOIN combines them with a chosen delimiter and can ignore empty cells. CONCAT can accept ranges, making it more convenient than listing every item, but it does not insert separators. TEXTJOIN is suited to names, lists, and sentences that need consistent punctuation or spacing.

The functions produce text even when inputs include numbers. If a date or number needs a controlled appearance, it should first be formatted with TEXT. For a few fragments, the [[Excel Text Concatenation Operator]] may be clearest; for a range or variable list, CONCAT or TEXTJOIN better communicates the intended structure.
