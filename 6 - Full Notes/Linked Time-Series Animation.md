# Linked Time-Series Animation

A linked time-series animation pairs an animated map with a temporal plot whose marker and vertical line move in synchrony with the current frame. The map shows where values occur, while the plot locates the frame within the network's overall temporal pattern. Pause and resume events can make inspection controllable. Synchronization must use the same time index so the spatial and temporal states never disagree.
