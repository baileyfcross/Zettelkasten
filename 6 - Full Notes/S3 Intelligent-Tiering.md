# S3 Intelligent-Tiering

S3 Intelligent-Tiering monitors object access and automatically moves eligible data among access tiers when the pattern is unknown or changes over time. It reduces the need to predict which objects will remain hot or become infrequently used.

The class charges a monitoring fee and does not remove the need to consider retrieval and archive behavior. It is useful when access uncertainty is the problem; known, stable patterns may be cheaper with a deliberately selected class and lifecycle policy.
