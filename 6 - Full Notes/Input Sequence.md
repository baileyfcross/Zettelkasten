# Input Sequence

An input sequence is an ordered pattern of control activations recognized within timing constraints. Fighting-game combinations and gesture-like button patterns depend on the progression of states rather than simultaneous activation.

The recognizer must track partial progress and reject the pattern when an expected event fails to occur in time. Unlike an [[Input Chord]], sequence meaning is distributed across multiple moments.
