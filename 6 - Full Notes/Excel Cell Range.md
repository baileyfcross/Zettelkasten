# Excel Cell Range

An Excel cell range is a rectangular group of cells identified by its upper-left and lower-right addresses, separated by a colon. `A1:C4`, for example, includes every cell from column A through C and row 1 through 4. Functions use ranges to process many values without naming each cell separately.

Ranges also define the shape of many spreadsheet operations: filling formulas, naming data, applying formatting, and supplying function arguments. A range reference should match the intended data block and exclude headings or totals unless a function explicitly needs them. Stable table structure makes range-based formulas easier to copy and audit.
