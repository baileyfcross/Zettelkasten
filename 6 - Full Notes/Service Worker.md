# Service Worker

A service worker is a script the browser runs in the background without its own user interface. It can intercept fetch events, manage cached resources, and support application startup when the network is unavailable.

Because it mediates network resources, registration requires a [[Secure Origin]]. Its cache rules must distinguish application files from requests that should always reach the server.
