# Local Property

A local property is a property of a ring or module that holds globally if and only if it holds after [[Localization at a Prime Ideal]] for every prime. Local checks replace one global object with a family of local objects.

Vanishing is local, and under suitable finite-presentation conditions projectivity is local. The method is powerful because each localized ring has a single relevant maximal ideal.
