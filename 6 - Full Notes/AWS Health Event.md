# AWS Health Event

An AWS Health event communicates an AWS service condition that may affect an account or its resources. Public service status describes broad availability, while account-specific health information can identify impacted resources, scheduled changes, and recommended actions.

Health events complement workload monitoring: CloudWatch reveals what the system is experiencing, whereas AWS Health supplies provider context about service incidents or planned lifecycle changes. EventBridge rules can route relevant events into an operational response workflow.
