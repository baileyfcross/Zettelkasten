# R Index Vector

An R index vector selects object positions by supplying integer locations inside square brackets. Positive indexes retain the named positions, while negative indexes exclude positions; mixing positive and negative selections in one index is not a meaningful request.

For a matrix or data frame, row and column indexes occupy separate positions divided by a comma. Omitting one side retains every row or column along that dimension.
