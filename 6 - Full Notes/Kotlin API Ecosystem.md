# Kotlin API Ecosystem

The book groups Kotlin-accessible APIs into Android, networking, database and storage, graphics, machine learning and IoT, multimedia, cloud, backend, security, geolocation, dependency injection, and testing families. Kotlin's Java interoperability makes many established JVM libraries usable alongside Kotlin-specific libraries.

Examples include Retrofit, OkHttp, Ktor, Room, Firebase, Jetpack Compose, ML Kit, CameraX, ExoPlayer, and cloud SDKs. Selecting an API therefore begins with the system boundary—transport, persistence, interface, device, or service—that the application must integrate.
