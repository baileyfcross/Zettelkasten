# Java Queue and Deque Collections

A Java queue represents elements waiting to be processed, commonly in first-in-first-out order. Queue methods come in exception-throwing and special-value forms for inserting, examining, and removing an element, allowing a caller to choose how an empty or capacity-limited queue is handled.

A `Deque<E>` permits operations at both ends and can model a queue or stack. Implementations differ in ordering, capacity, thread safety, and null handling, so the interface expresses the access discipline while the chosen class expresses the operational guarantees.
