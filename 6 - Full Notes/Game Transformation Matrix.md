# Game Transformation Matrix

A game transformation matrix encodes a spatial operation such as scale, rotation, or translation in a form that can be applied consistently to points and directions. Homogeneous coordinates let translation participate in the same matrix machinery as linear transformations.

Combining transformations creates the matrices used to move geometry among model, world, camera, and projection spaces. The order matters because matrix multiplication is not commutative.
