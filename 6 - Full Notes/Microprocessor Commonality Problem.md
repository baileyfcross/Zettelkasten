# Microprocessor Commonality Problem

As integrated circuits grew more complex, each custom logic design served a narrower market. The commonality problem asked how a dense chip could justify mass production when few customers needed exactly the same fixed function.

The microprocessor solved the dilemma by putting a programmable general-purpose processor on the chip. Memory, input-output, and software let many customers adapt the same device to different applications.
