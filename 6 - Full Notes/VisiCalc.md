# VisiCalc

VisiCalc was an early electronic spreadsheet whose interactive grid let users change a value and immediately see related calculations update. It gave the Apple II a compelling business purpose.

The program put financial modeling under direct user control in a way batch mainframes could not match. It became an example of application software driving demand for a hardware platform.
