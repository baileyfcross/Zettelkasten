# Apache Hadoop

Apache Hadoop provides distributed storage, resource management, and MapReduce execution for data spread across a cluster. High-level systems can compile their scripts into Hadoop jobs instead of requiring users to implement every parallel task directly.

Its disk-oriented job boundaries scale one-pass processing but add startup, cleanup, and repeated-read costs to iterative analytics. Extensions can preserve data and worker processes across iterations.
