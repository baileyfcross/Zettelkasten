# Roblox Team Create

Team Create lets multiple collaborators edit a Roblox experience through a shared cloud session. Permissions determine who may access or edit the project, and real-time collaboration makes each person's changes visible to the others.

Shared editing needs coordination as well as access. Collaborators should divide work, communicate before restructuring shared objects, and test integrated changes rather than assuming isolated edits compose correctly. Reusable content managed through [[Roblox Package Versioning]] can reduce duplicated work across places and experiences while preserving a common source for updates.
