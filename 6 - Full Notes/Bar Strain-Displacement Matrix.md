# Bar Strain-Displacement Matrix

A bar strain-displacement matrix contains derivatives of the element shape functions. Multiplying it by the nodal displacement vector produces the axial strain represented within the element.

Multiplying that strain by Young's modulus gives element stress. The matrix is constant for a two-node linear bar but varies with position for a quadratic bar element.
