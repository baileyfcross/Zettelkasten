# Simple Field Extension

A simple field extension has the form K(c), the smallest subfield of an ambient field containing K and one adjoined element c. If c is algebraic, its minimum polynomial gives a finite basis.

The extension contains exactly the values a(c) obtained from polynomials over K, reduced below the minimum-polynomial degree.
