# Domain Name System

The Domain Name System maps human-readable domain names to network addresses used by hosts and routers. It lets an application identify a service by a stable name while the corresponding address can be maintained separately.

DNS resolution is a distributed lookup rather than a property inherent in the name. A network client must therefore account for lookup delay, unavailable resolvers, and names that resolve to several addresses.
