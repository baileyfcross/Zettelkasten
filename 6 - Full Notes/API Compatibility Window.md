# API Compatibility Window

An API compatibility window is the period during which an older published contract remains available while consumers move to a newer one. It separates releasing an improvement from immediately forcing every client to change.

The book recommends using versioning to preserve existing behavior, announcing the transition, and publishing version-specific documentation. The window needs an explicit end condition so maintaining old routes does not become an indefinite, unowned obligation.
