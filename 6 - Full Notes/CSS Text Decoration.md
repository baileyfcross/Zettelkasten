# CSS Text Decoration

CSS text decoration adds lines such as underlines, overlines, or line-through marks to text. Decoration properties can control the line type, style, and color, and a shorthand can combine those choices.

Decorations are painted across inline descendants even though the property is not inherited in the ordinary sense. This propagation explains why removing an underline from a nested element may not erase a line established by an ancestor.
