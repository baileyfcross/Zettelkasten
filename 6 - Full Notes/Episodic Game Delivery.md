# Episodic Game Delivery

Episodic game delivery releases one larger game in purchasable installments over time. Each episode can reach the market sooner and feedback from early releases can inform later work.

The core mechanics and interface usually must exist before the first episode, so the initial cost does not disappear. Declining sales can also leave promised story or features unfinished, which makes episode boundaries and production capacity part of the design.
