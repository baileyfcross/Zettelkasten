# Error Checks in Computational Pipelines

Errors can enter a computation while defining the problem, choosing formulas, setting constants, communicating values, storing data, performing operations, or displaying results. A reliable pipeline therefore checks intermediate as well as final outputs.

Checks should be placed where a recipient can verify what it receives before the error propagates. This makes failures easier to localize and prevents a long, fast computation from silently amplifying an early mistake.
