# Rectangular Matrix

A rectangular matrix has a different number of rows and columns. An $m\times n$ matrix is rectangular when $m\neq n$.

Rectangular coefficient matrices naturally describe [[Overdetermined Linear System|overdetermined]] and [[Underdetermined Linear System|underdetermined]] systems. They do not have ordinary two-sided inverses, but a [[Pseudoinverse]] and [[Least Squares Approximation]] can supply useful generalized solutions.
