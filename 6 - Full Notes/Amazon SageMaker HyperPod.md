# Amazon SageMaker HyperPod

Amazon SageMaker HyperPod provides resilient infrastructure for training large foundation models. It monitors cluster health, replaces faulty hardware, and helps resume training from checkpoints so a long distributed run does not have to restart after a node failure. HyperPod addresses infrastructure resilience and cluster management; teams still design the model, parallelization, checkpoint cadence, data pipeline, and evaluation process.
