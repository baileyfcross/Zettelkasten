# Client Endpoint Security

Client endpoint security protects the device from which a person reaches a cloud service. Malware, stolen credentials, unsafe applications, or a compromised browser can defeat server-side controls by impersonating an otherwise legitimate user.

Anti-malware, local firewalls, careful credential handling, timely updates, and restricted data storage reduce this risk. Thin or centrally managed clients can narrow the endpoint's responsibilities, but user behavior and device access remain part of the end-to-end security boundary.
