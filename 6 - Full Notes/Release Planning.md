# Release Planning

Release planning establishes a shared goal and forecasts how ordered backlog work may fit across several Sprints. The result connects product vision, likely Sprint Goals, scope, and a target date without claiming certainty.

The forecast is revised after every Sprint using completed work and newly discovered information. Scope or time changes when actual [[Velocity]] differs from the assumptions.
