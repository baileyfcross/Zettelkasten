# Turing-Computable Function

A function from strings to strings is Turing-computable when a [[Turing Machine]] halts on every input in its domain with the function's value arranged as its output. The machine must therefore both produce the correct string and halt in a defined output configuration.

Computable functions are closed under composition because one machine can compute the first function and then run a machine for the second on that result. This formalizes effective calculation independently of a particular programming language.
