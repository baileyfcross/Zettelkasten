# AWS CodeCommit

AWS CodeCommit is a managed private Git repository service. It stores source code and version history and integrates with AWS identity controls and delivery services, allowing repository changes to initiate an [[AWS CodePipeline]].

The repository supplies version control, not a complete delivery process. Reviews, branch practices, build verification, artifact handling, and deployment controls still need to be designed around it.
