# API Push Notification Delivery

API push notification delivery sends a message through a platform notification service to a registered application or device. It allows the back end to signal an event even when the client does not maintain an active connection to the API.

The book includes push notifications among serverless real-time patterns. Registration tokens, user preferences, authorization, payload privacy, delivery failure, and token expiration are part of the feature; accepting a notification is not the same as completing the underlying business operation.
