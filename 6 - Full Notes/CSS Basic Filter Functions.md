# CSS Basic Filter Functions

CSS basic filter functions include blur, drop shadow, and opacity operations. Blur spreads color around each pixel, drop-shadow derives a shadow from the rendered alpha shape, and opacity scales the visibility of the filtered result.

These operations can be chained within [[CSS Filter Effects]]. A filter drop shadow differs from [[CSS Box Shadows]] because it follows the alpha outline of the rendered content rather than the element's border box.
