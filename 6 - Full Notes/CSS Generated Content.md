# CSS Generated Content

CSS generated content uses the `content` property, commonly on `::before` and `::after`, to create presentational material around an element's content. Values can include strings, images, quotes, counters, and values obtained through [[CSS Attribute Values]].

Generated content participates in rendering without becoming ordinary source markup. It can label or number items, but essential document meaning should not depend solely on a presentational insertion.
