# Automated Feature Engineering

Automated feature engineering searches for transformations that improve a dataset's usefulness to a learning task. It reduces reliance on manual trial and error by generating, evaluating, and selecting candidate representations under a computational budget.

Automation does not remove design choices. The transformation library, exploration policy, evaluation signal, and stopping rule define which representations the system can discover and what it considers useful.
