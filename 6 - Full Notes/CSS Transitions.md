# CSS Transitions

A CSS transition interpolates an animatable property's value when a style change gives it a new computed value. Transition properties select the affected property, duration, timing function, and delay, and a shorthand can declare the components together.

The transition is triggered by an ordinary state change rather than by a separately named timeline. Unsupported transitions fall back to the final state, making them a presentational enhancement rather than a dependency for content.
