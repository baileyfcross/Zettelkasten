# Generative Model

A generative model describes how observed data could arise from underlying variables and their dependencies. It separates visible measurements from latent causes, allowing a complicated observation to be explained through a smaller set of interacting factors.

Inference often runs opposite the assumed causal direction. A disease may generate symptoms, but diagnosis estimates the hidden disease from observed symptoms; [[Bayesian Network Inference]] relates these conditional directions. A graphical representation can make the dependencies explicit and support probability calculations over causes and observations.
