# Acceptance Criterion

An acceptance criterion states an observable condition that must hold for a requirement or [[User Story]] to be considered satisfied. It turns an intended outcome into evidence that a customer, tester, and developer can evaluate consistently.

Criteria should describe behavior and relevant conditions without prescribing incidental implementation. They later support acceptance tests and prevent completion from being judged only by whether code was written.
