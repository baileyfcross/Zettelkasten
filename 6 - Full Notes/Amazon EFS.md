# Amazon EFS

Amazon Elastic File System provides a managed, elastic NFS filesystem that Linux workloads can mount from multiple availability zones. Capacity grows and shrinks with stored files rather than requiring a fixed volume size.

EFS is useful when several compute instances need shared hierarchical file access. Network path, throughput mode, access points, lifecycle policies, and security groups still affect its behavior. It serves a different contract than per-instance block storage.
