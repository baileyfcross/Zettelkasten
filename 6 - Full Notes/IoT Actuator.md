# IoT Actuator

An IoT actuator converts a digital instruction into a physical action. Whereas an [[IoT Sensor]] turns the environment into data, an actuator closes the loop by moving a motor, locking a door, changing a valve, sounding an alarm, adjusting a thermostat, or otherwise altering the world.

Actuation makes connected-system errors materially consequential. A false reading is no longer only bad information when it can trigger braking, medication delivery, industrial machinery, or building controls. IoT control therefore requires explicit rules, dependable controllers, and [[IoT Reliability and Fail-Safe Design]] proportionate to the action's possible effects.
