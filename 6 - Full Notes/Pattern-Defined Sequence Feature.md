# Pattern-Defined Sequence Feature

A pattern-defined sequence feature combines a sequence pattern with a usage method. The pattern states what ordered structure to recognize, while the usage method turns its matches into a value or set of values.

Separating these two parts clarifies that one mined pattern can support several representations. Presence, frequency, interval counts, positions, and sliding-window summaries emphasize different aspects of the same matches.
