# MongoDB .NET Driver

The MongoDB .NET Driver provides typed client, database, collection, query, and document-identifier APIs for C# applications. The book installs the driver in ASP.NET Core and points it at the MongoDB-compatible endpoint of a Cosmos DB account.

A `MongoClient` uses the configured connection string, then selects a named database and collection. Compatibility at this API boundary lets application code remain familiar even though the underlying service is Azure Cosmos DB.
