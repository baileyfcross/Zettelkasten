# Exponential Function

An exponential function has the form $f(x)=a^x$ for a positive base $a\ne1$. Its domain is all real numbers, its values are positive, and it passes through $(0,1)$. It grows when $a>1$ and decays when $0<a<1$. Its inverse is the logarithm with the same base.
