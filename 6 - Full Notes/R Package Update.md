# R Package Update

R package update compares installed package versions with those available from configured repositories and installs newer releases. Updating can deliver corrections and compatibility changes, but it can also alter behavior on which an analysis depends.

The candidate list should be reviewed before changing a working environment, and important analyses should preserve session and version information. Packages currently loaded may need to be updated in a fresh session so their files are not in use.
