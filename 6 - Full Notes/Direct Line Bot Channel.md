# Direct Line Bot Channel

The Direct Line channel lets a custom application communicate directly with a registered Bot Framework bot. A client uses the channel secret to start a conversation, post activities, and retrieve the bot's replies.

The book wraps the Direct Line client library in a .NET Standard project used by a UWP interface. The wrapper keeps the external dependency and conversation identifier outside the view while delivering received messages through a callback.
