# zoo Time Series Object

A `zoo` object couples ordered observations with a [[Time Index]] without requiring a particular index class. It can hold a vector, matrix, or factor as its [[zoo Core Data]], which makes it suitable for regular and irregular series. Methods for merging, [[Time Series Windowing|windowing]], [[Time Series Aggregation|aggregation]], plotting, and missing-value treatment preserve the temporal relationship instead of reducing the object to an ordinary table.
