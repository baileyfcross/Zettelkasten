# Triangular Potential Element

A triangular potential element uses three nodal values to define a linear scalar potential over a two-dimensional triangle. Counterclockwise node ordering and vertex coordinates determine the shape functions and element area.

Because the potential varies linearly, its gradient and the associated field are constant within the element. A mesh of triangles approximates spatially changing fields through piecewise-constant gradients.
