# LUIS Endpoint

A LUIS endpoint is the hosted address through which an application submits language for recognition. The bot configures the service hostname together with an application identifier and API key, then constructs a recognizer for each request.

The endpoint exposes the published model rather than draft edits in the authoring interface. Configuration must therefore identify the correct model version and credentials before runtime predictions can reflect recent training.
