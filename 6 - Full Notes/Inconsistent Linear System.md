# Inconsistent Linear System

An inconsistent linear system has no solution because its equations impose contradictory requirements.

Row reduction exposes inconsistency when an [[Augmented Matrix]] contains a row with all zero coefficients but a nonzero right-hand side. No choice of the unknown vector can satisfy such an equation.
