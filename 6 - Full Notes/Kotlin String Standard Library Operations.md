# Kotlin String Standard Library Operations

Kotlin's standard library supplies string operations for inspecting length and content, changing case, splitting and joining text, replacing segments, trimming surrounding characters, and testing prefixes, suffixes, or containment.

These functions return results without changing the original string, because strings are immutable values. A chain of operations therefore describes successive text transformations, while the original reference continues to denote the same text unless it is reassigned to a new result.
