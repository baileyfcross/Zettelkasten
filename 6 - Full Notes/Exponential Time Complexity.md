# Exponential Time Complexity

Exponential time complexity has a variable in the exponent, such as $O(2^n)$. Each modest increase in [[Input Size]] can multiply the required work, causing runtime to exceed physical limits quickly.

An exponential [[Algorithm]] may prove that a solution can be found in principle without providing a practical method. When no efficient exact method is known, an [[Approximation Algorithm]] may trade guaranteed optimality for a useful answer obtainable in reasonable time.
