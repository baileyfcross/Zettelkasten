# Unity Tilemap

A Unity Tilemap stores and renders repeated tiles on a grid to build two-dimensional worlds efficiently. Creating one also establishes a Grid object whose cell size and spacing can be shared by several layered tilemaps.

Separate background, platform, and foreground maps can use their own sorting and collision behavior while remaining aligned. The Tilemap component governs cell content and placement, whereas its renderer controls presentation. Tiles are selected from a [[Unity Tile Palette]] and painted into cells.
