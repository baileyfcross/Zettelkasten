# Web Form

A web form collects user values and submits them for an application operation. A useful form must provide understandable controls and feedback while also producing data the application can validate and process.

Angular can represent a form through a template-driven or reactive model. Regardless of the client approach, the server must repeat essential validation because the browser-side form can be bypassed or altered.
