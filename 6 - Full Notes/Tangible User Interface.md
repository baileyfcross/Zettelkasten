# Tangible User Interface

A tangible user interface uses physical objects to represent digital information and to provide mechanisms for interacting with it. Computation can be distributed among objects that are aware of their location or proximity to other objects.

Because the physical representation and the control are integrated, users can apply existing skills for handling real-world objects. Multiple spatially aware objects can also support concurrent access and manipulation.

Tangible interfaces are a form of [[Embodied Interaction]] and can overlap with [[Augmented Reality]] when physical objects are enhanced by digital information.
