# Fraction

A fraction is a number written as

$$\frac{m}{n},$$

where the [[Numerator]] (m) and nonzero [[Denominator]] (n) are integers. It represents the quotient (m\div n) and can be located by dividing each unit interval on the [[Number Line]] into (n) equal parts.

A single value can have many fractional names because multiplying the numerator and denominator by the same nonzero factor preserves the quotient. This relationship produces [[Equivalent Fraction]]s and allows reduction through the [[Cancellation Law for Fractions]].
