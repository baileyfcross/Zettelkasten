# TSV-SAFE Framework

TSV-SAFE is a two-stage framework for protecting defective through-silicon vias from electromigration. An offline stage tests TSVs and produces a [[TSV Defect Fault Map]]; an online stage connects the damaged vias to mitigation modules.

The online modules monitor current direction and periodically drive balancing current to exploit electromigration self-healing. A switching network and grouped sharing reduce overhead while keeping every mapped defective via reachable.
