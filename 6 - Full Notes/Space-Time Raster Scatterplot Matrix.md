# Space-Time Raster Scatterplot Matrix

A space-time raster scatterplot matrix compares cell values between every pair of selected raster times or temporal aggregates. Each point represents the same cell in two layers, so linear or nonlinear patterns show how spatial values persist or change. Diagonal density summaries describe each layer's distribution. The matrix grows quickly with layer count and does not show where deviating cells are located.
