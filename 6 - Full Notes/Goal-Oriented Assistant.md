# Goal-Oriented Assistant

A goal-oriented assistant is built to help a user complete a concrete task rather than merely sustain conversation. The goal supplies a criterion for choosing actions, asking for missing information, and deciding when the interaction is complete.

A [[Dialog Manager]] advances the task by collecting required values, invoking [[Digital Service Integration]], and presenting the result through language or another interface.
