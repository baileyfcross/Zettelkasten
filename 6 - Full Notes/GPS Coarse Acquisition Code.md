# GPS Coarse Acquisition Code

The GPS coarse/acquisition code is the shorter civil ranging code used to acquire satellite signals and measure code phase. Each satellite transmits a distinct sequence, enabling a receiver to separate signals that occupy the same carrier frequency. Its unexpectedly strong positioning accuracy helped create a civil market, but that accuracy also led the Defense Department to introduce [[Selective Availability]] as a policy-based degradation rather than redesign the code.
