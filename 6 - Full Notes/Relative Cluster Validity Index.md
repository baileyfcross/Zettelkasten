# Relative Cluster Validity Index

A relative cluster validity index compares two or more candidate clusterings of the same data. It helps select an algorithm, parameter setting, or number of groups by ranking their fit under one criterion.

The result identifies the best member of the compared set, not necessarily an adequate model in absolute terms. The candidate set and criterion must therefore be reported.
