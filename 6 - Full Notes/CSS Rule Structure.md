# CSS Rule Structure

A CSS style rule contains a selector followed by a declaration block. The selector identifies the document subjects, while each declaration pairs a property with a value and ends with a semicolon inside braces.

Several selectors can share one block through [[CSS Selector Grouping]], and several declarations can style the same matched elements. Invalid or unsupported declarations are ignored independently when the surrounding syntax can still be parsed.
