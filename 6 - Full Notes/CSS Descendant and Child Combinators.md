# CSS Descendant and Child Combinators

A descendant combinator matches an element anywhere inside another matched element, regardless of the number of intervening generations. It is represented by whitespace between selectors.

A child combinator, written with `>`, requires the second subject to be an immediate child of the first. The distinction lets selectors use document structure either broadly or narrowly without altering the markup.
