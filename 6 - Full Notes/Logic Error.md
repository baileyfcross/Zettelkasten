# Logic Error

A logic error occurs when valid code executes but implements the wrong rule, ordering, condition, or calculation. The program may return an incorrect result, fail only on an edge case, or appear correct until a particular path is exercised.

Because the language processor cannot know the intended behavior, logic errors require evidence from tests, review, or observed failures. Debugging then compares the actual state transition with the requirement or algorithm to locate where the program's reasoning diverges.
