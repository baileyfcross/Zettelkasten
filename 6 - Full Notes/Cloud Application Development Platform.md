# Cloud Application Development Platform

A cloud application development platform supplies a standardized runtime, tools, libraries, and supporting services so developers can build and deploy without first procuring the infrastructure stack. Ready-made storage and database services can become application building blocks.

The model can shorten the develop-build-test-deploy cycle and let capacity grow with an application's users. The convenience may create [[Vendor Lock-In]] when code, data, or operational procedures depend strongly on provider-specific facilities.
