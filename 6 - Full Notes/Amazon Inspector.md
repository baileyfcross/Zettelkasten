# Amazon Inspector

Amazon Inspector continuously scans supported workloads for software vulnerabilities and unintended network exposure. It correlates findings with contextual information so teams can prioritize affected EC2 instances, container images, and Lambda functions.

Inspector identifies known weaknesses; it does not apply every repair or prove that an application is secure. Findings need an ownership and remediation process that considers exploitability, workload importance, patch testing, and accepted exceptions.
