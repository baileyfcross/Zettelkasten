# CSS Element Blending

Element blending uses `mix-blend-mode` to choose how an element's colors combine with the backdrop behind it. Modes include darkening, lightening, multiply, screen, overlay, difference, hue, saturation, color, and luminosity families.

The backdrop depends on stacking and compositing context, so the same element can produce different colors over different content. [[CSS Isolated Blending]] can restrict which backdrop participates.
