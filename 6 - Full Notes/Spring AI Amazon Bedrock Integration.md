# Spring AI Amazon Bedrock Integration

Spring AI's Amazon Bedrock integration lets a Java application configure supported Bedrock models behind Spring AI model interfaces and ChatClient usage. Provider credentials, region, and model selection remain infrastructure configuration while the application uses the framework's common interaction pattern.

The integration reduces provider-specific request code but does not remove Bedrock's service constraints or a model's distinct capabilities. Model identifiers, permissions, regions, options, guardrails, and response behavior require environment-specific verification.
