# Processor Customization Flow

A processor customization flow starts with a simple programmable core and adds architectural features that match an application's bottlenecks. The book evaluates cache-aware software transformations, prefetch and cache controls, on-chip memory with DMA, and floating-point SIMD.

The goal is not a fixed-function circuit. It is a small general core augmented with reusable features, evaluated jointly for performance, power, energy, and area so that an improvement in one dimension does not conceal an unacceptable cost in another.
