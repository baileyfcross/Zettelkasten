# Route-Aware Page Template

A route-aware page template keeps navigation or other shared interface elements in place while rendering the selected route's content through the [[Children Prop|children prop]]. Section components compose their changing content inside the same surrounding layout rather than copying the menu into every page.

When paired with nested routes, the template makes URL hierarchy and visual hierarchy reinforce each other. Active navigation links can derive their styling from the current match while the template remains independent of the particular section body.
