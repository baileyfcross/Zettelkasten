# Model Recognition

Model recognition infers which of several candidate probabilistic models best explains observed evidence. A hidden model variable selects a component, and the posterior over that variable retains uncertainty when several behaviors remain plausible.

The chosen models and their priors define the alternatives the system can recognize. Evidence outside all candidates can still be forced toward the least unsuitable model unless the description includes an unknown or failure alternative.
