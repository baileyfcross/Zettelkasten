# Matrix Norm

A matrix norm assigns a nonnegative size to a matrix and is compatible with matrix addition and scalar multiplication. Common induced norms measure the largest column sum, largest row sum, or maximum stretching of Euclidean vector length.

Matrix norms bound products and errors. They are used with the norm of the inverse to define a [[Matrix Condition Number]].
