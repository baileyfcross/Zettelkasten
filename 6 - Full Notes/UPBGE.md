# UPBGE

UPBGE, the Uchronia Project Blender Game Engine, is an open-source continuation derived from Blender's former integrated game engine. It preserves a Blender-centered workflow in which scenes, game logic, physics, audio, and rendering can be developed within a unified application rather than exported repeatedly to a separate engine.

The version described in the source combines Bullet-powered rigid and soft bodies, obstacle simulation, pathfinding, OpenAL and SDL audio, visual logic, Python bindings, physically based materials, reflection controls, and an HDR pipeline. Its main architectural promise is continuity between content creation and interactive execution, though its version-specific capabilities still require verification for a chosen project.
