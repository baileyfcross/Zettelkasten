# Databricks Genie MCP Connection

A Databricks Genie MCP connection exposes a Genie space to a Microsoft Foundry agent through Model Context Protocol tools. The integration lets the agent discover the available analytical capability, submit a natural-language data question, and use the returned result inside a broader conversational workflow.

Production setup requires more than establishing network reachability. Teams need a supported OAuth or workload identity flow, reviewed tool schemas, least-privilege access to the Genie space, traceable calls, and tests for routing and answer accuracy. After publishing, managed identity can replace development credentials when the downstream configuration supports it.
