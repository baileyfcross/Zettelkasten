# Network Threat Detection Report

A network threat detection report turns parsed events and context into a reviewable incident artifact. It should identify the affected asset, source and destination, observed behavior, supporting log lines, threat-intelligence matches, severity rationale, uncertainty, and recommended next steps.

Structured fields make reports comparable and let downstream systems reject missing evidence. The model can improve explanation and prioritization, but source events should remain linked so an analyst can verify every claim. Recommendations should distinguish investigation from containment because they carry different operational risk.
