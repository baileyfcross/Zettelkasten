# Simple Game Entity

A simple game entity is completely described by one datum. The value can be numeric, such as a score, or symbolic, such as the current color of a traffic light.

Simplicity concerns representation rather than importance. A single value can govern major consequences, and its allowed range and meaning still need precise rules.
