# Streaming Machine Learning

Streaming machine learning updates a model or produces predictions from a continuing sequence without repeatedly retraining from a complete stored dataset. Incremental algorithms use bounded state and can adapt as conditions change.

They must detect concept drift, control the influence of stale data, and evaluate accuracy when labels arrive late or only for a subset of events.
