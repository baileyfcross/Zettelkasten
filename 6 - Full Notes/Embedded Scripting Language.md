# Embedded Scripting Language

An embedded scripting language is an existing language whose interpreter or virtual machine is integrated into the game engine. The engine registers functions and objects that scripts can call, and it invokes scripts at defined events.

Using a language such as Lua avoids implementing a complete language toolchain. The tradeoff is adapting the language's runtime, data model, debugging, and security characteristics to the needs of the game.
