# Web Analytics Data Quality

Web analytics data quality concerns whether logs and derived fields consistently represent real user activity. Missing identifiers, duplicate events, bot traffic, internal requests, malformed timestamps, and changing instrumentation can distort conclusions.

Quality review should precede aggregation so apparently precise charts do not merely summarize collection artifacts.
