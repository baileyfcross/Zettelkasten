# R LaTeX Graphics Export

R LaTeX graphics export separates or coordinates graphical elements and text so mathematical labels can be typeset consistently with a LaTeX document. This workflow improves font and equation consistency but requires the generated graphics and text files to remain paired during compilation.

The target document size should be chosen before export so line widths, label positions, and symbol sizes remain legible. It complements a general [[Plot Export Device]] when publication typography matters more than a self-contained image file.
