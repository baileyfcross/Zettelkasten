# Karma

Karma is a JavaScript test runner that starts a web server, launches a browser, executes source code against configured tests, and reports results. It supplies the runtime environment in which Jasmine-defined Angular tests operate.

The runner can watch source changes and execute the suite again, giving quick feedback while a component or service is developed.
