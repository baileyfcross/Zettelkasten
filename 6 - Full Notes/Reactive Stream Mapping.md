# Reactive Stream Mapping

Mapping a reactive stream transforms each emitted value into a value for a derived stream. In the book's numerical example, a stage adds three to each value after merging and filtering. The transformation preserves a flow of notifications while changing their payload, allowing several small operators to express a larger data-processing pipeline.
