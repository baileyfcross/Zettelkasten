# Partition Summary Cross-Tabulation

A partition summary calculates cluster counts and sizes and, when labels are present, builds a cross-tabulation between discovered cluster indexes and supplied classes. The table reveals how each unlabeled group overlaps known categories.

Cluster indexes have no inherent correspondence with class labels, so the table is more informative than comparing index numbers directly. It remains an external diagnostic, not a parameter used by the unsupervised algorithm.
