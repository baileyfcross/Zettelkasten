# Azure Site-to-Site VPN

An Azure Site-to-Site VPN connects an external network to an Azure virtual network through encrypted IPsec tunnels across the public internet. It can establish hybrid connectivity quickly and suits smaller traffic volumes or backup paths where ExpressRoute is unnecessary. Gateway redundancy, tunnel configuration, on-premises devices, internet quality, route exchange, bandwidth, and failover testing determine the actual reliability of the connection.
