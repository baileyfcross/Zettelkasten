# Game Attribute

A game attribute is a named value that contributes to a part's current state. First-order attributes hold amounts, second-order attributes describe rates of change, and higher-order attributes can describe changes in those rates.

Attribute ranges should be understandable, broad enough to distinguish meaningful states, and reusable across related parts. Every added attribute increases implementation and balance complexity, so it should enable useful behavior or a [[Meaningful Decision]].
