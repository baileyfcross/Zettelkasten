# Data Science Problem Framing

Problem framing translates a real-world goal into a task whose required evidence and output can be specified. The book identifies clustering, anomaly detection, association-rule mining, and prediction as four common task classes. Prediction further divides into categorical classification and numeric regression.

Choosing the task early changes dataset design. A churn classifier needs historic cases with churn labels; a clustering study does not require a target attribute. The business-understanding phase should therefore specify both the intended action and the kind of pattern that could inform it before selecting an algorithm.
