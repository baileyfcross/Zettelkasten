# UML Destroy Message

A UML destroy message indicates that a participant's lifetime ends during the interaction. The receiving lifeline terminates at that point, conventionally marked with an X.

The message is useful when disposal or explicit termination affects later behavior. It should represent an actual modeled lifetime decision rather than the ordinary end of a diagram.
