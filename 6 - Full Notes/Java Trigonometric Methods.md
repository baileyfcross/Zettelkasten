# Java Trigonometric Methods

Java Math trigonometric methods such as `sin`, `cos`, and `tan` accept angles in radians and return double-precision results. `toRadians` converts a degree measurement before it is passed to those operations.

Graphing sampled sine and cosine values requires mapping each returned value, which lies from negative one through positive one, into an array's row coordinates. Scaling, rounding, and offsetting connect the mathematical result to the discrete display grid.
