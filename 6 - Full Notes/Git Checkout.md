# Git Checkout

`git checkout` can switch the working tree and `HEAD` to another branch or commit. In the workflow described by the source, `git checkout -b name` creates a branch and immediately switches to it.

Switching can overwrite the working-tree representation, so conflicting uncommitted changes must be resolved or preserved first. Newer Git versions also provide more focused switch and restore commands, but checkout remains a historical combined interface.
