# Git Status

`git status` summarizes the current branch and the relationship among the working tree, staging area, and current commit. It identifies untracked paths, unstaged modifications, and changes selected for the next commit.

The command is a safety check before staging, committing, or switching work. It does not change repository state and should be used to verify what Git currently sees.
