# LLMOps

LLMOps is the set of practices and tools used to manage the lifecycle of applications built around large language models. It extends [[MLOps]] with prompt and context management, retrieval pipelines, foundation-model selection, adaptation, evaluation of generated output, safety controls, and token-cost monitoring.

Because an LLM application may change when its prompt, retrieved knowledge, model endpoint, or tool set changes, release evidence must cover more than a model binary. Continuous evaluation and traceable configuration are central to dependable operation.
