# Recommendation Evaluation Objective

A recommendation evaluation objective specifies what outcome the system is trained and tested to improve. Rating error, click-through rate, watch time, completion, conversion, diversity, and satisfaction reward different behaviors, so selecting the metric helps define what the recommender learns to do.

YouTube's early click-optimized system illustrates objective misalignment: enticing but disappointing videos generated more clicks and were mistakenly rewarded. Moving attention toward watch time changed the ranking behavior and user experience. [[Learning to Rank]] can optimize an ordered set of candidates, but [[Algorithmic Accountability]] still requires asking whose outcome the objective represents and checking the consequences through real-world experiments.
