# Query Parameter

A query parameter is a named value encoded after the question mark in a URL. It supplies optional navigation state, such as search criteria, without changing the route's path structure.

A React component reads the location search string and parses its values. The parameter should be encoded when written and treated as untrusted input when it later becomes part of an API request.
