# Eye Tracking

Eye tracking measures where and how a person's eyes move. In a [[Head-Worn Display]], inward-facing sensors can estimate gaze direction so the system knows which part of the visual field currently receives direct attention.

Gaze can serve both as input and as a rendering signal. It can help select an object, reveal where attention moves, or drive [[Foveated Rendering]], which concentrates graphical detail near the point of regard. The system must distinguish looking from intending to act, because ordinary visual inspection should not trigger every gazed-at control.

The same measurements create a privacy concern. Patterns of fixation, avoidance, and repeated attention can expose interests or reactions that a person never chose to state, connecting display instrumentation to [[Data Privacy]].
