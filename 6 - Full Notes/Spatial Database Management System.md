# Spatial Database Management System

A spatial database management system extends ordinary data management with geographic data types, operations, algorithms, and indexes. It can store points, lines, polygons, and rasters and answer questions involving distance, containment, overlap, direction, slope, or proximity without requiring every application to recreate the geometry machinery.

These capabilities support GIS, navigation, remote sensing, and spatial analysis. Their value is both semantic and computational: the database can express a spatial question directly and can use a [[Spatial Index]] or geometric algorithm to avoid testing every stored object.
