# Susceptible-Infected-Susceptible Model

The susceptible-infected-susceptible model allows an active node to stop transmitting and become susceptible again. Unlike the recovered state in an SIR process, the node can later be reinfected.

This recurrence changes the relationship between a current snapshot and its source because nodes may enter the active set more than once. Source estimation must use a model consistent with that possibility.
