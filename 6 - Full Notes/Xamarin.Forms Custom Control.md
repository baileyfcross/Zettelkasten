# Xamarin.Forms Custom Control

A Xamarin.Forms custom control defines a reusable shared abstraction with its own bindable properties and behavior. It can derive from an existing Xamarin.Forms element or establish a new element intended to be rendered differently on each platform.

The control should describe the cross-platform contract rather than embed native implementation details. A composite implementation or custom renderer can then supply its appearance and behavior.
