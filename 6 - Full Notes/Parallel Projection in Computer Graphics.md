# Parallel Projection in Computer Graphics

Parallel projection models the center of projection as being at infinity, so every projector reaches the view plane in the same direction. It avoids the distance-dependent foreshortening of [[Perspective Projection in Computer Graphics]] and can preserve parallelism and measurable scale in selected directions.

Orthographic projection uses projectors perpendicular to the view plane, while oblique projection uses a different fixed direction. Axonometric views are orthographic views of a rotated object that expose several faces at once. These forms favor dimensional clarity and technical communication over photographic realism.
