# Neural Network FPGA Acceleration

Neural network FPGA acceleration configures programmable logic, memory blocks, and DSP resources for a particular network or layer schedule. It can tailor bit width, sparsity handling, pipeline depth, and dataflow more closely than a GPU while consuming less energy.

The design is constrained by on-chip memory, off-chip bandwidth, logic resources, and compilation effort. [[High-Level Synthesis]] and generated accelerator frameworks can shorten development, but efficient mapping still requires explicit control of locality and parallelism.
