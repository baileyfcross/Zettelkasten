# Web Browser

A Web browser requests resources identified by URLs, interprets HTML and related formats, and presents linked information for navigation. Berners-Lee created an early browser along with the Web’s protocols.

Graphical browsers integrated images, typography, icons, and mouse input. They turned Internet access from a specialist activity into a widely usable information environment.
