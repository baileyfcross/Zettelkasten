# Query by Committee

Query by committee maintains several plausible classifiers and requests labels where their predictions disagree most. Disagreement marks cases for which the current evidence does not determine a stable hypothesis.

The committee must represent meaningful alternatives rather than repeated copies of one model. Vote entropy, divergence among predicted distributions, or margin between competing votes can quantify the disagreement used for selection.
