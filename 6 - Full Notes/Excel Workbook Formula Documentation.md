# Excel Workbook Formula Documentation

Excel workbook formula documentation is an inventory of calculated cells and their relevant properties, such as worksheet, address, formula text, and current value. A VBA procedure can scan worksheets and write this information to a dedicated documentation sheet.

The inventory exposes logic that is otherwise distributed across the grid and supports review, comparison, and maintenance. It is a snapshot rather than a live guarantee, so it should be regenerated after material workbook changes. A documentation routine should avoid including its own output in repeated scans and should clearly distinguish formulas from cached results.
