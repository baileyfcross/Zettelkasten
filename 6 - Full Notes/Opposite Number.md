# Opposite Number

The opposite of a number (a) is the number (-a) that combines with it to produce the additive identity:

$$a+(-a)=0.$$

Opposites lie the same distance from zero on opposite sides of the [[Number Line]]. Taking the opposite twice returns the original value, so (-(-a)=a). The notation does not say a number is negative by itself: if (a<0), then (-a>0). Subtraction can be defined as addition of an opposite, (a-b=a+(-b)).
