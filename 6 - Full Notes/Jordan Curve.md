# Jordan Curve

A Jordan curve is a [[Closed Parametric Curve|closed]] planar curve whose only repeated point is the shared initial and terminal point. Thus it is closed and otherwise [[Simple Parametric Curve|simple]].

Because the trace does not cross itself, it forms the kind of oriented boundary for which an enclosed region and a positive traversal direction can be identified unambiguously.
