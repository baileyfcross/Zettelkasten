# Predictive Policing Feedback Loop

A predictive policing feedback loop occurs when recorded police activity is used to direct future enforcement, causing more activity to be recorded in the same places and then treated as evidence of greater underlying crime. The model learns partly from the institution's earlier attention rather than from a neutral measure of all offending.

This loop can intensify unequal surveillance even if the algorithm applies its rule consistently. More deployment creates more data, and more data appear to validate the deployment. Breaking the loop requires distinguishing reported or discovered incidents from actual prevalence and evaluating the social costs of concentrated enforcement.

Spatial hot-spot analysis can initiate this cycle when a department treats recorded crime as a neutral map of underlying crime. Assigning more officers to the selected area increases opportunities to observe and record offenses there, which makes the next analysis reproduce the original concentration. The feedback is social as well as statistical because the model changes the data-generating environment.
