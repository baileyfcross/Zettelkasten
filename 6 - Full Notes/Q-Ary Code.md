# Q-Ary Code

A q-ary code uses an alphabet identified with a finite field containing $q$ elements. A linear q-ary code of length $n$ and dimension $k$ is a $k$-dimensional subspace of the $n$-coordinate message space.

Binary and ternary codes are the cases $q=2$ and $q=3$. Arithmetic performed in the field makes parity conditions and matrix-based encoding algebraically closed.
