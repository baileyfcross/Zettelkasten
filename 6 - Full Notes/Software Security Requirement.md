# Software Security Requirement

A software security requirement states a protection the system must provide for identities, data, operations, or infrastructure. Authentication, authorization, confidentiality, integrity, auditing, and isolation requirements constrain both application behavior and deployment design.

The requirement should identify the asset and threat context rather than merely request that a system be secure. Specificity allows controls and tests to be matched to the consequence of unauthorized access or modification.
