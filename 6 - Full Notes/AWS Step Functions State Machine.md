# AWS Step Functions State Machine

An AWS Step Functions state machine describes a workflow as connected states. States can run tasks, make choices, execute work in parallel, wait, retry failures, catch errors, and pass structured data from one step to the next.

The service makes orchestration logic visible instead of scattering it among application components. It can coordinate Lambda functions and other AWS services, while execution history provides a record of transitions and failures for each workflow instance.
