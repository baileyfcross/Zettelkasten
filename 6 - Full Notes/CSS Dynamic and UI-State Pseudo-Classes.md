# CSS Dynamic and UI-State Pseudo-Classes

Dynamic pseudo-classes match states that can change through user activity, such as links being visited, a pointer hovering, or an element receiving focus. UI-state pseudo-classes describe controls that are enabled, disabled, checked, valid, invalid, required, or optional.

Because the matched state can change without editing the document, the applicable declarations can change interactively. Their order in the [[CSS Cascade and Inheritance|cascade]] still determines which visual response wins.
