# CSS Text Shadows

The `text-shadow` property paints one or more shadows behind text. Each shadow supplies horizontal and vertical offsets, an optional blur radius, and an optional color; comma-separated shadows are layered together.

A zero-blur shadow produces a sharp displaced copy, while increasing blur softens its edge. Several shadows can create outlines or depth effects, but they do not alter the text's layout dimensions.
