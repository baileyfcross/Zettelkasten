# Analytic Metadata

Analytic metadata records the information needed to interpret and reuse a prepared dataset: variable names, classes, roles, labels, units, transformations, exclusions, and target definitions. It turns implicit script knowledge into an explicit contract.

Saving metadata with the data and partition information supports consistent modeling and later scoring.
