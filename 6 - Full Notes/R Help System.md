# R Help System

The R help system provides documentation for functions, packages, datasets, and topics from within the working environment. Help pages describe arguments, returned values, details, references, and runnable examples.

Consulting the installed documentation ties an analyst's understanding to the package version actually in use and supports careful interpretation of function behavior.
