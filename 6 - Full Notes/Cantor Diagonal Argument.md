# Cantor Diagonal Argument

Cantor's diagonal argument refutes a proposed enumeration by constructing an object that differs from the nth listed object in its nth position. The constructed object cannot equal any entry, so the list is incomplete.

Applied to infinite binary sequences or real-number expansions, the argument proves uncountability. The related theorem that no set is bijective with its [[Power Set]] shows that larger cardinalities can always be formed.
