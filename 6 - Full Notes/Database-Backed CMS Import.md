# Database-Backed CMS Import

A database-backed CMS import maps existing records into the content types, identifiers, and relationships expected by the new system. It must preserve meaning while translating source fields into structured pages, posts, components, or media references.

Reliable imports are repeatable, validated, and explicit about conflicts and missing data. Running them as a controlled migration is safer than embedding one-time assumptions in ordinary request handling.
