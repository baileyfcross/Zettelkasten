# Support Vector Machine Dual Problem

The support vector machine dual problem rewrites margin optimization in terms of one coefficient for each training observation. Feature vectors appear only through pairwise inner products, which permits kernel substitution.

Box and equality constraints restrict the coefficients, and observations with nonzero solutions become support vectors. The dual can be advantageous when feature dimension is large, though its quadratic dependence on training cases creates scaling challenges.
