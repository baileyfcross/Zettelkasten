# Azure DevOps

Azure DevOps is the service used in the book to host source code and automate the application's build and release flow. Repository changes trigger a build pipeline, and successful artifacts move through a release pipeline toward Azure staging and production resources.

The service coordinates the workflow, but the pipeline definition supplies its actual guarantees. Compilation, tests, artifact boundaries, deployment settings, and promotion rules must all be made explicit.
