# String Text Representation

A string text representation treats a document as an encoded sequence of characters. Byte sequences interpreted through standards such as UTF-8 can represent written symbols from many languages without first assuming words, grammar, or meaning.

This shallow form supports operations such as approximate matching, spelling correction, plagiarism alignment, and spam similarity. It is general but poorly suited to semantic tasks because character sequence alone does not expose word identity or higher linguistic structure.
