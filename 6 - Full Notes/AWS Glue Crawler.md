# AWS Glue Crawler

An AWS Glue crawler connects to a data source, samples its contents, infers schema and partitions, and creates or updates table metadata in the [[AWS Glue Data Catalog]]. Crawlers reduce manual catalog maintenance when files arrive or structures evolve. Inference should still be reviewed: inconsistent source files can produce undesirable types or table boundaries, and a scheduled crawl is not a substitute for explicit data contracts and quality checks.
