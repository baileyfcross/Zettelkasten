# MATLAB Plot

MATLAB plotting turns vector or matrix data into two- or three-dimensional graphs. A two-dimensional plot pairs vectors of input and output values, while mesh and surface commands use gridded values for functions of two variables.

Labels, axes, markers, multiple curves, and subplots provide context. The numerical sampling chosen through the [[MATLAB Colon Operator]] affects how smoothly a curve or surface is represented.
