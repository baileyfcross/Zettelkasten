# AWS Cloud WAN

AWS Cloud WAN provides a centrally managed policy and dashboard for connecting VPCs and on-premises networks across regions. Its core network acts as a global routing fabric whose segments can isolate environments or business groups while policies automate attachment and route behavior. It is useful when a single-region Transit Gateway design becomes a collection of separately managed regional networks.
