# AWK Built-In Variable

Awk built-in variables expose processing state and control parsing or output. Examples include the current and total record numbers, field count, input and output separators, output number format, and the current filename.

Assigning a control variable can change how later records are interpreted, while reading a state variable supplies context for conditions and reports. Their names are part of awk's language and should not be reused as ordinary application variables.
