# Gap-Constrained Sequence Pattern

A gap-constrained sequence pattern allows matched elements to be separated while limiting the permitted gap lengths. It captures ordered relationships that need not be contiguous but should remain locally related.

Tighter gap bounds reduce accidental matches and search complexity; looser bounds provide invariance to intervening events. The appropriate constraint follows from the sequence's domain and scale.
