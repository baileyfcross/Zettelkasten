# Reference Images for Blender Sculpting

Reference images help a digital artist judge proportion, scale, and silhouette while modeling or sculpting. Blender can place an image object directly in the 3D Viewport, keeping the reference aligned with the work instead of in a separate application.

An image object can be transformed like other scene elements and aligned to a chosen viewing orientation. Camera objects can also display background images that appear only through the camera view.
