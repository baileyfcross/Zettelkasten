# AWS X-Ray

AWS X-Ray collects distributed traces that follow requests across supported applications and AWS services. Segments and subsegments expose service relationships, latency, faults, and downstream calls, helping operators distinguish where a distributed request spent time or failed. Useful traces require propagated context and application instrumentation, and sampling must balance diagnostic coverage with overhead and cost.
