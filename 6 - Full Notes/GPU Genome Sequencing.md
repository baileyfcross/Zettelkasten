# GPU Genome Sequencing

GPU genome sequencing maps parallel sequence comparison or alignment work onto many graphics-processor threads. It can exploit repeated arithmetic and independent candidate regions while retaining more programming flexibility than a fixed circuit.

Irregular control and memory access can reduce utilization, and host-device transfer remains part of runtime. GPU suitability therefore depends on how the sequencing algorithm decomposes, not only on dataset size.
