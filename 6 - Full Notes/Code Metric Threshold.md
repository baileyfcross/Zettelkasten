# Code Metric Threshold

A code metric threshold marks a value beyond which a measurement should trigger review or fail a quality policy. It can be applied to complexity, maintainability, duplication, coverage, or other automated signals.

Thresholds make expectations repeatable, but a universal number can punish necessary complexity or permit poorly structured code just below the limit. Teams should tune them from risk and history and retain an explicit process for justified exceptions.
