# File-Level Defect Prediction

File-level defect prediction estimates which source files are likely to contain defects. Each file is represented by code properties and historical process measures accumulated over a chosen period.

The prediction unit makes outputs actionable for inspection or testing, but labels and features must respect time to avoid using future defect information. Class imbalance and project differences also affect evaluation.
