# HTTP Request

An HTTP request is a message a client sends to a server to ask for a resource or operation. Its route, method, headers, parameters, and optional body give the server the information needed to select and perform handling.

In ASP.NET Core, the request passes through the [[HTTP Request Pipeline]] before an endpoint or middleware handles it. An Angular client can construct requests through [[Angular HttpClient]].
