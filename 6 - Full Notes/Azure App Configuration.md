# Azure App Configuration

Azure App Configuration centralizes application settings and feature flags outside deployable binaries and container images. Labels can distinguish environments or variants, and supported applications can refresh values without rebuilding. It can reference Key Vault secrets while retaining configuration metadata itself. Centralization improves consistency only when access, naming, version behavior, fallback values, cache duration, and change ownership are defined.
