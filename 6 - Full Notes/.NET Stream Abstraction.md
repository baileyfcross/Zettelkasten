# .NET Stream Abstraction

A .NET stream represents an ordered flow of bytes and gives code a common interface to files, memory, networks, and other data sources. Consumers can read, write, seek, or copy according to the capabilities reported by the particular stream.

Because the abstraction separates data processing from storage, the same logic can often operate on a `FileStream`, `MemoryStream`, or network-backed stream. Buffering and asynchronous operations can then be selected without redesigning the domain logic that consumes the bytes.
