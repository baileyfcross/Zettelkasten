# Reinforcement Learning for Feature Exploration

Reinforcement learning for feature exploration models transformation choices as actions and performance improvement as reward. A policy or value function learns which operations tend to produce useful representations in particular states.

This approach can reuse experience across search steps or datasets. State design, delayed rewards, expensive evaluations, and the enormous action space remain major challenges.
