# AWS Network Firewall

AWS Network Firewall is a managed, scalable, stateful network firewall for inspecting VPC traffic. Rule groups can use stateful and stateless rules, including Suricata-compatible definitions, and logs can be sent to services such as Amazon S3 or CloudWatch Logs. Route tables must deliberately steer traffic through firewall endpoints; deploying a firewall without symmetric routing and maintained rule policy does not create effective inspection.
