# Azure User-Assigned Managed Identity

An Azure user-assigned managed identity is a standalone Azure resource that can be attached to one or several workloads. Its lifecycle is independent of those workloads, allowing permissions to remain stable during resource replacement and enabling controlled sharing. That reuse also broadens the blast radius of its role assignments, so ownership, attachment, scope, and separation among applications should be deliberate.
