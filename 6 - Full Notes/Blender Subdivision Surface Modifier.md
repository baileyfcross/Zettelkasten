# Blender Subdivision Surface Modifier

The Subdivision Surface modifier adds derived geometry to make a coarse mesh appear smoother. It is especially useful for organic forms because a relatively simple control mesh can define a much denser displayed surface.

Keeping subdivision procedural separates shape control from display detail. Viewport and render levels can be managed independently so the scene stays responsive while still producing a smooth final image.
