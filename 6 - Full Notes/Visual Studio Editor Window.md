# Visual Studio Editor Window

The Visual Studio Editor window displays and edits the active source file. Multiple open files appear as tabs, while syntax analysis, completion, and quick actions connect the text to the project's compiled model.

Because the editor understands code structure, it can propose fixes and refactorings that update more than the visible line. Those operations should still be reviewed as semantic changes to the solution.
