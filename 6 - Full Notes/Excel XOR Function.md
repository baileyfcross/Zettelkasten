# Excel XOR Function

The Excel XOR function applies an exclusive logical test. With two conditions, it returns TRUE when exactly one condition is true and FALSE when both have the same truth value. It is useful for mutually exclusive alternatives rather than the inclusive alternatives represented by [[Excel OR Function]].

For more than two arguments, XOR reflects whether an odd number of conditions are true, which can be less intuitive than the two-condition case. A formula using several arguments should therefore document the intended rule and be tested against representative combinations. The function can feed an [[Excel IF Function]] when mutually exclusive states require different outputs.
