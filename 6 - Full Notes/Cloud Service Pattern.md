# Cloud Service Pattern

A cloud service pattern is a reusable description of how cloud capabilities solve a recurring use case. It gives the pattern a name, states the problem and circumstances, identifies component [[Cloud Cell]]s and their relationships, and records the tradeoffs or consequences.

A web-service pattern might combine web, database, storage, service-bus, and firewall cells with stated internal and external interfaces. The pattern supports repeatable architecture without requiring every implementation to be identical.
