# Shared Cloud Security Responsibility

Shared cloud security responsibility divides protection duties between the cloud provider and the consumer. The provider commonly secures infrastructure up to the service interface, while the consumer secures its configuration, application behavior, credentials, data, and manner of access.

The precise boundary changes with the [[Cloud Abstraction Level]]. A more managed service transfers more infrastructure operation to the provider, but it does not transfer the consumer's responsibility to configure access correctly or use the service safely.
