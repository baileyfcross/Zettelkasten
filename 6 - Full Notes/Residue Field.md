# Residue Field

For a [[Local Ring]] (R,m), the residue field is the [[Quotient Ring]] R/m. It is a [[Field]] because m is a [[Maximal Ideal]].

Reducing a module modulo m turns it into a vector space over the residue field. [[Nakayama's Lemma]] uses the dimension of this vector space to identify a minimal number of generators.
