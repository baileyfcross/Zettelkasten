# Cold Cloud Storage

Cold cloud storage is optimized for data retained for longer periods and accessed infrequently. It lowers the continuing storage price while making reads and writes more expensive than a hot tier.

Backups and archived photos can fit this tradeoff once routine testing is complete. Some providers also offer a still colder archival tier for data that is expected to be retrieved rarely, if at all.
