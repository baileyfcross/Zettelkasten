# Thin Client

A thin client is a user device that retains a local operating system but depends on remotely hosted applications, data, or computation for much of its useful work. It provides an interface to services instead of running and maintaining every application locally.

Centralizing applications can reduce endpoint hardware and support requirements and limit data stored on a lost device. The client becomes more dependent on network access and the availability of the remote service.
