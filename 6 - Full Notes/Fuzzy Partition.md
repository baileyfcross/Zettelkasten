# Fuzzy Partition

A fuzzy partition covers a data set with clusters whose membership values may lie anywhere between zero and one. Under a probabilistic constraint, the memberships of each observation across all clusters sum to one.

A [[Crisp Partition]] is the special case in which every membership is exactly zero or one. Fuzzy partitions make boundary cases visible instead of hiding them behind one hard label.
