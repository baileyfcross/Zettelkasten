# User Manager

User Manager is the ASP.NET Core Identity service that provides APIs for creating, locating, validating, and updating application users. It coordinates the user store with configured normalization, password, and validation services.

Application code receives it through [[Dependency Injection]]. A seed operation can use User Manager with [[Role Manager]] to establish default users and role membership in a repeatable way.
