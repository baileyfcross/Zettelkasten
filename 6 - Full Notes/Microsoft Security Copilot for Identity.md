# Microsoft Security Copilot for Identity

Microsoft Security Copilot can investigate identity activity through an Entra integration using natural-language prompts. It grounds a request in authorized tenant data, decomposes the request into a process, calls security capabilities, and presents a result that an analyst can inspect and refine.

Embedded experiences bring this assistance into identity investigation surfaces, while the standalone experience supports broader cross-product analysis. The assistant inherits the operator's permissions and does not replace verification: prompts can be ambiguous, source data can be incomplete, and a generated explanation remains an analytical aid. Organizations should therefore apply least privilege, review cited evidence, protect submitted data, and keep consequential remediation under accountable human control.
