# Expression Evaluation

Expression evaluation finds the numerical value of an [[Algebraic Expression]] for specified values of its variables. The values are inserted through [[Substitution]], then operations are performed according to the expression's grouping and precedence.

For (a^3+b^3+3ab) with (a=1) and (b=2), evaluation replaces every occurrence consistently before calculating. Parentheses around substituted negative values are important because ((-2)^2) differs from (-2^2). Evaluation checks a formula at a particular assignment; it does not prove an [[Algebraic Identity]] for all assignments.
