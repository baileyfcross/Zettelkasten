# Model Space

Model space is the coordinate system in which a three-dimensional model's vertices are authored relative to that model's own origin. The same mesh can be reused because its stored geometry does not need to know where the object will appear in the game world.

A world transform converts these local coordinates into [[World Space]] by applying the object's scale, rotation, and translation.
