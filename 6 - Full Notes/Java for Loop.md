# Java for Loop

A classic Java `for` loop places initialization, continuation condition, and update in one header followed by a repeated body. Initialization runs once, the condition is checked before each iteration, and the update runs after the body unless control leaves the loop.

Any header component can be omitted, so the form can express an intentionally unbounded loop as well as a counted one. Keeping the loop variable's scope in the header and making progress toward a terminating condition visible reduces off-by-one and nontermination errors.
