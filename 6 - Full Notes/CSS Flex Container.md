# CSS Flex Container

An element becomes a flex container when its display value is `flex` or `inline-flex`. The former participates externally as a block-level box and the latter as an inline-level box, while both create the same flex formatting context for their contents.

Direct child boxes become [[CSS Flex Items]]. Text runs can be wrapped in anonymous flex items, but an element nested inside a child is not itself a flex item of the outer container.
