# Computer Worm

A computer worm is self-contained [[Independent Malware]] that copies itself between systems, commonly by exploiting network reachability or software weaknesses. Unlike a [[Computer Virus]], it does not need to attach to a host file to propagate.

Autonomous replication can create rapid, large-scale effects even when damage is not the only objective. The [[Worm Component Model]] highlights the targeting, propagation, activation, and payload functions that enable this spread.
