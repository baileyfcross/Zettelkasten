# Gaussian Mixture Model

A Gaussian mixture model combines several normal distributions, each with its own mean, covariance, and mixture weight. The components create regions of increased density interpreted as clusters.

Covariance determines each cluster's volume, orientation, and ellipsoidal shape. Probabilistic memberships allow the component regions to overlap.
