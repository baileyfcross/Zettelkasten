# Neural Network Optimizer

A neural-network optimizer is an algorithm that determines how weights and biases are changed to reduce the [[Loss Function]]. It converts derivative information into a sequence of [[Neural Network Parameter Update|parameter updates]].

Different optimizers can make training faster or more stable, enabling larger networks to be fitted efficiently. The optimizer does not define the network's architecture or loss; it governs the procedure used to move the adjustable parameters toward lower error.
