# Shell Environment Variable

A shell environment variable is a named value exported into the environment inherited by child processes. Variables such as `PATH`, `HOME`, `SHELL`, locale settings, and editor preferences influence how the shell and launched programs locate resources and present behavior.

A shell-local variable is not inherited until it is exported. Command-line assignments normally last only for the active session, while persistent settings belong in the appropriate startup file and should be scoped globally or per user with care.
