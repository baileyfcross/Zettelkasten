# Input Chord

An input chord is a combination of controls that must be active at approximately the same time to represent one command. It treats simultaneous state as meaningful, such as a modifier held while another button is pressed.

Chord recognition differs from an [[Input Sequence]], where order and timing across successive presses matter. Both translate low-level device events into higher-level player actions.
