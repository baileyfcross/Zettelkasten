# Network Layer

A network layer contains nodes and edges associated with one relationship type, system, context, or time slice. A complete multilayer model combines its layer graphs with rules for how their nodes and edges correspond.

Separating layers prevents distinct interactions from being collapsed into one edge. Whether every layer shares the same node set depends on the selected [[Multilayer Network]] type.
