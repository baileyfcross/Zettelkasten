# Attribute Selection for Clustering

Attribute selection for clustering chooses the features that define similarity among observations. Irrelevant variables can dominate proximity calculations and obscure the structure the study intends to discover.

The selection should follow the application and data types. For categorical data, redundant attributes can violate useful independence assumptions by counting the same distinction repeatedly.
