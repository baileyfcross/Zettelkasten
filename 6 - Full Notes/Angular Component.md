# Angular Component

An Angular component is a client-side unit that coordinates interface behavior with a view. Its TypeScript class stores state and actions, its [[Angular Component Template|template]] describes rendered markup, and its styles control presentation.

Components can receive injected services, participate in the [[Angular Component Lifecycle]], issue requests through an [[Angular HttpClient]], and expose data for binding in their templates.
