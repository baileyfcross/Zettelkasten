# Excel IFERROR Function

The Excel IFERROR function evaluates an expression and returns an alternate value when that expression produces an error. It can replace errors with a message, a blank, or a defined fallback, which is useful when a lookup has no match or a denominator may be zero.

IFERROR should make an anticipated failure understandable rather than conceal every defect. Wrapping a large formula too early can hide misspelled names, invalid references, and other errors that need correction. The fallback should communicate what happened, and the unwrapped expression should be tested first so the workbook does not mistake a broken formula for missing data.
