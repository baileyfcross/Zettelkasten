# Root

An (m)th root reverses an (m)th power. If (a=b^m), then (b) is an (m)th root of (a), written

$$b=\sqrt[m]{a}.$$

The number (m\geq2) is the root's index and (a) is the quantity under the root symbol. An index of two is normally omitted, producing a [[Square Root]], while an index of three gives a [[Cube Root]]. Root extraction can produce an [[Irrational Number]] even when the original value is a natural number.
