# Common Neighbor Link

A common-neighbor link between two categorical records is the number of other records that are neighbors of both under a selected similarity threshold. A large link count suggests the pair participates in the same local structure.

ROCK uses links rather than raw pairwise similarity when deciding cluster merges. This makes shared context part of the relationship.
