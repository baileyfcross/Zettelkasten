# Metric Units for Game Asset Exchange

Using metric scene units gives Blender and a target game engine a shared interpretation of object size. When both treat a world unit as a meter, scale decisions can be checked during modeling instead of corrected unpredictably after import.

Unit consistency does not replace transform checks or exporter settings, but it creates a stable foundation for them. Character height, doorway clearance, physics distances, and camera movement can all be reasoned about in the same measurement system.
