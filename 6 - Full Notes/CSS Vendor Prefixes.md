# CSS Vendor Prefixes

A vendor prefix marks a property, value, or related feature as an implementation-specific version associated with a browser engine. Prefixes historically allowed browsers to expose experimental CSS before the feature was finalized or consistently implemented.

Prefixed and unprefixed forms may need to coexist, with the standard form placed later so it can win when supported. [[CSS Feature Queries]] can test relevant property-value support instead of assuming a feature from the browser name.
