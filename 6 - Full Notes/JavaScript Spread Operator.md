# JavaScript Spread Operator

JavaScript spread syntax expands the values of an array or the fields of an object into a new surrounding structure. It can combine arrays, copy a collection before applying a mutating operation, or construct a changed object while leaving the original object intact.

The related rest form collects remaining items into an array, such as the unassigned arguments after destructuring the first and last values. In functional code, spread commonly supports [[JavaScript Immutability|immutable updates]] by copying existing data before adding or replacing a field.
