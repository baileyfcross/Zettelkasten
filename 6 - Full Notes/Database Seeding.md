# Database Seeding

Database seeding populates a database with an initial or known set of records after its structure is available. Seed data can establish application prerequisites, development examples, or default identities and roles.

The WorldCities application imports city and country data through a seed controller, while its identity setup creates default users and roles. Seeding should be repeatable enough to avoid creating unintended duplicates when it runs again.
