# Selenium Tag Name Locator

A Selenium tag-name locator selects elements by their HTML tag with `By.tagName`. It is useful for collecting repeated structures such as all anchors, images, list items, or options rather than identifying one unique element.

Because a tag is broad, the method commonly participates in [[Selenium Multiple Element Lookup]]. Tests can then iterate over the returned elements to read text, validate attributes, or perform the same check on each item.
