# ML.NET

ML.NET is a machine-learning framework for building and consuming models from .NET applications. It provides data-loading, transformation, training, evaluation, and prediction APIs that integrate with C# types and ordinary application projects.

The framework organizes work as a pipeline rather than hiding the decisions required for useful learning. A successful application still depends on representative data, an algorithm suited to the task, appropriate metrics, and validation against data not used for training.
