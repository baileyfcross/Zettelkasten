# Text Classification Gini Index

The text classification Gini index scores a word from the concentration of class probabilities among documents containing it. Under the source's convention, values approach one when a term occurs almost entirely in one class and approach one divided by the number of classes when it is evenly distributed.

Normalization against the global class distribution can prevent an already dominant class from making ordinary words appear discriminative.
