# Drug-Target Interaction Network

A drug-target interaction network represents drugs and biological targets as nodes with known interactions as edges. Chemical similarity, target similarity, and network structure can be used to predict missing links that suggest new mechanisms or repurposing opportunities.

The network is only partially observed. A missing edge may mean that no interaction exists or simply that it has not been studied. Evaluation should therefore avoid treating all unknown pairs as reliable negatives and should prioritize predictions whose evidence can be tested experimentally.
