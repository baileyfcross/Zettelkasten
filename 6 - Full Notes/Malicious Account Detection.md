# Malicious Account Detection

Malicious account detection identifies profiles operated to spam, deceive, or automate harmful dissemination. Useful features include duplicated profile fields, shared URLs, geographic concentration, sparse fields, name patterns, and posting behavior.

Early detection can cluster similar account names or profiles before classifying the clusters. The cost of false positives remains important because blocking legitimate participants damages the service and its users.
