# Game Release

Game release is the transition from controlled development to availability for the intended public. It requires accepting that a creative work can be finished enough to deliver without becoming perfect in its creators' eyes.

Release also opens the outermost [[Designer Loop]]: broad player behavior and market response reveal lessons unavailable from prototypes or small playtests. Those lessons can guide later refinement, but the game must first become a real, accessible whole.
