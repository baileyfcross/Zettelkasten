# Diverging Color Palette

A diverging color palette uses two contrasting ordered ramps extending from a light neutral center. It suits values whose sign or direction around a meaningful reference, often zero, matters. For an asymmetric distribution, the class interval containing the reference should align with the neutral color; otherwise the visual center misstates the analytical center. The palette should not be used merely because a variable has a wide range.
