# Common Illumination

Common illumination models light transport across the real-virtual boundary so both kinds of object appear to share one environment. Real lights affect virtual objects, while virtual objects may cast shadows, reflections, or indirect light onto representations of real surfaces.

This requires more than matching the brightness of a virtual object. The renderer needs scene geometry, material assumptions, illumination estimates, and a compositing method that preserves the original camera image where no virtual effect occurs.
