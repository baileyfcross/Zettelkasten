# Feature Extraction

Feature extraction reduces dimensionality by transforming original variables into a smaller set of derived coordinates. Unlike [[Feature Selection]], it does not retain a literal subset of the input columns.

Methods such as [[Principal Component Analysis]] and [[Linear Discriminant Analysis]] construct linear combinations that preserve variance or improve class separation. Extraction can concentrate useful signal, but the resulting coordinates are often less directly interpretable than the original variables.
