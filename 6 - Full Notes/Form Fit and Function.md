# Form Fit and Function

Form describes an object's geometry, fit describes how it interfaces with neighboring objects or an environment, and function describes the behavior it must perform. An engineering model is adequate only when its representation preserves the aspects of all three that matter to the analysis.

A visually correct shape can still be unusable if contact locations do not connect or if omitted features carry an important load, flow, or thermal path. The intended function determines which geometric details are essential.
