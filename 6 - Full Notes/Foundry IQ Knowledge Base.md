# Foundry IQ Knowledge Base

A Foundry IQ knowledge base connects a Microsoft Foundry agent to approved documents and other knowledge sources so responses can be grounded at runtime. Adding a source triggers parsing, structural extraction, and indexing; access settings can restrict the knowledge base to selected sources and disable external browsing.

Creation is not proof that retrieval works. Uploaded documents may index poorly because of scans, unsupported layouts, stale versions, or ambiguous structure. Test queries should verify that the expected content and citations are returned before the knowledge base is attached to an agent, and every source should have an owner and update process.
