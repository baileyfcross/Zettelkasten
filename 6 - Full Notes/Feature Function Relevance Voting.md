# Feature Function Relevance Voting

Feature function relevance voting scores a variable by summing the relevance assigned to the known functions associated with it. A controlled vocabulary provides a binary feature-by-function representation, and each function contributes its weight to every annotated feature.

Function weights can come from experts or be learned from data. The method makes functional knowledge directly actionable without first converting it into sample geometry, but incomplete or uneven annotation can favor heavily documented features.
