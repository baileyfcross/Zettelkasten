# Game World

A game world is the artificial universe in which game events occur. It can be a simulated space containing characters and objects or a more abstract setting established through rules and representation.

The world gives context to actions and goals, but not every game needs an elaborate fictional place. Its dimensions should support gameplay rather than accumulate detail that the player cannot use or perceive.
