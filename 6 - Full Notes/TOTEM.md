# TOTEM

TOTEM is a heterogeneous graph-processing system that partitions graph work between CPUs and GPUs. It aims to use GPU throughput while retaining CPU memory capacity and flexible control for work less suited to the accelerator.

Partition choice and communication across the host-device boundary determine whether heterogeneous execution outperforms either processor alone.
