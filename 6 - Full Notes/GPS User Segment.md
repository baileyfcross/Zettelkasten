# GPS User Segment

The GPS user segment consists of receivers, antennas, software, and the people or machines that use their results. A receiver selects visible satellites, correlates their codes, decodes orbital data, measures pseudoranges, and solves for position, velocity, and time. Because reception is passive, the constellation can serve an unlimited practical number of users, while receiver design determines which frequencies, codes, corrections, and integrity features are available.
