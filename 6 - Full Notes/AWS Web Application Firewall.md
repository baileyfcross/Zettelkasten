# AWS Web Application Firewall

AWS Web Application Firewall filters HTTP and HTTPS requests using web access control lists and rules. Rules can inspect addresses, headers, paths, query strings, request bodies, rates, and known malicious patterns before traffic reaches a supported application endpoint.

AWS WAF mitigates application-layer threats and abusive requests; it is not a replacement for secure application code or network controls. Managed rule groups offer maintained starting points, while logging and testing help avoid rules that block legitimate clients.
