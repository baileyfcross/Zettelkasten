# Inverse Interpolation

Inverse interpolation estimates an argument $x$ corresponding to a specified function value $y$. One approach interchanges the roles of the tabulated variables and interpolates $x$ as a function of $y$.

The interchange is appropriate only on a locally one-to-one portion of the data. Alternatively, an ordinary interpolation formula can be rearranged into an equation for the normalized argument and solved iteratively, connecting inverse interpolation with [[Numerical Root-Finding Methods]].
