# EasyFX Add-On

EasyFX exposed prepared compositor effects such as vignettes, cel-style treatments, curves, and contrast adjustments through a simpler control panel. Changing its options generated the corresponding compositor node network instead of requiring every node to be assembled manually.

The convenience did not eliminate the underlying graph: the generated nodes remained available for inspection. Some changes updated the rendered image immediately, while others required a fresh render because they depended on newly calculated scene output.
