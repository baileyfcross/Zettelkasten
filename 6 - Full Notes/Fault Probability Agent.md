# Fault Probability Agent

A fault probability agent estimates which candidate nodes are most likely to have caused an incident. It combines reachability, response time, error rate, resource saturation, historical failures, recent changes, and dependency relationships supplied by an investigation workflow.

The probabilities rank hypotheses rather than establish causation. The calculation method, inputs, uncertainty, and updates should be visible so engineers can compare the model's ranking with the actual fault network and gathered evidence.
