# Cross-Platform Mobile Application

A cross-platform mobile application targets more than one operating system while reusing some language, framework, interface, or application logic. Cross-platform development does not make the platforms identical; it establishes a deliberate shared layer and leaves platform projects responsible for differences that cannot or should not be abstracted.

The amount of reuse depends on the chosen approach. Hybrid applications share web assets, while native cross-platform frameworks share managed code and translate or connect it to native APIs and controls.
