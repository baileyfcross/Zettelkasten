# Network Optimization Opportunity Detection

Network optimization opportunity detection compares topology, capacity, and health evidence to find overloaded links, underused alternatives, fragile dependencies, or configuration patterns worth reviewing. A model can assemble these signals into candidate changes and explain their expected benefit.

An opportunity is not a command. The analysis must preserve affected devices, evidence, assumptions, and dependencies so engineers can reject a locally attractive change that harms the wider topology. Recommendations move next to [[Change Risk Assessment for Network Remediation]].
