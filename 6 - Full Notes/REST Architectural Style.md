# REST Architectural Style

Representational State Transfer is an architectural style for networked systems built from constraints rather than a prescribed wire format. It organizes an API around resources, representations, self-descriptive messages, stateless exchanges, cacheability, client-server separation, and layered intermediaries.

Compliance is a system property rather than a label attached to JSON over HTTP. Each constraint changes how clients and servers evolve, scale, and understand an interaction, so adopting only an HTTP endpoint does not by itself make a service RESTful.
