# CreatedAt Action Result

A created-at action result reports that a request created a resource and includes a location from which the new representation can be retrieved. ASP.NET Core can generate that URI from a named action or route and return the created response body with it.

The result connects creation to the resource's stable public identity. Route values must identify the new item correctly, or the response advertises a location that cannot resolve to the created resource.
