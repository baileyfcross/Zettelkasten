# Address Translation

Address translation converts a virtual address generated by a CPU into a physical page frame plus an offset. The memory-management unit walks the active [[Page Table]] when a translation is not already cached in the translation lookaside buffer.

Translation enables isolation, sharing, permissions, sparse address spaces, and demand paging without requiring programs to know physical locations. A missing or disallowed translation raises a page fault so the kernel can populate the mapping or reject the access.
