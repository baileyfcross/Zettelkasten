# Tree Ancestor Distance

In a ranked dendrogram, the distance between two leaves can be read from the level at which their branches first share a common ancestor. Nearby leaves join low in the hierarchy; leaves from distant branches meet at a higher level.

This cophenetic or ancestor distance is ultrametric when merge levels rise consistently toward the root. It turns the tree into a distance representation, so the same hierarchy can support cluster cuts, proximity queries, and analysis of how data structure changes with resolution.
