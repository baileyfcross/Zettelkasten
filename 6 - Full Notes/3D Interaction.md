# 3D Interaction

3D interaction is [[Human-Computer Interaction]] in which the user's task is performed directly in a real or [[Virtual Environment|virtual]] three-dimensional spatial context.

Displaying 3D graphics does not by itself create 3D interaction. Choosing a viewpoint from a conventional menu is still ordinary menu interaction, while selecting a location in a 3D world with a 2D mouse can count as 3D interaction because the input is mapped directly to a spatial target. Spatial input such as hand gestures or physical walking is common but not required.

A [[3D User Interface]] combines 3D interaction with suitable [[Input Device]]s, [[Output Device]]s, and [[Interaction Technique]]s.
