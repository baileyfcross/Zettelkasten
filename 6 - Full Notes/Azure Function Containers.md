# Azure Function Containers

Azure Function containers package the Functions runtime, triggers, bindings, application code, and dependencies into a container image. They can run on supported App Service or Functions plans, in Container Apps environments, or on compatible self-hosted infrastructure. Packaging improves runtime control and portability, but trigger scale, platform integration, image updates, startup time, and hosting-plan behavior still distinguish a function container from an ordinary long-running service.
