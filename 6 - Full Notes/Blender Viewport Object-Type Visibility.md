# Blender Viewport Object-Type Visibility

Blender's object-type visibility controls limit which categories of objects a particular 3D Viewport displays or allows the user to select. Meshes, curves, cameras, lights, armatures, empties, Grease Pencil objects, and other types can be controlled independently through visibility and selectability switches.

The control is especially useful in large scenes because it reduces visual clutter and prevents accidental selection without deleting data or globally reorganizing the scene. Its scope is the viewport, so it is a working-view filter rather than a render decision. The distinction complements object- and collection-level organization in the [[Blender Outliner]].
