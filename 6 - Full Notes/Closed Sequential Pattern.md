# Closed Sequential Pattern

A closed sequential pattern is a frequent sequence pattern for which no strictly more specific superpattern has the same support. Retaining closed patterns removes support-equivalent redundancy without losing the frequency information of the full frequent set.

Closedness compresses the candidate space before feature mapping. It does not guarantee predictive usefulness, so class discrimination or downstream selection may still be needed.
