# R HTML Table Import

R HTML table import locates table elements in a web document and converts their rows and cells into candidate data frames. A page may contain layout tables, repeated headers, footnotes, merged cells, or several unrelated tables, so the analyst must select and validate the intended result.

This is narrower than [[R Web Page Scraping]], which extracts data from arbitrary page structure. Table import works best when the publisher has already encoded the information as a consistent HTML table.
