# Matrix Sketching for Data Streams

Matrix sketching maintains a compact matrix that approximates important properties of a much larger streaming data matrix. The sketch can preserve covariance or projection behavior needed for downstream dimension reduction.

Because its size is bounded independently of stream length, a sketch makes one-pass processing feasible. Approximation guarantees quantify the information sacrificed for memory and speed.
