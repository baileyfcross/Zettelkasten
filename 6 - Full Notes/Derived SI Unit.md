# Derived SI Unit

A derived SI unit is an algebraic combination of [[SI Base Unit]]s. Force, for example, has base units $\mathrm{kg\,m\,s^{-2}}$ and is named the newton; energy has units $\mathrm{kg\,m^2\,s^{-2}}$ and is named the joule. Expressing a named unit in base units makes dimensional consistency visible.
