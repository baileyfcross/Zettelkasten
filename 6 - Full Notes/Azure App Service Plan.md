# Azure App Service Plan

An Azure App Service plan defines the compute capacity and hosting tier used by one or more App Services. The web applications run within the resources allocated by that plan rather than owning independent servers directly.

The plan is therefore a capacity and cost decision for the hosted application. Client and backend services may share a plan when that arrangement fits their environment and demand.
