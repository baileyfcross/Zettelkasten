# Vertical Scalability

Vertical scalability changes the capacity of an individual resource by making it more powerful, such as by increasing its memory or processing capability. The service continues to rely on fewer larger instances rather than adding more peers.

This contrasts with [[Horizontal Scalability]], which changes the number of resource instances. The two approaches have different operational limits, and the book defines cloud elasticity specifically through horizontal scaling out and in.
