# Azure DevOps Feature Work Item

An Azure DevOps feature work item groups backlog items that together provide a coherent capability within an epic. It is smaller than the strategic outcome but larger than the user-valued increments a team completes during sprints.

The feature boundary helps coordinate related work and expose progress. It should describe a recognizable capability, not merely a component team or an arbitrary calendar bucket.
