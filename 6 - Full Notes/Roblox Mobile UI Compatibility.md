# Roblox Mobile UI Compatibility

A Roblox mobile interface must remain readable and operable on smaller screens while sharing space with touch controls. Buttons need adequate target size and spacing, important information must avoid device-specific overlays, and layouts should adapt rather than assume a desktop resolution.

Device emulation helps reveal problems, but interaction should also be tested with touch behavior and mobile performance. [[Roblox Responsive GUI Layout]] provides proportional sizing and constraints, while [[Roblox Cross-Platform Performance Optimization]] ensures that the interface is not attached to a world the device cannot run smoothly.
