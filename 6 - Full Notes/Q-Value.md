# Q-Value

A q-value assigns each feature the smallest estimated false discovery rate at which that feature would be included in the selected set. It is a multiple-testing analogue of a p-value tied to discovery-list error rather than one-test null evidence.

Thresholding q-values produces a list with a chosen estimated error rate. The interpretation depends on the underlying [[Null Proportion Estimate]] and false-discovery model used to calculate them.
