# Universal Machine versus Stored Program

A universal machine can simulate any other computer when given that computer’s program. A stored-program machine is one particular organization in which instructions reside in internal memory alongside data.

The concepts are related but not identical. Babbage’s Analytical Engine and ENIAC were intended as universal machines even though their programs were supplied externally rather than stored in memory.
