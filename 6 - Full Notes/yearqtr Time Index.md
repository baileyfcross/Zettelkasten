# yearqtr Time Index

The `yearqtr` class represents calendar quarters in an ordered form designed for quarterly [[Time Series|time series]]. It preserves the period's meaning when printing, converting, selecting a [[Time Series Windowing|window]], or aligning observations. The class plays the same role for quarters that [[yearmon Time Index]] plays for months: it records temporal resolution without manufacturing a precise day that the source data does not contain.
