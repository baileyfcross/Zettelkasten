# Monte Carlo Simulation

Monte Carlo simulation repeats a random experiment computationally and summarizes the generated outcomes to approximate probabilities, expectations, or model behavior. The algorithm must specify the probability mechanism, the statistic recorded from each trial, and the number of repetitions.

Increasing repetitions reduces simulation noise but does not repair an incorrect model. R scripts make the experiment inspectable by separating random generation, repeated calculation, summarization, and diagnostic plotting.
