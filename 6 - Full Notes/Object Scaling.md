# Object Scaling

Object scaling changes the size of an object. Unlike selection, positioning, and rotation, it has no direct everyday counterpart, but it is a common manipulation in two- and three-dimensional interfaces.

Scaling tasks vary by initial size, target size, amount of change, distance to the object, and required precision. A technique should make the scale factor and reference point clear through its mapping and [[Feedback]].

Object scaling is a canonical [[3D Manipulation]] task and should remain distinct from scaling an entire world for [[3D Travel]] or viewpoint control.
