# Inverse Hyperbolic Function

An inverse hyperbolic function reverses a suitably restricted [[Hyperbolic Function]]. Because hyperbolic functions are built from exponentials, solving their defining equations for the original argument produces logarithmic formulas.

For example, inverting $x=\sinh y$ gives $y=\ln(x+\sqrt{x^2+1})$. Hyperbolic cosine requires a branch choice because it is even, so its inverse is defined only after a domain and output range are selected.
