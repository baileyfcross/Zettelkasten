# Amazon Comprehend

Amazon Comprehend applies natural-language processing to text. It can detect language, entities, key phrases, sentiment, and syntax, and it supports custom models for organization-specific classification and entity recognition.

The service turns unstructured text into labels and metadata that applications can search, aggregate, or route. Results express model judgments rather than objective truth, so confidence scores, representative evaluation data, and human review matter when classifications have consequences.
