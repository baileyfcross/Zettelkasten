# Client-Side Validation

Client-side validation checks form values in the browser and provides immediate feedback before a request is submitted. Required fields, lengths, numeric ranges, and pattern rules can be reflected directly in the form model and template.

This improves user experience but is not a security boundary. A caller can bypass the Angular interface, so every important rule must also be enforced through [[Server-Side Validation]].
