# Thermal Analysis

Thermal analysis determines temperature distribution and derived heat flow in a body. In the primer, it is a scalar finite element problem because each node carries one temperature degree of freedom.

The procedure selects an element and temperature interpolation, derives conduction and source terms, assembles the global equations, applies thermal boundary conditions, and solves temperatures before recovering gradients and heat fluxes.
