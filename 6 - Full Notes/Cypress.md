# Cypress

Cypress is the browser testing tool used in the book to automate an end-to-end React application scenario. A test visits the running application, locates interface elements, performs user actions, and asserts the resulting visible behavior.

Because the scenario crosses client, API, and data behavior, its environment and starting state must be controlled. A failure can indicate a broken workflow even when every isolated unit test still passes.
