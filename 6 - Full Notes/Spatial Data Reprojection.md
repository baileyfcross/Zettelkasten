# Spatial Data Reprojection

Spatial data reprojection transforms geometry coordinates from one [[Coordinate Reference System]] to another. It is necessary when layers use different datums or projections and must align in a [[Map Layer Overlay]]. The operation can distort distance, area, direction, or shape according to the destination projection, and rasters require resampling as well as coordinate transformation. The target system should therefore suit both the base map and the intended comparisons.
