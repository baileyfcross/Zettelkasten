# Deep Belief Network

A deep belief network stacks latent layers so that higher levels capture progressively abstract structure. It can be initialized by training restricted Boltzmann machines one layer at a time and then refined for a generative or supervised task.

Layer-wise learning historically made deep representation training more feasible. The final hidden activations can serve as derived features even when the network is later paired with a separate predictor.
