# First Isomorphism Theorem for Groups

The first isomorphism theorem states that G/ker(f) is isomorphic to the image of a group homomorphism f. If f is onto K, then K is isomorphic to that quotient.

The theorem explains exactly which source elements a homomorphism identifies.
