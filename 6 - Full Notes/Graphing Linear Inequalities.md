# Graphing Linear Inequalities

Graphing a one-variable linear inequality displays its [[Solution Set of an Inequality]] on a [[Number Line]]. Mark the boundary, use an [[Open Endpoint]] for a strict relation or a [[Closed Endpoint]] for an inclusive one, and draw a ray or segment through the values that satisfy the comparison.

For (x<-5), the graph has an open point at (-5) and extends left. For (x\geq-5), it has a closed point and extends right. A test value can confirm the selected direction before the graph is finalized.
