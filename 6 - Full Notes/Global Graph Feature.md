# Global Graph Feature

A global graph feature describes a node or network using structure beyond an immediate neighborhood. Long-range centrality, community position, and path-based measures can expose roles invisible to local counts.

Global context can improve discrimination, but calculating it may require expensive access to much of the graph. Dynamic or massive networks often need approximations.
