# Homeostasis

Homeostasis is a system's ability to maintain internal conditions within a narrow range despite changes in its environment. It is an adaptive form of dynamic balance rather than a perfectly static state.

Homeostatic [[Balancing Loop|balancing loops]] make a system resilient within limits. If disturbances exceed the system's ability to rebalance, it can become brittle and cross a point from which it cannot recover.
