# CSS Writing Modes and Direction

CSS writing modes determine whether lines progress horizontally or vertically and which direction new lines are stacked. Text orientation controls how individual glyphs are turned within a vertical line.

The `direction` and related bidirectional behavior address left-to-right and right-to-left scripts. Logical start and end values in [[CSS Text Alignment]] follow this writing direction, allowing layout choices to adapt without hard-coding a physical left or right side.
