# .NET Exception Object

A .NET exception object carries structured information about a runtime failure. Common members include `Message` for a human-readable description, `StackTrace` for the active call path, `TargetSite` for the throwing method, and `InnerException` for an underlying cause.

This structure lets a handler preserve causal context instead of reducing the failure to a generic Boolean result. `ToString()` combines the exception's type and diagnostic information for logging and investigation.
