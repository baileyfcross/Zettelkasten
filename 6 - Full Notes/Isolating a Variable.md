# Isolating a Variable

Isolating a variable rewrites an equation so the target variable appears alone on one side. The process reverses surrounding operations in an order that preserves equality.

For (3x-5=28), add five to both sides to obtain (3x=33), then divide both sides by three to obtain (x=11). Expressions may first need to be expanded, like terms combined, or denominators cleared. Isolation is an algebraic form of [[Working Backward]]: undo the operations applied to the unknown while applying each change to both sides.
