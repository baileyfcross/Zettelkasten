# Choropleth Class Count

Choropleth class count is the number of intervals used in a [[Classed Choropleth]]. More classes retain finer numeric distinctions but demand more difficult color discrimination; fewer classes are legible but may conceal spatial variation. The source recommends a modest range, commonly three to seven classes, as a compromise. The final choice depends on data distribution, palette, map size, and the distinctions the map must support.
