# Puzzle Possibility Space

A puzzle possibility space is the set of candidate solutions still compatible with what the solver knows. Solving consists of using clues, rules, and experiments to reduce that set until one valid solution remains.

An effective puzzle begins with enough alternatives to require reasoning but supplies a fair route for eliminating them. A single obvious answer is trivial, while an enormous space with no usable structure forces guessing or brute force.
