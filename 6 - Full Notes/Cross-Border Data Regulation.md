# Cross-Border Data Regulation

Cross-border data regulation governs information that is collected, stored, processed, or distributed across national and regional jurisdictions. Differences in legal definitions, rights, enforcement, and sectoral rules can make one technical operation subject to several regimes.

A distributed system must map where data and decisions travel. Locating only the user or the server is insufficient when processing and control are divided among multiple organizations and territories.
