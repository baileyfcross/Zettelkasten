# Platform Shift-Left Security

Platform shift-left security places preventive controls early in the software lifecycle instead of relying on inspection after an application reaches production. People, dependencies, source control, builds, registries, deployment definitions, and runtime configuration all become security boundaries before the final application endpoint exists.

The platform can make these controls reusable through protected branches, secret detection, dependency and artifact scanning, signed or reviewed changes, policy checks, and secure defaults. Shift-left does not mean the platform team owns every security decision; it distributes responsibilities and supplies feedback where a developer can still correct the problem cheaply.
