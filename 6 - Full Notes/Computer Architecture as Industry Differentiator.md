# Computer Architecture as Industry Differentiator

Computer architecture defines features such as instruction sets, registers, data paths, and memory behavior. Mainframe and minicomputer firms competed by offering architectures tailored to performance, cost, or application needs.

A single-chip processor threatened this advantage because semiconductor vendors could sell a standardized architecture cheaply to many system builders. Good-enough mass production often outweighed the benefits of a custom design.
