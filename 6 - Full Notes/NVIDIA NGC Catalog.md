# NVIDIA NGC Catalog

The NVIDIA NGC catalog is a repository and delivery platform for GPU-optimized containers, models, Helm charts, SDKs, and supporting resources. It supplies tested building blocks across development, training, deployment, and inference rather than functioning as a GPU compute service.

Curated assets reduce dependency assembly work but do not replace governance. Teams still need to select a version, inspect release information, test compatibility and behavior, scan artifacts, and control the identity promoted into production.
