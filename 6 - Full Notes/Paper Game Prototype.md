# Paper Game Prototype

A paper game prototype represents screens, objects, rules, and state changes with inexpensive physical materials. A facilitator can perform operations that software would eventually automate, allowing interaction ideas to be tested before code exists.

Paper is especially useful for clarifying the player's role, the information that must be visible, and how objects relate in the playspace. It is less suitable when timing, continuous motion, or sensory response is the central question.

Cards, labels, tokens, and inexpensive graphics can be revised faster when their variable data is separated from the visual template. The point of production polish is legibility for the current test, not final art that makes the team reluctant to change the design.
