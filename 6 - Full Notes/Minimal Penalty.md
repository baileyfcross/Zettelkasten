# Minimal Penalty

A minimal penalty is the threshold below which a penalized selection rule begins to choose models that are far too complex. It marks a phase change between controlling opportunistic noise fits and systematic overfitting.

For sparse model collections, the required penalty depends on how many candidate supports are searched, not only on the dimension of each support. Choosing a multiplicative constant below the theoretical threshold can make the selected model large even when the true signal is zero. A familiar low-dimensional criterion can therefore fail in a large combinatorial collection.
