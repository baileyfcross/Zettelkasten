# MCP Server Usage Telemetry

MCP server usage telemetry measures which tools are called, by whom, how long they take, what they cost, and why they fail. Logs and traces preserve arguments, policy decisions, and the surrounding agent workflow, while metrics summarize adoption, latency, error rate, and result quality.

The evidence shows whether unused tools should be removed, whether descriptions or instructions are inadequate, and whether users are missing an important capability. OpenTelemetry-based instrumentation can connect the agent, MCP invocation, model, and downstream system in one execution trace.
