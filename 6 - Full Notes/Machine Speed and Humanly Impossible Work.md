# Machine Speed and Humanly Impossible Work

The computer revolution depends heavily on the speed difference between people and electronic machines. A modern machine can perform billions or trillions of elementary steps while a person performs only a few, making computations such as real-time graphics and large simulations humanly impossible without machinery.

Speed magnifies both capability and error. A defective [[Algorithm]] can drive a safety-critical system into failure before a human can intervene, so computational speed increases the need for disciplined design and verification.
