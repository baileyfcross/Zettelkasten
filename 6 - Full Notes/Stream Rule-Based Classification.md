# Stream Rule-Based Classification

Stream rule-based classification maintains if-then conditions from incrementally updated coverage and class statistics. Rules can be added, specialized, retired, or reweighted as new labeled cases arrive.

Unlike a fixed batch rule set, the model must represent both current evidence and change over time. Local rule updates can adapt a portion of the feature space without discarding conditions that remain useful elsewhere.
