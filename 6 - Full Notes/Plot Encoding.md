# Plot Encoding

Plot encoding assigns data meaning to position, length, color, symbol, fill, or line type. Position on a common axis is generally easier to compare precisely than angle or area, while redundant encodings can make groups distinguishable in grayscale or for color-impaired readers.

An encoding should remain consistent between the main graph and its [[Plot Legend]]. Decorative variation that has no data meaning can create false groupings or distract from the comparison the figure is meant to support.
