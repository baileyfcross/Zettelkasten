# Batch Processing

Batch processing groups programs and data into queued jobs that a computer executes sequentially without direct user interaction. Operators load the input, keep the expensive machine occupied, and distribute printed results afterward.

The model is efficient for repetitive workloads such as payroll and billing. It is frustrating for program development because a small error may be discovered only after a long submit-wait-output cycle.
