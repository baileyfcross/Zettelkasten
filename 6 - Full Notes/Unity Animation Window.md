# Unity Animation Window

The Unity Animation window edits an [[Unity Animation Clip]] against time. It can add animated properties, place and move keyframes, record changes made through the Inspector, and display either a dope-sheet arrangement or editable curves.

Keyframes specify property values at selected times; interpolation determines the values between them. Record mode accelerates authoring by capturing property changes at the current playhead, but the resulting keys and curves still need review for unintended values, uneven timing, or discontinuous loops.
