# Network Agent Investigation Stop Condition

A network agent investigation stop condition ends tool use when the collected evidence is sufficient for the scoped question or when a bounded iteration, timeout, or policy limit is reached. Without an explicit stop, a confused model can repeatedly request more observations without improving the conclusion.

Stopping does not require pretending the case is solved. The agent can report confirmed facts, incomplete checks, and a recommended next step. A loop limit controls resource use, while an evidence-based condition helps the agent avoid unnecessary calls after the material device, interface, routing, and reachability facts are already known.
