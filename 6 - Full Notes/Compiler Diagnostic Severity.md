# Compiler Diagnostic Severity

Compiler diagnostic severity classifies an analyzer finding as informational, warning, or error according to how strongly it should affect development and builds. A project can elevate an important rule or suppress one that does not fit its context.

Severity is governance, not decoration. If every concern is an error, delivery can be blocked by low-risk style differences; if serious warnings are routinely ignored, the analysis no longer protects the codebase.
