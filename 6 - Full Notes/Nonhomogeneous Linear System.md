# Nonhomogeneous Linear System

A nonhomogeneous linear system has the form $Ax=b$ with a nonzero right-hand side. Unlike a [[Homogeneous Linear System]], it may be consistent or inconsistent.

When it is consistent, every solution can be viewed as one particular solution plus a solution from the associated homogeneous system $Ax=0$.
