# AWS Application Discovery Service

AWS Application Discovery Service gathers information about on-premises servers, utilization, and communication patterns to support migration planning. Dependency evidence helps teams group related components into migration waves instead of moving a server in isolation and discovering an unseen connection during cutover. Its output can be viewed through [[AWS Migration Hub]], where discovery data becomes part of a coordinated portfolio view.
