# Psychological Acceptability in Security

Psychological acceptability requires security controls to fit human use well enough that the secure action is at least as convenient as the insecure alternative. Confusing or burdensome protection encourages bypasses and errors.

Security is therefore an interaction-design property as well as a technical mechanism. Clear feedback, understandable permissions, and recoverable workflows help users maintain protection in practice.
