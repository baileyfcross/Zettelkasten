# Subprogram Call and Return

A call instruction transfers control to reusable code while saving enough information to resume the caller afterward. A return restores that saved continuation, allowing one subprogram to be invoked from many places.

Hardware support for call and return made functions, procedures, and libraries efficient building blocks. It enabled programs to be organized around reusable operations instead of repeated instruction sequences.
