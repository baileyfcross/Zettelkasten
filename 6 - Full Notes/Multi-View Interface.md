# Multi-View Interface

A multi-view interface presents related views of one augmented world through different displays, viewpoints, or levels of detail. Each view can emphasize information suited to a user, device, location, or task while referring to shared underlying objects.

The physical environment provides a common frame that helps relate the views. Designers must preserve consistency and awareness so actions in one view can be understood from the others.
