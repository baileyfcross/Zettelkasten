# Game Choice Anatomy

A game choice can be examined as five linked parts: the context before the decision, the communication of available options, the mechanism used to select one, the consequences and future choices that follow, and the feedback that reveals what happened.

A failure in any part can make an otherwise sound decision feel arbitrary. Hidden context creates a [[Blind Game Decision]], unclear option presentation prevents informed comparison, awkward input obstructs commitment, indistinguishable consequences reduce meaning, and weak feedback prevents the player from learning for the next choice.
