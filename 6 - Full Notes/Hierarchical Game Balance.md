# Hierarchical Game Balance

Hierarchical game balance orders tunable features from globally important constraints to local details. When two features conflict, the lower-ranked one changes; local objects should conform to the broader design rather than forcing repeated changes to a player character, camera, platform constraint, or other system-wide foundation.

The hierarchy makes priorities and conflict resolution explicit while limiting the radius of rework. It can begin as a coarse list and gain detail as the project develops. The team should discuss and share it early, because its value comes from a common understanding of which assumptions are stable and which elements must adapt.
