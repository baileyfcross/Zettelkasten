# Framework-Dependent Executable

A framework-dependent executable is a platform-specific launcher produced for an application that still depends on a compatible shared .NET runtime on the target. It can be started directly rather than through the generic `dotnet` command.

It combines executable-style startup with the smaller runtime footprint of [[Framework-Dependent Deployment]], but separate launchers are produced for selected target platforms.
