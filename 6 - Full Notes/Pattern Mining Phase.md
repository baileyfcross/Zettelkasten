# Pattern Mining Phase

The pattern mining phase searches the pattern space for candidates satisfying constraints such as minimum support or class contrast. It produces the raw vocabulary from which pattern features may be constructed.

Mining is distinct from choosing the final model inputs. A frequent candidate can be redundant or nonpredictive, so later selection or in-process pruning remains necessary.
