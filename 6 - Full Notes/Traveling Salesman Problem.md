# Traveling Salesman Problem

The traveling salesman problem asks for the shortest tour that visits every city in a given collection once and returns to the starting city, using known distances between each pair.

Enumerating every ordering of $n$ cities produces [[Factorial Time Complexity]], so brute force becomes unusable quickly. The problem is a standard example of an [[Intractable Problem]] for which practical work often relies on an [[Approximation Algorithm]] that finds a good route without guaranteeing the absolute shortest one.
