# Function Sweep in COMSOL

A function sweep compares alternative functional definitions used by a model, such as several time profiles, interpolation tables, or analytic property relations. It changes the relationship itself rather than only a scalar parameter within one relationship.

Each candidate function must share compatible arguments and units so that the study comparison remains meaningful. This approach is useful for testing uncertain [[COMSOL Analytic and Interpolation Functions|input curves]] or operating schedules while preserving the rest of the thermal model.
