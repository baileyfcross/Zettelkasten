# Legislative Network

A legislative network represents lawmakers as nodes and a defensible political relationship as an edge. Possible relationships include co-sponsorship, voting similarity, caucus membership, communication, or shared committee work.

The selected edge is a proxy whose institutional validity must be examined. Roll-call, media, and membership ties can be distorted by gatekeeping, selection, or unequal data access, so the network must match the research question.
