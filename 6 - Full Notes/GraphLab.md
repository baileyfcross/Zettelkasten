# GraphLab

GraphLab is a graph-parallel framework that lets update functions read and modify a vertex and a defined surrounding scope. Consistency models control which overlapping updates may run concurrently.

Its asynchronous execution can converge faster than strict global supersteps for some machine-learning algorithms, while scheduling and consistency become more complex.
