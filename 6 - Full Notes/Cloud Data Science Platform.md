# Cloud Data Science Platform

A cloud data science platform supplies remotely accessible computation, storage, and analytic software. It can place a consistent environment near shared data and reduce the need to configure every analyst's machine independently.

Remote access does not remove governance or reproducibility requirements; data access, versions, and execution environments still need to be recorded.
