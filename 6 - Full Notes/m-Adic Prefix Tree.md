# m-Adic Prefix Tree

An m-adic prefix tree branches according to successive digits in base m. In a decimal tree, the first digit chooses one of ten root bins, the second digit divides each bin again, and deeper levels represent finer precision.

Each record can be placed by reading its code from left to right. The resulting hierarchy is simultaneously a set of nested cluster bins and an index for matching or retrieval. It need not be a prime-base p-adic number system; the book uses m-adic to include practical nonprime bases such as decimal.
