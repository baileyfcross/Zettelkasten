# Merge Operation

A merge operation combines two already sorted sequences into one sorted sequence. It compares the first remaining item of each sequence, appends the smaller one to the result, and advances within that sequence.

When one input is exhausted, the remaining items of the other can be appended directly. This linear operation is the combining stage of [[Merge Sort]] and is what turns separately solved subproblems into a complete ordered result.
