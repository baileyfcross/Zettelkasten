# Excel RANK Function

An Excel rank function returns a value's position relative to a numeric reference set. The order argument determines whether the largest value receives rank one or the smallest does. Ranking preserves the original table order while adding a comparative position to each record.

Tied values receive the same rank, which creates gaps in subsequent positions under the standard ranking behavior described in the book. The comparison range should usually be absolute before the formula is filled, while the value being ranked remains relative. Rank shows ordering but not the size of the difference between neighboring records.
