# Blender UV Project Modifier

The UV Project modifier derives UV placement by projecting from one or more objects. It gives a texture a controlled viewpoint and can use several projectors for coverage from multiple directions.

Because the projection remains a modifier, its source objects and settings can be changed without manually rebuilding the UV layout. The result can participate in the same texture workflow as coordinates produced by unwrapping.
