# Java Markdown Documentation Comment

A Java Markdown documentation comment begins each line with three slashes and lets Javadoc render Markdown rather than HTML-oriented comment markup. Backticks mark code, bracket syntax creates links, and ordinary Markdown supplies emphasis, lists, tables, and fenced code blocks.

Javadoc-specific block tags such as parameter and return documentation remain available. The form makes source comments more readable before rendering while preserving the generated API-documentation workflow described by [[Javadoc Documentation Generation]].
