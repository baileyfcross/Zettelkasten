# Mother Cloud

A mother cloud is a composite cloud that contains several reusable [[Cloud Cell]]s. A web-service mother cloud, for example, can contain cells for web serving, business logic, databases, storage, messaging, and a firewall.

An optional controller cell can orchestrate the other cells. The concept makes the overall service a higher-level unit while leaving each component responsible for a focused capability.
