# Kubernetes

Kubernetes is a container orchestrator that maintains and changes a declared set of container workloads. It creates instances, replaces failed ones, rolls out updated images, and routes work so the running system moves toward its desired configuration.

The book uses Kubernetes to operate replicated sales-order workers. Its value comes from orchestration rather than from changing the worker's business logic; the service must already be designed so multiple instances can safely share queued work.
