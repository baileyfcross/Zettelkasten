# Responsive Image Candidate Selection

The browser converts candidate descriptors, the `sizes` slot estimate, device density, and its own conditions into a resource choice. It may consider cache state or network policy and can change its selection when relevant conditions change.

Responsive markup therefore offers a set and the information needed to rank it; it does not command a permanent exact file. Developers should verify outcomes through the selected URL rather than assuming the nominal density always wins. See [[currentSrc Selected Image URL]].
