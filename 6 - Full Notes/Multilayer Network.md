# Multilayer Network

A multilayer network represents a connected system with several network layers and relationships within or across them. Nodes may appear in one or more layers, and interlayer edges preserve dependencies that a collection of isolated graphs would omit.

Different constraints produce multiplex, interdependent, interconnected, temporal, and other network types. The representation matters because aggregation can change paths, centrality, diffusion, and failure behavior.
