# Long-Format Space-Time Data

Long-format space-time data store one measurement per row together with its location identifier, time, and variable value. This form is convenient for recording station observations but may need reshaping before constructing a [[Point Space-Time Grid]]. The source casts long station data into a space-wide time series, vectorizes it in the required ordering, and then builds an [[STFDF Object]].
