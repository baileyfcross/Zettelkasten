# R Code Layout

R code layout uses indentation, braces, spaces, and line breaks to reveal program structure. Limiting line length encourages readable expressions and diffs, while consistent braces make control flow visible.

Layout should support comprehension and review without forcing dense code into arbitrary one-line forms.
