# Missing Term in a Difference Table

A missing tabulated value can be treated as an unknown and placed in the appropriate [[Difference Table]]. If the data are assumed to come from a polynomial of known degree, the next higher differences must vanish or the target-order differences must remain constant.

That condition produces an equation for the unknown entry. The result depends on the polynomial assumption, so a value recovered this way is an interpolation estimate rather than independently observed data.
