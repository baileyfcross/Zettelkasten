# Accommodation

Accommodation is the change in the shape of the eye's lens used to focus an image. Muscular feedback from this adjustment provides a [[Depth Cue]] about the distance of the focused object.

For a distant object, the muscles relax and the lens becomes more spherical. For a near object, the muscles pull on and flatten the lens. Many stereoscopic displays place all light on one fixed screen depth while using binocular images to suggest other depths. This can make accommodation disagree with [[Vergence]], reducing visual comfort.
