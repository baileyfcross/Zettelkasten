# Time-to-Event Variable

A time-to-event variable measures elapsed time from a defined origin to an event or the end of observation. For participants with the event, it records the event time; for censored participants, it records their last known event-free time.

The origin, units, and maximum study window must be consistent across records. If event timing is missing for most event-positive participants, exclusions can create severe [[Survival Data Selection Bias]].
