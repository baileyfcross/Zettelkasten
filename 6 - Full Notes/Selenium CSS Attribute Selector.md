# Selenium CSS Attribute Selector

A Selenium CSS attribute selector locates elements by the presence or value of an HTML attribute. It can require an exact value or match a value that contains, begins with, or ends with a substring.

Attribute selectors are useful for stable custom data attributes and for controls distinguished by `type`, `href`, or `src`. Partial matches trade precision for flexibility and should be constrained with a tag or relationship when several elements could match.
