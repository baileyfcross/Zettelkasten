# Game Interface Prototype

A game interface prototype explores how players issue commands and receive information or feedback. It may test screen layout, navigation, controller mapping, gesture, physical input, or the transition between interface states.

Its fidelity should match the uncertainty. Clickable wireframes can answer flow questions, while timing and embodied control may require a working input device and a responsive scene.
