# Twitter Profile Classification

Twitter profile classification assigns categories to accounts using their profile, content, behavior, and network features. The target may describe role, interest, organization type, or another user-level property.

Aggregating many posts can stabilize an account representation, but topics and behavior change over time. Labels and observation windows should match the period for which the classification is intended.
