# Angular Material Table

An Angular Material table renders structured rows and columns from a component-provided data source. Column definitions connect named fields to headers and cells, while paginator and sort modules add controls around the displayed data.

For large datasets, the table should display the page returned by [[Server-Side Paging]] instead of binding every database row. A loading state can hide or replace the table while the request is unresolved.
