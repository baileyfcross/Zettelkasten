# Recursive Function

A recursive function invokes itself with a smaller or deeper version of the problem until a stopping condition returns a value. A countdown decrements its argument on each call, while a nested-object lookup consumes one path segment before recurring into the selected child object.

Recursion makes the continuation rule and base case explicit, but it consumes call-stack capacity unless the runtime or implementation removes that pressure. Asynchronous recursion can schedule the next call later, as when a delayed countdown invokes itself from a timer callback.
