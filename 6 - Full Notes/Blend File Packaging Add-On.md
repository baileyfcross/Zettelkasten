# Blend File Packaging Add-On

The Blend File Utils add-on could package a saved `.blend` project and its dependencies into a ZIP archive for transfer. Packaging reduces the chance that an external texture or other file is omitted when the project moves to another computer.

The workflow depends on saving the scene and separately saving any edited images before creating the archive. Packaging captures referenced files; it cannot preserve image changes that still exist only as unsaved editor state.
