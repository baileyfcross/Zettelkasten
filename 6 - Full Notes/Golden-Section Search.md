# Golden-Section Search

Golden-section search locates a one-dimensional optimum of a unimodal function without derivatives. It maintains a bracketing interval and places interior test points so one previous evaluation can be reused after each reduction.

The constant proportions steadily shrink the interval containing the optimum. The method trades the rapid local convergence of derivative methods for predictable derivative-free progress.
