# Push Notification Service

A push notification service accepts a message from an application backend and routes it through the notification system of each target platform. It gives the backend a way to alert a mobile application without maintaining a continuously active application process on the device.

Platform notification services impose different payload and addressing rules. A broker such as Azure Notification Hubs can provide one server-side interface while templates or platform payloads preserve the target-specific delivery requirements.
