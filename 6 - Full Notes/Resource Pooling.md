# Resource Pooling

Resource pooling combines computing, storage, or networking capacity so that it can be assigned among consumers according to demand. Pooling raises utilization because idle capacity from one workload can serve another rather than remaining tied to one dedicated machine.

Virtualized resources are well suited to a pool because software can create, move, and release instances automatically. When several consumers share the resulting service, the pool also supports [[Multi-Tenancy]] and [[Rapid Elasticity]].
