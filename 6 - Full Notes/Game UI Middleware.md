# Game UI Middleware

Game UI middleware supplies an external authoring and runtime system for building interface layouts, animation, and behavior. Artists and content creators can iterate in a visual tool while programmers integrate the runtime with the engine and expose game data.

The arrangement reduces low-level layout work and can accelerate revision. It also introduces licensing, integration, performance, and scripting boundaries that the engine must manage explicitly.
