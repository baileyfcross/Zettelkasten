# JavaScript Array Reduce

`Array.reduce` transforms an array into one accumulated result by passing the previous result and the next item to a callback. An explicit initial value establishes the accumulator's starting type and value.

The result can be a number, string, object, array, or even a function. The source uses reduce to find a maximum, build an object keyed by identifiers, remove duplicate values, and implement [[Function Composition|function composition]], showing that reduction is a general folding operation rather than only numeric addition.
