# Universal Turing Machine

A universal Turing machine interprets an encoded [[Turing Machine]] together with its input and simulates that machine one step at a time. It records the simulated state, tape contents, and head position as data on its own tape.

Universal simulation shows that one fixed machine can perform any computation expressible by a machine description. It also makes self-reference possible, which is central to the proof of the [[Halting Problem]].
