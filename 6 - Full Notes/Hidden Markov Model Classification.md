# Hidden Markov Model Classification

Hidden Markov model classification represents a sequence through unobserved states that evolve with a Markov transition structure and emit the observed symbols or measurements. A class can be associated with a separate model or incorporated into the state structure.

Prediction compares the sequence likelihood under competing class models. Dynamic programming makes inference feasible by reusing partial calculations rather than enumerating every possible hidden-state path.
