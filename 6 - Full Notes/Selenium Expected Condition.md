# Selenium Expected Condition

A Selenium expected condition is a predicate used by an explicit wait to describe the state required before a test continues. Conditions can require an element to be present, visible, clickable, selected, or absent; text, attributes, counts, titles, URLs, alerts, and frames can also be checked.

The distinction between presence and visibility is important: an element can exist in the DOM without being displayed or interactable. The condition should match the next intended operation rather than merely prove that some node exists.
