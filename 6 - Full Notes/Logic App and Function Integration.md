# Logic App and Function Integration

Logic App and Function integration combines visible managed workflow steps with custom code. The workflow selects a deployed function as an action, formats its input as JSON, and consumes its returned value in later control flow.

This relationship preserves the strengths of both layers: connectors and the designer coordinate services, while a focused function implements logic that is awkward in the graphical system. The request and response shape become the contract between them.
