# Expressive Game System

An expressive game system communicates ideas through rules and the experiences those rules produce. Its message is carried not only by text or imagery, but by what players can do, what resists them, and what consequences follow.

Because players participate in producing the experience, the system can express relationships and feelings that are difficult to state directly. [[Story as System]] is one use of this broader expressive capacity.
