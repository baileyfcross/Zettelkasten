# CSS Attribute Values

The CSS `attr()` expression retrieves an attribute value from the element being styled. The source shows its dependable use with [[CSS Generated Content]], where an ID or another attribute can be inserted before or after the element's content.

The source also describes typed use of `attr()` in other properties as theoretical and unsupported by tested browsers in late 2016. That historical limitation matters when interpreting examples from this edition.
