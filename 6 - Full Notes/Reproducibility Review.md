# Reproducibility Review

A reproducibility review executes the submitted code on the supplied data to determine whether it regenerates the publication's claimed results. It goes beyond checking that files exist and tests whether the computational materials are usable together.

The review can support graded evidence: publication alone, publication with code, publication with code and data, and publication with executable code and data. It is not a complete scientific replication or proof of correctness. Instead, it verifies the recoverability promised by an [[Executable Research Publication]] and can reveal missing instructions, incompatible software, or incomplete archives before publication.
