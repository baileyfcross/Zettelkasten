# CSS Structural Pseudo-Classes

Structural pseudo-classes match elements through their position or relationships in the document tree. They include root, empty, first- or last-child, only-child, and indexed patterns such as `:nth-child()` and `:nth-of-type()`.

Indexed expressions can represent single positions or repeating sequences. These selectors make structure available to CSS without adding classes solely to identify alternating, leading, trailing, or otherwise patterned elements.
