# Ordinal Feature

An ordinal feature takes values from a set with a meaningful order but without guaranteed numerical spacing. Educational degrees can be ordered from bachelor to master to doctorate, yet the gaps between those levels are not measurable as equal quantities.

Algorithms may exploit the ranking while avoiding arithmetic interpretations that the scale does not support. Treating an ordinal variable as either unordered categories or fully quantitative values discards or invents structure.
