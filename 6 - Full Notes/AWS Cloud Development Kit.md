# AWS Cloud Development Kit

The AWS Cloud Development Kit defines cloud infrastructure in general-purpose programming languages and synthesizes the result into [[AWS CloudFormation Stack|AWS CloudFormation]] templates. This allows familiar abstractions, functions, tests, and package reuse while retaining CloudFormation's declarative deployment engine. CDK does not turn infrastructure into an ordinary application program; synthesized templates, deployment permissions, state transitions, and resource replacement behavior still require infrastructure review.
