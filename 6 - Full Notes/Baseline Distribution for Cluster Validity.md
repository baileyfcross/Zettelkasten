# Baseline Distribution for Cluster Validity

A baseline distribution for cluster validity describes the index values expected when data are generated under a specified null or random model. It provides a reference for judging whether an observed clustering score is unusually strong.

When an analytic distribution is unavailable, repeated Monte Carlo trials can generate the baseline. Its meaning is conditional on the simulation assumptions and clustering method.
