# Feature Board

A feature board visualizes the state of complete features across the disciplines working on them. Rows distinguish features that are active or waiting, columns show the kind of work underway, and priority remains visible as cards move toward done.

Unlike a task-centered board, it exposes whether code, art, animation, design, or testing is stalling playable value. It encourages swarming, limits parallel features, and creates time for integrated tuning before a Sprint ends.
