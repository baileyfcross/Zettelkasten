# Average Neighborhood Margin Maximization

Average neighborhood margin maximization learns a projection that enlarges the average difference between distances to nearby different-class cases and nearby same-class cases. It targets local class separation rather than only global scatter.

The neighborhood definition determines which pairs contribute to the margin. Kernel variants can replace the linear projection when useful separation requires a nonlinear feature space.
