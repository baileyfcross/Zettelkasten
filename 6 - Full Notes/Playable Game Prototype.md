# Playable Game Prototype

A playable game prototype is an early functional artifact that lets a person perform the game's main actions. It can omit final goals, content, visuals, and sound when those elements are not necessary to test the core interaction.

Its roughness is deliberate. The prototype asks whether the basic activity produces useful feedback and possibilities before the team invests in making that activity look complete.
