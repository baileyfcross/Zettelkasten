# React Context

React context passes a value through a component subtree without forwarding it through every intermediate component's props. A provider establishes the value, and descendants beneath that provider can consume it.

Context is useful for closely related shared concerns such as form values and handlers or authentication state. It does not make all state global; provider placement defines the boundary of access.
