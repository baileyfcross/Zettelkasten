# Joint Feature Selection and Extraction

Joint feature selection and extraction first restricts a representation to a small set of original variables and then combines those variables into a smaller set of derived coordinates within one objective. Selection preserves interpretability and removes irrelevant inputs; extraction can concentrate the remaining signal into more discriminative directions.

Row-sparse multivariate regression provides this bridge. Nonzero coefficient rows identify selected features, while the coefficient columns define extracted directions that approximate a target class, similarity, or principal-component representation.
