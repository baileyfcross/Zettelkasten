# AWS Shield

AWS Shield provides managed protection against distributed denial-of-service attacks. Standard protection is automatically available for AWS customers, while Shield Advanced adds expanded detection, response support, visibility, and cost-protection features for designated resources.

Shield focuses on availability threats created by malicious traffic volume and patterns. It complements [[AWS Web Application Firewall]], resilient scaling, Route 53, and CloudFront; none of these removes the need to plan capacity, dependencies, and incident response for the complete workload.
