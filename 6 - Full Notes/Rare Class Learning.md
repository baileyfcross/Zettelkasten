# Rare Class Learning

Rare class learning develops a classifier when one important class has far fewer labeled examples than the others. Standard error minimization can favor the majority because misclassifying all rare cases contributes little to overall accuracy.

Costs, weights, resampling, ensembles, one-class models, and specialized evaluation measures redirect attention toward minority detection. The correct choice depends on whether the rare class is known, partially labeled, or genuinely novel.
