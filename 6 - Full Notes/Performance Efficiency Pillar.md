# Performance Efficiency Pillar

The performance efficiency pillar uses computing resources effectively as demand and technology change. It encourages selecting suitable resource types, using managed or serverless services where appropriate, monitoring performance, and experimenting with new approaches.

Efficiency is relative to workload requirements rather than maximum raw speed. Architecture should match storage, compute, database, and network choices to access patterns and then use measurements to revise those choices as scale or constraints evolve.
