# Krull Intersection Theorem

For an ideal I in a Noetherian ring and a finitely generated module M, the intersection of all IⁿM is annihilated by an element 1−a with a ∈ I. If I lies in the [[Jacobson Radical]], this intersection is zero.

The theorem shows that repeated multiplication by a sufficiently small ideal eventually separates every nonzero module element. Its proof uses the [[Artin-Rees Lemma]].
