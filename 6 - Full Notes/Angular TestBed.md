# Angular TestBed

Angular TestBed configures a testing module for components and services. It declares the units under test, supplies imported capabilities and providers, compiles components, and creates fixtures.

TestBed can replace a production [[Angular Service]] with a [[Test Double]]. The test then accesses the component and rendered template through the created [[Test Fixture]].
