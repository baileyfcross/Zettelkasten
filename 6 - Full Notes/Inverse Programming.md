# Inverse Programming

Inverse programming composes a model by using the result of one probabilistic question as a factor within another description. It lets an inference developed for one direction or subsystem become reusable knowledge in a larger model.

The called program remains a probabilistic relation rather than a deterministic return value. When the outer inference evaluates that factor, it may trigger the inner question for the conditioning values currently under consideration.
