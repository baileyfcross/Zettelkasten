# Blender Multi-Monitor Areas

Blender areas can be duplicated into separate operating-system windows and placed on different monitors. The detached window remains part of the same Blender session, so it can dedicate a large display to an editor such as the 3D View while another monitor holds properties, animation, or reference views.

This arrangement expands visible workspace without creating another project instance. Closing the detached window removes that view, not the underlying scene data shared by the editors.
