# Kotlin Class and Object

A Kotlin class defines a type's properties and functions, while an object is a concrete instance of that definition. Each instance can hold its own property values and use the behavior declared by the class.

Construction connects the general definition to initialized state. The resulting object exposes only the members allowed by its visibility and type, letting a class combine data and operations behind a coherent boundary rather than leaving related values and functions unstructured.
