# Spring AI Multimodal Prompt

A Spring AI multimodal prompt combines text with supported media, such as an image, in one model request. The source demonstrates using this representation when visual information must be interpreted together with an instruction rather than processed as a detached file.

The application must provide a supported media type and format, control payload size, and select a model that accepts the modality. Uploaded media should receive the same authorization, retention, and content-safety treatment as textual prompts.
