# Set Heading Point and Diversion Pattern

A set heading point is the identifiable location where an aircraft begins the calculated course toward its destination. During a diversion, a short racetrack pattern around that point can buy time to measure the new bearing, review landmarks, establish altitude, and organize the cockpit. Timing begins as the aircraft crosses the point on the selected heading.
