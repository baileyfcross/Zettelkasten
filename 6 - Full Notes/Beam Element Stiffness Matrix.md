# Beam Element Stiffness Matrix

A beam element stiffness matrix relates two endpoint deflections and two endpoint slopes to corresponding shear forces and bending moments. Its coefficients scale with flexural rigidity and powers of element length.

The symmetric matrix is assembled using the global order of displacement and rotation degrees of freedom. Shorter elements increase the stiffness coefficients and allow finer representation of the deflected shape.
