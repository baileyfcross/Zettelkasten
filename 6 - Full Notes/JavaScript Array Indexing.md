# JavaScript Array Indexing

A JavaScript array is a specialized object intended to hold values at zero-based numeric positions. Its `length` property tracks the indexed collection, and each position can contain a value of any type.

Although arrays can technically receive arbitrary named properties because they are objects, doing so obscures their intended representation. Arrays are the natural structure for numerically ordered values, while ordinary objects are the natural structure for values addressed by descriptive names.
