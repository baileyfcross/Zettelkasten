# Git Pull

`git pull` obtains updates from a remote and integrates them into the current local branch according to the configured strategy. It combines the retrieval step of [[Git Fetch]] with a merge or rebase operation.

Because it can change the checked-out branch, pull is not merely a status check. Inspecting local changes and understanding the chosen integration policy helps avoid an unexpected merge or conflict.
