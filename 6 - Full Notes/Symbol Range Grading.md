# Symbol Range Grading

Symbol range grading selects a finite sequence of symbol sizes intended to be visually distinguishable across a [[Graduated Symbol Map]]. The data range is first divided into classes, then each class receives a representative size. Too many grades make neighboring symbols hard to tell apart, while too few conceal variation. Size selection must also account for map density so large symbols do not cover nearby locations.
