# Multiplication Property of Equality

The multiplication property of equality states that multiplying equal quantities by the same number preserves equality. If (a=b), then

$$ac=bc.$$

Division by the same nonzero number is the inverse use of this property. The nonzero restriction is essential when reversing the transformation, because multiplication by zero collapses every value to the same equation. The property isolates coefficients, clears denominators, and creates [[Equivalent Equations]] during solving.
