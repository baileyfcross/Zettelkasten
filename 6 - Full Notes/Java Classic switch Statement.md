# Java Classic switch Statement

The classic Java `switch` statement compares a selector with case labels and begins executing at the matching label. Without a `break`, execution falls through into following cases, which can intentionally share behavior but can also create accidental paths.

A `default` label handles selectors not matched by another case. Strings and enum constants can be selectors in addition to supported primitive forms. The colon-and-break form controls statements; [[Java switch Expression]] provides arrow labels and a resulting value when the decision is naturally an expression.
