# Assistant Personality

Assistant personality is the consistent set of linguistic and behavioral choices through which a system presents a social character. Vocabulary, tone, timing, humor, voice, and response style all contribute.

Consistency helps users predict the interaction, but personality should support the assistant's role rather than conceal its limitations. A [[Social Virtual Assistant]] must avoid implying human understanding or feelings it does not have.
