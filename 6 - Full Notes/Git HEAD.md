# Git HEAD

Git `HEAD` identifies the currently checked-out branch or, in a detached state, a specific commit. It tells Git which history position the working tree represents and where a new commit will normally attach.

When a branch is checked out and a commit is created, that branch reference advances and `HEAD` continues to point through it. Commands that switch commits therefore change both the visible files and the context for later history operations.
