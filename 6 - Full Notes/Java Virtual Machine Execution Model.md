# Java Virtual Machine Execution Model

The Java Virtual Machine is an abstract execution machine that loads Java class files and runs their bytecode above a host operating system. Starting a Java application launches a JVM process, which supplies runtime services such as class loading, managed memory, threads, diagnostics, and [[Garbage Collection]].

The JVM is distinct from the Java language and from any single vendor distribution. HotSpot is a common implementation, while other vendors provide compatible virtual machines; the program relies on the JVM contract while the implementation adapts execution to the local platform.
