# Consumer IoT Device Discovery

Consumer IoT device discovery is the process by which an app or platform finds a nearby device, establishes a network or Bluetooth relationship, and associates it with a user's environment. Once discovered, the device can receive settings, expose controls, and sometimes learn about other installed products.

Discovery hides network details that once required manual configuration and is a major reason connected products can behave as plug-and-play systems. Its simplicity also carries responsibility: the setup flow must authenticate the intended device, create a secure connection, make permissions understandable, and avoid silently enrolling the device into a wider data ecosystem than the user expects.
