# CSS Property Inheritance

Inheritance allows the value of certain CSS properties to pass from an element to its descendants when they do not receive a directly cascaded value. Text-related properties commonly inherit, while box properties such as margins and borders generally do not.

An inherited value has no selector specificity of its own; any directly matched declaration wins over it. CSS-wide keywords can explicitly request inheritance or restore another initial behavior where a property permits them.
