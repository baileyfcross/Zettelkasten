# DPU Telemetry

DPU telemetry observes network traffic, storage behavior, application usage, and infrastructure data-plane activity close to the interfaces that carry it. A programmable DPU can export this evidence while continuing to offload selected movement, transformation, or security functions.

These signals complement host metrics and DCGM GPU telemetry. Correlating all three views distinguishes a device-compute problem from congestion, policy enforcement, remote I/O, or tenant traffic behavior around the node.
