# Kotlin Lambda Expression

A Kotlin lambda is an unnamed function value written inside braces. Its parameters appear before `->`, and the final expression in its body supplies the result when the function type expects one.

Lambdas can be stored, passed to higher-order functions, and invoked later. When the last parameter of a call is a function, Kotlin can place the lambda outside the parentheses, a convention that supports readable collection pipelines and internal domain-specific languages.
