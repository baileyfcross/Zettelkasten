# Django REST Framework Serializer

A Django REST Framework serializer converts model instances or other complex values into renderable data and validates incoming data before constructing or updating application objects. Declared fields control representation, types, requirements, and writable input.

The book demonstrates both direct serializers and model serializers, including nested relationships. Serialization and deserialization are two directions of the boundary, so output exposure rules and input validation should be deliberate rather than inferred from every model field.
