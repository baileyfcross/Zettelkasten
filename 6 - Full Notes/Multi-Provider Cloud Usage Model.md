# Multi-Provider Cloud Usage Model

A multi-provider cloud usage model lets an organization obtain services from several providers while a central IT function retains brokerage and oversight. A service that no longer meets a need can be supplemented or replaced by another provider.

The flexibility creates an integration obligation. The central function must connect providers to one another and to business units while reconciling their contracts, identities, data, service levels, and reports.
