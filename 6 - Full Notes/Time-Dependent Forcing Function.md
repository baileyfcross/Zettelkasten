# Time-Dependent Forcing Function

A time-dependent forcing function specifies how an applied structural load changes with time. It drives a transient response whose displacement history depends on load shape, duration, stiffness, mass, damping, and boundary conditions.

Finite element software samples or integrates the forcing history over analysis time steps. The step interval must be small enough to represent abrupt changes and the structural frequencies of interest.
