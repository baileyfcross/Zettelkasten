# Attribute-Weighted Nearest Neighbor

Attribute-weighted nearest neighbor assigns different importance to feature dimensions when computing proximity. Features with greater discriminatory value contribute more strongly to the distance between a test case and stored observations.

Weights may be learned globally or adapted near the test instance. This changes nearest-neighbor classification into a form of metric learning and can suppress noisy dimensions that would otherwise dominate solely because of their scale or number.
