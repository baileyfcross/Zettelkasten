# Intent Schema

An intent schema defines the actions and argument structures an assistant supports within a domain. It specifies allowable intents, the entities or slots associated with them, and sometimes their constraints.

The schema supplies the target vocabulary for [[Intent Classification]] and [[Named Entity Recognition]]. A narrow [[Assistant Skill]] can use a detailed schema that would be difficult to maintain across every possible domain.
