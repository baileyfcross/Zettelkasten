# Kubernetes Metrics Pipeline

A Kubernetes metrics pipeline collects measurements from cluster components, nodes, containers, and applications and stores them as time series. Labels attach workload and infrastructure identity so a query can aggregate by cluster, namespace, pod, service, or another operational dimension.

Resource metrics used for commands or autoscaling are only one part of observability. A production pipeline also needs durable historical storage, service-level measurements, controlled label cardinality, protected endpoints, dashboards, and alert routing.
