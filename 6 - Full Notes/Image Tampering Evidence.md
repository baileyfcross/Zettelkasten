# Image Tampering Evidence

Image tampering evidence is an observable inconsistency that an expected capture or encoding process does not explain. Examples include incompatible shadows, a locally missing sensor pattern, a second compression history, duplicated image structure, or metadata that conflicts with the visible scene.

Some findings directly localize an edit, while others show only that a file was resaved or passed through unexpected software. The conclusion should preserve that distinction: evidence of post-processing is not automatically evidence that the depicted event was fabricated.
