# Kotlin Function Declaration

A Kotlin function begins with `fun`, followed by its name, typed parameter list, optional return type, and body. A function that produces no meaningful value uses `Unit`, which can usually be omitted from the declaration.

Naming an operation creates a reusable boundary around its inputs, behavior, and result. Kotlin supplies standard-library functions, while user-defined functions capture application-specific operations and can be called wherever their visibility and parameter contract permit.
