# Self-Organizing Map

A self-organizing map is a competitive neural network whose output units occupy an ordered grid. The winning unit and nearby units update together, so neighboring map locations come to represent neighboring regions of the input space.

The topology-preserving organization provides a low-dimensional view of multidimensional patterns and can support exploratory clustering.
