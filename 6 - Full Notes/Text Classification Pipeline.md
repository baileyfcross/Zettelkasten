# Text Classification Pipeline

A text classification pipeline converts documents into features, selects discriminative terms, fits a supervised model from labeled documents, and predicts one or more categories for new text. The representation used during prediction must match the representation learned during training.

Text requires special attention because vocabulary features are sparse, high-dimensional, and unevenly distributed. Stop-word removal, stemming, weighting, and dimensionality reduction shape the evidence available to the classifier.
