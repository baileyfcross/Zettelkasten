# Fuzzing

Fuzzing is a testing technique that supplies an application with inputs outside its expected specification to expose crashes, unsafe behavior, or security vulnerabilities. It explores cases that ordinary examples or valid-input tests may never exercise.

The technique is most useful when failures are recorded reproducibly and converted into regression tests after repair. In a cloud service, the test environment should be isolated so malformed traffic does not disrupt production consumers.
