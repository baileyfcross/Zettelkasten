# Equivalent Nodal Load

An equivalent nodal load replaces a distributed or thermal element action with nodal forces that produce the same finite element work. The conversion uses the interpolation model and element geometry.

For a uniformly distributed axial load on a two-node bar, the total is divided consistently between the end nodes. A temperature change produces signed nodal forces governed by modulus, area, and thermal expansion when expansion is constrained.
