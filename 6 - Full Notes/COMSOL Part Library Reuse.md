# COMSOL Part Library Reuse

The COMSOL part library supplies parameterized reusable geometry such as rings or heat sinks. Instantiating a part creates a controlled set of dimensions and features without reconstructing the shape from elementary entities for every model.

Library reuse accelerates model setup and standardizes common components, but its parameters and resulting domains still require review. A convenient template does not guarantee that the geometry, detail level, or [[Thermal Mesh Refinement|mesh requirements]] match the present thermal question.
