# Derivative Function

The derivative function assigns to each differentiable input $x$ the limit

$$f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}.$$

It records the original function's instantaneous rate of change across its domain. Its sign describes local increase or decrease, and differentiating it again produces higher-order change.
