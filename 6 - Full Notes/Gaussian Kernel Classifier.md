# Gaussian Kernel Classifier

A Gaussian kernel classifier assigns high similarity to observations separated by a small squared Euclidean distance and lets similarity decay exponentially with distance. The corresponding implicit feature space supports flexible nonlinear boundaries.

Kernel width determines locality: a narrow kernel can form intricate regions around examples, while a broad kernel behaves more smoothly. Feature scaling is essential because the kernel converts raw distances directly into influence.
