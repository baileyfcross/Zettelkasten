# CSS Media Types

A CSS media type identifies a broad output category. The source focuses on `screen`, `print`, `speech`, and `all`, while noting that many earlier specialized media types had been deprecated.

A media type can stand alone or form the first part of a [[CSS Complex Media Queries|complex query]]. It provides a coarse distinction, while media feature descriptors test particular capabilities or dimensions within a type.
