# UML Return Message

A UML return message represents control or a result flowing back to the participant that made an earlier call. It is commonly drawn as a dashed arrow pointing from the receiver back toward the caller.

Return messages can label meaningful outputs, but a diagram may omit obvious returns to reduce clutter. Including them is valuable when the response data or timing is part of the scenario being explained.
