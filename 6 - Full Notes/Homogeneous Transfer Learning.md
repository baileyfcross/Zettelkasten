# Homogeneous Transfer Learning

Homogeneous transfer learning reuses knowledge between source and target domains that share the same feature and label spaces but differ in their data distributions or available labels. The representation itself is compatible across domains.

Methods can reweight source instances, learn a shared representation, or adapt model parameters toward the target. Similarity must still be assessed because matching variable names do not guarantee matching predictive relationships.
