# Animation Progress Bar

An animation progress bar makes the current temporal position visible as a sequence plays. Labeled ticks can mark months or other meaningful boundaries, and a growing foreground bar distinguishes elapsed from remaining time. The source also attaches pointer events that pause and resume playback. A progress bar gives orientation but not values; a [[Linked Time-Series Animation]] can provide a richer temporal reference.
