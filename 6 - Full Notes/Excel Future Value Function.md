# Excel Future Value Function

The Excel FV function calculates the value of an investment or balance after a specified number of periods at a periodic rate. It can account for a starting amount, recurring payments, and whether those payments occur at the beginning or end of each period.

The interest rate, payment interval, and period count must use compatible time units. Cash-flow signs represent direction, so deposits and the resulting balance may appear with opposite signs. FV models a defined rate and payment pattern; it does not account for unmodeled fees, taxes, irregular contributions, or uncertain returns.
