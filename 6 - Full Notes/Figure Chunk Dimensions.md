# Figure Chunk Dimensions

Figure chunk dimensions specify the size of the graphics device used when R draws a figure. They influence aspect ratio, text scaling, and how geoms arrange before the image is inserted.

Device dimensions differ from the final display dimensions and should be selected with the plot design in mind.
