# Progressive Refinement

Progressive refinement divides a difficult selection into stages. A coarse first action reduces the set of possible targets, and later actions refine that set until one object remains.

This is useful when objects are small, distant, occluded, or densely packed. The first stage can favor speed and low precision, while the second presents a simpler arrangement or menu of candidates. This can avoid requiring a single exact movement and reduce fatigue.

The stages should remain fast and preserve the spatial relationship between candidates and their original locations. Progressive refinement is an [[Interaction Technique]] pattern for improving [[Object Selection]].
