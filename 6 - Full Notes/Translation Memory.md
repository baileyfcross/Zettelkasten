# Translation Memory

A translation memory stores previously translated source segments with their approved target-language equivalents. When a similar passage appears, a translator can retrieve, compare, and adapt earlier work instead of starting from an empty page.

The memory improves consistency in manuals, software, and other recurring material whose terminology and phrasing must remain stable across revisions. Unlike a fully automatic system, it keeps the human translator in control of selection and reformulation. Its usefulness depends on relevant, trusted examples and responsive retrieval; irrelevant or constantly shifting suggestions can slow the work they are meant to support.
