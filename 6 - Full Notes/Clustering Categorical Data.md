# Clustering Categorical Data

Categorical data clustering groups records whose attribute values have no inherent numeric order. Ordinary geometric distance cannot be applied directly to values such as sunny, red, or regulatory.

Algorithms therefore define similarity through matching values, co-occurrence, shared neighbors, graph connectivity, or supported projections. The representation should respect attribute cardinality and meaning.
