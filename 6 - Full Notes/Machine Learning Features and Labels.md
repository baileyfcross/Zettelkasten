# Machine Learning Features and Labels

Features are the input values a model uses to make a prediction, while the label is the target value it learns to predict during supervised training. Data preparation converts source fields into the numeric or categorical representation expected by the chosen algorithm.

Feature selection encodes assumptions about what information is available at prediction time. Including a field that directly or indirectly reveals the label creates leakage and produces evaluation results that will not survive real deployment.
