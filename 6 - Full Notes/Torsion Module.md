# Torsion Module

A torsion module over an integral domain is a module in which every element is annihilated by some nonzero scalar. In the source's broader formulation, the annihilating scalar is required to be a non-zero-divisor.

Over a Noetherian integral domain, M is torsion exactly when the zero ideal is not an [[Associated Prime]]. Torsion records elements supported away from the generic prime.
