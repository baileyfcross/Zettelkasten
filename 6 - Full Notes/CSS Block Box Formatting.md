# CSS Block Box Formatting

A block box in normal flow is laid out vertically with surrounding block boxes and ordinarily expands to fill the available inline width. Its width, horizontal margins, padding, and borders must together satisfy the width of its [[CSS Containing Block]].

Automatic horizontal values distribute the available space according to CSS formatting rules. Vertical placement also responds to box height and [[CSS Vertical Margin Collapsing]].
