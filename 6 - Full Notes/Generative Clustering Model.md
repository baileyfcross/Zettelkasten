# Generative Clustering Model

A generative clustering model describes a mechanism by which a latent cluster first selects a component and that component then generates an observation. Clustering reverses this description to infer likely membership from the observed values.

Because it models the data distribution, it can estimate density, simulate observations, and express overlapping memberships. Its conclusions depend on the assumed component family.
