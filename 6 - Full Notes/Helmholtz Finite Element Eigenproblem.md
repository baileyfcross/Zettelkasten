# Helmholtz Finite Element Eigenproblem

A Helmholtz finite element eigenproblem arises when a source-free wave equation contains an unknown wave-number parameter. Element gradient and interpolation matrices assemble into a generalized eigenvalue equation.

In a waveguide, eigenvalues approximate cutoff parameters and eigenvectors approximate field patterns of supported modes. Symmetric assembled matrices yield real eigenvalues under the stated homogeneous formulation.
