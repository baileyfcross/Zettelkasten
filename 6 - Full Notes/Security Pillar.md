# Security Pillar

The security pillar protects information, systems, and assets while enabling the workload to deliver value. Its design principles include strong identity foundations, traceability, layered controls, automated security practices, data protection, and preparation for security events.

Security decisions span people, process, and technology. Least privilege, protected logs, classification, encryption, vulnerability management, and rehearsed incident response work together under the [[AWS Shared Responsibility Model]].
