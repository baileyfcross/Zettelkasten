# Physically Based Interface

A physically based interface uses real surfaces, objects, constraints, or material behavior as part of the interaction rather than treating the physical world only as a backdrop. The environment supplies affordances and feedback that computation can augment.

Tracked props and tangible objects can provide shape, weight, contact, and shared access without simulating those qualities visually. The digital mapping should respect the physical behavior closely enough that the combined object remains understandable.
