# Build Reliability

Build reliability is the ability to compile and package a deliverable consistently enough that code changes can proceed to verification and release. Failures in dependencies, environments, scripts, capacity, or configuration interrupt the delivery path even when application code is correct.

Useful measures include build success rate, failure causes, queue time, and execution duration over a fixed period. Improving both success and speed shortens feedback while preventing an unreliable build system from becoming a release bottleneck.
