# Dataset Glimpse

A dataset glimpse is a compact inspection of a table's dimensions, column names, variable types, and sample values. It helps an analyst spot obvious schema problems without printing the entire dataset.

The book uses this review early in ingestion so character, factor, date, and numeric fields can be corrected before modeling.
