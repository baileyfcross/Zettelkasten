# Amazon GuardDuty

Amazon GuardDuty is a threat-detection service that analyzes AWS data sources for suspicious or malicious activity. It can identify patterns such as unusual API calls, compromised credentials, cryptocurrency mining, reconnaissance, and communication with known malicious infrastructure.

GuardDuty produces prioritized findings rather than blocking every detected action. Effective use requires centralized visibility, notification, investigation, and response processes, often followed by deeper relationship analysis in [[Amazon Detective]].
