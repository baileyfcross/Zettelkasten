# First-Class Function

A first-class function can be handled as a value: assigned to a variable, passed to another function, returned, or stored. C# delegates and lambdas give functions this role. A filter need not hard-code its comparison; the caller can pass a price or discount criterion, making the same traversal reusable for different selection rules.

JavaScript functions have the same value-like role: they can be placed in objects or arrays, passed as callback arguments, and returned from other functions. This property is the basis for [[Higher-Order Function|higher-order functions]] and lets behavior flow through an application alongside ordinary data.
