# Roblox GUI Container Types

Roblox provides several containers for interface content. ScreenGui places two-dimensional controls on the player's screen, SurfaceGui places interface elements on a face of a three-dimensional object, and BillboardGui displays a world-linked panel that can face the camera.

Choosing the container establishes the coordinate and visibility context before individual labels, images, buttons, or frames are added. Interaction usually runs in a LocalScript because it belongs to one player's device. [[Roblox Responsive GUI Layout]] then adapts those elements to different screen dimensions and input environments.
