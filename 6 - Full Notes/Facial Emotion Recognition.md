# Facial Emotion Recognition

Facial emotion recognition estimates visible expression categories from an image of a face. The service does not return a certain statement about a person's inner state; it returns model scores for categories learned from labeled examples.

The mobile application selects the highest-scoring returned category for one detected face. The book warns against anthropomorphizing the algorithm because the result depends on training examples and can be distorted by incorrectly labeled data.
