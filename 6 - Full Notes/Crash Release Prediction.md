# Crash Release Prediction

Crash release prediction estimates whether a software release is likely to exhibit severe crash behavior. Its representation can combine complexity, time, code, diffusion, commit, and textual dimensions.

A release aggregates many development events, so features must summarize both the product and the process leading to it. The target definition should separate ordinary failures from the crash outcome of interest.
