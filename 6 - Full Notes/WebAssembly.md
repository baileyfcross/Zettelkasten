# WebAssembly

WebAssembly is a browser execution format for compiled code produced from languages other than JavaScript. The 2019 appendix presents it as a way for supported browsers to run portable, processor-oriented code while retaining the browser as the deployment environment.

WebAssembly expands the implementation choices available to a web application but does not replace every JavaScript or browser API interaction. The source emphasizes tradeoffs involving downloads, browser support, tooling, performance, and the amount of existing code that can be reused.
