# Semi-Automatic Reconstruction

Semi-automatic reconstruction combines user-supplied constraints with computational fitting to build a model of a physical scene. The user identifies meaningful points, edges, planes, or object classes, and the system estimates the remaining geometry from images or measurements.

Human input resolves semantic or ambiguous choices that full automation may miss, while optimization reduces repetitive precision work. The physical object remains visible for immediate comparison with the reconstructed result.
