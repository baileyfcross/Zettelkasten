# Active and Passive Transformation

An active transformation changes a geometric vector or object while the coordinate axes remain fixed. A passive transformation keeps the geometric object fixed and instead changes the coordinate system used to describe it.

The same matrix relationship can be interpreted in either way when the convention is stated carefully. For rotations, confusing the two viewpoints reverses the apparent angle or exchanges a rotation matrix with its inverse, even though both descriptions refer to the same geometry.
