# Gaussian Quadrature

Gaussian quadrature chooses both nodes and weights so an $n$-point rule integrates every polynomial through degree $2n-1$ exactly. This is greater exactness than an equally spaced rule with the same number of evaluations.

For an integral on a finite interval, a change of variables first maps the domain to the standard interval. The nodes are roots of an orthogonal polynomial for the relevant weight function, and the weights are then determined by polynomial exactness.
