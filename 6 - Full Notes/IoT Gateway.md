# IoT Gateway

An IoT gateway connects device-level networks to other networks or services. It can translate between protocols and data formats, aggregate traffic, store or process data locally, and reduce the number of direct connections that constrained devices must maintain with the Internet or a cloud.

The gateway need not be a dedicated appliance. A smartphone can bridge a Bluetooth device to the Internet, and a mesh node can relay data toward a reachable connection. A smart gateway adds local computation and storage, overlapping with [[IoT Edge Computing]] and [[IoT Fog Computing]] to reduce bandwidth use, latency, and dependence on a remote service.
