# Score-Based Structure Learning

Score-based structure learning evaluates candidate dependency graphs with a function that combines how well they explain data with a preference against unnecessary complexity. Search operations modify the graph and retain improvements.

Decomposable scores let a local edge change be assessed through only the affected factors. Because exhaustive graph search is generally impractical, the result also depends on the search strategy and starting structure.
