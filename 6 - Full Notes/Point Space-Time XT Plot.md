# Point Space-Time XT Plot

A point space-time XT plot assigns each monitoring location a column, places time on the vertical axis, and maps its observed value to color. It gives a compact history of the full station network and exposes persistent high or low stations as vertical bands. Geographic position is lost because columns follow an identifier order, so [[Space-Time Point Small Multiples]] are needed to locate those patterns on a map.
