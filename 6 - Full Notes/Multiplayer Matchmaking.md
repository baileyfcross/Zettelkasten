# Multiplayer Matchmaking

Multiplayer matchmaking selects players and an execution destination for a compatible game session. It can search existing [[Multiplayer Game Lobby|lobbies]], create a new group, and eventually direct the participants to a dedicated server or to one another.

The matching rules may consider game mode, capacity, connection quality, region, or player criteria, but the output must also reserve or launch the needed session infrastructure. Matchmaking therefore connects player discovery to [[Game Server Provisioning]] rather than ending when a list of names has been assembled.
