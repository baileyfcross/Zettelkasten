# Addition Property of Inequality

The addition property of inequality states that adding the same real number to both sides preserves their order. If (a<b), then

$$a+c<b+c.$$

Subtracting the same number also preserves order because it adds an opposite. Geometrically, both values shift by the same distance on the [[Number Line]], so neither passes the other. This property allows constant terms to be removed while solving a [[Linear Inequality in One Variable]].
