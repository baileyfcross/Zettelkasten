# Sparse Least-Squares Support Vector Machine

A least-squares support vector machine replaces the inequality-constrained margin problem with regression toward class-coded targets. For high-dimensional data, this approximation can behave similarly to [[Soft-Margin Support Vector Classification]] while avoiding the same quadratic-program form.

Adding an L2,1 penalty to the multi-class weight matrix selects a common subset of input variables across class outputs. The resulting sparse least-squares model is also a supervised instance of [[Multi-Output Regression Feature Selection]].
