# Compound Linear Inequality

A compound linear inequality combines more than one linear constraint. An "and" relationship requires values satisfying both constraints and therefore uses their intersection. An "or" relationship accepts values satisfying either constraint and uses their union.

Each component can be solved separately with the ordinary sign rules, then the solution sets are combined. A chained form such as (-1\leq x<2) describes one bounded interval with different endpoint types. A disjoint "or" condition may produce two rays rather than one interval, so graphing helps reveal the final structure.
