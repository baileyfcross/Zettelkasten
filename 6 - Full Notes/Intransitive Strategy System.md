# Intransitive Strategy System

An intransitive strategy system has a cyclic relationship in which one option beats a second, the second beats a third, and the third beats the first. Rock-paper-scissors is the simplest example.

Because no pure option is universally best, rational play can require a [[Mixed Strategy in Matrix Games|mixed strategy]] that keeps every option in use. This makes intransitivity useful for avoiding dominated content, although equal random choices alone do not create an informed decision.
