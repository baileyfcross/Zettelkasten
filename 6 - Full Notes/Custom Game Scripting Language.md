# Custom Game Scripting Language

A custom game scripting language is designed specifically around the concepts and workflows of one engine or project. It can expose concise domain operations and restrict features that would complicate execution or authoring.

The benefit of a tailored surface comes with the cost of implementing and maintaining lexical analysis, syntax analysis, execution, tools, documentation, and debugging that a mature general-purpose language already provides.
