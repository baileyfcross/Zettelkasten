# Light Probe Reference for CG

An omnidirectional light probe records the incident illumination around a point, supplying both a record of a location and a possible image-based-lighting source. The book distinguishes a high-dynamic-range probe from an ordinary spherical lighting reference that captures similar directions without the same intensity range. Bracketed exposures can be merged to extend that range. Even a regular blurred environment image may provide useful soft fill, often combined with a separate sun or key light. The goal is a match to the photographed set, not merely a technically elaborate lighting rig. See [[Plate Lighting Reference for CG]].
