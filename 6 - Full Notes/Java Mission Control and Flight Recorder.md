# Java Mission Control and Flight Recorder

Java Flight Recorder captures JVM and application events such as allocation, garbage collection, thread activity, class loading, and method behavior with controlled overhead. Java Mission Control opens those recordings and supplies views for monitoring, profiling, and troubleshooting.

A recording preserves time relationships that a single heap or thread snapshot cannot show. Event selection and duration still affect overhead and evidence size, so a diagnostic session should target a question and retain the launch and environment context needed to interpret its observations.
