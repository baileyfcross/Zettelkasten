# Energy-Aware Workload Deferral

Energy-aware workload deferral postpones flexible computation so it can run when electricity is cheaper, cleaner, or more plentiful. Batch analytics with a completion deadline often provides more timing freedom than interactive requests.

Deferral is bounded: a scheduler must retain enough future capacity to finish the job even if renewable output falls or new urgent work arrives.
