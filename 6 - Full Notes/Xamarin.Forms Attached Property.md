# Xamarin.Forms Attached Property

A Xamarin.Forms attached property lets one type declare a bindable value that can be set on another control. Its property-changed callback can add or remove behavior when the value changes, making it useful for small reusable extensions.

An attached property can enable validation or attach an effect directly in XAML. It is most appropriate when the extension is compact and does not need the fuller lifecycle and state of a separate behavior object.
