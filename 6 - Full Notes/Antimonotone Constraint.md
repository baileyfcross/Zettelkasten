# Antimonotone Constraint

An antimonotone constraint has the property that if an itemset violates it, every superset also violates it. This permits an entire branch of the search lattice to be pruned as soon as one failing pattern is found.

Minimum support is the standard example: adding items cannot increase the number of transactions containing the set.
