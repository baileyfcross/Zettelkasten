# AWS Edge Location

An AWS edge location is a point of presence near end users that serves global edge services such as CloudFront and Route 53. Cached content can be returned without a round trip to the origin region, reducing latency and origin load.

An edge location is not an availability zone for general-purpose workload deployment. Its role is to bring supported delivery, routing, and security functions closer to clients while the authoritative application continues to run in regional infrastructure.
