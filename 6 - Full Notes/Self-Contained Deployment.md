# Self-Contained Deployment

A self-contained deployment publishes an application together with the .NET runtime required for one target operating system and architecture. The target machine does not need a separately installed compatible runtime.

The result is larger and must be published for each target platform, but it gives the application control over the runtime version it carries. This contrasts with [[Framework-Dependent Deployment]].
