# Kubernetes Cluster

A Kubernetes cluster is the collection of compute and control resources on which containerized workloads are scheduled. It provides the environment in which nodes host pods and the control plane works to preserve declared deployments.

The AKS project creates a cluster as an Azure resource and connects command-line and dashboard tools to it. Cluster capacity and lifetime affect cost even when the application itself is idle.
