# Agentic Kubernetes Remediation

Agentic Kubernetes remediation connects rollout, alert, and cluster evidence to an investigation agent guided by environment-specific runbooks. The agent can inspect application state, events, Pod logs, dependencies, constraints, and configuration, then explain a cause or propose a manifest correction.

A safe rollout begins with read-only investigation. Later stages can open a source-controlled pull request or use a narrowly permissioned remediation tool, allowing GitOps reconciliation and human review to remain part of the change path.
