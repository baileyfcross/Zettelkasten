# CSS Replaced Element Formatting

A replaced element supplies externally rendered content and may carry intrinsic width, height, and aspect ratio. CSS uses those intrinsic values when `width` or `height` is automatic, subject to available constraints and any explicit dimensions.

Inline replaced elements enter line layout as a single box with a defined baseline behavior. Their sizing differs from nonreplaced text because the browser is fitting an external object rather than formatting descendant inline content.
