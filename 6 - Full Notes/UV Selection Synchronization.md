# UV Selection Synchronization

UV selection synchronization links component selection in the UV Editor with the corresponding mesh selection in the 3D Viewport. It helps the artist identify which flattened vertices, edges, faces, or islands belong to visible surface regions.

When synchronization is disabled, sticky selection modes govern how related UV coordinates follow an initial choice. Switching deliberately between vertex, edge, face, and island modes reduces accidental edits to unrelated portions of the layout.
