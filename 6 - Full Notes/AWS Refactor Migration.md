# AWS Refactor Migration

Refactoring redesigns an application to use cloud-native structures such as microservices, managed services, containers, or serverless execution. It can improve scalability, resilience, and development speed, but it requires the greatest architectural and code change among the [[AWS Seven Rs Migration Strategy|seven Rs]]. The additional benefit must justify the delivery time, skill demand, testing burden, and transformation risk.
