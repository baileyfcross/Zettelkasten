# Git Configuration

Git configuration stores settings that affect repository behavior and commit identity, including the user's name and email. Settings can be global for the user or overridden within one repository.

`git config --list` displays effective entries, while scoped commands add or change them. Repository-specific configuration is useful when one project needs an identity or behavior different from the user's general defaults.
