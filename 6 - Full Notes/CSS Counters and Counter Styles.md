# CSS Counters and Counter Styles

CSS counters are named values that can be reset, incremented, and displayed through generated content. Nested scopes make counters suitable for hierarchical section numbers as well as ordinary list markers.

Counter styles define how numeric values become symbols. The source describes fixed, cyclic, symbolic, alphabetic, numeric, and additive systems, along with extensions, prefixes, suffixes, fallbacks, ranges, and spoken forms.
