# sizes Attribute

The responsive-image `sizes` attribute tells the browser how wide an image slot is expected to be under ordered media conditions. It supplies layout knowledge that may not be available when the preloader needs to select a source.

The value describes the display slot, not the file width. An inaccurate default or media expression can make the browser choose a larger candidate than needed. See [[Responsive Image Selection Before Layout]] and [[srcset Width Descriptor]].
