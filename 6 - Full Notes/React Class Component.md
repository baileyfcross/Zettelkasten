# React Class Component

A React class component is a JavaScript class that extends `React.Component` and defines a `render` method. The base class supplies component capabilities such as props and state, while the subclass supplies the element tree and any instance methods needed by its behavior.

In the React 15-era API described by the source, class components were used when a component needed state, lifecycle methods, or an instance scope. A [[Function Component|function component]] remained the simpler option when output could be calculated directly from props without those instance features.
