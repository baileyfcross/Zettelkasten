# XPath Positional Filter

An XPath positional filter selects a match by its one-based position, such as the second list item in a set. It distinguishes structurally similar elements when tags and attributes do not provide a unique identifier.

Position should be a last resort because inserting, removing, or reordering siblings changes what the index selects. A semantic attribute or relationship usually communicates test intent more reliably.
