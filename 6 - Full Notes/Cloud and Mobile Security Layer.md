# Cloud and Mobile Security Layer

Cloud and mobile security extends layered defense to services and devices that move beyond a traditional organizational perimeter. Protection must still address people, networks, hosts, applications, and data, but ownership and physical location may be distributed.

The source emphasizes that these environments do not replace established security layers. They change where controls operate and who is responsible for configuration, access, monitoring, and data protection.
