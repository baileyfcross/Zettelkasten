# Equation

An equation is an assertion that two expressions have equal value. The equals sign records a relationship, not an instruction to calculate only one side.

An [[Algebraic Identity]] is true for every permitted value of its variables, while a [[Conditional Equation]] is true only for particular values. Solving a conditional equation finds those values by producing [[Equivalent Equations]]. The balance must be preserved: an operation applied to one side must be applied compatibly to the other, and any division must respect nonzero restrictions.
