# Running Mean Overlay

A running mean overlay adds a locally averaged line to a [[Time Plot]]. Each displayed average summarizes a moving neighborhood of observations, reducing short-term variation so slower movement becomes easier to see. Window width controls the tradeoff: a wider window produces a smoother line but can suppress or displace brief events. The raw series should remain visible because the overlay is a transformation, not an independent measurement.
