# Software Catalog

A software catalog is an indexed inventory of services, APIs, libraries, and other software components available to an organization. It records what a component is, who owns it, where its source and documentation live, and how other teams can use or operate it.

Repository metadata can populate much of the catalog, while external sources add third-party or non-repository entities. The catalog reduces duplicate implementation and gives users a discovery surface for existing capabilities. A portal such as Backstage may present the catalog, but the catalog and portal are only interfaces into the broader [[Internal Developer Platform]], not the platform by themselves.
