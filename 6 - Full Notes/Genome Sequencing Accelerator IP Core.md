# Genome Sequencing Accelerator IP Core

A genome sequencing accelerator IP core packages a KMP or BWA hardware implementation with standardized control and data interfaces. High-level synthesis can translate a validated algorithmic description into register-transfer logic, followed by simulation and timing verification.

The core becomes useful only after it is connected to DMA, memory, drivers, and the host application. Separate cores can share the same system shell while implementing different sequence-search algorithms.
