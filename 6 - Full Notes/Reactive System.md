# Reactive System

A reactive system is an architectural arrangement designed to remain responsive under changing load and partial failure. The book describes responsiveness, scalability, resilience, and message-based communication as its related properties. This is broader than using an observable sequence inside one process: component boundaries, resource allocation, and failure isolation determine whether the whole service can keep responding.
