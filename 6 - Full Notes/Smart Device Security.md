# Smart Device Security

Smart device security protects connected consumer and embedded products whose computation is tied to a physical function. These devices may collect sensitive information, accept remote commands, and remain deployed longer than ordinary software support cycles.

Default credentials, limited update mechanisms, and weak visibility can turn a convenient product into a [[Cyber Vulnerability]]. Device identity, secure configuration, updates, network isolation, and lifecycle support are therefore essential.
