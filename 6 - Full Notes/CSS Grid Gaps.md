# CSS Grid Gaps

Grid gaps are spaces inserted between adjacent row or column tracks. In the source's property names, `grid-row-gap`, `grid-column-gap`, and `grid-gap` define nonnegative lengths or percentages for the two axes.

Gaps consume space during [[CSS Grid Track Sizing]] as if the separating grid lines had thickness. Content-distribution alignment can add further spacing, but the declared gap itself remains distinct from margins on individual items.
