# Boole Rule

Boole's rule is a closed [[Newton-Cotes Formula]] over four equal subintervals. For one five-node panel,

$$\int_{x_0}^{x_4}f(x)\,dx\approx\frac{2h}{45}(7y_0+32y_1+12y_2+32y_3+7y_4).$$

Composite use requires the total number of subintervals to be a multiple of four. It integrates the local fourth-degree interpolating polynomial rather than fitting one polynomial across the entire data set.
