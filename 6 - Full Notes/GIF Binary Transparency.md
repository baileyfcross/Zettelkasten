# GIF Binary Transparency

GIF transparency designates one palette index as transparent. A pixel is therefore either fully visible or fully transparent; the format does not carry intermediate alpha values for smooth partial coverage.

This one-bit behavior can leave jagged or haloed edges when a graphic was prepared against a different background. PNG is preferable when graded opacity is required because [[PNG Alpha Transparency]] can represent partial transparency per pixel.
