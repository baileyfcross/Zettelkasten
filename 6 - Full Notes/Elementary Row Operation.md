# Elementary Row Operation

An elementary row operation interchanges two rows, multiplies a row by a nonzero scalar, or adds a multiple of one row to another.

Applied to an [[Augmented Matrix]], these operations preserve the solution set of its [[Linear System]]. Each operation is equivalent to left multiplication by an [[Elementary Matrix]].
