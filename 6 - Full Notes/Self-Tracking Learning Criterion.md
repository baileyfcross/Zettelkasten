# Self-Tracking Learning Criterion

The self-tracking learning criterion judges a project by whether it produced useful learning rather than by whether it resembled formal science or achieved a predetermined behavioral target. Learning can include discovering a pattern, improving a question, developing a sensation, recognizing that a measure is unhelpful, or deciding not to continue tracking.

This criterion accommodates different orientations. A science-first project may try to minimize bias and test an intervention, while a count-first project may use numbers to widen reflection before deciding which hypothesis matters. Artistic and narrative uses can also yield insight without claiming objective proof.

Learning still requires honesty about scope. A personal discovery should not be presented as a population law, and an attractive visualization should not be confused with causal evidence.
