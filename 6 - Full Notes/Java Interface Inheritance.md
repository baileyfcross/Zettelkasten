# Java Interface Inheritance

A Java interface may extend one or several other interfaces. The subinterface inherits their method declarations and constants and can add further operations, while a concrete implementing class must provide the required abstract method implementations.

Multiple interface inheritance can create ambiguous names when two superinterfaces declare the same constant. The ability to extend several interfaces does not grant a class multiple class implementations; it combines type contracts that the implementing class must reconcile.
