# AWS Free Tier

The AWS Free Tier provides limited no-charge usage for eligible services under offers whose duration and allowances vary. It helps users experiment or run small workloads, but only the specified service dimensions and quantities are covered.

Free-tier eligibility is not a universal spending cap. Usage beyond an allowance, excluded features, data transfer, or resources left running can create charges, so accounts should combine experimentation with budgets, alerts, and prompt resource cleanup.
