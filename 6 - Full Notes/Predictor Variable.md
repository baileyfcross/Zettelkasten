# Predictor Variable

A predictor variable is an observed or derived quantity used to explain or predict an outcome. In a linear model it contributes one or more columns to the [[Design Matrix]], depending on whether it is numeric, categorical, transformed, or involved in an interaction.

The term does not imply causation. A predictor can improve fit because it represents a cause, a consequence, a confounder, or merely a correlated measurement.
