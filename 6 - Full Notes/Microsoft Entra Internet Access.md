# Microsoft Entra Internet Access

Microsoft Entra Internet Access is an identity-centric secure web gateway within Global Secure Access. It acquires internet and supported Microsoft-service traffic from clients or remote networks, applies centralized access policy and web controls, and records activity with user and device context.

Traffic-forwarding profiles determine which destinations enter the service. Web content filtering and security profiles can restrict categories or threats, while Conditional Access can require an acceptable identity, device, risk, or compliant network before access proceeds. Source IP restoration preserves location and audit fidelity that a cloud proxy might otherwise hide. The service protects outbound reachability; it does not replace application authorization or the need to minimize what users can do after a site is reached.
