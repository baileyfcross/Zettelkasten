# Finite Element Discretization

Finite element discretization divides a physical domain into elements and nodes. The analyst chooses element type, size, and arrangement so the mesh can approximate the geometry and expected field variation.

Discretization converts an infinite-dimensional continuum problem into finitely many nodal unknowns. Finer or higher-order elements can improve accuracy, but they also increase the size and cost of the assembled equations.
