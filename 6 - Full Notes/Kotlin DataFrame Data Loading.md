# Kotlin DataFrame Data Loading

Kotlin DataFrame can load structured records from sources such as CSV and JSON into named columns. A notebook can inspect the inferred schema, filter rows, add or remove columns, and write transformed data back to a file or render it as an HTML table.

Loading is only the first boundary: column names and types determine which later expressions are valid. Schema inspection makes those assumptions visible before transformations and summaries depend on them.
