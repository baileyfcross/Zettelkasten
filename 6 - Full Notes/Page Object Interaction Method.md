# Page Object Interaction Method

A page object interaction method expresses a meaningful operation such as entering a username, submitting a login form, or reading a result. It hides the sequence of element lookups and low-level commands required to perform that behavior.

Methods should remain focused and use meaningful names so a test reads like a user workflow. Assertions normally stay in the test, allowing the same page behavior to support different expected outcomes.
