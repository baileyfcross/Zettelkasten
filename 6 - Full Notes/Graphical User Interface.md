# Graphical User Interface

A graphical user interface represents commands, documents, and applications as visual objects selected with a pointing device. Windows, icons, menus, and a mouse reduce reliance on typed command languages.

The interface uses human pattern recognition and motor skill while the computer handles hidden operations. Good graphics do not make a system inherently simple; the represented actions still require a coherent conceptual model.
