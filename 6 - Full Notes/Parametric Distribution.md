# Parametric Distribution

A parametric distribution belongs to a chosen mathematical family whose behavior is determined by a finite set of parameters. A normal family, for example, is specified by parameters controlling its location and spread.

Selecting the family and parameter meanings is preliminary modeling knowledge. Identification then supplies or learns parameter values from data, allowing the distribution to be computed without storing an unrestricted table over every possible case.
