# Faithful Module

A faithful module is a module whose [[Module Annihilator]] is zero. No nonzero scalar acts as zero on every module element.

Any module M becomes faithful when regarded over the quotient R/Ann(M). Faithfulness therefore separates properties of the module action from ring elements that the action cannot detect.
