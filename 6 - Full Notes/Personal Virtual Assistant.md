# Personal Virtual Assistant

A personal virtual assistant serves one user across many domains and devices. It can answer questions, manage personal information, invoke services, and use [[Personal Context]] to tailor results.

Its breadth creates a triggering problem: the system must infer which [[Assistant Skill]] should handle an utterance before that skill can interpret the request in detail.
