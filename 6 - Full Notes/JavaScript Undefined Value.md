# JavaScript Undefined Value

JavaScript's `undefined` value represents the absence of an assigned or produced value. A declared but uninitialized variable contains it, and a function that finishes without returning another value produces it as its result.

Code can also assign `undefined` explicitly or obtain it through the `void` operator. These routes are behaviorally similar at the value level, so a variable's current `undefined` state does not by itself reveal how that state arose.
