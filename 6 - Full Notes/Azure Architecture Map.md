# Azure Architecture Map

An Azure architecture map organizes a domain as a tree of concerns, alternatives, possible solutions, and sensitivity or trade-off points. It is a navigation aid rather than a prescriptive blueprint: the leaves show options an architect should evaluate against the workload, and dotted relationships expose connections across concerns. Specialized maps are needed because one diagram cannot represent the entire Azure service landscape at useful depth.
