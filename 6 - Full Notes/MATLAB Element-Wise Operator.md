# MATLAB Element-Wise Operator

A MATLAB element-wise operator applies multiplication, division, or exponentiation independently to corresponding array entries. A period distinguishes it from the matrix operator, as in `A.*B`, `A./B`, or `A.^2`.

The arrays must have compatible sizes for the intended component calculation. Confusing `A*B` with `A.*B` can produce a valid but mathematically different result.
