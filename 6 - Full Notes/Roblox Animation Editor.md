# Roblox Animation Editor

The Roblox Animation Editor records poses for a character or articulated model over time and previews the resulting motion. It operates on a compatible rig, exposes a timeline for keyframes, and exports the authored animation as an asset that scripts can load and play.

Editing is iterative: pose major moments first, preview the interpolation, refine timing and curves, then test the animation in the actual experience. The tool depends on [[Roblox Animation Rig Requirements]] and builds sequences from [[Roblox Pose Keyframes]], while export follows the platform's asset ownership rules.
