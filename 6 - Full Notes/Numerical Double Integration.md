# Numerical Double Integration

Numerical double integration applies one-dimensional quadrature successively in two coordinate directions. On a rectangular grid, the inner rule is evaluated for each fixed value of the outer variable, and the resulting values are integrated again.

Tensor-product trapezoidal or Simpson weights classify grid points as corners, edge points, or interior points. The method assumes a region that can be described by compatible limits or decomposed into such subregions.
