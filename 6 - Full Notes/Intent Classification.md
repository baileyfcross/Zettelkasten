# Intent Classification

Intent classification assigns an utterance to one of the actions defined by an [[Intent Schema]]. A statistical classifier learns from example phrases labeled with their intended action.

The task is separate from [[Named Entity Recognition]], which identifies argument values. Broad assistants may first use [[Intent Triggering]] to choose a domain and then apply a more specialized classifier inside it.
