# Azure Storage Client Library

The Azure Storage client library exposes .NET objects for storage accounts, blob clients, containers, block blobs, queue clients, queues, and messages. These objects translate application operations into calls to the remote Azure services.

The book isolates storage access behind interfaces and helper classes so most application logic does not depend directly on the Azure package. This reduces provider-specific coupling and makes calling code easier to test.
