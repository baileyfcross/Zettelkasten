# Deployment Window

A deployment window is an agreed period during which a production change may occur. It can align release activity with staff availability, business demand, dependent-system coordination, or regulatory restriction.

Windows reduce some operational risk but can increase batch size if they are too infrequent. A team should distinguish a genuine timing constraint from a habit created by unreliable deployment and recovery practices.
