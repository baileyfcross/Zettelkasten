# R Logical Indexing

R logical indexing uses a logical vector inside square brackets to retain values whose corresponding condition is true. It connects vectorized comparison directly to subsetting and can extract rows of a data frame that satisfy a scientific criterion.

The condition must align with the dimension being selected. Missing logical entries can produce missing selections, so an inclusion rule should decide explicitly whether unknown cases are retained, excluded, or reviewed separately.
