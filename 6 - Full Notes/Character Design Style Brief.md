# Character Design Style Brief

A character design style brief states the intended visual language before detailed modeling. It can establish realism or stylization, shape vocabulary, level of detail, mood, reference material, and how strongly anatomy or surface detail should be simplified.

Style also constrains production. A smooth cartoon character may support a learning project with fewer forms, while a real-time character requires geometry, textures, hair, and effects that can be evaluated within the target performance budget.
