# Equal-Correlation Optimality Condition

In L2,1-regularized multi-output regression, every active feature has feature-residual correlation norm equal to the regularization parameter, while every inactive feature has correlation norm no greater than that parameter. This is the equal-correlation optimality condition.

The condition provides both a selection rule and a certificate. An inactive feature that reaches the common correlation level is ready to enter the active set; an inactive feature exceeding it proves that a solution optimized only on the current active variables is not yet globally optimal.
