# Embedded Quantum Annealing Pause Evidence

On one native 800-qubit problem, scanning pause location and duration produced orders-of-magnitude changes in ground-state success probability within a narrow location band. Each scan point used 10,000 anneals across five gauges, while the unpaused one-microsecond schedule had success probability near $10^{-4}$.

For 50 embedded degree-constrained minimum-weight spanning-tree instances, pausing produced about a fivefold mean success-probability improvement and a consistent favorable location. The smaller effect on embedded problems remained an open question, so the result supports schedule tuning without establishing a universal pause gain.
