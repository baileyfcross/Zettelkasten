# Excel Custom Number Format

An Excel custom number format changes how a stored value is displayed without changing the value itself. Format codes can control decimal places, thousands separators, percentages, dates, times, and literal labels. This separation allows the same number to participate in calculations while appearing in a form suited to readers.

Custom formats are particularly important for [[Excel Date and Time Serial Value]] calculations. Date codes expose calendar components, time codes expose hours and minutes, and bracketed hour formats can show elapsed durations greater than one day without wrapping at twenty-four hours. Because formatting can conceal precision or underlying values, the formula bar remains an important audit view.
