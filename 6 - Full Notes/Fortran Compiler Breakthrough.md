# Fortran Compiler Breakthrough

Fortran combined algebra-like notation familiar to engineers with a compiler that generated efficient machine code for IBM computers. Its 1957 success showed that higher-level programming did not require an unacceptable performance penalty.

By hiding machine-specific details, Fortran let scientists focus on mathematical problems. IBM’s market position helped it become a widely adopted language for technical computing.
