# GraRep Graph Embedding

GraRep learns graph representations by factorizing matrices that describe node relationships at several transition-step lengths. Concatenating the resulting coordinates captures multiple orders of global proximity.

The explicit matrix view provides a systematic multiscale representation. Factorization and storage can be demanding for large graphs, motivating sparse computation or approximation.
