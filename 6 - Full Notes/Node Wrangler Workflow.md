# Node Wrangler Workflow

Node Wrangler accelerates material-node work with shortcuts and graph operations. In the book's example, an existing node can be switched to another type without manually dismantling and reconnecting its surrounding links.

The add-on also frames selected nodes for visual organization and exposes its hotkeys through its preferences. It improves authoring efficiency without changing the underlying shader graph, so the resulting material remains a network of ordinary nodes and connections.
