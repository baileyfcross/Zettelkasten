# Space-Wide Point Time Series

A space-wide point time series uses time as the row index and gives each point location its own value column. It is created by reshaping [[Long-Format Space-Time Data]] and supports multivariate temporal plotting. To construct a full point space-time object, its values can be transposed and vectorized so the spatial index varies fastest within each time. The wide form makes missing location-time combinations explicit.
