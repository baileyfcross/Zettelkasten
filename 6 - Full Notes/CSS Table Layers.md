# CSS Table Layers

Table backgrounds are painted in an ordered stack involving the table, column groups, columns, row groups, rows, and cells. Transparent portions allow lower layers to show through, so a cell background can conceal the row and column colors beneath it.

This layering allows a single cell to inherit a visual context from both its row and column. Borders and the selected border model are painted in addition to these backgrounds.
