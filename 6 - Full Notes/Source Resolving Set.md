# Source Resolving Set

A source resolving set is a collection of observed nodes whose graph-distance patterns can distinguish candidate rumor sources. Each candidate receives a vector of distances to the observers, and distinct vectors make the origins identifiable.

For multiple sources, the objective is to find a small resolving set under source-count constraints. Greedy approximation can make the combinatorial search practical on general graphs.
