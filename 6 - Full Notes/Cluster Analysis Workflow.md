# Cluster Analysis Workflow

A basic cluster analysis workflow represents observations through attributes, computes similarities or dissimilarities, applies a grouping algorithm, selects a stopping level or number of groups, and interprets and validates the result.

Each stage can change the outcome. Attribute selection, scaling, the [[Proximity Measure]], initialization, stopping rules, and treatment of outliers should therefore be documented as part of the result rather than hidden as preprocessing details.
