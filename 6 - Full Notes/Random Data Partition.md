# Random Data Partition

A random data partition assigns observations to training, validation, and test subsets using random selection. Randomization reduces systematic allocation bias when records are exchangeable.

Class imbalance, grouped observations, or time order may require stratified, grouped, or temporal splitting instead of unrestricted sampling.
