# Azure DevSecOps Pipeline

An Azure DevSecOps pipeline embeds security checks and evidence into source control, pull requests, build, release, and runtime feedback. Typical controls include peer review, dependency and secret scanning, static analysis, container and infrastructure checks, policy gates, artifact integrity, and constrained deployment identities. Shift-left detection shortens feedback, but blocking rules should be risk-based and actionable. Production telemetry and incident lessons must also flow back into code and pipeline controls.
