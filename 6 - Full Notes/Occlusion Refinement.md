# Occlusion Refinement

Occlusion refinement improves the boundary where a coarse real-scene model decides visibility. The projected model supplies an initial contour, and evidence from the current camera image adjusts that contour toward the observed physical edge.

This lets a practical model support convincing masking without reproducing every surface detail. Refinement must remain temporally stable, since a boundary that changes unpredictably from frame to frame creates visible flicker.
