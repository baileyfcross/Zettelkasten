# Countable Set

A set is countable when it is finite or can be put into one-to-one correspondence with the natural numbers. A countably infinite set can therefore be arranged as a sequence in which every member eventually appears.

The rational numbers are countable even though they are dense on the number line, because their integer numerator-denominator pairs can be systematically enumerated while repetitions are skipped.
