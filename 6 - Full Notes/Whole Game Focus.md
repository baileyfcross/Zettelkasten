# Whole Game Focus

Whole game focus keeps every team oriented toward one integrated, playable build rather than a collection of locally optimized components. Each Sprint should demonstrate progress in that shared game.

This focus gives developers context for local trade-offs and exposes mismatched features early. Cross-team structures and practices are valuable only insofar as they improve the flow of value to the whole product.
