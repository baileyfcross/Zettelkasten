# Microsoft Entra External ID

Microsoft Entra External ID manages people outside an organization's employee population. It covers business-to-business collaboration with partners, suppliers, contractors, and guests as well as consumer identity and access management for customer-facing applications.

Those scenarios use different tenant models. An [[External Identity Workforce Tenant|External Identity Workforce Tenant]] keeps guest collaboration alongside employees and supports Entra governance and protection capabilities. An [[External Identity External Tenant|External Identity External Tenant]] is a separate consumer directory for application sign-up, sign-in, branding, and profile collection. Keeping the boundary explicit prevents a consumer population and its journeys from being treated as ordinary internal directory membership.
