# Data Transformation

Data transformation converts extracted records into forms that can be combined and analyzed. It can standardize types, units, formats, categories, or structures and derive fields needed by later processing.

A transformation should make its semantic assumptions explicit. Two values that look compatible after conversion may still represent different events or populations, so technical uniformity does not guarantee conceptual equivalence.
