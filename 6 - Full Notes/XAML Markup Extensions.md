# XAML Markup Extensions

A XAML markup extension supplies a property value through runtime logic rather than a literal string. Its brace syntax can reference a resource, establish a data binding, resolve a type, or produce another context-dependent value.

Markup extensions keep dynamic relationships inside declarative markup. Their meaning depends on the surrounding object and framework, so clear use of standard extensions is preferable to hiding substantial application behavior in custom value providers.
