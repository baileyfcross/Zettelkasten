# .NET Standard

.NET Standard is an API specification implemented by multiple .NET platforms. A library targeting a standard version can use the APIs in that contract and can run on implementations that support the same or a later compatible level.

The standard is not a runtime that can be installed or executed by itself. It provides a compatibility boundary for sharing code across .NET Framework, .NET Core, and Xamarin as they existed in the source's 2019 ecosystem.
