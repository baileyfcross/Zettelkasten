# CSS Border Images

CSS border images slice an image into corner, edge, and center regions and map those regions around an element's border. Properties choose the source, slice offsets, border-image width, outward extension, and whether edge slices stretch, repeat, or round.

The border style must still permit a border to be drawn, and the image replaces the ordinary border painting rather than changing layout. The center region is omitted unless filling is requested.
