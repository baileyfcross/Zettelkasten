# Unity Animator Component

A Unity Animator component evaluates an Animator Controller for a GameObject and applies the selected animation motion. It is the runtime bridge between stored clips, controller logic, and the animated object or character.

The component references an [[Unity Animator Controller]] and may also use an avatar when imported rigs need a common skeletal mapping. Scripts generally influence animation by changing controller parameters rather than directly choosing frames, keeping gameplay decisions separate from motion playback.
