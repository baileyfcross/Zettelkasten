# Helidon MP Programming Model

Helidon MP is a MicroProfile runtime for portable Jakarta EE microservices. It uses declarative APIs, annotations, and Jakarta Contexts and Dependency Injection while providing full MicroProfile support and a selected portion of Jakarta EE.

An MP application is still a standalone Java program running in its own JVM rather than an application that must be deployed to a separate application server. In Helidon 4, its blocking and synchronous programming model runs on the same virtual-thread web server used by [[Helidon SE Programming Model]].
