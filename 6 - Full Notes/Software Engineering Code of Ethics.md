# Software Engineering Code of Ethics

A software engineering code of ethics states the professional relationships and obligations that should guide practitioners, managers, educators, and trainees. It recognizes that software engineers can enable benefit or harm through analysis, specification, design, development, testing, certification, and maintenance.

The code supplies a shared reference when commercial pressure, safety, privacy, quality, or attribution creates a conflict. It informs judgment rather than replacing it: a professional must still connect the applicable principle to the stakeholders and facts of the case.
