# Visual Studio Call Stack

The Visual Studio Call Stack window lists the active chain of method calls that led to the current paused location. It helps identify which caller selected a path when the same method can be reached from several sources.

Moving among frames exposes each frame's source location and context. The stack explains control flow at one instant and is especially valuable when paired with an exception or [[Breakpoint]].
