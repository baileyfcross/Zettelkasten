# Agglomerative Clustering

Agglomerative clustering begins with each observation in its own cluster and repeatedly merges the pair judged most compatible. After n minus one merges, all observations belong to one group.

The linkage or objective function determines which pair merges next. Because earlier merges are not reconsidered, local choices shape every later level of the hierarchy.
