# Feature Transformation Recommendation

Feature transformation recommendation predicts which operation is likely to improve a given variable or dataset. A recommender can learn from earlier transformation outcomes rather than testing every function.

Compact distribution summaries, including quantile-based sketches, provide inputs to recommendation models. The system's generality depends on the diversity of prior datasets and on respecting feature types and operation requirements.
