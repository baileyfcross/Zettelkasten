# Vector-Matrix Multiplication

Vector-matrix multiplication multiplies each element of a row [[Vector]] by the corresponding element of a matrix column and sums the products. Repeating this for every column produces a new vector.

In the [[Power Method]], the current vector is repeatedly multiplied by the same matrix. PageRank uses this operation to redistribute every page's importance through the graph in each iteration.
