# Graph Path Length

Graph path length measures the total cost of a [[Graph Path]]. In an unweighted graph it can be counted as the number of edges. In a [[Weighted Graph]], it is the sum of the weights assigned to the traversed edges.

The meaning of a weight comes from the model. It may represent physical distance, travel time, cost, reward, or another quantity, so the shortest path is defined relative to that chosen measure.
