# Raster Attribute Table

A raster attribute table associates integer raster cell codes with category labels and possibly additional class attributes. It lets a [[Categorical Raster Map]] display meaningful names instead of raw numbers and supports selecting a qualitative palette by class. The table does not change cell geometry; it supplies semantics for stored values. Codes, labels, and colors should remain synchronized when classes are merged or reordered.
