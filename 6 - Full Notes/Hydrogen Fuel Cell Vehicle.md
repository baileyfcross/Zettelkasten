# Hydrogen Fuel Cell Vehicle

A hydrogen fuel-cell vehicle feeds stored hydrogen to a [[Fuel Cell]] and uses its electrical output to drive a propulsion motor. It differs from a [[Hydrogen Combustion Vehicle]], which burns fuel to move an engine piston or turbine. The source presents polymer-membrane cells as suitable for transport because output can change quickly, while fuel storage and distribution remain system-level constraints.
