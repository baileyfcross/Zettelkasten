# Blender Command Log

The Blender Command Log records Python operator calls generated by many actions in the graphical interface. Moving an object, for example, exposes a corresponding `bpy.ops.transform` call, giving the developer a concrete starting point for automation without first memorizing the API.

Recorded calls often contain interface-state arguments that are unnecessary in a reusable script. A productive workflow copies the call into the [[Blender Interactive Console]], removes optional details, and tests the smallest expression that preserves the intended result. The log is therefore a discovery aid, not automatically finished program code.
