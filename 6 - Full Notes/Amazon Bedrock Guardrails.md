# Amazon Bedrock Guardrails

Amazon Bedrock Guardrails defines reusable safety and content policies that can be applied consistently across supported foundation models and applications. A guardrail can filter unwanted topics or content, detect sensitive information, and constrain responses according to organizational rules. It provides a policy layer independent of a single model, but it should be combined with authorization, testing, monitoring, and human review because generated output remains probabilistic.
