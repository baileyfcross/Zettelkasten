# Linguistic Proximity Analysis

Linguistic proximity analysis measures how closely marker sets occur within text to investigate their semantic relationship. A narrow token window suggests tight coupling, while a wide window may capture separate discussions that merely share a page or document.

The chosen distance changes the number and interpretation of returns. Proximity is therefore a methodological assumption that must be justified and tested rather than an arbitrary search setting.
