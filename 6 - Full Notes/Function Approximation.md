# Function Approximation

Function approximation replaces a complicated or unavailable analytic function with a simpler function that is easier to evaluate, differentiate, or integrate.

The source data may be tabulated measurements or costly calculations. [[Interpolation]] requires the approximation to match known values, while [[Least Squares Approximation]] allows discrepancies so noisy data can be modeled without passing through every point.
