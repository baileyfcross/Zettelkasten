# Programming to Learn

Programming to learn uses code as a medium for exploring another subject rather than treating programming itself as the final objective. Constructing an executable model forces learners to state relationships precisely and observe their consequences.

The approach can deepen understanding when the programming environment and domain are carefully integrated. Transfer is not automatic; learners still need instruction and experience in the subject being modeled.
