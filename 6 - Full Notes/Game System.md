# Game System

A game system is a functional assembly of parts whose looping interactions perform a recognizable purpose within a game. Combat, progression, inventory, and crafting can each be treated as machines that produce particular forms of gameplay.

The parts and behaviors of a game system must support the desired player experience and connect coherently to peer and higher-level systems. A [[Game System Design Document]] records that purpose, structure, interactions, and context.
