# Vehicular Cloud

A vehicular cloud pools computing, storage, sensing, and communication resources contributed by vehicles. A coordinating system presents these changing resources as services for participating applications.

Vehicle mobility makes membership, connectivity, incentives, privacy, and reliability more variable than in a conventional fixed data center.
