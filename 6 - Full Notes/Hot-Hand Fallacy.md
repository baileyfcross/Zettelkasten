# Hot-Hand Fallacy

The hot-hand fallacy interprets a streak of independent successes as evidence that success has become more likely. Random sequences naturally contain clusters, but observers often infer a changing ability or hidden cause from the cluster alone.

Simulation can test whether an observed streak exceeds what independent trials would routinely produce. The comparison must model the actual base probability and number of opportunities rather than treating any visible run as proof of momentum.
