# CSS Font Variants and Features

CSS font-variant properties request typographic alternatives such as small capitals, ligatures, numeric styles, and other feature groups. These high-level choices provide named access to capabilities stored in the selected font.

The lower-level `font-feature-settings` property can address OpenType feature tags directly. The source presents an ordering in which required and default features, face descriptors, variant properties, and explicit feature settings combine to determine the final glyph shaping.
