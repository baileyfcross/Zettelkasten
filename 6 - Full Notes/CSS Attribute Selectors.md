# CSS Attribute Selectors

An attribute selector matches elements by the presence or value of an attribute. Operators can require an exact value or test whether a value begins with, ends with, contains, or includes a whitespace- or hyphen-separated token.

This lets CSS respond to information already present in the document without adding a class. A case-insensitivity flag can alter value comparison where supported, while the document language still determines how attribute names and values behave.
