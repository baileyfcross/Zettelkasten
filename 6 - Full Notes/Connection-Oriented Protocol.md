# Connection-Oriented Protocol

A connection-oriented protocol establishes a session between endpoints before exchanging application data. The maintained connection can support ordering, acknowledgments, retransmission, flow control, and a defined close operation.

TCP is the book's principal example. Its reliability features reduce work for the application but add setup, state, and protocol overhead compared with independent datagrams.
