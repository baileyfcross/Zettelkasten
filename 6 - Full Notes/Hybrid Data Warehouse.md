# Hybrid Data Warehouse

A hybrid warehouse places frequently used data in a conventional warehouse while storing larger, older, or less frequently accessed collections in distributed storage. A connection between the environments can present a unified query interface and combine results computed in each location.

The architecture responds to different cost and latency needs rather than declaring one storage system universally superior. Its usefulness depends on whether data meaning, access rights, query execution, and result integration remain coherent across the two places.
