# Compound Game Entity

A compound game entity requires more than one data value for its description. Each component is an attribute, such as the speed and direction that together describe wind.

Compound entities let mechanics address one quality without replacing the whole object. Designers must specify which attributes are independent, derived, bounded, or changed together.
