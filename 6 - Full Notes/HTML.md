# HTML

Hypertext Markup Language describes the structure and links of a Web document. Tim Berners-Lee chose a deliberately simple subset of an established markup tradition so nonspecialists could create pages.

Its accessibility accelerated publication on the early Web. Browsers interpret the markup and combine it with media and styling to produce a displayed page.
