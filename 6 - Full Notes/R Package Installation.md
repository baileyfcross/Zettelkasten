# R Package Installation

R package installation copies a package and its dependencies into a library directory where R can find it in later sessions. A repository installation selects an available binary or source version appropriate to the platform, while a local installation uses an explicitly obtained package archive.

Installation is distinct from [[R Library Attachment]], which exposes an installed package in the current session. Reproducible work should record the repository and version context rather than assuming that a future installation will retrieve identical code.
