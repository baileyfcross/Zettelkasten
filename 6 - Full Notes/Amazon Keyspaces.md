# Amazon Keyspaces

Amazon Keyspaces is a serverless, managed wide-column database compatible with Apache Cassandra’s query language and data model. It removes cluster provisioning and node maintenance while scaling tables around request demand. The service suits applications already shaped around partition keys and Cassandra access patterns, but compatibility does not remove the need to design balanced partitions, choose capacity behavior, and verify supported Cassandra features.
