# Sweave Document

A Sweave document combines LaTeX prose with embedded R code, conventionally in an `.Rnw` file. Processing evaluates code chunks and produces a LaTeX document whose tables, figures, and values reflect the analysis.

The format established a workflow later extended by tools such as knitr.
