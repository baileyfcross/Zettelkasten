# Blender Vertex Paint Brush Tools

Vertex Paint provides Draw, Blur, Average, and Smear tools. Draw assigns color, Blur softens variation, Average moves painted values toward a local mean, and Smear drags existing color across adjacent mesh elements.

Radius, strength, falloff, blend mode, and brush color shape each stroke. Saving customized brushes turns those settings into reusable painting instruments rather than one-time interface states.
