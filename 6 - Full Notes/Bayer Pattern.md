# Bayer Pattern

The Bayer pattern is a common color filter array that repeats a 2-by-2 arrangement containing one red, one blue, and two green samples. Green is sampled twice because human vision is especially sensitive to luminance detail, to which the green channel contributes strongly.

The repeating layout determines which channel values are measured and which are interpolated at every pixel. A known pattern therefore predicts a periodic structure of color correlations in ordinary camera output.
