# ASP.NET Core Identity

ASP.NET Core Identity is a membership system for adding users, credentials, roles, login, logout, and account management to an ASP.NET Core application. Its entity types can be stored through Entity Framework Core.

Identity services are registered in the application's dependency-injection container and middleware pipeline. [[User Manager]] and [[Role Manager]] then provide APIs for managing the stored identities and roles.
