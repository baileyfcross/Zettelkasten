# Process Integration

Process integration connects business workflows so one service can continue work started by another or so equivalent processes can substitute for one another. The connection must define the triggering event, transferred information, expected state, and completion behavior.

Shared process languages, protocols, and interfaces support this coordination. An [[Enterprise Service Bus]] can hide some transport details, but it cannot supply agreement about the business meaning of the connected steps.
