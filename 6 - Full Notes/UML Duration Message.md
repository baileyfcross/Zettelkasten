# UML Duration Message

A UML duration message makes a meaningful passage of time between sending and receiving visible in a sequence diagram. Its angled path contrasts with an effectively immediate horizontal message.

The notation is useful when latency, waiting, or transmission time affects the scenario. It communicates relative timing significance without requiring the diagram to be a precise performance chart.
