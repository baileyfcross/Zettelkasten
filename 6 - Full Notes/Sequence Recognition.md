# Sequence Recognition

Sequence recognition infers hidden labels, states, or models from an ordered series of observations. The temporal decomposition represents how earlier hidden states constrain later ones and how each state produces evidence.

Order provides information that isolated classification discards. Filtering supports online recognition, while smoothing can reinterpret earlier elements after later observations become available.
