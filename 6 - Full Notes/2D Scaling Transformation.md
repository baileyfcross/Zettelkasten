# 2D Scaling Transformation

A two-dimensional scaling transformation multiplies a point's x and y coordinates by scale factors sx and sy. Equal factors produce uniform scaling; unequal factors change proportions. Factors greater than one enlarge the corresponding dimension, while factors between zero and one reduce it.

The diagonal scaling matrix acts about the coordinate origin. Consequently, an object not centered at the origin changes both size and position. Scaling about a chosen fixed point requires translating that point to the origin, applying the scale, and translating back, an instance of [[Coordinate Frame Conjugation]].
