# Pattern Post-Processing Pruning

Pattern post-processing pruning removes redundant or low-value patterns after mining has produced a candidate collection. It can use equivalence, subsumption, correlation, coverage, or model performance.

Because the full candidates already exist, post-processing is flexible but may inherit the mining phase's memory cost. Earlier constraint pushing is preferable when the raw pattern set is too large to materialize.
