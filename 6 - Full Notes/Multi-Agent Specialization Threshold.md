# Multi-Agent Specialization Threshold

Multiple agents are justified when a task contains distinct expertise domains, independent checks, or evidence-gathering work that benefits from parallel execution. Incident response can meet this threshold because deployment history, runtime health, runbook compliance, remediation, and communication are separable responsibilities.

A single agent remains preferable when one bounded context and tool set can solve the task. Adding agents creates coordination, validation, latency, and failure-handling costs. Specialization should therefore improve evidence quality or reduce context and tool overload, not merely make the architecture appear advanced.
