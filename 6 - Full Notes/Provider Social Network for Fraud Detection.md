# Provider Social Network for Fraud Detection

A provider social network represents healthcare providers as nodes and connects them through shared patients, referrals, claims, or other relationships. Network structure can reveal clusters and interaction patterns that provider-by-provider analysis misses.

An edge is not itself evidence of wrongdoing; legitimate care also produces dense professional relationships. The graph must define what a connection means and control for specialty, geography, and patient volume. It becomes useful for fraud detection when suspicious billing behavior aligns with unusually coordinated network structure.
