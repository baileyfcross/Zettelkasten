# Virtual Assistant

A virtual assistant is a software system that accepts natural-language requests, interprets what the user wants, and returns information or performs an action. Its conversational surface should not be confused with intelligence: a fluent response can hide a narrow service, while a constrained [[Voice User Interface]] can expose a capable one.

A complete assistant commonly combines [[Automatic Speech Recognition]], [[Natural Language Understanding]], a [[Dialog Manager]], [[Natural Language Generation]], [[Text-to-Speech]], and [[Digital Service Integration]].
