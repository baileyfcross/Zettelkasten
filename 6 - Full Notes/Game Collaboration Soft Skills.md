# Game Collaboration Soft Skills

Game collaboration depends on listening, clear explanation, constructive criticism, empathy, negotiation, reliability, and willingness to revise one's own idea. These skills determine whether specialized knowledge can become a coherent shared design.

They are production capabilities rather than personality extras. A technically strong contribution loses value when teammates cannot question, understand, integrate, or build upon it.
