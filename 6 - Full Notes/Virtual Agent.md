# Virtual Agent

A virtual agent is an assistant designed to represent an organization in a bounded service interaction. It typically guides users through tasks such as customer support, reservations, or account operations rather than offering the broad capabilities of a [[Personal Virtual Assistant]].

Because its domain is narrow, a virtual agent can use [[Directed Dialog]] and a controlled [[Voice User Interface]] to reduce ambiguity and recover from recognition or understanding errors.
