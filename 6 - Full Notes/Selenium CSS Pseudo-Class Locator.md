# Selenium CSS Pseudo-Class Locator

A Selenium CSS pseudo-class locator selects an element by its position or state within a structural relationship. The book demonstrates `:first-child`, `:last-child`, and `:nth-child(n)` for choosing ordered children of a parent.

Like an [[XPath Positional Filter]], an order-based pseudo-class can break when siblings are inserted or reordered. It is most appropriate when position is itself part of the behavior being tested.
