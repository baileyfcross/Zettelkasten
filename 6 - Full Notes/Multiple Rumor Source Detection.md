# Multiple Rumor Source Detection

Multiple rumor source detection searches for a set of origins that jointly explains observed diffusion. Treating a genuinely multi-source process as single-source can place the estimate between cascades rather than near any origin.

The number of sources may itself be unknown. Graph algorithms can seek a small candidate set whose distance patterns distinguish the observed nodes while satisfying an assumed upper bound.
