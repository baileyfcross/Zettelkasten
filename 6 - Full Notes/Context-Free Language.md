# Context-Free Language

A context-free language is a [[Formal Language]] generated by some [[Context-Free Grammar]]. Different grammars may generate the same language, including grammars that differ in ambiguity or suitability for mechanical parsing.

Context-free languages strictly include the regular languages: for example, a grammar can generate matched counts such as aⁿbⁿ, which the [[Pumping Lemma for Regular Languages]] shows is not regular. [[Pushdown Automaton|Pushdown automata]] recognize exactly the context-free languages.
