# Vector Normalization

Vector normalization divides a nonzero vector by its magnitude to produce a unit vector pointing in the same direction. The normalized result has length one, so direction is separated from distance or speed.

Unit directions simplify lighting, movement, and angle calculations. A zero vector cannot be normalized because it has no direction and would require division by zero.
