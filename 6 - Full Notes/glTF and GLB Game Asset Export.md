# glTF and GLB Game Asset Export

glTF 2.0 represents a scene through node hierarchies, meshes, materials, cameras, and animation descriptors in a form optimized for download and runtime loading. A `.gltf` package can reference external resources, while `.glb` combines the asset into a binary container that can include textures.

Blender export options cover selection, transforms, modifiers, UVs, normals, tangents, vertex colors, materials, shape keys, skinning, and animation. This scope makes glTF useful for [[Godot glTF 2.0 Import Workflow|real-time engine transfer]] when the supported feature subset is verified.
