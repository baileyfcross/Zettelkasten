# Unity Inspector

The Unity Inspector displays and edits the serialized properties of the currently selected asset or [[Unity GameObject]]. For a GameObject it presents the attached components, their enabled state, and fields exposed for authoring.

The Inspector is the bridge between code-defined structure and scene-specific configuration. A script can define a tunable value once, and designers can assign different values or asset references to individual instances without modifying the source. Because Inspector edits become project data, their relationship to prefab defaults and runtime changes must remain clear.
