# Distance Matrix

A distance matrix records the pairwise distance between every pair of observations. It is symmetric when the distance is symmetric, has zeros on its diagonal, and provides the input for many clustering and multidimensional-scaling procedures.

The source constructs one from high-dimensional gene-expression samples. The matrix preserves pairwise relationships without retaining the original feature coordinates, so its meaning depends entirely on the selected distance and preprocessing.
