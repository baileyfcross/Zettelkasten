# Kubernetes as a Platform Core

Kubernetes often serves as the common resource and orchestration layer beneath an internal platform because it supplies a standardized API, declarative desired state, controllers, and a large ecosystem of infrastructure integrations. Those properties let a platform team expose repeatable capabilities without inventing a control system for each one.

Kubernetes is a platform for building platforms, not a complete developer platform by itself. The product decision must still begin with user pain and supported use cases; virtual machines, managed services, or SaaS may be better components for some capabilities. An all-in-Kubernetes strategy is a constraint that needs evidence, not a goal.
