# Cloud Service Aggregation

Cloud service aggregation combines comparable cloud cells or services into a larger service. Replicas can share demand, operate from different data centers, or be supplied by different providers while presenting one capability to the consumer.

Aggregation supports elasticity, cloud bursting, continuity, and reuse. Because the components are intended to fulfill the same role, their interfaces and service commitments need to be compatible enough for work to move between them.
