# Inertial Navigation as a GPS Backup

Inertial navigation can bridge a GPS outage because accelerometers and gyroscopes measure motion without receiving or transmitting radio signals. A navigation filter carries the last trusted satellite solution forward using inertial changes, so tunnels or brief interference need not cause an immediate loss of guidance. Error grows with time as sensor bias is integrated, making inertial equipment a continuity layer rather than a permanent replacement for external fixes.
