# Disk-Based Storage

Disk-based storage persists data in files or database structures backed by durable block storage. It usually offers greater capacity and lower cost than keeping the same data entirely in memory, with higher access latency.

Local disk can bind state to one machine or container, while managed or networked disks change availability and throughput characteristics. Backup, replication, and recovery remain explicit architecture decisions.
