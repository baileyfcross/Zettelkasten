# Staging Deployment

A staging deployment installs a release candidate into a nonproduction environment before live promotion. It provides a hosted destination for checking the artifact, environment settings, network relationships, and application startup.

Passing staging supplies additional release evidence but does not erase environmental differences. The pipeline must use the correct staging configuration and define how promotion follows verification.
