# Unity Hierarchy View

The Unity Hierarchy view lists the [[Unity GameObject|GameObjects]] in the currently open scene. It represents the scene's object graph rather than the project's complete asset library, and it supports creation, selection, search, ordering, and parent-child nesting.

Dragging one object beneath another establishes a hierarchy. Child transforms are interpreted relative to their parent, so hierarchy structure affects spatial behavior as well as organization. Selecting an entry connects the Hierarchy to the [[Unity Inspector]], where its components and properties can be examined.
