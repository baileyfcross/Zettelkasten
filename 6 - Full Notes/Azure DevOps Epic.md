# Azure DevOps Epic

An Azure DevOps epic is a high-level work item representing a large outcome that spans multiple features or delivery increments. It provides an organizing horizon without pretending that the entire result can be implemented as one indivisible task.

Features and backlog items decompose the epic into progressively actionable work. The hierarchy supports planning and reporting only when each level preserves a meaningful outcome rather than restating the same title.
