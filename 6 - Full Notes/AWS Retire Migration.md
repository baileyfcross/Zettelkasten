# AWS Retire Migration

Retiring decommissions an application that no longer provides sufficient business value or is made redundant by another system. Discovery is important because unused workloads can otherwise be migrated merely because they exist. A controlled retirement confirms owners and dependencies, preserves required data, and removes the workload, avoiding migration effort and eliminating its ongoing infrastructure, license, security, and support costs.
