# Cat Text Concatenation

The `cat` utility writes the contents of one or more files to standard output in argument order, making it a basic source for display, concatenation, or a larger pipeline. Options can reveal nonprinting characters or number lines when the output is being inspected rather than merely copied.

Its reverse-oriented companion `tac` writes lines in reverse order within each file. Neither utility edits the source unless its output is deliberately redirected, and redirecting into an input file can destroy data before the command reads it.
