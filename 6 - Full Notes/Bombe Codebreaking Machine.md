# Bombe Codebreaking Machine

The Bombe was an electromechanical codebreaking device used to test possible settings of the German Enigma cipher machine. Rotating wheels and electrical circuits effectively ran many reverse Enigma configurations against known constraints.

It differed from [[Colossus Computer|Colossus]], which processed electronically encrypted teleprinter text. Both show how urgent cryptographic work drove specialized computing during World War II.
