# Search Log Cluster Replication

Search log cluster replication repeats the same preprocessing, feature construction, scaling, and clustering on independent samples of sessions. A pattern that reappears across samples is stronger evidence than an attractive partition found once.

Replication should compare cluster profiles and substantive interpretations because numeric labels can permute between runs. Large shifts may indicate sampling dependence, sensitivity to initialization, or a few extreme sessions rather than stable behavioral types.
