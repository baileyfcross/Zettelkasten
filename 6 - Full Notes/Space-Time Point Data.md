# Space-Time Point Data

Space-time point data record attributes at geographic point locations across times. A fixed monitoring network can form a [[Point Space-Time Grid]] when every station is associated with the same time index, while mobile or opportunistic measurements may be irregular. The values can be mapped as time slices, reorganized into a [[Space-Wide Point Time Series]], or reduced to an XT matrix depending on which relationships need emphasis.
