# Cross-Platform .NET Development

Cross-platform .NET development separates the operating system used to write code from the systems on which the compiled application can run. A compatible SDK, runtime, and editor can support the same project on Windows, macOS, and Linux.

Portability still depends on the APIs the program calls. A project may compile against a cross-platform framework while using an operating-system feature that throws or behaves differently elsewhere. Testing on intended targets is therefore part of the portability claim.
