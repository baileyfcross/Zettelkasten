# Retrieval-Augmented Text-to-SQL

Retrieval-augmented text-to-SQL supplies a language model with relevant database schema, documentation, examples, and validated query patterns before it translates a natural-language request into SQL. Retrieval reduces dependence on model memory for organization-specific table and column meanings.

The generated query still requires dialect checks, least-privilege execution, cost limits, and validation against business semantics. Ambiguous questions or changing schemas can produce plausible but incorrect SQL even when the syntax is valid.
