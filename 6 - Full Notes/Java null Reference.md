# Java null Reference

`null` is the reference value that designates no object. Reference fields default to null, and a reference variable can usually be assigned null, while primitive variables cannot.

Invoking an instance member through null causes a `NullPointerException`. A null check can make absence explicit, but APIs can often reduce ambiguity by returning an empty collection, empty stream, or [[Java Optional Container]] when absence is expected. Null remains useful for uninitialized or deliberately absent references, so its meaning should be part of the contract.
