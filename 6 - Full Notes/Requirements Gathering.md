# Requirements Gathering

Requirements gathering is the collaborative process of discovering what a proposed system must accomplish and which constraints shape an acceptable solution. It combines [[Stakeholder Need Elicitation]], analysis, specification, and review rather than treating the first request as a complete design.

The architect uses the process to expose performance, scalability, security, usability, schedule, and budget concerns early. Missing one of these forces can produce software that implements visible features yet fails in the environment where users depend on it.
