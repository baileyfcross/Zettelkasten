# CSS Inline Vertical Alignment

The `vertical-align` property positions an inline or table-cell box relative to an alignment reference. Inline values can align a baseline, middle, text edge, subscript, superscript, or a length or percentage offset.

For inline elements, vertical alignment helps determine the height and contents of the line box; it does not vertically center an arbitrary block within its parent. Percentages are calculated from the element's [[CSS Line Height]].
