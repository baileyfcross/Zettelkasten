# Azure Stream Analytics

Azure Stream Analytics is a managed near-real-time engine that applies SQL-like queries to streaming inputs and sends transformed results to one or more outputs. It can filter, aggregate over time windows, join reference data, and detect conditions in Event Hubs or IoT streams. Query evaluation interval, event time, late arrival, partitioning, scaling units, and empty output behavior affect downstream semantics.
