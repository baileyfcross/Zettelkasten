# Unity Hub

Unity Hub is the launcher and management layer for Unity editor installations and projects. A single Hub can keep multiple editor versions, add platform modules to an installation, create a project from a template, and reopen existing projects.

Separating installation management from the editor matters because projects may depend on different engine releases or target platforms. The Hub makes those choices explicit before authoring begins, while the [[Unity Editor Workspace]] remains focused on the content of the open project.
