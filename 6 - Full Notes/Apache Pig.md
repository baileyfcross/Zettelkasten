# Apache Pig

Apache Pig is a high-level dataflow system for transforming large collections of semi-structured data in Hadoop-compatible storage. Its compiler turns [[Pig Latin]] operations into ordered MapReduce jobs and submits them for parallel execution.

Pig is suited to extract-transform-load pipelines, log processing, and custom analytics. It hides much of the job-level code while allowing [[User-Defined Function|user-defined functions]] for specialized transformations.
