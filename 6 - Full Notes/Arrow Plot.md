# Arrow Plot

An arrow plot places an oriented arrow at sampled positions in a [[Vector Field Map]]. Arrow direction encodes the vector's orientation and length commonly encodes magnitude. The display makes local measurements explicit but can become dense when every raster cell receives an arrow. Subsampling and a clear reference arrow help interpretation, while color or background context should not obscure the shafts and heads.
