# Azure Virtual WAN Secured Hub

An Azure Virtual WAN secured hub combines the managed Virtual WAN routing hub with Azure Firewall or a supported security provider. VNet, branch, VPN, and ExpressRoute connections can use the hub’s managed route propagation while security policy inspects selected public or private traffic. The service reduces custom hub routing work, but segmentation, default routes, firewall policy, regional placement, and the effect of routing intent remain design decisions.
