# Blender Local View Isolation

Local View temporarily isolates selected objects in a viewport so surrounding scene content no longer obstructs inspection or editing. Leaving Local View restores the wider scene without deleting or permanently hiding anything.

The isolation is a viewing state rather than a structural reorganization. It is useful for concentrating on a dense asset while preserving the object's actual relationships and placement in the complete scene.
