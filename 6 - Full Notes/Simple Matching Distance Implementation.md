# Simple Matching Distance Implementation

Simple matching distance for categorical records counts or aggregates components whose discrete values disagree. Equality is interpreted through each attribute's metadata rather than through the human-readable category strings.

The measure is appropriate when categories are unordered and mismatches have equal cost. It does not express that some category pairs are more similar than others unless the metadata or strategy is extended.
