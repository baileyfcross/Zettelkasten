# Clarification Question

A clarification question asks the user to distinguish among interpretations or supply a missing value. It converts uncertainty inside the assistant into a focused next turn.

Good clarification presents only the distinctions needed to proceed and preserves values already understood. It is a core recovery action in a [[Dialog Policy]], especially when [[Candidate Hypothesis Ranking]] leaves close alternatives.
