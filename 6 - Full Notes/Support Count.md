# Support Count

Support count is the number of transactions that contain a specified itemset. It is the raw frequency underlying both itemset support and association-rule evaluation.

Candidate generation methods use support counts to discard combinations that occur too rarely. Counting normally requires scanning the transaction data or maintaining an equivalent summary.
