# Visual Studio Watch Window

The Visual Studio Watch window repeatedly evaluates selected variables or expressions while execution is paused. It keeps important state visible across debugging steps without requiring the developer to hover over each value again.

Watching a small set of values can expose when an invariant first changes. Complex property evaluations may execute code, so they should be chosen carefully when side effects or evaluation cost matter.
