# Blob Container

A blob container is the named grouping that holds blobs inside an Azure Storage account. The photo application obtains a reference to a `photos` container before requesting the block blob corresponding to a local file name.

Container access policy determines whether content is private or anonymously reachable. Naming and permission therefore establish both the organizational and security boundary around the stored objects.
