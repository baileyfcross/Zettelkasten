# Visual Feature Representation

Visual feature representation converts an image or region into measurements that a learning algorithm can compare. A representation may be engineered from color, texture, and shape, or learned as a latent feature space from image data.

The choice determines which distinctions become easy for a model to detect. Handcrafted descriptors expose a defined visual property, while dimension-reduction and deep methods trade some direct interpretation for compact or task-adapted representations.
