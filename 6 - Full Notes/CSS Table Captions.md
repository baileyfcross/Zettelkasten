# CSS Table Captions

A table caption is a table-associated box that labels or describes the table. The `caption-side` property places it above or below the table box within the overall table wrapper.

The caption participates in width calculations for the wrapper but is not treated as one of the table's grid rows. It can receive ordinary block styling while retaining its structural relationship to the table.
