# Cloud-Based Collaboration

Cloud-based collaboration provides shared documents, messaging, email, conferencing, and other group communication through network-hosted services. It shifts the center of collaboration from software installed on one operating system to services reachable across devices and locations.

The model supports distributed work but makes provider dependency and shared information security central concerns. Independent backups and open file formats can reduce the cost of losing or changing the collaboration provider.
