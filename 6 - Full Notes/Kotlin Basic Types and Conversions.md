# Kotlin Basic Types and Conversions

Kotlin's basic value types include integer and floating-point numbers, Boolean values, characters, and strings. A declaration may name its type explicitly or let the compiler infer it from an initializer.

Numeric representations are not silently widened as if they were interchangeable. Conversion functions such as `toInt`, `toLong`, and `toDouble` make the requested target representation explicit. This preserves the difference between selecting a type and converting a value into that type.
