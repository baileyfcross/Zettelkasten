# Blender Extra Objects Add-On

Blender 2.7x's Extra Objects add-ons expanded the Add menu with parameterized mesh and curve generators. Examples included single vertices, rounded cubes, pipe joints, gears, diamonds, spirals, and torus knots.

Each generated form exposed creation parameters appropriate to its geometry, such as gear teeth or pipe divisions. The add-on therefore served as a starting-shape library rather than a collection of fixed assets, preserving procedural control immediately after creation.
