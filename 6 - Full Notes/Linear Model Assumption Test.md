# Linear Model Assumption Test

A linear model assumption test evaluates features such as skewness, kurtosis, link specification, and heteroscedasticity in a fitted model's residual behavior. A global test combines several diagnostics into one assessment.

With very large samples, small departures can yield extremely small p-values, so formal rejection should be interpreted with graphical evidence and the analysis goal. The test identifies inconsistency with assumptions; it does not automatically prescribe the best alternative model.
