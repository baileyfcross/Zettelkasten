# Address-Contents Distinction

In stored-program computing, an address names a memory location while its contents are the value held there. A program assignment changes the contents at a named location; it is a command rather than a statement of mathematical equality.

Novice programmers often confuse the name of storage with the stored value. Keeping address and contents distinct is essential for understanding variables, pointers, state changes, and machine execution.
