# Obvious Game Decision

An obvious game decision offers one option that is rationally superior to every alternative under the current conditions. Once the player recognizes it, choosing becomes routine execution rather than meaningful deliberation.

If the choice can be automated without changing the game state or intended experience, automation removes needless input. If the designer wants a real choice, the alternatives need different benefits, costs, risks, or future consequences so that none is universally best.
