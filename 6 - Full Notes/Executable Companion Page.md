# Executable Companion Page

An executable companion page links a publication to its code and data and provides an interface for running the computation remotely. A reader may reproduce the original settings, alter parameters, or supply new data without first installing the research software locally.

The page lowers the technical cost of verification and can provide persistent attribution, usage statistics, and suggested citations for the code. It should also permit downloading the underlying materials, because a locked interface limits inspection and extension. The page is one implementation of an [[Executable Research Publication]], not a replacement for transparent code, metadata, or licensing.
