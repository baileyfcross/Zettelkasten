# Libtool Portable Clustering Library

Libtool provides a portable interface for compiling, linking, installing, and using the ClusLib library across Unix-like environments. The build combines subject-specific convenience libraries into the final libClusLib library and handles platform differences in shared-library commands.

Examples can link against the Libtool archive without reproducing every object dependency. Portability still depends on correct compiler, header, and Boost-library discovery during configuration.
