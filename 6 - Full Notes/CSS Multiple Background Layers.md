# CSS Multiple Background Layers

CSS can paint several background images on one element by using comma-separated layer values. The first listed image is closest to the viewer, and later images are painted behind it above the background color.

Position, size, repetition, origin, clipping, and attachment lists are matched across the layers, repeating values when a list is shorter. The background color belongs only to the bottommost layer.
