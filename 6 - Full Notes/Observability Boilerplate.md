# Observability Boilerplate

Observability boilerplate is reusable code or configuration that implements common instrumentation and metadata practices. An SDK can expose standard metrics, sampling, exporters, and resource attributes so a service begins with supported behavior instead of a custom telemetry design.

Boilerplate lowers adoption cost but remains code that must be versioned, documented, tested, and upgraded. It should encode stable organizational standards while leaving clear extension points for the health and business indicators unique to one service.
