# Transitive Game Balance

In the source's terminology, transitive game balance is a circular relationship in which each type defeats some peers and is defeated by others, as in rock-paper-scissors. No one part dominates the whole system.

The structure uses an odd number of peer types so each can have a clear advantage over half and disadvantage against half of the others. External factors must still perturb the ecology enough to preserve strategy without producing a dominant path.
