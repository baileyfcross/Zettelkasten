# Incident Response Agent Roles

Incident response can be divided into focused agent roles: intake normalizes the alert, evidence collection gathers logs and telemetry, root-cause analysis identifies a fault domain, remediation drafts safe next steps, and communication prepares stakeholder updates. A practical workflow may consolidate these into pipeline, application-health, runbook, and commander roles.

Responsibilities should overlap as little as possible. Narrow roles produce smaller contexts and clearer output contracts, while a coordinator combines their evidence. Tools and credentials are then assigned by role so a communication agent does not inherit production access merely because another specialist needs telemetry.
