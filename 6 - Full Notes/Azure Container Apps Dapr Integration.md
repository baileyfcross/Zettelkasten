# Azure Container Apps Dapr Integration

Azure Container Apps can attach a managed Dapr sidecar to an application so code uses Dapr APIs for service invocation, publish-subscribe messaging, state, bindings, or secrets. Components map those abstractions to services such as Azure Service Bus. Dapr reduces provider-specific code and supplies resiliency features, but component scope, access policy, message semantics, and sidecar resource use still shape the system boundary.
