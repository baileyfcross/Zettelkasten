# Angular Reactive Form

An Angular reactive form defines controls, groups, values, and validation rules as an explicit model in component code. The template binds to that model instead of creating the model implicitly from markup.

This model-driven approach gives the developer direct control and a clearer separation between the application's data model and the [[Form Model]]. It also exposes observable value and status changes for validation and debugging.
