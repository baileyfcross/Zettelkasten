# Smart UV Project

Smart UV Project automatically separates mesh faces into islands according to angular relationships and packs them into texture space. It provides a fast starting layout for objects whose form does not suggest one simple cube, cylinder, or sphere projection.

Angle limit, island margin, area weighting, and aspect correction affect the result. Automatic output still requires inspection for overlap, stretching, wasted space, inconsistent scale, and seams placed in visually important regions.
