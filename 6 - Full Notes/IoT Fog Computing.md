# IoT Fog Computing

IoT fog computing distributes computation across intermediate nodes between devices and a centralized cloud. A fog node or [[IoT Gateway]] can serve several nearby devices, deciding where storage and processing should occur along a continuum from the physical endpoint to remote infrastructure.

Fog differs from a simple edge-to-cloud relationship because processing can migrate among multiple local and network resources rather than remain attached to one endpoint. This flexibility supports low-latency industrial systems and reduces dependence on a single cloud, but it also makes placement, coordination, security, and management more complex.
