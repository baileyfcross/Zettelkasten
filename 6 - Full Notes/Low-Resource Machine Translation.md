# Low-Resource Machine Translation

Low-resource machine translation addresses language pairs that lack the millions of aligned sentences expected by data-intensive systems. Scarcity is especially severe when neither language is English, when a language has little web presence, or when the target domain is confidential.

Possible responses include collecting comparable documents, exploiting monolingual text, routing through a [[Pivot Language Translation]], sharing representations across languages, or returning to dictionaries and hand-authored rules. None removes the underlying imbalance: quality tends to follow data availability, computational investment, and economic interest. A system that lists many supported languages may therefore provide radically different usefulness across them.
