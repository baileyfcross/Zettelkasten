# .NET Portability Analysis

.NET portability analysis compares an existing assembly's API use with the APIs available on proposed target platforms. The report identifies dependencies that are portable, unavailable, or require replacement before a .NET Framework codebase can move to .NET Core.

Technical possibility is only one part of a porting decision. A team must also consider application value, platform constraints, dependency support, migration effort, and whether maintaining the current system is safer than rewriting or moving it.
