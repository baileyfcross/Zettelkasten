# Shell Function

A shell function is a named block of shell commands executed in the current shell context. It packages one task behind a reusable name, reducing repeated code and allowing a larger script to be organized around explicit operations.

Functions must be defined or sourced before they are called. Because they share much of the caller's state, unqualified variable assignments can create hidden coupling; local variables and a clear status-and-output contract make reuse safer.
