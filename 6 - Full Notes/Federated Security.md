# Federated Security

Federated security lets an application rely on a trusted identity provider to authenticate a person or service and issue a token carrying identity claims. Several applications can accept that trusted identity, enabling a shared sign-on experience without each application managing a separate password store. The application must still validate the token and decide which resources the authenticated subject may use; delegated identity does not delegate every authorization decision.
