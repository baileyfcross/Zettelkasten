# Photovoltaic Array Sizing

Array sizing matches expected electrical load to site sunlight and generator efficiency. The source first sums each consumer's power multiplied by daily operating hours, then uses daily radiation and photovoltaic efficiency to estimate required [[Solar Array]] area and module count. Ambient temperature, network voltage, storage specification, and standby supply also affect the design; a peak-watt module rating alone is insufficient.
