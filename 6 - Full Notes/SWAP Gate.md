# SWAP Gate

The SWAP gate exchanges two qubit states, mapping every computational-basis input $|ab\rangle$ to $|ba\rangle$. Its operator can be constructed as

$$
|00\rangle\langle00|+|10\rangle\langle01|+|01\rangle\langle10|+|11\rangle\langle11|.
$$

Logically, SWAP changes where quantum information resides without changing its value. Physically, inserted SWAPs are a routing cost when a device allows a required two-qubit interaction only between neighboring locations.
