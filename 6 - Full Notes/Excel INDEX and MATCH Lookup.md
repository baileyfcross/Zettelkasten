# Excel INDEX and MATCH Lookup

An Excel INDEX and MATCH lookup separates finding a position from returning a value. MATCH locates a lookup value within a one-dimensional range and returns its relative position. INDEX then returns the item at that position from another range or array.

This combination can look to the left or right because the lookup and return ranges are independent. MATCH supports exact and approximate modes, so the chosen mode and any sorting requirement must be explicit. The ranges must align: position three in the lookup range must describe the same record as position three in the return range.
