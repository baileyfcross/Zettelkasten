# Analog Input Device

An analog input device reports a value over a range rather than a single on-or-off state. Thumbsticks, triggers, and motion sensors can express direction or intensity in addition to activation.

Raw values often contain noise or small unwanted deviations. [[Analog Input Filtering]] converts them into stable control values before gameplay interprets them.
