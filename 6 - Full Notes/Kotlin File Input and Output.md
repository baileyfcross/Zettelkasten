# Kotlin File Input and Output

Kotlin can use file functions to create a file, write or append text, read its contents, and delete it. Convenience operations such as reading an entire text value suit small inputs, while line-oriented or stream-oriented access better represents incremental work.

File I/O crosses from program memory into an external resource. Paths, permissions, encoding, existence, and possible failures must therefore be handled as part of the operation rather than assumed from the in-memory type alone.
