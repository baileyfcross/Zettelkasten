# Multi-Provider Cloud Backup

Multi-provider cloud backup keeps recovery copies with a provider different from the one holding the primary cloud data, or distributes backup tiers among several providers. This reduces the chance that one outage, business failure, or account problem removes both production data and its recovery copy.

The services need enough interoperability for automated transfer and restoration. Encryption, credentials, egress time, retention, and the ability to recover without the primary provider should all be tested.
