# TypeScript

TypeScript is a Microsoft-created superset of JavaScript that adds type checking, class and type declarations, and object-oriented language features during development. Its source is transpiled into standard JavaScript that browsers can execute.

Angular uses TypeScript for components, services, modules, and tests. The generated JavaScript can retain a connection to its source through a [[JavaScript Source Map]], allowing client-side debugging at the TypeScript level.
