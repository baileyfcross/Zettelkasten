# Repeated Characteristic Root

A repeated characteristic root occurs when the auxiliary polynomial of a linear constant-coefficient differential equation has the same root more than once. A single exponential associated with that root does not supply enough independent modes for the equation's order.

For a root $\lambda$ repeated twice, the independent solutions are $e^{\lambda x}$ and $xe^{\lambda x}$. Higher multiplicity continues the pattern with successive powers of $x$, ensuring that the complementary function still contains the required number of arbitrary constants.
