# Sverchok Parametric Node Modeling

Sverchok expresses parametric geometry as a node network inspired by visual procedural systems. Input nodes introduce values or geometry, intermediate nodes transform and combine the data, and output nodes create or update scene results.

The node chain separates a form's generating logic from one particular result. Reusing the graph with new parameters makes it possible to explore related structures without repeating every modeling operation.
