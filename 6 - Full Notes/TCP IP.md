# TCP IP

TCP/IP is the protocol suite that connects heterogeneous networks into the Internet. TCP manages reliable end-to-end data exchange, while IP addresses and routes individual packets across intervening networks.

Separating these responsibilities lets local networks use different technologies while presenting a common internetwork service. The suite has remained the Internet’s technical foundation since ARPANET adopted it.
