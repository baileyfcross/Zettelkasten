# Information Processing

Human information processing is the cycle through which a person senses and interprets stimuli, uses memory and [[Cognition]] to choose a response, performs an action, and perceives resulting [[Feedback]].

Information changes form during this cycle, and each transformation takes time and can introduce errors. [[Attention]] controls which information receives further processing. [[Working Memory]] temporarily holds attended information, while [[Long-Term Memory]] supplies learned concepts, procedures, and past experience.

In interface design, processing time and errors are major contributors to user performance.
