# Godot Cross-Platform Export

Godot is designed to author one project and export it to multiple desktop, mobile, web, and console targets supported by the engine's toolchain. The editor also combines scripting, debugging, profiling, and error logging around that project.

Cross-platform engine support does not remove asset budgets. Mesh complexity, texture size, shader features, and post-processing still need target-specific validation, connecting engine export back to [[Target Hardware Polygon Budget|environment optimization]].
