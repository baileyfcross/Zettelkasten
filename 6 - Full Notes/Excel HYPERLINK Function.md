# Excel HYPERLINK Function

The Excel HYPERLINK function creates a clickable link to a web address, file, email destination, or location inside a workbook. It accepts the destination and an optional friendly label, allowing displayed text to remain readable while the underlying target contains a long address.

Internal links can turn an index or summary sheet into navigation for a large workbook. Link targets should be constructed carefully because moved files, renamed sheets, or malformed addresses can leave a formula that displays normally but leads nowhere. Friendly text should describe the destination rather than hide its purpose.
