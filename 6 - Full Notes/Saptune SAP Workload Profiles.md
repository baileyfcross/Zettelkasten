# Saptune SAP Workload Profiles

Saptune applies and checks operating-system tuning recommendations for SAP workloads through named solutions and notes. It translates the selected SAP guidance into host parameters and can report whether the current system conforms to the expected settings.

A profile is a managed baseline, not proof of application correctness. The selected solution must match the deployed SAP product and host role, and local exceptions should be documented rather than silently overwriting the expected state. Verification after updates helps detect drift between the configured recommendation and the running system.
