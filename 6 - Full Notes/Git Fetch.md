# Git Fetch

`git fetch` downloads objects and updates remote-tracking references without integrating them into the current branch. It lets a developer inspect the remote history before deciding how to combine it with local work.

This separation distinguishes fetch from [[Git Pull]]. After fetching, an explicit merge, rebase, or other comparison can be performed with the now-current remote-tracking branch.
