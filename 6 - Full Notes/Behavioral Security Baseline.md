# Behavioral Security Baseline

A behavioral security baseline represents the expected activity of users, devices, applications, or networks. Security analytics can compare new observations with this model to identify deviations that may indicate misuse or compromise.

Because legitimate behavior changes, a baseline must adapt without learning an attack as normal. It provides the reference point for [[Cybersecurity Anomaly Detection]] and complements known-pattern defenses.
