# Cluster Feature Vector

A cluster feature vector is a compact triple containing the number of points, their linear sum, and their squared sum. These sufficient summaries can be combined by addition and support centroid, radius, and dispersion calculations without retaining every original point at each tree node.

BIRCH uses the vector to summarize subclusters while scanning a large data set.
