# Vehicular Cloud Network

A vehicular cloud network interconnects participating vehicles with coordinators, storage, and external services. Wireless links support mobility but can be bandwidth-constrained and variable; wired parking-lot connections can provide stable high throughput.

Topology and bandwidth determine whether the cloud can move virtual-machine state and big datasets quickly enough for useful computation.
