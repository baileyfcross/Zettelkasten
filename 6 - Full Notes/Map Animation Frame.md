# Map Animation Frame

A map animation frame is one rendered spatial state in an animated sequence. Every frame should share projection, extent, legend limits, layout, and contextual layers so that the changing variable is the principal difference. File names need a sortable sequence for reliable concatenation. When frames differ excessively in content, viewers lose correspondence and the sequence no longer communicates a continuous evolution.
