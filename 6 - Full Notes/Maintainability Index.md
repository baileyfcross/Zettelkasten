# Maintainability Index

The maintainability index combines code measurements such as complexity, volume, and size into a comparative score intended to signal how difficult code may be to maintain. Visual Studio can calculate it for assemblies, namespaces, types, and members.

The score is an indicator rather than proof of quality. A low value identifies code worth examining, while a high value cannot establish that behavior, naming, boundaries, or requirements are correct.
