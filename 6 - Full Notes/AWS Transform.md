# AWS Transform

AWS Transform is an agentic-AI service for planning and accelerating large modernization tasks, including changes to legacy application platforms and VMware environments. It analyzes the workload, coordinates transformation steps, and assists with code or configuration changes rather than acting only as a question-answering assistant. Modernization output still requires business-context review, testing, security validation, and controlled deployment before it becomes a production replacement.
