# Azure Cloud-Native Security Model

An Azure cloud-native security model integrates identity, policy, automation, telemetry, and remediation throughout a workload’s lifecycle. It assumes that resources and deployments change continuously, so repeatable guardrails and feedback are more dependable than occasional manual reviews. Identity becomes a primary control plane, while defense in depth still spans data, network, compute, applications, and operations. The model also treats security responsibility as shared across architecture, development, platform, and response teams.
