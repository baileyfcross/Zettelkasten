# XML Documentation Comments

C# XML documentation comments attach structured descriptions to functions and other members. Elements can summarize behavior, explain parameters and return values, and describe exceptional conditions.

Development tools read this metadata to display richer call-site help, reducing the need to open the implementation to understand its contract. Documentation is most useful when it states meaning and constraints that the type signature cannot express, rather than merely repeating member names.
