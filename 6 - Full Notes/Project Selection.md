# Project Selection

Project selection chooses which proposed investments or subprojects an organization will actually run. The decision compares expected value, cost, risk, dependency, strategic fit, and the capital unavailable for alternatives.

A portfolio method need not select every component. Omitting a low-value subproject can improve the return of the remaining feasible big-data program.
