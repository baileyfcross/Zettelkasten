# Mixed-Initiative Dialog

Mixed-initiative dialog allows both the user and assistant to steer the interaction. The assistant can ask for needed information, while the user can volunteer values, correct assumptions, change goals, or request help.

It combines the task control of [[Directed Dialog]] with the flexibility of [[Open Dialog]]. The [[Dialog Manager]] must accept relevant information even when it arrives outside the anticipated order.
