# Angular Workspace

An Angular workspace is the project-level structure containing client source, build configuration, package metadata, TypeScript settings, and testing configuration. Files such as `angular.json`, `package.json`, and `tsconfig.json` govern different parts of that toolchain.

Within a combined ASP.NET Core template, the workspace lives under the client application folder, while its compiled static output is served through the back-end project.
