# Date Difference

A date difference is the elapsed time between two parsed dates, often expressed in days. It can measure follow-up from an index event to a reference date or help determine whether a later event falls inside a predefined observation window.

The operation is meaningful only after both operands have valid date classes and a clear temporal interpretation. A fixed calendar censoring date and a subject-specific window, such as sixty days after discharge, answer different questions.
