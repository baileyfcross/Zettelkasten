# Helidon Command-Line Interface

The Helidon Command-Line Interface is a standalone executable for generating, building, inspecting, and running Helidon projects. Its commands include `init`, `build`, `dev`, `info`, and `version`, and the tool is distributed for Linux, macOS, and Windows.

During project initialization, the CLI guides the developer through the Helidon version, SE or MP flavor, quickstart, database, or custom application type, JSON media library, and Maven coordinates. The result retains the same deployable project structure as a corresponding [[Helidon Quickstart Archetype]].
