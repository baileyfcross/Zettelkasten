# Microsoft Azure

Microsoft Azure is the cloud platform used in the book to host the React client, ASP.NET Core API, and SQL database. These parts are created as related resources and configured with their deployed URLs and environment-specific values.

The platform changes where the system runs, not the contracts among its parts. Routing, cross-origin access, authentication settings, database connectivity, and build artifacts must all match the hosted environment.
