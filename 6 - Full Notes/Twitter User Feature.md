# Twitter User Feature

A Twitter user feature comes from an account's profile and accumulated activity. Description text, account age, follower and friend counts, list membership, and posting totals can characterize the source of a post.

These variables add context beyond one message. They can also reflect popularity or longevity rather than the target itself, so interpretation and temporal availability matter.
