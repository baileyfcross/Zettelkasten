# UML Class Diagram

A UML class diagram is a structural model of classes, their attributes and operations, and the relationships among them. It can guide implementation or document an existing object model by making important responsibilities and dependencies visible at a glance.

Each class is commonly drawn with separate name, attribute, and operation areas. Lines and endpoint symbols distinguish generalization, association, aggregation, composition, and dependency rather than treating every connection as equivalent.
