# DBSCAN Border Point

A DBSCAN border point has fewer than MinPts observations in its own Eps neighborhood but lies within the neighborhood of a core point. It belongs to a cluster without being able to initiate further dense expansion.

Its assignment can depend on which adjacent cluster reaches it first when dense regions are close.
