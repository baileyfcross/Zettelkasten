# Zero Divisor on a Module

An element r of the base ring is a zero divisor on a module M when rm = 0 for some nonzero m ∈ M. The definition generalizes a [[Zero Divisor]] in a ring.

Over a Noetherian ring, the set of zero divisors on M is the union of its [[Associated Prime]]s. An element is M-regular precisely when it is not a zero divisor on M.
