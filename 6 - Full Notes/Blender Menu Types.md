# Blender Menu Types

Blender uses several menu forms to balance discoverability with limited screen space. Header menus organize an editor's principal commands, select menus choose one value from a defined set, popovers expose temporary settings, context menus respond to the item under the pointer, and pie menus arrange actions radially around the cursor.

Collapsing menus recover horizontal space, while special menus collect context-sensitive operators. The distinction matters because the same action may appear differently depending on the active editor, object type, and mode. Reading the menu form and current context helps explain why an operation is available in one workspace but absent or disabled in another.
