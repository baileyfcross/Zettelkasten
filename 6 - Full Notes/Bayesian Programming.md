# Bayesian Programming

Bayesian programming is a methodology for constructing and using probabilistic models as executable programs. The modeler specifies variables, conditional structure, and mathematical forms, identifies remaining parameters from data, and asks a conditional probability question.

The approach separates modeling from inference algorithms. One description can support simulation, prediction, diagnosis, classification, or control depending on which variables are searched, known, and marginalized.
