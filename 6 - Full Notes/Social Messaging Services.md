# Social Messaging Services

A social messaging service centers interaction on direct or group conversations, often adding voice, video, file sharing, bots, and community spaces. The book groups WhatsApp, Facebook Messenger, Telegram, Discord, and Viber under this model rather than treating every social platform as a public feed.

Messaging integrations usually depend on event delivery as well as outbound API calls. A business may send text or media through a service API and receive webhooks when a user acts or a message changes status. [[WhatsApp Business Java SDK]] illustrates that pattern, while [[Java Discord Client Libraries]] shows how different Java wrappers expose a real-time community platform.
