# EXIF Metadata

EXIF metadata use the Exchangeable Image File Format to record camera-generated information within an image file. Common fields include device identity, aperture, shutter speed, ISO, focal length, time, orientation, GPS location, and details of any software that last saved the image.

An analyst can compare these fields with visible properties such as depth of field, motion blur, illumination, or claimed location. Missing EXIF data are common after export or online sharing, so absence alone is not evidence of manipulation.
