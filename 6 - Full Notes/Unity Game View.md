# Unity Game View

The Unity Game view previews the image produced by active cameras when the project runs. It is the player-facing result of scene geometry, camera settings, lighting, user interface, and runtime scripts rather than a free-form authoring viewport.

Play mode makes the Game view interactive, but changes made during play are generally temporary and revert when play stops. It is therefore best used as a fast feedback surface: test behavior, observe the result, stop, and then make durable edits through the Scene view or [[Unity Inspector]].
