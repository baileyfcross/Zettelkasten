# Blender Armature Object

An armature object stores a hierarchy of bones used to pose and deform other objects. The armature provides the transformable control structure, while vertex groups and modifiers determine how a mesh follows those bones.

Keeping the rig separate from render geometry allows animation to be edited without rebuilding the surface. Export settings must preserve the needed hierarchy, deformed bones, and actions when the asset moves into a game engine.
