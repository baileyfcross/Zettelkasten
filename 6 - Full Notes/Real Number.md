# Real Number

A real number is any [[Rational Number]] or [[Irrational Number]]. The real numbers fill the [[Number Line]]: each point corresponds to a real value, and order corresponds to position from left to right.

Elementary algebra generally treats variables as real unless another domain is specified. The real-number system supports addition, subtraction, multiplication, and division by nonzero values, along with order comparisons. Restrictions still matter; for example, a denominator cannot equal zero, and an even root is not a real number when its radicand is negative.
