# CSS Repeating Grid Tracks

The grid `repeat()` function expresses a recurring track pattern without rewriting every size. A fixed repetition count creates a known sequence, while automatic filling or fitting can repeat a pattern according to available container space.

The repeated fragment can include named lines as well as track sizes. This makes regular column or row systems compact while retaining addressable placement lines.
