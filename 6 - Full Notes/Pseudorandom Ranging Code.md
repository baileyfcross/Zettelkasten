# Pseudorandom Ranging Code

A pseudorandom ranging code is a deterministic bit sequence chosen to resemble random noise while remaining exactly reproducible by a receiver. Each satellite uses an identifiable code, allowing several weak signals to occupy the same carrier band with limited mutual interference. The receiver slides a local copy of a code until it correlates with the received sequence. That alignment both identifies the satellite and exposes the signal delay used for ranging.
