# AWS Retain Migration

Retaining keeps a workload in its current environment for the present. Valid reasons include limited remaining life, migration complexity, latency dependencies, regulatory constraints, or insufficient near-term business value. Retain is an explicit portfolio decision rather than an unnoticed omission: its rationale and review point should remain visible because changing requirements may later make another [[AWS Seven Rs Migration Strategy|migration disposition]] appropriate.
