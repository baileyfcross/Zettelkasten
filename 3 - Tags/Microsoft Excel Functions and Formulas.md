# Microsoft Excel Functions and Formulas

Microsoft Excel Functions and Formulas is the chapter-level topic for building, interpreting, and auditing spreadsheet calculations in Excel 2019 and Office 365. Full Notes should link to one of the focused child topics rather than directly to this chapter tag.

## Overview Chapter

An Excel workbook becomes a computational model when cells contain formulas rather than isolated values. [[Excel Formula Foundations]] explains the grammar of that model. A formula begins with an equals sign, combines operators, constants, functions, and references, and recalculates when its precedents change. Cell ranges let one expression address a block of data. Relative references move when a formula is copied, absolute references remain fixed, and mixed references anchor only a row or column. These reference modes make filling a formula across a table reliable. Excel also stores dates and times as serial numbers, separates underlying values from display formats, and uses ordinary arithmetic for percentages, elapsed time, and unit conversions. The model is therefore both mathematical and spatial: meaning depends on the calculation and on how references behave when moved.

[[Excel Logical Text and Date Functions]] turns raw worksheet values into decisions, labels, and schedules. AND, OR, and XOR combine conditions, while IF selects results and IFS or SWITCH organizes multiple branches. IFERROR replaces an expected calculation failure with a controlled result. Text functions extract substrings, find patterns, replace or clean characters, and join fields into readable output. Date functions construct, decompose, and compare calendar values; workday functions exclude weekends and holidays; month functions move among reporting periods. Because dates are numeric underneath, these operations can be combined with arithmetic while still being displayed in familiar calendar and clock formats.

[[Excel Statistical and Forecast Functions]] summarizes a dataset and uses its history to estimate future values. Extrema, ordered values, counts, ranks, medians, quartiles, and standard deviation answer different questions about position and spread. Conditional extrema narrow those summaries to records satisfying chosen criteria. Linear forecasting extends a straight-line relationship, while exponential smoothing forecasting models recurring seasonal patterns and can report confidence intervals and detected seasonality. CORREL measures the direction and strength of a linear relationship, but its coefficient describes association rather than proving a causal mechanism.

[[Excel Mathematical and Conditional Aggregation]] covers the functions that combine, round, classify, and sample numeric data. SUM provides the basic total; conditional aggregation functions apply one or several criteria; SUMPRODUCT performs elementwise multiplication followed by aggregation and can express compact conditional calculations. Rounding functions differ in whether they target decimal precision, a chosen multiple, or a required direction. Integer division and remainder functions reveal cycles and group positions, ROW and COLUMN expose worksheet coordinates, SUBTOTAL can ignore filtered-out records, and random functions generate volatile samples that must be converted to values when a fixed draw is required.

[[Excel Financial Database and Lookup Functions]] connects formulas to structured business questions. Financial functions express depreciation schedules, present and future value, periodic payments, and implied rates, with careful attention to cash-flow signs and period-compatible rates. Database functions operate on a table whose first row contains field names and whose separate criteria range describes which records qualify. Lookup and reference functions then retrieve or construct connections across tables: VLOOKUP and HLOOKUP search fixed orientations, INDEX with MATCH separates position-finding from retrieval, and LOOKUP supports approximate searches. INDIRECT converts text into a reference, OFFSET moves or resizes a reference, HYPERLINK creates navigable destinations, and CHOOSE selects from an indexed list.

[[Excel Formula Analysis and Automation]] extends calculation into visual diagnosis, constrained input, scenario analysis, and reusable code. Formula-based conditional formatting can reveal duplicate values, missed deadlines, or time spans such as Gantt bars. Legacy array formulas perform several calculations at once and require Ctrl+Shift+Enter in the book's Excel versions; TRANSPOSE and FREQUENCY are important array-oriented examples. Data validation rejects unacceptable input, named ranges make references readable, and Goal Seek finds an input that produces a chosen output. VBA macros can inspect formulas, replace formulas with values, inventory workbook logic, and define worksheet-callable functions. These capabilities are powerful precisely because they alter or expose model behavior, so they should be tested on copies and documented.

Taken together, the six topics present Excel as a layered modeling environment. Reliable work begins with reference semantics, proceeds through transformation and aggregation, connects tables through explicit criteria and lookups, and ends with tools that expose or automate the model. Function availability and array behavior vary by Excel version, so a workbook should record assumptions about its target version. Good formulas are not merely correct on the current data: they remain understandable when copied, auditable when results look wrong, and robust when the workbook grows.
