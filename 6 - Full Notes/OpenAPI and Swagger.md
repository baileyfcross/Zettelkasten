# OpenAPI and Swagger

OpenAPI describes an HTTP API's operations, parameters, payload schemas, responses, and other contract details in a machine-readable document. Swagger tooling can generate that description from an ASP.NET Core API and present an interactive interface for exploring endpoints.

The document improves discovery and can drive client generation, but it must accurately reflect runtime behavior. Response types, status codes, and schema annotations should therefore be maintained as part of the API contract rather than treated as incidental documentation.
