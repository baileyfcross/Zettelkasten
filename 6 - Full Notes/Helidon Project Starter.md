# Helidon Project Starter

Helidon Project Starter is a web application that generates a customized Helidon project. It presents the same principal choices as the CLI—Helidon flavor, application type, JSON media support, and project coordinates—through a guided graphical interface.

The downloaded ZIP expands into a project with Maven configuration, Java sources, tests, runtime configuration, Dockerfiles, and Kubernetes configuration. It is therefore an alternate project-generation front end rather than a different application architecture.
