# Sequential Text Window Analysis

Sequential text window analysis estimates a corpus statistic in successive contiguous segments rather than in random samples. Moving through the original order reveals where vocabulary growth, rank-frequency parameters, or stylistic patterns change across a document or collection.

The comparison with random windows helps separate local structure from ordinary sampling variation. Window size and overlap control the resolution, and a change in a fitted parameter is evidence of distributional variation rather than automatic proof of authorship or cause.
