# Angular Momentum

Angular momentum describes rotational motion. For a point particle about an origin, $L=r\times p$; for a rigid body rotating about a fixed principal axis, $L=I\omega$. The resultant external [[Torque]] equals $dL/dt$, making angular momentum the rotational counterpart of linear momentum.
