# Cold-Start Problem

The cold-start problem occurs when a recommender lacks enough interactions for a new user or item to estimate useful preferences. A new user with no target-domain posts leaves conventional collaborative evidence unavailable.

Social connections and activity in auxiliary domains can reduce the gap. [[Cross-Domain Recommendation]] transfers that evidence while the target-domain history develops.
