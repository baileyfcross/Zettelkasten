# COMSOL Thermal Plot Groups

One-, two-, and three-dimensional plot groups organize compatible result features for curves, contours, surfaces, slices, arrows, and isosurfaces. Each group references a data set and can combine field magnitude with flow direction or geometric context.

A plot should be designed around a claim rather than decorated with every available layer. Labels, units, range, viewpoint, and [[Thermal Result Scale Selection|color scale]] determine whether the visualization exposes thermal behavior or conceals it.
