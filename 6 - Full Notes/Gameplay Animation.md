# Gameplay Animation

Gameplay animation uses motion to communicate the state, character, and relationships of game objects. Speed, rhythm, direction, and posture can make an object appear aggressive, cautious, vulnerable, or important.

Animation also acknowledges input and state changes. A pushing motion can confirm that movement input was received even when a wall blocks progress, while blinking or color flashing can indicate temporary invulnerability or a successful hit.
