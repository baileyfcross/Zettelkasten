# World Wide Web

The World Wide Web is an information system that runs over the Internet and links resources through hypertext. Tim Berners-Lee and Robert Cailliau developed it at CERN to let diverse research groups share material across incompatible computers.

Open software and simple standards allowed the system to spread rapidly. The Web should be distinguished from the Internet infrastructure that transports its requests and files.
