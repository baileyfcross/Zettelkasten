# Cloud Robotics

Cloud robotics connects a physical robot to remote computation, shared data, external sensors, or learned knowledge over a network. Offboard resources can perform processing too expensive for the robot's onboard power and heat budget, while multiple robots can benefit from common maps or experience.

The connection also introduces latency, outages, bandwidth limits, privacy concerns, and dependence on infrastructure. Safety-critical local behavior cannot assume the cloud will always answer. Cloud robotics therefore divides capability between an autonomous edge that can remain safe and a remote layer that expands computation and coordination.
