# Active Challenge

An active challenge requires special mechanics to implement and determine whether the player has overcome it. Enemies, puzzles, and dynamic hazards actively participate in the test.

Because the system evaluates progress and success, the challenge needs explicit state and behavior. This differs from a [[Passive Challenge]] whose difficulty comes from a static arrangement.
