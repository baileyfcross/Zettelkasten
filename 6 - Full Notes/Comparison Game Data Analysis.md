# Comparison Game Data Analysis

Comparison game data analysis isolates two or a few objects and places their attributes side by side. A spreadsheet can use validated object selectors and lookups to make the comparison reusable, then calculate attribute differences, normalized positions between minimum and maximum, or charts tailored to the design question.

Reducing the view from an entire catalog to a small set permits more detailed reasoning about tradeoffs and identity. The most useful comparisons depend on the game: the tool should highlight relationships that affect play rather than produce detail for its own sake.
