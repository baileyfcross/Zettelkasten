# Gaussian Copula Graphical Model

A Gaussian copula graphical model assumes that monotone transformations of the observed variables are jointly Gaussian. Because coordinatewise one-to-one transformations preserve conditional-dependence structure, the transformed precision matrix can represent the graph of the original variables.

The transformations may be estimated from marginal distributions, or the latent correlation can be estimated from ranks before applying Gaussian graph procedures. This extends [[Gaussian Graphical Model|Gaussian graphical modeling]] beyond Gaussian marginals while retaining a strong structural assumption: the dependence after transformation must still be Gaussian.
