# SAS Data Step

The SAS data step is a procedural language for creating or editing datasets one observation at a time. SAS implicitly loops through qualifying rows, applies the statements in the step, and writes the resulting observations to one or more output datasets.

Because execution is record-oriented, sorting and careful code design can strongly affect performance. The data step is powerful but differs conceptually from R's object operations and from declarative query systems, which specify a result while leaving execution planning to an optimizer.
