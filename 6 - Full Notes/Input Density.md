# Input Density

Input density is the amount of meaningful interaction expressed through a compact [[Physical Input Layer]]. A single button can represent several related phases when pressing, holding, and releasing it each have a clear role.

Dense input can reduce hand movement, mispresses, and memorization while keeping important [[Game Verb|verbs]] prominent. Density is useful when the mappings remain coherent; compressing unrelated actions onto one control can instead make the system harder to predict.
