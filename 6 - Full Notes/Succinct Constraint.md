# Succinct Constraint

A succinct constraint lets eligible items be selected directly before candidate generation. Conditions such as an item's category or value belonging to a specified range can reduce the transaction representation and the pattern search space immediately.

This property is valuable in distributed mining because it avoids communicating and processing items that cannot appear in a valid result.
