# XAML Data Binding

XAML data binding connects a target property in the interface to a value exposed by a data source. The binding specifies a path and direction and may apply conversion or formatting as values move between source and target.

Binding reduces code that manually copies state into controls. For the interface to reflect later source changes, the bound object must provide the framework's expected change-notification behavior.
