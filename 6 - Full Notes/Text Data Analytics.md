# Text Data Analytics

Text data analytics is a collection of techniques, tools, and methodologies for studying large datasets of unstructured natural language. It ranges from automated methods that treat words as discrete observations to approaches that preserve relationships among language, meaning, and context.

There is no single correct method for every corpus. The research question, data form, linguistic variation, and need for interpretation determine whether [[Text Data Mining]], [[Corpus Linguistics]], manual analysis, or a combination is appropriate.
