# Azure Platform Architect

An Azure platform architect builds automated, CI/CD-driven cloud platforms that let application teams deliver through standardized self-service paths. The role extends infrastructure architecture with DevOps, GitOps, container orchestration, reusable templates, policies, and developer experience. Its output is not only a shared environment but an operating product whose interfaces, upgrades, guardrails, and feedback loops are owned over time.
