# Azure Non-Functional Requirement Roadmap

An Azure non-functional requirement roadmap sequences reliability, security, performance, observability, governance, and delivery improvements across planned releases. Each item should state the current capability, target maturity, accountable owner, dependency, and accepted interim risk. This keeps a first implementation from being presented as finished architecture while avoiding an unrealistic demand to solve every cross-cutting concern before any business value is delivered.
