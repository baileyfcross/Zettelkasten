# Unity Project View

The Unity Project view exposes the durable files and resources available to a project. Its Assets area mirrors the project's Assets folder on disk, while its Packages area shows installed modules and dependencies managed outside that folder.

A resource appearing in the Project view does not mean it exists in the current [[Unity Scene]]. It is an [[Unity Asset]] that can be organized, searched, configured, or placed into scenes. Moving project content through the editor helps Unity preserve the identity and references that connect assets.
