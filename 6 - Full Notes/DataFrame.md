# DataFrame

A DataFrame is a distributed collection organized into named columns with known structure. The schema gives a query optimizer more semantic information than an opaque collection of application objects.

In Spark SQL, DataFrame operations and relational queries can share an optimized execution plan while remaining connected to the broader Spark runtime.
