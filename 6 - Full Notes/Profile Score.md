# Profile Score

A profile score is one judge's rating of one profile case. A set of profile scores forms the criterion vector that a policy-capturing regression attempts to predict from the case attributes.

Scores must be collected across enough varied profiles to reveal the judge's weighting policy. Repeated profiles can also provide evidence about the stability of the judgments.
