# AWS Three-Phase Migration Process

AWS groups a migration program into assess, mobilize, and migrate and modernize. Assessment inventories the estate, evaluates readiness, and builds a business case. Mobilization closes gaps in skills, governance, accounts, landing zones, and dependency knowledge. The final phase moves workload waves with tools such as [[AWS Application Migration Service]] and then improves the migrated systems. The phases separate decision evidence, operational preparation, and execution while allowing learning to feed later waves.
