# AWS CDK Construct

An AWS CDK construct is a reusable component that represents one or more cloud resources and their configuration. Low-level constructs closely mirror individual CloudFormation resources, while higher-level constructs can encode defaults, relationships, and an organization’s preferred architecture. Composing constructs lets platform knowledge become executable code, but safe reuse depends on documenting assumptions and versioning changes that affect downstream stacks.
