# Excel AND Function

The Excel AND function tests several logical conditions and returns TRUE only when every condition is true. It is useful for requirements that must all be satisfied, such as a value falling between a lower and upper boundary or a record meeting both a date and status criterion.

AND commonly supplies the logical test inside an [[Excel IF Function]] or a formula-based conditional formatting rule. Because one false condition makes the complete result false, each condition should be inspectable on its own when debugging. AND expresses intersection: it narrows a result to records belonging to all specified sets.
