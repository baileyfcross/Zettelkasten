# CSS Clip Fill Rules and Reference Boxes

Clipping can use a reference box such as the margin, border, padding, or content box as the coordinate boundary for a basic shape. This determines the rectangle against which percentages and shape positions are resolved.

When a path crosses itself or encloses overlapping regions, a fill rule determines which areas count as inside. Nonzero and even-odd rules use different methods to classify those regions.
