# Java Shebang Source File

A Java source-launch file can use a Unix shebang line to select the Java launcher and behave like an executable command-line script. The operating system reads the interpreter directive, while Java compiles and runs the source without a separately managed class-file step.

This is a deployment convenience for a small source program, not a separate Java language. The file still obeys the source-launch rules and can use the same direct-execution path as [[Java Source-File Launch Mode]].
