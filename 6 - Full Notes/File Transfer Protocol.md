# File Transfer Protocol

The File Transfer Protocol is an application-layer protocol for remote directory operations and file transfer. It uses a command connection to authenticate and negotiate an operation and a separate data connection to carry directory listings or file contents.

Active and passive modes differ in which endpoint opens the data connection. Because ordinary FTP does not protect credentials and content, use over an untrusted network requires a secure alternative.
