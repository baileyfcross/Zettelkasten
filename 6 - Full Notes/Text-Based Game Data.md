# Text-Based Game Data

Text-based game data stores configuration or content in a human-readable character format such as INI, XML, or JSON. Developers can inspect and edit it with ordinary tools, and source-control diffs can show meaningful line-level changes.

Parsing text consumes more time and storage than a compact binary representation, and a schema or validation layer is needed to catch missing, misspelled, or incorrectly typed values.
