# Blender Empty Object

An empty has a transform and viewport display but no renderable surface. It can mark a location, rotation, scale, image reference, relationship pivot, or organizational point without adding visible geometry.

Because empties can parent other objects, they provide a lightweight control for moving an asset group or establishing an export hierarchy. Their meaning must be communicated by naming and display shape because the object itself contributes no rendered appearance.
