# COMSOL Boolean Geometry Operations

COMSOL Boolean geometry operations create new entities from spatial relationships among objects. Union joins regions, intersection retains their common portion, difference subtracts one object from another, and composition combines several objects according to a declared expression.

The operation can preserve or discard input objects and interior boundaries. That choice affects whether the result behaves as one domain or as connected subdomains available for separate materials, meshes, or physics.
