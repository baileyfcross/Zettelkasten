# Java Conditional Operator

The Java conditional operator has the form `condition ? valueIfTrue : valueIfFalse`. It evaluates the boolean condition and then exactly one of its two alternative expressions, producing a value that can participate in a larger expression.

It is useful for a small selection where both branches naturally yield the same or a compatible type. Nested or side-effect-heavy conditional expressions can obscure flow and are better written as an `if-else` statement. The operator is sometimes informally called ternary because it has three operands.
