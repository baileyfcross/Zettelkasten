# CSS Relative Length Units

Relative CSS lengths are measured against another value. `em` relates to an element's font size, `rem` to the root font size, `ex` and `ch` to font metrics, and viewport units to percentages of the viewport's width or height.

Because the reference can change with typography or screen dimensions, relative units support adaptable sizing. Their final effect may remain unresolved until the browser knows the relevant font metrics or containing geometry.
