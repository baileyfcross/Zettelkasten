# Multiplication Property of Inequality

The multiplication property of inequality depends on the sign of the common multiplier. If (a<b) and (c>0), then

$$ac<bc.$$

Multiplication by a positive value scales both positions without changing their order. If (c<0), the order reverses:

$$ac>bc.$$

Division follows the same rule because it multiplies by a reciprocal. This sign-sensitive behavior is the key difference between solving inequalities and solving equations.
