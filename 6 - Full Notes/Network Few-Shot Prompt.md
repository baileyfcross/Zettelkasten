# Network Few-Shot Prompt

A network few-shot prompt includes examples of acceptable input and output before presenting the new case. Existing interface descriptions, device templates, naming conventions, or configuration fragments show the model the local pattern more concretely than a general instruction can.

Examples should be representative, sanitized, and internally consistent. A model may copy an accidental address, platform assumption, or insecure convention embedded in them. The new result therefore requires comparison with both the stated rule and the live environment; similarity to an example is not itself correctness.
