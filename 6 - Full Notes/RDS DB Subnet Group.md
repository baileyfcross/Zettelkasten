# RDS DB Subnet Group

An RDS DB subnet group names subnets in which Amazon RDS may place database network interfaces. A resilient group spans at least two availability zones so a standby or replacement can occupy another zone.

The subnets are commonly private and reachable only from authorized application security groups. The group defines placement options; route tables and security controls still determine connectivity to clients and administrative services.
