# Software as Equal to Hardware

A general-purpose computer can perform radically different work only through the procedures that direct it. This gives software a status equal to hardware, unlike a classical machine whose operating procedure is tied to one physical purpose.

Early designers underestimated the effort required to create and maintain programs. As applications expanded, programming languages, operating systems, and reusable libraries became major technologies in their own right.
