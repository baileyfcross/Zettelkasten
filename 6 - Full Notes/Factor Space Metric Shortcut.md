# Factor Space Metric Shortcut

The complete correspondence-analysis factor map preserves chi-squared distances among source profiles as Euclidean distances. When a task requires only a particular distance to an average profile, the book shows that it can be calculated directly from the original counts and marginals without computing every factor.

For massive data this can avoid a costly full eigenreduction while retaining the specified metric quantity. It does not provide the complete factor coordinates or every interpretation available from the full map; the shortcut is useful only when the requested measure is one of the identities preserved by that map.
