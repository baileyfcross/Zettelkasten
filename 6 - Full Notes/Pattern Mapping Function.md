# Pattern Mapping Function

A pattern mapping function converts the relationship between an object and a pattern into a feature value. Common mappings encode binary match, frequency, confidence, or class growth behavior.

The same pattern set can yield different learning spaces under different mappings. A mapping should reflect what match strength means for the data type and task.
