# Java Development Kit and Runtime Environment

The Java Development Kit is the environment used to build Java software. It includes the runtime needed to execute programs together with development tools such as the `javac` compiler, the `java` launcher, an archiver, documentation utilities, diagnostics, and interactive tools.

The runtime side supplies the JVM and standard libraries required by an application. A developer normally installs a JDK because it can both compile and run code; a deployed runtime can be reduced to the modules the application actually needs through the [[Java Platform Module System]].
