# Code Semantic Understanding

Code semantic understanding is a model's ability to relate syntax to behavior, data flow, dependencies, intent, and program structure. It supports tasks such as code search, summarization, clone detection, review, and reasoning beyond surface token similarity.

Language-model representations help capture recurring code patterns, but repository-specific meaning also depends on definitions, configuration, libraries, and runtime behavior. [[Codebase Context Retrieval]] and execution tools provide evidence that pretraining alone cannot supply.
