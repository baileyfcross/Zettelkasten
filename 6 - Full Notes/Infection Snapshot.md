# Infection Snapshot

An infection snapshot records which network nodes occupy diffusion states at one observation time. It provides a cross-section of the spread but usually omits exact transmission paths and activation times.

Source estimators infer backward from this incomplete result. Different origins can create similar snapshots, especially under recovery, missing observations, variable edge rates, or multiple sources.
