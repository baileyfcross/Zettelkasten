# Soft Cluster Indicator

A soft cluster indicator assigns continuous values to observations so that samples believed to share a cluster receive similar values, without forcing a discrete membership label. Leading nontrivial eigenvectors of a [[Normalized Graph Laplacian]] provide indicators of this kind.

The relaxation makes a difficult graph-partition problem tractable and exposes degrees of affiliation or transition between groups. In spectral feature scoring, a feature that aligns with a useful soft indicator can preserve cluster structure even if it is not itself a binary label.
