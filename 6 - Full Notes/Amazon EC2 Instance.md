# Amazon EC2 Instance

An Amazon EC2 instance is a virtual server launched in an availability zone from an Amazon Machine Image and an instance type. Its configuration combines operating-system image, CPU and memory profile, network placement, storage, identity role, and security groups.

EC2 gives the customer operating-system and application control, which also means responsibility for patching, configuration, and workload availability. Instances are replaceable compute units; durable data should use storage whose lifecycle matches the application.
