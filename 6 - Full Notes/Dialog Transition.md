# Dialog Transition

A dialog transition moves a finite-state interaction from one state to another after an event. Events can include a recognized user value, a no-match condition, timeout, help request, service result, or error.

Transitions make recovery behavior explicit in a [[Finite-State Dialog Manager]]. Their number can grow rapidly when every exceptional path is copied across many states.
