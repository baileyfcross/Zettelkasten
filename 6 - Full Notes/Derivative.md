# Derivative

A derivative describes the rate at which a function changes at a particular point. Geometrically, it is the slope of the tangent line at that point.

Its sign provides local directional information. If increasing a parameter produces a negative derivative of loss, the loss decreases; if the derivative is positive, increasing that parameter raises the loss. A multivariable function has a [[Partial Derivative]] for each variable.
