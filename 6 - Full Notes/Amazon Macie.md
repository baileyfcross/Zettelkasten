# Amazon Macie

Amazon Macie discovers and helps protect sensitive data in Amazon S3. It evaluates bucket security and uses managed data identifiers and machine learning to locate patterns associated with personal, financial, credential, and other sensitive information.

Macie findings improve visibility into where sensitive data resides and how buckets are exposed. They still require classification policy, investigation, and remediation; discovery alone does not change access permissions, encrypt an object, or decide whether the data has a legitimate purpose.
