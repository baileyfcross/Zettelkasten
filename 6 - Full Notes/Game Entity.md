# Game Entity

A game entity is a datum or collection of data representing an object, character, quantity, or state of affairs in the game world. A building, character, score, pile of gold, or traffic-light state can all be entities.

Entities make the world computable. Their values and attributes supply the state on which events, processes, and conditions operate.
