# HTTP Response

An HTTP response is the server's reply to an [[HTTP Request]]. It combines an [[HTTP Status Code]], headers, and an optional body that may contain HTML, JSON, or another representation.

ASP.NET Core middleware or controller actions can write responses. A client interprets both the returned data and the status, because a successful health result, a degraded result, and a server failure should not be treated as equivalent outcomes.
