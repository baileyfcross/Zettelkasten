# Spatial Polygon Data

Spatial polygon data represent areas enclosed by one or more rings, possibly including holes or multiple disconnected parts. Administrative regions and land-cover zones are common examples. Polygon attributes can be encoded with a [[Choropleth Map]], which visually assumes a value applies throughout each region. Boundaries can also provide geographic context over a [[Quantitative Raster Map]].
