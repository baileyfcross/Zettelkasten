# Network Agent Conclusion Validation

Network agent conclusion validation compares the model’s final explanation with deterministic facts in the tool results. If established BGP peers are fewer than total peers, the answer must report a routing issue; if a target is unreachable, it must not claim successful reachability; if a tool failed, the response must expose missing evidence rather than silently proceeding.

The final prose is never more authoritative than the observations that produced it. Small domain rules around a [[Network Troubleshooting Evidence Record]] catch polished contradictions that prompt instructions alone cannot reliably prevent.
