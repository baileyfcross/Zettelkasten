# CSS Resolution Units

CSS resolution values describe pixel density using dots per inch, dots per centimeter, or dots per CSS pixel. These values are especially useful in [[CSS Media Feature Descriptors]] when a stylesheet needs to distinguish output devices or choose suitably detailed resources.

Resolution is not an element length. It expresses a ratio between device pixels and a reference measurement, so it describes the output surface rather than the size of an individual box.
