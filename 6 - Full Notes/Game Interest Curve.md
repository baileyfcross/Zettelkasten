# Game Interest Curve

A game interest curve plots a player's engagement against time and connects rises or falls with events in the experience. It helps a designer locate moments that create attention, frustration, recovery, climax, or disengagement.

Low points are not automatically failures because sustained peaks can exhaust attention and make later events indistinguishable. The dangerous pattern is an extended decline below the player's interest floor with no event capable of restoring engagement. Playtest ratings and observed behavior can approximate the curve for different audiences.
