# Game Condition

A game condition is a true-or-false test used by mechanics to decide whether an event occurs, a process begins or ends, or a consequence applies. Conditions can inspect entity values, time, location, ownership, or prior events.

Precise conditions prevent ambiguity between design and implementation. Complex behavior is built by combining tests without hiding exceptions that the player cannot learn.
