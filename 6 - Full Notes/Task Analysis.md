# Task Analysis

Task analysis identifies the tasks and subtasks people perform and describes their relationships, sequences, and dependencies. A hierarchical task analysis arranges them into a structure that exposes how a larger activity is completed.

The result helps derive requirements and choose appropriate [[Interaction Technique]]s. For example, treating all [[3D Manipulation]] as one task hides important differences among selection, positioning, rotation, and scaling. Breaking the work into canonical tasks and task parameters makes design and evaluation more precise.

Task analysis supports [[Requirements Analysis]], [[User-Centered Design]], and application-specific [[User Interface Evaluation]].
