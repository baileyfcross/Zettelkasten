# AWS Certificate Manager

AWS Certificate Manager provisions and manages public and private TLS certificates for use with integrated AWS services. Managed public certificates can be renewed automatically while attached to supported resources such as load balancers and CloudFront distributions.

A certificate binds a domain identity to a public key and supports encrypted transport, but it does not authorize the application user or protect data after termination. DNS validation, correct domain ownership, secure private-key handling, and protocol configuration remain essential parts of the trust chain.
