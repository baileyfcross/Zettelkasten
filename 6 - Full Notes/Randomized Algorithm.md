# Randomized Algorithm

A randomized algorithm deliberately uses chance when selecting part of its execution path. Its result or runtime can vary between runs even when the input is unchanged.

Randomness can avoid consistently unfavorable deterministic choices. [[Quicksort]] selects pivots randomly so that its expected complexity is loglinear, even though a theoretically possible sequence of extreme pivots would be much slower. Correct sorting is guaranteed; chance affects performance rather than correctness.
