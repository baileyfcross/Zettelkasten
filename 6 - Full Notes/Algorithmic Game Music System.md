# Algorithmic Game Music System

An algorithmic game music system composes or arranges music at runtime from formal rules. Rather than choosing only among finished tracks, it can generate melodic, harmonic, rhythmic, or contrapuntal events in response to game parameters.

Continuous generation can provide long-term and subtle variation, but the system must encode enough musical knowledge to avoid incoherent results. Its [[Game Music Rule Set]] may be based on an established musical model or on constraints invented for one project. Greater generative freedom also increases implementation cost, processor use, and the amount of testing needed to cover possible outputs.
