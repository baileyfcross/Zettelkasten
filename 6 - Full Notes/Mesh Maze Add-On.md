# Mesh Maze Add-On

Mesh Maze converts a mesh into labyrinthine geometry. The source mesh supplies the spatial domain, and parameters alter how the generated maze traverses that structure.

The result is an example of procedural modeling: a compact rule can produce a complex form and can be rerun with different inputs or settings instead of rebuilding the pattern by hand.
