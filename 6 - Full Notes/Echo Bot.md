# Echo Bot

An echo bot replies with the text it receives, making it a minimal end-to-end test of bot hosting and message transport. The template proves that the endpoint, adapter, activity handler, and emulator can exchange messages before language behavior is added.

The book first special-cases a greeting and later replaces that rule with intent recognition and an intent-response map. This progression keeps infrastructure verification separate from conversational sophistication.
