# Information-Theoretic Metric Learning

Information-theoretic metric learning finds a Mahalanobis matrix close to an initial metric while satisfying upper bounds for must-link distances and lower bounds for cannot-link distances. LogDet divergence measures the change from the starting geometry.

Efficient Bregman projections enforce pairwise constraints iteratively while preserving positive semidefiniteness. The prior metric therefore supplies a meaningful default that supervision modifies only as much as necessary.
