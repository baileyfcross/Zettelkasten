# HTTP Status Code

An HTTP status code is the numeric outcome attached to an [[HTTP Response]]. It communicates whether a request succeeded, failed because of the request, or failed because the server could not complete it.

Status selection is part of an API contract. A health endpoint can map healthy, degraded, and unhealthy results to responses that monitoring clients interpret, while a Web API uses status codes alongside its serialized body.
