# CSS Grid Auto-Placement

Grid auto-placement assigns positions to items whose row, column, or both axes remain automatic. The algorithm moves through the grid by row or column and creates [[CSS Implicit Grid|implicit tracks]] as needed.

A dense mode can backfill earlier holes with later items that fit, but this can make visual order differ from source order. Explicitly positioned items reserve their occupied cells before the remaining items are placed.
