# Distributed Object System

A distributed object system lets software objects communicate across process or host boundaries through an interface that resembles local interaction. In AR, tracking, simulation, rendering, and device services may run on different computers while participating in one application.

Distribution can place work near specialized hardware and share state among users. Network delay, partial failure, serialization, and object identity remain real concerns even when the programming abstraction hides connection details.
