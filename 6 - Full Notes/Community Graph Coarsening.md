# Community Graph Coarsening

Community graph coarsening contracts all nodes in each detected community into one representative node and combines parallel edges between communities. The reduced graph preserves aggregate connectivity while removing the detail that makes a large network unreadable.

Coarsening is both a dimensionality-reduction and visualization step. The resulting labels, merged weights, and community algorithm shape the picture, so the coarse graph should be paired with local views when individual relationships matter.
