# Azure DNS Private Resolver

Azure DNS Private Resolver provides managed inbound and outbound DNS endpoints between Azure virtual networks and external DNS systems. Inbound queries let on-premises clients resolve Azure private zones; outbound rules forward selected domains from Azure to corporate or other resolvers. This supports centralized, distributed, or hybrid DNS architectures without customer-managed DNS virtual machines, but zone links and forwarding rules must avoid ambiguous or circular resolution.
