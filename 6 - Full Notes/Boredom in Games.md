# Boredom in Games

Boredom in games can occur when the player's mastery exceeds the demands of the activity and the system asks only for repetition of already understood actions. Resistance remains, but it no longer produces significant learning or choice.

Avoiding boredom does not require constant escalation. New relationships, altered pacing, wider choices, or a deliberate reflective pause can change the experience without simply increasing [[Game Difficulty|difficulty]].
