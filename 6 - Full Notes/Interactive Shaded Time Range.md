# Interactive Shaded Time Range

An interactive shaded time range marks a selected or analytically important interval behind a temporal plot. Dragging its boundaries can couple range selection with [[Temporal Zooming]], filtering, or a summary calculation. The translucent fill preserves the primary lines while making the active interval unmistakable. The selected dates should also be stated textually so the range is not communicated by position alone.
