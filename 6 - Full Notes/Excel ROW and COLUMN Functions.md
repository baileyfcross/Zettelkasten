# Excel ROW and COLUMN Functions

Excel ROW returns a reference's row number, and COLUMN returns its column number. When no reference is supplied, each reports the position of the cell containing the formula. These coordinate values can drive numbering, alternating patterns, and position-dependent calculations.

Combining a coordinate with [[Excel Integer Division and Remainder Functions]] creates repeating cycles, such as highlighting every other row or assigning records to periodic groups. Coordinate formulas depend on worksheet layout, so inserting rows or columns may change their meaning even when Excel updates references correctly. They should be used when position itself is meaningful, not as a substitute for a stable identifier.
