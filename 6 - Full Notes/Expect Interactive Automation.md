# Expect Interactive Automation

Expect automates terminal-oriented programs by waiting for recognizable output patterns and sending the responses an interactive user would type. It is useful when a program lacks a noninteractive interface and repeated prompts would otherwise require continuous attention.

Generated Expect scripts need review because prompts can vary and captured responses may contain credentials. Whenever possible, a program's documented batch mode or secure input channel is less fragile than simulating a conversation.
