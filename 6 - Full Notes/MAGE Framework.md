# MAGE Framework

The Massively Agile Game Environment, or MAGE, is an inspect-and-adapt framework for applying agile and lean principles across a large game organization. It organizes multiple teams around a single integrated game while allowing structure to evolve with the project.

Its emphasis is [[Whole Game Focus]], short communication paths, product ownership at several levels, visible dependencies, and recurring cross-team coordination rather than one fixed scaling blueprint.
