# Azure Container Service Responsibility Spectrum

The Azure container service responsibility spectrum compares how much runtime and orchestration work remains with the customer. Container Instances exposes a small execution surface, App Service and Functions provide workload-specific platforms, Container Apps adds managed microservice features, and AKS or OpenShift exposes a full cluster platform. More control enables specialized networking and policy but also adds upgrades, node management, isolation, capacity, and operational ownership.
