# AWS Amplify

AWS Amplify provides an integrated development and hosting path for web and mobile applications. It connects frontend code with managed backend capabilities and supports build, deployment, and hosting workflows so teams can deliver without assembling each service manually. Its opinionated abstractions accelerate common applications, while architects must still understand the generated resources, identity model, data access, and operational limits beneath the developer experience.
