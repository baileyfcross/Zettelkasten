# Extreme Programming

Extreme Programming is a set of engineering practices for sustaining rapid change through technical feedback and collaboration. Practices include [[Test-Driven Development]], [[Continuous Integration]], [[Pair Programming]], simple design, and frequent refactoring.

Scrum can organize the product and team cadence while XP strengthens the way code is created inside that cadence. The practices make small iterations safer rather than trading speed for accumulating instability.
