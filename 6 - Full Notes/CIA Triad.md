# CIA Triad

The CIA triad describes information security through [[Information Confidentiality|confidentiality]], [[Data Integrity|integrity]], and [[Information Availability|availability]]. Confidentiality limits disclosure, integrity protects correctness and intended use, and availability makes information or services accessible when needed.

The three properties expose different kinds of failure. A system can keep data secret while allowing unauthorized alteration, or can preserve correct data that users cannot reach in time, so a security requirement should address each property separately.
