# Generic Method

A generic method declares one or more type parameters on the method itself, so it can reuse one algorithm across different statically checked types. The containing class does not need to be generic.

Constraints can state which operations the method requires, such as `IComparable<T>` for comparison. When arguments make the type unambiguous, C# type inference can supply the type argument at the call site.
