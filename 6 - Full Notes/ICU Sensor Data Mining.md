# ICU Sensor Data Mining

ICU sensor data mining analyzes dense, continuous measurements from critically ill patients to recognize deterioration, reduce false alarms, and support timely intervention. Multiple monitors can provide complementary evidence about the same changing physiological state.

The environment is difficult because signals are noisy, interventions alter the data, and abnormal values may be common even without a new crisis. A useful system must integrate streams in real time, separate sensor failure from patient change, and present conclusions quickly enough to matter without overwhelming clinicians with low-value alerts.
