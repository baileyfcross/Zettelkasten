# CKAN Package

A CKAN package is the catalog-level description of a dataset. It groups title, ownership, description, tags, update information, and one or more [[CKAN Resource|resources]] under a stable identifier.

Selecting a package does not by itself select a file, because different formats or vintages may be attached as separate resources.
