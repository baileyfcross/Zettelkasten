# Signature-Based Threat Detection

Signature-based threat detection compares observed code or behavior with known patterns associated with malicious activity. It is efficient when the harmful pattern has already been identified and encoded into a detection rule.

Its central limitation is novelty: a changed or previously unseen attack may not match a stored signature. This gap helps explain why a [[Zero-Day Attack]] and adaptive techniques such as a [[Behavioral Security Baseline]] require complementary defenses.
