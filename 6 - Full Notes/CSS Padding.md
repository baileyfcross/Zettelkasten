# CSS Padding

Padding is the transparent region between an element's content and its border. Each side can receive a length or percentage, and shorthand syntax expands one to four values around the box.

Percent padding on every side is calculated from the containing block's width in the model described by the source. Padding cannot be negative, contributes to outer box dimensions, and is painted by the element's background.
