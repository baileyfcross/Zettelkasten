# Double-Error Drift Correction

The double-error method is used before the halfway point of a leg. The pilot estimates the track error, turns by twice that angle toward the planned course, flies for the same time already spent drifting, and then removes one error angle to parallel the original track with a wind correction. Its geometry assumes the elapsed-time symmetry is still available.
