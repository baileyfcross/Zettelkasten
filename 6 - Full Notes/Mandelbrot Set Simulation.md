# Mandelbrot Set Simulation

The Mandelbrot set is generated by repeatedly applying a simple complex-number rule at each point on a grid and coloring points according to whether their values remain bounded. The resulting image reveals intricate structure not obvious from the equation alone.

Zooming exposes self-similar detail at new scales, motivating the idea of a [[Fractal]]. The example shows how repeated computation and visualization can turn a compact mathematical definition into an exploratory object.
