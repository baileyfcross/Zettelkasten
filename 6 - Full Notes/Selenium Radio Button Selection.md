# Selenium Radio Button Selection

Selenium radio-button selection locates an option by ID, label, value, or position and clicks it when the desired value is not already selected. `isSelected()` verifies the resulting state.

Radio groups represent a single choice, so selecting one option replaces the group's prior selection. Unlike a checkbox, a selected radio option is not normally deselected by clicking it again; another option is chosen instead.
