# R Graphical Parameter

An R graphical parameter controls features such as point symbol, line type, axis limits, tick marks, label size, line width, margins, or color. A parameter supplied to one plotting call changes that element locally, while a device-level setting can affect later graphics until it is restored.

Styling choices alter interpretation when they hide data, truncate a relevant range, or make groups indistinguishable. Reproducible graphs keep consequential parameters in code rather than in manual edits after export.
