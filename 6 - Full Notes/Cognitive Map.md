# Cognitive Map

A cognitive map is the mental, hierarchical structure that represents the [[Spatial Knowledge]] a person obtains from an environment. It is stored in [[Long-Term Memory]] and used to understand position, orientation, routes, and relationships among places.

Cognitive mapping is the process of building, accessing, and using this structure. During [[Navigation]], perception and the cognitive map form a feedback loop: new environmental information updates spatial knowledge, while existing knowledge guides movement and interpretation.

Interfaces can support this process with stable landmarks, legible environments, maps, and transitions that preserve spatial context.

AR guidance can reduce immediate navigation effort by overlaying a route, yet it should still help the user relate the path to surrounding structure. Overview views, visible decision points, and [[Transitional Interface|transitions]] between perspectives preserve opportunities to build survey and route knowledge.
