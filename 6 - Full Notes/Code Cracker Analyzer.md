# Code Cracker Analyzer

Code Cracker is a collection of Roslyn-based rules and code fixes that can extend Visual Studio's C# analysis. It demonstrates how compiler diagnostics can identify a questionable construct and sometimes offer a structured correction.

An automatic fix still changes source behavior or structure and deserves review. Extensions must also be compatible with the project's toolchain so analysis does not depend on one developer's unrecorded environment.
