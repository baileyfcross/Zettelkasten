# Hilbert Function

For a graded module M whose degree pieces have finite length over R₀, the Hilbert function is H_M(n) = ℓ(Mₙ). It counts the algebraic size available in each degree.

For a finitely generated module over a standard graded polynomial ring, the function eventually agrees with a [[Hilbert Polynomial]]. Encoding all values as coefficients of a generating function gives the [[Hilbert Series]].
