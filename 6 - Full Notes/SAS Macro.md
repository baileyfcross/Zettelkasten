# SAS Macro

A SAS macro is reusable code written in SAS macro language to generate or repeat procedural operations. Macros accept parameters, expand into SAS statements, and commonly automate recurring data-management, analysis, or reporting tasks.

Macro language is a separate layer beside procedures and data steps. An R workflow usually approaches the same need through [[Statistical Function Automation]], iteration, or apply-family functions rather than reproducing SAS macro syntax directly.
