# Java Class and Object

A Java class declares a type's state and behavior; an object is a runtime instance of that declaration. The class names fields, methods, and constructors, while `new` invokes a constructor and allocates an instance whose reference can be stored in a compatible variable.

Every ordinary class ultimately extends `java.lang.Object`, inheriting common operations such as `toString`, `equals`, and `hashCode`. A class is therefore both an implementation unit and a type in an inheritance hierarchy, while each object has its own instance state unless a field is declared static.
