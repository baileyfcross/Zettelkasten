# CLIQUE Grid Subspace Clustering

CLIQUE divides each dimension into intervals, identifies dense units, and joins adjacent dense units into clusters within subspaces. It uses the fact that a dense unit in a high-dimensional subspace must also be dense in every lower-dimensional projection.

This downward-closure property prunes much of the subspace search. The resulting descriptions are interpretable as unions of grid units, although density and interval parameters can produce fragmented or redundant clusters.
