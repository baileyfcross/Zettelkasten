# Object Layering

Object layering combines game objects whose behaviors create a stronger situation together than either creates alone. Different movement patterns, threats, or reactions can require the player to track and manage several relationships at once.

Layering works best after each object has received a clear [[Rule Introduction]]. Without that prior understanding, the combination becomes a trap based on hidden information rather than a [[Meaningful Decision|meaningful choice]].
