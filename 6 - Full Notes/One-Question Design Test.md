# One-Question Design Test

A one-question design test turns the game's central vision into a single criterion for evaluating proposed features and changes. Each element is judged by whether it strengthens the intended player experience.

The question helps maintain coherence when many appealing ideas compete for attention. It links daily decisions to the [[Game Concept]] and provides a compact defense against [[Scope Creep]].
