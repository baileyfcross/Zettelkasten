# Native Mobile Application

A native mobile application is implemented with the language, SDK, controls, and runtime conventions of its target operating system. It offers direct access to platform APIs and generally the clearest path to platform-specific performance and user experience.

The tradeoff is duplication across targets: an iOS and an Android edition may require different skills, codebases, and maintenance work even when they implement the same product behavior.
