# Game Behavior State Machine

A game behavior state machine places an agent in one behavior state at a time and defines events or conditions that trigger transitions. States such as patrol, chase, attack, and flee isolate behavior appropriate to different situations.

The model is easy to reason about when transitions remain explicit. Large machines can become tangled, which motivates encapsulating behavior and transitions with the [[State Design Pattern]].
