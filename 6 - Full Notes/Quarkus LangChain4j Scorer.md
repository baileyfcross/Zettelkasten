# Quarkus LangChain4j Scorer

Quarkus LangChain4j scoring support lets a test evaluate model responses against a declared criterion or expected behavior. The source uses scoring as a bridge between probabilistic output and repeatable Java test execution.

A score is evidence about a sampled case, not a deterministic proof of application quality. Useful suites include diverse examples, stable settings where possible, recorded model and prompt versions, failure diagnostics, and thresholds chosen from human-reviewed results.
