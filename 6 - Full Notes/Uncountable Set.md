# Uncountable Set

An uncountable set cannot be placed in one-to-one correspondence with the natural numbers. Its members cannot all be exhausted by any infinite sequence indexed by natural numbers.

The real numbers are uncountable, and removing a [[Countable Set|countable subset]] from an uncountable set leaves an uncountable remainder. [[Cantor Diagonal Argument]] demonstrates this by constructing an element omitted from every proposed list.
