# Absorbing Boundary Condition

An absorbing boundary condition truncates an open electromagnetic domain while minimizing nonphysical reflection from the artificial outer boundary. It allows a finite mesh to approximate radiation into an unbounded region.

Moving the boundary farther away generally improves the approximation but raises memory cost. Higher-order radiation conditions seek to place it closer to the object while matching more terms of the outgoing-wave behavior.
