# Attribute-Based XPath Locator

An attribute-based XPath locator selects an element whose attribute satisfies a condition, such as `//input[@name='username']`. It is useful when an element has a distinctive ID, name, type, or custom attribute even if its structural position can change.

Several conditions can be combined through an [[XPath Logical Locator]], while a stable parent or sibling can supply context when the target's own attributes are not unique.
