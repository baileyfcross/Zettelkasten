# Reinforcement Learning Agent-Environment Interaction

Reinforcement learning is organized as a repeated interaction between an agent and an environment. The environment occupies a state, the agent selects an available action, and that action can change the state while returning an immediate reward or no reward at all.

Unlike a [[Supervised Learning|supervised learner]], the agent helps generate its own data through the actions it tries. The outcome of one action also changes which later situations can occur, so the goal is to learn a sequence or policy that produces high cumulative reward rather than to optimize each step in isolation.
