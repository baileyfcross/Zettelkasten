# System Load Requirement

A system load requirement defines the volume and concurrency a system is expected to handle while meeting its other service targets. It can describe simultaneous users, requests per interval, queued work, or data size.

Load makes a performance claim testable and informs [[Scalability]]. Average demand alone is insufficient when bursts, seasonal peaks, or uneven work cause the capacity problem the architecture must absorb.
