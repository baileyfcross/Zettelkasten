# Direct Manipulation Interface

A direct manipulation interface lets users act on visible objects through pointing, dragging, and selection while receiving immediate feedback. The actions resemble operations on physical objects more than memorized command syntax.

Graphical displays and the mouse made this interaction practical. Its effectiveness depends on clear visual representations and predictable relationships between gestures and system state.
