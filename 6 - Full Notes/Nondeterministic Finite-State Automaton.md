# Nondeterministic Finite-State Automaton

A nondeterministic finite-state automaton maps a state and input symbol to a set of possible next states and may also use ε-transitions that consume no input. A string is accepted when at least one possible computation finishes in an accepting state.

Nondeterminism changes how a machine is designed but not which languages finite automata can recognize. [[Subset Construction]] converts every NFA into an equivalent [[Deterministic Finite-State Automaton]].
