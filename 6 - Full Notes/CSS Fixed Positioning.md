# CSS Fixed Positioning

A fixed-position box uses a containing block tied to the viewport in continuous media, so it remains in the same visible place while document content scrolls. Like [[CSS Absolute Positioning]], it is removed from normal flow.

In paged media, fixed content can be repeated in the same position on each page. Transformed ancestors and other context rules can alter which rectangle establishes the fixed containing block.
