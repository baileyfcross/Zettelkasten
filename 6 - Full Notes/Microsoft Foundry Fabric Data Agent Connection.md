# Microsoft Foundry Fabric Data Agent Connection

A Microsoft Foundry Fabric Data Agent connection lets a Foundry agent use a Fabric data agent as a governed analytical capability. The Fabric side can translate natural-language questions into queries over configured enterprise data, while the Foundry agent provides the broader conversation, instructions, knowledge, and tool-routing experience.

The connection should preserve the separation between conversational orchestration and data access. Teams must verify identity behavior, source permissions, schema understanding, response fields, and failure handling before production use. Evaluation should confirm that the Foundry agent invokes the data agent only for appropriate questions and accurately represents its returned evidence.
