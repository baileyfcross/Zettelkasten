# AWS Security Hub

AWS Security Hub aggregates and normalizes security findings from AWS services and supported third-party products, and it evaluates resources against security standards. Cross-account and cross-region aggregation gives security teams a consolidated posture view. Security Hub does not replace the finding sources or incident process: teams still prioritize context, suppress known exceptions carefully, investigate causes, and automate remediation with controlled permissions.
