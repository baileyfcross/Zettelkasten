# Truss Element Stiffness Matrix

A truss element stiffness matrix relates the four global translational degrees of freedom of a planar member to their nodal force components. Its scale is axial rigidity divided by length, and its pattern is built from direction-cosine products.

The matrix is symmetric and couples both nodes and both coordinate directions. Assembly adds each coefficient to the rows and columns associated with the element's global node numbers.
