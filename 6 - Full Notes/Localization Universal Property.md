# Localization Universal Property

The localization universal property says that a [[Ring Homomorphism]] R → T that sends every element of a multiplicatively closed set S to a unit factors uniquely through [[Ring Localization]] S⁻¹R.

The factor map must send r/s to the image of r multiplied by the inverse of the image of s. This property defines localization independently of a particular fraction representation.
