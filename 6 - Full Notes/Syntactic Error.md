# Syntactic Error

A syntactic error violates the lexical or grammatical rules of a programming language, such as a misspelled keyword, missing delimiter, undeclared name where declarations are required, or malformed statement. Compilers and interpreters detect most such errors before normal execution begins.

Warnings should be treated as part of this first feedback boundary rather than ignored because a build produced an executable. Removing errors and warnings establishes a cleaner starting point for investigating the semantic and logic defects that compilation cannot prove absent.
