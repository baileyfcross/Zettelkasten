# Referential Transparency

An expression is referentially transparent when replacing it with its evaluated value leaves the program's observable behavior unchanged. A pure price calculation has this property for fixed inputs; a call that reads a changing database or prints a message does not. This substitution view makes it easier to compose calculations and reason about them independently of execution order.
