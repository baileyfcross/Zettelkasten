# Cluster Ensemble Problem

The cluster ensemble problem combines several partitions of the same observations into one consensus without assuming that cluster labels correspond across inputs. Labels are arbitrary, so direct voting by label name is invalid.

Consensus methods instead use co-membership, graph, probabilistic, or relabeling structures. Their goal is to recover stable shared evidence while reducing sensitivity to individual algorithms, samples, or initializations.
