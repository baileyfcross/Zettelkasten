# Competitive Neural Network

A competitive neural network lets output units compete to represent an input pattern. The winning unit, and sometimes its neighbors, updates its weights toward that observation.

Because desired class outputs need not be known, competitive learning can discover clusters in unlabeled data. Convergence can be indicated when weight vectors cease changing noticeably.
