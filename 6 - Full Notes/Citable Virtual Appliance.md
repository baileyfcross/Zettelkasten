# Citable Virtual Appliance

A citable virtual appliance is a saved [[Virtual Machine]] image given a stable identifier that can be referenced from a publication. It can preserve the operating system, installed software, configuration, scripts, data, logs, and intermediate results as a runnable snapshot of the computational laboratory.

Launching a copy lowers the installation burden for a reproducer and can supply the same class of computing resources when hosted in a cloud. The appliance should still be documented: direct rerunning is easier than understanding or extending opaque software, and long-term use depends on preserving the image format and required platform.
