# Ring Identity

A ring identity is an element 1 such that multiplying any ring element by 1 leaves it unchanged. In the book's convention, every [[Commutative Ring]] has an identity and every [[Ring Homomorphism]] preserves it.

The identity distinguishes units: a [[Ring Unit]] is an element that can be multiplied by another element to obtain 1. A nonzero [[Field]] requires its identity to be distinct from zero.

The source writes the ring identity as 1_A to keep track of the ambient ring. It also singles out the [[Trivial Ring]], where 0_A = 1_A, before defining characteristics and nontrivial domains.
