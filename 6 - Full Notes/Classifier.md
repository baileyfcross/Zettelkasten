# Classifier

A classifier is a computational system that assigns an observation to one of several classes. During [[Supervised Learning]], labeled examples teach the system a relationship between input features and desired categories.

A simple artificial neuron can classify two linearly separable groups by learning a [[Decision Boundary]]. A multiclass network can use a [[Softmax Function]] to output a probability for every class and select the class with the strongest result.
