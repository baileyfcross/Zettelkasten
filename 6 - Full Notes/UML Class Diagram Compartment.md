# UML Class Diagram Compartment

A class symbol in a UML class diagram is commonly divided into compartments for the class name, attributes, and operations. Attribute entries can show visibility, name, and type; operation entries can show visibility, parameters, and return type.

Separating these compartments lets the diagram convey both the identity of a class and the public or relevant structure it presents. A model can omit low-value detail when the diagram's purpose is architectural rather than implementation-level.
