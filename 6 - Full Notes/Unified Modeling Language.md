# Unified Modeling Language

The Unified Modeling Language is a standardized visual language for communicating software models. Its diagrams provide shared notation for structure and behavior so developers, architects, and stakeholders can discuss a system without relying only on prose or implementation code.

UML contains multiple diagram types rather than one universal view. A [[UML Class Diagram]] emphasizes static structure, a [[UML Use Case Diagram]] emphasizes functional scope, and a [[UML Sequence Diagram]] emphasizes interactions over time.
