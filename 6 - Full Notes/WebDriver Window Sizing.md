# WebDriver Window Sizing

WebDriver window sizing controls the browser dimensions used by a test. A window can be maximized, minimized, placed in full-screen mode, or assigned an exact width and height with a dimension object; its current size can also be retrieved.

Exact dimensions help exercise responsive layouts at repeatable view sizes. Full screen differs from maximize because it hides browser interface elements, while minimizing can test whether background behavior continues when the window is not foregrounded.
