# AWS Cost Explorer

AWS Cost Explorer visualizes historical and forecast AWS cost and usage. Users can filter and group data by dimensions such as service, account, region, usage type, and [[AWS Cost Allocation Tag|cost allocation tag]] to identify trends and cost drivers.

It helps answer where spending occurred and how it is changing, but those results need workload context to explain why. Reviews should connect cost patterns with resource ownership, demand, architecture changes, and optimization actions.
