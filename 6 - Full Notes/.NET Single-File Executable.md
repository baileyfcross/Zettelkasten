# .NET Single-File Executable

A .NET single-file executable packages an application's published output into one executable artifact. The .NET Core 3 project demonstrates this as a deployment option for a migrated desktop application so users do not have to manage a loose collection of runtime and application files.

Single-file publication can be combined with removal of unused components to reduce the artifact. The convenience changes packaging rather than platform requirements: a Windows desktop application remains Windows-specific even when its files are consolidated.
