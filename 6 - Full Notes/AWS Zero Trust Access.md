# AWS Zero Trust Access

Zero trust access evaluates each request using identity, device, resource, and contextual signals rather than treating network location as sufficient trust. On AWS, the approach favors explicit authentication and authorization, least privilege, short-lived credentials, segmentation, and continuous visibility.

It is an architectural direction rather than a single AWS product. Identity policies, network controls, workload authentication, logs, and data protections must reinforce one another so a compromised user, device, or component has limited reach.
