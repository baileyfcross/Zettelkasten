# Azure Infrastructure Architect

An Azure infrastructure architect designs shared hosting, connectivity, hybrid integration, monitoring, resilience, and landing-zone foundations. The role concentrates on where workloads run and how they reach common services rather than on application features. Infrastructure diagrams expose virtual networks, hubs, gateways, DNS, routing, security appliances, regions, and recovery boundaries so application teams can consume a governed platform.
