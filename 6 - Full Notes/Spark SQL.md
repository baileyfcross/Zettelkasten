# Spark SQL

Spark SQL compiles relational queries into operations executed by the Spark runtime. In the book's described version, it reused Hive parsing and metastore compatibility while using its own Catalyst logical optimizer and DataFrame representation.

In-memory reusable data reduces disk input/output and job-restart overhead when queries feed iterative analysis. The account is version-specific and notes that contemporary Spark SQL supported only a subset of HiveQL features.
