# CSS Table Formatting Model

The CSS table formatting model represents a table through a wrapper, table box, row groups, rows, column groups, columns, cells, and captions. HTML table elements normally generate these roles, but table-related display values can assign them to other elements.

The model arranges cells into a shared grid and coordinates their borders, backgrounds, dimensions, and alignment. Missing structural roles can be supplied through [[CSS Anonymous Table Objects]].
