# CSS Custom Properties

A CSS custom property defines a reusable value under a case-sensitive identifier beginning with two hyphens. The value is retrieved with `var()`, allowing colors, dimensions, fonts, or compound values to be named once and substituted into many declarations.

Custom properties participate in the cascade and can be redefined within a narrower element context, so descendants receive the scoped value. They can also enter [[CSS Calculation Values]], creating coordinated measurements from a shared base value.
