# Boolean Algebra

Boolean algebra manipulates propositions using [[Logical Operators]] and equivalence laws. Identity, idempotent, commutative, associative, distributive, double-negation, excluded-middle, contradiction, and De Morgan laws permit a formula to be replaced by one with the same truth values.

These replacements can simplify both proofs and [[Electronic Circuits]], because logically equivalent formulas describe circuits with the same input-output behavior.
