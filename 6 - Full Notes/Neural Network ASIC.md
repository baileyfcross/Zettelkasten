# Neural Network ASIC

A neural network ASIC implements a fixed or narrowly programmable architecture for neural computation. Dedicated processing elements, dataflows, instruction support, and memory hierarchies can eliminate general-purpose overhead and achieve high energy efficiency.

The cost is long design and verification time while network topologies and numerical formats change rapidly. An ASIC therefore needs enough configurability for its intended model family, or it risks becoming mismatched before its efficiency advantage is realized.
