# Overview Game Data Analysis

Overview game data analysis uses summary statistics to identify the broad shape and suspicious features of an attribute set. Average, median, mode, count, minimum, maximum, and the frequency of extreme or modal values provide complementary clues; no single statistic is a sufficient description.

A large gap between average and median can reveal skew or an outlier, while comparing the mode count with the full count shows whether the most common value is actually influential. Summary results should lead back to inspection of the raw objects and their names, where a designer can connect numeric patterns to the game's content and mechanics.
