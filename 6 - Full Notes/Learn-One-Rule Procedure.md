# Learn-One-Rule Procedure

A learn-one-rule procedure constructs a single antecedent by adding conditions that improve the quality of the examples it covers. Candidate refinements are evaluated until no acceptable gain remains or a stopping condition is met.

The learned consequent names the class favored within the covered region. Repeating the procedure after changing the active training set turns this local search into a complete rule-induction algorithm.
