# Spreadsheet Output Sheet

A spreadsheet output sheet separates analysis tables and visualizations from the game data that drives them. Charts, probability models, and large comparison tables can become cumbersome; placing them beside source data makes both the inputs and the results harder to navigate and easier to damage.

An output sheet gives derived information enough room to communicate a particular question while leaving the data schema stable. It also clarifies direction: object sheets contain authoritative records, formulas transform them, and the output sheet presents the result for inspection or decision-making.
