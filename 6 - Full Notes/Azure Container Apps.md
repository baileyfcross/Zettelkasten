# Azure Container Apps

Azure Container Apps is a serverless container platform for microservices, APIs, background workers, and event-driven workloads. It runs on managed Kubernetes foundations while exposing application-level concepts such as revisions, ingress, scaling, jobs, secrets, and Dapr integration rather than the cluster control plane. This reduces platform operations, but environment boundaries, networking, identity, resource sizing, scaling rules, and application observability still require design.
