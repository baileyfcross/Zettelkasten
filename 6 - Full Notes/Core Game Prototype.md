# Core Game Prototype

A core game prototype integrates the full set of primary player actions with goals, important rules, and win or loss conditions. It goes beyond a rough playable prototype so the central experience can be evaluated as a connected system.

Basic art and sound can be included when they materially affect understanding or feeling. Secondary content and final polish remain unnecessary unless the test question depends on them.
