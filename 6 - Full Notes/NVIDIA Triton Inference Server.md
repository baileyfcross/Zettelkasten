# NVIDIA Triton Inference Server

NVIDIA Triton Inference Server is an open-source service for deploying models on GPUs or CPUs through a common operational interface. It supports multiple frameworks and runtimes, including TensorFlow, PyTorch, ONNX Runtime, TensorRT, and XGBoost, while exposing inference through REST or gRPC.

Triton supplies serving behavior around a model rather than replacing its execution backend. A platform can standardize repositories, health checks, metrics, batching, model instances, containers, and deployment patterns while model teams retain different training frameworks.
