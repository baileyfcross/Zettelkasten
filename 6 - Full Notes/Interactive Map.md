# Interactive Map

An interactive map supports operations such as panning, zooming, selecting features, and requesting details. It can combine tiled [[Reference Map|reference maps]] with thematic points, polygons, or rasters. Interaction makes dense attributes available through [[Spatial Tooltip|tooltips]] and [[Map Popup Graphic|popups]], but the initial extent, legend, and visible layers must still communicate the map's purpose. Controls should preserve awareness of scale and location as the view changes.
