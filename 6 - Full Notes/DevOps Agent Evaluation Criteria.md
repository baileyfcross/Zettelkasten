# DevOps Agent Evaluation Criteria

DevOps agent evaluation covers task adherence, tool correctness, output quality, safety, operational efficiency, and human usefulness. It asks whether the agent followed its instructions, selected the right tool with valid arguments, produced actionable grounded output, avoided policy violations, and used acceptable time and tokens.

No single score captures all of these dimensions. A structurally complete incident report may still recommend an unsupported action, while a safe response may be too vague to help. Evaluation should preserve individual checks so failures point to a specific behavior that can be improved.
