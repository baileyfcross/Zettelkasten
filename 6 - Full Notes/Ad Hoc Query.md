# Ad Hoc Query

An ad hoc query retrieves or summarizes data for a question that was not fixed as a recurring pipeline. Social-media examples search by hashtags, text, users, retweets, and time intervals before deeper analysis.

Indexes and schemas can avoid or narrow full scans, while high-level query systems reduce the code required. Performance depends on both query planning and the number of records retrieved from distributed storage.
