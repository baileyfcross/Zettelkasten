# Git Branch

A Git branch is a movable reference to a commit. Creating a branch records a lightweight name for a line of development rather than copying the entire working directory and history.

New commits advance the currently checked-out branch, while other branch references remain at their previous commits. Branches let related work develop independently until [[Git Merge|integration]] or another history operation combines it.
