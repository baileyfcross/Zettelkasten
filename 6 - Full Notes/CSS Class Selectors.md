# CSS Class Selectors

A class selector matches elements whose `class` attribute contains a named, whitespace-separated class. It is written with a period before the class name, and several class selectors can be combined to require multiple classes on the same element.

Classes can be reused throughout a document and can describe presentation or a shared role. They carry less [[CSS Specificity]] than an ID selector, making them easier to override in a reusable style system.
