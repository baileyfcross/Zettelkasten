# R Script Error Tracing

R script error tracing locates the first expression that fails, inspects the console message, and checks the objects and syntax used by that expression. A missing parenthesis, incorrect name, or invalid value can prevent the remainder of the script from running or can produce a warning that leaves a questionable result.

The book recommends correcting and rerunning small sections rather than guessing at a long script as a whole. Intermediate values and hand-calculated examples help distinguish a coding mistake from a faulty scientific formula.
