# Expertise Reversal Effect

The expertise reversal effect occurs when guidance that helps novices hinders experts. An experienced player must reconcile redundant or conflicting instruction with an established [[Player Knowledge Schema]], consuming attention and working memory that a novice does not spend in the same way.

Games should vary support with expertise: novices need explicit guidance and constrained practice, while experts need the ability to skip, shorten, or disable it. A single tutorial path can therefore be both insufficient for one group and frustrating for another.
