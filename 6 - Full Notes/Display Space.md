# Display Space

Display space is the set of physical and virtual surfaces through which an AR system can present information. It may include head-worn imagery, handheld screens, wall displays, projectors, and other devices distributed throughout the environment.

Unlike a single desktop window, this space can surround the user and change with location. Architecture must decide which content belongs on which display while preserving shared coordinates, continuity, privacy, and device capability.
