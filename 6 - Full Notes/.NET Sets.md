# .NET Sets

A .NET set stores unique values and supports membership-oriented operations. Adding an existing value does not create a duplicate, and set union, intersection, difference, and subset relationships express comparisons between collections.

Sets are appropriate when uniqueness and containment matter more than position. Their equality and hash behavior depend on how the element type defines comparison, so domain-specific equality must be correct for membership results to be meaningful.
