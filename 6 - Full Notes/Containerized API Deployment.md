# Containerized API Deployment

Containerized API deployment packages the application and its runtime dependencies into an image that can run consistently across development, test, and hosting environments. A container exposes the service port and starts the API with a declared command.

The book supplies Docker examples for several frameworks and connects containers to cloud deployment and orchestration. The image does not contain every operational concern: configuration, secrets, persistent data, health checks, networking, scaling, and image updates still belong to the deployment design.
