# Interpolation

Interpolation estimates a function value at a point inside the range of known data. It constructs a function that agrees with the supplied data values and evaluates that function between them.

[[Polynomial Interpolation]] is convenient because polynomials are easy to evaluate, differentiate, and integrate. The distinction from extrapolation is that interpolation stays within the span of the known independent-variable values.
