# Amazon Bedrock Multi-Agent Collaboration

Amazon Bedrock multi-agent collaboration divides a complex generative-AI workflow among specialized agents. A supervisor agent coordinates agents responsible for narrower capabilities such as retrieval, calculation, or content generation, then assembles their results. Specialization can make a large workflow easier to reason about, but agent roles, tool permissions, shared context, handoffs, failure behavior, and final validation must be designed explicitly.
