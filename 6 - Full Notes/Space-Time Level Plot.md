# Space-Time Level Plot

A space-time level plot displays selected layers of a [[Space-Time Raster]] as colored map panels. Each panel preserves the complete spatial grid for one time, and a shared color key supports comparison among snapshots. The approach exposes both geographic pattern and change but is limited by page area: as the number of layers grows, panels become too small. Temporal aggregation or animation provides alternative views.
