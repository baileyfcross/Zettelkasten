# Azure DevOps User Story Work Item

An Azure DevOps user story work item records a user-centered slice of value in process templates that use stories rather than product backlog items. It can hold acceptance criteria, priority, effort, state, and links to parent features and child tasks.

The record supports conversation and traceability; its short narrative is not a complete substitute for domain knowledge, examples, and agreed constraints.
