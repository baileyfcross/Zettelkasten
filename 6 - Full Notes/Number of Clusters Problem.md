# Number of Clusters Problem

The number of clusters problem asks how many groups provide the most useful representation of a data set. A hierarchical tree supports many cut levels, while a partition method such as K-means generally requires a value of k before fitting.

There may be several defensible answers at different resolutions. Objective functions, validity indices, stability tests, visualizations, and domain knowledge provide evidence, but none makes cluster count independent of purpose.
