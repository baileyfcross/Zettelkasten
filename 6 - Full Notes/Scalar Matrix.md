# Scalar Matrix

A scalar matrix is a [[Diagonal Matrix]] whose diagonal entries are all the same scalar. It has the form $cI$, where $I$ is the [[Identity Matrix]].

Scalar matrices commute with every compatible square matrix. The special cases $c=1$ and $c=0$ produce the identity and zero matrices.
