# Cloud Price Model

A cloud price model defines the rule used to calculate what a consumer pays for a cloud service. It is derived from the provider's cost model but also reflects business strategy, expected revenue, transferred risk, market positioning, and the value unit visible to the customer.

Pricing can follow resource use, transactions, subscriptions, volume, service commitments, outcomes, or marketing strategy. A useful comparison normalizes the unit and term rather than comparing only the headline monthly amounts.
