# Xamarin.Forms Composite Customization

A Xamarin.Forms composite customization packages several existing controls and layouts into a reusable interface component. The composition can expose bindable properties while retaining the standard renderers of its child controls.

This approach reduces repeated XAML and can simplify a page's visual tree without crossing into native rendering. It is preferable to a custom renderer when the desired component can be expressed entirely by arranging existing shared controls.
