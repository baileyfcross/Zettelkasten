# Mobile Camera Permission

Mobile camera permission is the user's runtime authorization for an application to access device camera hardware. The platform project must declare the required capability and handle the result of the user's permission decision.

The emotion detector cannot perform its central feature without a camera, but the book notes that other applications should consider degraded behavior when permission is refused. Permission is therefore both a platform configuration and a product-design boundary.
