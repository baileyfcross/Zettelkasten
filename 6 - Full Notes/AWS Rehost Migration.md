# AWS Rehost Migration

Rehosting moves an application to AWS with minimal architectural change, the pattern often called lift and shift. [[AWS Application Migration Service]] can replicate source servers and launch converted instances for testing and cutover. Rehosting is fast and reduces migration disruption, but it also carries the workload's existing design limitations into the cloud, so later optimization may still be necessary.
