# Linear Programming Model Formulation

Linear programming model formulation translates a verbal decision problem into [[Decision Variable|decision variables]], a [[Linear Objective Function]], [[Linear Constraint|linear constraints]], and sign restrictions. The sequence matters: first identify what can be chosen, then express the benefit or cost of each choice, and finally represent every resource limit or requirement with the same variables.

For example, a product-mix model can let each variable count a product's output, maximize the sum of unit profits, and limit assembly, polishing, and packing time. A formulation is useful only when its coefficients retain that operational meaning and all relevant restrictions are represented.
