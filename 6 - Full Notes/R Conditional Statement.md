# R Conditional Statement

An R conditional statement evaluates one logical condition and executes its braced block only when that condition is true. It controls program execution rather than filtering a whole vector, so its condition should resolve to one nonmissing logical value.

Conditional logic is useful when a scientific procedure changes at a threshold or when input validity must be checked before a calculation. The tested assumption should be stated clearly enough that each branch can be checked independently.
