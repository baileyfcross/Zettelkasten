# Long Document Segmentation Clustering

Long-document clustering often begins by segmenting each document into locally coherent passages. Segments can then be grouped to reveal recurring themes that would be diluted in one vector for the entire text.

Segmentation boundaries and cluster assignments interact because topic changes help define passages while passage content defines topics. Joint or iterative methods can refine both, but they require safeguards against producing many tiny fragments.
