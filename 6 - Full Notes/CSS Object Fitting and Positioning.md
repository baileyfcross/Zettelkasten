# CSS Object Fitting and Positioning

The `object-fit` property controls how replaced content such as an image or video is sized inside its content box. It can preserve intrinsic size, contain the entire object, cover the box, fill without preserving aspect ratio, or choose a scale-down result.

The `object-position` property aligns the fitted object within any remaining or clipped space. These properties change the external content inside the box without changing the box's own declared dimensions.
