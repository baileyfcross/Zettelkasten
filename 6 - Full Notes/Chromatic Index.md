# Chromatic Index

The chromatic index of a graph is the minimum number of colors needed for a valid [[Edge Coloring]]. It therefore measures the smallest number of mutually exclusive slots required when adjacent edges cannot receive the same assignment.

For a tournament graph, the chromatic index is the minimum number of days required under the rule that each player can appear in only one match per day. A greedy algorithm can find a valid schedule without always attaining this minimum.
