# STTDF Object

An `STTDF` object represents a simple [[Spatial Trajectory]] together with attributes recorded along it. Locations are paired with ordered times so the structure describes movement rather than an independent grid of places and dates. Subsetting must preserve that pairing. A mapped path can show where the entity traveled, while temporal or attribute displays are needed to explain how its measurements changed along the route.
