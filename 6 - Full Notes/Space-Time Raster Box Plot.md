# Space-Time Raster Box Plot

A space-time raster box plot summarizes the distribution of cell values at each time or temporal group using quartiles, a median, and outlier conventions. It supports compact comparison across many periods but does not show multiple modes or geographic arrangement. A [[Space-Time Raster Violin Plot]] adds distribution shape, while the original maps identify where unusually high or low cells occur.
