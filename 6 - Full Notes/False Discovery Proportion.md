# False Discovery Proportion

The false discovery proportion is the number of [[False Positive|false positives]] divided by the total number of features selected by a procedure. It is defined as zero when no features are selected.

Because both the selected list and its mistaken members change across repeated datasets, the proportion is a random variable. Its expected value gives the [[False Discovery Rate]].
