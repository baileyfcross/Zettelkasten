# Azure Target Reference Architecture

An Azure target reference architecture maps business requirements and non-functional constraints to concrete services, flows, trust boundaries, and deployment relationships. The source builds it by extracting scenario keywords, consulting the architecture maps, and adding numbered explanations to the diagram. It is a reasoned candidate rather than a universal template; monitoring, security, resilience, and operational views must still expose unresolved gaps and tradeoffs.
