# CSS Complex Media Queries

Complex media queries combine a media type and feature tests with logical operations. `and` requires every joined condition, a comma separates alternatives, and `not` negates a complete query rather than merely one feature expression.

The `only` keyword was designed to hide a feature-bearing query from older user agents that would otherwise read only its media type. Query lists succeed when any member is true.
