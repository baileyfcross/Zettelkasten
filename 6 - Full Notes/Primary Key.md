# Primary Key

A primary key is a column or combination of columns whose value uniquely identifies each row in a [[Relational Database|relational database]] table. The database management system rejects changes that would create two rows with the same key.

Key uniqueness also guarantees that no two table rows are identical, preserving the mathematical interpretation of a table as a set of tuples rather than a collection with duplicates.
