# Java Migration Compatibility Audit

A Java migration compatibility audit checks the application and its ecosystem before changing JDK versions. It covers third-party libraries, build and IDE support, removed or separated APIs, module-system effects, licensing constraints, and full regression testing of behavior that should remain unchanged.

The book identifies JAXB and JavaFX removals, unsupported dependencies, and the module system as examples of obstacles that kept projects on older releases. The audit distinguishes genuine blockers from inertia and supplies the evidence needed for a staged [[Java LTS Migration Strategy]].
