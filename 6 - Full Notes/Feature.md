# Feature

A feature is an attribute or variable used to describe an aspect of a data object. Useful features make objects distinguishable, support interpretable models, and provide the measurements on which classification, regression, clustering, retrieval, and other analytic tasks operate.

Feature meaning depends on the application. A color may be categorical, age numerical, and degree ordinal. The value of a feature is therefore inseparable from its domain, measurement scale, and the analytic question it is intended to answer.
