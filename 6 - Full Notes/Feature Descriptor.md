# Feature Descriptor

A feature descriptor encodes the local image appearance around an interest point into a form that can be compared efficiently. A useful descriptor remains distinctive while tolerating expected changes in scale, rotation, illumination, or viewpoint.

Descriptors from the current camera image are searched against descriptors in a tracking model. A close descriptor match proposes a point correspondence, which geometry must then verify before it influences pose.
