# Binary Representation in Hardware

Early computer engineers chose binary codes because two-state circuits and storage devices were simpler and more reliable than components that had to distinguish many voltage levels. Groups of bits could represent numbers, instructions, text, images, and other discrete information.

Binary digits are abstractions over physical states such as voltages, magnetic orientations, or stored charge. Syntax rules distinguish valid code patterns, even though the machine does not understand what the patterns mean.
