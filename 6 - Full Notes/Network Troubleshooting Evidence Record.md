# Network Troubleshooting Evidence Record

A network troubleshooting evidence record is an application-managed structure containing the case, target, tools used, material result fields, unhealthy observations, and deterministic validation facts. It exists outside the prose answer so code and reviewers can inspect exactly what the agent observed.

For a BGP incident, the record might preserve device status, total and established peer counts, non-established neighbors, zero-prefix sessions, and down interfaces. It can also state facts that the final answer must mention. This makes [[Network Agent Conclusion Validation]] possible without asking a second model to judge the first model’s wording.
