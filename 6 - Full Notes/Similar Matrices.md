# Similar Matrices

Two square matrices $A$ and $B$ are similar when an invertible matrix $Q$ satisfies $B=Q^{-1}AQ$. They represent the same linear transformation in different coordinate bases.

Similar matrices have the same [[Characteristic Polynomial]], eigenvalues, determinant, and trace. Numerical eigenvalue algorithms exploit this by replacing a matrix with progressively simpler similar matrices.
