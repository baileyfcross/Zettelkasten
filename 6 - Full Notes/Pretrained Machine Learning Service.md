# Pretrained Machine Learning Service

A pretrained machine-learning service exposes a model that a provider has already trained for a defined task. Application developers send supported inputs and consume predictions without assembling a dataset or fitting the model themselves.

This saves time and specialized modeling work, but the service may not match a narrow application's population or question. Building a custom model offers more control at the cost of data, expertise, training, evaluation, and ongoing maintenance.
