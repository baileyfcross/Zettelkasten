# Data Stream Compression

Data stream compression reduces the number of bits transmitted or stored for a continuing sequence. Sensor streams often contain temporal correlation and repeated values that can be encoded as changes, summaries, or models rather than raw samples.

Lossless methods preserve exact recovery; lossy methods trade accuracy for stronger reduction. The acceptable error depends on the later decision, not only the compression ratio.
