# Azure Virtual Network Manager

Azure Virtual Network Manager centrally groups virtual networks and applies connectivity, security-admin, and routing configurations across them. Network groups can select VNets dynamically, allowing standard topology or route policies to propagate at scale instead of being recreated per subscription. Central management improves consistency, but group membership and policy rollout need change control because one configuration can affect many application networks.
