# COMSOL Analytic and Interpolation Functions

Analytic functions encode an explicit mathematical relationship, while interpolation functions map tabulated data into values between measured points. Either can supply time histories, temperature-dependent properties, spatial sources, or operating curves.

The function's arguments, units, interpolation method, and extrapolation behavior must match the physical data. A [[Function Sweep in COMSOL|function sweep]] can compare alternative relationships, while a material model can call an interpolation function repeatedly as the solution temperature changes.
