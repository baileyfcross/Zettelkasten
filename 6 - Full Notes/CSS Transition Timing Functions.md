# CSS Transition Timing Functions

A transition timing function maps elapsed time to progress through the interpolated property values. CSS supplies named easing curves, custom cubic Bézier curves, and step functions that jump through a fixed number of stages.

The duration determines how long the transition lasts, while the timing function determines how that time is distributed internally. A delay shifts when interpolation begins and can be negative to start partway through the transition.
