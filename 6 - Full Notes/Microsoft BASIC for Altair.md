# Microsoft BASIC for Altair

Bill Gates and Paul Allen created a BASIC interpreter for the Altair using a DEC PDP-10 as their development system. The program let owners write software in a simple high-level language instead of entering machine instructions.

It was Microsoft’s first product and demonstrated that software would determine the personal computer’s usefulness. The same language moved from a shared mainframe setting to a machine owned by one person.
