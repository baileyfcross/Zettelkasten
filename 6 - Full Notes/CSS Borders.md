# CSS Borders

A CSS border is the painted region surrounding an element's padding box. Each side has a style, width, and color, and the border is absent when its style is `none` even if a width has been declared.

Side-specific and shorthand properties can set the components individually or together. Borders contribute to the element's dimensions under the ordinary [[CSS Box Model]] and can be curved by [[CSS Rounded Corners]].
