# 2D Painter's Algorithm

The 2D painter's algorithm draws visual elements from the farthest layer to the nearest so later images cover earlier ones. The ordering acts like a painter placing foreground paint over an existing background.

It is a practical visibility method for sprites and tile layers when depth relationships are known. An incorrect draw order produces elements that appear in front of objects that should obscure them.
