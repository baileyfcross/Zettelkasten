# Blender Object Groups

In Blender 2.7x, an object group recorded a named set of objects without joining their geometry or requiring a shared parent. Groups supported repeated selection and reuse while the Outliner exposed their membership.

Because grouping and hierarchy expressed different relationships, grouped objects could remain independently transformable. This historical system predates modern collection-centered organization and is best understood as saved object membership rather than a transform chain.
