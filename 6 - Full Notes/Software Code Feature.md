# Software Code Feature

A software code feature measures static properties of a software artifact, such as size, complexity, coupling, or organization. These product metrics summarize what the code is like at a selected revision.

Code features are interpretable and widely available, but they provide only a snapshot. Combining them with process features captures how the artifact reached that state.
