# Volume Specification

Volume specification defines a bounded three-dimensional region associated with a physical object or space. The user may indicate corners, faces, an axis, or another small set of constraints from which the system constructs a box, cylinder, or related primitive.

Using a constrained primitive reduces the number of difficult spatial inputs. The volume can support selection, collision, annotation, occlusion, or a starting approximation for more detailed reconstruction.
