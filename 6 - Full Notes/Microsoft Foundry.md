# Microsoft Foundry

Microsoft Foundry is a unified Azure platform for building, customizing, evaluating, deploying, and operating generative AI applications. Its model catalog, agents, workflows, knowledge sources, tools, evaluations, guardrails, and monitoring capabilities place the application lifecycle in one managed environment.

The platform's central idea is that a production AI solution is more than a model call. Data access, orchestration, identity, safety, observability, and change control must be designed together. Foundry supplies connected workspaces and controls for those concerns while relying on related Azure services for storage, secrets, search, networking, and telemetry.
