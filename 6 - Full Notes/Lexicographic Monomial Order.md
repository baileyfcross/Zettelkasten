# Lexicographic Monomial Order

Lexicographic order compares exponent vectors at the first coordinate where they differ. The monomial with the larger exponent at that position is ordered first.

Because earlier variables dominate every comparison, lexicographic order supports the [[Elimination Theorem]]. A Gröbner basis computed in this order exposes equations involving only later variables.
