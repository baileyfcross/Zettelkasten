# Game Music Asset Tracking

Game music asset tracking records the identity, version, location, ownership, review state, and delivery status of every music file used by a project. Version-control or asset-management systems distribute current builds, preserve earlier revisions, and let authorized contributors add or update files.

Consistent naming is part of the system because a mismatched filename or letter case can prevent the game from loading an asset. Tracking should also connect each file to its [[Game Music Cue Sheet|cue-sheet entry]] and [[Game Music Approval Workflow|approval state]], especially when a project contains hundreds or thousands of variations.
