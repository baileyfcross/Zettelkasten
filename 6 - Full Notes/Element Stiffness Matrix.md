# Element Stiffness Matrix

An element stiffness matrix relates an element's nodal response vector to its nodal load vector. Its coefficients depend on the element geometry, material properties, interpolation model, and governing physics.

Although “stiffness” comes from structural mechanics, an analogous characteristic matrix appears in thermal, fluid-potential, and electromagnetic problems. Assembly maps each local coefficient into the global equation system.
