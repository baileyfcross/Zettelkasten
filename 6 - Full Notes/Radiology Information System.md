# Radiology Information System

A radiology information system manages the operational data surrounding medical imaging, including patient tracking, scheduling, procedure identification, result reporting, and image tracking. It commonly works with a picture archiving and communication system, which stores and distributes the images themselves.

This distinction matters analytically: the radiology system provides encounter and workflow context, while the archive provides pixel or voxel data. Linking the two enables [[Biomedical Image Object Detection|image-derived findings]] to be interpreted with the correct patient, procedure, time, and report.
