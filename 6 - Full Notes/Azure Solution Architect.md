# Azure Solution Architect

An Azure solution architect assembles building blocks for a particular business solution while addressing cross-cutting requirements such as security, performance, reliability, and scalability. The role needs T-shaped knowledge: depth in a specialty plus enough breadth to collaborate with other architects. High-level application building blocks express technology-neutral intent, while solution building blocks map that intent to concrete Azure services and configurations.
