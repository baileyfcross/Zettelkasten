# Amazon FSx for Windows

Amazon FSx for Windows File Server provides a managed Windows-native filesystem using SMB. It supports Windows access semantics and integration patterns such as Active Directory, making it suitable for applications that expect shared Windows file services.

The service removes much of the filesystem infrastructure administration but not share permissions, directory design, backup requirements, or client connectivity. It should be chosen for Windows file semantics rather than as a generic replacement for every shared store.
