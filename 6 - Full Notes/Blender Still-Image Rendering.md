# Blender Still-Image Rendering

A still render converts the active camera's view of the 3D scene into one two-dimensional image. Blender can start this operation from the Render menu or with F12 and displays the result in its Image Editor.

The rendered buffer is not yet a file. It must be saved in an image format, and render slots can retain alternate results for comparison while lighting, materials, or camera settings are refined.

The source repeatedly contrasts the setup visible in the 3D viewport with the F12 result from the active camera. Particle fragments, materials, lights, world background, and simulation domains can produce a different final image than the solid viewport suggests, so both the camera composition and render output must be inspected.
