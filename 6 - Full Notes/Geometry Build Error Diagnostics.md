# Geometry Build Error Diagnostics

Geometry build error diagnostics use the failed sequence node, highlighted entity, and accompanying message to locate disconnected vertices, overlaps, self-intersections, invalid relationships, or operations that cannot produce a domain. The earliest failing feature is usually more informative than later mesh errors.

Dividing complex assemblies into identifiable regions narrows the search. Repairing or suppressing one feature at a time preserves evidence about which geometric condition caused the failure.
