# Azure Artifacts

Azure Artifacts supplies package feeds within Azure DevOps for reusable compiled components and their versions. A team can publish a library once and let multiple projects consume a declared package rather than copying source or binaries manually.

Package versioning makes reuse an explicit dependency. Access, retention, provenance, and compatibility still need governance because a feed can distribute a defect as efficiently as a correct component.
