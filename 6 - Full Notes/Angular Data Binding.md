# Angular Data Binding

Angular data binding connects component state and template output. Interpolation places a value into text, property binding supplies a value to an element or component property, and form binding can also carry user changes back into the model.

Binding allows an [[Angular Component Template]] to describe how data is presented without manually rewriting the document for every change. Directives can repeat rows or conditionally display loading and validation states.
