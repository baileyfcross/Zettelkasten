# Unity Mobile Build Configuration

Unity mobile build configuration begins by adding the Android or iOS module to the relevant editor installation through [[Unity Hub]]. Platform documentation and toolchain requirements then determine what additional setup is needed for a deployable build.

Mobile authoring resembles other Unity development, but input, performance, screen shape, and deployment constraints differ. Unity Remote can relay display, touch, and accelerometer data to an editor session for quick interaction checks, while a real build remains necessary for trustworthy performance and platform testing.
