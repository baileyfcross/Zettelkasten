# Clinical Code Extraction

Clinical code extraction maps narrative evidence to concepts in a [[Clinical Coding System]]. It can convert mentions of diseases, findings, procedures, or medications into standardized identifiers that support search, aggregation, and decision support.

The task requires more than finding matching words. Synonyms, abbreviations, negation, and differences in coding granularity can all change the result. A mapping should retain confidence and textual provenance, and ambiguous phrases should not be forced into a precise code when the report does not support that precision.
