# DBSCAN Noise Point

A DBSCAN noise point is neither a core point nor a border point under the selected Eps and MinPts parameters. It is left outside the discovered density-connected clusters.

Noise is a model-relative label, not proof of error. Changing the radius, minimum count, metric, or data representation can change the classification.
