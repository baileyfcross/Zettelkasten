# Hyperboloid Model

The hyperboloid model realizes hyperbolic space as one sheet of a hyperboloid embedded in a higher-dimensional real space. A specialized inner-product relationship defines distances between points on that surface.

The model is useful for coordinate computation and underlies the [[Rigel Embedding]] method. Perspective projection can transform it into the [[Poincare Disk Model]] without changing the represented geometry.
