# Level Curve

For a scalar function $f(x,y)$, a level curve at value $c$ is the planar set satisfying $f(x,y)=c$. It is the intersection of the graph $z=f(x,y)$ with the horizontal plane $z=c$, projected onto the input plane.

A family of level curves describes a surface without requiring a three-dimensional drawing. The three-variable analogue is a [[Level Surface]].
