# Quantitative Raster Map

A quantitative raster map assigns a color from an ordered scale to each cell's numeric value. It shows the spatial variation of a [[Spatial Field]] at the raster's resolution. A color key must state the value mapping, and boundaries or coastlines can provide context without hiding cells. For multilayer data, shared limits make panels comparable, while [[Raster Marginal Summary|marginal summaries]] can relate the map to aggregated row or column patterns.
