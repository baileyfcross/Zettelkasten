# Mixture Component

A mixture component is one probability distribution available under a particular value of a mixture model's hidden choice variable. Each component can represent a distinct behavior, class, process, or local approximation.

The mixture combines components without requiring the observation to be assigned to one with certainty. Component weights express how often or under which inputs each model contributes, while posterior inference can update those weights from evidence.
