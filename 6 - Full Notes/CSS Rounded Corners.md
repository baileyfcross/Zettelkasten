# CSS Rounded Corners

The `border-radius` properties replace each sharp border corner with an elliptical curve. One radius defines a circular corner, while separate horizontal and vertical radii define an ellipse.

Values can be assigned per corner or through shorthand, and percentages refer to box dimensions. The browser reduces overlapping radii proportionally when their combined sizes would not fit the box.
