# CACTUS Clustering

CACTUS, Clustering Categorical Data Using Summaries, identifies values that co-occur more often than expected under attribute independence. It summarizes those connections, builds projections on individual attributes, synthesizes cluster candidates, and validates them by support.

The method can operate from inter- and intra-attribute summaries instead of repeatedly reading the original database.
