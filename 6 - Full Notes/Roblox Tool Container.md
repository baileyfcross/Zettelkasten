# Roblox Tool Container

A Tool is a Roblox container for an item a player can equip from the Backpack, such as a sword, spell, instrument, or utility. A conventional Tool may include a part named Handle that is attached to the character's hand when equipped, though not every tool needs visible geometry.

Scripts connect Tool events such as Equipped, Unequipped, and Activated to implement behavior. Client input can initiate the action, but important results such as damage or purchases should be checked by the server through [[Roblox Server-Side Validation]].
