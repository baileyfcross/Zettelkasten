# Azure Agentic AI

Azure agentic AI combines a model with instructions, memory, planning, retrieval, and tools so it can pursue a multi-step objective. An agent may select actions and adapt from intermediate results, but autonomy enlarges the failure surface: loops, excessive cost, invalid tool calls, prompt injection, and unintended side effects all require controls. Effective designs bound permissions, steps, budgets, and execution time while preserving traces that show what the agent decided and why.
