# Azure Container Apps Environment

An Azure Container Apps environment is the shared security, network, logging, and runtime boundary for a group of container apps. Apps in one environment can discover and communicate with each other through the managed platform, and the environment integrates with a virtual network and common telemetry. Because connectivity is shared broadly, separate environments or application-level policies may be needed when tenant or trust boundaries require stronger isolation.
