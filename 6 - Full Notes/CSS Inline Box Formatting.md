# CSS Inline Box Formatting

Inline boxes participate in lines rather than beginning a new block row. Their content, font metrics, [[CSS Line Height]], and [[CSS Inline Vertical Alignment|vertical alignment]] contribute to construction of the line box.

An inline box may be split across several lines when content wraps. Horizontal padding, borders, and margins appear at the fragment edges, while vertical box properties do not expand line height in the same way as ordinary block dimensions.
