# Vertical Line Test

A plane graph represents $y$ as a [[Function]] of $x$ exactly when every vertical line intersects the graph at most once. A second intersection would assign two outputs to the same input. The test concerns the orientation of the graph, so a relation that fails it may still express $x$ as a function of $y$.
