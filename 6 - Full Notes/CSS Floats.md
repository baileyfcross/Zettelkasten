# CSS Floats

A floated box is shifted to the left or right of its containing block until it reaches the container edge or another float. It is removed from ordinary block flow, while following inline content is shortened and wraps alongside it.

Floats affect one another and can move downward when insufficient horizontal space remains. Their behavior historically supported layouts as well as image-like text wrapping, although [[CSS Flexible Box Layout]] and [[CSS Grid Layout]] provide dedicated layout systems.
