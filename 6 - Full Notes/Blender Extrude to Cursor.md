# Blender Extrude to Cursor

Extrude to Cursor extends selected mesh geometry toward the 3D cursor's screen-projected location. Repeated use can build a connected path rapidly while the cursor supplies the target for each new section.

Because the result depends on view and cursor placement, it favors visual construction over numeric regularity. Orthographic views and deliberate snapping help control depth when the tool is used for low-poly outlines or branching forms.
