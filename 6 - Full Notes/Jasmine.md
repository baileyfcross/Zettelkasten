# Jasmine

Jasmine is a JavaScript testing framework used to define test suites, setup, individual specifications, and expectations. Angular component tests use its functions to describe behavior and assert rendered or component state.

Jasmine defines the tests, while [[Karma]] runs them in a browser environment and reports their combined results.
