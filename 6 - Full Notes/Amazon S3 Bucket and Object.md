# Amazon S3 Bucket and Object

Amazon S3 stores data as objects inside buckets. A bucket belongs to an account and region and uses a globally unique name, while an object combines data, metadata, a key, and optionally a version identifier.

The key forms a flat namespace even when prefixes and delimiters make the console appear folder-like. S3 is accessed through APIs and endpoints rather than mounted block semantics. Access and lifecycle controls can apply at bucket, prefix, or object scope.
