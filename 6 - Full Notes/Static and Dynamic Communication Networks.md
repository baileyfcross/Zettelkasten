# Static and Dynamic Communication Networks

A static communication network gives processing nodes fixed direct connections, so paths follow the installed topology. A dynamic network uses switching elements to create routes among endpoints as communication demands change.

Static links make locality and hop structure visible but can constrain rerouting. Dynamic switching improves flexibility and utilization at the cost of arbitration, switch complexity, and possible contention within the fabric.
