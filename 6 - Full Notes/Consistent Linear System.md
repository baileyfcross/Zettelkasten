# Consistent Linear System

A consistent linear system has at least one solution. It may have a unique solution or infinitely many solutions.

In row reduction, consistency requires that the [[Augmented Matrix]] contain no row representing an impossible equation such as $0=1$. Rank comparisons also distinguish consistent systems from an [[Inconsistent Linear System]].
