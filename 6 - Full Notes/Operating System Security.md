# Operating System Security

Operating system security preserves the confidentiality, integrity, and availability of a host while many users and processes share hardware. It must separate objects, protect memory, enforce access decisions, and recognize unauthorized changes or code.

The source groups these responsibilities into separation, [[Memory Protection]], and [[Access Control]]. Together they prevent one execution context from freely reading, corrupting, or denying resources belonging to another.
