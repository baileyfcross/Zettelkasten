# Xamarin.Forms Value Converter

A Xamarin.Forms value converter translates a binding value between the source and target representations. An `IValueConverter` implements conversion from the source for display and conversion back when a binding scenario allows edits to return to the source.

Converters are appropriate for reusable presentation transformations such as rendering a `DateTime` as text. They should not conceal domain decisions that belong in the model or view model.
