# CSS Font Weight

The `font-weight` property selects how light or bold a font face should appear. CSS accepts named values such as normal and bold, numeric weights from 100 through 900, and relative values that seek a bolder or lighter face than the inherited weight.

Available fonts may not supply every requested weight, so [[CSS Font Matching]] maps the request to a suitable face. An `@font-face` weight descriptor declares which requests a downloadable resource represents.
