# Plot Legend

A plot legend maps visual encodings such as color, symbol, fill, or line type to substantive categories. Its ordering must match the ordering used to draw the data, or the graph will communicate the wrong group identities.

Placement and scale should preserve the data region. When several lines are overlaid, the legend should repeat the same widths, colors, and line types used in the plot rather than rely on a separate default style.
