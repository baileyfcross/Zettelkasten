# CSS Font Style and Stretch

The `font-style` property chooses among normal, italic, and oblique faces. Italic usually requests a separately designed face, whereas oblique requests a slanted presentation when that distinction is available.

The `font-stretch` property requests a condensed or expanded face along a named scale. Both properties participate in [[CSS Font Matching]], and `@font-face` descriptors state which style and stretch a downloaded resource supplies.
