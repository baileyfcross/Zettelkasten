# Cost-Adjusted Network Model Selection

Cost-adjusted network model selection combines measured response quality with the price of using each model. Averaging evaluation scores shows relative performance across question categories, while a cost factor reveals whether a small improvement justifies a materially more expensive default.

The weighting must reflect operational consequences. A troubleshooting assistant used rarely may favor quality, while a high-volume explanatory service may value economy and latency. Selection is revisited when prompts, prices, models, or task mix change; it is not a permanent property of the model name.
