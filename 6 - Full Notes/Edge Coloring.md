# Edge Coloring

Edge coloring assigns colors to a graph's edges so that no two edges sharing a vertex have the same color. In tournament scheduling, vertices represent players, edges represent matches, and each color represents a day; the constraint prevents a player from being scheduled twice on one day.

The smallest number of colors required is the [[Chromatic Index]]. A greedy procedure can color edges efficiently, though its result depends on processing order and may use more colors than an optimal solution.
