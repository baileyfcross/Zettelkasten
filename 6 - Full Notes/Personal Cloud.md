# Personal Cloud

A personal cloud is a cloud whose scope is one person and that person's information or activities. It can store documents, media, financial information, shopping preferences, or health records and make them available across locations and devices.

The scope does not determine the deployment model: a personal cloud can be private, public, or hybrid. As it combines more intimate data and services, ownership, consent, provider access, interoperability, and security become especially important.
