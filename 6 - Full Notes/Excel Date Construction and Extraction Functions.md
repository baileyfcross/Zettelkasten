# Excel Date Construction and Extraction Functions

The Excel DATE function constructs a valid date from year, month, and day numbers. DATEVALUE converts recognizable date text into a serial date, while YEAR, MONTH, and DAY extract calendar components from a date value. TIME and TIMEVALUE perform similar construction and conversion for clock times, with HOUR and MINUTE extracting components.

These functions separate stored temporal values from their displayed forms. Constructing dates numerically is generally more reliable than assembling date-looking text, especially across different regional formats. Once a value is a true [[Excel Date and Time Serial Value]], it can be sorted, compared, shifted, and used in duration calculations.
