# Logic App Designer

The Logic App Designer is the graphical editor for constructing a workflow from configured components. It can run in the Azure portal or in the 2019 Visual Studio extension, with the underlying logic app retained as JSON for deployment and comparison.

The designer makes triggers, actions, conditions, and loops visible as a flow and exposes dynamic output from earlier steps to later ones. Descriptive step names are important because a workflow quickly becomes difficult to understand when it retains generic generated labels.
