# R Interactive 3D Plot

An R interactive 3D plot renders points, lines, shapes, or surfaces in an OpenGL-backed device that can be rotated, zoomed, and inspected in real time. Changing the viewpoint can reveal occlusion or spatial relationships hidden in a single static projection.

Interaction is part of the display and may not survive ordinary document export. A reproducible analysis should preserve the code, camera choice, and a static view that still communicates the essential pattern without requiring the original graphics device.
