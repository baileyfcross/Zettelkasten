# Dynamic Aesthetics

Dynamic aesthetics are sensory qualities generated or transformed during play. They include procedural imagery and music, changing animation and sound produced by state, and physical sensations created by sustained interaction with controls.

The category separates stored assets from performed presentation. A recorded sound file is an [[Inscribed Aesthetics|inscribed aesthetic]], but the timing, layering, repetition, and contextual meaning of sounds in a particular session are dynamic. The same authored material can therefore produce markedly different sensory experiences as game state changes.
