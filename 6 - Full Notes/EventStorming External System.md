# EventStorming External System

An EventStorming external system represents an organization or technical system outside the modeled team's control. It can receive [[Domain Event]]s or produce events that enter the modeled flow, so placing it on the wall makes integration boundaries and dependencies visible. The notation prevents an outside response from being treated as an internal method call whose timing and reliability are guaranteed. It also helps distinguish the team's model from the broader system in which it participates.
