# K-Means Initialization Sensitivity

K-means initialization sensitivity is the dependence of the final partition on its starting seeds or assignments. Different starts can change the convergence path, produce empty groups, and settle at different local minima.

An analysis should use deliberate seeding or multiple runs and report how stable the solution is. A single unexplained start gives weak evidence for the resulting clusters.
