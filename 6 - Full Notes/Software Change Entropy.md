# Software Change Entropy

Software change entropy measures how a change is distributed across files or components. Concentrated edits have lower entropy, while broadly scattered edits have higher entropy.

The feature represents diffusion rather than raw change size. A change touching many areas unevenly can therefore differ from one of similar size concentrated in a single component.
