# Intel Single-Chip Cloud Computer

The Intel Single-Chip Cloud Computer is a research many-core processor with 48 cores organized as a networked tiled system. It exposes communication and power-management choices that make it useful for studying parallel algorithms.

The source evaluates parallel backpropagation on this platform across core counts and voltage-frequency configurations, emphasizing that fastest execution and lowest energy can occur at different settings.
