# TestNG Test Group

A TestNG test group labels methods as members of a category such as smoke, regression, sanity, feature, or module. Suite configuration can include or exclude groups so a selected testing purpose runs without editing the test code.

Groups organize execution across classes and should describe durable intent. A method can belong to more than one group when it serves several legitimate suite views.
