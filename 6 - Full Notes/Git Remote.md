# Git Remote

A Git remote is a local name for another repository location used to exchange refs and objects. `origin` is a common default name created by cloning, but a repository can define multiple remotes.

`git remote -v` displays configured fetch and push URLs, while `git remote add` creates a new mapping. The remote name is only an alias; synchronization still occurs through explicit fetch, pull, or push operations.
