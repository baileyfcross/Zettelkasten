# Game State Snapshot

A game state is a snapshot of every element that currently matters to play: object positions and properties, available actions, resource values, player progress, and the status of goals. An action changes some part of this state and thereby creates the situation for the next decision.

State is not the same as the full history of play. Two sessions can arrive at an identical visible state through different paths, although a game may preserve past events as state when they affect future possibilities.
