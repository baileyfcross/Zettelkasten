# Twitter Network Feature

A Twitter network feature describes relationships created by following, mentioning, replying, retweeting, or sharing hashtags. Each relation defines a different graph and therefore a different notion of proximity.

Network measures capture influence, coordination, and community context that isolated messages omit. Results depend on collection boundaries and should not assume the observed network is complete.
