# Bayesian Model Combination Ensemble

A Bayesian model combination ensemble treats the weights assigned to a finite set of base classifiers as uncertain parameters and infers their posterior distribution. The hypothesis space therefore consists of combinations rather than the individual models alone.

This can represent complementary predictors that Bayesian model averaging might treat as competing explanations. The approach pays for that flexibility with a more complex inference problem over combination weights.
