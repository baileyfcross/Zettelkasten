# Multi-Source Spectral Feature Selection

Multi-source spectral feature selection uses several data or knowledge sources to estimate which variables are relevant in a target dataset. It is especially useful when the feature count is large but the target sample is too small for stable relevance estimates.

The sources can describe samples, features, functions, or interactions and may have incompatible representations. A multi-source method must therefore convert them into comparable internal evidence, integrate that evidence, and only then rank or jointly select features. Additional sources improve reliability only when they are relevant and trustworthy.
