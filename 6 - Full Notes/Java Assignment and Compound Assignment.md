# Java Assignment and Compound Assignment

The Java assignment operator evaluates its right operand and stores the resulting compatible value in the variable, field, or array element named on the left. Assignment copies a primitive value or a reference value; it does not copy the referenced object.

Compound forms such as `+=`, `-=`, and `*=` combine an operation with assignment and include an implicit conversion back to the left operand's type. That conversion can make a compound statement compile where the visibly equivalent expanded expression requires a cast, so the shorter form is not merely textual abbreviation.
