# Cloud Cell

A cloud cell is a cloud unit that provides one distinct, fundamental function which other clouds can reuse. Examples include a database cell, storage cell, web-server cell, service-bus cell, or firewall cell.

The cell exposes an interface and can be combined through [[Cloud Service Aggregation]], [[Cloud Service Composition]], or [[Cloud Federation]]. Standard definitions and management characteristics make replicas easier to provision and maintain across several composite services.
