# Cluster Analysis Objective Function

A cluster analysis objective function assigns a numerical quality to a proposed grouping. An algorithm searches for merges, splits, or reallocations that improve this value, such as reducing within-cluster squared error or limiting loss of information.

The objective defines what the algorithm regards as a good cluster. Because distinct objectives reward different shapes and balances, optimizing one perfectly does not establish that its solution is uniquely correct for the application.
