# EC2 Dedicated Host

An EC2 Dedicated Host allocates a physical server for one customer's EC2 instances. It provides visibility and control over host placement that can support software licensing or compliance requirements.

A Dedicated Instance also uses single-tenant hardware but offers less host-level control. Both cost more than shared tenancy and should be selected for a stated isolation or license need, not simply because dedicated hardware sounds safer.
