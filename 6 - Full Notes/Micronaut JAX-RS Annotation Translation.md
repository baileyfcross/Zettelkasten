# Micronaut JAX-RS Annotation Translation

Micronaut JAX-RS lets a Micronaut application define controllers with commonly used JAX-RS annotations and types. Its annotation processor translates supported JAX-RS declarations into equivalent Micronaut routing metadata at compilation time.

The project is a compatibility layer rather than a complete implementation of the JAX-RS specification. It is intended to ease migration of existing annotated resources or let teams retain familiar declarations, so an application must verify that every annotation and runtime behavior it relies on belongs to the supported subset.
