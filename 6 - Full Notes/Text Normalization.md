# Text Normalization

Text normalization converts written forms into the words a speech synthesizer should pronounce. It expands abbreviations, numbers, dates, currencies, and symbols according to their context.

The same characters can require different readings, so simple character substitution is insufficient. Normalized text becomes input to [[Phonetic Transcription]] in a [[Text-to-Speech]] pipeline.
