# Network Agent Approval Record

A network agent approval record gives a human reviewer the exact target, proposed action, requester, evidence, risk, expected result, rollback thinking, and current decision before a state-changing operation can execute. The approval gate therefore separates a model’s recommendation from application-authorized execution.

The record should link to the change or incident context and survive after the interaction as audit evidence. Approval is not a generic button: the reviewer needs enough verified information to understand scope and consequences, and a denied or expired decision must stop safely.
