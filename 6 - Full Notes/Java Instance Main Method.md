# Java Instance Main Method

A Java instance main method is a program entry point that does not have to be `static`, `public`, or accept a string array. It lets a small program begin with a parameterless `void main()` and postpones visibility, static members, arrays, and command-line parameters until they are actually needed.

The method remains part of normal Java compilation and execution. Unlike a [[Java Compact Source File]], it can also appear inside an explicitly declared and packaged class; the two simplifications can be used independently or together.
