# AWS Seven Rs Migration Strategy

The AWS seven Rs classify what should happen to each workload in a migration portfolio: [[AWS Rehost Migration|rehost]], [[AWS Replatform Migration|replatform]], [[AWS Refactor Migration|refactor]], [[AWS Repurchase Migration|repurchase]], [[AWS Relocate Migration|relocate]], [[AWS Retain Migration|retain]], or [[AWS Retire Migration|retire]]. The choice records a workload disposition rather than a universal sequence. It balances business value, technical change, risk, time, and the expected benefit of cloud capabilities.
