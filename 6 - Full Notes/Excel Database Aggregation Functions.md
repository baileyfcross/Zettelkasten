# Excel Database Aggregation Functions

Excel database aggregation functions summarize a table after applying an [[Excel Database Criteria Range]]. DSUM totals a selected field, DAVERAGE calculates its mean, and DMAX or DMIN returns its largest or smallest qualifying value.

The database range must include a header row, and the field argument identifies the column to summarize. Because the criteria are stored in worksheet cells, users can change the filter logic without rewriting the function. The visible criteria block becomes part of the calculation and should be labeled, protected from accidental edits when appropriate, and included in audits.
