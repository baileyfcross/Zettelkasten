# Rule-Based Machine Translation

Rule-based machine translation uses bilingual dictionaries plus explicitly authored linguistic rules to analyze a source sentence and generate its target-language counterpart. Its knowledge can include morphology, word categories, reordering patterns, syntactic relations, and domain terminology.

The approach is inspectable and can be built when parallel data are scarce, but coverage grows through sustained manual effort. As rules accumulate, their interactions become difficult to maintain, and an analysis failure can block an entire sentence. The broad family ranges from [[Direct Machine Translation]] through [[Transfer-Based Machine Translation]] to [[Interlingual Machine Translation]].
