# Constrained Frequent Itemset Mining

Constrained frequent itemset mining returns patterns that satisfy both a frequency threshold and user-specified conditions. Constraints can restrict items, length, aggregate values, or relationships relevant to the application.

Pushing a constraint into the search can prune unproductive branches before enumeration, whereas applying it only afterward spends resources generating patterns that will be discarded.
