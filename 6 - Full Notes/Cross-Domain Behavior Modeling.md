# Cross-Domain Behavior Modeling

Cross-domain behavior modeling connects one social domain with several item domains, such as posts, labels, images, or videos. Within-domain links express user ties or item similarity, while cross-domain links express adoption or rejection.

A star-structured graph uses the social domain as the center through which auxiliary evidence can reach a target domain. Shared user behavior then supports recommendations where direct target interactions are sparse.
