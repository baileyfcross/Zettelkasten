# AWS Storage Gateway

AWS Storage Gateway connects on-premises applications to AWS-backed storage through familiar file, volume, or tape interfaces. A local gateway and cache preserve low-latency access while data is stored or protected in AWS services.

The gateway supports hybrid migration, backup, and tiering without requiring every legacy application to adopt an object API. Network capacity, cache sizing, outage behavior, and recovery procedures remain part of the design.
