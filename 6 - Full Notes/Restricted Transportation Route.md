# Restricted Transportation Route

A restricted transportation route is an origin-destination cell through which shipment is prohibited. The route is assigned an infinite or sufficiently large penalty cost so an optimizing procedure will not select it when a permitted feasible plan exists.

The restriction must remain compatible with the network's supply and demand requirements. In software that cannot represent infinity, the penalty should be large enough to exclude the cell without causing avoidable numerical trouble.
