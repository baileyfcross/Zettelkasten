# Cyber Command and Control

Cyber command and control is the communication channel through which an attacker directs a compromised system and receives information from it. This connection turns an isolated foothold into a remotely managed part of an operation.

Blocking or detecting command traffic can disrupt the [[Cyber Kill Chain]] after installation. Network monitoring, destination controls, behavioral analysis, and [[Extrusion Detection]] can reveal communication that ordinary permitted traffic might otherwise conceal.
