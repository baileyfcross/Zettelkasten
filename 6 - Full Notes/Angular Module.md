# Angular Module

An Angular module groups related components, directives, pipes, and imported capabilities into a coherent unit. Module metadata declares what belongs to the unit and what external features it depends on.

The root module bootstraps the application, while feature or utility modules can collect narrower responsibilities such as routing, reactive forms, HTTP communication, or Angular Material controls.
