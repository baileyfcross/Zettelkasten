# Stealth Puzzle

A stealth puzzle is a traversal problem constrained by the need to avoid detection. Patrol paths, schedules, sight lines, sound, hiding places, and tools create a time-varying space through which the player must plan a route.

The system needs legible perception rules so the player can predict risk. Tools that disable or distract enemies expand the solution space, but their consequences must also be observable. When detection feels arbitrary, repeated attempts teach caution rather than strategy; when rules are consistent, failure reveals information for the next plan.
