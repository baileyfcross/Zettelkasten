# Firewall

A firewall is a logical or physical boundary that allows or blocks network traffic according to defined rules. It can protect the edge of a cloud environment and separate internal security containers so only traffic appropriate to a service can cross.

Rules can restrict ports, protocols, sources, and destinations, while logs record rejected or accepted activity for monitoring. A firewall is one layer of defense and does not replace application authorization, endpoint protection, or secure data handling.
