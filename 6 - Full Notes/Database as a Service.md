# Database as a Service

Database as a service provides an accessible database system as a reusable cloud capability. The provider supplies the platform and storage beneath it, while applications connect through established query languages and connectivity protocols.

Keeping the database near the applications that use it can reduce transaction delay. A standardized database service can also be instantiated as a reusable [[Cloud Cell]], but licensing, performance, data protection, and the ability to move data remain important constraints.
