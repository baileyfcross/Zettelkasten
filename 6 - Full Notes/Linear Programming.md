# Linear Programming

Linear programming optimizes a linear objective subject to linear equality or inequality constraints. Decision variables usually also satisfy sign restrictions.

The feasible points form a polygon or higher-dimensional polyhedron, and an optimum, when it exists, can be found at an extreme point. The [[Simplex Method]] moves between basic feasible solutions.
