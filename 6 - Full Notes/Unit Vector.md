# Unit Vector

A unit vector is a [[Vector]] whose [[Vector Norm|norm]] is one. It represents direction without carrying an independent magnitude.

For any nonzero vector $v$, the vector $v/\|v\|$ is a unit vector pointing in the same direction. This construction is [[Vector Normalization|normalization]] and is undefined for the zero vector because its norm cannot be used as a divisor.
