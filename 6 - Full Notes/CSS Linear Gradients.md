# CSS Linear Gradients

A CSS linear gradient is a generated image whose colors change along a straight gradient line. A direction or angle establishes the line, and color stops place colors or transitions at positions along it.

Because a gradient is an image, it can be used wherever an image value is accepted and can be positioned or sized like [[CSS Background Images]]. Omitted stop positions are distributed according to the gradient rules.
