# Angular HttpClient

Angular HttpClient is the framework service used to issue HTTP requests and receive typed responses. It is injected into a component or [[Angular Service]] and can request JSON from an ASP.NET Core [[Web API]].

HttpClient returns an [[Observable]] rather than the final value itself. The consumer subscribes to the asynchronous result and handles returned data or errors when the response arrives.
