# Difficulty Mode

A difficulty mode is a player-selected configuration that changes how much resistance a game presents. It can alter rules, resources, timing, enemy behavior, or other demands to create different pacing through the same underlying system.

Choosing a mode before play creates a paradox: the player may not yet understand the game well enough to know which setting will be satisfying. Multiple modes can also imply that one is the intended experience, so their effects should be made understandable and revisable where possible.
