# Mechanics-Dynamics-Aesthetics Framework

The Mechanics-Dynamics-Aesthetics framework separates a game into mechanics, the components and algorithms directly specified by designers; dynamics, the runtime behavior that emerges during play; and aesthetics, the desired emotional responses of players.

Designers usually reason from mechanics through dynamics to aesthetics, while players encounter the game in the reverse direction. The framework connects directly specified [[Game Token|tokens]] and [[Game Rule|rules]] to the indirect experience created by [[Second-Order Design]].

A dynamic is a recurring behavior produced when mechanics operate in play, not simply a rule restated at runtime. Because the same mechanic can participate in several dynamics, the designer tests the chain from implementation to behavior to experience rather than assuming the intended aesthetic follows automatically.
