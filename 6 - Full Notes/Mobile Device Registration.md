# Mobile Device Registration

Mobile device registration records the platform notification handle needed to address an application installation. Client registration can send the handle directly to a notification hub, while backend registration can associate it with authenticated users, tags, or application rules before creating the registration.

Handles can change and users can use several devices, so registrations require renewal and cleanup. A registration identifies a delivery endpoint; it should not be treated as permanent proof of a person's identity.
