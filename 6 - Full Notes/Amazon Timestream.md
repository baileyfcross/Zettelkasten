# Amazon Timestream

Amazon Timestream is a serverless time-series database for observations indexed by time, such as application metrics, sensor readings, or industrial telemetry. It separates recent memory-tier data from longer-lived storage-tier data and provides time-aware query functions. The model works best when writes, retention, dimensions, and time-window queries are designed together; it is not a general replacement for transactional relational data.
