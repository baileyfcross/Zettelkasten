# Space-Time Map Series

A space-time map series displays the spatial observations for several time indexes as repeated map panels. Each panel retains two-dimensional geography, making local differences and moving patterns visible, but page space limits the number of times that can be shown. Shared symbols, class boundaries, and extents support comparison. A [[Space-Time XT Plot]] or time-series view provides a more comprehensive account of long temporal sequences.
