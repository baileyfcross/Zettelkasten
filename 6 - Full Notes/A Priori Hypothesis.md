# A Priori Hypothesis

An a priori hypothesis specifies the expected relationship between defined variables before examining the analysis that will test it. Prespecification separates confirmatory reasoning from patterns discovered after looking at the data.

For an existing dataset, the exposure, outcome, target population, and candidate confounders should be operationalized from documentation before model fitting. A broad verbal claim that leaves all coding and variable choices open still permits substantial [[Researcher Degrees of Freedom]].
