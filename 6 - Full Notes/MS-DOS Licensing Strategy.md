# MS-DOS Licensing Strategy

Microsoft supplied the IBM PC operating system while retaining the ability to license MS-DOS to other manufacturers. As compatible computers multiplied, the same software platform spread across the market.

The agreement allowed Microsoft to benefit from every clone rather than only IBM sales. Control of the software standard became more valuable than control of the original hardware.
