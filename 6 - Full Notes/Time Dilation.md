# Time Dilation

In special relativity, a clock moving relative to an inertial observer is measured to run slowly. If $\Delta\tau$ is the proper time recorded with the events at one location, then $\Delta t=\gamma\Delta\tau$, where $\gamma=1/\sqrt{1-v^2/c^2}$. The effect is reciprocal between inertial frames and becomes large near light speed.

A light-clock construction derives the relation because all inertial observers measure the same light speed while disagreeing about the distance the pulse travels between ticks. Proper time belongs to the path on which the two events occur at one spatial location; confusing which clock records proper time reverses the comparison.

The same effect follows by treating a boost as a [[Hyperbolic Rotation]]: the time component of a rotated spacetime vector is projected with $\cosh\chi=\gamma$. Experiments with fast-moving unstable particles and transported precision clocks confirm the predicted rate difference.
