# CSS Display Roles

An element's display role describes the kind of box it generates and how that box participates in layout. Common roles include block boxes that begin on a new line, inline boxes that flow within a line, and list items that combine a principal box with a marker.

The role is not permanently fixed by the element name. The [[CSS Display Property]] can change the generated box behavior, separating document semantics from visual formatting.
