# Feature-Representation Transfer Learning

Feature-representation transfer learning constructs a space in which source knowledge and target observations become more compatible. The transformation may encode shared factors, reduce distribution distance, or combine source-specific and target-specific components.

After alignment, a classifier can use labeled source structure to support a sparsely labeled target. A representation that aligns marginal distributions while mixing class boundaries can create negative transfer, so class relevance remains essential.
