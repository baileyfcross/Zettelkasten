# API Metrics

API metrics are quantitative measurements of service behavior over time. The book highlights response time, end-to-end latency, throughput, error rate, and processor, memory, or network utilization as complementary signals of health and capacity.

Prometheus can scrape measurements and Grafana can visualize them in dashboards and alerts. A metric needs a meaningful unit, labels, and threshold; collecting numbers without relating them to an expected service behavior does not identify what should change.
