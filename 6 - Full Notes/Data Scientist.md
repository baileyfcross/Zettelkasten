# Data Scientist

A data scientist combines statistical reasoning, machine learning, software practice, and domain understanding to turn data into decisions. The role extends beyond producing a model because the scientist must also test assumptions, explain uncertainty, and make the analysis repeatable.

The book presents the role as a progression from data handling and analysis toward discovering patterns and creating new knowledge.
