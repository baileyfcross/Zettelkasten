# Blender Speaker Object

A Blender speaker object places an audio source in the three-dimensional scene. Unlike renderable geometry, it supplies sound that can be heard during viewport playback and can participate in an animated scene's spatial organization.

Treating a speaker as an object allows its position and relationships to be managed with the same scene structure used for cameras, lights, and meshes. The object itself remains in Object Mode and is adjusted through transforms and properties rather than mesh editing. It represents an audible source in the scene, not the waveform-editing functions of the Video Sequencer.
