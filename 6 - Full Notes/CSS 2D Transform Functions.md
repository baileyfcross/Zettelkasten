# CSS 2D Transform Functions

CSS two-dimensional transform functions translate, scale, rotate, or skew an element in its rendered plane. Axis-specific forms affect one coordinate, while `matrix()` can express the combined affine transformation directly.

Transforms alter painting and the element's coordinate space without reflowing surrounding normal-flow boxes. A list of functions is order-sensitive because each function receives coordinates already changed by the preceding functions.
