# Zipf-Mandelbrot Rank-Frequency Model

The Zipf-Mandelbrot rank-frequency model describes how word frequency declines as vocabulary rank increases, with parameters that soften the highest-frequency end of a simple power law. Fitting the model summarizes a long, skewed distribution with a small set of values.

Comparing parameters across [[Sequential Text Window Analysis|sequential windows]] can expose local changes in lexical behavior. The fitted curve is descriptive: different preprocessing, window sizes, genres, or sampling schemes can change the apparent parameters.
