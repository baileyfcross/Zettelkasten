# Finite Element Node

A finite element node is a shared reference point at which unknown field values or degrees of freedom are defined. Adjacent elements meet at common nodes, allowing their local approximations to be connected.

Nodes carry different variables in different problems: displacement in structural analysis, temperature in thermal analysis, or potential in field problems. Shared nodal values enforce compatibility between neighboring elements during assembly.
