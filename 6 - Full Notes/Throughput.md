# Throughput

Throughput is the number of work items completed per unit of time. It measures the output of a workflow rather than how busy each person or stage appears.

Together with [[Cycle Time]] and work-in-progress levels, throughput helps a team evaluate whether changes improve the whole flow. Item sizes must remain comparable enough for the count to be meaningful.
