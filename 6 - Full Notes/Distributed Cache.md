# Distributed Cache

A distributed cache is a network-accessible cache shared by several application instances. It gives horizontally scaled processes a common fast copy of data instead of leaving each process with an unrelated in-memory view.

The shared store improves consistency of cached access across instances but adds a remote dependency. Serialization, key design, expiration, invalidation, cache availability, and the behavior on cache failure remain application concerns.
