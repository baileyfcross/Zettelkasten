# NMF Co-Clustering

NMF co-clustering uses a low-rank nonnegative representation to group rows and columns of a matrix together. In a document-term matrix, it can associate document clusters with the word groups that characterize them.

The paired structure often improves interpretation because each object cluster is accompanied by a feature profile. Choosing factor rank controls granularity, and overlapping factor weights may need a rule before they become crisp co-clusters.
