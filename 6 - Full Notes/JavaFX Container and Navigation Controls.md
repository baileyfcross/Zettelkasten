# JavaFX Container and Navigation Controls

JavaFX container controls add interaction to content organization. `TitledPane` can expand or collapse one content region, and `Accordion` coordinates a collection of titled panes so only one is expanded. `ScrollPane` exposes oversized content through horizontal and vertical movement, while `SplitPane` lets the user redistribute space among children without violating their minimum and maximum sizes.

`TabPane` switches among tabbed views, `ToolBar` arranges commands and moves excess items into an overflow menu, and `Pagination` constructs only the currently requested page instead of placing every page in the scene graph. These controls differ from basic [[JavaFX Layout Panes]] because the user can navigate or resize their presentation at runtime.
