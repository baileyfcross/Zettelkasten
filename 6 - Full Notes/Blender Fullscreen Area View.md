# Blender Fullscreen Area View

Blender can temporarily maximize the editor beneath the pointer so it occupies the available application window. This enlarges a 3D Viewport, node editor, image editor, or other area without permanently rebuilding the workspace layout.

The action is useful when a task needs detail or screen space but still belongs within a multi-editor workflow. Returning from the maximized view restores the surrounding areas and their prior arrangement.
