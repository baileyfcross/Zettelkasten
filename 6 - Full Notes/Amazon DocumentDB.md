# Amazon DocumentDB

Amazon DocumentDB is a managed document database with MongoDB-compatible APIs for storing and querying JSON-like documents. Its cluster architecture separates storage from instances and supports replicas for read scaling and availability. API compatibility makes some MongoDB workloads easier to migrate, but it is not the MongoDB engine itself, so supported features, indexes, query behavior, and operational expectations must be tested.
