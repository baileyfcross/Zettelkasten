# Bayesian Description

A Bayesian description is the probabilistic model used by a Bayesian program. It combines a specification expressing the modeler's preliminary knowledge with identification that supplies parameters learned from observed data.

Any valid joint probabilistic model can serve as a description. It exists independently of the question, so the same model can be conditioned and marginalized in several ways.
