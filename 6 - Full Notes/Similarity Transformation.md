# Similarity Transformation

A similarity transformation maps $A$ to $Q^{-1}AQ$ using a nonsingular matrix $Q$. It changes the coordinate representation while preserving the matrix's eigenvalues.

When $Q$ is an [[Orthogonal Matrix]], the transformation becomes $Q^TAQ$, which is easier and usually more stable to compute. [[Matrix Diagonalization]] is a special similarity transformation.

Similarity is precisely the change-of-basis relation between two matrices representing the same linear operator. It therefore preserves not only eigenvalues but also characteristic and minimal polynomials, determinant, trace, and Jordan structure.
