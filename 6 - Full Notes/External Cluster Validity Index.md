# External Cluster Validity Index

An external cluster validity index compares a captured clustering with an independently known classification or expected structure. It measures how closely the algorithm recovers that external criterion.

Pair-counting measures such as adjusted Rand and Jaccard can perform this comparison. The index is available only when trustworthy reference information exists.
