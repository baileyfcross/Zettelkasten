# Module Endomorphism

A module endomorphism is a [[Module Homomorphism]] from a module to itself. It preserves the module's addition and scalar action while transforming its elements internally.

Endomorphisms can be added and composed. They provide algebraic operators on a module and appear when compatible actions or repeated transformations must be studied without changing the ambient module.
