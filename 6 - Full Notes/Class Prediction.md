# Class Prediction

Class prediction assigns a categorical label to a new observation from its measured features. An ideal rule chooses the class with the largest conditional probability for the observed predictor vector.

Because the true conditional probabilities are unknown, an algorithm estimates a decision rule from a [[Training Dataset]]. Performance must then be measured on held-out observations, since accurate classification of the training data can result from [[Overfitting]].
