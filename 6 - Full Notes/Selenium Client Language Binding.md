# Selenium Client Language Binding

A Selenium client language binding is the API used to express browser commands in a programming language such as Java, Python, C#, Ruby, or JavaScript. The binding lets test code create a driver, locate elements, navigate, and perform interactions without speaking directly to the browser.

The binding is the starting point in the book's Selenium architecture. It serializes commands for [[Selenium Command Transport]], which passes them to the appropriate [[Browser Driver]].
