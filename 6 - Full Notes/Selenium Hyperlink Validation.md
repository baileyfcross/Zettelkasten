# Selenium Hyperlink Validation

Selenium hyperlink validation retrieves an anchor's `href` and checks whether the destination is accessible. The book demonstrates sending an HTTP `HEAD` request and interpreting the returned status code, with a successful response indicating that the destination can be reached.

This complements click-based navigation tests by finding broken destinations across a set of links. It should also confirm that a link points to the intended resource, not only that some server responds.
