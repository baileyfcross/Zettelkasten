# Equivalent Fraction

Equivalent fractions are different numerator-denominator forms that represent the same number. For a nonzero factor (k),

$$\frac{m}{n}=\frac{mk}{nk}.$$

For example, (2/3=4/6=10/15). Multiplying both components by the same factor changes the partition used to name the point but not the point itself. Dividing both by a common factor reverses the process and leads toward a [[Fraction in Lowest Terms]]. The equality is justified by the [[Cancellation Law for Fractions]].
