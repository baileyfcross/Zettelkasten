# CSS Line Height

The `line-height` property defines the minimum height of an inline box's line area and contributes to the height of each line box. Extra space beyond the font size is distributed as leading above and below the glyph area.

A unitless number scales with each element's own font size when inherited, whereas a computed length can pass unchanged to descendants. This distinction makes unitless line-height useful across text whose font sizes vary.
