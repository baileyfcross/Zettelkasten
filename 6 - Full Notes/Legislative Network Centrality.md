# Legislative Network Centrality

Legislative network centrality measures a lawmaker's relative position in a political graph. Degree counts direct ties, closeness reflects distance to others, and betweenness reflects participation in paths connecting other legislators.

Computing these measures by session reveals how position changes through a term. Centrality alone omits attributes and does not guarantee electoral success, so it can be combined with homophily and other institutional evidence.
