# Message-Oriented Middleware

Message-oriented middleware lets applications communicate by placing messages into and retrieving them from a [[Message Queue]]. The queue separates senders from receivers in time and location, so the applications do not have to execute together or use the same internal technology.

The delivery model can specify synchronicity, reliability, transactions, ordering, filtering, addressing, and access control. A shared message model preserves meaning while allowing business logic to remain decoupled.
