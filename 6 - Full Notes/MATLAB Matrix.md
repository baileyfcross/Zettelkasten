# MATLAB Matrix

A MATLAB matrix is entered with spaces or commas between columns and semicolons between rows. Matrix variables are the central data structure of MATLAB.

Standard operators implement linear-algebra operations when dimensions are compatible. [[MATLAB Element-Wise Operator|Element-wise operators]] are distinct and apply the operation separately to corresponding entries.
