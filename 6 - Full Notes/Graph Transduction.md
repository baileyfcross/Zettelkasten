# Graph Transduction

Graph transduction predicts labels for the particular unlabeled nodes already present in a similarity graph. It seeks an assignment consistent with known labels and strong connections rather than learning only a general function for future cases.

Because the test nodes participate directly in the optimization, transductive predictions can exploit their joint geometry. New observations usually require rebuilding or extending the graph instead of applying a fixed inductive rule.
