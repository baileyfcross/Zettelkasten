# R Code Comment Style

R code comment style uses comments to explain purpose, assumptions, or non-obvious decisions rather than restating each expression. Consistent spacing and section conventions help readers scan a script.

Comments must be maintained with the code because an obsolete explanation is worse than an absent one.
