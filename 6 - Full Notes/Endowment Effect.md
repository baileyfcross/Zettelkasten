# Endowment Effect

The endowment effect is the tendency to value an object more after it enters one's possession. Giving a player a capability and then taking it away can produce a stronger response than withholding the capability from the start.

The effect is related to [[Loss Aversion]]: surrendering an owned item is experienced as a loss, while receiving the same item is only a gain. Temporary ownership, trial periods, and threatened inventory can therefore change motivation without changing the item's mechanics.
