# AWS Lakehouse Architecture

An AWS lakehouse architecture combines the low-cost, multi-format storage of a data lake with the schema, transaction, governance, and query characteristics associated with a data warehouse. It seeks to reduce copying between isolated lake and warehouse systems while serving analytics and machine-learning consumers from governed data. The architecture still needs catalog consistency and performance design; placing both workloads near S3 does not automatically unify their semantics.
