# R Scatterplot Matrix

An R scatterplot matrix arranges pairwise scatter plots for several quantitative variables in a square grid. It reveals linear and curved associations, clusters, differing spreads, and outliers across many variable pairs before a multivariate model is chosen.

The matrix is symmetric and becomes visually dense as the variable count grows. Selecting a purposeful subset and keeping scales and labels legible produces more information than displaying every available column.
