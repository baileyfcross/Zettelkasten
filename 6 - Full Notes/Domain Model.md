# Domain Model

A domain model is a representation in the [[Solution Space]] that expresses domain concepts, state, and behavior in a form software can enforce. It should use the [[Ubiquitous Language]] and make rules discoverable in the model rather than scattering them through controllers or database procedures. A model is selective: it includes what is needed to solve the chosen problem, not every fact about the real world. Unlike an [[Anemic Domain Model]], it incorporates the operations that change its state.
