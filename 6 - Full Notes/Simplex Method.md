# Simplex Method

The simplex method solves a linear program by moving between basic feasible solutions represented in tableaus. At each iteration it selects an entering variable that can improve the objective and a leaving variable that preserves feasibility.

Pivot row operations update the basis. The process stops when the objective row shows that no permitted entering variable can improve the solution.
