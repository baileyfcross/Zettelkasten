# NVIDIA-SMI

NVIDIA-SMI is a command-line utility for a quick view of NVIDIA GPU visibility, utilization, memory consumption, temperature, power, and active processes. It is a useful first device check because it confirms whether the driver sees the hardware and whether another process occupies resources.

The snapshot is not a substitute for time-series fleet telemetry or profiling. DCGM reveals trends and health, Nsight Systems explains the application timeline, and Nsight Compute provides kernel-level detail after the broader evidence has isolated the problem.
