# XMLHttpRequest

XMLHttpRequest is a browser-provided JavaScript object for transferring data between a web client and server without performing a complete page navigation. Despite its name, it can exchange formats such as JSON as well as XML.

Its low-level event-oriented interface can require substantial code. [[Angular HttpClient]] wraps the underlying request capability in Angular services and exposes results through the [[Observable]] pattern.
