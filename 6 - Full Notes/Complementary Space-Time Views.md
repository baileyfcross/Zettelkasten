# Complementary Space-Time Views

Complementary space-time views present the same dataset through maps, space-time matrices, and time-series plots because each projection of the data sacrifices different relationships. Maps preserve geographic arrangement, XT plots preserve the full temporal history by location, and temporal lines expose trajectories and common changes. Agreement across these views strengthens an interpretation; disagreement often reveals a pattern that one reduction concealed.
