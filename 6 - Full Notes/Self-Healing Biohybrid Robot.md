# Self-Healing Biohybrid Robot

A self-healing biohybrid robot restores function by using living cells to repair damaged biological components. Experiments described in the source added healthy cells to torn muscle actuators and supported recovery of the tissue.

This is not autonomous whole-machine regeneration: detection, cell delivery, matrix repair, synthetic-part damage, and operating conditions still require external support.
