# High-Dimensional Cluster Model

A high-dimensional cluster model specifies whether a group is expected to be compact in the full space, selected original dimensions, a projected linear subspace, or a nonlinear local structure. The model defines which deviations count as within-cluster variation.

Choosing that model before interpreting an output prevents an algorithm's bias from being mistaken for discovered fact. It also guides the appropriate similarity, regularization, search strategy, and validation test.
