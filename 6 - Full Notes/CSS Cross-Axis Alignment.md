# CSS Cross-Axis Alignment

Flexbox cross-axis alignment uses `align-items` to set the default for items and `align-self` to override one item. Values can align starts, ends, centers, baselines, or stretch an auto-sized item across the available cross dimension.

For a multiline container, `align-content` distributes the flex lines themselves across extra cross-axis space. It has no effect when the container has only one flex line.
