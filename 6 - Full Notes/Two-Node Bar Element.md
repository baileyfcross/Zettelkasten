# Two-Node Bar Element

A two-node bar element connects two end nodes and assigns one axial translational degree of freedom to each node. Linear shape functions interpolate displacement between the endpoints.

The element is exact for a constant-area bar with nodal loading under its assumptions. Distributed loading or varying area can be approximated by using a finer mesh of shorter linear elements.
