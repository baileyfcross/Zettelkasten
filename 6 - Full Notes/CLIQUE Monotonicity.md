# CLIQUE Monotonicity

CLIQUE monotonicity states that if a unit is dense in a set of dimensions, every projection of that unit onto fewer dimensions is also dense under the corresponding support threshold. An infrequent lower-dimensional unit therefore eliminates all of its higher-dimensional extensions.

This property supports an Apriori-like levelwise search through subspaces. It reduces computation but does not eliminate redundant descriptions when the same objects form dense units in many related projections.
