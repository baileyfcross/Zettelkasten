# Software Analytics

Software analytics applies data analysis and learning to artifacts created during software development and operation. Source code, commits, defects, crashes, reports, and developer activity provide different feature spaces.

Feature engineering connects these heterogeneous records to prediction targets. Useful representations combine product structure with development process, time, change diffusion, and natural-language evidence.
