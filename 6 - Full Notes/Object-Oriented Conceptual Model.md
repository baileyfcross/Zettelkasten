# Object-Oriented Conceptual Model

An object-oriented conceptual model describes the essential domain objects, features, and relationships that explain a problem and its proposed behavior before target-platform constraints are added. It captures what must be represented rather than the final class implementation.

The model may combine use cases, scenarios, preliminary class diagrams, storyboards, and interface sketches. [[Object-Oriented Design]] then transforms it into concrete classes and collaborations, preserving a visible separation between understanding the problem and choosing how code will realize it.
