# Blender Image Scopes

Blender image scopes translate pixel data into diagnostic displays. A histogram summarizes the distribution of luminance or individual color channels, a waveform shows luminance values across the image, and a vectorscope plots hue and saturation. Sample and sample-line tools inspect a selected point or path more locally.

Scopes supplement vision with measurable evidence. They can reveal clipped whites, crushed blacks, channel imbalance, or excessive saturation that is difficult to judge from a monitor alone. Because each scope answers a different question, color correction should use them together: luminance tools assess brightness structure, while the vectorscope assesses chroma direction and intensity.
