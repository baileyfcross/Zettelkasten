# Cascading Style Sheets

Cascading Style Sheets (CSS) is a declarative language for controlling the presentation of structured documents. A stylesheet associates selectors with property-value declarations, allowing the same document content to be presented without embedding every visual decision in the markup.

The “cascade” combines declarations from authors, readers, and the user agent. When several declarations apply to the same property, [[CSS Cascade and Inheritance|cascade rules]] choose one result by importance, origin, [[CSS Specificity|specificity]], and order.
