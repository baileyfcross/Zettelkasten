# Java Abstract Class

An abstract class represents a partially defined class that cannot be instantiated directly. It can hold fields, constructors, and concrete methods while declaring abstract methods whose implementation is deferred to concrete subclasses.

This form is useful when related types share state or implementation as well as a required operation. Java permits a class to extend only one class, so choosing an abstract superclass commits the subclass to that lineage; a [[Java Interface Contract]] is preferable when unrelated classes only need to promise common behavior.
