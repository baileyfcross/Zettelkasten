# Azure Domain Architect

An Azure domain architect owns the roadmap for a broad field such as cloud, which can include public providers, private cloud, and software-as-a-service products rather than Azure alone. The role is more technically focused than enterprise architecture but still too broad to master every implementation detail. Domain architecture translates enterprise direction into a coherent capability roadmap and supervises initiatives within that scope.
