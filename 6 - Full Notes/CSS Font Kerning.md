# CSS Font Kerning

Kerning adjusts the space between particular pairs of glyphs to improve their visual fit. The CSS `font-kerning` property can request normal font kerning, disable it, or leave the decision to the user agent.

Kerning depends on information available in the selected font and differs from the uniform tracking-like effect of [[CSS Word and Letter Spacing|letter spacing]]. It refines specific pairs rather than adding the same amount between every character.
