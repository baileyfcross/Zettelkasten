# dotnet CLI

The `dotnet` command-line interface creates projects, restores packages, builds source, runs applications, executes tests, and publishes deployment output. Its commands provide a common workflow across operating systems and editors.

Project templates establish the initial SDK and target framework configuration, while later commands operate from the project file's declared dependencies. Command help and template listings make the tool self-describing enough to discover available operations without an IDE-specific menu.
