# Intransitive Game Balance

In the source's terminology, intransitive game balance allows some parts to be plainly more capable than others. Overall balance is achieved by making greater benefits carry proportionately greater costs.

This structure appears in progression systems, where later objects or abilities are intended to be more powerful. A [[Progression Curve]] coordinates cost and benefit so every part retains a viable role at the appropriate point in play.
