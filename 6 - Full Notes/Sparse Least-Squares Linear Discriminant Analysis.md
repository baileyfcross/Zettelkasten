# Sparse Least-Squares Linear Discriminant Analysis

Least-squares Linear Discriminant Analysis encodes class membership in a target matrix and fits the discriminant projection through multivariate least squares. Under a mild rank condition in high-dimensional data, the solution is equivalent to ordinary [[Linear Discriminant Analysis]].

Adding an L2,1 row penalty produces a sparse version that uses one shared subset of original features to construct all discriminant directions. The formulation therefore performs supervised feature selection and feature extraction together.
