# Interaction Technique

An interaction technique is a method that lets a user accomplish a task through a [[User Interface]]. It includes hardware and software: an [[Input Device]] captures user information, software maps that information to an action, and an [[Output Device]] presents the system's response.

The same device can support many techniques, and the same technique can sometimes be implemented with different devices. What matters is whether the mapping is natural, efficient, and appropriate for the task. In a [[3D User Interface]], major technique families support [[3D Manipulation]], [[3D Travel]], [[Wayfinding]], and [[System Control]].
