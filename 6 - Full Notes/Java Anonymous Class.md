# Java Anonymous Class

An anonymous class is an unnamed class declared and instantiated as part of an expression. The expression either extends one named class or implements one named interface, supplies a class body, and immediately returns the new object's reference.

Because the class has no name, it cannot declare a constructor. It can use an instance initialization block, fields, methods, and local classes, and it can capture final or effectively final values from its enclosing block. The form is useful for a compact one-place implementation of an abstract operation or interface.
