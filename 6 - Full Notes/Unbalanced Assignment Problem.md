# Unbalanced Assignment Problem

An assignment problem is unbalanced when its number of origins differs from its number of destinations. Dummy rows or columns with zero assignment cost are added until the cost matrix is square.

The [[Hungarian Method]] can then operate normally. A match to a dummy represents an unused worker, unfilled job, idle machine, or other unmatched entity rather than a real pairing.
