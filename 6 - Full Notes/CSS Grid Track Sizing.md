# CSS Grid Track Sizing

Grid track sizing defines the widths of columns and heights of rows. Tracks can use fixed or percentage lengths, content-based keywords, flexible fractions, and functions such as `minmax()` that place lower and upper bounds on growth.

Intrinsic content can expand a track when the sizing function permits it. Gaps and fixed tracks consume space before [[CSS Fractional Grid Units]] divide the remaining amount.
