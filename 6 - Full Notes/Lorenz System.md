# Lorenz System

The Lorenz system is a set of three coupled nonlinear first-order differential equations originally motivated by a simplified model of convection. Its behavior depends on three parameters controlling dissipation, forcing, and geometric response.

For suitable parameter values, trajectories approach a bounded two-lobed strange attractor while never settling into a periodic orbit. The system demonstrates how deterministic equations can produce long-term unpredictability through sensitive dependence on initial conditions.
