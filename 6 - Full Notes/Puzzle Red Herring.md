# Puzzle Red Herring

A puzzle red herring is an element that appears relevant but does not contribute to the solution. It can support misdirection, but adding many irrelevant elements does not create meaningful complexity when the actual reasoning remains trivial.

Red herrings become harmful when they obscure critical information or force exhaustive checking instead of insight. The puzzle should still provide fair [[Puzzle Breadcrumb|breadcrumbs]] that let the solver reduce the possibility space through reasoning.
