# Amazon EMR Serverless

Amazon EMR Serverless runs applications built on distributed data frameworks without requiring the team to create and manage a persistent EMR cluster. The service provisions compute and memory for a job, scales capacity with demand, and releases it when work completes. It suits intermittent or variable processing, while framework configuration, data layout, job efficiency, permissions, and maximum capacity still determine performance and cost.
