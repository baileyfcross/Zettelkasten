# R Bubble Plot

An R bubble plot extends a [[Scatter Plot]] by mapping a third quantitative variable to point size. Because viewers perceive area rather than radius, the size transformation should make circle area proportional to the encoded value and should include a legend or reference sizes.

Large bubbles can conceal smaller points and make precise comparison difficult. The display is best for revealing broad multivariate patterns, while exact values remain better communicated in a table or labeled subset.
