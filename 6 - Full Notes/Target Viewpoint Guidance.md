# Target Viewpoint Guidance

Target viewpoint guidance helps a user reproduce a required camera or observer pose rather than merely locate an object. The interface compares the current position and orientation with the target view and shows how to reduce the difference.

This is useful when an inspection, photograph, reconstruction, or comparison depends on seeing the scene from a particular perspective. Position and orientation errors need cues that the user can act on separately.
