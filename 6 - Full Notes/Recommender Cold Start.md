# Recommender Cold Start

A recommender cold start occurs when a new user or item has too little interaction history for reliable personalized inference. It is a special case of [[Behavioral Data Sparsity]]: the system must make useful initial suggestions before the feedback loop that normally improves them exists.

Common starting evidence includes a short preference questionnaire, popular items, demographic or contextual data, and item features available to [[Content-Based Recommendation]]. Each source changes the tradeoff between immediate usefulness, user effort, privacy, and premature assumptions. The goal is not perfect personalization on the first interaction, but enough relevant choice to elicit informative feedback.
