# Log Attention Encoding

Log attention encoding represents a sequence of log events with attention that preserves semantic and sequential relationships among templates. It lets an anomaly detector emphasize combinations and positions that signal abnormal execution rather than treating each message independently.

In the LogFormer workflow, this pretrained encoding supplies transferable log knowledge before domain adaptation. The representation is then refined through [[Cross-Domain Log Adapter Fine-Tuning]] for a target system.
