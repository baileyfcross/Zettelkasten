# Microsoft Entra ID

Microsoft Entra ID is a cloud identity provider and directory that represents people, groups, devices, applications, and administrative roles. It authenticates those identities, issues tokens for protected resources, and supplies policy and audit signals to the services that make authorization decisions.

The tenant is its main trust and administration boundary. Unlike an on-premises directory organized around forests, domains, and network reachability, Entra ID uses a flat tenant model and modern protocols such as OAuth, OpenID Connect, and SAML. Its role as an identity control plane connects [[Authentication]], [[Authorization]], [[Microsoft Entra Conditional Access]], governance, and monitoring without making every protected application implement those capabilities independently.
