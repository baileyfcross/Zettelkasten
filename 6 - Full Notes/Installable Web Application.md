# Installable Web Application

An installable web application can be added to a device's application launcher or home screen without passing through a traditional application store. It remains a web application reached from a URL but can open with app-oriented display behavior.

Installation depends on progressive-web requirements such as a [[Web App Manifest]], suitable icons, a [[Service Worker]], and a [[Secure Origin]].
