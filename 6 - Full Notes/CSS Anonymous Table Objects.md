# CSS Anonymous Table Objects

CSS creates anonymous table boxes when table-related display roles appear without the structural parents or children required by the table model. For example, orphaned cells may be wrapped in anonymous rows and a table wrapper.

This repair makes the formatting structure valid without adding elements to the document tree. The generated boxes take part in layout but cannot be selected directly because they do not correspond to source elements.
