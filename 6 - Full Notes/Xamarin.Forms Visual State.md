# Xamarin.Forms Visual State

A Xamarin.Forms visual state groups property setters under a named condition in a visual state group. A control can move among states such as normal, focused, and disabled, applying the corresponding set of visual properties together.

The Visual State Manager reduces duplicated triggers when several properties should change as one condition changes. Custom states can also be activated explicitly when an application-specific condition has no built-in control state.
