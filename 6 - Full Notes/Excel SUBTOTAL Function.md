# Excel SUBTOTAL Function

The Excel SUBTOTAL function applies a selected aggregation, such as sum, average, count, minimum, or maximum, to a range. Its function-number argument chooses the operation and determines whether manually hidden rows are included. Filtered-out rows can be excluded from the displayed summary.

SUBTOTAL is useful for interactive lists because the result follows the currently visible records. It also avoids double counting nested subtotals in its referenced range. A worksheet should choose the function-number variant deliberately, since hidden and filtered rows are different states and can otherwise make two apparently similar totals disagree.
