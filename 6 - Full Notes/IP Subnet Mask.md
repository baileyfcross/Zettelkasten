# IP Subnet Mask

An IP subnet mask identifies which bits of an IPv4 address describe the network and which describe the host within that network. Applying the mask lets a device determine whether a destination is local or must be reached through a router.

Variable-length subnet masking allows the boundary to use an arbitrary prefix length instead of being fixed by the older address classes. That flexibility supports differently sized subnets within the available address space.
