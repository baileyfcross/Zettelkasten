# Git Working Tree State

Git distinguishes changes in the working tree from content staged for the next commit and content already committed to repository history. A file may therefore be modified without being selected for the next snapshot.

This separation lets a developer prepare a coherent commit from only part of the current work. [[Git Status]] exposes the state of tracked, untracked, modified, and staged paths before history is changed.
