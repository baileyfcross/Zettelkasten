# Amazon Cognito

Amazon Cognito manages identities for application users rather than the AWS workforce. User pools provide sign-up, sign-in, and directory features, while identity pools can exchange authenticated identity for temporary AWS credentials to access authorized resources.

The application must still define its user experience, data handling, and authorization model. Cognito keeps customer identity separate from IAM administration, preventing end users from becoming ordinary AWS account users.
