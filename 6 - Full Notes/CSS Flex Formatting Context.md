# CSS Flex Formatting Context

A flex formatting context arranges a container's direct children along a main axis and aligns them along a cross axis. It is primarily one-dimensional: a flex line distributes items in one direction even when wrapping creates several lines.

The axes follow [[CSS Flex Direction]] and the active writing mode rather than always meaning horizontal and vertical. Flexible sizing then distributes positive or negative free space among the items.
