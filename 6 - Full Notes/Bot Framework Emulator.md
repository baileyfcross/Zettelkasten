# Bot Framework Emulator

Bot Framework Emulator is a local client for connecting to a bot service during development. It displays the conversation, raw activity JSON, endpoint and network history, and can save a transcript for later inspection.

The bot remains an HTTP service even when the emulator makes it look like a chat window. Inspecting messages and network details helps separate dialog mistakes from endpoint, authentication, or serialization failures.
