# AWS Local Zone

An AWS Local Zone places selected compute, storage, and other services closer to a metropolitan area while remaining an extension of a parent region. It supports workloads whose latency requirements cannot be met as effectively from the region's ordinary availability zones.

Service availability is narrower than in the parent region, so a design must verify that every required component is supported. Local execution can reduce delay, while regional services still provide control and broader application capabilities.
