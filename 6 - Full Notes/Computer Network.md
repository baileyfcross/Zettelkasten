# Computer Network

A computer network is a set of computational or navigational devices connected by channels that let them exchange information. The set can be small or arbitrarily large, and its nodes do not need to share one hardware type or operating system.

Network software must therefore communicate through defined messages rather than assume access to the remote device's memory or implementation. Distribution introduces latency, partial failure, security boundaries, and asynchronous behavior that are absent from a purely local call.
