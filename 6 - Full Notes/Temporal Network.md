# Temporal Network

A temporal network represents a changing graph as discrete time-indexed layers. Each layer is a snapshot, and interlayer connections associate entities that persist between adjacent times.

Keeping snapshots separate preserves when edges existed and allows communities or diffusion to be followed through time. Aggregating them into one graph can create paths that never existed at any single moment.
