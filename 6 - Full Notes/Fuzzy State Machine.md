# Fuzzy State Machine

A fuzzy state machine assigns degrees of membership to multiple behavior states rather than requiring exactly one state to be active. Contributions from states can be blended according to their weights.

The approach supports gradual changes such as becoming increasingly afraid as health falls. It can avoid abrupt thresholds, though blended behaviors need rules that prevent incompatible actions from producing incoherent results.
