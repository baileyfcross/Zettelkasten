# Flow

Flow is a state of focused absorption in a challenging, uncertain activity. It is supported by understandable goals, clear feedback, concentrated attention, and a match between the participant's skill and the difficulty of the task.

When challenge is too low, boredom threatens; when it is too high, anxiety or frustration takes over. Keeping the activity within this shifting channel can make it an [[Autotelic Experience]] and sustain [[Engagement]].
