# Local Minimum

A local minimum is a point whose objective value is no greater than values at sufficiently nearby feasible points. It describes neighborhood behavior and need not be the smallest value over the entire domain.

A differentiable interior local minimum is normally a [[Stationary Point]]. Positive curvature, expressed by a positive-definite [[Hessian Matrix]], provides a sufficient second-order condition for a strict local minimum.
