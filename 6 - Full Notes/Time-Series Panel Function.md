# Time-Series Panel Function

A time-series panel function defines how the observations assigned to one lattice panel are drawn. It can combine background regions, reference lines, raw curves, points, and text in a deliberate order. Because the high-level plot has already performed subsetting and scale calculations, the panel function receives the panel's coordinates and grouping information. It therefore provides a reusable mechanism for [[Layered Time-Plot Annotation]] across multiple series.
