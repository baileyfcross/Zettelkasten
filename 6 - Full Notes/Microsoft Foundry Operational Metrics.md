# Microsoft Foundry Operational Metrics

Microsoft Foundry operational metrics describe how a deployed AI asset behaves as a service. They include signals such as request volume, latency, errors, token usage, and resource consumption, with Application Insights and related Azure monitoring services providing telemetry for deployed applications.

These measures reveal availability, performance, and cost problems, but they do not by themselves establish that answers are accurate or safe. They should be interpreted beside behavioral evaluation results. A healthy endpoint can return poor content, while a high-quality response path can still be too slow or unreliable for its service objective.
