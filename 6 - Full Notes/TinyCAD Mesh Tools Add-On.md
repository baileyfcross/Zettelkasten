# TinyCAD Mesh Tools Add-On

TinyCAD Mesh Tools supplies geometric construction commands inside Blender Edit mode. Its operations can intersect or extend coplanar edges, create vertices at intersections, bisect planar angles, recover a circle center from three points, and extend an edge to a face.

These operations are useful when a technical model depends on inferred geometric relationships rather than freehand placement. The add-on brings a small set of CAD-like constructions into the mesh-editing context.
