# Web Browser Aggregation

Web browser aggregation groups detailed user-agent strings or browser versions into analytically meaningful browser families. It reduces high cardinality while preserving distinctions relevant to traffic and compatibility analysis.

The mapping should be documented and revisited as new browser labels appear.
