# EXIF Image File Directory

An EXIF image file directory groups related metadata fields within a JPEG or TIFF structure. Typical directories describe the primary image, camera and exposure information, interoperability fields, the embedded thumbnail, and GPS coordinates.

The directory structure matters because metadata are not merely a flat list of labels. Fields can point to related records and previews, allowing an analyst to compare values produced at different stages of capture and storage. Broken relationships or incompatible entries can indicate that a file was altered or rebuilt by other software.
