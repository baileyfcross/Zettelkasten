# Go Build Command

`go build` compiles the selected package and its dependencies and, for a [[Go Main Package]], links a runnable native executable. The build incorporates only required code and targets a particular operating system and hardware architecture.

Unlike an interactive run, the command leaves the compiled result available for later execution or packaging. Compilation also enforces Go rules such as unused ordinary imports and exact type compatibility before a program can be produced.
