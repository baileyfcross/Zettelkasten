# Convex Set

A set is convex when the line segment joining any two of its points remains entirely inside the set. For points $x$ and $y$, every combination $tx+(1-t)y$ with $0\leq t\leq1$ must remain in the set.

Convex feasible regions prevent separated pockets of admissible solutions. A [[Convex Function]] defined on a convex set has especially useful global optimization properties.
