# AWS File Gateway

AWS File Gateway presents NFS or SMB file shares to local applications while storing files as objects in Amazon S3. Frequently used content can remain cached on premises, and cloud-side lifecycle or protection features can apply to the underlying objects.

It is a protocol bridge rather than a conventional shared disk. Applications and administrators must understand how file metadata, object keys, cache consistency, and direct S3 access interact.
