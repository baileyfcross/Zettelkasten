# kable Table

A kable table converts a data frame or matrix into a simply formatted table for a knitr report. It is useful when the underlying result is already organized and needs a readable presentation rather than complex styling.

Labels, units, rounding, and captions should be chosen deliberately instead of exposing raw object names.
