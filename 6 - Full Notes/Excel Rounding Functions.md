# Excel Rounding Functions

Excel ROUND changes a number to a specified number of digits, while ROUNDDOWN moves toward zero and ROUNDUP moves away from zero at the chosen precision. The digit argument can target decimal places, whole numbers, or positions to the left of the decimal point.

Rounding changes the numeric result, unlike a display format that merely hides digits. It should be applied at the stage required by the domain because rounding intermediate values can yield a different total than rounding only the final result. For values that must land on a particular increment rather than a power-of-ten position, use [[Excel Multiple Rounding Functions]].
