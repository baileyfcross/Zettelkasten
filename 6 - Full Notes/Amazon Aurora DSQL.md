# Amazon Aurora DSQL

Amazon Aurora DSQL is a serverless distributed SQL database designed for always-available applications. It separates compute from distributed storage, scales without customers managing database instances, and can operate across availability zones or regions while preserving relational transactions and PostgreSQL-compatible access. Its model targets applications that need SQL semantics and horizontal availability, but compatibility, transaction behavior, latency, and regional topology must be evaluated against the application.
