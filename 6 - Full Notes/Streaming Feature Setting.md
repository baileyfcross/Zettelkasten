# Streaming Feature Setting

A streaming feature setting presents new dimensions sequentially for a collection of observations. The learner must decide how to use or retain each feature without knowing the complete feature space in advance.

This differs from an ordinary data stream because variables, rather than cases, are the arriving objects. Irreversible decisions, feature order, redundancy, and the cost of storing accepted dimensions shape the algorithm.
