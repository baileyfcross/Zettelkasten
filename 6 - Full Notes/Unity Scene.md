# Unity Scene

A Unity scene is a saved arrangement of [[Unity GameObject|GameObjects]] that forms a level, screen, or other runtime context. The Hierarchy shows the objects currently included, while the Scene pane lets an author position, rotate, scale, select, and organize them.

A scene refers to project assets but does not contain every asset in the project. This distinction allows reusable code, models, materials, and [[Unity Prefab|prefabs]] to exist independently and be instantiated where needed. Loading or changing scenes therefore changes the active object graph without redefining the entire project.
