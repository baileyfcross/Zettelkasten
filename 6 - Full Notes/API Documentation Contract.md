# API Documentation Contract

An API documentation contract explains how a consumer can form a request and interpret every expected response. It identifies the URI, method, parameters, request and response formats, authentication, rate limits, status codes, error bodies, and representative examples.

The book treats documentation as part of change communication rather than an afterthought. Version-specific instructions and examples reduce integration ambiguity only when they stay synchronized with the behavior of the deployed service.
