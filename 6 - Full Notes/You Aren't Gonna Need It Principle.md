# You Aren't Gonna Need It Principle

You Aren't Gonna Need It (YAGNI) says to add functionality when a real requirement calls for it, not merely because it might be useful later. Speculative features increase implementation and testing work while potentially shaping the design around a future that never arrives. A small extension seam can preserve adaptability without building the unrequested feature itself.
