# Inscribed Technology

Inscribed technology is the underlying technical capacity built into a game, whether the artifact uses paper, dice, electronics, software, or a networked platform. For a digital game it includes the engine, code, data structures, tools, and platform capabilities available to support the design.

Technology defines a practical [[Possibility Space]]. A seemingly small creative change can require a large engineering investment when the existing architecture cannot express it. Designers therefore need enough technical understanding to recognize when an idea fits the current system and when it changes the system itself.
