# Stacked Bar Chart

A stacked bar chart partitions each bar according to the levels of a second categorical variable. It shows both the size of the primary groups and how the secondary outcome is distributed within them.

The first segment has a common baseline, while later segments do not, so subtle comparisons can be difficult. Frequencies, proportions, and the intended denominator should therefore be made explicit in the labels or accompanying table.
