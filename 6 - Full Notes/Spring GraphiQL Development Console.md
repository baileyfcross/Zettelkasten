# Spring GraphiQL Development Console

GraphiQL is an in-browser development interface for writing and executing GraphQL queries against a compliant endpoint. Spring GraphQL can expose the console at a development route when its configuration property is enabled.

The console helps inspect schema behavior and requested response shapes without building a separate client. Because the endpoint is disabled by default, enabling it is a deliberate development and testing choice rather than an assumed production interface.
