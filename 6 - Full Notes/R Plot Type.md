# R Plot Type

An R plot type determines whether an x-y display draws points, lines, both, vertical segments, or a step pattern. The same coordinates can therefore communicate discrete measurements, a connected trajectory, or a function curve depending on the selected type.

Connecting points implies an ordering that should exist in the data. A line should not be added merely for decoration when neighboring rows have no meaningful sequence.
