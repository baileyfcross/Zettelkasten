# Data-Centric Scientific Computing

Data-centric scientific computing brings computation, visualization, and collaboration to large shared datasets rather than repeatedly copying the data to each researcher. This model becomes necessary when the cost and time of transferring or reacquiring data dominate the analysis itself.

A shared platform can expose storage, processing, and interactive tools around the authoritative data. Reproducibility then depends on identifying the dataset state, preserving analysis provenance, and giving others usable access to the same resources. [[Open Standard for Scientific Interoperability|Open standards]] and a [[Data Sharing Plan]] help independent tools participate in the environment.
