# AWS Backup

AWS Backup centralizes backup policies, schedules, retention, vaults, and recovery points across supported AWS services. Plans can select resources by tags or assignment and copy backups across accounts or regions for stronger isolation. Centralization improves consistency and auditability, but recovery objectives are met only when protected resources, retention, permissions, and restore procedures are tested rather than inferred from a successful backup job.
