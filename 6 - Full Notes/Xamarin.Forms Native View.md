# Xamarin.Forms Native View

A native view is a control from the target platform's UI toolkit embedded within or composed alongside Xamarin.Forms content. It gives a shared application access to a platform component whose behavior or performance is not represented by a standard Xamarin.Forms element.

Using a native view makes that portion of the interface platform-dependent. The application should isolate the view behind a shared contract when other targets need equivalent behavior.
