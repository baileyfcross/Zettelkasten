# Inverse Reinforcement Learning

Inverse reinforcement learning infers a reward function from demonstrated behavior instead of copying each demonstrated action directly. The recovered objective can then guide an ordinary [[Reinforcement Learning]] agent in states that were not shown.

This is useful when people can perform a task but cannot state the criteria that govern all of their choices. The inferred reward is still an interpretation of the demonstrations: incomplete or inconsistent behavior can yield an objective that differs from the demonstrator's actual intent.
