# Blender Technical Annotation Tools

Blender's annotation tools place freehand strokes, straight lines, or polygonal marks in a three-dimensional viewport without turning those marks into model geometry. An annotation eraser removes strokes, while the viewport overlay controls whether the marks are visible.

Annotations can preserve design intent, construction reminders, or review comments beside a model. Because they are guidance rather than geometry, they should not be mistaken for the measured edges or surfaces used to produce an architectural result.
