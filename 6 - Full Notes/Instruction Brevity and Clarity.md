# Instruction Brevity and Clarity

Instruction brevity and clarity communicate the smallest complete statement a player needs to act correctly. Brevity removes language that delays action, while clarity preserves non-obvious consequences that would otherwise make the instruction misleading.

These goals must be balanced. “Press the button near cover” may be short but incomplete if cover also changes how incoming damage is calculated. A useful prompt names the context, action, and important result without explaining unrelated rules. [[Immediate Instruction Timing]] then supplies that message where it can be tested at once.
