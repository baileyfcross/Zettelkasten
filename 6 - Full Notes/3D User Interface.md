# 3D User Interface

A 3D user interface is a [[User Interface]] that involves [[3D Interaction]]. It may combine spatial input, visual, auditory, or haptic output, and software mappings that let a person act in a real or [[Virtual Environment|virtual]] three-dimensional context.

Its main components are [[Input Device]]s, [[Output Device]]s, and [[Interaction Technique]]s. Common task families include [[3D Manipulation]], [[3D Travel]], [[Wayfinding]], and [[System Control]]. Good design requires these parts to work together; individually usable techniques do not automatically form a coherent interface.

3D interfaces appear in [[Virtual Reality]], [[Augmented Reality]], design, training, games, data analysis, medicine, collaboration, and [[Telerobotics]].
