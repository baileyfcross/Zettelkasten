# Go For Loop Forms

Go uses one `for` statement for indexed loops, condition-controlled loops, and infinite loops. The classic form provides optional initialization, condition, and post statements; omitting the outer clauses leaves a while-like condition or an unconditional loop.

`break`, `continue`, and `return` control exit or progression, and labels can target an enclosing loop when nested flow requires it. Collection traversal uses the related [[Go Range Iteration]] form.
