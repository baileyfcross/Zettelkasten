# Trivial Solution

The trivial solution of a [[Homogeneous Linear System]] is the zero vector. It always satisfies $Ax=0$ because multiplying any matrix by the zero vector gives zero.

A nonsingular square system has only this homogeneous solution. Nontrivial solutions exist when the coefficient matrix has a nonzero null space.
