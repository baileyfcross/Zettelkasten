# .NET Desktop Resource Deployment

Desktop resources such as icons and images must be present where the running application expects them after publication. During the book's migration, files that had been included implicitly are declared in the SDK-style project with output-copy behavior.

`PreserveNewest` copies a resource when the source is newer while avoiding an unconditional copy on every build. Resource validation is part of migration because a project can compile successfully and still produce a broken interface when runtime assets are absent.
