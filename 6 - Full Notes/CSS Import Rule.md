# CSS Import Rule

The CSS `@import` rule loads another stylesheet into the current stylesheet. Import rules must precede ordinary style rules, and they can include media conditions that determine when the imported rules participate.

Imports make a stylesheet modular, but the imported resource still enters the same [[CSS Cascade and Inheritance|cascade]]. An import is a CSS-level relationship, whereas [[External Stylesheet Linking]] is declared by the document markup.
