# Test Spy

A test spy observes calls made to a function or service method and can optionally replace its result. It lets a test verify interaction without using the real dependency behavior.

An Angular component test can spy on a data-service method, return controlled values, and then assert how the component responds. The spy is one form of [[Test Double]].
