# Multiplayer Game Lobby

A multiplayer game lobby is a pre-session group in which players discover one another, exchange membership changes, and prepare to start a match. A service can search for compatible lobbies, join one that has space, or create a new lobby when no result is suitable.

The lobby is coordination state rather than the gameplay simulation itself. When the group is ready, it can select a server for a client-server game or distribute peer identities for a peer-to-peer game. Membership callbacks keep every participant's roster current until the transition to the active session is complete.
