# Microsoft Purview Data Governance

Microsoft Purview data governance provides cataloging, classification, lineage, and discovery across a data estate. It helps an organization identify what data exists, where it moves, who owns it, and which policies apply, linking technical metadata to governance responsibilities. Governance coverage is broader than access control alone: scanners, classifications, glossary terms, stewardship, lineage quality, and remediation workflows must remain current as platforms and pipelines change.
