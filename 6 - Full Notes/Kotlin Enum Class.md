# Kotlin Enum Class

A Kotlin enum class defines a fixed set of named instances. Each constant has a `name` and `ordinal`, and the class can declare properties, constructor values, and methods shared by or specialized for those instances.

Operations such as `values` and `valueOf` enumerate or retrieve constants. Enums are appropriate when the alternatives are stable named members of one type, so callers cannot invent an unrecognized value while the program is running.
