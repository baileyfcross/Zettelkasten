# Pumping Lemma for Context-Free Languages

The context-free pumping lemma says that every sufficiently long string w in a context-free language can be written w = uxyzv, where x and z are not both empty, |xyz| is bounded, and uxⁿyzⁿv remains in the language for every n ≥ 0.

The two pumped regions arise from a repeated nonterminal along a sufficiently tall [[Parse Tree]] path. As with the regular pumping lemma, the result is used contrapositively to prove that certain languages are not context-free.
