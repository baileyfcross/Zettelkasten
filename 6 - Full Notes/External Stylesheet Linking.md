# External Stylesheet Linking

An external stylesheet is attached to an HTML document with a `link` element whose relationship is `stylesheet`. The browser retrieves the referenced CSS resource and applies its rules to the document, allowing one file to provide shared presentation across many pages.

Media restrictions, alternate stylesheets, and resource URLs can be declared on the link. Compared with [[Embedded CSS Style Sheets]], external linking separates presentation from an individual document and makes reuse easier.
