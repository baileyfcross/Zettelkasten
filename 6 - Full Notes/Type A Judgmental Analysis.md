# Type A Judgmental Analysis

Type A judgmental analysis has every judge evaluate the same subjects using the same criterion and predictor variables. The common design supports direct comparison of individual policy equations.

Because case exposure is held constant, differences in estimated policy are more plausibly attributed to the judges. The approach requires all judges to complete the shared set of profiles.
