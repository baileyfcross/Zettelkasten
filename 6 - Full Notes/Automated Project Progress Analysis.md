# Automated Project Progress Analysis

Automated project progress analysis synthesizes task status, dependencies, milestones, communication, and risks into an updated account of delivery health. It can identify divergence from plan and prepare reports without manually reconciling every source.

The analysis should link claims to current work items and distinguish completed evidence from optimistic narrative. Missing updates and inconsistent definitions of done must be surfaced rather than silently resolved by the model.
