# Operating System Object Separation

Operating system object separation keeps one user's files, folders, permissions, application space, and memory segments distinct from those belonging to another user. The boundary limits both accidental interference and deliberate unauthorized access.

Separation may be physical, temporal, sandboxed, or cryptographic. Each method trades convenience, resource sharing, and performance against the strength of isolation it provides.
