# Eulerian Path

An Eulerian path is a route through a [[Graph]] that visits every [[Edge]] exactly once. The route need not return to its starting vertex; when it does, it becomes an [[Eulerian Circuit]].

Vertex degrees constrain whether such a path exists. Every intermediate vertex must allow a traveler to enter and leave on different unused edges, so only the starting and ending vertices may have odd [[Vertex Degree]].
