# Static Code Analysis

Static code analysis examines source or compiled structure without executing the application. Rules can identify suspicious control flow, unsafe patterns, style violations, complexity, duplication, and maintainability concerns while the code is still being developed.

Analysis expands review coverage but cannot establish runtime behavior or business correctness. Useful adoption combines actionable rules, manageable severity, and a feedback point early enough that developers can respond.

LLMs can add semantic explanation, finding summarization, false-positive review, and proposed remediation around a static analyzer. The analyzer remains the repeatable localization mechanism, and its structured finding can ground [[Static-Analysis-Guided Vulnerability Repair]] instead of asking a model to inspect an unconstrained codebase.
