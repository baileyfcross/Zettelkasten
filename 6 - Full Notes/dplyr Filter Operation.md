# dplyr Filter Operation

The dplyr `filter` operation keeps rows of an [[R Data Frame]] that satisfy a logical condition. In the source's mouse-weight example, it selects observations belonging to a specified diet before the outcome values are analyzed.

Filtering changes which experimental units contribute to a result, so its condition is part of the analytical definition rather than a cosmetic coding step. Counts and category values should be checked after it runs.
