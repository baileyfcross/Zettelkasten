# Plot Axis Scaling

Plot axis scaling selects the displayed range, tick marks, and label format for a graph. A focused range can reveal small but meaningful differences, as when survival probabilities all remain near one, while a broad range provides context about absolute magnitude.

Scaling must not conceal relevant observations or exaggerate an effect. Analysts should derive plausible limits from descriptive statistics, label the units, and avoid formats such as unnecessary scientific notation when they impede interpretation.
