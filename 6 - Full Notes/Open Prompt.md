# Open Prompt

An open prompt invites a wide range of user requests, as in asking how the assistant can help. It gives the user initiative but provides little linguistic constraint to recognition and understanding.

After an open prompt, the system must perform broad [[Intent Triggering]] and [[Candidate Hypothesis Ranking]]. If confidence is low, it can narrow the interaction with a [[Directed Prompt]].
