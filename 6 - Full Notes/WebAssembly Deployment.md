# WebAssembly Deployment

WebAssembly deployment delivers compiled application code through the web so the browser obtains the current version when it loads the site. This avoids many target-machine installation and update problems associated with conventional desktop software.

The model combines local browser execution with centralized web distribution. Download size remains a deployment concern, particularly when a client framework also ships a runtime and several assemblies.
