# Cloud Backup Service

A cloud backup service receives and retains recovery copies over a network. It can provide remote location, elastic storage, monitoring, and recurring schedules without requiring the consumer to operate a separate physical backup server.

The service does not remove backup design. The consumer must define the fileset, scheme, retention, encryption, provider independence, bandwidth, and restoration objectives before the remote copy becomes dependable recovery capability.
