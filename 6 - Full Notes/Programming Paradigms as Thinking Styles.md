# Programming Paradigms as Thinking Styles

A programming paradigm frames computation through a characteristic set of concepts. Imperative programs command procedures, object-oriented programs coordinate encapsulated objects, and functional programs compose transformations of inputs into outputs.

Different paradigms expose different structures in a problem and hide others. Selecting one is therefore a choice about how to think, represent state, and organize interactions—not merely a choice of syntax.
