# Reverse Image Search

Reverse image search submits an image or image fragment to retrieve visually matching material already indexed on the web. It can reveal an earlier publication, the source from which an element was copied, or variants that have been cropped, recolored, or combined into a new composition.

A confirmed earlier match can strongly clarify [[Image Provenance]], especially when dates and context contradict the current claim. Searching distinctive fragments separately can help when a composite contains material drawn from multiple sources.
