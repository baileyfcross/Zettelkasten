# Machine Realizability of Computational Ideas

A computational idea ultimately has to be realizable by some human or physical machine. Its representation, operations, memory needs, timing, and error behavior must fit an architecture capable of carrying it out.

Machine realizability keeps computational thinking grounded. An elegant procedure may fail as a practical computation when it requires impossible operations, unbounded resources, or an architecture whose behavior does not match the proposed model.
