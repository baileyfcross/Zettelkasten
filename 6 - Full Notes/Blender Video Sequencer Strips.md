# Blender Video Sequencer Strips

A strip represents a piece of media or an effect on the Sequencer timeline. It can be added from Blender's file browser, dragged from the operating system, or created through the Add menu.

Sidebar controls set a strip's name, start frame, channel, blend behavior, crop, timing, lock, and mute state. Higher channels can overlap lower ones, giving the sequence both temporal order and a visual stack.
