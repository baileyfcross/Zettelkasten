# AWS Proton

AWS Proton lets platform teams define reusable infrastructure and deployment templates for serverless and container-based applications. Developers select a standardized service environment instead of reconstructing networking, compute, observability, and delivery configuration for every workload. Template ownership remains with the platform team, allowing updates and policy to be managed centrally while application teams use a self-service path.
