# Amazon Redshift Serverless

Amazon Redshift Serverless supplies data-warehouse capacity without requiring customers to provision and resize a cluster. A workgroup provides compute and a namespace holds database objects and users; capacity scales around query demand. This reduces infrastructure administration for variable analytical workloads, but schema design, data loading, workload isolation, query efficiency, security, and spending limits remain architectural responsibilities.
