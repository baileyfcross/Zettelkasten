# Deadline-Aware MapReduce Scheduling

Deadline-aware MapReduce scheduling estimates the map and reduce capacity a job needs to finish by a specified time. It can treat completion as a constraint while minimizing resources, cost, or the number of missed deadlines.

Reliable estimates must account for input size, task duration, data placement, cluster heterogeneity, phase dependencies, and contention from other jobs.
