# Twitter Metadata Feature

A Twitter metadata feature uses structured fields attached to a post, such as creation time, language, location, client source, reply status, or identifier relationships. It avoids inferring information already encoded by the platform.

Metadata supports filtering, grouping, and contextual prediction. Missingness and changing platform fields are themselves important because not every account or collection method exposes the same values.
