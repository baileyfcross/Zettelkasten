# .NET Standard Mobile Library

A .NET Standard mobile library contains platform-agnostic code compiled against a common API contract implemented by several .NET runtimes. Xamarin platform projects reference the resulting assembly, allowing shared interfaces and application logic to be compiled and tested independently.

This differs from a Xamarin shared project, whose source files are linked into and compiled separately by each target project. The library boundary makes dependencies explicit, although code outside the standard contract still requires a platform abstraction.
