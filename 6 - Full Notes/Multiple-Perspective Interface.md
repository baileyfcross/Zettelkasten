# Multiple-Perspective Interface

A multiple-perspective interface combines views of the same environment from different frames or scales. An egocentric augmented view can provide local guidance while an exocentric map supplies overview, route structure, and destinations outside the current view.

The views may appear simultaneously in separate or layered regions or be visited in sequence. Corresponding landmarks, highlighting, and stable orientation help the user relate detail to overview.
