# Mocked Network Agent Evaluation

Mocked network agent evaluation uses repeatable device, interface, routing, topology, and reachability data to test an investigation without credentials or live infrastructure. A deliberately degraded case can verify whether the agent requests the right tools, notices every unhealthy field, and avoids unsupported conclusions across repeated model runs.

Mocking evaluates workflow behavior rather than production integration. It does not prove that SSH, APIs, timeouts, authentication, or live vendor output will behave correctly, but it provides a safe first gate before those variables are introduced.
