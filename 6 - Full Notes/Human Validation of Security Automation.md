# Human Validation of Security Automation

Human validation of security automation is the accountable review between generated defensive code and permission to affect a live environment. The reviewer confirms the incident scope, commands, target selection, privileges, evidence preservation, failure behavior, and recovery path.

Validation should use tests and representative logs rather than intuition alone. An assistant can produce a persuasive explanation of unsafe code, and a successful happy-path run may hide destructive edge cases. Approval is recorded for a specific version and environment so later AI revisions do not inherit trust automatically.
