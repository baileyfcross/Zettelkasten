# Upper Triangular Matrix

An upper triangular matrix is a [[Square Matrix]] whose entries below the main diagonal are zero. Its determinant is the product of its diagonal entries.

An upper triangular system can be solved by [[Back Substitution]]. In [[LU Decomposition]], the factor $U$ has this form, and [[QR Decomposition]] also produces an upper triangular factor.
