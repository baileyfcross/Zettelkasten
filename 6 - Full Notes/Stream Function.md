# Stream Function

A stream function is a scalar representation of two-dimensional incompressible flow whose derivatives give orthogonal velocity components. Curves of constant stream function are streamlines.

It automatically satisfies mass conservation in the plane. The choice between stream function and velocity potential depends on geometry and which boundary conditions are simpler to express.
