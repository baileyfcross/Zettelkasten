# Horizontal Scalability

Horizontal scalability changes capacity by changing the number of comparable resource instances. Scaling out adds servers or service instances to meet greater demand; scaling in releases them when the demand recedes.

Unlike [[Vertical Scalability]], the individual resource does not have to become more powerful. [[Rapid Elasticity]] applies horizontal scaling dynamically in both directions, normally using pooled and virtualized resources.
