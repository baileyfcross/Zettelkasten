# CSS Grid Formatting Context

A grid formatting context lays out direct child boxes against intersecting rows and columns. An element creates it with a grid display value, after which its children become grid items that can occupy cells or span several tracks.

Unlike the primarily one-dimensional [[CSS Flex Formatting Context]], grid defines both axes together. Source order does not have to determine visual placement, and items can overlap deliberately.
