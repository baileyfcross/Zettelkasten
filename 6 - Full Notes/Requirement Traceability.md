# Requirement Traceability

Requirement traceability connects a stakeholder need to its specification, planned work, implementation, and verification evidence. Work-item relationships make it possible to ask why a change exists and which tests or releases demonstrate it.

Traceability supports impact analysis when a requirement changes. It should expose meaningful dependency and coverage relationships rather than becoming a collection of links that no one maintains or interprets.
