# Windows Desktop App Models

.NET supports several Windows desktop application models with different histories and capabilities. Windows Forms uses an event-driven control model, Windows Presentation Foundation uses XAML and a retained presentation system, and the Universal Windows Platform targets the modern Windows application platform.

Choosing among them depends on operating-system reach, existing code, UI requirements, deployment constraints, and access to platform APIs. Shared .NET libraries can preserve domain logic even when the presentation model is Windows-specific.
