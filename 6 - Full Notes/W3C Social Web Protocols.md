# W3C Social Web Protocols

The W3C social-web family standardizes recurring operations such as creating and updating content, subscribing to another actor, interacting with published objects, and receiving notifications. The source identifies ActivityPub, ActivityStreams concepts, Linked Data Notifications, and Micropub among the specifications used for these tasks.

Each protocol addresses a boundary rather than one complete social product. Micropub provides client-to-server publishing, Linked Data Notifications delivers JSON-LD notifications, and ActivityPub spans client publishing and server federation. Shared representations for actors, activities, objects, links, and collections let independent implementations exchange meaning. [[ActivityPub Federation Model]] shows how those objects move between inboxes and outboxes.
