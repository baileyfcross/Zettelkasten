# Programming

Programming is the activity of translating an intended computational process into a notation a computer can execute. It uses a [[Programming Language]] to express operations and arrange them through sequence, selection, and iteration.

When programming an [[Algorithm]], the programmer preserves the method's logic while accounting for the capabilities and limits of an actual machine. A mathematically valid method can still be implemented incorrectly or encounter machine-specific problems such as [[Integer Overflow]].
