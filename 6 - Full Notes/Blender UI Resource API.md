# Blender UI Resource API

The UI resource API exposes Blender interface themes, colors, and related presentation resources. Its declarations include theme identifiers and functions that retrieve or adjust shaded color values in several numeric forms.

Using shared resources lets custom editor drawing participate in the application's visual system instead of hard-coding every interface color. It complements the widget-building [[Blender UI Interface API]] and the coordinate-focused [[Blender UI View2D API]].
