# TSV Defect Fault Map

A TSV defect fault map records which vertical interconnects failed pre-bond or post-bond tests. Void tests can use charge and discharge behavior, while bonded-pad defects can be identified from abnormal resistance.

The map connects manufacturing diagnosis to runtime protection. [[Defective TSV Crossbar Sharing]] uses it to route the identified vias to a limited number of mitigation circuits rather than protecting every TSV with dedicated hardware.
