# Data Store Selection

Data store selection matches a data set's structure, access patterns, consistency needs, distribution, durability, scale, and cost to a storage technology. The application need is evaluated before choosing a familiar database product.

Different families of data in one system can justify different stores. The choice should include operational skill, migration, backup, observability, and failure recovery rather than comparing only a benchmarked read or write path.
