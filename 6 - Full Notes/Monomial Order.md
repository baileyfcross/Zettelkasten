# Monomial Order

A monomial order is a total order on monomials that places every nonconstant monomial above 1 and is preserved by multiplication. It determines which monomial of a polynomial is treated as leading.

Different orders can produce different [[Initial Ideal]]s and Gröbner bases for the same ideal. An elimination order is chosen when certain variables should be removed from the resulting equations.
