# Entity Framework Core

Entity Framework Core is an open-source [[Object-Relational Mapping|object-relational mapper]] for .NET applications. It lets application code work with domain-specific object classes while mapping their persistent state to a relational database.

An EF Core model combines entity classes, relationships, conventions, and annotations. A [[Database Context]] coordinates access, a database provider connects the model to a DBMS, and [[Entity Framework Migration|migrations]] translate model changes into schema changes.
