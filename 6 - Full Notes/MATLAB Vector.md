# MATLAB Vector

A MATLAB vector is a one-dimensional numeric array written as a row or column. Spaces or commas separate row entries, and a semicolon or transpose can create a column.

The [[MATLAB Colon Operator]] efficiently constructs regularly spaced vectors. Vector orientation matters for matrix multiplication even when the same components are present.
