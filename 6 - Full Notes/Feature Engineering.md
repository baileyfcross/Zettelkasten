# Feature Engineering

Feature engineering changes how data objects are represented so an analytic method can use their relevant structure. It includes feature transformation, generation, extraction, selection, analysis, evaluation, automated construction, and application-specific design.

Its purpose is not simply to increase the number of variables. The engineered representation should improve the task at hand while remaining computationally manageable and, when needed, understandable. Different data types and applications therefore demand different construction and selection strategies.
