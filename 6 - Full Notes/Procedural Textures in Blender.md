# Procedural Textures in Blender

A procedural texture is generated by an algorithm rather than loaded from a fixed image. It can be added as a texture node in the Shader Editor and adjusted through parameters that define its pattern.

Procedural data can serve materials as well as brushes used for painting, sculpting, or Grease Pencil. Because it is calculated, its scale and placement depend strongly on the coordinate system supplied to it.
