# Quantile Map Classification

Quantile map classification assigns approximately equal numbers of regions to each class. It uses the color range evenly and makes relative rank easy to inspect, especially when values are skewed. Unequal numeric widths mean neighboring classes can be separated by a tiny difference while one class spans a large range. A quantile [[Classed Choropleth]] therefore represents position in the distribution more directly than absolute magnitude intervals.
