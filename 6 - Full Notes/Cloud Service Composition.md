# Cloud Service Composition

Cloud service composition combines distinct cloud services or cells into a new service. Unlike [[Cloud Service Aggregation]], the components perform different functions that contribute to the whole.

Standardized interfaces, requirements, and management characteristics make components reusable across compositions. Changes to a standard cell must be tested in every composite service that uses its replicas because one update can affect several contexts.
