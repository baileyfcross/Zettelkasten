# Statistical Code Module

A statistical code module is a short file devoted to one coherent operation, such as importing data, checking distributions, recoding variables, fitting models, or producing tables. Focused modules make the purpose and output of each stage easier to inspect.

Modules should be organized into an explicit [[Reproducible Statistical Pipeline]]. When an early definition changes, the analyst can rerun the ordered stages and verify that every downstream dataset and result reflects the correction.
