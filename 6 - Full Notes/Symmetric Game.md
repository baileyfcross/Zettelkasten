# Symmetric Game

A symmetric game gives players the same starting conditions, goals, and rules. Symmetry makes fairness easier to establish because structural advantages are minimized.

Equal structure does not guarantee an interesting or perfectly even match: position, chance, and skill still matter. It provides a clear baseline from which remaining advantages can be examined.
