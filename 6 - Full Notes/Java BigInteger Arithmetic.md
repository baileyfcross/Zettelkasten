# Java BigInteger Arithmetic

Java `BigInteger` represents immutable integers of arbitrary precision. It can hold magnitudes beyond the range of `long`, and its operations behave as though the values used two's-complement representation.

Methods such as `add`, `subtract`, `multiply`, and `divide` return new BigInteger objects rather than modifying either operand. The class also supplies integer-oriented operations for modular arithmetic, greatest common divisors, prime testing and generation, and bit manipulation.
