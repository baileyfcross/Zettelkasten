# Java Annotation Type

A Java annotation type declares metadata that can be attached to program elements. Marker annotations carry no elements, while other annotations expose named values whose types and defaults are defined by the annotation declaration.

Meta-annotations state where and how the metadata exists. `@Target` limits permitted element kinds and `@Retention` determines whether information remains only in source, in the class file, or at runtime for reflection. An annotation does not execute behavior by itself; a compiler, framework, tool, or program must interpret it.
