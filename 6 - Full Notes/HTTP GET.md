# HTTP GET

HTTP GET retrieves a representation of a resource without asking the server to change it. An ASP.NET Core GET action uses route and query values to identify or shape the requested data and returns a result the React client can read.

Collection GET endpoints often accept paging, sorting, or filtering parameters. Their response contract should distinguish an empty collection from a missing individual resource.
