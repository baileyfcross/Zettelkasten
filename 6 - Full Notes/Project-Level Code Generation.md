# Project-Level Code Generation

Project-level code generation modifies or creates functionality across a repository rather than producing an isolated snippet. It must understand architecture, dependencies, conventions, build systems, tests, and the consequences of changing several files.

Large codebases exceed simple prompt context and make fine-grained change risky. A [[Code Agent]] addresses this by navigating for relevant context, using tools, implementing incrementally, and testing within a controlled environment.
