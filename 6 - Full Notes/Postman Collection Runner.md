# Postman Collection Runner

The Postman Collection Runner executes a sequence of saved API requests and their test scripts with a selected environment or data set. It turns an interactive collection into a repeatable check of status codes, payloads, and cross-request behavior.

Runner results can reveal contract regressions, but they remain dependent on test data and environment state. Repeatable setup and assertions are necessary before a run can serve as dependable automated evidence.
