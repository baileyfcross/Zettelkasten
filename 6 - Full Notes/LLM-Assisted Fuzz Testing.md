# LLM-Assisted Fuzz Testing

LLM-assisted fuzz testing uses code and interface semantics to propose seeds, mutations, or input structures likely to exercise unusual behavior. Language understanding can make generation more targeted than purely random bytes for structured formats and APIs.

The fuzzer still needs automated execution, crash detection, deduplication, minimization, and reproducibility. Model suggestions expand the search strategy but only runtime evidence establishes that an input reaches a defect.
