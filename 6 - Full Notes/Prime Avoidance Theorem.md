# Prime Avoidance Theorem

The prime avoidance theorem states that if an [[Ideal]] is contained in a finite union of [[Prime Ideal]]s, then it is contained in one of them. The finite union cannot cover the ideal only by distributing different elements among different primes.

A dual intersection statement says that if a prime contains a finite intersection of ideals, then it contains at least one of those ideals. These forms help select elements outside specified primes.
