# Microsoft Foundry Workflow

A Microsoft Foundry workflow is a node-based execution graph that connects model calls, agent invocations, transformations, conditions, tool calls, messages, and human review. It moves orchestration out of a long prompt and into explicit steps whose inputs, outputs, and dependencies can be inspected.

The visual structure improves debugging and governance because teams can identify where classification, validation, routing, or escalation occurs. A workflow is most useful when behavior should be repeatable and auditable. It can still contain probabilistic model nodes, but conventional flow logic decides how their structured results move through the larger process.
