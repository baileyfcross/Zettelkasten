# CSS Grid Item Placement

A grid item can be placed by naming its starting and ending row and column lines, by giving a start plus a span, or by assigning it to a named grid area. Row and column shorthands combine the corresponding edges.

Explicitly placed items can overlap, and placement outside the declared template can cause [[CSS Implicit Grid|implicit tracks]] to be created. Unspecified axes remain available to the auto-placement algorithm.
