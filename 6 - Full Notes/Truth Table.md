# Truth Table

A truth table lists the value of a [[Compound Propositions|compound proposition]] for every assignment of truth values to its [[Propositional Variable|propositional variables]]. A formula with n distinct variables requires 2^n rows because every variable independently has two possible values.

Truth tables mechanically test whether two formulas are [[Logically Equivalent]] and whether a formula is a [[Tautology]]. Their exhaustive character is reliable for small formulas but becomes impractical as the number of variables grows.
