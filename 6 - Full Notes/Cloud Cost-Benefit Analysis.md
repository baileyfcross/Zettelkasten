# Cloud Cost-Benefit Analysis

A cloud cost-benefit analysis compares the full costs of a cloud service with the benefits it is expected to deliver. Benefits can include flexible capacity, earlier revenue, broader access, lower asset ownership, and more attention available for the organization's primary work.

The analysis should use comparable time periods and include switching, integration, support, risk, and dependency rather than only the advertised subscription. [[Net Present Value]], [[Return on Investment]], and [[Payback Period]] turn parts of the comparison into financial measures.
