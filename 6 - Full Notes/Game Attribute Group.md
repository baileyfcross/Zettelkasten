# Game Attribute Group

A game attribute group combines several candidate measures under one broader attribute that is practical for the game's mechanics. A simple action game might fold lifting, striking, and carrying measures into Strength while grouping aiming and acrobatics under Dexterity.

Grouping occurs after brainstorming, research, and definition, so potentially useful distinctions are not discarded too early. The categories need not reproduce real life perfectly; they need to make the designed universe understandable and operational. Unused candidates can remain in an attribute bank for another game rather than burdening the current object model.
