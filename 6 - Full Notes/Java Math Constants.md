# Java Math Constants

The Java Math class exposes double-precision constants for `E`, `PI`, and `TAU`. They approximate the base of natural logarithms, the ratio of a circle's circumference to its diameter, and the ratio of circumference to radius.

These named values make formulas state their mathematical quantities instead of embedding unexplained decimal literals. Circle calculations can use `PI` with a radius or diameter, while trigonometric loops can use multiples of `PI` to describe complete angular ranges.
