# Compile-Time Error and Runtime Exception

A compile-time error prevents source code from being successfully built, while a runtime exception interrupts a program after it has compiled and begun executing. The distinction identifies whether the compiler rejected the program or execution encountered a condition the running code could not continue through normally.

Exception handling addresses anticipated runtime failure paths. It cannot repair syntax or type errors that stop compilation before the program exists as an executable artifact.
