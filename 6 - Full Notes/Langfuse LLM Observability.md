# Langfuse LLM Observability

Langfuse LLM observability tracks interactions, prompts, responses, token use, model parameters, latency, errors, and multi-step workflow traces. It can connect an end-user request to API gateways, vector databases, tools, and model endpoints for debugging and optimization.

Self-hosting on Kubernetes supplies scaling and integration with Prometheus, Grafana, and OpenTelemetry, but also makes Langfuse a sensitive data store. Access policy, redaction, encryption, retention, and deletion must reflect the privacy of the interactions it records.
