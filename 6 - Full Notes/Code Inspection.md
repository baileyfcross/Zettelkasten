# Code Inspection

A code inspection is a formal, trained review process whose sole meeting objective is to find defects in a bounded work product. Participants prepare independently, use roles and defect checklists, and record findings and effort so the process can be followed up and measured.

The meeting deliberately avoids solving the defects it identifies. Separating detection from repair keeps attention on complete discovery, after which the author performs rework and the moderator verifies the result.
