# Processing Date Effect

A processing date effect is a [[Batch Effect]] associated with the day, month, or period when samples were measured. Changes in reagents, calibration, environment, or procedures can make samples processed near one another more similar than biology alone predicts.

Date metadata can expose this structure through correlations and principal-component plots. Treating only a coarse month indicator may leave finer daily variation unmodeled.
