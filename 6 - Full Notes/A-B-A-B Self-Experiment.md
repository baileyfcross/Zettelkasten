# A-B-A-B Self-Experiment

An A-B-A-B self-experiment alternates a baseline condition A with an intervention condition B, then repeats both phases. If an outcome changes with B, returns toward baseline with A, and changes again when B returns, the repeated reversal is stronger evidence than a single before-and-after comparison.

The design requires an outcome that can respond within each phase and an intervention that can be started and stopped safely. It is poorly suited to irreversible changes or effects that persist long after the intervention ends. Daily life also introduces confounding events, so records of context remain important.

This is one way to give an [[N-of-1 Experiment]] a deliberate internal comparison while keeping its conclusion limited to the person and conditions studied.
