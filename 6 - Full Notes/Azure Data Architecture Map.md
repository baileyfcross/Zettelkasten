# Azure Data Architecture Map

The Azure Data Architecture Map organizes a platform by ingestion, processing, raw storage, serving, visualization, governance, operational databases, and infrastructure enablers. It maps recurring capabilities and patterns to possible Azure services without asserting one universal stack. Reading the map from required capability to service choice keeps an architect from selecting an all-in-one platform before clarifying latency, data shape, security, ownership, and consumer needs.
