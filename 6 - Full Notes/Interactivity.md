# Interactivity

Interactivity is a reciprocal cycle in which two or more agents act on and affect one another in a contextually related way. In a game, player input changes the game state and the game's feedback changes the player's mental state.

This reciprocity distinguishes interaction from one-way reaction. The resulting [[Game-Player System]] can carry several nested timescales, from rapid [[Action-Feedback Interactivity]] to slower cognitive, social, emotional, and cultural loops.
