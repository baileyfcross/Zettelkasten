# Inertial Navigation Drift

Inertial navigation derives velocity and position by integrating measurements from gyroscopes and accelerometers. Small sensor biases and alignment errors are integrated along with real motion, so the estimated state gradually diverges from the true state. The system is self-contained, passive, and immune to radio jamming, but it periodically needs an external position fix unless its mission is short. Satellite measurements and inertial estimates therefore complement one another: one supplies absolute correction and the other continuity.
