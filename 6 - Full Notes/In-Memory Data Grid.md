# In-Memory Data Grid

An in-memory data grid distributes key-value or object data across the memory of multiple machines. Partitioning and replication provide a shared data space that can grow beyond one server while keeping access faster than disk-oriented storage.

Applications can place computation near partitions, but concurrent updates require consistency, isolation, and failure-recovery mechanisms across nodes.
