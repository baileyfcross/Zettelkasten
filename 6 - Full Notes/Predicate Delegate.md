# Predicate Delegate

`Predicate<T>` is a C# delegate whose result is Boolean, naming a test applied to a value of type `T`. The book uses a product-name predicate to decide whether a name meets a title-case rule before including the product in a result sequence. Keeping the criterion as a callable value separates the selection mechanism from the business rule being tested.
