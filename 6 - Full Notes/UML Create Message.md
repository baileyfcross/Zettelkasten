# UML Create Message

A UML create message indicates that one participant creates another during the interaction. The message points to the new participant's header, and that lifeline begins at the creation point rather than at the top of the diagram.

This makes object lifetime part of the scenario and distinguishes a newly constructed collaborator from one that already existed when the interaction began.
