# CSS 3D Transform Functions

CSS three-dimensional transforms extend translation, scaling, and rotation onto a z-axis. Functions can move an element toward the viewer, rotate around individual axes or an arbitrary vector, and express a combined transform with a 4-by-4 matrix.

Depth becomes visible when the scene has perspective, and child elements can either preserve their 3D relationships or be flattened into the parent's plane. [[CSS Transform Perspective and Backface Visibility]] controls key parts of that presentation.
