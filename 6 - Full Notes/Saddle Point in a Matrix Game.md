# Saddle Point in a Matrix Game

A saddle point is a payoff-matrix entry that is both the minimum in its row and the maximum in its column. Equivalently, it exists when the row player's maximin equals the column player's minimax.

The entry gives the value of the game and its row and column identify optimal pure strategies. Neither player can improve unilaterally, so the solution is stable and the game is deterministic in the book's terminology.
