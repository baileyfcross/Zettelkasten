# Inline CSS Styles

An inline style stores declarations in an element's `style` attribute. Because the declarations are attached directly to one element, no selector is needed and the styling is difficult to reuse across other elements.

Inline declarations receive a dedicated, very strong position in [[CSS Specificity]], although an important declaration can still alter cascade precedence. Inline styles therefore trade structural reuse for a narrowly targeted declaration source.
