# Neural Network Classification

Neural network classification learns a mapping from input attributes to output class representations through weighted connections and nonlinear activation functions. Training adjusts the weights from differences between predicted and target outputs.

Multilayer networks can form nonlinear decision boundaries that a single perceptron cannot. Performance should be checked on observations not used to update the weights.
