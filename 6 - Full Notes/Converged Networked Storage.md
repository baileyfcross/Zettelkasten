# Converged Networked Storage

Converged networked storage carries remote storage traffic over the same general network technology used for ordinary communication, commonly Ethernet. Consolidation can simplify cabling and management while using widely available hardware.

The shared fabric must still meet storage expectations for latency, throughput, loss handling, ordering, and isolation from unrelated network traffic.
