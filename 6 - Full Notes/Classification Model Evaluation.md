# Classification Model Evaluation

Classification model evaluation tests whether a fitted classifier is accurate, reliable, and valid beyond the records used to construct it. A pilot or held-out test set can be temporarily treated as unseen data and then compared with its known labels.

Evaluation should reflect the intended application and class costs. A high training score alone can conceal overfitting.
