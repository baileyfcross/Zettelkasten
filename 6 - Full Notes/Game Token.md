# Game Token

A game token is a representational object with defined state and behavior. Tokens are the game's nouns: characters, cards, currency, territory, time, or any other object whose condition can be represented and changed.

Tokens communicate selected aspects of the [[Game Model]] to the player. Combined with [[Game Rule|rules]], they form [[Game Mechanic|mechanics]] and the concrete parts from which game systems are built.
