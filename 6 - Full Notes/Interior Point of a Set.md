# Interior Point of a Set

A point $p$ is an interior point of a set $S\subseteq\mathbb{R}^n$ when some [[Open Ball]] centered at $p$ lies completely inside $S$.

The radius may depend on the point; only the existence of one positive radius is required. A set is an [[Open Set in Euclidean Space]] exactly when all of its points are interior points.
