# Java Text Reversal with StringBuffer

`StringBuffer.reverse()` replaces a buffer's character sequence with the same characters in reverse order and returns the mutable buffer. A program can append command-line words and separators, reverse the assembled sequence in place, and convert the result to String for output.

This operation reverses characters, not the logical order of whole words while preserving each word's spelling. Its in-place mutation distinguishes it from String transformations, which return another immutable object.
