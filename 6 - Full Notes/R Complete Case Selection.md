# R Complete Case Selection

R complete case selection identifies rows with no missing values in the variables being considered. Applying the test to only the variables required by an analysis avoids discarding a record because of an unrelated missing field.

The operation is a filtering rule, not evidence that deletion is unbiased. The number and characteristics of excluded records should be reviewed before the resulting [[R Data Frame]] is used for inference.
