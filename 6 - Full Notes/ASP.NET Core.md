# ASP.NET Core

ASP.NET Core is an open-source, modular web framework for building HTTP services. It can run cross-platform on .NET Core and separates hosting, configuration, services, and request handling into parts that an application can assemble for its own needs.

An ASP.NET Core application commonly starts a [[Web Host]], accepts traffic through a [[Web Server]], and processes each [[HTTP Request]] through ordered [[ASP.NET Core Middleware|middleware]] before routing it to an endpoint such as an [[MVC Controller]].
