# R Data File Naming

R data file naming distinguishes serialized workspaces or objects from scripts and source data. Consistent extensions and lowercase descriptive names help tools and collaborators infer the file's role.

Generated data filenames should also encode versioning or provenance through the workflow rather than ad hoc renaming.
