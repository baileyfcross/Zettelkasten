# Code Pattern Detection

Code pattern detection classifies or compares programs to identify clones, recurring structures, likely types, defects, or reasoning patterns. Learned representations can recognize semantic similarity even when two implementations use different surface syntax.

The task may operate on code pairs, token labels, or larger program representations. Results are hypotheses for review or downstream tools, since training-corpus bias and project conventions can make a generally learned pattern misleading locally.
