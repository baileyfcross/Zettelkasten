# Stored-Program Principle

The stored-program principle places instructions and data in a common high-speed memory. A processor can fetch both electronically, avoiding the mechanical or manual delays of tapes, cards, and plugboards.

Because instructions share the same representation as data, a program can generate, copy, or modify other programs. This principle enabled compilers and flexible general-purpose computing.
