# Load Testing

Load testing sends repeated or concurrent requests to observe an application's behavior under demand. It reveals how latency and successful request rates change as work approaches the capacity of the API, database, or host.

A useful test targets a representative endpoint with a repeatable scenario. Results should be compared before and after an optimization rather than treated as an isolated score.
