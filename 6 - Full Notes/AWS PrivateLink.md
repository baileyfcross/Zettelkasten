# AWS PrivateLink

AWS PrivateLink exposes a service privately to consumer VPCs through interface endpoints. Traffic uses private IP addresses and the AWS network, so consumers do not need an internet gateway, NAT, VPC peering, or routes into the provider VPC. The relationship is deliberately service-oriented and one-way: consumers reach the published service without gaining general network reachability to the provider environment.
