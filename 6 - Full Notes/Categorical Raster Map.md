# Categorical Raster Map

A categorical raster map assigns a qualitative color to each cell class, such as forest, water, urban land, or snow. Integer cell codes are commonly decoded through a [[Raster Attribute Table]]. Unlike a [[Quantitative Raster Map]], the palette should distinguish categories without implying numeric order. Missing values need a background treatment that is visibly separate from every valid class.
