# AWS Migration Evaluator

AWS Migration Evaluator collects or imports information about an existing environment to develop a data-supported business case for migration. It analyzes infrastructure utilization and cost so proposed AWS configurations can be compared with the current operating model.

The assessment helps replace simple server-count comparisons with measured demand and total-cost assumptions. Its output remains a planning estimate; application dependencies, migration effort, licensing, risk, and organizational change also influence the actual outcome.
