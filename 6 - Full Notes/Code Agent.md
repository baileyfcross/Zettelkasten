# Code Agent

A code agent combines a code-focused language model with planning and tools for repository navigation, documentation lookup, implementation, static analysis, execution, and testing. It iterates on tool results so project-level work is not limited to one generated completion.

The agent's authority should be bounded by its workspace and task, with changes exposed as reviewable diffs. Tool integration improves evidence and feedback but does not eliminate the need for human ownership and acceptance criteria.
