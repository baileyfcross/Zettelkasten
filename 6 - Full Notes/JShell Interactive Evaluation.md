# JShell Interactive Evaluation

JShell is the JDK's read-evaluate-print loop for executing Java declarations, expressions, and statements without first constructing a complete application. It keeps definitions alive across snippets, shows evaluated results, supports imports and methods, and provides commands for inspecting, editing, saving, or resetting the session.

This makes JShell useful for learning syntax and testing a small API call. It is not a substitute for a structured project: session state and shortened declarations can hide the package, module, build, and test boundaries that normal source files make explicit.
