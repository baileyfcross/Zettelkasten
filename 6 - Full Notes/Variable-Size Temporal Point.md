# Variable-Size Temporal Point

A variable-size temporal point encodes an additional quantitative variable through symbol area in a time-conditioned scatterplot. Class intervals can reduce a continuous variable to a small set of discriminable sizes, while color identifies groups and position encodes two other variables. Because people judge area imperfectly, the size scale and legend must be explicit. Severe overlap can obscure small points and should be managed through transparency or interaction.
