# Excel Conditional Aggregation Functions

Excel SUMIF and COUNTIF aggregate records meeting one criterion, while SUMIFS and COUNTIFS support several criteria. Each criteria range is tested record by record; SUM functions then add a target range, while COUNT functions count the matching records.

Multiple criteria in the `IFS` variants normally act together as AND conditions. Target and criteria ranges must align, and text criteria containing comparison operators require the syntax Excel expects. These functions make common filtered summaries readable, while [[Excel SUMPRODUCT Function]] can express cases that need array arithmetic or more flexible combinations.
