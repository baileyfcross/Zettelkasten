# Integration by Substitution

Integration by substitution reverses the chain rule. If an integrand contains a composite function together with the derivative of its inner expression, defining a new variable for that inner expression can reduce the integral to a standard form.

The differential must be transformed along with the variable. For a definite integral, the limits can either be converted to the new variable or the antiderivative can be returned to the original variable before the endpoints are applied.
