# .NET Text and XML Streams

Byte streams become text streams through readers and writers that apply a character encoding. `StreamReader` and `StreamWriter` provide line- and character-oriented operations, while `XmlReader` and `XmlWriter` process structured XML incrementally.

These wrappers compose with an underlying stream, so representation concerns stay separate from transport and storage. Incremental reading is especially valuable for large documents because an application can process content without first materializing the whole document in memory.
