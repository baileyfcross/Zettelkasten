# AWS Application Migration Service

AWS Application Migration Service supports server rehosting by installing a source agent, continuously replicating source disks into a staging area, and creating launchable AWS instances for nondisruptive tests and cutover. Continuous block-level replication keeps the target close to the source while teams validate launch settings. The service automates much of the movement, but application dependency testing and business cutover decisions remain part of the migration plan.
