# On-Demand Self-Service

On-demand self-service lets a cloud consumer obtain or release computing capability when it is needed without waiting for routine manual interaction with the provider. A portal or automated interface can turn a request into provisioned resources almost immediately.

This characteristic requires more than spare virtual machines. Standardized offerings, orchestration, capacity management, reporting, and access controls must work together so that self-service remains dependable and governed.
