# Scientific Simulation as an Abstract Machine

A scientific simulation realizes a mathematical model as an executable abstract machine. Variables become state, equations become transition rules, and repeated execution produces a history of the modeled phenomenon.

This translation requires choices about representation, approximation, and numerical method. Those choices are part of the scientific claim because they determine which behavior the simulation can and cannot reproduce.
