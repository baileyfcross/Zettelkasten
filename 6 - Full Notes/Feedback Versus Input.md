# Feedback Versus Input

Playtest feedback describes where the game did or did not produce the intended experience. Input proposes a change to the work. Both can be useful, but they carry different authority.

The designer owns the diagnosis and solution because a tester's suggestion may solve a different problem or contradict the project's values. Separating the observed shortfall from the proposed feature lets the team consider several remedies without dismissing the underlying evidence.
