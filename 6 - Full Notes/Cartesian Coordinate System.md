# Cartesian Coordinate System

The Cartesian coordinate system locates a point in the plane by an ordered pair $(x,y)$. Perpendicular number lines meet at the origin, the first coordinate measures horizontal displacement, and the second measures vertical displacement. This translation between points and numbers allows geometric objects to be studied through equations.
