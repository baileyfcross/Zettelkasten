# AR Application Architecture

AR application architecture organizes tracking, world modeling, simulation, interaction, rendering, and display into a real-time system. It must coordinate physical processes the software does not fully control while keeping virtual state consistent with them.

Practical architectures also accommodate changing devices, distributed computation, large object collections, and rapid experimentation. Hardware and user-interface abstractions, dataflow components, scene graphs, scripting, and runtime inspection address different parts of that complexity.
