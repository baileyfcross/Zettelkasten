# Java Object Superclass

`java.lang.Object` is the ultimate superclass of Java classes. A class that does not explicitly extend another class still directly extends Object, while a subclass reaches it indirectly through its inheritance chain.

Object establishes operations common to every class, including equality, hashing, string representation, runtime-class access, cloning support, and thread coordination methods. Their inherited defaults form a contract that a class may override where its own value or diagnostic semantics require it.
