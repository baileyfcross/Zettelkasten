# Static Friction

Static friction adjusts to oppose impending relative motion between contacting surfaces, up to a limiting value $F_s\leq\mu_sN$. Motion begins when the required friction exceeds that limit. Once sliding starts, kinetic friction is usually lower, so the coefficient of static friction should not be substituted automatically for a moving interface.
