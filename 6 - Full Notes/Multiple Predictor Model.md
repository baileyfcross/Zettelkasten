# Multiple Predictor Model

A multiple predictor model relates one response to several explanatory variables in the same fitted equation. Each coefficient describes how prediction changes with its predictor when the other modeled predictors are held fixed, within the assumptions and range of the data.

In R, a formula or design matrix adds one column for each coefficient to be estimated. Graphical assessment becomes harder beyond two predictors, so residual checks and carefully chosen conditional views must supplement a single fitted surface.
