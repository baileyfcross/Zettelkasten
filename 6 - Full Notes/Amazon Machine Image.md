# Amazon Machine Image

An Amazon Machine Image is a regional template used to launch EC2 instances. It defines a boot operating system, block-device mapping, and optional preinstalled software or configuration.

AWS Quick Start, community, Marketplace, and customer-owned images provide different trust and support relationships. A custom AMI can standardize patched application hosts, but it must be rebuilt or maintained as software and security requirements change.
