# Streaming Locally Linear Embedding

Streaming Locally Linear Embedding extends neighborhood-preserving manifold learning to arriving data. It incrementally places new observations using local reconstruction relationships instead of rebuilding the entire embedding.

The approach preserves nearby geometry when neighborhoods remain informative. A changing manifold, insufficient stored landmarks, or expensive neighbor search can weaken both accuracy and scalability.
