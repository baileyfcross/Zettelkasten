# Development Environment

A development environment is configured for creating and diagnosing an application. It may enable detailed error pages, verbose logging, development signing material, and tooling that should not be exposed publicly.

Environment-specific configuration can override general settings without changing production values. Publishing an application must explicitly select the intended [[Production Environment]] rather than carrying development diagnostics forward.
