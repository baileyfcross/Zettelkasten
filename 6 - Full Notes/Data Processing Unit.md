# Data Processing Unit

A data processing unit, or DPU, is a programmable processor optimized for infrastructure data-plane work such as packet processing, storage I/O, encryption, compression, virtualization, and telemetry. It offloads repeated movement and policy enforcement from the host CPU.

In an accelerated server, the CPU handles control-oriented logic, the GPU handles parallel model computation, and the DPU moves, secures, transforms, and observes data near network and storage interfaces. These roles are complementary rather than successive replacements.
