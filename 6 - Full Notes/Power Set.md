# Power Set

The power set P(A) is the set of every [[Subset]] of A. It always contains the empty set and A itself; if A is finite with n elements, then P(A) has 2^n elements.

Power sets distinguish membership from containment: ∅ is a subset of every set and therefore an element of every power set. Cantor's result that no set is bijective with its power set also drives the distinction between countable and [[Uncountable Set|uncountable sets]].
