# Node2vec Graph Embedding

Node2vec learns node embeddings from biased random walks. Parameters governing return and outward exploration let the walks interpolate between locally breadth-oriented and structurally exploratory behavior.

This bias can emphasize homophily or structural equivalence. The best walk policy depends on the downstream task, so parameter choices encode an assumption about which graph relationship matters.
