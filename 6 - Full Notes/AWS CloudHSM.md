# AWS CloudHSM

AWS CloudHSM provides dedicated hardware security modules in an Amazon VPC for cryptographic operations and customer-controlled key material. Customers manage HSM users, keys, clustering, availability, and integration with applications that use supported cryptographic interfaces.

It offers more direct control and isolation than the broadly integrated managed-key experience of [[AWS Key Management Service]]. That control brings additional operational responsibility, so CloudHSM is generally selected for requirements that specifically call for dedicated HSM ownership or interface compatibility.
