# CSS Implicit Grid

The implicit grid consists of tracks created beyond the rows and columns explicitly declared in a grid template. It grows when placement names a line outside the explicit grid or when automatic placement needs additional room.

Implicit row and column sizing properties determine the pattern used for those new tracks. This lets a grid accept an unknown number of items without requiring every possible track to be written in advance.
