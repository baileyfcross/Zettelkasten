# Proximity Matrix

A proximity matrix is a square table whose cell at row i and column j records the similarity or distance between the corresponding objects. Symmetric measures produce mirrored values around the diagonal, though asymmetric relationships are possible.

Many hierarchical algorithms operate on this matrix rather than the original feature table. It also provides the basis for comparing original relationships with the [[Cophenetic Proximity]] represented by a dendrogram.
