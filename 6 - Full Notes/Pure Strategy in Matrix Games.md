# Pure Strategy in Matrix Games

A pure strategy selects the same available action with probability one. In a matrix game with a saddle point, each player's optimal choice can be a pure strategy because neither can improve by changing alone.

A pure-strategy solution is found from row minima and column maxima rather than by randomization. When maximin and minimax differ, fixed predictable play is unstable and a [[Mixed Strategy in Matrix Games]] is needed.
