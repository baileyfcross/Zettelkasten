# Geographic Data Exchange Format

A geographic data exchange format serializes geometry, attributes, and often coordinate information so a map can move between software systems. GeoJSON expresses simple geographic features and properties in JSON and can be rendered directly by web tools. KML uses XML to describe geographic content for Earth browsers. Exchange requires checking supported geometry, projection assumptions, attribute types, and file size rather than assuming every spatial object survives unchanged.
