# Execution-Order Prefix

An execution-order prefix is a numerical code placed at the beginning of a script filename so files sort in the sequence they should run. Leaving gaps between numbers permits later insertion of an intermediate step without renaming the entire workflow.

Prefixes turn a folder of scripts into a visible pipeline. They also help collaborators distinguish preprocessing, data editing, analysis, and exploratory work when the naming convention reserves different number ranges for different kinds of operations.
