# Observability as Self-Service

Observability as self-service packages expert practices so developers, SREs, product owners, and other users can obtain relevant operational insight without waiting for an observability specialist. The interface may be a portal, template, API, agent, pull request check, or automated message.

Self-service does not expose unrestricted raw telemetry. It combines standardized collection, access control, context, and curated questions so each user receives the right information in a form that supports a decision.
