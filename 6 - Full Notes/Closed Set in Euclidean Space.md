# Closed Set in Euclidean Space

A set $S\subseteq\mathbb{R}^n$ is closed when its complement $\mathbb{R}^n\setminus S$ is an [[Open Set in Euclidean Space|open set]].

Closedness concerns the set relative to its surrounding Euclidean space. A closed interval includes both endpoints, while a half-open interval is generally neither open nor closed in the real line.
