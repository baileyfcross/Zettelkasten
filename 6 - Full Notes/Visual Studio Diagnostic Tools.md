# Visual Studio Diagnostic Tools

Visual Studio Diagnostic Tools displays runtime observations such as CPU and memory use while an application is being debugged. The timeline relates resource behavior to the period being investigated.

These measurements help locate suspicious activity, but they are a starting point rather than a complete performance explanation. A useful investigation connects a resource spike to call paths, allocations, inputs, and repeatable conditions.
