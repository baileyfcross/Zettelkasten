# AWS Service Catalog AppRegistry

AWS Service Catalog AppRegistry associates AWS resources with the applications they support and stores application metadata such as owner, purpose, and organizational context. This turns a resource inventory into an application-oriented view that supports governance, collaboration, security review, and operational response. The registry does not deploy an application; it supplies the identity and metadata needed to understand scattered resources as one managed system.
