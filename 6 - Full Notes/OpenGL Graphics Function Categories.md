# OpenGL Graphics Function Categories

OpenGL exposes graphics operations as procedural commands rather than as a stored scene description. Its capabilities include primitive drawing, viewing and modeling transformations, hidden-surface removal, alpha blending, antialiasing, texture mapping, pixel operations, lighting, shading, selection, and feedback.

Some commands execute immediately, while display lists can preprocess a repeatable command sequence. Geometry and image data take partly different routes through the rendering pipeline before converging at rasterization, fragment operations, and the frame buffer. The API specifies these operations independently of the operating system's windowing interface.
