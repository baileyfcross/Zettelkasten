# Objective Function

An objective function assigns a value to each candidate solution in an optimization problem. The task is to find a permitted point that minimizes or maximizes this value.

In [[Linear Programming]], the objective is linear. In [[Nonlinear Programming]], either the objective or at least one constraint is nonlinear. The objective must be interpreted together with the [[Feasible Solution|feasible solutions]] defined by the constraints.
