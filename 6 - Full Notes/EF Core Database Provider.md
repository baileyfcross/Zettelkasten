# EF Core Database Provider

An Entity Framework Core provider translates the framework's database operations for a particular data store. Providers supply database-specific SQL generation, type mappings, connection behavior, and capabilities while preserving EF Core's common programming model.

Applications select and configure a provider when registering their database context. Because provider capabilities and translations differ, a model or query that works with one engine should still be tested against the actual production database.
