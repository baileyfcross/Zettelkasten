# Sapling Tree Generator

Sapling generates tree structures procedurally as curves. Creation parameters control scale, trunk radius, branching, and random variation, allowing related but nonidentical trees to be produced rapidly.

The initial curve can receive beveled geometry so its branches become renderable volume. Random seed changes the form, while the other parameters preserve broad species-like constraints; this separation supports believable variation without building every tree manually.
