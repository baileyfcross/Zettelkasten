# R Cluster Analysis

R cluster analysis groups observations from a dissimilarity representation using methods such as k-means or hierarchical agglomeration. K-means seeks compact groups around centers for a chosen number of clusters, while hierarchical clustering produces a dendrogram that can be cut at different levels.

Scaling, distance, linkage, and cluster count all shape the result. A plotted dendrogram or cluster display helps reveal whether the grouping is stable and interpretable, but the algorithm does not by itself establish that the clusters correspond to real populations.
