# Overlapping Network Communities

Overlapping community detection allows one vertex to participate in several network groups. The model fits systems in which a person, protein, document, or resource serves multiple roles.

Membership can be represented through shared cliques, link communities, latent factors, or fractional weights. Evaluation is harder than for a partition because both the group boundaries and the degree of overlap must be assessed.
