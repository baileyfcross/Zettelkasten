# Reproducible Statistical Pipeline

A reproducible statistical pipeline is an ordered collection of code that can rebuild analytic data and results from documented inputs. Each stage has a clear purpose, and downstream artifacts are regenerated after an upstream correction rather than patched by hand.

Reproducibility depends on more than saved code. It also requires stable source data, [[External Data Dictionary|external metadata]], explicit software dependencies, recorded modeling decisions, and output names that consistently point later stages to the current analytic dataset.
