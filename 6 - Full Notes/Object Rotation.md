# Object Rotation

Object rotation changes an object's orientation. It is a canonical [[3D Manipulation]] task whose difficulty depends on the initial and target orientations, the amount of rotation, distance to the object, and required precision.

An [[Input Device]] that integrates rotational degrees of freedom can support coordinated movement, but its grip and range matter. A precision grip can use smaller finger muscles for fine rotation, while a limited hand or device range may force [[Clutching]].

Directionally compliant [[Feedback]] makes the virtual object rotate in the same direction as the physical control, helping the user predict the result.
