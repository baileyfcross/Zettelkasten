# Context Map

A context map describes the landscape of [[Bounded Context]]s and the relationships through which they exchange information. Early evidence can appear in [[EventStorming]] when groups form separate event clusters joined by only a few cross-boundary events. The map makes dependencies visible without merging the internal models. It supports decisions about ownership, translation, integration, and the direction in which one context depends on another.
