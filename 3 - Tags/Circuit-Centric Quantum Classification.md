# Circuit-Centric Quantum Classification

Parent topic: [[Neural Network Classification and Clustering]]

Quantum classifiers that encode features through amplitude states, quantum image representations, or repeated data-dependent rotations, transform them with parameterized circuits, and derive predictions from measurements. The family includes generic variational models, hardware-aware image circuits, and structured circuits whose unary subspaces implement classical linear-algebra operations.
