# Backup Rotation

Backup rotation defines when backup jobs run, which storage destination or set each run uses, and how long the resulting data is retained. Traditional rotation minimized the number of reusable media while preserving several recovery points.

With cloud storage, rotation can instead reduce dependency on one provider by alternating destinations. The schedule should match recovery objectives and be tested as a complete restore path, not only as successful upload jobs.
