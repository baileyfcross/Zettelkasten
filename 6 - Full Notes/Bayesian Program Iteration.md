# Bayesian Program Iteration

Bayesian program iteration repeats a probabilistic substructure across an indexed collection or sequence. The repeated variables and factors can represent trials, sensors, objects, or time steps without writing each copy separately.

The iteration rule defines how one instance relates to earlier or shared variables. When adjacent steps depend on one another, the resulting structure supports recursive filtering and sequence models rather than independent repetition.
