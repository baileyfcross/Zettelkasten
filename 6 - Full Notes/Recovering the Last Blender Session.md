# Recovering the Last Blender Session

Blender's last-session recovery reconstructs the most recently autosaved working state after a crash or an accidental close. It is distinct from opening a numbered backup because it targets the temporary state of the previous session rather than an earlier explicit save.

Recovery should be followed by a normal Save As operation so the rescued state receives a deliberate project filename and does not remain dependent on temporary recovery data.
