# Fuzzy Set

A fuzzy set assigns every element in a universe a membership value between zero and one. Values near one indicate strong membership, values near zero weak membership, and intermediate values express partial belonging.

Unlike a crisp set, membership need not switch at one hard threshold. Several fuzzy sets can describe one attribute through linguistic terms such as low, medium, and high.
