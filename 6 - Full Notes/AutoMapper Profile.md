# AutoMapper Profile

An AutoMapper profile groups declarative mappings between source and destination types. Convention-based member matches handle simple cases, while profile rules define renamed, transformed, or nested values for application models.

Registration makes the mapper available through dependency injection, but configuration should be validated and covered by tests. Automatic mapping reduces repetitive assignment without removing the need to design the public response shape.
