# CloudWatch Dashboard

A CloudWatch dashboard is a configurable visual surface for metrics, alarms, logs, and related operational data. It can combine signals from multiple AWS resources and regions so an operator sees service health and important workload indicators in one place.

A useful dashboard reflects questions the team needs to answer rather than displaying every available measurement. It supports observation and diagnosis, while [[CloudWatch Alarm|alarms]] provide active notification or automated response when specified conditions occur.
