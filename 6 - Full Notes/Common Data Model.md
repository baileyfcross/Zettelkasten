# Common Data Model

A common data model gives communicating applications an agreed meaning and structure for exchanged information. It separates the shared contract from the private business logic and storage choices inside each participant.

The contract can define fields, identifiers, relationships, and interpretation while a separate format defines how those values are encoded. Industry-standard models improve interoperability when many independent organizations must exchange the same business information.
