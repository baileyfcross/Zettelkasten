# User-Developer Continuity in Blender

Blender narrows the distance between using a tool and programming it. Many interface actions expose Python operators, the scripting workspace sits beside the modeling interface, and the same data can be changed manually or through `bpy` without translation into a separate application.

This continuity supports gradual automation. A user can begin with a repeated manual operation, discover its API call, test it, and grow it into a script or add-on. Development becomes an extension of ordinary Blender work rather than a disconnected software project, although robust distribution still requires explicit architecture and lifecycle management.
