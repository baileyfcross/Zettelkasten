# Platform Data Asset Protection

Platform data asset protection follows information while it is in motion, in use, and at rest. Each state requires controls for confidentiality, integrity, authorized access, and safe handling, including encryption, input sanitization, network policy, storage protection, and log sanitization.

The platform may not own application data semantics, but it supplies the paths through which data moves and is observed. Secure networking, tenant separation, secret delivery, retention rules, and sanitized telemetry reduce the chance that a shared capability becomes the route for disclosure. Data minimization also lowers both operating burden and incident impact.
