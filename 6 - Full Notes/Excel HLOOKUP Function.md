# Excel HLOOKUP Function

Excel HLOOKUP searches the top row of a table and returns a value from a specified row in the matching column. It is the horizontal counterpart of [[Excel VLOOKUP Function]], fitting tables whose categories run across columns rather than down rows.

Exact-match mode looks for the requested heading, while approximate-match mode depends on an appropriately ordered top row. The return row is specified by position inside the table, which makes the formula sensitive to structural changes. A table should be oriented for clarity and maintenance rather than rotated solely to accommodate a lookup function.
