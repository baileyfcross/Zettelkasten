# Squared Error Loss

Squared error loss measures a prediction error by subtracting the desired output from the actual output and squaring the difference. Squaring removes the sign and penalizes larger differences more strongly.

For a predicted value of 0.2 and target of 1.0, the loss is $(0.2-1.0)^2=0.64$. It is a simple [[Loss Function]] for scalar outputs; classification across multiple probabilities may instead use [[Categorical Cross-Entropy]].
