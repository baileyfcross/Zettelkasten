# Constructor's-Eye and Designer's-Eye Views

A constructor’s-eye view asks whether hardware and software implement specified functions correctly and efficiently. A designer’s-eye view begins with the system, its users, and their context together, asking whether the artifact works for people in practice.

Both views matter. Technical robustness is necessary, but a system can meet its specification and still fail because the specification omitted an obvious feature of the user community’s world.
