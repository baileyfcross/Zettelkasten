# CSS Inline-Block Formatting

An inline-block box participates in an outer inline formatting context while establishing a block-style formatting context for its contents. It can sit beside text like one inline unit but accept explicit dimensions and contain block boxes internally.

Its baseline normally relates to its final internal line box, with special behavior when it has overflow other than visible. This hybrid makes it different from both [[CSS Inline Box Formatting]] and ordinary block flow.
