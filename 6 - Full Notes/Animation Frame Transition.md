# Animation Frame Transition

An animation frame transition interpolates a graphical object's position, size, color, or other attribute between observations. Smooth transitions in an [[Animated Bubble Chart]] help viewers preserve object identity and perceive direction, but long interpolation can imply measurements that were never observed. Frame and transition durations should match the sampling interval and task. A redraw may be necessary when the underlying geometry changes rather than merely moving.
