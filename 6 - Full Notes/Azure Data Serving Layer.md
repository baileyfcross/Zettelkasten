# Azure Data Serving Layer

An Azure data serving layer exposes prepared data to applications, analysts, dashboards, or downstream services in a form suited to their access pattern. A warehouse, analytical database, semantic model, API, or materialized view may serve different consumers. Serving is distinct from visualization: it establishes query performance, schema, freshness, security, and concurrency guarantees upon which tools such as Power BI build reports.
