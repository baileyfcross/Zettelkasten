# Pattern-Based Object Selection

Pattern selection chooses objects whose names match a text pattern, including wildcard forms. A consistent naming scheme can therefore turn a semantic class such as every wheel or every left-side control into a reusable selection command.

The technique shifts effort from spatial clicking to naming discipline. Ambiguous or inconsistent names weaken it, while predictable prefixes and suffixes make large scenes easier to query without depending on current visibility or proximity.
