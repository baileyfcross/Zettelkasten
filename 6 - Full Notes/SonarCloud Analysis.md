# SonarCloud Analysis

SonarCloud analysis evaluates a repository during a hosted build and records issues and quality measures outside one developer workstation. Integrating it with Azure Pipelines makes a specific revision's analysis part of repeatable delivery evidence.

Central analysis supports trends and shared policy. It should report on changed code promptly and avoid a backlog so large that teams stop distinguishing new regressions from inherited debt.
