# Hyperbolic Data Correlation

Hyperbolic data correlation represents data items as coordinates and treats sufficiently small [[Hyperbolic Distance]] as evidence of a relationship. A distance threshold controls how far each inferred neighborhood extends.

Latent features can be assigned to radial and angular coordinates before links are created. This produces a network representation that can feed clustering, embedding, navigation, link prediction, and visualization within the same geometric framework.
