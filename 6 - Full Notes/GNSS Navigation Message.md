# GNSS Navigation Message

A GNSS navigation message is the low-rate data superimposed on a ranging signal. It supplies the transmitting satellite's ephemeris, clock correction and health information, along with broader constellation data that helps a receiver find and assess other satellites. The code phase measures when a signal arrived, while the navigation message provides the orbital and timing context needed to turn that measurement into a position solution.
