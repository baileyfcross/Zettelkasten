# ADO.NET Data Provider

An ADO.NET data provider is a coordinated set of classes for a particular database access mechanism. It supplies compatible connection, command, data reader, parameter, and data adapter implementations derived from common .NET abstractions.

Provider-specific types such as SQL Server and ODBC classes differ in details but preserve the same overall workflow. Selecting a provider therefore chooses both the database protocol and the concrete objects used to execute it.
