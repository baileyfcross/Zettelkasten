# Von Neumann Architecture

The von Neumann architecture organizes a computer around a central processing unit, memory, and input-output subsystem. The CPU follows a sequence of instructions stored in memory and exchanges data with that memory as it works.

The architecture gives physical meaning to familiar programming ideas such as sequential steps, branches, and variables. Its separation of processing and memory also creates the [[Processor-Memory Bottleneck]].
