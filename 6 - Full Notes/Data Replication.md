# Data Replication

Data replication stores copies of information on multiple hosts so one departure or failure does not make the data unavailable. Replicas can also place frequently used content nearer to computation.

More copies improve resilience but consume capacity and network bandwidth. Updates require a consistency rule that defines which versions readers may observe.
