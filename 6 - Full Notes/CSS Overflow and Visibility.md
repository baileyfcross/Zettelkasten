# CSS Overflow and Visibility

The `overflow` property determines what happens when content exceeds a box's available dimensions. It can remain visible, be clipped, or become accessible through a scrolling mechanism, and overflow behavior can create a clipping region around padding edges.

The `visibility` property hides painting while generally preserving the box's layout space. This differs from `display: none`, which suppresses box generation and causes surrounding layout to be recalculated without the element.
