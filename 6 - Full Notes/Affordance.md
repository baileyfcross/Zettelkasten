# Affordance

An affordance is a property that helps a user understand or perform an action. Affordances help the user's [[Conceptual Model]] match the intended design.

Four useful categories are:

- Cognitive affordances help decide what action to take.
- Physical affordances help carry out the action.
- Functional affordances help accomplish a higher-level task.
- Sensory affordances help perceive state or recognize an outcome.

For example, a visible virtual eraser can suggest deletion, being within reach can make selection physically possible, its behavior supplies deletion functionality, and highlighting on contact can make the interaction perceptible. A [[3D User Interface]] must often consider all four categories together.
