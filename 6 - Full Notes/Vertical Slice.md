# Vertical Slice

A vertical slice is a polished sample in which representative layers of a game work together, from interface and art through gameplay systems and supporting technology. It demonstrates how the finished experience may appear to stakeholders.

Unlike a fast [[Prototype]], it requires polish and broad integration, so it is expensive and can distract from unresolved core design questions. Completing one also does not make the rest of an innovative game a merely linear content-production task.

A smaller [[Tracer Bullet]] can reduce end-to-end technical uncertainty before this level of polish is justified. Both forms gain their value from crossing component boundaries, not from demonstrating isolated task completion.
