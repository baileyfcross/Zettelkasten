# Kotlin Google Maps Android Integration

The book's Google Maps case enables the Maps SDK for Android in a cloud project, creates and restricts an API key, adds the Android dependency, places the key in the manifest, and hosts a map fragment in the interface.

Kotlin code then loads the map and can add markers or polylines. Location-aware features additionally require runtime location permission and a location provider. The integration is consequently a chain of cloud configuration, application metadata, layout, code, permissions, and a device with Google Play services.
