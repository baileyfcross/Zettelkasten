# Git Log

`git log` displays commits reachable through repository history. A log entry can show the commit hash, author, date, message, and relationships to branches or parent commits.

History inspection helps identify when and why a change entered the codebase. Formatting and filtering options can narrow the view by path, author, time, or graph structure without modifying the repository.
