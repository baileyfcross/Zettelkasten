# R Friedman Test

The R Friedman test compares treatments in a blocked or repeated-measure design by ranking responses within each block. It is a nonparametric counterpart to a two-way design with one observation per treatment-block cell and tests whether treatment rank distributions are alike.

The block identifier is essential because the method uses within-block comparisons rather than treating all observations as independent. A significant omnibus result does not by itself identify the differing treatment pairs.
