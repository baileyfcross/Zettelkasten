# Bilinear Map

A bilinear map f: M × N → P is linear in each argument when the other is held fixed. It preserves addition and scalar multiplication separately in both module inputs.

The [[Tensor Product of Modules]] represents bilinear maps universally: every bilinear map from M × N factors uniquely through a linear map from M ⊗ N.
