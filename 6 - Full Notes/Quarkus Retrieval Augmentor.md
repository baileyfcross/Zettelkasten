# Quarkus Retrieval Augmentor

A Quarkus LangChain4j retrieval augmentor connects an AI service to content retrieval so relevant document segments can be included before the model generates a response. It turns retrieval into a declared service capability rather than a manually repeated sequence in each REST method.

The augmentor's usefulness depends on the retriever and corpus beneath it. Search limits, metadata filters, embedding compatibility, and evidence-aware evaluation must be configured explicitly because automatic context insertion can still supply irrelevant material.
