# Kotlin Map Collection

A Kotlin map associates distinct keys with values. Looking up a key retrieves its corresponding value or indicates that the key is absent, making the key the stable access path rather than a numeric position.

`mapOf` presents read-only associations, while `mutableMapOf` permits entries to be inserted, replaced, or removed. Keys and values have separate generic types, so the compiler can preserve both sides of the relationship across lookup and iteration.
