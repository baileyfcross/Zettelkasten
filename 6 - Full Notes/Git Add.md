# Git Add

`git add` places selected working-tree content into the [[Git Staging Area]]. It can stage a named file, a directory, or a broader set of paths for inclusion in the next commit.

The command stages the content as it exists at that moment; later edits to the same file are not automatically included. Reviewing the staged diff prevents accidental selection of unrelated or sensitive changes.
