# Excel Percentage Formula

An Excel percentage formula treats a percentage as a decimal proportion. A percentage of a quantity is found by multiplication, while a proportion of a total is found by division. Percentage formatting changes how a decimal is displayed; it does not create a different underlying kind of value.

Common percentage models include markup, discount, profit margin, goal completion, and change between periods. Their formulas answer different questions, so similar-looking results should not be substituted for one another. Keeping the base amount in a referenced cell and using an [[Excel Absolute and Mixed Cell Reference]] makes the chosen denominator or rate explicit when the formula is filled.
