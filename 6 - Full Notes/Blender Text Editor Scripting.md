# Blender Text Editor Scripting

Blender's Text Editor provides an in-application place to create, open, edit, and run Python scripts. It is suited to assembling multiple tested API calls into a sequential procedure while keeping the resulting scene visible in the surrounding Blender interface.

Several Text Editor areas can be opened at once, which is useful when a main script depends on a separate utility module. This convenience is strongest for early exploration and single-file scripts; packaged add-ons eventually benefit from [[Blender Add-On Filesystem Development]], where development and deployment use the same file structure.
