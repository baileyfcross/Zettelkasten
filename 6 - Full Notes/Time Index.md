# Time Index

A time index is the ordered set of temporal coordinates attached to the observations of a [[Time Series]]. The `zoo` model only requires the index to be totally ordered, so it can use dates, date-times, years, or specialized classes such as [[yearmon Time Index]]. Separating the index from [[zoo Core Data]] allows the same measurements to be selected, merged, plotted, or aggregated according to time.
