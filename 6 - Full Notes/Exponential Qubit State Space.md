# Exponential Qubit State Space

An $n$-qubit pure state is a normalized complex vector with $2^n$ amplitudes, one for each computational-basis bit string. Adding one qubit doubles the dimension because the combined space is a [[Multi-Qubit Tensor-Product State|tensor product]].

The exponential representation is a capacity of the state space, not an automatic exponential computational speedup. Measurement cannot reveal all amplitudes from one preparation, and a useful algorithm must prepare, transform, and sample the state so that the desired answer becomes accessible.
