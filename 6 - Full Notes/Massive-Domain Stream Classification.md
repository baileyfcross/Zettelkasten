# Massive-Domain Stream Classification

Massive-domain stream classification handles categorical attributes whose possible values are too numerous to maintain a separate statistic for every value-class combination. New values may also appear continually.

Compact summaries, hashing, sketches, or selective counting replace complete frequency tables. The representation must preserve enough class association to predict while keeping memory independent of the expanding domain size.
