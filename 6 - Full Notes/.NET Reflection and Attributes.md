# .NET Reflection and Attributes

.NET reflection examines assemblies, types, and members at runtime through their metadata. A program can discover names, versions, properties, methods, and applied attributes, and advanced reflection can load or invoke code dynamically.

An attribute attaches structured metadata to a program element. Framework and custom attributes can describe validation, serialization, compiler generation, or application conventions. Reflection reads that metadata so tools and runtimes can change behavior without hard-coding every decorated type.
