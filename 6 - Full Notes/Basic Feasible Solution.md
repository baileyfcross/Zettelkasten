# Basic Feasible Solution

A basic feasible solution is a basic solution whose variable values also satisfy the nonnegativity restrictions of a linear program. It is degenerate when at least one [[Basic Variable]] equals zero and nondegenerate when all basic variables are positive.

For a feasible linear program in standard form, basic feasible solutions correspond to extreme points of the feasible polyhedron. This relationship lets the [[Simplex Method]] search a finite collection of corner solutions instead of every point in the feasible region.
