# Cluster Homogeneity

Cluster homogeneity is the degree to which observations within the same cluster resemble one another. High within-cluster similarity is one side of a useful grouping; the other is strong [[Between-Cluster Separation]].

Homogeneity is always relative to the attributes and proximity measure used. A group can be homogeneous for one purpose while concealing important differences for another.
