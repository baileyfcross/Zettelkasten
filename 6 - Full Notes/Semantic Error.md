# Semantic Error

A semantic error uses syntactically valid language constructs in a way that has an invalid or unintended meaning, such as applying an operation to an incompatible type or violating a rule the compiler can infer from declarations. Static checking can identify some semantic errors, while others surface only at runtime.

The category lies between grammar and algorithmic intent. A program may compile after its types and calls are legal yet still contain a [[Logic Error]] because the legal operations implement the wrong calculation or condition.
