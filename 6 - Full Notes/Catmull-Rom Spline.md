# Catmull-Rom Spline

A Catmull-Rom spline is a smooth interpolating curve whose segments pass through their central control points while neighboring points determine the tangents. Four points contribute to the position evaluated on one segment.

Because the curve passes through authored points, it is convenient for a [[Spline Camera]]. Uniform parameter steps do not necessarily produce uniform travel speed, so timing may need additional adjustment.
