# CSS Calculation Values

The CSS `calc()` function constructs a value from addition, subtraction, multiplication, and division. It is useful when a declaration must combine compatible quantities, such as a percentage width minus an `em` gutter.

Addition and subtraction require compatible types, multiplication requires one side to be a number, and division requires a numeric divisor. Spaces are required around `+` and `-`, and any expression that divides by zero is invalid.
