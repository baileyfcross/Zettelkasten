# Computational Statistics

Computational statistics develops and applies computational methods to statistical problems. It translates a mathematical objective into an algorithm and then into executable operations that produce a numerical approximation, simulation, or data analysis.

The translation includes more than choosing a formula. Finite representation, stopping tolerances, error analysis, data structures, and implementation language can all change whether a theoretically valid method produces a useful result. R and C++ can be used together so R supplies an interactive statistical environment while compiled C++ supplies controlled structures and computational kernels.
