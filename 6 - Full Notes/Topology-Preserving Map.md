# Topology-Preserving Map

A topology-preserving map places similar input patterns at nearby output locations. In a self-organizing map, the neighborhood around the winning unit participates in learning with an influence that decreases with grid distance.

The arrangement makes cluster relationships visible, but it is an approximate projection and can distort distances or densities from the original space.
