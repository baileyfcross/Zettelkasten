# Elementary Matrix

An elementary matrix is obtained by applying one [[Elementary Row Operation]] to an [[Identity Matrix]]. Left multiplication by it performs the same row operation on another matrix.

Every elementary matrix is invertible, and its inverse corresponds to undoing the row operation. A [[Nonsingular Matrix]] can be represented as a product of elementary matrices.
