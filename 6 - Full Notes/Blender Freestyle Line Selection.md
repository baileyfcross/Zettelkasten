# Blender Freestyle Line Selection

Freestyle line sets select renderable strokes by visibility, edge type, face marks, or collection membership. Edge-type criteria include silhouettes, creases, open borders, marked edges, contours, material boundaries, and ridge or valley relationships.

Selection separates geometric detection from visual styling. A project can render different collections or edge classes with separate line sets, giving technical and illustrative drawings a controlled hierarchy.
