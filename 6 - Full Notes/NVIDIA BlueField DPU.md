# NVIDIA BlueField DPU

An NVIDIA BlueField DPU combines high-speed Ethernet or InfiniBand interfaces, Arm CPU cores, memory, and accelerators for encryption, compression, packet processing, storage, and data movement. The host connects through PCIe while embedded resources run selected infrastructure services close to the data path.

BlueField is more than a network adapter because it can execute independently managed software and policy. [[NVIDIA DOCA]] provides the framework for programming services that offload or isolate networking, storage, security, and telemetry functions.
