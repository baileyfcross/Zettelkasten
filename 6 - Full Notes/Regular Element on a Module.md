# Regular Element on a Module

An element r of a ring is regular on a module M when multiplication by r is injective on M. Equivalently, r is not a [[Zero Divisor on a Module]].

A [[Regular Sequence]] requires each element to be regular after quotienting by the preceding elements. Regularity therefore records independence successively rather than testing every element only on the original module.
