# Microsoft Foundry Model Leaderboard

A Microsoft Foundry model leaderboard ranks candidate models on dimensions such as quality, safety, throughput, and estimated benchmark cost. Scenario-specific views relate those measures to particular tasks, while trade-off charts show how quality changes against cost, speed, or safety.

Leaderboard position is comparative evidence, not an application acceptance test. Benchmarks may use different prompts, data, and traffic assumptions from the intended workload. The leaderboard helps identify promising candidates, which should then pass governance filters and be tested with the project's own dataset, latency target, and failure thresholds.
