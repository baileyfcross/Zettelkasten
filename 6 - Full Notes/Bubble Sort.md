# Bubble Sort

Bubble sort organizes an array through repeated passes that compare values and exchange those found in the wrong order. A temporary variable preserves one value while the two array positions are swapped.

The algorithm emphasizes simple indexed control flow rather than minimizing work. Its nested passes can perform many comparisons and swaps, so it serves as an introductory demonstration of array mutation and ordering rather than an efficient general-purpose choice for large data sets.
