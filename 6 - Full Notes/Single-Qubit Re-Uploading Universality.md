# Single-Qubit Re-Uploading Universality

Repeated data-dependent rotations can make a single-qubit circuit a universal function approximator. The paper relies on prior theoretical results showing that increasing the number of re-uploading queries supplies progressively richer functions even though the accessible Hilbert space remains two-dimensional.

Universality concerns the model family as depth is allowed to grow; it does not imply that a particular shallow circuit learns every boundary efficiently. The experiment uses at most a few layers, synthetic datasets, and carefully controlled rotations, so it tests finite instances rather than proving a practical advantage from universality.

This distinction separates representational possibility from usable capacity. [[Data Re-Uploading Quantum Layer]] defines how each query inserts the features, while [[Re-Uploading Depth as Model Capacity]] shows how the finite experimental classifier changes as more layers are added.
