# Sparse Model Matrix

A sparse model matrix represents predictors numerically while storing only nonzero entries. It is efficient for one-hot encoded categorical data because most indicator columns are zero for any record.

The encoding rules must be learned from training data and applied consistently to validation, test, and future scoring records.
