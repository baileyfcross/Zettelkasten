# Unity Asset

A Unity asset is a file or reusable resource that belongs to a project, including images, 3D models, C# scripts, text, audio, fonts, materials, and prefabs. Assets appear in the Project pane and need not be present in the current [[Unity Scene]].

The project's Assets folder mirrors files stored with the project, while installed package content can be shared from package-managed locations. Keeping asset identity separate from scene instances lets many objects reuse one source resource and allows a change to propagate to every reference intentionally.
