# Role Manager

Role Manager is the ASP.NET Core Identity service that provides APIs for finding, creating, and managing roles. It works with a role store connected to the application's identity database.

The service can be injected into setup or controller code through [[Dependency Injection]]. Database seeding can use it to create required roles only when they do not already exist.
