# Green Function

A Green function is the kernel of an integral operator that inverts a linear differential operator under specified conditions. Convolving the Green function with a forcing function constructs a particular solution of the inhomogeneous differential equation.

For a second-order equation, a Green function can be assembled from two independent homogeneous solutions and their [[Wronskian Determinant]]. Its form changes with the boundary conditions, so it represents both the differential operator and the constraints imposed on its inverse.
