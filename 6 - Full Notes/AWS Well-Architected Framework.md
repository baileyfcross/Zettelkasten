# AWS Well-Architected Framework

The AWS Well-Architected Framework is a structured set of design principles and questions for evaluating cloud workloads. It organizes architectural quality into six pillars: operational excellence, security, reliability, performance efficiency, cost optimization, and sustainability.

The framework supports recurring, collaborative review rather than a one-time certification. Teams identify risks, prioritize improvements, and revisit decisions as workload requirements and AWS capabilities change; the [[AWS Well-Architected Tool]] records this assessment process.
