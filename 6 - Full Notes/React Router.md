# React Router

React Router is a client-side routing library that maps browser locations to React components. It lets a single-page application present multiple navigable pages without requesting a complete HTML document for each route.

Routes can redirect, select a not-found component, capture path parameters, and load components lazily. Link and history APIs change location while keeping navigation inside the client application.

The source frames routing as the layer that restores browser history, forward and back navigation, deep links, and bookmarks to a single-page application. A router observes location changes and renders the component whose declared path matches that browser-visible state.
