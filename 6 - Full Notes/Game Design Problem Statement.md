# Game Design Problem Statement

A game design problem statement expresses the central question the project is trying to explore, often in a "What if...?" form. It gives the team a durable direction without pretending to predict the finished solution.

The statement should identify the underlying design problem rather than naming an already selected feature. Asking why a proposed feature is interesting can reveal a deeper question against which several solutions can be generated and evaluated.
