# Recursive Graph Feature

A recursive graph feature repeatedly aggregates features from neighboring nodes. Starting with basic properties, each iteration expands the represented context to another graph radius.

This construction can create expressive relational features without naming every motif. Repeated aggregation may blur distinct nodes into similar representations, so depth, aggregation functions, and pruning matter.
