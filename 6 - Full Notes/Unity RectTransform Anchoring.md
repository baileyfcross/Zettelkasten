# Unity RectTransform Anchoring

Unity RectTransform anchoring positions and resizes a UI element relative to its parent rectangle. A single-point anchor preserves offsets from one reference location, while split anchors relate the element's edges to an adjustable region and allow it to stretch as the parent changes.

Anchors make one [[Unity Canvas|Canvas]] layout adapt across aspect ratios and resolutions. A reliable workflow sets the intended anchor before positioning the element, then previews several window shapes to confirm that controls remain aligned, readable, and reachable.
