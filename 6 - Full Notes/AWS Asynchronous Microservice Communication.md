# AWS Asynchronous Microservice Communication

AWS asynchronous microservice communication places a queue, stream, or event bus between a producer and consumer so the producer does not wait for immediate completion. SQS supports buffered work, SNS fans messages to subscribers, EventBridge routes events, and Kinesis retains ordered streams. Decoupling improves failure isolation and independent scaling, while delivery semantics, duplicate handling, ordering, retries, schema evolution, and dead-letter processing become explicit contracts.
