# Control Creep

Control creep is the repurposing of data or monitoring infrastructure from its initial function into a wider system of regulation or surveillance. A camera or sensor installed to manage traffic may later become a source for security investigations.

The new use can be defended as beneficial, but it changes the relationship between the system and the people recorded by it. The book argues that joining sources and repeatedly expanding purposes can make ordinary actions appear suspicious in an anticipatory governance system. Purpose and limits need renewed scrutiny whenever a dataset changes roles.
