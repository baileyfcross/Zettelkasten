# Hobson's Choice in Games

A Hobson's choice in a game presents an apparent alternative while making refusal unacceptable, such as "do this or lose." The player can technically decline, but the structure supplies only one viable path.

This device can communicate coercion or reinforce a dramatic situation, but it should not be mistaken for broad [[Player Agency]]. Repeated use makes the interface ask for consent to outcomes the game has already determined and can weaken trust in later choices.
