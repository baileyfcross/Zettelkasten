# Sliding-Window Sequence Feature

A sliding-window sequence feature applies a pattern-matching summary within successive local windows. The resulting values describe how pattern activity changes along the sequence.

Window length and stride determine temporal or positional resolution. Short overlapping windows preserve locality but increase dimensionality and dependence among neighboring features.
