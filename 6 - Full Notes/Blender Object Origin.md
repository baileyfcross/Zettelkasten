# Blender Object Origin

An object's origin is the reference point Blender uses for its location and for many rotations, scales, mirrors, and modifier relationships. The origin can be moved to the geometry, to the 3D cursor, or to another computed position without necessarily moving the mesh itself.

Changing the origin changes how later operations behave. A deliberately offset origin can become a hinge, radial center, or architectural insertion point, while an accidental offset can make otherwise ordinary transforms seem incorrect.
