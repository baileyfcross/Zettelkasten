# CSS Cascade Origins

CSS declarations can originate with the document author, the reader, or the user agent. Author rules express the site's presentation, reader rules express user preferences, and user-agent rules provide defaults for elements that would otherwise be unstyled.

Origin is one stage in the cascade rather than an absolute winner. Its precedence interacts with [[CSS Important Declarations]], after which selector specificity and source order resolve declarations remaining in the same group.
