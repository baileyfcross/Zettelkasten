# R Package Vignette

An R package vignette is a longer-form document distributed with a package to explain workflows, methods, or examples that exceed the scope of an individual help page. R can list installed vignettes and open one by topic or package.

Vignettes are valuable orientation material but remain version-specific documentation. Their examples should be read alongside the function help and adapted to the actual data rather than copied as undocumented defaults.
