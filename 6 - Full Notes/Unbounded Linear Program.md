# Unbounded Linear Program

A linear program is unbounded when its feasible region permits the objective to improve without limit. The model can remain feasible even though no finite [[Optimal Solution]] exists.

Graphically, an objective line can keep moving in the improving direction while still intersecting the feasible region. In a simplex calculation, an improving entering column with no admissible leaving row signals that the objective can continue indefinitely.
