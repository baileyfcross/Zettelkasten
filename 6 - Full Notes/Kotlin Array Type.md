# Kotlin Array Type

A Kotlin array stores a fixed number of indexed elements of a compatible type. Its elements can be read by index, replaced at an existing position, tested with the `in` operator, and visited in a loop.

The array's size is established when it is created even though individual slots may be mutable. This separates a stable indexed shape from the values currently occupying that shape; collections are a different abstraction when the number of elements must grow or shrink.
