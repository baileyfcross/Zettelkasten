# JavaScript Object Literal Enhancement

JavaScript object literal enhancement shortens the construction of an object from variables and functions already in scope. When a property name matches its variable name, the name can appear once, and a method can be declared without the `function` keyword.

The feature is the constructive counterpart to [[JavaScript Destructuring Assignment|destructuring]]: destructuring takes named values out of an object, while enhanced literal syntax gathers scoped values and methods into a new object. This keeps transformations concise without changing the resulting property names.
