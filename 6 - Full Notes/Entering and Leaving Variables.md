# Entering and Leaving Variables

The entering variable is a nonbasic variable whose objective-row coefficient shows that increasing it can improve the objective. The leaving variable is the current basic variable that reaches zero first as the entering variable increases.

This exchange changes the basis by one column. The objective condition chooses a promising direction, while the [[Minimum Ratio Test]] prevents the step from making a right-hand-side value negative.
