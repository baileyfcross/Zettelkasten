# R Function Naming

R function naming uses a consistent convention that describes an action or computation. Predictable names help readers distinguish operations and discover related functions.

The project should avoid arbitrary mixtures of dots, underscores, and capitalization that obscure relationships.

The student companion favors descriptive user-defined names because they remain understandable inside long scientific scripts. It also cautions against replacing an existing R function name, since the new assignment can hide the built-in operation expected by later code.
