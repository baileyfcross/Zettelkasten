# Model Output Statistics for Aviation Weather

Model Output Statistics applies location-specific statistical relationships to raw numerical weather predictions. It can account for systematic local behavior and interpolate useful values where no aerodrome forecast is directly available. The method may extend some predictions beyond a TAF period, but it does not reproduce every layered ceiling detail available in [[Terminal Aerodrome Forecasts]].
