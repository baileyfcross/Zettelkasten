# Java IO Convenience Class

The `java.lang.IO` convenience class supplies simple console input and output operations for small modern Java programs. It lets beginners interact with a console without first assembling buffered readers, scanners, streams, exception handling, and `System.out` chains.

Because `java.lang` is automatically available, an implicitly declared class can call the helper without an import. The facility is intended for compact learning and experimentation; ordinary I/O APIs remain necessary when a program needs richer encoding, buffering, or resource-control behavior.
