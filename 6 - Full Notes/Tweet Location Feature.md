# Tweet Location Feature

A tweet location feature estimates or records the geographic origin or relevance of a post. Explicit coordinates, place fields, profile locations, named entities, time zones, and network context provide signals with different precision.

A post's author location, posting location, and mentioned location are not necessarily the same. Feature engineering must preserve this distinction and represent uncertainty when exact geolocation is unavailable.
