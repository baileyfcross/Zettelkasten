# Comment the Why

A useful code comment records reasoning, constraints, a non-obvious consequence, or the larger plan behind an implementation. It explains why the code takes this form when the syntax already shows what each statement does.

Comments can also begin as pseudocode that keeps the programmer at one level of thought before implementation details are inserted. They must remain accurate: a comment that contradicts changed code is worse than an absent comment because it gives the next reader false evidence.
