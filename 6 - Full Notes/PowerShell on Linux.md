# PowerShell on Linux

PowerShell on Linux provides the PowerShell language, cmdlets, modules, and object pipeline on a Unix-like host. It can support administrators who manage mixed Windows, Linux, and macOS environments with a shared automation language.

The runtime does not erase operating-system differences. Paths, permissions, available modules, native commands, service managers, and hardware data remain platform-specific and need explicit checks in a script that claims cross-platform behavior.
