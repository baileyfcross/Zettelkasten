# CSS Outlines

An outline is a line drawn around an element for emphasis, often when the element has focus. Its style, width, and color resemble border components, and an offset can move it away from the border edge.

Unlike [[CSS Borders]], an outline occupies no layout space and need not follow a rectangular shape. It is an all-or-nothing decoration rather than four independently styled sides.
