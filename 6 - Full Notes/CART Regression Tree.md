# CART Regression Tree

A CART regression tree recursively divides observations by feature thresholds and predicts a numerical value in each terminal region. A split is chosen to reduce within-node prediction error.

In a random forest for treatment duration, many such trees are trained from varied samples and feature choices, then combined to reduce the instability of one tree.
