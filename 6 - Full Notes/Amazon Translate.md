# Amazon Translate

Amazon Translate provides neural machine translation between supported languages. Applications can translate individual text requests or batches of stored documents without maintaining translation models or language-specific server infrastructure.

Machine translation is useful for scale and rapid localization, but wording can lose nuance, domain meaning, or legal precision. Custom terminology can guide preferred translations, and important public or regulated content may still need qualified human review.
