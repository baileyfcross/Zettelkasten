# Progression System

A progression system organizes how the player's representation, capabilities, knowledge, or status improve over time. It connects short-term actions and rewards to longer-term goals and a continuing sense of achievement.

Progression usually relies on reinforcing loops regulated by thresholds, costs, challenges, or [[Braking Engine|brakes]]. A [[Progression Curve]] coordinates those changes so benefits remain meaningful and attainable without ending the game too quickly.
