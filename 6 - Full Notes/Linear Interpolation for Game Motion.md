# Linear Interpolation for Game Motion

Linear interpolation produces a value between a start and an end using a parameter usually ranging from zero to one. For vectors, the same parameter blends corresponding components and traces a straight path between positions.

Games use interpolation to move values smoothly over time. The parameter must be tied to elapsed time when the motion should remain independent of frame rate.
