# Input Action Mapping

Input action mapping associates logical commands such as jump, fire, or pause with device-specific controls. Gameplay queries the action instead of knowing whether it came from a key, mouse button, controller button, or axis.

The mapping supports remapping and multiple device layouts while preserving one gameplay interface. Digital edges and analog values still need appropriate semantics after several physical inputs are combined into the same action.
