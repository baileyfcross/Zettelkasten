# CSS List Marker Images and Position

The `list-style-image` property replaces an ordinary list marker with an image when that image is available. The `list-style-position` property places the marker outside the principal block box or inside it as part of the content flow.

The `list-style` shorthand combines type, image, and position. A marker type can remain as a fallback when the image cannot be loaded.
