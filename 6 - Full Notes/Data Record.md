# Data Record

A data record is a group of related fields describing one entity for an application. An email record, for example, can contain its sender, delivery date, subject, and message body.

A [[Sorting Algorithm]] reorders whole records according to selected fields called a [[Sort Key]]. The remaining fields travel with the record, so sorting changes position without altering the information represented by each entity.
