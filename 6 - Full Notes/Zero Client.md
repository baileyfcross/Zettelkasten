# Zero Client

A zero client is a minimal endpoint whose operating environment is embedded and whose applications and data are supplied remotely. It presents access to hosted computing without maintaining a general local application installation.

The limited device can be inexpensive to replace and less useful to a thief when organizational data remains in centralized storage. Like a [[Thin Client]], it depends strongly on network and service availability.
