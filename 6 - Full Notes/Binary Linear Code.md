# Binary Linear Code

A binary linear code is a [[Linear Code]] over the two-element field. Its codewords are fixed-length vectors of zeros and ones, and addition is performed componentwise modulo two.

The notation $[n,k]$ records codeword length and vector-space dimension. Redundant coordinates permit a [[Parity-Check Matrix]] to detect or locate certain transmission errors.
