# CSS Generic Font Families

CSS generic font families describe broad visual categories rather than a particular installed face. The source covers serif, sans-serif, monospace, cursive, and fantasy families, each of which the user agent maps to an available font.

A `font-family` list normally places preferred named families first and a generic family last. This gives [[CSS Font Matching|font matching]] a usable fallback when a requested face is absent or lacks a required glyph.
