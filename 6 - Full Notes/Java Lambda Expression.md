# Java Lambda Expression

A Java lambda expression supplies an implementation of a target functional interface without declaring a named class. Its parameters correspond to the interface method, and its expression or block body computes that method's result or side effects.

The target type comes from assignment, argument, or return context, so the same lambda syntax can represent different compatible interfaces. A lambda can capture local variables only when they are final or effectively final, preventing later reassignment from creating ambiguous shared local state.
