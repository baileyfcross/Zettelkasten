# Page Object Class

A page object class models one web page or focused page section. It owns the WebDriver reference, the locators for relevant elements, and methods that express permitted interactions.

A constructor supplies the driver so the object can act in the active browser session. Keeping one coherent page per class supports high cohesion and makes changes easier to find.
