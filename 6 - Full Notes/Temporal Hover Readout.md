# Temporal Hover Readout

A temporal hover readout displays the time and value nearest the pointer in an [[Interactive Time-Series Plot]]. It supplies precise local information without permanently labeling every observation. When several series share the time coordinate, the readout can compare their values at one instant. Hover alone is inaccessible to some devices and users, so the display should retain readable axes and, where necessary, keyboard or touch alternatives.
