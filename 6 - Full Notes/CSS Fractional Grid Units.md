# CSS Fractional Grid Units

The grid `fr` unit represents a fraction of leftover space in a grid container after nonflexible tracks and gaps have been accounted for. Tracks receive space in proportion to their fraction numbers.

An `fr` value is a flex factor rather than a simple percentage of total container size. Content-based minimum constraints can affect the final distribution, so a fractional track may not shrink below the minimum needed by its items.
