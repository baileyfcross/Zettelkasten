# Zero-Sum Game

A zero-sum game is a competitive situation in which the algebraic sum of all players' gains and losses is zero. In a two-person zero-sum game, one player's gain is exactly the other's loss, so one [[Payoff Matrix]] can represent both perspectives by reversing signs.

The row player is treated as the maximizer and the column player as the minimizer. Each knows the available strategies and payoffs but chooses without knowing the opponent's simultaneous choice.
