# Subspace Cluster Representation

SubspaceCluster extends CenterCluster with a real-valued vector of dimension weights. Each weight expresses how strongly an attribute contributes to the formation or compactness of that particular cluster.

Per-cluster weights allow different groups to occupy different projected spaces while retaining an ordinary center and record collection. The vector length and ordering must match the shared schema.
