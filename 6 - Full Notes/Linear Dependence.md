# Linear Dependence

Vectors are linearly dependent when some nontrivial [[Linear Combination]] equals the [[Zero Vector]]. Equivalently, at least one vector can be written as a combination of the others.

Adding more vectors to an already dependent set cannot restore independence. Dependence reveals redundant directions in a matrix or spanning set.
