# Performance-Guided Feature Search

Performance-guided feature search uses measured or predicted task performance to decide which transformations to explore next. Each evaluation supplies feedback about a derived dataset's utility.

Direct model training gives relevant evidence but is expensive and can overfit repeated validation. Surrogate scores, careful holdout design, and budget-aware policies reduce that cost and bias.
