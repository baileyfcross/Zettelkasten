# Netscape Navigator

Netscape Navigator was a commercial browser descended from Mosaic. It combined a polished graphical interface with features needed for online business and user sessions.

Netscape’s 1995 public offering became a symbol of the Web investment boom. Its innovations included secure transport and cookies, both of which changed the Web beyond static publishing.
