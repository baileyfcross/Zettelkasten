# AWS Landing Zone Accelerator

AWS Landing Zone Accelerator provides code and configuration for deploying a secure, governed, multi-account AWS environment. It builds on the landing-zone approach with opinionated security, networking, logging, and account foundations that can be adapted to organizational requirements. Because the baseline is automated, changes can be reviewed and repeated, but the organization must still map its own policies and operating responsibilities onto the supplied architecture.
