# Excel IF Function

The Excel IF function evaluates a logical test and returns one result when the test is true and another when it is false. Its three parts separate the condition from the two possible outcomes, allowing a worksheet to classify records, display messages, or choose alternate calculations.

IF can use direct comparisons or logical functions such as [[Excel AND Function]] and [[Excel OR Function]]. Nested IF expressions support more branches but become difficult to read as depth grows. When the decision is genuinely multiway, [[Excel Multi-Branch Logical Functions]] can express the alternatives more clearly. Each boundary condition should be tested explicitly to avoid gaps or overlaps.
