# Information Filtering

Information filtering selects which available augmentations should be shown for the current task and context. A knowledge-based filter uses semantic relevance, while a spatial filter uses location, distance, direction, visibility, or the region exposed through an interface such as a magic lens.

Combining both prevents the display from presenting every nearby item merely because it can. The filter reduces data overload while retaining information that matters to the user's purpose.
