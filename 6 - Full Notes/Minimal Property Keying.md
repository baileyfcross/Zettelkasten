# Minimal Property Keying

Minimal property keying records only the channels that actually changed instead of keying an object's complete location, rotation, and scale set. In the historical Auto-Key workflow, Only Insert Needed reduced unnecessary keys.

A smaller set of keys makes intent easier to read and prevents unchanged channels from resisting later edits. The animator still needs enough keys to define the motion; minimal means avoiding redundant properties, not eliminating necessary timing information.
