# API Load Testing

API load testing sends controlled concurrent traffic to measure how latency, throughput, errors, and resource use change as demand rises. It reveals capacity limits and bottlenecks that are not visible in a single functional request.

The book mentions tools such as Apache JMeter and treats load evidence as part of scaling decisions. A useful test models realistic routes, payloads, authentication, and traffic shape, establishes a baseline, and avoids confusing failures in the test generator with failures in the API.
