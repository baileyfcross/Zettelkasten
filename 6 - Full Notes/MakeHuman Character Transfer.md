# MakeHuman Character Transfer

MakeHuman generates configurable human characters from parameters for body shape, age, face, clothing, and rigging. The book recommends FBX as the practical bridge into Blender for the software versions it covers.

The exported package can carry mesh, clothes, textures, and a rig, reducing character setup time. A direct community plug-in can synchronize a character into Blender, while Collada and STL provide file-based alternatives; import still requires inspection of scale, materials, and skeleton compatibility before animation work begins.
