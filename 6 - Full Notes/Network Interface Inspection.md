# Network Interface Inspection

Network interface inspection queries the adapters, addresses, gateways, connection state, and traffic statistics visible to a host. In .NET, the `System.Net.NetworkInformation` namespace exposes classes for building this local view of network operation.

The information helps diagnostics and monitoring code relate application behavior to the active interfaces and nearby network. It describes the host's observed configuration, not a complete authoritative map of every remote device.
