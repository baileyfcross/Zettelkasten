# Position-Specific Sequence Feature

A position-specific sequence feature records whether or how strongly a pattern matches at particular locations. It preserves alignment information that a whole-sequence count would remove.

Such features are valuable when the same event has different meaning at different stages. They require comparable positional structure across sequences or a normalization rule for unequal lengths.
