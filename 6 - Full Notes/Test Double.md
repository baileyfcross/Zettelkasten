# Test Double

A test double is a substitute used in place of a production collaborator during a test. Fakes, stubs, mocks, and spies provide different kinds of controlled behavior or observation.

Replacing an HTTP service or database dependency reduces external variability and lets a [[Unit Test]] concentrate on one component. The chosen double should implement only the behavior relevant to that test.
