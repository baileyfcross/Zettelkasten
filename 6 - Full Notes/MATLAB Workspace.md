# MATLAB Workspace

The MATLAB workspace is the collection of variables currently stored during a session. Variables can be scalars, vectors, matrices, strings, or other arrays.

Commands create and transform these values, and workspace inspection shows their names, sizes, and current contents. Matrix-oriented variables let the same language express both data and numerical algorithms.
