# R Poisson Regression

R Poisson regression models a count response with a logarithmic link, so exponentiated coefficients describe multiplicative changes in the expected count. An exposure term can enter as an offset when observations represent different amounts of time or opportunity.

The Poisson model equates its conditional variance and mean. Extra variation produces underestimated uncertainty unless overdispersion is recognized and handled with an alternative variance or count model.
