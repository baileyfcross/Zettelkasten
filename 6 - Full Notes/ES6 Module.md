# ES6 Module

An ES6 module is a separate JavaScript file that explicitly exports reusable values and imports the values it consumes. A module can provide several named exports or one default export, while declarations that are not exported remain local to the file.

Named imports can be destructured, renamed, or collected into a namespace object. The explicit boundary supports a component-oriented codebase because each component, helper, or reducer can publish a deliberate interface instead of relying on shared globals.
