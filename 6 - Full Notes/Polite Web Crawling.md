# Polite Web Crawling

Polite web crawling respects site terms, robots directives, authentication boundaries, and server capacity. Delays and limited concurrency reduce the chance that automated collection interferes with the service being observed.

Ethical and operational constraints are part of data quality because blocked or throttled requests create patterned omissions. A collection report should record pacing, access rules, and excluded locations rather than describing the resulting corpus as a complete copy of the site.
