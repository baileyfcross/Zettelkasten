# AWS IAM Identity Center

AWS IAM Identity Center centralizes workforce access to multiple AWS accounts and supported applications. It can use its own identity store or connect to an external identity provider, then assign permission sets to users and groups.

The service reduces the need for separate IAM users in every account and supports a single sign-on experience. Permission sets are deployed as roles in target accounts, preserving account boundaries while centralizing workforce administration.
