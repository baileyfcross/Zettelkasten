# Stepwise Refinement

Stepwise refinement develops a program through a series of increasingly detailed descriptions. At each step, a task is divided into subtasks while its data representation and interfaces are refined with criteria such as clarity, structural regularity, time, and space in view.

The early descriptions should use notation natural to the problem rather than commit immediately to programming-language syntax. Implementation begins when a subproblem is small and precise enough that its solution is evident, preserving a trace from the top-level problem to the code that realizes it.
