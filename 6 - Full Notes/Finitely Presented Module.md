# Finitely Presented Module

A module is finitely presented when it is generated by finitely many elements and the relations among a finite generating set are themselves finitely generated. Equivalently, it has an exact presentation Rᵐ → Rⁿ → M → 0 with finite m and n.

Finite presentation is stronger than finite generation. It is the finiteness condition needed for a reliable [[Local Criterion for Projectivity]].
