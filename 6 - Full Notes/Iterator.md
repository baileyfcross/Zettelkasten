# Iterator

An iterator is an object that identifies a position within a container and supplies operations for accessing an element and advancing to another position. Algorithms can work through iterators without depending on the container's internal representation.

Different iterator categories support different movement. Contiguous containers can offer random access similar to pointer arithmetic, whereas a linked container normally supports only sequential movement; requesting an operation unsupported by the iterator category is not interchangeable with traversal.
