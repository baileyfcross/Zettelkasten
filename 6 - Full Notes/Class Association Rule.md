# Class Association Rule

A class association rule is an association whose consequent is restricted to a class label. Its antecedent is a set of attribute-value conditions, while support and confidence summarize how often the pattern occurs and how reliably it implies the class.

Restricting the consequent turns pattern mining into a source of predictive rules. Minimum support can miss useful rare-class patterns, so thresholds and class-sensitive weighting require deliberate selection.
