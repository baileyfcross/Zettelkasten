# Blender Image Editor

The Blender Image Editor displays and inspects two-dimensional assets such as source images, textures, generated images, movie frames, and render results. Its available menus and panels depend on the loaded image and its mode, while the central slot provides the visible canvas for viewing, painting, masking, or comparing output.

The editor exposes image source, file path, packing, reload, color-space, alpha, and diagnostic-scope settings. In a shading workspace it supports texture and material work; in a rendering workspace it also exposes render results and slots. This shared editor connects external pixels, scene materials, and final output without treating them as the same kind of data.
