# WebSurge

WebSurge is the load-testing tool used in the book to send a controlled volume of requests to an ASP.NET Core endpoint. Its measurements make changes in request throughput and response time visible during performance work.

The tool supplies evidence, not an explanation. Query count, server traces, and implementation details are still needed to identify why one version behaves differently from another.
