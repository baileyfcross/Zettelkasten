# Adversarial Example

An adversarial example is a valid input changed by a small perturbation that causes a disproportionately large change in a model's output. Such sensitivity shows that apparent accuracy on ordinary validation cases may hide a fragile learned boundary.

The failure matters even when no attacker is present, because sensor noise, weather, or other routine variation can create related perturbations. High-stakes systems therefore need robustness tests and independent validation in addition to average accuracy; a model should not be assumed to have generalized simply because its training and validation samples were similar.
