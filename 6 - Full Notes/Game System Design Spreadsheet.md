# Game System Design Spreadsheet

A game system design spreadsheet is a workbook in which data containers communicate through references, formulas, and functions. It lets a designer organize raw game data, manipulate it consistently, ask questions of it, and expose relationships that are hard to see in disconnected lists.

Its value depends on structure rather than sheer quantity of data. A useful workbook separates inputs, calculations, outputs, and temporary work; labels what each value means; and makes later tuning safe. The workbook should support repeated iteration without forcing the designer to hunt down every occurrence of a changed number.
