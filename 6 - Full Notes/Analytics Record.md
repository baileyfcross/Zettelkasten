# Analytics Record

An analytics record is the chosen set of attributes used to represent one instance for analysis. It may mix directly captured fields with derived fields calculated from them. Designing the record defines what distinctions a later algorithm can see.

For a service customer, relevant fields might describe a contract, usage, changes in usage, life-cycle stage, or network relationships. Domain knowledge guides this selection; highly correlated fields may be redundant. Removing an irrelevant or redundant field can simplify a model and reduce opportunities to fit spurious patterns.
