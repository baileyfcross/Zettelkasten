# Linear Quadrilateral Element

A linear quadrilateral element is a four-node two-dimensional element used to cover planar domains. Each node carries in-plane translational degrees of freedom, and bilinear interpolation represents the displacement field.

Quadrilaterals can be efficient in regular regions but their accuracy deteriorates with excessive distortion. Mesh layout should align elements with geometry and important stress gradients when possible.
