# Cloud Service

A cloud service is a coordinated set of systems, components, and resources that implements a useful function or process for a consumer over a network. The consumer primarily evaluates the value delivered rather than the internal machines or software used to produce it.

Its expected scope, quality, and timeliness can be expressed in a [[Service Level Agreement]], while measurable internal targets are expressed as [[Service Level Objective]]s. A service must also exhibit the defining properties of [[Cloud Computing]] rather than merely being remotely hosted.
