# Research Software Version-to-Result Link

A research software version-to-result link records the exact code revision that generated a specific output. Version control alone preserves revisions, but it does not establish which revision, working-tree state, parameters, and inputs belonged to a particular run.

The execution record should therefore bind the result to a commit and account for uncommitted modifications. This creates a concrete form of [[Result-to-Computation Traceability]]. It also lets a researcher compare results across revisions and avoid attributing an output to the current code merely because both occupy the same project directory.
