# Probabilistic Model-Based Clustering

Model-based clustering assumes observations were generated by a mixture of probability distributions whose component memberships are unknown. Each component represents a cluster with estimable parameters.

The analyst fits the model by maximizing likelihood and can compare competing component counts or covariance structures. The result supports overlapping, probability-weighted memberships rather than only hard assignments.
