# Bus Network Topology

A bus network topology connects every node through one shared communication channel. A transmission placed on the bus can reach the attached nodes, which must determine whether the message is intended for them.

The shared channel limits infrastructure, but it also concentrates contention and failure. If the central bus becomes unavailable, every attached node can become isolated at once.
