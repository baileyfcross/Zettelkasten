# Perceptual Symbol Scaling

Perceptual symbol scaling adjusts mathematically proportional areas to compensate for systematic human underestimation of differences between symbol sizes. It can make magnitude changes more visually apparent than uncorrected [[Symbol Area Scaling]]. The correction is an empirical viewing model, not a change in the data, so the legend should display actual example values. Excessive correction can overstate differences just as badly as uncorrected radius scaling.
