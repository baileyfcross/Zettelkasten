# Highly Comparative Time-Series Analysis

Highly comparative time-series analysis computes a broad library of operations on each series and compares the resulting features across a dataset. The library spans distribution, correlation, entropy, model, and other families of temporal behavior.

This systematic approach reduces dependence on a small handpicked descriptor set and can reveal unexpected discriminators. It also requires careful handling of invalid operations, redundancy, scaling, and multiple comparisons.
