# CSS Pseudo-Elements

A pseudo-element styles a portion or generated abstraction that is not an ordinary element in the document tree. Examples include the first formatted line, the first letter, and generated `::before` or `::after` content.

First-line and first-letter styling are constrained to properties that make sense for those fragments. The generated pseudo-elements work with [[CSS Generated Content]] to insert presentational material around an element's content.
