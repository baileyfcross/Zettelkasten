# Software World Inhabitants

An inhabitant is a user engaged in the virtual world created by software. During use, the world’s objects and rules become the practical environment through which the person acts.

Thinking of users as inhabitants draws attention to learned practices, expectations, social relationships, and breakdowns. It discourages treating people as external inputs to an otherwise self-contained technical system.
