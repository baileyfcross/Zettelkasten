# Replaced and Nonreplaced Elements

A replaced element is rendered using content outside the document itself, such as an image supplied through a URL or a form control drawn by the user agent. CSS generally treats that external object as a unit with intrinsic dimensions instead of laying out its internal contents.

A nonreplaced element has content represented within the document tree, so CSS constructs and formats boxes for that content directly. The distinction affects sizing, baselines, and inline formatting in the [[CSS Box Model]].
