# MATLAB Colon Operator

The MATLAB colon operator creates regularly spaced sequences and selects ranges of array indices. An expression $a:d:b$ starts at $a$, advances by step $d$, and stops without passing $b$.

Used inside parentheses, a colon can select every entry along a dimension. It therefore supports both vector construction and [[MATLAB Array Indexing]].
