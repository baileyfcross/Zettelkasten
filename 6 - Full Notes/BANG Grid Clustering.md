# BANG Grid Clustering

BANG organizes a multidimensional grid through a hierarchical directory and evaluates the population density of its blocks. Dense neighboring blocks are combined while lower-density regions are left outside the main clusters.

The hierarchical grid supports multiresolution analysis and efficient access to occupied regions. Boundaries remain aligned with the chosen partition of the space, so shifts in origin or resolution can change which structures appear connected.
