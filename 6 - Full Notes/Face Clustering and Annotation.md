# Face Clustering and Annotation

Face clustering groups detected face instances by identity or visual similarity, often combining appearance with contextual evidence from images, videos, captions, or co-occurrence. Annotation assigns a name or semantic label to the resulting groups.

Pose, lighting, expression, age, and detection error create large within-person variation. Context can improve grouping but may also reinforce mistaken associations, so representative examples and uncertain assignments should be reviewed.
