# Spatiotemporal Point Symbol

A spatiotemporal point symbol represents a location's value at one time through size, color, or both. Repeating the mapping across panels or animation lets the same station be followed through time. Size should use area-based scaling, and color classes must remain stable across frames. If both channels encode the same value, redundancy can reinforce magnitude; if they encode different variables, the legend must explain their combination.
