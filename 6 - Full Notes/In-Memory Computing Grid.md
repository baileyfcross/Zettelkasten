# In-Memory Computing Grid

An in-memory computing grid distributes executable tasks across cluster nodes and coordinates them with memory-resident data. It emphasizes computation placement and parallel execution rather than only storing shared objects.

Combining a computing grid with an [[In-Memory Data Grid]] can reduce network transfers by running an operation on the node that owns its inputs.
