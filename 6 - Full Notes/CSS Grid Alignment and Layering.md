# CSS Grid Alignment and Layering

Grid alignment controls items within their grid areas and the track collection within the grid container. `justify-*` properties operate on the inline axis, while `align-*` properties operate on the block axis; item and content variants select the subject being aligned.

Grid items can occupy the same cells and overlap. Document order and `z-index` then determine their painting layers according to [[CSS Stacking Order]].
