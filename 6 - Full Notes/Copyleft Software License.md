# Copyleft Software License

A copyleft software license grants permission to use, study, modify, and redistribute code while requiring certain distributed derivative works to remain under the same or a compatible license. The reciprocal condition is intended to preserve freedoms as the software evolves.

Copyleft can strengthen an open commons, but it also affects which components may legally be combined. The scope varies among licenses, especially for linking, modification, and network use. Choosing between copyleft and a [[Permissive Software License for Research]] should follow the collaboration and redistribution goals of the project rather than treating all open-source licenses as equivalent.
