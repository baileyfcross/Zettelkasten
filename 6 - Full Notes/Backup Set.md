# Backup Set

A backup set is the stored output produced by one backup operation. Depending on the scheme, it may contain an entire [[Backup Fileset]] or only items that changed since an earlier backup.

Restoration may require one set or a sequence of related sets. Labels, timestamps, integrity checks, and retention rules must preserve that relationship so the required copies can be located when the primary data is unavailable.
