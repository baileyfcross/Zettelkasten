# Unity Model Import

Unity model import converts supported 3D files into project assets that can provide meshes, materials, rigs, animations, and object hierarchies. Imported model assets can then be placed in a scene or incorporated into a [[Unity Prefab]].

The conversion boundary is important: Unity uses the source file but adds engine-specific interpretation through importer settings. Scale and axis conventions should be checked immediately, because a mismatch between an art tool's units and Unity's world units can make models disproportionately large, small, or incorrectly oriented.
