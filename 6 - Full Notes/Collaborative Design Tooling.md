# Collaborative Design Tooling

Collaborative design tooling gives every team member access to current decisions, files, assignments, and discussion outcomes. A tool is useful only when its shared conventions make the project's state easier to see than scattered private messages or personal documents.

The lightest system that supports the team is usually preferable. Complexity that discourages updates creates an authoritative-looking record that no longer matches the game.
