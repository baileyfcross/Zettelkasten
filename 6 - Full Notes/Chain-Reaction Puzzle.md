# Chain-Reaction Puzzle

A chain-reaction puzzle asks the player to arrange or initiate interacting elements so one event causes a sequence of later events. Materials, forces, explosions, environmental changes, and enemy behavior can become links in the chain.

The player's work lies in anticipating propagation through the system. Because several rules interact, clear intermediate feedback is necessary: the solver must be able to see where a sequence diverged from the intended result. Reusable systemic parts make these puzzles rich without requiring every solution to be scripted separately.
