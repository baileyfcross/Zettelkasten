# Unity Console

The Unity Console collects messages produced by the editor, imported content, and running scripts. Informational logs help trace behavior, warnings identify suspicious conditions, and errors indicate failures that often prevent part of a project from functioning as intended.

Because scripts and assets interact through the editor, Console output is a central diagnostic link between authored state and runtime behavior. Reading the first relevant error and opening its source location is usually more productive than continuing to modify a scene whose underlying script does not compile.
