# Maximization Assignment Problem

A maximization assignment problem contains profits or effectiveness scores rather than costs. To use the minimization-oriented Hungarian method, every entry is subtracted from the largest matrix entry, producing an opportunity-loss matrix.

Minimizing total opportunity loss yields the same pairing that maximizes the original total profit. The reported objective must then be calculated from the selected entries in the original profit matrix, not the transformed one.
