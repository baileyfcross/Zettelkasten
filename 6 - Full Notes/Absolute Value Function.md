# Absolute Value Function

The absolute value function $f(x)=|x|$ returns the nonnegative distance of $x$ from zero. Its graph is the V-shaped union of $y=x$ for $x\geq0$ and $y=-x$ for $x<0$. Translations and scalings of this graph illustrate how a piecewise rule can remain continuous at its joining point.
