# Performance Requirement

A performance requirement defines a measurable expectation for the speed or throughput of a system under stated conditions. It may constrain response time, concurrent load, processing rate, memory use, or resource consumption.

The condition matters as much as the number. A response target without representative data volume and system load can encourage an optimization that succeeds in a demonstration but fails in normal operation.
