# Transitive Property of Inequality

The transitive property of inequality states that an ordering can pass through an intermediate value. If

$$a<b\quad\text{and}\quad b<c,$$

then

$$a<c.$$

The property allows separate comparisons to be chained and justifies the order represented on a [[Number Line]]. It also supports compound bounds: if a variable is greater than a lower boundary and less than an upper boundary, its solution belongs between them, subject to whether each endpoint is strict or inclusive.
