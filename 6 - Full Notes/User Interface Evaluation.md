# User Interface Evaluation

User interface evaluation is the analysis, assessment, and testing of a whole interface or one of its components. Its main purpose is to find usability problems so the design can be revised iteratively.

An evaluation method is a particular procedure, such as a [[Cognitive Walkthrough]], [[Heuristic Evaluation]], [[Formative Evaluation]], or [[Summative Evaluation]]. An evaluation approach combines methods in a sequence suited to a project.

Useful evidence includes system performance, user task performance, and subjective response. Speed and accuracy alone do not equal [[Usability]]; learning, comfort, [[Presence]], and other aspects of [[User Experience]] may also matter.
