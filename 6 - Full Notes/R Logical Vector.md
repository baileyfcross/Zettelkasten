# R Logical Vector

An R logical vector contains `TRUE`, `FALSE`, or missing logical values and commonly results from applying a comparison to every element of a numeric or character vector. It can participate in Boolean operations, count satisfied conditions, or select corresponding positions from another object.

Logical-to-numeric coercion maps true and false to one and zero, which can count events in a simulation. Missing comparisons remain unknown and must be handled explicitly rather than treated as false.
