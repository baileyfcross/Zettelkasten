# Dynamic User Behavior

Dynamic user behavior changes across time instead of remaining a fixed profile. Social activity may evolve simultaneously through users, actions, topics, locations, or other facets.

Time-indexed tensors can preserve these aspects and support prediction of future behavior. Efficient updates adjust a learned representation as new sparse observations arrive rather than decomposing the entire history again.
