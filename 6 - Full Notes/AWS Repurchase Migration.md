# AWS Repurchase Migration

Repurchasing replaces an existing application with a different product, commonly a software-as-a-service offering, rather than moving the original implementation. The migration effort shifts from infrastructure conversion toward product selection, data movement, integration, configuration, and user adoption. This strategy is useful when maintaining or modernizing the current system produces less value than adopting a supported replacement.
