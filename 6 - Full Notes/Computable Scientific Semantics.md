# Computable Scientific Semantics

Computable scientific semantics expresses the meaning of data, parameters, mathematical operations, and outputs in forms a machine can interpret rather than leaving them implicit in column positions, abbreviations, or prose manuals.

Explicit semantics make independent implementation and validation possible because a competent system does not need unstated domain conventions to interpret the computation. They also allow data to move among programs that share definitions. The foundation is a [[Shared Scientific Semantic Dictionary]] referenced through a [[Unique Semantic Identifier]] and enforced by [[Syntactic and Semantic Validation]].
