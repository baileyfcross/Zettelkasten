# Classed Choropleth

A classed choropleth groups numeric observations into intervals and assigns one color to each class. Classes simplify the map and make a small number of spatial patterns easy to identify, but observations on opposite sides of a boundary appear more different than nearby values within a class. The [[Choropleth Class Count]] and classification rule must therefore be disclosed in the legend.
