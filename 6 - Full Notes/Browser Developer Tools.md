# Browser Developer Tools

Browser developer tools inspect a web application's client-side execution. Their views expose console errors, loaded sources, network requests and responses, rendered elements, storage, and runtime JavaScript state.

They complement an IDE debugger by showing what the browser actually received and executed. Angular errors can include contextual file and line information, while network inspection reveals an API's status and serialized body.
