# Azure Data Explorer

Azure Data Explorer is a managed analytical service for rapidly ingesting and querying large volumes of structured and semi-structured telemetry. It uses Kusto Query Language and is well suited to logs, time-series measurements, anomaly exploration, and near-real-time dashboards. High ingestion and query speed do not make it a general transactional store; table design, retention, caching, partitioning, and update policy should follow analytical access patterns.
