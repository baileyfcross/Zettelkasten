# Atmospheric Perspective for CG Elements

Objects farther from the camera receive more intervening atmospheric color and lose apparent contrast as light is scattered. Simply scaling duplicate aircraft down does not create that depth cue; the book adds atmosphere color and adjusts dark and light densities for the jets' different distances. A compositor can place colored 2.5D cards in front of individual elements, limiting each card with the element's alpha so the photographed background remains unchanged. See [[2.5D Atmospheric Cards]].
