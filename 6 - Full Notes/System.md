# System

A system is a set of parts whose interactions form loops that create a persistent whole. The whole has properties and behaviors that do not belong to any single part and are not merely the parts added together.

Each part has [[System State|state]], a [[System Boundary|boundary]], and [[System Behavior|behaviors]]. A system may also be a part inside a larger [[System Hierarchy]], so the appropriate boundary depends on the behavior being studied.
