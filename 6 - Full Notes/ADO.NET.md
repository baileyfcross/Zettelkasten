# ADO.NET

ADO.NET is the .NET data-access framework for connecting to database systems, executing commands, reading results, and transferring data into disconnected in-memory structures. Provider-specific classes share common abstractions while adapting to systems such as SQL Server or ODBC data sources.

Its core workflow connects through a configured connection, executes a command, and consumes the result through a reader, scalar, affected-row count, or data adapter. Resource lifetime and transaction boundaries remain explicit responsibilities.
