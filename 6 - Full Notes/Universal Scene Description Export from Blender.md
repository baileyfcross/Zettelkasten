# Universal Scene Description Export from Blender

Universal Scene Description is a framework for exchanging composed 3D scene data in ASCII or binary-encoded forms such as `.usd`, `.usda`, and `.usdc`. References can connect a scene to external assets without forcing every source into the same encoding.

Blender's export can include animation, hair, UV maps, normals, materials, and selected objects. Blender 3.0 also added USD import, making the format a two-way interchange path rather than an export-only endpoint. The artist must still confirm which scene features and dependencies survive the transfer.
