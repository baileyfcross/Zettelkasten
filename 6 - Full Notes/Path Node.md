# Path Node

A path node is a deliberately placed location used as a vertex in a [[Pathfinding Graph]]. Connections between visible or reachable nodes define the routes an agent may consider.

Path-node networks can be compact but require careful authoring and may constrain movement to conspicuous corridors. A [[Navigation Mesh]] instead represents connected walkable regions and usually permits more natural choices within each region.
