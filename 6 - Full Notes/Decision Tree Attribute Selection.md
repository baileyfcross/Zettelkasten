# Decision Tree Attribute Selection

Decision tree attribute selection chooses the feature used to split the examples at a non-leaf node. Entropy-based methods compare the expected class uncertainty remaining after each candidate split.

The choice shapes every lower branch. An attribute used as a split is removed from later consideration in the basic ID3 procedure because repeating it adds no new information.
