# Java Array Type

A Java array is an object containing a fixed number of elements of one component type. Its length is established at creation and cannot change, and valid indexes run from zero through `length - 1`. Elements receive the default value for their type.

Arrays can hold primitives or references and can have multiple dimensions represented as arrays of arrays. Their runtime component type is retained, so an incompatible store through a covariant reference can fail at runtime. Resizable collections are preferable when the number of elements must change.
