# Presentation Matrix

A presentation matrix for a module M has columns that generate the [[Syzygy Module]] of a chosen generating set of M. It appears in an exact sequence Rˢ → Rᵗ → M → 0.

The matrix encodes relations among generators. Its minors define [[Fitting Ideal]]s, and its kernel supplies the next module in a free resolution.

If the coefficient ring is a principal ideal domain, equivalent presentation matrices describe isomorphic presented modules. Reducing the matrix to [[Smith Normal Form]] reveals invariant factors and a direct-sum classification.
