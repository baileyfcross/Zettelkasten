# Interactive Computing

Interactive computing lets a user issue an action and receive a response quickly enough to guide the next action. It replaces the delayed submit-and-wait cycle of batch processing with an ongoing conversation.

Terminals, displays, time-sharing, minicomputers, and personal machines each advanced this mode. Interactivity changed software from a finished calculation into an environment for exploration.
