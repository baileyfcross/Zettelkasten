# Intent Triggering

Intent triggering chooses which domain, skill, or high-level intent should receive an open-ended user request. It is essential for a broad [[Personal Virtual Assistant]] whose many capabilities cannot share one small grammar.

The trigger can rank candidate [[Assistant Skill|skills]] using the utterance together with context. After selection, a domain-specific [[Intent Classification|classifier]] extracts the detailed action and arguments.
