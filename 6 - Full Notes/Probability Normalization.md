# Probability Normalization

Probability normalization requires the probabilities of every mutually exclusive and exhaustive value of a variable to sum to one. For a discrete variable $X$, $\sum_x P(X=x)=1$.

When inference first produces values only proportional to a desired distribution, a normalization constant divides each value by their total. This preserves their relative support while turning them into a valid probability distribution.
