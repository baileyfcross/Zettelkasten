# AWS Snow Family

The AWS Snow Family supplies rugged devices for edge processing and bulk data transfer when ordinary network movement is too slow, expensive, or unavailable. Snowcone addresses smaller portable use, while Snowball Edge offers greater storage and compute capacity.

Data can be loaded locally and the device physically returned for ingestion into AWS. The workflow requires chain-of-custody, encryption, job tracking, and a verified destination; shipping an appliance is a transfer process, not an automatic migration plan.
