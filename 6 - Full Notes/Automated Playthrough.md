# Automated Playthrough

An automated playthrough drives a game through scripting or replay data so integrated behavior can be checked without continuous human input. Assertions can detect crashes, failed progress, performance violations, or outcomes outside an expected range.

It covers longer paths than a unit test while remaining repeatable. Human testing is still required for unanticipated behavior and experiential quality.
