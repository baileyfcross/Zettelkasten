# Nonlinearity

Nonlinearity occurs when a change in input does not produce a proportional change in output. Interacting feedback loops can create thresholds, oscillations, acceleration, or collapse that a linear projection would miss.

Nonlinear behavior is central to many [[Complex System|complex systems]] and [[Progression Curve|progression curves]]. It can expand a game's decision space, but it also makes prediction and balancing more difficult.
