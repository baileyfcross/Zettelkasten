# Zsh Parameter Expansion

Zsh parameter expansion uses zsh-specific flags and modifiers to substitute defaults, replace substrings, change case, and transform values. Some operations that resemble Bash expansion use different syntax, so a Bash expression cannot be assumed to work under zsh.

The expansion should be documented as zsh code and paired with a zsh interpreter directive. Its richer transformations can remove external filter processes, but that benefit is purchased with an explicit portability boundary.
