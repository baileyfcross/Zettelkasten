# Visual Scripting

Visual scripting represents operations, values, and control flow as graphical elements and connections. It lets authors assemble behavior without writing the equivalent textual syntax directly.

The visual form still defines a program that must be validated and executed. It can make local flow approachable, but large graphs need organization and abstraction so connections do not become harder to understand than text.
