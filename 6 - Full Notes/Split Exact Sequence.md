# Split Exact Sequence

A [[Short Exact Sequence]] 0 → A → B → C → 0 splits when the surjection B → C has a right inverse C → B. Equivalently, the injection A → B has a compatible left inverse.

Splitting produces an isomorphism B ≅ A ⊕ C. Projective modules force sequences ending in them to split, while injective modules force sequences beginning in them to split.
