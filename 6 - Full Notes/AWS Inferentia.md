# AWS Inferentia

AWS Inferentia is custom silicon optimized for machine-learning inference rather than model training. Inferentia-powered EC2 instances use the Neuron software stack to serve trained models with an emphasis on throughput, latency, and cost efficiency. The workload must be compiled and compatible with the accelerator, and serving architecture still needs batching, scaling, model-version, and fallback decisions around the chip.
