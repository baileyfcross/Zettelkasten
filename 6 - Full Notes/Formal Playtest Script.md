# Formal Playtest Script

A formal playtest script standardizes what investigators say, how they respond during play, the environment and duration of the session, the questions asked afterward, and the observations to record. Consistency reduces the chance that different facilitators create different test conditions.

The script should specify whether hints or follow-up questions are allowed and preserve enough investigator identity to detect facilitator bias. It does not make the session mechanically rigid; it defines which variations would contaminate the comparison and which probes are part of the method.
