# Roblox Developer Exchange

The Roblox Developer Exchange program provides an eligible creator a path to convert earned Robux into money through the platform's required account and payment process. Participation depends on current eligibility, compliance, account standing, and transaction rules.

Exchange rates and requirements can change, so financial planning should use current official terms rather than values printed in an older guide. DevEx sits after creation and monetization: [[Roblox Game Pass]], [[Roblox Developer Product]], and [[Roblox Premium Payout]] can generate Robux, but exchange is a separate operational process with its own conditions.
