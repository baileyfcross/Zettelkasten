# Microsoft Entra Verified ID

Microsoft Entra Verified ID is an issuance and verification service for digital credentials based on decentralized identifiers and the W3C Verifiable Credentials model. An organization can issue a signed claim, a person can keep it in a wallet, and another organization can verify it without receiving an account from the original issuer.

The service uses a did:web authority, credential definitions, issuance and presentation APIs, and callback endpoints that report the result to an application. The trust model still requires the verifier to decide which issuers and credential types it accepts and to check status or revocation. Verified ID improves selective, portable proof; it does not make every self-presented claim authoritative.
