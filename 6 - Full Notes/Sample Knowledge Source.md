# Sample Knowledge Source

A sample knowledge source describes categories or pairwise relationships among the observations being analyzed. Class labels, class hierarchies, and auxiliary measurements of the same subjects can each supply evidence about which samples should be considered similar.

Unlike a [[Feature Knowledge Source]], sample knowledge is often tied to a particular experiment. It can be represented directly as a [[Sample Similarity Matrix]] or converted from categories, allowing heterogeneous sources to guide the same spectral selection mechanism.
