# Live CAD-FEM Link

A live CAD-FEM link maintains an active connection through which parameter changes in the authoring tool rebuild the geometry used by an analysis model. The link can support design sweeps without repeatedly exporting and importing files.

Useful associativity requires more than refreshed shape. Selections, materials, mesh controls, and boundary assignments must continue to identify the intended entities after every rebuild, or the automated update can silently change the physical model.
