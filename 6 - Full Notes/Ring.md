# Ring

A ring is a set with addition and multiplication such that addition forms an abelian group, multiplication is associative, and multiplication distributes over addition. The book distinguishes when multiplication is commutative and when a multiplicative identity is present.

Rings generalize integer arithmetic while allowing structures with zero divisors, nonunits, or noncommuting products.
