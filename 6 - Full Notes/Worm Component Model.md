# Worm Component Model

The worm component model describes a [[Computer Worm]] through target selection, propagation, activation, and payload behavior. Target selection identifies reachable systems, propagation transfers or executes the worm, activation determines when it runs, and the payload carries out its effect.

Separating these functions helps defenders locate intervention points. Reducing exposed targets, correcting exploited weaknesses, blocking propagation traffic, and limiting payload privileges can each disrupt a different part of the worm's operation.
