# CSS Text Transformation

The `text-transform` property changes the displayed capitalization of text without changing the underlying document content. It can request uppercase, lowercase, capitalization, or no transformation.

Because the transformation is presentational, copied or otherwise processed content can retain its source spelling. The exact result of case conversion depends on the document language and the user agent's handling of language-specific rules.
