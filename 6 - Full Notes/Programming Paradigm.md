# Programming Paradigm

A programming paradigm is a broad model for expressing computation and organizing programs. It describes which entities are central, such as commands, functions, rules, or objects, and how those entities relate to state and execution.

Languages can support several paradigms at once. C++ combines [[Imperative Programming]], [[Procedural Programming]], and object-oriented mechanisms, while R combines functional evaluation with object systems; selecting a paradigm is therefore a design choice as well as a language choice.
