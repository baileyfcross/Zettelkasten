# Caesar Cipher

The Caesar cipher is a substitution cipher that replaces every letter by the letter a fixed number of positions later in the alphabet. If letters are numbered from 0 through 25 and the shared key is (k), encryption adds (k) modulo 26 and decryption subtracts it modulo 26. The modular operation wraps the end of the alphabet back to its beginning.

Because one shift is applied everywhere, the cipher preserves much of the plaintext's language structure and has only 25 nontrivial shifts. It is therefore vulnerable to [[Caesar Cipher Exhaustive Search]] and is useful mainly as a compact model of a [[Classical Cipher]].
