# Roblox Mesh Import

Roblox Studio can import authored three-dimensional models as mesh assets. A MeshPart represents imported geometry in the place, while the Asset Manager supports importing and organizing multiple assets, including models whose individual pieces need to remain available.

Import settings must preserve the intended scale, orientation, materials, and object separation. The resulting geometry still needs Roblox-side collision and performance decisions, because visible detail does not automatically make good physical detail. Asset availability is governed by [[Roblox Asset Identifier and Moderation]], and reusable imported assemblies can be distributed through [[Roblox Package Versioning]].
