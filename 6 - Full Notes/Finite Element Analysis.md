# Finite Element Analysis

Finite element analysis is a numerical procedure that replaces a continuous engineering domain with a finite collection of simpler elements connected at nodes. An assumed response inside each element relates nodal unknowns to loads or other inputs.

Element equations are assembled into a global system, modified by boundary conditions, and solved for primary field variables. Secondary quantities such as stress, strain, heat flux, or velocity are then recovered from that nodal solution.
