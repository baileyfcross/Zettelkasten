# Visual Display

A visual display is an [[Output Device]] that presents information through the human visual system. In a [[3D User Interface]], real-time graphics produce images that the device turns into perceptible light.

Important characteristics include [[Field of View]], [[Field of Regard]], [[Spatial Resolution]], screen geometry, light-transfer method, [[Refresh Rate]], ergonomics, and support for [[Depth Cue]]s. These characteristics interact with the task and technique. A front-projected screen, for example, can make direct manipulation difficult when the user's hand casts a shadow, while a wide display can make better use of peripheral vision.
