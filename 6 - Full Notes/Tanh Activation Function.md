# Tanh Activation Function

The tanh activation function is the hyperbolic tangent used as a neural activation. It has an S shape like the [[Sigmoid Activation Function]], but its output ranges from negative one to one.

Large negative input approaches negative one, zero maps to zero, and large positive input approaches one. Its negative outputs can represent an inhibitory effect while retaining a smooth function suitable for derivative-based training.
