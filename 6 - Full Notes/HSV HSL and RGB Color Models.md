# HSV HSL and RGB Color Models

RGB describes emitted color through red, green, and blue channel intensities. HSV and HSL reorganize related color choices around hue plus saturation and either value or lightness, which can be more intuitive when adjusting a palette.

These models are alternative coordinate systems, not different physical colors on the same display. Artists should watch how equal numeric changes affect perceived brightness and saturation, particularly when moving a palette between Blender, image tools, and a game engine.
