# Chain-of-Thought Prompting

Chain-of-thought prompting supplies examples or instructions that encourage a language model to work through intermediate reasoning steps before producing a final answer. The source presents it as a way to decompose complex requests into a logical sequence, clarify assumptions, and make multistep tasks easier for a model to address.

The technique does not make the intermediate text true, nor should private model reasoning be treated as an audit trail. Applications should evaluate the final answer against task evidence and use explicit, verifiable intermediate artifacts when a workflow needs inspection. [[ReAct Prompting]] extends the pattern by interleaving reasoning with actions and observations from external capabilities.
