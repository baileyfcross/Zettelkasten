# Fetch API

The Fetch API is a browser interface for making asynchronous network requests with a promise-based programming model. It offers a more direct and readable alternative to using raw [[XMLHttpRequest]] callbacks.

Angular applications normally use [[Angular HttpClient]] because it integrates with dependency injection, typed responses, interceptors, and observables. Fetch remains a browser-level alternative rather than an Angular-specific service.
