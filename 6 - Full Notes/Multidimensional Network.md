# Multidimensional Network

A multidimensional network assigns a label or dimension to each edge. The same pair of nodes can have several connections as long as each belongs to a different dimension.

Mapping every edge label to a [[Network Layer]] turns the structure into a multiplex representation. The dimensions preserve interaction types that would otherwise become one aggregated tie.
