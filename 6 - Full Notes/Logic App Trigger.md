# Logic App Trigger

A Logic App trigger is the event or condition that begins a workflow instance. It may respond to a schedule, a file appearing, a queue message, or an event produced by another connected system.

Only one starting trigger is needed, after which actions and control structures define the remaining flow. Trigger frequency and event volume also affect cost because each invocation can cause managed workflow operations to run.
