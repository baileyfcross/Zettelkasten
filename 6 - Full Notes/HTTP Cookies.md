# HTTP Cookies

An HTTP cookie is a small identifier or value a Web site asks a browser to retain and return on later requests. It supplies continuity across pages even though basic Web requests are otherwise independent.

Cookies enabled shopping sessions, preferences, and authenticated use. They also made long-term behavioral tracking possible, creating privacy concerns not anticipated by the original Web design.
