# Azure Container Apps Revision

An Azure Container Apps revision is an immutable version of an app’s template and container configuration. A deployment can create a new revision, keep one or several revisions active, and divide ingress traffic among them for staged or blue-green release behavior. Revision control separates deployment from immediate replacement, but data compatibility, background work, minimum replicas, rollback, and observability must support simultaneous versions safely.
