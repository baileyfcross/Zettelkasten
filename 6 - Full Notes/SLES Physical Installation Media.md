# SLES Physical Installation Media

A physical SLES installation requires bootable media, compatible hardware, and a boot path that the machine firmware can select. The installation image can be written to removable media, after which firmware settings determine whether the system reaches the installer and whether features such as UEFI and Secure Boot participate.

Media preparation is only one layer of readiness. Storage capacity, network access, subscription information, and a recovery plan must also be available before [[Agama Installer Workflow]] commits changes. Verifying the image and the intended target reduces the risk of diagnosing corrupt media as a hardware or installer problem.
