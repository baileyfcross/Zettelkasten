# GPS Precise Code

The GPS precise code is a long ranging sequence intended for authorized military use. It supports higher-security and higher-accuracy service than the open coarse/acquisition code and can be encrypted through anti-spoofing measures. Separating civil and protected codes allowed one constellation to serve broad public navigation while reserving authenticated capabilities for military operations.
