# Agent Role Definition

An agent role definition states the responsibility, expertise, goal, tools, and boundaries assigned to one participant in a multi-agent workflow. Clear roles reduce overlap and make it possible to judge whether an output addresses the intended part of the task.

A role is an orchestration contract rather than a fictional personality. It should limit authority, identify required evidence, and align with an [[Agent Task Contract]] so the coordinator can route work and validate results predictably.
