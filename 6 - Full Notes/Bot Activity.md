# Bot Activity

A bot activity is the structured message exchanged through Bot Framework. A message activity includes fields such as its sender, text, and activity type and is transported as JSON between a client, channel, and bot service.

The bot's activity handler receives the current turn and sends a reply activity through the turn context. A Direct Line client constructs the same kind of object when posting a user's message to an active conversation.
