# Declarative Programming

Declarative programming emphasizes what result should be produced while hiding the step-by-step mechanism that produces it. A string replacement declares the desired transformation, whereas a manual character loop exposes each branch, index, and assignment needed to perform the same work.

React applies this style to interfaces: a component describes the element tree for current data, and the rendering system handles the DOM operations. Named transformations and [[Function Composition|composition]] can make a data pipeline readable as a sequence of intentions instead of a collection of mutable control steps.
