# Business Process Control Interface

A business process control interface carries the event or command that causes another process to begin, stop, change state, or perform a defined action. It coordinates the flow of work rather than merely supplying descriptive data.

The signal should identify the relevant process instance and expected behavior. In cloud automation, delayed or repeated control events require explicit handling so the workflow does not perform the same irreversible action twice.
