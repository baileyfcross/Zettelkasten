# Random Event Impact

Random event impact is the amount by which one uncertain result can change a game's outcome. Luck is shaped jointly by event frequency and event impact: many small random events may average toward a stable distribution, while one early event with enormous consequences can dominate the whole session.

Adjusting luck therefore requires more than adding or removing rolls. A designer should examine how random results accumulate, how much choice players have in using them, and whether each event changes the final state enough to overwhelm skill. Increasing the number of low-impact events can sometimes reduce rather than increase luck dominance.

Perceived fairness is asymmetric: players readily accept an upset when they are the underdog but may treat the same probability as broken when they lose from an advantage. Randomizing initial resources before they become identified with a player, or allowing drafting and mitigation, can make uncertainty easier to accept.
