# Offsite Backup

An offsite backup stores a recovery copy in a location separated from the primary system. A fire, theft, electrical event, or local configuration error can then damage the original environment without necessarily destroying its backup.

A cloud backup service can supply this geographic separation. Sensitive data should be protected before or during transfer, and the restoration path must remain available when the primary site is not.
