# 2D Matchmove and Inverse Stabilization

A 2D track can move a replacement element with a photographed feature. The same motion can be inverted to hold the feature still for paint or other repairs; applying the original motion again returns the repaired image to the shot. The book distinguishes this stabilization and destabilization workflow from simply leaving the shot stabilized. For manual alignment, a still over moving footage in Difference blend mode becomes darkest when the images coincide, offering a visual check for a keyframed track. See [[One-Point and Two-Point Tracking]].
