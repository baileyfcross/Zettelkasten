# Exported UV Layout Guide

An exported UV layout is a transparent image of island boundaries used as a guide in an external painting application. Placing it above the artwork reveals which pixels correspond to each surface region while leaving the texture visible underneath.

The guide should match the target texture dimensions and be hidden before final export. It describes coordinates rather than adding surface detail, so changes to the UV map require a newly exported guide.
