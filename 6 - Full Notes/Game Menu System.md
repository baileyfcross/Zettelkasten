# Game Menu System

A game menu system presents interactive screens for actions such as starting play, changing settings, pausing, or managing saved data. Each screen owns visible elements and maps player input to navigation or commands.

The system must coordinate focus, selection, transitions, and return behavior across many screens. A [[Game Menu State Machine]] or [[Game Menu Stack]] makes those relationships explicit instead of scattering menu rules through individual buttons.
