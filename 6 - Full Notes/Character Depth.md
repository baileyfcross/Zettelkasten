# Character Depth

Character depth is the sense that a game character has coherent motives, traits, relationships, and possible responses beyond a visual stereotype. Depth makes behavior understandable without requiring it to be simple or entirely predictable.

It emerges from alignment among appearance, back story, mechanics, animation, dialogue, and change over time. Contradictions can add complexity when the story acknowledges them; accidental contradictions weaken credibility.
