# Discrete Sequence Classification

Discrete sequence classification assigns a category to an ordered list of symbols such as events, words, or biological elements. The same symbols in a different order can carry a different class signal.

Representations may use frequent subsequences as features, alignment distances, sequence kernels, or generative models. Effective methods balance order sensitivity against tolerance for insertions, deletions, and irrelevant intervening symbols.
