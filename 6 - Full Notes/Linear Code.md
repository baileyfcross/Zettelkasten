# Linear Code

A linear code of length $n$ over a finite field is a [[Vector Subspace]] of the field's $n$-dimensional vector space. Its dimension $k$ determines how many independent message symbols can be encoded, and the code contains $q^k$ codewords over a field with $q$ elements.

Linearity makes encoding and validation matrix operations. A [[Generator Matrix for a Linear Code]] spans the code, while a [[Parity-Check Matrix]] has the code as its null space.
