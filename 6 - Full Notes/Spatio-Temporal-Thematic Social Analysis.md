# Spatio-Temporal-Thematic Social Analysis

Spatio-temporal-thematic social analysis jointly examines what people discuss, where activity occurs, and how it changes over time. It integrates textual themes with geographic and temporal features rather than analyzing each dimension separately.

Systems such as Twitris organize these relationships for event and trend analysis. Coupled views can reveal localized emerging topics, but sampling bias and missing location data limit conclusions about the wider population.
