# .NET Assembly

A .NET assembly is a deployment unit that stores compiled intermediate language, type metadata, version information, and references to other assemblies. It commonly appears as a DLL or executable file.

Referencing an assembly makes its public types available to a project, while importing one of its namespaces shortens how those types are named in source. A NuGet package can distribute several assemblies and related resources as one versioned dependency.
