# Cognitive Service Endpoint

A cognitive service endpoint is the regional base address assigned to an Azure cognitive resource. The client combines that address with a service operation, such as face detection, and with query parameters describing the output it needs.

Endpoint and access key identify different parts of the boundary: the endpoint locates the service, while the key authorizes use of the resource. Both values must match the same deployed service for a request to succeed.
