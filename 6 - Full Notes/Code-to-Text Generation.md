# Code-to-Text Generation

Code-to-text generation produces natural-language artifacts such as summaries, docstrings, reviews, explanations, or identifier suggestions from source code. It can reduce the cost of navigating unfamiliar code and make implementation details accessible to different roles.

The generated text should remain linked to a specific code revision because an explanation becomes stale as implementation changes. Review is particularly important when a summary is used for security, architecture, or operational decisions.
