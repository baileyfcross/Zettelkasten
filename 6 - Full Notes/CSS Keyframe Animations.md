# CSS Keyframe Animations

CSS keyframe animation defines a named sequence with an `@keyframes` rule. Selectors such as `from`, `to`, or percentages associate points in the timeline with declarations, and omitted intermediate property values are interpolated where possible.

An element uses the sequence by assigning its animation name. Unlike [[CSS Transitions]], keyframes can introduce several deliberate intermediate states and can run without a separate selector state change.
