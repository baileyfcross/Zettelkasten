# Model Fitting

Model fitting is the process through which a machine-learning model learns from training examples. For a neural network, fitting changes its weights and biases so its outputs better match the desired results in the [[Training Dataset]].

A fitted model should capture a relationship that also holds for new examples. Excessively close agreement with the training collection can become [[Overfitting]], which is detected by evaluating performance on a separate [[Test Dataset]].
