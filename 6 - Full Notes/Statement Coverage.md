# Statement Coverage

Statement coverage measures whether a test suite executes each program statement at least once. Unexecuted statements are untested behavior, so coverage can expose portions of a unit that no current case reaches.

Executing every statement does not prove every decision or data condition is correct. One path can cover the statements inside a branch without testing the alternative outcome, making [[Branch Coverage]] and representative data necessary complements.
