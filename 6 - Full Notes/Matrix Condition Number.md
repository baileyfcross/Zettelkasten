# Matrix Condition Number

A matrix condition number compares the size of a nonsingular matrix with the size of its inverse, commonly $\kappa(A)=\|A\|\|A^{-1}\|$ for a chosen norm.

A value near one indicates relatively low sensitivity, while a large value warns that small coefficient, right-hand-side, or round-off errors may cause large relative errors in the solution. It measures problem sensitivity rather than algorithm quality.
