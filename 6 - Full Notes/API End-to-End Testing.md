# API End-to-End Testing

API end-to-end testing exercises a complete public workflow from an external-style client request through the deployed or production-like service and its real dependencies. It verifies the behavior a consumer observes rather than one internal collaboration.

The book includes end-to-end testing in its serverless test strategy alongside unit, integration, and load tests. Because this scope is slower and more environment-sensitive, it is best reserved for critical journeys while narrower tests provide faster diagnosis of individual rules.
