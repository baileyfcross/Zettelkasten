# Form Validation Rule

A form validation rule is a function or condition that tests one field value and returns an error when the value violates an expected constraint. Required, minimum-length, and pattern rules can be composed for a field.

React form state records the errors and whether a field has been touched so feedback appears at an appropriate time. All rules are invoked again before submission, and authoritative checks are repeated on the server.
