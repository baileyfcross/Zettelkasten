# Blender Integrated Search

Blender's integrated search helps locate an operator when its menu path or shortcut is unknown. Search is especially useful in an application whose tools are spread across many editors and contexts.

The result is both a command launcher and a learning aid: an artist can perform the operation immediately, then use the displayed result to learn the terminology Blender assigns to the action.
