# DBSCAN Neighborhood Parameters

DBSCAN uses Eps as the radius around a point and MinPts as the minimum number of observations required for a dense neighborhood. Together they determine which points can initiate cluster growth.

A radius that is too small fragments groups and creates noise; one that is too large merges structures. One global setting can struggle when densities vary.
