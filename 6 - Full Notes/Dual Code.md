# Dual Code

The dual $C^\perp$ of a linear code $C$ contains every vector orthogonal to every codeword in $C$. For an $[n,k]$ binary code, the dual has dimension $n-k$.

A parity-check matrix for $C$ serves as a generator matrix for $C^\perp$, while the transpose of a generator matrix for $C$ provides parity checks for the dual. A self-dual code equals its own dual.
