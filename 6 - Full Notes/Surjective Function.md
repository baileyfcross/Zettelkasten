# Surjective Function

A surjective function reaches every element of its codomain. Its image therefore equals the codomain.

For a surjective homomorphism, the first isomorphism theorem presents the target as a quotient of the source by the kernel.

Surjectivity depends on the declared codomain: the same assignment may be onto one codomain but not a larger one. Every codomain element must have at least one preimage.
