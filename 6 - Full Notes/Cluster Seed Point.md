# Cluster Seed Point

A cluster seed point is an initial representative used to begin a partitioning algorithm. Each observation can be assigned to its nearest seed before centroids are recomputed.

Useful seeds should cover the occupied regions of attribute space. Poorly placed or duplicate seeds can create unstable, empty, or locally suboptimal clusters.
