# Dialog Manager

A dialog manager chooses what an assistant should do next after receiving an interpreted user input. It combines the current [[Meaning Representation]] with conversation state, personal or display context, external results, and a [[Dialog Policy]].

Its actions can include asking for missing information, clarifying ambiguity, invoking a service, presenting a result, or recovering from an error. It therefore coordinates the other modules of the [[Virtual Assistant Pipeline]].
