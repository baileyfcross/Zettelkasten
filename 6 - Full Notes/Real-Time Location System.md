# Real-Time Location System

A real-time location system continuously estimates where tagged assets, vehicles, or people are within an operational environment. Unlike an RFID process that records an item only when it passes a fixed reader, an RTLS is intended to maintain current location awareness.

The location stream can support fleet routing, item-level inventory, hospital equipment retrieval, personnel authorization, and analysis of movement through a facility. Location does not explain purpose by itself, so useful deployment joins coordinates with asset identity, time, condition, and process context while placing limits on personnel surveillance.
