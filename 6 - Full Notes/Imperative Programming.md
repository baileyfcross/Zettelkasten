# Imperative Programming

Imperative programming describes a computation as a sequence of commands that change program state. Assignment, conditional branches, and loops specify how execution should progress from the current state to the desired result.

The explicit sequence maps naturally to step-by-step numerical algorithms, but shared mutable state can make interactions difficult to trace. [[Procedural Programming]] controls that complexity by grouping recurring command sequences into callable units with defined inputs and outputs.
