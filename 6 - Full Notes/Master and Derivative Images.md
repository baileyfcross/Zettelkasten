# Master and Derivative Images

A master image is the controlled reference from which delivery versions are generated. It preserves enough resolution, color, and editing latitude to support future crops, sizes, formats, and quality choices, but is usually unsuitable for direct web delivery.

A derivative is a web-ready result produced for a defined use, such as a thumbnail, hero image, density candidate, or modern-format alternative. Keeping the transformation recipe separate from the master makes variants reproducible. See [[Static Derivative Image Build Pipeline]] and [[Dynamic Image Server Request Pipeline]].
