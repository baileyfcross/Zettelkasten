# Text-to-Code Generation

Text-to-code generation transforms a natural-language request into code or retrieves relevant code for that request. It includes function generation, query generation, numeric programming, and code search based on aligned text and code representations.

Ambiguous descriptions create multiple plausible implementations, so the request should state interfaces, constraints, examples, and acceptance tests. Generated code must be integrated and validated in its actual dependency and repository context.
