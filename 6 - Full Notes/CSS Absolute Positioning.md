# CSS Absolute Positioning

An absolutely positioned box is removed from normal flow and placed through offsets relative to its containing block. That block is commonly established by the nearest ancestor whose position is not static.

Left, right, top, bottom, width, height, and automatic margins form constraint equations that determine placement and size. Because the box no longer reserves flow space, later in-flow content is laid out as if it were absent.
