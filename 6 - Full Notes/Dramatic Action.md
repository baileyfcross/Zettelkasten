# Dramatic Action

A dramatic action is a player action that changes the direction of the plot and therefore the story events the player can experience later. It is more specific than an action that merely overcomes a gameplay challenge.

The game must communicate the action's consequences well enough for agency to be meaningful. A choice that changes only hidden data or reconverges immediately without perceptible effect may feel dramatic in code but not in experience.
