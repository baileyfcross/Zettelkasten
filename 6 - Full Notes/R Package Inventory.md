# R Package Inventory

An R package inventory lists installed packages, their versions, library locations, and related metadata. Inspecting a particular package can also reveal its exported functions, datasets, documentation, and dependencies.

The inventory distinguishes what is installed from what is attached in the current session. It supports environment auditing and troubleshooting when a function is unavailable or when multiple libraries contain different versions of the same package.
