# Blender Lattice Object

A lattice object is a coarse three-dimensional control cage used to deform another object. Moving a small number of lattice points produces a smooth change across the target without editing its dense topology directly.

The lattice is a control object rather than rendered surface geometry. It is useful for broad proportion changes and reusable deformations, after which the relationship can remain adjustable or be applied before an export pipeline that cannot represent it.
