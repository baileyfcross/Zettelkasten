# Multistage FEM Data Transfer

Multistage FEM data transfer uses the output of one analysis environment as input to another when different solvers provide the required physics or expertise. For example, electromagnetic field results can be transformed into heat-generation data for a thermal model.

The transfer needs explicit mappings for coordinates, units, variables, and geometric entities. A spreadsheet, script, or delimited table can bridge the tools, but the intermediate transformation becomes part of the model and must be validated.
