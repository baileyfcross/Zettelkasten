# Blender Compositor Node Groups

A node group packages a selected portion of a compositing network into one named unit. This reduces visible cable clutter and identifies a section by its purpose, such as a background blur or character color correction.

Groups also become available from the node Add menu. A useful effect can therefore be inserted elsewhere in the file, or linked into another file, without reconstructing its internal network each time.
