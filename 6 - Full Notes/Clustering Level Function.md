# Clustering Level Function

A clustering level function records the proximity value at which each stage of a hierarchy is formed. It gives the vertical scale of a dendrogram and assigns a cophenetic proximity to every pair of observations.

Large jumps between adjacent levels can suggest a useful stopping point because the next merge joins groups that were substantially farther apart under the chosen linkage.
