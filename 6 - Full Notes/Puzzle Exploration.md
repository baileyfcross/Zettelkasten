# Puzzle Exploration

Puzzle exploration is the phase in which a solver tests actions to learn the problem space. Exploration can investigate physical layout, rules, scoring, object behavior, or a simulated world; each informative result narrows the set of plausible solutions.

Useful feedback makes failed experiments produce knowledge rather than mere rejection. Exploration may also revise [[Puzzle Goal Understanding]] when new information exposes a deeper objective. The phase continues until observations support a [[Puzzle Insight]] worth attempting.
