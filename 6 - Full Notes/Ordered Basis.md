# Ordered Basis

An ordered basis is a [[Basis]] whose vectors have a fixed sequence. The order determines which coefficient occupies each position in a coordinate tuple.

Changing the order changes the [[Coordinate Vector Relative to a Basis|coordinate vector]] even though the underlying vector is unchanged. The same ordering also determines the rows and columns of a matrix representing a linear transformation.
