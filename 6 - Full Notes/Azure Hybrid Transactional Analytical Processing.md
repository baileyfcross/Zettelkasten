# Azure Hybrid Transactional Analytical Processing

Azure hybrid transactional analytical processing serves analytics from operational data with minimal delay and without a conventional duplicated ETL copy between OLTP and OLAP systems. It seeks real-time insight while protecting transactional performance through a separate analytical representation maintained by the platform. The source identifies Synapse Link for Cosmos DB as Azure’s native mechanism for this pattern; workload isolation and consistency still require evaluation.
