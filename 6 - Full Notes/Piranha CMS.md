# Piranha CMS

Piranha CMS is a .NET content-management framework designed to integrate with ASP.NET Core applications. It supplies content APIs and a manager interface while allowing developers to define the application's content structures and rendering behavior.

The framework can manage sites, pages, posts, media, and reusable content components. Because it participates in the surrounding ASP.NET Core application, routing, dependency injection, persistence, and authorization remain part of the overall design.
