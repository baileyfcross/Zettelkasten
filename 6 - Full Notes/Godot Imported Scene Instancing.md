# Godot Imported Scene Instancing

An imported Godot scene becomes usable through an instance placed beneath a root node. Instancing preserves the imported resource as a reusable source while allowing copies to be positioned within a larger game scene.

The book's Godot 3 workflow begins with a 3D Spatial root and adds an appropriate mesh instance before placing the asset in the viewport. The durable idea is that imported content enters a node hierarchy rather than becoming an unstructured editor object.
