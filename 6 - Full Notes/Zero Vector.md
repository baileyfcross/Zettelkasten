# Zero Vector

The zero vector is the additive identity of a [[Vector Space]], satisfying $v+0=v$ for every vector $v$.

It has every component equal to zero in $\mathbb{R}^n$ and has norm zero. A set of vectors is linearly independent only when the zero vector has no nontrivial representation as their linear combination.
