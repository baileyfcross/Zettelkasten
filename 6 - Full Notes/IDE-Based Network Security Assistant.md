# IDE-Based Network Security Assistant

An IDE-based network security assistant works beside project files, code, tests, and configuration in an editor such as VS Code. Chat and agent modes can explain existing logic, propose new detection code, or coordinate edits while the practitioner views the affected files.

Repository context increases relevance and exposure at the same time. Sensitive logs, credentials, and unrelated files should be excluded, and proposed changes should be reviewed as ordinary code diffs. Access to an editor or agent mode does not authorize deployment or live network actions.
