# State-Space Controller Design

A state-space controller represents every relevant system configuration and the events that move the system between configurations. Outputs or indicators can be defined from the active state.

Unlike a probabilistic queueing model, the purpose may be to implement deterministic control logic. Explicit states and transitions make missing cases, impossible moves, and unsafe responses easier to inspect.
