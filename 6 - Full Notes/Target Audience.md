# Target Audience

A target audience is the group for whom a game is intentionally designed. It is best described through motivations, preferences, experience, and play context, with demographics included only when they matter to the design.

“Everyone” is not a useful target because players have different skills and [[Interactivity Budget|interactivity budgets]]. Audience assumptions shape game scope, complexity, presentation, and which forms of [[Player Motivation]] the experience supports.

The goal is to define the narrower audience for whom the game is being made while welcoming anyone who enjoys it. A useful [[Target Audience Composite]] replaces vague labels such as casual or hardcore with testable dimensions: willingness to learn rules, accepted failure rate, session and total time, pace, competitiveness, platform, required skills, thematic preferences, and expected [[Player Value Contribution]]. The team can revisit that profile when evaluating features and recruiting playtesters.
