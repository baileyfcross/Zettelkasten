# IoT Application Protocols

IoT application protocols define how application-specific messages are exchanged above the transport layer. MQTT supports lightweight publish-and-subscribe machine communication, CoAP serves constrained devices and networks, AMQP supports queued transactional messaging, and WebSocket maintains a persistent client-server connection.

No protocol is best for every device. Selection depends on processing and memory limits, connection stability, message size, delivery requirements, and interaction pattern. [[IoT Messaging Middleware]] can hide some differences from applications, but protocol choices still influence latency, power use, reliability, and [[Internet of Things Interoperability]].
