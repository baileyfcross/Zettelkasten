# Scatter Objects Add-On

The Scatter Objects add-on distributes instances by painting over a target surface. Density, radius, scale, randomness, rotation, offset, and seed parameters control how the selected source object is repeated.

This converts manual placement into a reproducible distribution process. It is suited to populations such as vegetation or repeated props where controlled variation matters more than individually positioning every instance.
