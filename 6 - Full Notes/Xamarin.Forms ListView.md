# Xamarin.Forms ListView

A Xamarin.Forms `ListView` displays a collection of items by applying an item template to each value. It supports selection, grouping, and cell reuse so a shared page can present repeated data efficiently.

The item source should expose changes when the list can update after binding, and each item should notify changes to displayed properties. Templates should remain lightweight because complex visual trees multiply their cost across every visible row.
