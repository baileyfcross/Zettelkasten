# Stream Classification

Stream classification predicts labels for observations that arrive continuously and often can be examined only once. A learner must update a bounded model without retaining the complete historical dataset.

The setting combines immediate prediction with incremental training. Its evaluation is temporal because the model used for a case should contain only evidence available before that case or label arrived.
