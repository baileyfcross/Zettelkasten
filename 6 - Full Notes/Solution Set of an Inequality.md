# Solution Set of an Inequality

The solution set of an inequality is the collection of all values that make the comparison true. For (x<3), every real number less than three belongs to the solution set, while three itself does not.

The set can be represented verbally, with an [[Interval]], or by [[Graphing Linear Inequalities]] on a number line. Boundary inclusion follows the symbol: (<) and (>) exclude an endpoint, while (\leq) and (\geq) include it. Substitution of a test value can verify the direction and detect sign mistakes.
