# Blender Toolbar Organization

Blender's toolbar presents tools appropriate to the current editor and interaction mode. Object mode emphasizes selection, transformation, annotation, measurement, and object creation, while Edit mode exposes component-level operations such as extrusion, inset, bevel, cuts, and sliding.

Some icons contain hidden tool families revealed by holding the pointer, and the T key toggles the toolbar. Its changing contents make mode awareness part of understanding why an expected command is or is not available.
