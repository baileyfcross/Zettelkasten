# AWS Shared Responsibility Model

The AWS shared responsibility model divides security and compliance duties between AWS and the customer. AWS protects the infrastructure that runs the cloud, including physical facilities, hardware, foundational networking, and managed service infrastructure; the customer protects what they configure, deploy, store, and permit in the cloud.

The boundary changes with the service model. A customer manages more of the operating system and software on EC2 than in a managed database or serverless service, but responsibility for data classification, identities, permissions, and appropriate configuration never disappears.
