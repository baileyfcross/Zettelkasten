# Blender Mesh Objects

A Blender mesh object represents a polygonal surface through vertices, edges, and faces. Object Mode transforms the container as a whole, while Edit Mode changes the connected components stored in its mesh data.

Meshes are the main real-time asset form because they can be triangulated for display and exported widely. Their topology controls silhouette, shading, deformation, UV mapping, and the cost described by [[Target Hardware Polygon Budget|polygon budgets]].
