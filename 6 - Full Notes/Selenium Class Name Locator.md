# Selenium Class Name Locator

A Selenium class-name locator uses `By.className` to find an element whose class attribute contains a specified class. It is useful when a styling or semantic class consistently identifies a family of elements.

Classes are often shared and can change with presentation code, so uniqueness should not be assumed. A CSS selector can combine a class with a tag, ancestor, or attribute when the class alone is ambiguous.
