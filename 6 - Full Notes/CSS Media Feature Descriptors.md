# CSS Media Feature Descriptors

Media feature descriptors test characteristics of the output environment, including width, height, aspect ratio, orientation, resolution, color capability, and related device measurements. Many numeric features accept `min-` and `max-` prefixes to express ranges.

Feature values describe the rendering environment rather than an individual element. They are combined in [[CSS Media Queries]] to select a suitable block of presentation rules.
