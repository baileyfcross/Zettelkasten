# Layer Management Add-On

The Blender 2.7x Layer Management add-on presented the fixed twenty scene layers as a named vertical list. It added controls for visibility, selectability, and assignment that were difficult to infer from the default row of layer buttons.

Layer Groups stored combinations of layer settings as presets, similar to visibility compositions. The add-on improved the older layer system's usability; its terminology should not be projected unchanged onto Blender's later collection system.
