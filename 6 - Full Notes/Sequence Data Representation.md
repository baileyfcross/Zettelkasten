# Sequence Data Representation

Sequence data representation preserves the order of elements in objects such as event logs, biological sequences, or symbol strings. Derived variables can encode which patterns occur, where they occur, and how often they recur.

Unlike an unordered item set, a sequence distinguishes arrangements containing the same elements. Feature design must therefore specify both a pattern and the rule used to map its matches into numerical values.
