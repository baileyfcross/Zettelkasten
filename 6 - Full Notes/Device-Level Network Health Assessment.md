# Device-Level Network Health Assessment

A device-level network health assessment keeps findings attached to a specific router, switch, or firewall instead of reducing all telemetry to one fleet status. It can state which metric is abnormal, how far it is from a threshold, and what nearby evidence supports investigation.

Device role changes interpretation: high connection count means something different on a firewall than on an access switch. Location and interface count also provide context. An overall summary should be derived from these traceable assessments so an engineer can move from a headline back to the exact observations.
