# Server Manager

Server Manager is the built-in console for configuring local and remote Windows servers. It installs roles and features, groups servers, surfaces health and event information, and launches role-specific management consoles from one place. Adding remote servers lets an administrator perform many tasks without opening an interactive desktop session on every machine.

The console is especially useful for consistent role deployment because a wizard can target a server other than the one running Server Manager. Its aggregated view is not a replacement for detailed monitoring, but it provides an operational starting point and a launch surface for MMC tools. In a Server Core environment, a management workstation can run Server Manager and keep graphical administration off the managed host.
