# Selenium Multi-Select List

A Selenium multi-select list is an HTML `select` control that permits several options to remain selected. The `Select` helper can choose and deselect options by text, value, or index and can return the set of selected options.

Tests should verify both included and excluded choices because a correct count can still contain the wrong values. Deselect operations are meaningful only when the underlying select element supports multiple selection.
