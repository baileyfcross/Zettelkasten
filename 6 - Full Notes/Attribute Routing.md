# Attribute Routing

Attribute routing declares route templates and HTTP methods on controllers or action methods. The public path is visible near the code that handles it, allowing an API to express resource-specific collection, item, and related-resource routes.

Templates can include tokens and parameters, but overlapping patterns can create ambiguity. A stable resource-oriented route should communicate public identity rather than mirror an internal method name.
