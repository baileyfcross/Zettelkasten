# Stored-Program Computer

A stored-program computer keeps machine instructions in the same internal memory system used for data. The processor can fetch its next instruction at electronic speed instead of waiting for an external card deck, tape, or patch board.

This organization made programs easier to load and change and enabled code generated as data to be executed. It became the basis of most commercial computers after the 1940s.
