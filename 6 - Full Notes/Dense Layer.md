# Dense Layer

A dense layer is a [[Neural Network Layer]] in which every neuron receives connections from every unit in the preceding layer. Each connection has its own [[Neural Network Weight]], and each receiving neuron has a bias.

Dense connectivity is simple and flexible but creates many parameters. A layer of 128 neurons following 784 input values requires 100,352 separate connection weights, illustrating how network size can grow even with only a few layers.
