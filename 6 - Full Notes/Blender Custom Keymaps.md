# Blender Custom Keymaps

Blender's event system maps mouse and keyboard input to operators. The Keymap section of Preferences can change those mappings, making it possible to reproduce familiar shortcuts or build a workflow around frequently used actions.

Because event customization can become complicated, restore controls are important during experimentation. A finished configuration can be exported as a Python script and later imported on another installation.
