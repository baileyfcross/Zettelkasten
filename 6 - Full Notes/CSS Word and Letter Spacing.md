# CSS Word and Letter Spacing

The `word-spacing` property adjusts separation at word boundaries, while `letter-spacing` adds or removes space between character glyphs. Both accept normal spacing or a length that modifies the font's ordinary result.

These properties can interact with [[CSS Text Alignment|justification]], because a user agent may further alter spacing to fill a line. Excessive positive or negative spacing can reduce readability or make glyphs overlap.
