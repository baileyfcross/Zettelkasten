# CSS Color Filter Functions

CSS color filter functions alter the color components of rendered content. The source covers grayscale, sepia, invert, hue rotation, brightness, contrast, and saturation, each accepting a value that controls the strength of the transformation.

Several color functions can be chained, but later functions operate on colors already changed by earlier ones. Filters affect the composited element rather than rewriting its declared [[CSS RGB and Alpha Colors|CSS colors]].
