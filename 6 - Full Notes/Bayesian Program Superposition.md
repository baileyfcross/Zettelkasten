# Bayesian Program Superposition

Bayesian program superposition combines several probabilistic descriptions so their results jointly constrain a shared set of variables. Coherence relationships connect corresponding variables, and inference reconciles the contributions rather than selecting only one program.

This lets independently developed models supply complementary knowledge. The combined model must still account for dependencies among their evidence, because treating correlated contributions as independent can overstate certainty.
