# Java while and do-while Loops

A Java `while` loop checks its boolean condition before each repetition, so its body may never run. A `do-while` loop checks after the body, guaranteeing at least one execution.

Both forms fit repetition whose count is not naturally known in advance, such as reading until a sentinel or retrying until a state changes. The body must eventually affect the condition or leave through a transfer statement unless an intentional infinite loop is required.
