# Offline Loading

Offline loading allows a web application to start with selected resources when the device cannot reach the network. A service worker serves cached application files or a deliberate offline page instead of leaving startup entirely dependent on a live server.

This does not mean every feature remains available. Operations requiring fresh API or database data must expose their unavailable state and recover when connectivity returns.
