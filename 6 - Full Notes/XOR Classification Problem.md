# XOR Classification Problem

The XOR classification problem assigns one class when two binary inputs differ and another when they match. Its positive and negative cases cannot be separated by one straight decision boundary.

XOR demonstrates the limit of a single perceptron. Hidden layers combine several linear boundaries to represent the required nonlinear separation.

Kelleher places XOR in the history of threshold-logic research: a single weighted-sum threshold unit defines a straight-line boundary, so it cannot divide the four XOR cases correctly. The example demonstrates a limit of that one-layer model, not of every possible [[Artificial Neural Network|neural network]]. A [[Multilayer Perceptron]] with nonlinear hidden processing changes the representational capacity.
