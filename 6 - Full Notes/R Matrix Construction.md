# R Matrix Construction

R matrix construction arranges a vector of values into specified row and column dimensions or binds compatible vectors together as rows or columns. The fill order and vector orientation determine where each value appears, so the printed matrix should be checked against the intended scientific layout.

Row and column names can preserve the meaning of states or variables through later operations. The dimensions must be chosen before matrix multiplication because they determine which products are defined.
