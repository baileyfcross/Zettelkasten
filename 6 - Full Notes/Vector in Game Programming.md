# Vector in Game Programming

A vector in game programming is an ordered set of components used to represent spatial quantities such as position, displacement, direction, velocity, and acceleration. Whether a value behaves as a point or a direction depends on its meaning and the operation being performed.

Vectors support the same reusable geometric operations across rendering, physics, cameras, audio, and artificial intelligence. Their components make spatial relationships explicit enough to calculate.
