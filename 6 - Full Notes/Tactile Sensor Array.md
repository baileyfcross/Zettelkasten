# Tactile Sensor Array

A tactile sensor array distributes many sensing elements across a robotic finger or palm to measure the spatial pattern of contact. From those measurements a controller can estimate contact area, pressure distribution, normal force, tangential force, and the onset of object slip.

Spatial coverage helps a rigid gripper regulate force instead of treating contact as a single binary event. Array density is useful only when elements are robust, calibrated, and sampled quickly enough for control. Wiring, flexible packaging, signal processing, and damage tolerance become harder as the number of elements grows.
