# Pattern Consequence Analysis

Pattern consequence analysis records both the flexibility a design pattern creates and the costs it introduces. Visitor makes new tree operations easy but new node types difficult; Strategy supports replacement but adds indirection and compatibility checks.

The analysis keeps a pattern from being adopted as decoration. A useful design chooses a consequence profile that matches the changes expected in the clustering library.
