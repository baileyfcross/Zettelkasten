# Selenium Action Chain

A Selenium action chain builds a sequence of low-level mouse, keyboard, or wheel inputs before executing them. The `Actions` builder can combine movement, button state, key state, text entry, pauses, and scrolling to reproduce an interaction whose steps depend on one another.

Chaining preserves the order of the simulated inputs. [[Selenium Action Builder Execution]] commits the accumulated sequence, making it suitable for hover menus, modified keystrokes, and drag-and-drop behavior.
