# Excel VBA User-Defined Function

An Excel VBA user-defined function is a Function procedure stored in a standard VBA module and called from worksheet cells like a built-in function. It can accept arguments, perform calculations or inspections not conveniently expressed with ordinary formulas, and return a value to its caller.

Examples include exposing a cell's formula, testing whether a cell contains a formula, reporting workbook or worksheet information, and transforming strings. A user-defined function introduces executable code and macro-enabled file requirements, so its inputs, return type, side effects, and security assumptions should be documented. It should calculate predictably rather than silently modify unrelated workbook state.
