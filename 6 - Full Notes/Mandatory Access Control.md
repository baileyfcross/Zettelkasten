# Mandatory Access Control

Mandatory access control applies permissions established by a central authority such as a system administrator. Ordinary users cannot independently change the policy merely because they own or can reach the protected object.

This model favors consistent enforcement of organizational classifications and rules. It contrasts with [[Discretionary Access Control]], in which an object's user-controlled permissions can be modified by an authorized owner.
