# Sprite Animation

Sprite animation presents a timed sequence of sprite images so a two-dimensional object appears to move or change. The current frame is commonly chosen from a [[Sprite Sheet]].

Animation speed should be stored independently from the rendering frame rate. Elapsed game time can advance the animation at its intended frames per second even when display performance varies.
