# Accelerometer Input

Accelerometer input measures acceleration along device axes and therefore includes effects of both user movement and gravity. Raw readings are noisy and do not directly provide a stable orientation.

Mobile device frameworks can combine accelerometer and gyroscope data into higher-level quantities such as gravity direction, user acceleration, and attitude. Games should prefer those processed values when they match the intended control.
