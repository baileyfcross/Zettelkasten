# Fault-Tolerance Threshold Theorem

A fault-tolerance threshold theorem states that, under a specified error model and architecture, arbitrarily long quantum computation can be performed reliably when physical error rates lie below a threshold and sufficient encoding and correction resources are supplied.

Error correction alone is not enough because imperfect correction circuits can spread or magnify faults. Fault-tolerant constructions limit that propagation so correctable errors do not become uncorrectable faster than they are removed. Every threshold claim therefore depends on precise noise, gate, locality, resource, and accuracy assumptions; it is not one universal hardware number.
