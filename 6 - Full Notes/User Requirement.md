# User Requirement

A user requirement describes what a person expects to observe or accomplish while interacting with a system. It is commonly written in natural language and may describe screens, controls, menus, input sequences, feedback, and the externally visible response to an action.

The requirement should state behavior from the user's perspective without silently substituting an implementation decision. That distinction lets a [[Functional Specification]] remain reviewable by stakeholders while design work decides how the behavior will be produced.
