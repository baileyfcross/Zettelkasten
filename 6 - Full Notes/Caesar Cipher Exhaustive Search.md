# Caesar Cipher Exhaustive Search

Caesar cipher exhaustive search tries every possible alphabet shift and inspects the resulting candidate plaintexts. With a 26-letter alphabet there are only 25 nontrivial keys, so the complete key space can be enumerated almost immediately by an automated tool.

The attack demonstrates that a reversible transformation is not secure merely because the key is unknown. If the key space is small enough to search completely, readable language identifies the correct output. This is a direct form of [[Cryptanalysis]] against the [[Caesar Cipher]].
