# Pull System

A pull system starts upstream work in response to available downstream capacity. A stage takes a completed item from the preceding stage when it can work on it, instead of receiving work pushed according to a schedule.

Pull limits queues and makes constraints visible. It works with a [[Work in Progress Limit]] so the system responds to actual flow rather than maximizing local utilization.
