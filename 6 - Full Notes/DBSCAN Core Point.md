# DBSCAN Core Point

A DBSCAN core point has at least MinPts observations inside its Eps neighborhood. It represents a locally dense location from which the algorithm can expand a cluster.

Core points connected through chains of dense neighborhoods belong to the same cluster. Nearby non-core observations may be included as border points.
