# CKAN Data Repository

A CKAN data repository publishes datasets through a catalog that can be searched by people and accessed programmatically. It separates catalog metadata from the downloadable resources that contain actual records.

An R workflow can use this structure to locate a dataset, inspect its metadata, and retrieve a selected resource reproducibly.
