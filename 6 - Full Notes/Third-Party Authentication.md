# Third-Party Authentication

Third-party authentication delegates identity verification to a trusted external provider instead of requiring every application to maintain a separate username and password. The user authenticates with the provider, which returns information the application can validate.

This can reduce repeated credentials across sites but introduces a dependency on the provider and its protocol. [[OpenID Connect]] is an identity protocol designed for this kind of exchange.
