# Processor Allocation

Processor allocation determines how many cores or processing elements each parallel application receives. The best division depends on speedup, memory and communication pressure, deadlines, and the other applications sharing the platform.

Giving more processors to one task can yield little benefit after its scaling curve flattens while delaying work that still scales efficiently.
