# Radioactive Decay

Radioactive decay is a spontaneous, random nuclear transformation. The time of one nucleus's decay cannot be predicted, but a large population follows $N=N_0e^{-\lambda t}$ with constant decay probability per unit time. Activity is $A=\lambda N$, so it falls with the same exponential law.
