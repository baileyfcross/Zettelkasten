# Blender Offset Edge Loop Cut

Offset Edge Loop Cut creates parallel loops on either side of an existing edge loop. The paired cuts add a controllable band of topology around a feature rather than inserting only one loop through the surrounding faces.

The new support edges can sharpen a subdivision result, frame an inset region, or reserve topology for later shaping. Their spacing should match the intended silhouette because closely packed loops create a tighter transition.
