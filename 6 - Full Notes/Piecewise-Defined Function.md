# Piecewise-Defined Function

A piecewise-defined function uses different formulas on specified portions of its domain. Endpoint inequalities determine which rule supplies a boundary value. This form can represent thresholds and abrupt changes, and it makes comparison of left- and right-hand behavior explicit when studying [[Continuity at a Point]] and [[One-Sided Limit]]s.
