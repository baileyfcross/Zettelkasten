# Interactive Time-Series Legend

An interactive time-series legend acts as both a decoding key and a control. Selecting an entry can apply [[Time-Series Highlighting]], hide a series, or restore it to a crowded display. This reduces overplotting while keeping all series available. The current visibility state must remain apparent, and interaction should supplement rather than replace meaningful labels because a long legend can itself become difficult to scan.
