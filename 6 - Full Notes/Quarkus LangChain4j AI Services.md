# Quarkus LangChain4j AI Services

Quarkus LangChain4j integrates declarative LangChain4j AI services with Quarkus dependency injection and configuration. A Java interface can become an injectable model-backed service whose prompts, return types, memory, retrieval, and tools are assembled by the extension.

This arrangement keeps REST resources focused on transport while the AI contract remains in a typed service. Build-time convenience still requires runtime evaluation because prompt wording and model behavior can change without producing a Java compilation error.
