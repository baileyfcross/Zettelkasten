# AWS Replatform Migration

Replatforming changes selected infrastructure components while preserving most application code and behavior. A team might move a self-managed database to a managed database or replace part of the runtime platform without redesigning the whole system. It occupies the middle ground between [[AWS Rehost Migration|rehosting]] and [[AWS Refactor Migration|refactoring]]: more cloud benefit than an unchanged move, with less time and risk than a complete redesign.
