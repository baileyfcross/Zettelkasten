# Relational Database Management System

A relational database management system represents data in relations governed by schemas and supports declarative queries, integrity rules, transactions, and controlled access. The optimizer chooses physical operations for a logical SQL request.

Traditional architectures remain strong for structured data and transactional consistency, but scaling them across massive heterogeneous datasets can require fragmentation, distributed execution, and alternative storage layouts.
