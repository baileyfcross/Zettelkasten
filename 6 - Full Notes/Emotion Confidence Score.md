# Emotion Confidence Score

An emotion confidence score is the numeric strength a model assigns to one candidate expression category for a detected face. Several categories can receive nonzero values because an image may exhibit features associated with more than one expression.

The project uses reflection to enumerate the returned emotion properties, orders them by score, and displays the name of the largest. Ranking identifies the model's strongest output but does not turn that output into certainty about what the person feels.
