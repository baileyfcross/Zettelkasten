# Azure DevOps Task Work Item

An Azure DevOps task work item describes implementation work needed to complete a backlog item or user story. Tasks make execution visible and can carry ownership, remaining effort, state, and sprint placement.

A task is not the customer outcome itself. Keeping it linked to the parent requirement prevents a list of technical activities from obscuring whether the intended behavior was delivered.
