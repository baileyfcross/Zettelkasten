# Tabulator Data Processing Workflow

A punched-card installation combined key punches, sorters, tabulators, and later calculators. Operators encoded records, sorted decks by selected columns, counted or summarized them, and carried results to the next machine.

The workflow performed sophisticated data processing even though no single device was a general computer. Human coordination supplied the program that connected specialized machines.
