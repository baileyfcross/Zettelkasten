# Business Process Information Interface

A business process information interface defines the data one process supplies to or receives from another. It specifies the meaning, structure, currency, and ownership of information needed for the receiving process to act correctly.

The interface complements a [[Business Process Control Interface]], which triggers the action. Separating control from information clarifies whether a message means that work should begin or merely provides facts that may be used later.
