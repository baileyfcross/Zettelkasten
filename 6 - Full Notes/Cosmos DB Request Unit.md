# Cosmos DB Request Unit

A Cosmos DB request unit is the service's normalized measure of database throughput. The book configures a number of request units per second for a collection, connecting performance capacity directly to the price of the managed resource.

Higher provisioned throughput permits more database work, while lower throughput reduces cost and can constrain requests. Capacity should therefore follow measured access patterns rather than being treated as an arbitrary portal default.
