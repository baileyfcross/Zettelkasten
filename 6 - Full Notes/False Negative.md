# False Negative

A false negative occurs when a procedure fails to select a feature whose alternative hypothesis is true. It is a type II error and represents a missed signal rather than a spurious discovery.

Stricter thresholds can reduce [[False Positive|false positives]] while increasing false negatives. Useful high-throughput procedures therefore balance specificity against sensitivity instead of minimizing one error type without regard to the other.
