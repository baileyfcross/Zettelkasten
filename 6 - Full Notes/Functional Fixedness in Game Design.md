# Functional Fixedness in Game Design

Functional fixedness is the tendency to see an object, mechanic, or convention only in its familiar role. It narrows the solution space by making available elements invisible as tools for a new design problem.

Brainstorming can counter the effect by separating idea generation from judgment, inviting unusual uses, and deliberately reframing the problem. The goal is not novelty for its own sake but access to solutions that established assumptions would otherwise exclude.
