# Routing and Remote Access Service

Routing and Remote Access Service lets Windows Server operate as a router, network address translator, or VPN endpoint. After the Remote Access role is installed, RRAS is configured for the required combination of LAN routing and remote access rather than becoming active with every possible function by default.

A VPN deployment must coordinate external reachability, internal addressing, authentication, certificates or shared secrets, firewall rules, and routes returned to clients. The server often has more than one network path, making [[Windows Routing Table|routing-table]] discipline essential. RRAS is infrastructure, not simply a login screen: capacity, redundancy, logging, patching, and protection of its internet-facing interface must be planned around the remote workforce it carries.
