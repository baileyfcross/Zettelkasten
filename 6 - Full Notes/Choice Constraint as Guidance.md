# Choice Constraint as Guidance

Choice constraint guides a player by limiting the alternatives available at a decision point. A small, intelligible set can make selection possible where an unrestricted space would produce confusion or choice paralysis.

Constraint need not dictate one answer. Its purpose is to shape the [[Possibility Space]] so the remaining alternatives can be compared meaningfully. Doors, tool availability, level geometry, and interface options can all narrow action while preserving the player's authorship of the final choice.
