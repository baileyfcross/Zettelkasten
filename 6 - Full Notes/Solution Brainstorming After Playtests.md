# Solution Brainstorming After Playtests

Solution brainstorming after playtests generates several ways to address a diagnosed problem before the team commits to one revision. Separating generation from judgment prevents the first plausible fix from defining the problem.

Each candidate should state which evidence it addresses and which design value it advances. A diverse set may include changing rules, information, pacing, representation, content, or the test itself.
