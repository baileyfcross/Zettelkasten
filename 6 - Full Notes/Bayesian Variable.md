# Bayesian Variable

In Bayesian programming, a variable is a set of mutually exclusive and exhaustive propositions representing its possible values. Exactly one proposition can be true, and the set covers every value recognized by the model.

The variable is not intrinsically random. Its value is either known as evidence or represented by a probability distribution conditional on current knowledge. Choosing the variables determines what distinctions the model can express.
