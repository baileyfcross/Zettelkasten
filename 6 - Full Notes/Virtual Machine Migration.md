# Virtual Machine Migration

Virtual machine migration transfers a running or paused machine's memory, device, and execution state from one host to another. It preserves a workload when a host must leave, undergo maintenance, or rebalance capacity.

In a vehicular cloud, migration must complete before the vehicle departs; dirty memory rate, image size, network bandwidth, and destination readiness determine whether that is feasible.
