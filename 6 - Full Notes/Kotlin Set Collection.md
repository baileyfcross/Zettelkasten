# Kotlin Set Collection

A Kotlin set represents membership without retaining duplicate equal elements. It is suited to questions such as whether a value is present and to set relationships where repeated occurrences do not carry additional meaning.

`setOf` exposes read-only set operations, while `mutableSetOf` allows membership to be added or removed. A set does not promise positional access like a list, so algorithms should depend on membership and iteration rather than an index.
